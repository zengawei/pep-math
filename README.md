# pep-math

人教版高中数学知识库 — 覆盖全部 5 册教材的习题、知识点、定义和例题。

> ⚠️ 本站题目均为原创编写，参考《普通高中数学课程标准》，与具体教材版本无关。

## 快速开始

```bash
npm install
npm run build:scripts
npm run build
npm run dev
```

## 技术栈

- Astro 5.x — 静态站点生成
- Tailwind CSS — 样式
- KaTeX — 数学公式渲染
- Vitest — 测试
- GitHub Pages — 部署
