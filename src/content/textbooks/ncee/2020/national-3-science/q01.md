**题目：**

已知集合 $A=\{x \mid x^2 - 2x - 3 \leqslant 0\}$，$B=\{x \mid x < 2\}$，则 $A \cap B =$

A. $\{x \mid -1 \leqslant x < 2\}$

B. $\{x \mid -1 \leqslant x \leqslant 2\}$

C. $\{x \mid x \leqslant 3\}$

D. $\{x \mid x < 2\}$

---

**解答：**

**第1步：** 求集合 $A$
> 📌 运用知识点：一元二次不等式的解法

解不等式 $x^2 - 2x - 3 \leqslant 0$：

$(x-3)(x+1) \leqslant 0$

所以 $A = \{x \mid -1 \leqslant x \leqslant 3\}$。

**第2步：** 求 $A \cap B$
> 📌 运用知识点：集合的交集运算

$A = \{x \mid -1 \leqslant x \leqslant 3\}$，$B = \{x \mid x < 2\}$

$A \cap B = \{x \mid -1 \leqslant x < 2\}$

**答案：** A

**⚠️ 易错提醒：** 解一元二次不等式时注意因式分解的符号，以及交集端点的开闭。$B$ 中 $x<2$ 是开区间，所以交集在 $x=2$ 处取开。

**💡 思路总结：** 先解不等式确定集合，再求交集时注意端点的取舍，可借助数轴辅助分析。
