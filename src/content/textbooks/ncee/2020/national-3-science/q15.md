**题目：**

设等差数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n$，$a_2 + a_4 = 10$，$S_7 = 49$，则 $a_{10} =$ \_\_\_\_\_\_。

---

**解答：**

**第1步：** 建立方程组
> 📌 运用知识点：等差数列的性质

设首项为 $a_1$，公差为 $d$。

$a_2 + a_4 = (a_1 + d) + (a_1 + 3d) = 2a_1 + 4d = 10$

即 $a_1 + 2d = 5$ ①

$S_7 = \dfrac{7(a_1 + a_7)}{2} = \dfrac{7 \times 2a_4}{2} = 7a_4 = 7(a_1 + 3d) = 49$

即 $a_1 + 3d = 7$ ②

**第2步：** 求解

② $-$ ①：$d = 2$

代入 ①：$a_1 = 5 - 4 = 1$

**第3步：** 求 $a_{10}$

$$a_{10} = a_1 + 9d = 1 + 18 = 19$$

**答案：** $\boxed{19}$

**⚠️ 易错提醒：** $S_7 = 7a_4$ 利用了等差数列性质（中间项），不要误算为 $S_7 = 7a_1 + 21d$ 后化简出错。

**💡 思路总结：** 等差数列问题常用性质：$a_m + a_n = a_p + a_q$（当 $m+n=p+q$），$S_n = na_{\frac{n+1}{2}}$（$n$ 为奇数）。
