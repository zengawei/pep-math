**题目：**

已知 $a, b, c$ 均为正数，且 $a + b + c = 1$。

(1) 证明：$ab + bc + ca \leqslant \dfrac{1}{3}$；

(2) 求 $\dfrac{1}{a} + \dfrac{1}{b} + \dfrac{1}{c}$ 的最小值。

---

**解答：**

**第1步：** 证明 $ab + bc + ca \leqslant \dfrac{1}{3}$（第(1)问）
> 📌 运用知识点：基本不等式

因为 $(a+b+c)^2 = a^2 + b^2 + c^2 + 2(ab+bc+ca) = 1$

又 $a^2 + b^2 \geqslant 2ab$，$b^2 + c^2 \geqslant 2bc$，$c^2 + a^2 \geqslant 2ca$

三式相加：$2(a^2+b^2+c^2) \geqslant 2(ab+bc+ca)$

即 $a^2 + b^2 + c^2 \geqslant ab + bc + ca$

所以 $1 = a^2 + b^2 + c^2 + 2(ab+bc+ca) \geqslant 3(ab+bc+ca)$

$$ab + bc + ca \leqslant \frac{1}{3}$$

等号在 $a = b = c = \dfrac{1}{3}$ 时成立。

**第2步：** 求 $\dfrac{1}{a} + \dfrac{1}{b} + \dfrac{1}{c}$ 的最小值（第(2)问）
> 📌 运用知识点：基本不等式的应用

$$\frac{1}{a} + \frac{1}{b} + \frac{1}{c} = \frac{a+b+c}{a} + \frac{a+b+c}{b} + \frac{a+b+c}{c}$$

$$= 3 + \left(\frac{b}{a} + \frac{a}{b}\right) + \left(\frac{c}{a} + \frac{a}{c}\right) + \left(\frac{c}{b} + \frac{b}{c}\right)$$

由基本不等式 $\dfrac{x}{y} + \dfrac{y}{x} \geqslant 2$：

$$\frac{1}{a} + \frac{1}{b} + \frac{1}{c} \geqslant 3 + 2 + 2 + 2 = 9$$

等号在 $a = b = c = \dfrac{1}{3}$ 时成立。

$\dfrac{1}{a} + \dfrac{1}{b} + \dfrac{1}{c}$ 的最小值为 $9$。

**⚠️ 易错提醒：** 第(1)问中利用 $a^2+b^2+c^2 \geqslant ab+bc+ca$ 是关键不等式，需要记住。第(2)问中"乘1法"（利用 $a+b+c=1$）是常用技巧。

**💡 思路总结：** 条件不等式证明的核心方法：①利用 $(a+b+c)^2$ 展开建立关系；②"乘1法"将条件代入目标式；③基本不等式求最值时注意验证等号条件。
