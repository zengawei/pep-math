**题目：**

在 $\triangle ABC$ 中，角 $A, B, C$ 的对边分别为 $a, b, c$，已知 $(2a - c)\cos B = b\cos C$。

(1) 求 $B$；

(2) 若 $b = 2$，求 $\triangle ABC$ 面积的最大值。

---

**解答：**

**第1步：** 利用正弦定理转化（第(1)问）
> 📌 运用知识点：正弦定理

由正弦定理 $\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C}$，将边化为角：

$$(2\sin A - \sin C)\cos B = \sin B \cos C$$

**第2步：** 化简求 $B$
> 📌 运用知识点：三角恒等变换

$$2\sin A \cos B = \sin B \cos C + \sin C \cos B = \sin(B + C)$$

因为 $A + B + C = \pi$，所以 $\sin(B+C) = \sin A$。

$$2\sin A \cos B = \sin A$$

因为 $\sin A \neq 0$，所以 $\cos B = \dfrac{1}{2}$，即 $B = \dfrac{\pi}{3}$。

**第3步：** 利用余弦定理建立关系（第(2)问）
> 📌 运用知识点：余弦定理、基本不等式

$b = 2$，由余弦定理：

$$b^2 = a^2 + c^2 - 2ac\cos B$$

$$4 = a^2 + c^2 - 2ac \cdot \frac{1}{2} = a^2 + c^2 - ac$$

**第4步：** 利用基本不等式求面积最大值

由 $a^2 + c^2 \geqslant 2ac$：

$$4 = a^2 + c^2 - ac \geqslant 2ac - ac = ac$$

所以 $ac \leqslant 4$，当 $a = c = 2$ 时取等号。

$$S = \frac{1}{2}ac\sin B = \frac{1}{2}ac \cdot \frac{\sqrt{3}}{2} = \frac{\sqrt{3}}{4}ac \leqslant \frac{\sqrt{3}}{4} \times 4 = \sqrt{3}$$

$\triangle ABC$ 面积的最大值为 $\sqrt{3}$。

**⚠️ 易错提醒：** 正弦定理"边化角"后，$\sin(B+C) = \sin A$ 这一步利用了三角形内角和为 $\pi$ 的性质，不要遗漏。基本不等式取等条件 $a=c$ 要验证。

**💡 思路总结：** 解三角形中求面积最值的常用策略：①余弦定理建立边的关系；②基本不等式求乘积范围；③代入面积公式求最值。
