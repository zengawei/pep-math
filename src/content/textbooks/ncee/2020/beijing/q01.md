**题目：** 已知集合 $A = \{0, 1, 2, 3\}$，$B = \{x \mid 0 < x \leqslant 3\}$，则 $A \cap B =$

A. $\{1, 2, 3\}$

B. $\{0, 1, 2\}$

C. $\{1, 2\}$

D. $\{0, 1, 2, 3\}$

---

**解答：**

**第1步：** 分析集合 $B$
> 📌 运用知识点：集合的表示

$B = \{x \mid 0 < x \leqslant 3\} = (0, 3]$

**第2步：** 求交集
> 📌 运用知识点：集合的交集运算

$A = \{0, 1, 2, 3\}$，$B = (0, 3]$

$A$ 中属于 $B$ 的元素：$1, 2, 3$（$0$ 不在 $B$ 中，因为 $B$ 要求 $x > 0$）

$A \cap B = \{1, 2, 3\}$

**答案：A**

**⚠️ 易错提醒：** $0 \notin B$，因为 $B$ 中 $x > 0$ 是严格不等号。求交集时注意端点的开闭。

**💡 解题思路总结：** 集合 $A$ 是有限集，逐一检查 $A$ 中每个元素是否属于 $B$ 即可。
