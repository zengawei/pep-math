**题目：** 已知椭圆 $C: \dfrac{x^2}{4} + \dfrac{y^2}{3} = 1$ 的左、右焦点分别为 $F_1$、$F_2$，过 $F_2$ 的直线 $l$ 与椭圆 $C$ 交于 $A$、$B$ 两点。

（1）求 $\triangle ABF_1$ 的周长；

（2）求 $\triangle ABF_1$ 面积的最大值。

---

**解答：**

**第1步：** 确定椭圆参数
> 📌 运用知识点：椭圆的定义

$a^2 = 4$，$b^2 = 3$，$c^2 = a^2 - b^2 = 1$。$a = 2$，$c = 1$。

$F_1(-1, 0)$，$F_2(1, 0)$。

**第2步：** 求周长
> 📌 运用知识点：椭圆的定义

$|AF_1| + |AF_2| = 2a = 4$

$|BF_1| + |BF_2| = 2a = 4$

$\triangle ABF_1$ 的周长 $= |AF_1| + |BF_1| + |AB|$

$= |AF_1| + |BF_1| + |AF_2| + |BF_2|$

$= (|AF_1| + |AF_2|) + (|BF_1| + |BF_2|) = 4 + 4 = 8$

$$\boxed{\text{周长} = 8}$$

**第3步：** 求面积最大值
> 📌 运用知识点：圆锥曲线的最值问题

设直线 $l: x = my + 1$（过 $F_2(1, 0)$）。

代入椭圆方程：$\dfrac{(my+1)^2}{4} + \dfrac{y^2}{3} = 1$

$3(my+1)^2 + 4y^2 = 12$

$(3m^2 + 4)y^2 + 6my - 9 = 0$

$y_1 + y_2 = \dfrac{-6m}{3m^2 + 4}$，$y_1 y_2 = \dfrac{-9}{3m^2 + 4}$

**第4步：** 计算面积

$|AB| = \sqrt{1 + m^2} \cdot |y_1 - y_2|$

$F_1$ 到直线 $x - my - 1 = 0$ 的距离 $d = \dfrac{|-1 - 0 - 1|}{\sqrt{1 + m^2}} = \dfrac{2}{\sqrt{1 + m^2}}$

$S = \dfrac{1}{2}|AB| \cdot d = \dfrac{1}{2} \cdot \sqrt{1+m^2} \cdot |y_1 - y_2| \cdot \dfrac{2}{\sqrt{1+m^2}} = |y_1 - y_2|$

$|y_1 - y_2|^2 = (y_1 + y_2)^2 - 4y_1 y_2 = \dfrac{36m^2}{(3m^2+4)^2} + \dfrac{36}{3m^2+4} = \dfrac{36m^2 + 36(3m^2+4)}{(3m^2+4)^2} = \dfrac{144m^2 + 144}{(3m^2+4)^2} = \dfrac{144(m^2+1)}{(3m^2+4)^2}$

令 $t = m^2 + 1 \geqslant 1$，$3m^2 + 4 = 3t + 1$。

$S^2 = \dfrac{144t}{(3t+1)^2}$

令 $f(t) = \dfrac{t}{(3t+1)^2}$，$f'(t) = \dfrac{(3t+1)^2 - 6t(3t+1)}{(3t+1)^4} = \dfrac{1 - 3t}{(3t+1)^3}$

$f'(t) = 0 \implies t = \dfrac{1}{3}$，但 $t \geqslant 1$，所以 $f'(t) < 0$，$f(t)$ 在 $[1, +\infty)$ 上递减。

$f(t)$ 在 $t = 1$（即 $m = 0$）时取最大值：$f(1) = \dfrac{1}{16}$

$S_{\max}^2 = 144 \times \dfrac{1}{16} = 9$，$S_{\max} = 3$

$$\boxed{S_{\max} = 3}$$

**⚠️ 易错提醒：** 设直线时 $x = my + 1$ 可以包含斜率不存在的情况（$m = 0$ 对应竖直线）。面积化简后恰好消去了 $\sqrt{1+m^2}$，要仔细检查。

**💡 解题思路总结：** 椭圆焦点三角形的周长利用定义直接得出。面积最值通过联立方程、韦达定理转化为函数最值问题。
