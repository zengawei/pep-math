**题目：** 已知函数 $f(x) = 2\sin x \cos x + 2\sqrt{3}\cos^2 x - \sqrt{3}$。

（1）求 $f(x)$ 的最小正周期；

（2）求 $f(x)$ 在区间 $\left[0, \dfrac{\pi}{2}\right]$ 上的最大值和最小值。

---

**解答：**

**第1步：** 化简 $f(x)$
> 📌 运用知识点：三角恒等变换

$f(x) = 2\sin x \cos x + 2\sqrt{3}\cos^2 x - \sqrt{3}$

$= \sin 2x + \sqrt{3}(2\cos^2 x - 1)$

$= \sin 2x + \sqrt{3}\cos 2x$

$= 2\left(\dfrac{1}{2}\sin 2x + \dfrac{\sqrt{3}}{2}\cos 2x\right)$

$= 2\sin\left(2x + \dfrac{\pi}{3}\right)$

**第2步：** 求最小正周期

$$T = \frac{2\pi}{2} = \pi$$

$$\boxed{T = \pi}$$

**第3步：** 求在 $\left[0, \dfrac{\pi}{2}\right]$ 上的最值
> 📌 运用知识点：三角函数的最值

当 $x \in \left[0, \dfrac{\pi}{2}\right]$ 时，$2x + \dfrac{\pi}{3} \in \left[\dfrac{\pi}{3}, \dfrac{4\pi}{3}\right]$。

**第4步：** 分析 $\sin$ 在此区间的取值

- 当 $2x + \dfrac{\pi}{3} = \dfrac{\pi}{2}$，即 $x = \dfrac{\pi}{12}$ 时，$\sin\left(2x + \dfrac{\pi}{3}\right) = 1$，$f(x) = 2$（最大值）
- 当 $2x + \dfrac{\pi}{3} = \dfrac{4\pi}{3}$，即 $x = \dfrac{\pi}{2}$ 时，$\sin\left(\dfrac{4\pi}{3}\right) = -\dfrac{\sqrt{3}}{2}$，$f(x) = -\sqrt{3}$（最小值）

$$\boxed{f(x)_{\max} = 2，f(x)_{\min} = -\sqrt{3}}$$

**⚠️ 易错提醒：** 化简时 $2\cos^2 x - 1 = \cos 2x$（二倍角公式），不要与 $1 - 2\sin^2 x$ 混淆。求最值时注意角的范围。

**💡 解题思路总结：** 三角函数化简的核心是利用二倍角公式和辅助角公式化为 $A\sin(\omega x + \varphi)$ 的形式，再根据角的范围求最值。
