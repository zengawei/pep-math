**题目：** 某班组织知识竞赛，有甲、乙、丙三道题供选手选择。已知某选手选择甲、乙、丙三道题答对的概率分别为 $\dfrac{3}{4}$、$\dfrac{2}{3}$、$\dfrac{1}{2}$，且各题作答相互独立。该选手随机等可能地选择一道题作答。

（1）求该选手答对所选题目的概率；

（2）若已知该选手答对了所选题目，求他选择的是甲题的概率。

---

**解答：**

**第1步：** 设定事件
> 📌 运用知识点：全概率公式

设事件 $A_1, A_2, A_3$ 分别表示选择甲、乙、丙题，$B$ 表示答对。

$P(A_1) = P(A_2) = P(A_3) = \dfrac{1}{3}$

$P(B|A_1) = \dfrac{3}{4}$，$P(B|A_2) = \dfrac{2}{3}$，$P(B|A_3) = \dfrac{1}{2}$

**第2步：** 用全概率公式求 $P(B)$

$$P(B) = P(A_1)P(B|A_1) + P(A_2)P(B|A_2) + P(A_3)P(B|A_3)$$

$$= \frac{1}{3} \times \frac{3}{4} + \frac{1}{3} \times \frac{2}{3} + \frac{1}{3} \times \frac{1}{2}$$

$$= \frac{1}{3}\left(\frac{3}{4} + \frac{2}{3} + \frac{1}{2}\right) = \frac{1}{3} \times \frac{9 + 8 + 6}{12} = \frac{1}{3} \times \frac{23}{12} = \frac{23}{36}$$

$$\boxed{P(B) = \frac{23}{36}}$$

**第3步：** 用贝叶斯公式求 $P(A_1|B)$
> 📌 运用知识点：条件概率

$$P(A_1|B) = \frac{P(A_1)P(B|A_1)}{P(B)} = \frac{\dfrac{1}{3} \times \dfrac{3}{4}}{\dfrac{23}{36}} = \frac{\dfrac{1}{4}}{\dfrac{23}{36}} = \frac{1}{4} \times \frac{36}{23} = \frac{9}{23}$$

$$\boxed{P(A_1|B) = \frac{9}{23}}$$

**⚠️ 易错提醒：** 全概率公式中各分支的概率要乘上选择该分支的概率（$\frac{1}{3}$），不要遗漏。贝叶斯公式的分子只是对应分支的贡献。

**💡 解题思路总结：** "先随机选择再作答"是典型的全概率模型。"已知结果反推原因"用贝叶斯公式。
