**题目：**

已知函数 $f(x) = |x - 1| + |x + 2|$。

（1）求不等式 $f(x) \leq 5$ 的解集；

（2）若关于 $x$ 的不等式 $f(x) < a$ 有解，求 $a$ 的取值范围。

---

**解答：**

**第1步：** 分段讨论（第1问）。

零点为 $x = 1$ 和 $x = -2$，分三段。

当 $x < -2$ 时：$f(x) = -(x-1) - (x+2) = -2x - 1$。

$-2x - 1 \leq 5 \implies x \geq -3$。所以 $-3 \leq x < -2$。

> 📌 运用知识点：quadratic-inequality

**第2步：** 当 $-2 \leq x \leq 1$ 时：$f(x) = -(x-1) + (x+2) = 3$。

$3 \leq 5$ 恒成立。所以 $-2 \leq x \leq 1$。

> 📌 运用知识点：inequality-properties

**第3步：** 当 $x > 1$ 时：$f(x) = (x-1) + (x+2) = 2x + 1$。

$2x + 1 \leq 5 \implies x \leq 2$。所以 $1 < x \leq 2$。

合并：解集为 $[-3, 2]$。

> 📌 运用知识点：quadratic-inequality

**第4步：** 第（2）问。

由分析知 $f(x)_{\min} = 3$（在 $[-2, 1]$ 上取到）。

$f(x) < a$ 有解 $\iff a > f(x)_{\min} = 3$。

> 📌 运用知识点：inequality-properties

**$a$ 的取值范围为 $(3, +\infty)$。**

**⚠️ 易错提醒：**
1. 绝对值不等式分段讨论时注意分界点归属。
2. "有解"只需 $a > f(x)_{\min}$；若改为"恒成立"则需 $a > f(x)_{\max}$（此函数无最大值）。

**💡 解题思路总结：** 绝对值函数：①找零点分段讨论；②利用三角不等式 $|x-1| + |x+2| \geq |(x-1)-(x+2)| = 3$ 直接得最小值。
