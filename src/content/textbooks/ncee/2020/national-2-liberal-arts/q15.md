**题目：**

在 $\triangle ABC$ 中，$a = 5, b = 7, c = 8$，则 $\cos B = $ ______。

---

**解答：**

**第1步：** 利用余弦定理。

$$\cos B = \frac{a^2 + c^2 - b^2}{2ac} = \frac{25 + 64 - 49}{2 \times 5 \times 8} = \frac{40}{80} = \frac{1}{2}$$

> 📌 运用知识点：trig-identity

**正确答案：** $\dfrac{1}{2}$

**⚠️ 易错提醒：** 余弦定理 $\cos B = \frac{a^2 + c^2 - b^2}{2ac}$，分子中减的是 $b^2$（角 $B$ 的对边），不要搞混。

**💡 解题思路总结：** 已知三边求角，直接用余弦定理。
