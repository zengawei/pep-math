**题目：**

在 $\triangle ABC$ 中，角 $A, B, C$ 的对边分别为 $a, b, c$，已知 $a\cos B + b\cos A = c\sin C$。

（1）求角 $C$ 的大小；

（2）若 $c = 2$，$a + b = 4$，求 $\triangle ABC$ 的面积。

---

**解答：**

**第1步：** 利用正弦定理化简（第1问）。

由正弦定理，$a = 2R\sin A$，$b = 2R\sin B$，$c = 2R\sin C$。

代入：$2R\sin A\cos B + 2R\sin B\cos A = 2R\sin C \cdot \sin C$

$\sin A\cos B + \sin B\cos A = \sin^2 C$

$\sin(A + B) = \sin^2 C$

因为 $A + B = \pi - C$，$\sin(A + B) = \sin C$。

所以 $\sin C = \sin^2 C$，即 $\sin C(1 - \sin C) = 0$。

因为 $0 < C < \pi$，$\sin C > 0$，所以 $\sin C = 1$，$C = \dfrac{\pi}{2}$。

> 📌 运用知识点：trig-identity

**第2步：** 利用勾股定理（第2问）。

$C = \dfrac{\pi}{2}$，$c = 2$。

$a^2 + b^2 = c^2 = 4$。

又 $(a + b)^2 = a^2 + 2ab + b^2 = 16$。

$4 + 2ab = 16 \implies ab = 6$。

> 📌 运用知识点：trig-function

**第3步：** 求面积。

$$S = \frac{1}{2}ab\sin C = \frac{1}{2} \times 6 \times 1 = 3$$

**$\triangle ABC$ 的面积为 $3$。**

**⚠️ 易错提醒：**
1. $\sin A\cos B + \sin B\cos A = \sin(A+B)$ 是和角公式。
2. 直角三角形中 $a^2 + b^2 = c^2$，利用 $(a+b)^2$ 展开求 $ab$。

**💡 解题思路总结：** 解三角形：①正弦定理边角互化求角；②勾股定理 + 完全平方公式求面积。
