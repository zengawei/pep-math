**题目：**

已知集合 $A = \{x \mid -1 < x < 3\}$，$B = \{x \mid x^2 - 4x + 3 \geq 0\}$，则 $A \cap B = $（）

(A) $\{x \mid -1 < x \leq 1\}$  (B) $\{x \mid -1 < x < 1\}$  (C) $\{x \mid 1 \leq x < 3\}$  (D) $\{x \mid 1 < x < 3\}$

---

**解答：**

**第1步：** 求集合 $B$。

$x^2 - 4x + 3 \geq 0 \implies (x-1)(x-3) \geq 0 \implies x \leq 1$ 或 $x \geq 3$。

$B = (-\infty, 1] \cup [3, +\infty)$。

> 📌 运用知识点：quadratic-inequality

**第2步：** 求 $A \cap B$。

$A = (-1, 3)$，$B = (-\infty, 1] \cup [3, +\infty)$。

$A \cap B = (-1, 1]$。

> 📌 运用知识点：set-operations

**正确答案：** (A)

**⚠️ 易错提醒：** 注意等号：$x^2 - 4x + 3 \geq 0$ 含等号，所以 $x = 1$ 属于 $B$。

**💡 解题思路总结：** 集合交集运算：先分别求解，再取公共部分。
