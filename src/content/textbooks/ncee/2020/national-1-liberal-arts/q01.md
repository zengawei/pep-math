**题目：**

已知集合 $A = \{x \mid x^2 - 3x - 4 \leq 0\}$，$B = \{x \mid |x| \leq 2\}$，则 $A \cap B = $（）

(A) $\{x \mid -1 \leq x \leq 2\}$  (B) $\{x \mid -2 \leq x \leq 4\}$  (C) $\{x \mid -2 \leq x \leq -1\}$  (D) $\{x \mid 1 \leq x \leq 4\}$

---

**解答：**

**第1步：** 求集合 $A$。

解不等式 $x^2 - 3x - 4 \leq 0$，因式分解得 $(x - 4)(x + 1) \leq 0$，解得 $-1 \leq x \leq 4$。

因此 $A = [-1, 4]$。

> 📌 运用知识点：quadratic-inequality

**第2步：** 求集合 $B$。

由 $|x| \leq 2$，得 $-2 \leq x \leq 2$。

因此 $B = [-2, 2]$。

> 📌 运用知识点：set-concept

**第3步：** 求 $A \cap B$。

$A \cap B = [-1, 4] \cap [-2, 2] = [-1, 2]$。

> 📌 运用知识点：set-operations

**正确答案：** (A)

**⚠️ 易错提醒：** 解二次不等式时要注意开口方向和因式分解的正确性；求交集时取两个区间的公共部分，不要混淆为并集。

**💡 解题思路总结：** 集合运算题的关键是先分别求出各集合的范围，再根据运算类型（交集、并集、补集）进行运算。画数轴是避免出错的有效方法。
