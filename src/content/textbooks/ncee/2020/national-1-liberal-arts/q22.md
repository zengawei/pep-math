**题目：**

已知函数 $f(x) = |x - 1| + |x + 2|$。

（1）求不等式 $f(x) \leq 5$ 的解集；

（2）若关于 $x$ 的不等式 $f(x) < a$ 有解，求 $a$ 的取值范围。

---

**解答：**

**第1步：** 分段讨论（第1问）。

零点为 $x = 1$ 和 $x = -2$，分三段讨论。

当 $x < -2$ 时：$f(x) = -(x-1) - (x+2) = -2x - 1$。

$-2x - 1 \leq 5 \implies x \geq -3$。所以 $-3 \leq x < -2$。

> 📌 运用知识点：quadratic-inequality

**第2步：** 当 $-2 \leq x \leq 1$ 时：$f(x) = -(x-1) + (x+2) = 3$。

$3 \leq 5$ 恒成立。所以 $-2 \leq x \leq 1$。

> 📌 运用知识点：inequality-properties

**第3步：** 当 $x > 1$ 时：$f(x) = (x-1) + (x+2) = 2x + 1$。

$2x + 1 \leq 5 \implies x \leq 2$。所以 $1 < x \leq 2$。

合并三段：解集为 $[-3, 2]$。

> 📌 运用知识点：quadratic-inequality

**第4步：** 求 $f(x)$ 的最小值（第2问）。

由第1问的分析，当 $-2 \leq x \leq 1$ 时 $f(x) = 3$（常数），其他区间 $f(x) > 3$。

所以 $f(x)_{\min} = 3$。

$f(x) < a$ 有解 $\iff a > f(x)_{\min} = 3$。

> 📌 运用知识点：inequality-properties

**$a$ 的取值范围为 $(3, +\infty)$。**

**⚠️ 易错提醒：**
1. 绝对值不等式要分段讨论，注意分界点的选取和每段的符号。
2. "有解"与"恒成立"不同：$f(x) < a$ 有解只需 $a > f(x)_{\min}$；若改为恒成立则需 $a > f(x)_{\max}$（但此函数无最大值）。

**💡 解题思路总结：** 含绝对值函数问题的核心方法：①找零点分段讨论；②利用三角不等式 $|a| + |b| \geq |a - b|$ 可直接得到 $f(x) \geq |(x-1)-(x+2)| = 3$。
