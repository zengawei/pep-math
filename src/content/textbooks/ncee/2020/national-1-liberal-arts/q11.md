**题目：**

从 $2, 3, 5, 7$ 四个数中随机取两个不同的数，分别作为点 $P$ 的横坐标和纵坐标，则点 $P$ 在直线 $x + y = 10$ 下方的概率为（）

(A) $\dfrac{1}{4}$  (B) $\dfrac{1}{3}$  (C) $\dfrac{1}{2}$  (D) $\dfrac{2}{3}$

---

**解答：**

**第1步：** 确定基本事件总数。

从 $4$ 个数中取 $2$ 个不同的数，分别作为横纵坐标（有序），共有 $A_4^2 = 4 \times 3 = 12$ 种。

> 📌 运用知识点：permutation

**第2步：** 找出满足 $x + y < 10$ 的点。

所有可能的点：$(2,3), (2,5), (2,7), (3,2), (3,5), (3,7), (5,2), (5,3), (5,7), (7,2), (7,3), (7,5)$。

满足 $x + y < 10$ 的点：
- $(2,3): 5 < 10$ ✓
- $(2,5): 7 < 10$ ✓
- $(2,7): 9 < 10$ ✓
- $(3,2): 5 < 10$ ✓
- $(3,5): 8 < 10$ ✓
- $(3,7): 10 < 10$ ✗
- $(5,2): 7 < 10$ ✓
- $(5,3): 8 < 10$ ✓
- $(5,7): 12 < 10$ ✗
- $(7,2): 9 < 10$ ✓
- $(7,3): 10 < 10$ ✗
- $(7,5): 12 < 10$ ✗

满足条件的有 $8$ 个。

> 📌 运用知识点：random-event-probability

**第3步：** 计算概率。

$$P = \frac{8}{12} = \frac{2}{3}$$

**正确答案：** (D)

**⚠️ 易错提醒：** 注意"在直线下方"是严格不等式 $x + y < 10$，不包括在直线上的情况（$x + y = 10$）。另外注意是有序选取（排列），不是组合。

**💡 解题思路总结：** 古典概型问题要列举所有基本事件，逐一验证条件，注意有序与无序的区别。
