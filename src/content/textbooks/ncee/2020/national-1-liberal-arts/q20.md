**题目：**

已知椭圆 $C: \dfrac{x^2}{4} + y^2 = 1$，过点 $M(1, 0)$ 的直线 $l$ 与椭圆 $C$ 交于 $A, B$ 两点。

（1）若直线 $l$ 的斜率为 $1$，求弦 $AB$ 的长度；

（2）设 $N$ 为椭圆 $C$ 的右顶点，求 $\triangle NAB$ 面积的最大值。

---

**解答：**

**第1步：** 求弦长（第1问）。

直线 $l: y = x - 1$，代入椭圆方程：

$$\frac{x^2}{4} + (x-1)^2 = 1$$

$$\frac{x^2}{4} + x^2 - 2x + 1 = 1$$

$$\frac{5x^2}{4} - 2x = 0$$

$$x\left(\frac{5x}{4} - 2\right) = 0$$

$x_1 = 0, x_2 = \dfrac{8}{5}$。

$y_1 = -1, y_2 = \dfrac{8}{5} - 1 = \dfrac{3}{5}$。

> 📌 运用知识点：conic-section-line

**第2步：** 计算弦长。

$$|AB| = \sqrt{\left(\frac{8}{5}\right)^2 + \left(\frac{3}{5} + 1\right)^2} = \sqrt{\frac{64}{25} + \frac{64}{25}} = \sqrt{\frac{128}{25}} = \frac{8\sqrt{2}}{5}$$

> 📌 运用知识点：ellipse-properties

**第3步：** 求面积最大值（第2问）。

右顶点 $N(2, 0)$。设直线 $l: y = k(x - 1)$（斜率存在时），代入椭圆方程：

$$\frac{x^2}{4} + k^2(x-1)^2 = 1$$

$$(1 + 4k^2)x^2 - 8k^2 x + 4k^2 - 4 = 0$$

$x_1 + x_2 = \dfrac{8k^2}{1 + 4k^2}$，$x_1 x_2 = \dfrac{4k^2 - 4}{1 + 4k^2}$。

> 📌 运用知识点：conic-section-line

**第4步：** 计算 $|AB|$ 和距离。

$$|AB| = \sqrt{1+k^2} \cdot \sqrt{(x_1+x_2)^2 - 4x_1 x_2} = \sqrt{1+k^2} \cdot \sqrt{\frac{64k^4}{(1+4k^2)^2} - \frac{4(4k^2-4)}{1+4k^2}}$$

$$= \sqrt{1+k^2} \cdot \frac{4\sqrt{1+3k^2}}{1+4k^2}$$

$N(2,0)$ 到直线 $kx - y - k = 0$ 的距离：

$$d = \frac{|2k - k|}{\sqrt{k^2+1}} = \frac{|k|}{\sqrt{k^2+1}}$$

> 📌 运用知识点：conic-section-optimization

**第5步：** 面积表达式。

$$S = \frac{1}{2}|AB| \cdot d = \frac{1}{2} \cdot \sqrt{1+k^2} \cdot \frac{4\sqrt{1+3k^2}}{1+4k^2} \cdot \frac{|k|}{\sqrt{1+k^2}} = \frac{2|k|\sqrt{1+3k^2}}{1+4k^2}$$

设 $t = k^2 > 0$：

$$S = \frac{2\sqrt{t(1+3t)}}{1+4t} = \frac{2\sqrt{3t^2+t}}{1+4t}$$

$$S^2 = \frac{4(3t^2+t)}{(1+4t)^2} = \frac{12t^2+4t}{16t^2+8t+1}$$

令 $f(t) = \dfrac{12t^2+4t}{16t^2+8t+1}$，求导或利用不等式：

当 $t \to +\infty$ 时 $f(t) \to \dfrac{12}{16} = \dfrac{3}{4}$，$S \to \sqrt{3}$。

通过求导可得 $f(t)$ 在 $t = \dfrac{1}{4}$ 时取最大值 $\dfrac{3}{4}$... 实际上需要更仔细计算。

令 $f'(t) = 0$：

$$f'(t) = \frac{(24t+4)(16t^2+8t+1) - (12t^2+4t)(32t+8)}{(16t^2+8t+1)^2}$$

分子 $= (24t+4)(16t^2+8t+1) - (12t^2+4t)(32t+8)$

$= 384t^3 + 192t^2 + 24t + 64t^2 + 32t + 4 - (384t^3 + 96t^2 + 128t^2 + 32t)$

$= 384t^3 + 256t^2 + 56t + 4 - 384t^3 - 224t^2 - 32t$

$= 32t^2 + 24t + 4 = 8(4t^2 + 3t + \frac{1}{2})$

Hmm, this is always positive for $t > 0$, so $f(t)$ is increasing. As $t \to \infty$, $f(t) \to 3/4$.

So $S^2 < \frac{3}{4}$, and $S < \frac{\sqrt{3}}{2}$... but the supremum is $\frac{\sqrt{3}}{2}$, not achieved.

Wait, let me reconsider. Maybe I should also check the case when the line is vertical ($x = 1$).

When $x = 1$: $\frac{1}{4} + y^2 = 1 \implies y^2 = \frac{3}{4} \implies y = \pm\frac{\sqrt{3}}{2}$.

$|AB| = \sqrt{3}$, $d = |2 - 1| = 1$.

$S = \frac{1}{2} \times \sqrt{3} \times 1 = \frac{\sqrt{3}}{2}$.

So the maximum is $\dfrac{\sqrt{3}}{2}$.

> 📌 运用知识点：conic-section-optimization

**$\triangle NAB$ 面积的最大值为 $\dfrac{\sqrt{3}}{2}$。**

**⚠️ 易错提醒：**
1. 设直线方程时要考虑斜率不存在的情况（$x = 1$）。
2. 面积最值问题需要综合考虑所有情况。

**💡 解题思路总结：** 圆锥曲线综合题的标准方法：联立直线与椭圆方程 → 韦达定理 → 弦长公式 → 面积表达式 → 求最值。
