**题目：**

已知集合 $A=\{x \mid x^2 - 3x \leqslant 0\}$，$B=\{x \mid x > 1\}$，则 $A \cap B =$

A. $\{x \mid 1 < x \leqslant 3\}$

B. $\{x \mid 0 \leqslant x < 1\}$

C. $\{x \mid x \leqslant 3\}$

D. $\{x \mid x > 1\}$

---

**解答：**

**第1步：** 求集合 $A$
> 📌 运用知识点：一元二次不等式的解法

$x^2 - 3x \leqslant 0 \Rightarrow x(x-3) \leqslant 0$

所以 $A = \{x \mid 0 \leqslant x \leqslant 3\}$。

**第2步：** 求 $A \cap B$
> 📌 运用知识点：集合的交集运算

$A = \{x \mid 0 \leqslant x \leqslant 3\}$，$B = \{x \mid x > 1\}$

$A \cap B = \{x \mid 1 < x \leqslant 3\}$

**答案：** A

**⚠️ 易错提醒：** 解 $x(x-3)\leqslant 0$ 时，根为 $x=0$ 和 $x=3$，取中间部分。交集端点处 $x=1$ 为开（$B$ 中不含 $1$），$x=3$ 为闭（$A$ 中含 $3$）。

**💡 思路总结：** 先解不等式确定集合，再借助数轴求交集，注意端点开闭。
