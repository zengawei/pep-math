**题目：**

下列函数中，既是偶函数又在 $(0, +\infty)$ 上单调递增的是

A. $f(x) = x^2$

B. $f(x) = x^3$

C. $f(x) = \cos x$

D. $f(x) = \dfrac{1}{x^2}$

---

**解答：**

**第1步：** 逐一判断奇偶性
> 📌 运用知识点：函数的奇偶性

- A：$f(-x) = (-x)^2 = x^2 = f(x)$，偶函数 ✓
- B：$f(-x) = (-x)^3 = -x^3 = -f(x)$，奇函数 ✗
- C：$f(-x) = \cos(-x) = \cos x = f(x)$，偶函数 ✓
- D：$f(-x) = \dfrac{1}{(-x)^2} = \dfrac{1}{x^2} = f(x)$，偶函数 ✓

排除 B。

**第2步：** 判断 $(0, +\infty)$ 上的单调性

- A：$f(x) = x^2$，在 $(0,+\infty)$ 上递增 ✓
- C：$f(x) = \cos x$，在 $(0,+\infty)$ 上不单调 ✗
- D：$f(x) = \dfrac{1}{x^2}$，在 $(0,+\infty)$ 上递减 ✗

**答案：** A

**⚠️ 易错提醒：** $\cos x$ 是偶函数但在 $(0,+\infty)$ 上不单调；$\frac{1}{x^2}$ 是偶函数但在 $(0,+\infty)$ 上递减。

**💡 思路总结：** 先判断奇偶性排除选项，再用导数或基本性质判断单调性。
