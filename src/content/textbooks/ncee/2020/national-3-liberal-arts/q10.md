**题目：**

已知 $a = \log_3 2$，$b = \log_4 3$，$c = \log_2 5$，则

A. $a < b < c$

B. $b < a < c$

C. $a < c < b$

D. $b < c < a$

---

**解答：**

**第1步：** 估算各值范围
> 📌 运用知识点：对数函数的性质

$a = \log_3 2$：因为 $3^0 = 1 < 2 < 3 = 3^1$，所以 $0 < a < 1$。

更精确地：$a = \dfrac{\ln 2}{\ln 3} \approx \dfrac{0.693}{1.099} \approx 0.631$

$b = \log_4 3$：因为 $4^0 = 1 < 3 < 4 = 4^1$，所以 $0 < b < 1$。

更精确地：$b = \dfrac{\ln 3}{\ln 4} \approx \dfrac{1.099}{1.386} \approx 0.793$

$c = \log_2 5$：因为 $2^2 = 4 < 5 < 8 = 2^3$，所以 $2 < c < 3$。

**第2步：** 比较大小

$$a \approx 0.631 < b \approx 0.793 < c > 2$$

所以 $a < b < c$。

**答案：** A

**⚠️ 易错提醒：** 比较对数大小时，先判断与 $0, 1$ 的关系确定大致范围，$c > 2$ 远大于 $a, b \in (0,1)$。

**💡 思路总结：** 对数值比较大小：①先与 $0, 1$ 等关键值比较确定范围；②同范围内用换底公式或中间值比较。
