**题目：**

在 $\triangle ABC$ 中，$a, b, c$ 分别为角 $A, B, C$ 的对边，已知 $a = 2$，$B = \dfrac{\pi}{4}$，$b = 2\sqrt{2}$。

(1) 求 $\sin A$；

(2) 若 $c = 2$，求 $\triangle ABC$ 的面积。

---

**解答：**

**第1步：** 利用正弦定理求 $\sin A$（第(1)问）
> 📌 运用知识点：正弦定理

$$\frac{a}{\sin A} = \frac{b}{\sin B}$$

$$\sin A = \frac{a \sin B}{b} = \frac{2 \times \dfrac{\sqrt{2}}{2}}{2\sqrt{2}} = \frac{\sqrt{2}}{2\sqrt{2}} = \frac{1}{2}$$

**第2步：** 求面积（第(2)问）
> 📌 运用知识点：三角形面积公式

已知 $a = 2$，$c = 2$，$B = \dfrac{\pi}{4}$：

$$S = \frac{1}{2}ac\sin B = \frac{1}{2} \times 2 \times 2 \times \frac{\sqrt{2}}{2} = \sqrt{2}$$

**⚠️ 易错提醒：** 第(1)问中 $\sin A = \frac{1}{2}$，$A$ 可能为 $\frac{\pi}{6}$ 或 $\frac{5\pi}{6}$，但因为 $a < b$，所以 $A < B = \frac{\pi}{4}$，$A = \frac{\pi}{6}$。第(2)问直接用面积公式，不需要先求 $A$。

**💡 思路总结：** 解三角形中，已知两边及夹角可直接用 $S = \frac{1}{2}ac\sin B$ 求面积；正弦定理用于求角。
