**题目：**

已知椭圆 $C: \dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$ $(a > b > 0)$ 的离心率为 $\dfrac{1}{2}$，且过点 $\left(1, \dfrac{3}{2}\right)$。

(1) 求椭圆 $C$ 的方程；

(2) 设直线 $l: y = kx + m$ 与椭圆 $C$ 交于 $A, B$ 两点，$O$ 为原点。若 $OA \perp OB$，求 $m^2$ 与 $k$ 的关系。

---

**解答：**

**第1步：** 利用离心率建立关系（第(1)问）
> 📌 运用知识点：椭圆的离心率

$e = \dfrac{c}{a} = \dfrac{1}{2}$，$c = \dfrac{a}{2}$

$$b^2 = a^2 - c^2 = a^2 - \frac{a^2}{4} = \frac{3a^2}{4}$$

**第2步：** 代入点求 $a^2$

$$\frac{1}{a^2} + \frac{9/4}{3a^2/4} = \frac{1}{a^2} + \frac{3}{a^2} = \frac{4}{a^2} = 1$$

$a^2 = 4$，$b^2 = 3$。

椭圆方程：$\dfrac{x^2}{4} + \dfrac{y^2}{3} = 1$

**第3步：** 联立直线与椭圆（第(2)问）
> 📌 运用知识点：直线与椭圆的位置关系

将 $y = kx + m$ 代入椭圆方程：

$$3x^2 + 4(kx+m)^2 = 12$$

$$(3+4k^2)x^2 + 8kmx + 4m^2 - 12 = 0$$

由韦达定理：

$$x_1 + x_2 = \frac{-8km}{3+4k^2}, \quad x_1 x_2 = \frac{4m^2-12}{3+4k^2}$$

**第4步：** 利用 $OA \perp OB$ 的条件

$OA \perp OB \Leftrightarrow x_1 x_2 + y_1 y_2 = 0$

$$y_1 y_2 = (kx_1+m)(kx_2+m) = k^2 x_1 x_2 + km(x_1+x_2) + m^2$$

$$x_1 x_2 + y_1 y_2 = (1+k^2)x_1 x_2 + km(x_1+x_2) + m^2 = 0$$

代入韦达定理的结果：

$$(1+k^2) \cdot \frac{4m^2-12}{3+4k^2} + km \cdot \frac{-8km}{3+4k^2} + m^2 = 0$$

两边乘以 $3+4k^2$：

$$(1+k^2)(4m^2-12) - 8k^2 m^2 + m^2(3+4k^2) = 0$$

展开：

$$4m^2 - 12 + 4k^2 m^2 - 12k^2 - 8k^2 m^2 + 3m^2 + 4k^2 m^2 = 0$$

合并同类项：

$$7m^2 - 12 - 12k^2 = 0$$

$$m^2 = \frac{12(1+k^2)}{7}$$

**⚠️ 易错提醒：** 韦达定理代入后展开化简要仔细，注意 $k^2 m^2$ 项的合并：$4k^2m^2 - 8k^2m^2 + 4k^2m^2 = 0$，恰好消去。

**💡 思路总结：** 椭圆中垂直条件的处理：联立→韦达定理→将 $x_1 x_2 + y_1 y_2 = 0$ 展开代入，化简得参数关系。
