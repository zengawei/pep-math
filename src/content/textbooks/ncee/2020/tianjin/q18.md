**题目：** 某学校为了解学生对食堂的满意度，随机调查了 $100$ 名学生，其中男生 $60$ 名，女生 $40$ 名。调查结果如下：男生中满意的有 $40$ 名，不满意的有 $20$ 名；女生中满意的有 $20$ 名，不满意的有 $20$ 名。

（1）根据以上数据完成 $2 \times 2$ 列联表，并判断能否有 $95\%$ 的把握认为"对食堂是否满意"与"性别"有关；

（2）从不满意的学生中随机抽取 $2$ 人，求恰好抽到 $1$ 名男生和 $1$ 名女生的概率。

附：$K^2 = \dfrac{n(ad - bc)^2}{(a+b)(c+d)(a+c)(b+d)}$，其中 $n = a + b + c + d$。

| | 满意 | 不满意 | 合计 |
|---|---|---|---|
| 男 | | | |
| 女 | | | |
| 合计 | | | |

$P(K^2 \geqslant 3.841) = 0.05$

---

**解答：**

**第1步：** 完成列联表
> 📌 运用知识点：列联表

| | 满意 | 不满意 | 合计 |
|---|---|---|---|
| 男 | $40$ | $20$ | $60$ |
| 女 | $20$ | $20$ | $40$ |
| 合计 | $60$ | $40$ | $100$ |

**第2步：** 计算 $K^2$
> 📌 运用知识点：独立性检验

$a = 40$，$b = 20$，$c = 20$，$d = 20$，$n = 100$。

$$K^2 = \frac{100 \times (40 \times 20 - 20 \times 20)^2}{60 \times 40 \times 60 \times 40}$$

$$= \frac{100 \times (800 - 400)^2}{5760000} = \frac{100 \times 160000}{5760000} = \frac{16000000}{5760000} \approx 2.78$$

因为 $2.78 < 3.841$，所以没有 $95\%$ 的把握认为"满意度"与"性别"有关。

**第3步：** 求概率
> 📌 运用知识点：古典概型

不满意的学生共 $40$ 人，其中男生 $20$ 人，女生 $20$ 人。

从 $40$ 人中抽 $2$ 人，总选法 $C_{40}^2 = 780$。

恰好 $1$ 男 $1$ 女的选法：$C_{20}^1 \times C_{20}^1 = 400$。

$$P = \frac{400}{780} = \frac{20}{39}$$

**答案：（1）列联表见解答，$K^2 \approx 2.78 < 3.841$，没有 $95\%$ 的把握认为有关；（2）$P = \dfrac{20}{39}$。**

**⚠️ 易错提醒：** 独立性检验中，$K^2$ 的值要与临界值比较，只有 $K^2$ 大于等于临界值才能认为有关。

**💡 解题思路总结：** 独立性检验的步骤：列联表→计算 $K^2$→与临界值比较→得出结论。古典概型注意"恰好"的含义。
