**题目：** 已知抛物线 $C: y^2 = 2px$（$p > 0$）的焦点为 $F$，过 $F$ 的直线 $l$ 与抛物线 $C$ 交于 $A$、$B$ 两点，$|AF| + |BF|$ 的最小值为 $4$。

（1）求抛物线 $C$ 的方程；

（2）当直线 $l$ 的斜率为 $1$ 时，求 $\triangle AOB$ 的面积（$O$ 为原点）。

---

**解答：**

**第1步：** 利用焦点弦性质
> 📌 运用知识点：抛物线的焦点弦

抛物线 $y^2 = 2px$ 的焦点 $F\left(\dfrac{p}{2}, 0\right)$。

设 $A(x_1, y_1)$，$B(x_2, y_2)$，由抛物线的焦半径公式：

$$|AF| = x_1 + \frac{p}{2}, \quad |BF| = x_2 + \frac{p}{2}$$

$$|AF| + |BF| = x_1 + x_2 + p$$

当直线 $l$ 垂直于 $x$ 轴时（即过焦点的竖直线），$x_1 = x_2 = \dfrac{p}{2}$。

$$|AF| + |BF| = p + p = 2p$$

这是最小值（通径长），所以 $2p = 4$，$p = 2$。

**第2步：** 写出抛物线方程

$$y^2 = 4x$$

**第3步：** 求 $\triangle AOB$ 的面积
> 📌 运用知识点：直线与抛物线

当 $l$ 的斜率为 $1$ 时，$F(1, 0)$，$l: y = x - 1$。

代入 $y^2 = 4x$：

$$(x - 1)^2 = 4x$$

$$x^2 - 6x + 1 = 0$$

$$x_1 + x_2 = 6, \quad x_1 x_2 = 1$$

$$y_1 + y_2 = (x_1 - 1) + (x_2 - 1) = x_1 + x_2 - 2 = 4$$

$$y_1 y_2 = (x_1 - 1)(x_2 - 1) = x_1 x_2 - (x_1 + x_2) + 1 = 1 - 6 + 1 = -4$$

$$|AB| = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$$

$(x_1 - x_2)^2 = (x_1 + x_2)^2 - 4x_1 x_2 = 36 - 4 = 32$

$(y_1 - y_2)^2 = (y_1 + y_2)^2 - 4y_1 y_2 = 16 + 16 = 32$

$$|AB| = \sqrt{32 + 32} = \sqrt{64} = 8$$

原点 $O$ 到直线 $y = x - 1$ 即 $x - y - 1 = 0$ 的距离：

$$d = \frac{|0 - 0 - 1|}{\sqrt{2}} = \frac{1}{\sqrt{2}}$$

$$S_{\triangle AOB} = \frac{1}{2} \times |AB| \times d = \frac{1}{2} \times 8 \times \frac{1}{\sqrt{2}} = \frac{4}{\sqrt{2}} = 2\sqrt{2}$$

**答案：（1）$y^2 = 4x$；（2）$S = 2\sqrt{2}$。**

**⚠️ 易错提醒：** 抛物线焦点弦长 $|AF| + |BF| = x_1 + x_2 + p$，最小值为通径 $2p$（当弦垂直于对称轴时）。

**💡 解题思路总结：** 抛物线焦点弦问题利用焦半径公式简化计算；求面积时用 $S = \dfrac{1}{2}|AB| \cdot d$。
