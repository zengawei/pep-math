**题目：** 已知双曲线 $\dfrac{x^2}{4} - \dfrac{y^2}{5} = 1$，则

A. 双曲线的实轴长为 $4$

B. 双曲线的渐近线方程为 $y = \pm\dfrac{\sqrt{5}}{2}x$

C. 双曲线的离心率为 $\dfrac{3}{2}$

D. 双曲线的焦点到渐近线的距离为 $\sqrt{5}$

在每小题给出的选项中，有多项符合题目要求．全部选对的得5分，部分选对的得2分，有选错的得0分．

---

**解答：**

**第1步：** 确定参数
> 📌 运用知识点：双曲线的标准方程

$a^2 = 4$，$b^2 = 5$，$c^2 = a^2 + b^2 = 9$。

$a = 2$，$b = \sqrt{5}$，$c = 3$。

**第2步：** 逐项判断

**A：** 实轴长 $= 2a = 4$。**A 正确。**

**B：** 渐近线 $y = \pm\dfrac{b}{a}x = \pm\dfrac{\sqrt{5}}{2}x$。**B 正确。**

**C：** $e = \dfrac{c}{a} = \dfrac{3}{2}$。**C 正确。**

**D：** 焦点 $(3, 0)$ 到渐近线 $\sqrt{5}x - 2y = 0$ 的距离：

$$d = \frac{|\sqrt{5} \times 3 - 0|}{\sqrt{5 + 4}} = \frac{3\sqrt{5}}{3} = \sqrt{5}$$

**D 正确。**

**答案：ABCD**

**⚠️ 易错提醒：** 双曲线中 $c^2 = a^2 + b^2$（不是 $a^2 - b^2$）。焦点到渐近线的距离等于 $b$，这是一个常用结论。

**💡 解题思路总结：** 双曲线基本量 $a, b, c$ 的关系：$c^2 = a^2 + b^2$。渐近线 $y = \pm\dfrac{b}{a}x$。焦点到渐近线的距离 $= b$。
