**题目：**

在 $\triangle ABC$ 中，角 $A, B, C$ 的对边分别为 $a, b, c$，已知 $b\cos C + c\cos B = 2a\cos A$。

（1）求角 $A$ 的大小；

（2）若 $a = 2\sqrt{3}$，$b + c = 4$，求 $\triangle ABC$ 的面积。

---

**解答：**

**第1步：** 利用正弦定理化简（第1问）。

由正弦定理 $\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C}$，将边替换为角：

$$\sin B\cos C + \sin C\cos B = 2\sin A\cos A$$

左边 $= \sin(B + C) = \sin(\pi - A) = \sin A$。

所以 $\sin A = 2\sin A\cos A$。

因为 $\sin A \neq 0$，所以 $\cos A = \dfrac{1}{2}$，$A = \dfrac{\pi}{3}$。

> 📌 运用知识点：trig-identity

**第2步：** 利用余弦定理（第2问）。

$a = 2\sqrt{3}$，$A = \dfrac{\pi}{3}$，$b + c = 4$。

由余弦定理：$a^2 = b^2 + c^2 - 2bc\cos A$

$$12 = b^2 + c^2 - 2bc \cdot \frac{1}{2} = b^2 + c^2 - bc$$

> 📌 运用知识点：trig-function

**第3步：** 利用 $b + c = 4$ 求 $bc$。

$(b + c)^2 = b^2 + 2bc + c^2 = 16$

$b^2 + c^2 = 16 - 2bc$

代入：$12 = 16 - 2bc - bc = 16 - 3bc$

$3bc = 4 \implies bc = \dfrac{4}{3}$

> 📌 运用知识点：basic-inequality

**第4步：** 求面积。

$$S = \frac{1}{2}bc\sin A = \frac{1}{2} \times \frac{4}{3} \times \frac{\sqrt{3}}{2} = \frac{\sqrt{3}}{3}$$

**$\triangle ABC$ 的面积为 $\dfrac{\sqrt{3}}{3}$。**

**⚠️ 易错提醒：**
1. 正弦定理边角互化时，$\sin B\cos C + \sin C\cos B = \sin(B+C)$ 是关键的和角公式。
2. 利用 $(b+c)^2$ 展开求 $bc$ 是常用技巧。

**💡 解题思路总结：** 解三角形综合题：①正弦定理边角互化求角；②余弦定理结合已知条件求边的关系，再求面积。
