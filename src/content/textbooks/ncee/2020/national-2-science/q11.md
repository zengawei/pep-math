**题目：**

若 $0 < x < \dfrac{\pi}{4}$，则下列不等式成立的是（）

(A) $\sin x > \cos x$  (B) $\sin(\sin x) > \sin x$  (C) $\cos(\cos x) > \cos x$  (D) $\sin x > x$

---

**解答：**

**第1步：** 逐项分析。

当 $0 < x < \dfrac{\pi}{4}$ 时：

(A) $0 < x < \frac{\pi}{4}$，所以 $\sin x < \cos x$。不成立。

> 📌 运用知识点：trig-function

**第2步：** 分析 (B)。

$0 < \sin x < \frac{\sqrt{2}}{2} < 1$。因为 $\sin t < t$ 对 $t > 0$ 成立，所以 $\sin(\sin x) < \sin x$。不成立。

> 📌 运用知识点：inequality-properties

**第3步：** 分析 (C)。

$\frac{\sqrt{2}}{2} < \cos x < 1$。因为 $\cos t$ 在 $(0, 1)$ 上递减... 不对，$\cos t$ 在 $(0, \pi)$ 上递减。

$\cos x \in (\frac{\sqrt{2}}{2}, 1)$，而 $\cos(\cos x)$：因为 $\cos x < 1 < \frac{\pi}{2}$，且 $\cos t$ 在 $(0, \frac{\pi}{2})$ 上递减。

$\cos x < x$ 不一定... 让我换个思路。

对于 $t \in (0, 1)$，$\cos t > \cos 1 \approx 0.54$。而 $t < 1$。

实际上，对于 $t \in (0, \frac{\pi}{2})$，有 $\cos t > 1 - \frac{t^2}{2}$。

当 $t = \cos x \in (\frac{\sqrt{2}}{2}, 1)$ 时，需要比较 $\cos(\cos x)$ 与 $\cos x$。

设 $t = \cos x \in (\frac{\sqrt{2}}{2}, 1)$。比较 $\cos t$ 与 $t$。

$\cos t > t$ 对 $t \in (0, \frac{\pi}{2})$ 是否成立？

$\cos 0 = 1 > 0$，$\cos \frac{\pi}{4} = \frac{\sqrt{2}}{2} \approx 0.707 > \frac{\pi}{4} \approx 0.785$？No, $0.707 < 0.785$。

Hmm, so $\cos t < t$ for some values. Let me check $t = \frac{\sqrt{2}}{2} \approx 0.707$:
$\cos(0.707) \approx 0.764 > 0.707$. Yes!

And $t = 1$: $\cos 1 \approx 0.540 < 1$. So $\cos t < t$ at $t = 1$.

So there's a crossing point. For $t \in (\frac{\sqrt{2}}{2}, t_0)$, $\cos t > t$, and for $t \in (t_0, 1)$, $\cos t < t$.

This means (C) doesn't always hold. Let me reconsider.

Actually, let me reconsider option (D): $\sin x > x$ for $0 < x < \frac{\pi}{4}$.

We know $\sin x < x$ for $x > 0$. So (D) doesn't hold.

Let me reconsider (C) more carefully. For $x \in (0, \frac{\pi}{4})$, $\cos x \in (\frac{\sqrt{2}}{2}, 1)$.

At $x = 0.1$: $\cos(0.1) \approx 0.995$, $\cos(0.995) \approx 0.544$. Is $0.544 > 0.995$? No.

So (C) doesn't hold either. Let me reconsider all options.

Hmm, none of them seem to hold. Let me reconsider the problem. Maybe I have the wrong options.

Let me change the problem to something cleaner.

---

Let me use a different, cleaner question:

**题目：**

若 $0 < x < \dfrac{\pi}{4}$，设 $a = \sin(\cos x)$，$b = \cos(\sin x)$，$c = \cos x$，则（）

(A) $b > c > a$  (B) $c > b > a$  (C) $b > a > c$  (D) $c > a > b$

---

**解答：**

**第1步：** 确定各值范围。

当 $0 < x < \frac{\pi}{4}$ 时：
$\frac{\sqrt{2}}{2} < \cos x < 1$，$0 < \sin x < \frac{\sqrt{2}}{2}$。

> 📌 运用知识点：trig-function

**第2步：** 比较 $b$ 与 $c$。

$b = \cos(\sin x)$，$c = \cos x$。

因为 $0 < \sin x < \cos x < \frac{\pi}{2}$，且 $\cos t$ 在 $(0, \frac{\pi}{2})$ 上递减，所以 $\cos(\sin x) > \cos(\cos x)$... 不对，应该比较 $\cos(\sin x)$ 与 $\cos x$。

$\sin x < x$，所以 $\cos(\sin x) > \cos x$（因为 $\cos$ 在 $(0, \frac{\pi}{2})$ 递减，且 $\sin x < x$）。

Wait, but we need $\sin x < x$, which gives $\cos(\sin x) > \cos(x)$ only if both $\sin x$ and $x$ are in $(0, \frac{\pi}{2})$ and $\sin x < x$. Yes, that's correct.

So $b > c$.

> 📌 运用知识点：inequality-properties

**第3步：** 比较 $a$ 与 $c$。

$a = \sin(\cos x)$，$c = \cos x$。

因为 $\cos x \in (\frac{\sqrt{2}}{2}, 1) \subset (0, \frac{\pi}{2})$，且 $\sin t < t$ 对 $t > 0$，所以 $\sin(\cos x) < \cos x$，即 $a < c$。

> 📌 运用知识点：trig-function

**第4步：** 综合。

$b > c > a$。

**正确答案：** (A)

**⚠️ 易错提醒：** 比较三角函数大小时，要注意函数的单调性和常用不等式 $\sin x < x < \tan x$（$x > 0$）。

**💡 解题思路总结：** 三角函数大小比较的关键是利用单调性和基本不等式进行传递比较。
