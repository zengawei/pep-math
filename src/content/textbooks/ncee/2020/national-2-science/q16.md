**题目：**

已知数列 $\{a_n\}$ 满足 $a_1 = 1$，$a_{n+1} = \dfrac{a_n}{1 + a_n}$，则 $a_n = $ ______。

---

**解答：**

**第1步：** 计算前几项找规律。

$a_1 = 1$

$a_2 = \dfrac{1}{1+1} = \dfrac{1}{2}$

$a_3 = \dfrac{\frac{1}{2}}{1 + \frac{1}{2}} = \dfrac{\frac{1}{2}}{\frac{3}{2}} = \dfrac{1}{3}$

$a_4 = \dfrac{\frac{1}{3}}{1 + \frac{1}{3}} = \dfrac{1}{4}$

猜测 $a_n = \dfrac{1}{n}$。

> 📌 运用知识点：sequence-concept

**第2步：** 用倒数法证明。

令 $b_n = \dfrac{1}{a_n}$，则 $b_1 = 1$。

$$b_{n+1} = \frac{1}{a_{n+1}} = \frac{1 + a_n}{a_n} = \frac{1}{a_n} + 1 = b_n + 1$$

$\{b_n\}$ 是公差为 $1$ 的等差数列，$b_n = n$。

因此 $a_n = \dfrac{1}{n}$。

> 📌 运用知识点：geometric-sequence

**正确答案：** $\dfrac{1}{n}$

**⚠️ 易错提醒：** 分式递推常用倒数法转化为等差或等比数列；注意验证初始条件。

**💡 解题思路总结：** 递推关系 $a_{n+1} = \frac{a_n}{1+a_n}$ 取倒数后变为 $b_{n+1} = b_n + 1$，是等差数列。
