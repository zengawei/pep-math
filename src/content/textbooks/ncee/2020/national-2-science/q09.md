**题目：**

曲线 $C: x^2 + y^2 = 2x$ 上的点到直线 $l: x - y + 1 = 0$ 的最大距离为（）

(A) $\sqrt{2}$  (B) $\sqrt{2} + 1$  (C) $2\sqrt{2}$  (D) $2\sqrt{2} + 1$

---

**解答：**

**第1步：** 将曲线方程化为标准形式。

$x^2 - 2x + y^2 = 0 \implies (x-1)^2 + y^2 = 1$。

圆心 $(1, 0)$，半径 $r = 1$。

> 📌 运用知识点：circle-equation

**第2步：** 求圆心到直线的距离。

$$d = \frac{|1 - 0 + 1|}{\sqrt{1^2 + (-1)^2}} = \frac{2}{\sqrt{2}} = \sqrt{2}$$

> 📌 运用知识点：line-circle-position

**第3步：** 最大距离 = 圆心到直线距离 + 半径。

$$d_{\max} = \sqrt{2} + 1$$

**正确答案：** (B)

**⚠️ 易错提醒：** 曲线 $x^2 + y^2 = 2x$ 需要配方化为标准圆方程；最大距离 = 圆心距 + 半径，最小距离 = 圆心距 - 半径。

**💡 解题思路总结：** 圆上点到直线距离的最值问题：先求圆心到直线的距离 $d$，则最大距离 $= d + r$，最小距离 $= d - r$。
