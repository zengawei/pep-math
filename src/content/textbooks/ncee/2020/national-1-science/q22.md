**题目：** 已知函数 $f(x) = |x - 1| + |x + 2|$。

（1）求不等式 $f(x) \leqslant 5$ 的解集；

（2）若关于 $x$ 的不等式 $f(x) < a^2 - a$ 有解，求 $a$ 的取值范围。

---

**解答：**

**（1）求不等式 $f(x) \leqslant 5$ 的解集**

**第1步：** 分区间讨论
> 📌 运用知识点：quadratic-inequality

零点为 $x = 1$ 和 $x = -2$，将数轴分为三个区间。

**情况一：** $x < -2$

$$f(x) = -(x - 1) - (x + 2) = -2x - 1$$

$$-2x - 1 \leqslant 5 \implies -2x \leqslant 6 \implies x \geqslant -3$$

与 $x < -2$ 取交集：$-3 \leqslant x < -2$。

**情况二：** $-2 \leqslant x \leqslant 1$

$$f(x) = -(x - 1) + (x + 2) = 3$$

$$3 \leqslant 5 \text{ 恒成立}$$

所以 $-2 \leqslant x \leqslant 1$。

**情况三：** $x > 1$

$$f(x) = (x - 1) + (x + 2) = 2x + 1$$

$$2x + 1 \leqslant 5 \implies 2x \leqslant 4 \implies x \leqslant 2$$

与 $x > 1$ 取交集：$1 < x \leqslant 2$。

**第2步：** 合并解集

$$[-3, -2) \cup [-2, 1] \cup (1, 2] = [-3, 2]$$

$$\boxed{\text{解集为 } [-3, 2]}$$

**（2）求 $a$ 的取值范围**

**第3步：** 求 $f(x)$ 的最小值
> 📌 运用知识点：basic-inequality

由绝对值三角不等式：

$$f(x) = |x - 1| + |x + 2| = |x - 1| + |{-2 - x}| \geqslant |(x - 1) - (-2 - x)| \text{（不适用）}$$

更直接地：$|x - 1| + |x + 2| = |x - 1| + |x - (-2)| \geqslant |1 - (-2)| = 3$

等号在 $-2 \leqslant x \leqslant 1$ 时成立。

所以 $f(x)_{\min} = 3$。

**第4步：** 建立不等式
> 📌 运用知识点：quadratic-inequality

$f(x) < a^2 - a$ 有解，等价于：

$$f(x)_{\min} < a^2 - a$$

$$3 < a^2 - a$$

$$a^2 - a - 3 > 0$$

**第5步：** 解二次不等式

方程 $a^2 - a - 3 = 0$ 的根：

$$a = \frac{1 \pm \sqrt{1 + 12}}{2} = \frac{1 \pm \sqrt{13}}{2}$$

所以：

$$a < \frac{1 - \sqrt{13}}{2} \quad \text{或} \quad a > \frac{1 + \sqrt{13}}{2}$$

$$\boxed{a \in \left(-\infty, \frac{1 - \sqrt{13}}{2}\right) \cup \left(\frac{1 + \sqrt{13}}{2}, +\infty\right)}$$

**⚠️ 易错提醒：**
1. 绝对值不等式分区间讨论时，注意每个区间的端点归属，最后合并时不要遗漏或重复。
2. "$f(x) < a^2 - a$ 有解"等价于 $f(x)_{\min} < a^2 - a$，而不是 $f(x)_{\max} < a^2 - a$。"有解"和"恒成立"的条件不同。
3. 绝对值三角不等式 $|x - a| + |x - b| \geqslant |a - b|$ 的等号在 $x$ 位于 $a$、$b$ 之间时成立。

**💡 解题思路总结：** 含绝对值的不等式，用"零点分段法"分区间去绝对值。"$f(x) < M$ 有解"等价于 $f(x)_{\min} < M$；"$f(x) < M$ 恒成立"等价于 $f(x)_{\max} < M$。两者不要混淆。
