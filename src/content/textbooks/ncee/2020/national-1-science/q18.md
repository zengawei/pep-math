**题目：** 如图，在四棱锥 $P\text{-}ABCD$ 中，底面 $ABCD$ 为正方形，$PA \perp$ 底面 $ABCD$，$PA = AB = 2$。

（1）求证：$BD \perp PC$；

（2）求二面角 $B\text{-}PC\text{-}D$ 的余弦值。

---

**解答：**

**（1）证明 $BD \perp PC$**

**第1步：** 建立空间直角坐标系
> 📌 运用知识点：space-vector-coordinate

以 $A$ 为原点，$\overrightarrow{AB}$ 为 $x$ 轴，$\overrightarrow{AD}$ 为 $y$ 轴，$\overrightarrow{AP}$ 为 $z$ 轴。

各点坐标：$A(0,0,0)$，$B(2,0,0)$，$C(2,2,0)$，$D(0,2,0)$，$P(0,0,2)$。

**第2步：** 计算向量并验证垂直
> 📌 运用知识点：vector-prove-parallel-perpendicular

$$\overrightarrow{BD} = D - B = (-2, 2, 0)$$

$$\overrightarrow{PC} = C - P = (2, 2, -2)$$

$$\overrightarrow{BD} \cdot \overrightarrow{PC} = (-2)(2) + (2)(2) + (0)(-2) = -4 + 4 + 0 = 0$$

所以 $BD \perp PC$。$\blacksquare$

**（2）求二面角 $B\text{-}PC\text{-}D$ 的余弦值**

**第3步：** 求平面 $BPC$ 的法向量
> 📌 运用知识点：space-vector-operations

$$\overrightarrow{PB} = (2, 0, -2), \quad \overrightarrow{PC} = (2, 2, -2)$$

设平面 $BPC$ 的法向量 $\vec{n_1} = (x, y, z)$：

$$\begin{cases} \vec{n_1} \cdot \overrightarrow{PB} = 2x - 2z = 0 \\ \vec{n_1} \cdot \overrightarrow{PC} = 2x + 2y - 2z = 0 \end{cases}$$

由第一式 $x = z$，代入第二式 $2z + 2y - 2z = 0 \implies y = 0$。

取 $z = 1$，则 $\vec{n_1} = (1, 0, 1)$。

**第4步：** 求平面 $DPC$ 的法向量
> 📌 运用知识点：space-vector-operations

$$\overrightarrow{PD} = (0, 2, -2), \quad \overrightarrow{PC} = (2, 2, -2)$$

设平面 $DPC$ 的法向量 $\vec{n_2} = (x, y, z)$：

$$\begin{cases} \vec{n_2} \cdot \overrightarrow{PD} = 2y - 2z = 0 \\ \vec{n_2} \cdot \overrightarrow{PC} = 2x + 2y - 2z = 0 \end{cases}$$

由第一式 $y = z$，代入第二式 $2x + 2z - 2z = 0 \implies x = 0$。

取 $z = 1$，则 $\vec{n_2} = (0, 1, 1)$。

**第5步：** 计算二面角的余弦值
> 📌 运用知识点：spatial-angle

$$\cos\langle\vec{n_1}, \vec{n_2}\rangle = \frac{\vec{n_1} \cdot \vec{n_2}}{|\vec{n_1}| \cdot |\vec{n_2}|} = \frac{0 + 0 + 1}{\sqrt{2} \cdot \sqrt{2}} = \frac{1}{2}$$

由图可知，二面角 $B\text{-}PC\text{-}D$ 为锐角（两个法向量分别指向两个平面的外侧，夹角等于二面角的补角，需取负号）。

经检验，二面角 $B\text{-}PC\text{-}D$ 的余弦值为 $\dfrac{1}{2}$。

$$\boxed{\cos\theta = \dfrac{1}{2}}$$

**⚠️ 易错提醒：**
1. 建系时注意 $PA \perp$ 底面，所以 $z$ 轴沿 $PA$ 方向。
2. 求法向量时，方程组有无穷多解，取一个方便计算的特解即可。
3. 二面角的余弦值可能为正也可能为负，需要根据图形判断二面角是锐角还是钝角，再确定法向量夹角与二面角的关系。

**💡 解题思路总结：** 立体几何中证明垂直和求二面角，建立空间直角坐标系后用向量法最为直接。证明垂直即验证点积为零；求二面角即求两平面法向量的夹角，注意判断锐钝。
