**题目：** 已知直三棱柱 $ABC\text{-}A_1B_1C_1$ 的 $6$ 个顶点都在球 $O$ 的球面上。若 $AB = 3$，$AC = 4$，$AB \perp AC$，$AA_1 = 12$，则球 $O$ 的半径为（  ）

A. $\dfrac{13}{2}$

B. $7$

C. $\dfrac{15}{2}$

D. $8$

---

**解答：**

**第1步：** 分析底面三角形
> 📌 运用知识点：solid-surface-area-volume

底面 $\triangle ABC$ 中，$AB \perp AC$，$AB = 3$，$AC = 4$。

$$BC = \sqrt{AB^2 + AC^2} = \sqrt{9 + 16} = 5$$

直角三角形的外接圆圆心为斜边中点，外接圆半径：

$$r = \frac{BC}{2} = \frac{5}{2}$$

**第2步：** 确定球心位置
> 📌 运用知识点：solid-surface-area-volume

直三棱柱的外接球球心在上下底面外接圆圆心连线的中点处。

设底面外接圆圆心为 $O_1$，顶面外接圆圆心为 $O_2$，则 $O_1O_2 = AA_1 = 12$。

球心 $O$ 为 $O_1O_2$ 的中点，$OO_1 = \dfrac{12}{2} = 6$。

**第3步：** 求球的半径
> 📌 运用知识点：solid-surface-area-volume

$$R = \sqrt{r^2 + \left(\frac{AA_1}{2}\right)^2} = \sqrt{\left(\frac{5}{2}\right)^2 + 6^2} = \sqrt{\frac{25}{4} + 36} = \sqrt{\frac{25 + 144}{4}} = \sqrt{\frac{169}{4}} = \frac{13}{2}$$

**答案：A**

**⚠️ 易错提醒：** 直棱柱外接球半径公式 $R = \sqrt{r^2 + \left(\dfrac{h}{2}\right)^2}$ 中，$r$ 是底面外接圆半径（不是内切圆半径），$h$ 是棱柱的高。

**💡 解题思路总结：** 直棱柱外接球问题的关键是：①求底面外接圆半径 $r$；②球心在上下底面外接圆圆心连线的中点；③利用勾股定理 $R = \sqrt{r^2 + (h/2)^2}$。
