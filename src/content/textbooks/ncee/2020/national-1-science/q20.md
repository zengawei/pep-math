**题目：** 已知椭圆 $C: \dfrac{x^2}{4} + y^2 = 1$，过点 $M(1, 0)$ 的直线 $l$ 与椭圆 $C$ 交于 $A$，$B$ 两点。

（1）当直线 $l$ 的斜率为 $1$ 时，求 $|AB|$；

（2）设 $N$ 为椭圆 $C$ 的右顶点，求 $\triangle NAB$ 面积的最大值。

---

**解答：**

**（1）求 $|AB|$**

**第1步：** 写出直线方程
> 📌 运用知识点：conic-section-line

直线 $l$ 过 $M(1, 0)$，斜率 $k = 1$：

$$y = x - 1$$

**第2步：** 联立直线与椭圆方程
> 📌 运用知识点：conic-section-line

将 $y = x - 1$ 代入 $\dfrac{x^2}{4} + y^2 = 1$：

$$\frac{x^2}{4} + (x-1)^2 = 1$$

$$\frac{x^2}{4} + x^2 - 2x + 1 = 1$$

$$\frac{5x^2}{4} - 2x = 0$$

$$x\left(\frac{5x}{4} - 2\right) = 0$$

解得 $x_1 = 0$，$x_2 = \dfrac{8}{5}$。

**第3步：** 求交点坐标和距离

$A(0, -1)$，$B\left(\dfrac{8}{5}, \dfrac{3}{5}\right)$。

$$|AB| = \sqrt{\left(\frac{8}{5}\right)^2 + \left(\frac{3}{5} + 1\right)^2} = \sqrt{\frac{64}{25} + \frac{64}{25}} = \sqrt{\frac{128}{25}} = \frac{8\sqrt{2}}{5}$$

$$\boxed{|AB| = \dfrac{8\sqrt{2}}{5}}$$

**（2）求 $\triangle NAB$ 面积的最大值**

**第4步：** 设直线方程并联立
> 📌 运用知识点：conic-section-line

右顶点 $N(2, 0)$。设直线 $l: x = my + 1$（可表示所有过 $M(1,0)$ 的直线）。

代入椭圆方程：

$$\frac{(my+1)^2}{4} + y^2 = 1$$

$$(my+1)^2 + 4y^2 = 4$$

$$(m^2 + 4)y^2 + 2my - 3 = 0$$

由韦达定理：

$$y_1 + y_2 = \frac{-2m}{m^2 + 4}, \quad y_1 y_2 = \frac{-3}{m^2 + 4}$$

**第5步：** 计算 $|y_1 - y_2|$
> 📌 运用知识点：conic-section-line

$$(y_1 - y_2)^2 = (y_1 + y_2)^2 - 4y_1 y_2 = \frac{4m^2}{(m^2+4)^2} + \frac{12}{m^2+4} = \frac{4m^2 + 12(m^2+4)}{(m^2+4)^2} = \frac{16(m^2+3)}{(m^2+4)^2}$$

$$|y_1 - y_2| = \frac{4\sqrt{m^2+3}}{m^2+4}$$

**第6步：** 计算面积
> 📌 运用知识点：conic-section-optimization

$N(2, 0)$ 到直线 $x - my - 1 = 0$ 的距离：

$$d = \frac{|2 - 0 - 1|}{\sqrt{1 + m^2}} = \frac{1}{\sqrt{1 + m^2}}$$

$$|AB| = \sqrt{1 + m^2} \cdot |y_1 - y_2|$$

$$S_{\triangle NAB} = \frac{1}{2} |AB| \cdot d = \frac{1}{2} \cdot \sqrt{1+m^2} \cdot \frac{4\sqrt{m^2+3}}{m^2+4} \cdot \frac{1}{\sqrt{1+m^2}} = \frac{2\sqrt{m^2+3}}{m^2+4}$$

**第7步：** 求最大值
> 📌 运用知识点：conic-section-optimization

令 $t = m^2 + 3 \geqslant 3$，则 $m^2 + 4 = t + 1$：

$$S = \frac{2\sqrt{t}}{t + 1}$$

设 $f(t) = \dfrac{\sqrt{t}}{t+1}$，求导：

$$f'(t) = \frac{\dfrac{1}{2\sqrt{t}}(t+1) - \sqrt{t}}{(t+1)^2} = \frac{t + 1 - 2t}{2\sqrt{t}(t+1)^2} = \frac{1 - t}{2\sqrt{t}(t+1)^2}$$

当 $t \geqslant 3$ 时，$f'(t) < 0$，$f(t)$ 单调递减。

所以 $f(t)$ 在 $t = 3$（即 $m = 0$）时取最大值：

$$S_{\max} = \frac{2\sqrt{3}}{3 + 1} = \frac{2\sqrt{3}}{4} = \frac{\sqrt{3}}{2}$$

$$\boxed{S_{\max} = \dfrac{\sqrt{3}}{2}}$$

**⚠️ 易错提醒：**
1. 设直线为 $x = my + 1$ 而非 $y = k(x-1)$，是为了包含斜率不存在的情况。
2. 韦达定理中注意符号，$(y_1 - y_2)^2 = (y_1+y_2)^2 - 4y_1y_2$ 不要漏掉负号。
3. 求最值时换元 $t = m^2 + 3$ 后，注意 $t$ 的范围是 $t \geqslant 3$。

**💡 解题思路总结：** 圆锥曲线与直线综合题的标准流程：设直线→联立方程→韦达定理→表示目标量→求最值。面积最值问题常用换元法或导数法求解。
