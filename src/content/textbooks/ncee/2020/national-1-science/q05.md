**题目：** 已知 $a > 0$，$b > 0$，且 $a + b = 1$，则 $\dfrac{1}{a} + \dfrac{1}{b}$ 的最小值为（  ）

A. $2$

B. $3$

C. $4$

D. $2\sqrt{2}$

---

**解答：**

**第1步：** 通分化简
> 📌 运用知识点：basic-inequality

$$\frac{1}{a} + \frac{1}{b} = \frac{a + b}{ab} = \frac{1}{ab}$$

**第2步：** 利用均值不等式求 $ab$ 的最大值
> 📌 运用知识点：basic-inequality

由均值不等式：

$$ab \leqslant \left(\frac{a + b}{2}\right)^2 = \left(\frac{1}{2}\right)^2 = \frac{1}{4}$$

等号成立条件：$a = b = \dfrac{1}{2}$。

**第3步：** 求最小值

$$\frac{1}{ab} \geqslant \frac{1}{\dfrac{1}{4}} = 4$$

所以 $\dfrac{1}{a} + \dfrac{1}{b}$ 的最小值为 $4$。

**答案：C**

**⚠️ 易错提醒：** 使用均值不等式 $ab \leqslant \left(\dfrac{a+b}{2}\right)^2$ 时，必须验证等号成立条件 $a = b$ 是否在约束条件 $a + b = 1$，$a > 0$，$b > 0$ 下可以取到。

**💡 解题思路总结：** 条件最值问题的常用方法：①利用"乘1法"——将 $\dfrac{1}{a} + \dfrac{1}{b}$ 乘以 $(a+b)$ 展开后利用均值不等式；②先通分再利用均值不等式求分母的最值。
