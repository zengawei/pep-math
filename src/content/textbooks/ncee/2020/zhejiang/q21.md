**题目：**

已知双曲线 $C: \dfrac{x^2}{4} - y^2 = 1$。

（1）求双曲线 $C$ 的渐近线方程和离心率；

（2）设 $F_1, F_2$ 分别为双曲线 $C$ 的左、右焦点，$P$ 为双曲线右支上一点，且 $|PF_1| + |PF_2| = 6$，求 $\triangle PF_1F_2$ 的面积。

---

**解答：**

**（1）**

**第1步：** 确定参数。

$a^2 = 4$，$b^2 = 1$，所以 $a = 2$，$b = 1$。

$$c = \sqrt{a^2 + b^2} = \sqrt{4 + 1} = \sqrt{5}$$

> 📌 运用知识点：hyperbola-properties

**第2步：** 求渐近线方程和离心率。

渐近线方程：

$$\boxed{y = \pm\frac{1}{2}x}$$

离心率：

$$\boxed{e = \frac{c}{a} = \frac{\sqrt{5}}{2}}$$

> 📌 运用知识点：hyperbola-properties

**（2）**

**第3步：** 利用双曲线定义求 $|PF_1|$ 和 $|PF_2|$。

$P$ 在右支上，由双曲线定义：

$$|PF_1| - |PF_2| = 2a = 4$$

又已知 $|PF_1| + |PF_2| = 6$。

联立解得：

$$|PF_1| = 5, \quad |PF_2| = 1$$

> 📌 运用知识点：hyperbola-properties

**第4步：** 求 $\cos\angle F_1PF_2$。

$|F_1F_2| = 2c = 2\sqrt{5}$。

由余弦定理：

$$\cos\angle F_1PF_2 = \frac{|PF_1|^2 + |PF_2|^2 - |F_1F_2|^2}{2|PF_1| \cdot |PF_2|} = \frac{25 + 1 - 20}{2 \times 5 \times 1} = \frac{6}{10} = \frac{3}{5}$$

> 📌 运用知识点：conic-section-line

**第5步：** 求面积。

$$\sin\angle F_1PF_2 = \sqrt{1 - \cos^2\angle F_1PF_2} = \sqrt{1 - \frac{9}{25}} = \sqrt{\frac{16}{25}} = \frac{4}{5}$$

$$S_{\triangle PF_1F_2} = \frac{1}{2}|PF_1| \cdot |PF_2| \cdot \sin\angle F_1PF_2 = \frac{1}{2} \times 5 \times 1 \times \frac{4}{5} = 2$$

$$\boxed{S_{\triangle PF_1F_2} = 2}$$

> 📌 运用知识点：conic-section-line

**⚠️ 易错提醒：** 第（2）问中，$P$ 在右支上，双曲线定义为 $|PF_1| - |PF_2| = 2a$（左焦点距离减右焦点距离为正），不要搞反方向。余弦定理中 $|F_1F_2| = 2c = 2\sqrt{5}$，$|F_1F_2|^2 = 20$，不要算成 $|F_1F_2|^2 = 5$。

**💡 解题思路总结：** 双曲线焦点三角形问题的核心方法：①利用双曲线定义 $|PF_1| - |PF_2| = \pm 2a$ 与已知条件联立求两边长；②用余弦定理求焦点处的角；③用面积公式 $S = \dfrac{1}{2}|PF_1||PF_2|\sin\angle F_1PF_2$ 求面积。
