**题目：**

已知数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n$，且满足 $S_n = 2a_n - 1$（$n \in \mathbb{N}^*$）。

（1）求数列 $\{a_n\}$ 的通项公式；

（2）设 $b_n = \dfrac{a_n}{(a_n + 1)(a_{n+1} + 1)}$，求数列 $\{b_n\}$ 的前 $n$ 项和 $T_n$。

---

**解答：**

**（1）**

**第1步：** 求 $a_1$。

当 $n = 1$ 时，$S_1 = a_1 = 2a_1 - 1$，解得 $a_1 = 1$。

> 📌 运用知识点：arithmetic-sequence

**第2步：** 求递推关系。

当 $n \geqslant 2$ 时：

$$S_n = 2a_n - 1 \quad \cdots (1)$$

$$S_{n-1} = 2a_{n-1} - 1 \quad \cdots (2)$$

$(1) - (2)$：$a_n = 2a_n - 2a_{n-1}$

$$a_n = 2a_{n-1}$$

> 📌 运用知识点：geometric-sequence

**第3步：** 确定通项公式。

$\{a_n\}$ 是以 $a_1 = 1$ 为首项，公比 $q = 2$ 的等比数列。

$$\boxed{a_n = 2^{n-1}}$$

> 📌 运用知识点：geometric-sequence

**（2）**

**第4步：** 化简 $b_n$。

$$b_n = \frac{a_n}{(a_n+1)(a_{n+1}+1)} = \frac{2^{n-1}}{(2^{n-1}+1)(2^n+1)}$$

> 📌 运用知识点：geometric-sequence

**第5步：** 裂项。

注意到：

$$\frac{2^{n-1}}{(2^{n-1}+1)(2^n+1)} = \frac{1}{2^{n-1}+1} - \frac{1}{2^n+1}$$

验证：

$$\frac{1}{2^{n-1}+1} - \frac{1}{2^n+1} = \frac{(2^n+1)-(2^{n-1}+1)}{(2^{n-1}+1)(2^n+1)} = \frac{2^n - 2^{n-1}}{(2^{n-1}+1)(2^n+1)} = \frac{2^{n-1}}{(2^{n-1}+1)(2^n+1)}$$

> 📌 运用知识点：geometric-sequence

**第6步：** 求和（裂项相消）。

$$T_n = \sum_{k=1}^n \left(\frac{1}{2^{k-1}+1} - \frac{1}{2^k+1}\right)$$

$$= \left(\frac{1}{2^0+1} - \frac{1}{2^1+1}\right) + \left(\frac{1}{2^1+1} - \frac{1}{2^2+1}\right) + \cdots + \left(\frac{1}{2^{n-1}+1} - \frac{1}{2^n+1}\right)$$

$$= \frac{1}{2} - \frac{1}{2^n+1}$$

$$\boxed{T_n = \frac{1}{2} - \frac{1}{2^n+1}}$$

> 📌 运用知识点：geometric-sequence

**⚠️ 易错提醒：** 第（1）问中，由 $S_n$ 求 $a_n$ 时，必须分 $n=1$ 和 $n \geqslant 2$ 两种情况讨论，并验证 $n=1$ 时的结果是否满足递推公式。第（2）问裂项时，关键是发现分子 $2^{n-1} = 2^n - 2^{n-1}$，从而拆分为两项之差。

**💡 解题思路总结：** $S_n$ 与 $a_n$ 的关系题，核心方法是 $a_n = S_n - S_{n-1}$（$n \geqslant 2$），将和的关系转化为递推关系。裂项求和的关键是观察通项的结构，将分子凑成分母两因子之差的形式。
