**题目：**

如图，在四棱锥 $P\text{-}ABCD$ 中，底面 $ABCD$ 为正方形，$PA \perp$ 底面 $ABCD$，$PA = AB = 2$。

（1）求证：$BD \perp PC$；

（2）求二面角 $P\text{-}BD\text{-}A$ 的余弦值。

---

**解答：**

**（1）**

**第1步：** 建立空间直角坐标系。

以 $A$ 为原点，$\overrightarrow{AB}$，$\overrightarrow{AD}$，$\overrightarrow{AP}$ 分别为 $x$，$y$，$z$ 轴正方向。

各点坐标：$A(0,0,0)$，$B(2,0,0)$，$C(2,2,0)$，$D(0,2,0)$，$P(0,0,2)$。

> 📌 运用知识点：space-vector-fundamental-theorem

**第2步：** 求向量并验证垂直。

$$\overrightarrow{BD} = D - B = (-2, 2, 0)$$

$$\overrightarrow{PC} = C - P = (2, 2, -2)$$

$$\overrightarrow{BD} \cdot \overrightarrow{PC} = (-2)(2) + (2)(2) + (0)(-2) = -4 + 4 + 0 = 0$$

所以 $BD \perp PC$。$\blacksquare$

> 📌 运用知识点：spatial-angle

**（2）**

**第3步：** 求二面角 $P\text{-}BD\text{-}A$。

需要求平面 $PBD$ 和平面 $ABD$ 的法向量。

$\overrightarrow{BD} = (-2, 2, 0)$，$\overrightarrow{BP} = (-2, 0, 2)$。

> 📌 运用知识点：space-vector-fundamental-theorem

**第4步：** 求平面 $PBD$ 的法向量 $\vec{n_1}$。

设 $\vec{n_1} = (x, y, z)$，则：

$$\vec{n_1} \cdot \overrightarrow{BD} = -2x + 2y = 0 \implies x = y$$

$$\vec{n_1} \cdot \overrightarrow{BP} = -2x + 2z = 0 \implies x = z$$

取 $x = 1$，则 $\vec{n_1} = (1, 1, 1)$。

> 📌 运用知识点：space-vector-fundamental-theorem

**第5步：** 求平面 $ABD$ 的法向量 $\vec{n_2}$。

平面 $ABD$ 即底面 $ABCD$（$z = 0$ 平面），法向量为 $\vec{n_2} = (0, 0, 1)$。

> 📌 运用知识点：space-vector-fundamental-theorem

**第6步：** 求二面角的余弦值。

$$\cos\theta = \frac{|\vec{n_1} \cdot \vec{n_2}|}{|\vec{n_1}||\vec{n_2}|} = \frac{|(1)(0)+(1)(0)+(1)(1)|}{\sqrt{3} \times 1} = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}$$

需要判断二面角是锐角还是钝角。观察几何体，$P$ 在底面上方，二面角 $P\text{-}BD\text{-}A$ 为锐角。

$$\boxed{\cos\theta = \frac{\sqrt{3}}{3}}$$

> 📌 运用知识点：spatial-angle

**⚠️ 易错提醒：** 第（1）问也可用几何法：$PA \perp$ 底面，所以 $PA \perp BD$；正方形中 $AC \perp BD$。但注意 $AC$ 和 $PC$ 不共线，需要用向量法或找到正确的几何关系。第（2）问中，二面角的余弦值取法向量夹角时，需根据几何体判断二面角是锐角还是钝角，确定是否取绝对值。

**💡 解题思路总结：** 立体几何中涉及垂直证明和求角，建系法（向量法）是最通用的方法。关键是：①选择合适的原点和坐标轴使各点坐标简洁；②用向量数量积为零证明垂直；③用法向量夹角求二面角。
