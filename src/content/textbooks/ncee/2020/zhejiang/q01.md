**题目：**

已知集合 $A = \{x \mid x^2 - 3x + 2 \leqslant 0\}$，$B = \{x \mid 1 < x < 3\}$，则 $A \cap B = $

A. $\{x \mid 1 < x \leqslant 2\}$

B. $\{x \mid 1 \leqslant x < 3\}$

C. $\{x \mid 1 < x < 2\}$

D. $\{x \mid 1 \leqslant x \leqslant 2\}$

---

**解答：**

**第1步：** 解集合 $A$ 中的不等式 $x^2 - 3x + 2 \leqslant 0$。

因式分解：$x^2 - 3x + 2 = (x-1)(x-2) \leqslant 0$

解得 $1 \leqslant x \leqslant 2$，即 $A = [1, 2]$。

> 📌 运用知识点：set-operations

**第2步：** 求 $A \cap B$。

$A = [1, 2]$，$B = (1, 3)$

$A \cap B = \{x \mid 1 \leqslant x \leqslant 2\} \cap \{x \mid 1 < x < 3\} = \{x \mid 1 < x \leqslant 2\}$

> 📌 运用知识点：set-operations

**答案：A**

**⚠️ 易错提醒：** 注意集合 $A$ 的端点 $x=1$ 和 $x=2$ 是包含的（$\leqslant$），而集合 $B$ 的端点 $x=1$ 和 $x=3$ 是不包含的（$<$）。取交集时，$x=1$ 不在 $B$ 中，所以不在交集中；$x=2$ 同时在 $A$ 和 $B$ 中，所以在交集中。

**💡 解题思路总结：** 先分别求出各集合的范围，再根据交集的定义取公共部分。解一元二次不等式时注意因式分解和符号判断，取交集时逐一检验端点的归属。
