**题目：**

已知函数 $f(x) = 2\sin\left(2x + \dfrac{\pi}{6}\right)$，则

A. $f(x)$ 的最小正周期为 $\pi$

B. $f(x)$ 的图象关于点 $\left(-\dfrac{\pi}{12}, 0\right)$ 对称

C. $f(x)$ 在 $\left[-\dfrac{\pi}{6}, \dfrac{\pi}{3}\right]$ 上单调递增

D. $f(x)$ 的最大值为 $2$

---

**解答：**

**第1步：** 判断 A——周期。

$$T = \frac{2\pi}{2} = \pi$$

✅ A 正确。

> 📌 运用知识点：trig-graph

**第2步：** 判断 B——关于点对称。

若 $f(x)$ 关于 $\left(-\dfrac{\pi}{12}, 0\right)$ 对称，则 $f\left(-\dfrac{\pi}{12}\right) = 0$。

$$f\left(-\frac{\pi}{12}\right) = 2\sin\left(2 \times \left(-\frac{\pi}{12}\right) + \frac{\pi}{6}\right) = 2\sin\left(-\frac{\pi}{6} + \frac{\pi}{6}\right) = 2\sin 0 = 0$$

且该点处函数值为零，确为对称中心。✅ B 正确。

> 📌 运用知识点：trig-graph

**第3步：** 判断 C——单调性。

当 $x \in \left[-\dfrac{\pi}{6}, \dfrac{\pi}{3}\right]$ 时：

$$2x + \frac{\pi}{6} \in \left[-\frac{\pi}{6}, \frac{5\pi}{6}\right]$$

$\sin t$ 在 $\left[-\dfrac{\pi}{6}, \dfrac{\pi}{2}\right]$ 上递增，在 $\left[\dfrac{\pi}{2}, \dfrac{5\pi}{6}\right]$ 上递减。

所以 $f(x)$ 在 $\left[-\dfrac{\pi}{6}, \dfrac{\pi}{3}\right]$ 上不是单调递增的。❌ C 错误。

> 📌 运用知识点：trig-identity

**第4步：** 判断 D——最大值。

$f(x) = 2\sin\left(2x + \dfrac{\pi}{6}\right)$，$\sin$ 的最大值为 $1$，所以 $f(x)$ 的最大值为 $2$。✅ D 正确。

> 📌 运用知识点：trig-graph

**答案：A、B、D**

**⚠️ 易错提醒：** 判断 C 项时，需要将 $x$ 的范围转化为 $2x + \dfrac{\pi}{6}$ 的范围，再看 $\sin$ 在此区间上是否单调。区间 $\left[-\dfrac{\pi}{6}, \dfrac{5\pi}{6}\right]$ 跨越了 $\sin$ 的峰值点 $\dfrac{\pi}{2}$，所以不单调。

**💡 解题思路总结：** 三角函数 $y = A\sin(\omega x + \varphi)$ 的性质分析：周期 $T = \dfrac{2\pi}{|\omega|}$；对称中心令 $\omega x + \varphi = k\pi$；单调性需要将 $x$ 的范围转化为整体相位的范围，再结合 $\sin$ 的单调区间判断。
