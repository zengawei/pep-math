**题目：**

已知双曲线 $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$（$a > 0, b > 0$）的一条渐近线方程为 $y = \sqrt{3}\,x$，则该双曲线的离心率为

A. $\dfrac{2\sqrt{3}}{3}$

B. $\sqrt{2}$

C. $2$

D. $\sqrt{3}$

---

**解答：**

**第1步：** 由渐近线方程确定 $a, b$ 的关系。

双曲线 $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$ 的渐近线为 $y = \pm\dfrac{b}{a}x$。

由题意 $\dfrac{b}{a} = \sqrt{3}$，即 $b = \sqrt{3}\,a$。

> 📌 运用知识点：hyperbola-properties

**第2步：** 求 $c$。

$$c^2 = a^2 + b^2 = a^2 + 3a^2 = 4a^2$$

$$c = 2a$$

> 📌 运用知识点：hyperbola-properties

**第3步：** 求离心率。

$$e = \frac{c}{a} = \frac{2a}{a} = 2$$

> 📌 运用知识点：hyperbola-properties

**答案：C**

**⚠️ 易错提醒：** 双曲线的渐近线是 $y = \pm\dfrac{b}{a}x$（焦点在 $x$ 轴上），不要与椭圆混淆。另外 $c^2 = a^2 + b^2$（双曲线），不是 $c^2 = a^2 - b^2$（椭圆）。

**💡 解题思路总结：** 由渐近线斜率得到 $\dfrac{b}{a}$ 的值，再利用 $c^2 = a^2 + b^2$ 求 $c$ 与 $a$ 的关系，最后代入离心率公式 $e = \dfrac{c}{a}$。
