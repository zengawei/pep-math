**题目：**

已知函数 $f(x) = \ln(x + \sqrt{x^2+1})$，则 $f(x)$ 是

A. 奇函数，且在 $(0, +\infty)$ 上单调递增

B. 偶函数，且在 $(0, +\infty)$ 上单调递增

C. 奇函数，且在 $(0, +\infty)$ 上单调递减

D. 偶函数，且在 $(0, +\infty)$ 上单调递减

---

**解答：**

**第1步：** 判断奇偶性。

计算 $f(-x)$：

$$f(-x) = \ln(-x + \sqrt{x^2+1})$$

注意 $(x + \sqrt{x^2+1})(-x + \sqrt{x^2+1}) = (x^2+1) - x^2 = 1$

所以 $-x + \sqrt{x^2+1} = \dfrac{1}{x + \sqrt{x^2+1}}$

因此：

$$f(-x) = \ln\frac{1}{x+\sqrt{x^2+1}} = -\ln(x+\sqrt{x^2+1}) = -f(x)$$

$f(x)$ 是奇函数。

> 📌 运用知识点：function-properties

**第2步：** 判断单调性。

设 $g(x) = x + \sqrt{x^2+1}$，当 $x > 0$ 时，$x$ 递增，$\sqrt{x^2+1}$ 也递增，所以 $g(x)$ 在 $(0, +\infty)$ 上单调递增。

又 $\ln t$ 在 $t > 0$ 上单调递增，所以 $f(x) = \ln(g(x))$ 在 $(0, +\infty)$ 上单调递增。

> 📌 运用知识点：function-properties

**答案：A**

**⚠️ 易错提醒：** 判断奇偶性时，关键是化简 $f(-x)$。利用 $(a+b)(a-b) = a^2 - b^2$ 的变形技巧，将 $-x+\sqrt{x^2+1}$ 与 $x+\sqrt{x^2+1}$ 的乘积化为 $1$，从而得到 $f(-x) = -f(x)$。

**💡 解题思路总结：** 判断奇偶性先算 $f(-x)$ 与 $f(x)$ 的关系；判断单调性时，利用复合函数的单调性——外层 $\ln$ 递增，内层也递增，则复合函数递增。
