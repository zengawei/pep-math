**题目：**

设等差数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n$，若 $a_3 + a_7 = 10$，则 $S_9 = $ \_\_\_\_\_\_。

---

**解答：**

**第1步：** 利用等差数列性质。

$a_3 + a_7 = (a_1 + 2d) + (a_1 + 6d) = 2a_1 + 8d = 2(a_1 + 4d) = 2a_5$

所以 $2a_5 = 10$，$a_5 = 5$。

> 📌 运用知识点：arithmetic-sequence-sum

**第2步：** 求 $S_9$。

$$S_9 = \frac{9(a_1 + a_9)}{2} = \frac{9 \times 2a_5}{2} = 9a_5 = 9 \times 5 = 45$$

> 📌 运用知识点：arithmetic-sequence-sum

**答案：** $\boxed{45}$

**⚠️ 易错提醒：** 等差数列中 $a_3 + a_7 = 2a_5$（等差中项性质，因为 $3 + 7 = 2 \times 5$），不要误以为 $a_3 + a_7 = a_{10}$。另外 $S_9 = \dfrac{9(a_1+a_9)}{2} = 9a_5$，利用了 $a_1 + a_9 = 2a_5$。

**💡 解题思路总结：** 等差数列求和问题中，若已知条件涉及若干项之和，优先利用等差中项性质 $a_m + a_n = 2a_{\frac{m+n}{2}}$ 化简，再与求和公式 $S_n = \dfrac{n(a_1+a_n)}{2}$ 建立联系。
