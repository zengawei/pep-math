**题目：** 已知椭圆 $C: \dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$）的离心率为 $\dfrac{\sqrt{3}}{2}$，且过点 $\left(1, \dfrac{\sqrt{3}}{2}\right)$。

（1）求椭圆 $C$ 的方程；

（2）直线 $l: y = kx + 1$ 与 $C$ 交于 $A$、$B$ 两点，当 $|AB| = \dfrac{8\sqrt{2}}{5}$ 时，求 $k$ 的值。

---

**解答：**

**第1步：** 利用离心率条件
> 📌 运用知识点：椭圆的离心率

$e = \dfrac{c}{a} = \dfrac{\sqrt{3}}{2}$，所以 $c^2 = \dfrac{3}{4}a^2$，$b^2 = a^2 - c^2 = \dfrac{1}{4}a^2$。

**第2步：** 代入点求 $a^2$、$b^2$

椭圆过点 $\left(1, \dfrac{\sqrt{3}}{2}\right)$：

$$\frac{1}{a^2} + \frac{3}{4b^2} = 1 \implies \frac{1}{a^2} + \frac{3}{a^2} = 1 \implies a^2 = 4,\ b^2 = 1$$

$$\boxed{C: \frac{x^2}{4} + y^2 = 1}$$

**第3步：** 联立直线与椭圆
> 📌 运用知识点：弦长公式

$y = kx + 1$ 代入 $\dfrac{x^2}{4} + y^2 = 1$：

$$\frac{x^2}{4} + (kx+1)^2 = 1 \implies \left(\frac{1}{4}+k^2\right)x^2 + 2kx = 0$$

解得 $x_1 = 0$，$x_2 = \dfrac{-8k}{1+4k^2}$。

$$|AB| = \sqrt{1+k^2} \cdot |x_1 - x_2| = \frac{8|k|\sqrt{1+k^2}}{1+4k^2}$$

**第4步：** 解方程求 $k$

$$\frac{8|k|\sqrt{1+k^2}}{1+4k^2} = \frac{8\sqrt{2}}{5}$$

$$\frac{|k|\sqrt{1+k^2}}{1+4k^2} = \frac{\sqrt{2}}{5}$$

两边平方：$\dfrac{k^2(1+k^2)}{(1+4k^2)^2} = \dfrac{2}{25}$

$25k^2(1+k^2) = 2(1+4k^2)^2$

$25k^2 + 25k^4 = 2 + 16k^2 + 32k^4$

$7k^4 - 9k^2 + 2 = 0$

$(7k^2 - 2)(k^2 - 1) = 0$

$k^2 = 1$ 或 $k^2 = \dfrac{2}{7}$

$$\boxed{k = \pm 1 \text{ 或 } k = \pm \frac{\sqrt{14}}{7}}$$

**⚠️ 易错提醒：** 直线 $y = kx + 1$ 过点 $(0,1)$，该点恰好在椭圆上，所以一个交点为 $(0,1)$。联立后有一个根 $x=0$，不要遗漏另一个根。平方后需验证解的合理性。

**💡 解题思路总结：** 直线过椭圆上的定点时，联立方程有一个已知根，可以简化计算。弦长公式 $|AB| = \sqrt{1+k^2}|x_1-x_2|$ 是解析几何的核心工具。
