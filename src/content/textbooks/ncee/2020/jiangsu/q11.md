**题目：** 已知 $f(x) = e^x \sin x$，则 $f'(0) =$

A. $0$

B. $1$

C. $e$

D. $-1$

---

**解答：**

**第1步：** 求导数
> 📌 运用知识点：导数的运算法则（乘法法则）

$$f'(x) = (e^x)' \sin x + e^x (\sin x)' = e^x \sin x + e^x \cos x = e^x(\sin x + \cos x)$$

**第2步：** 代入 $x = 0$

$$f'(0) = e^0(\sin 0 + \cos 0) = 1 \times (0 + 1) = 1$$

**答案：B**

**⚠️ 易错提醒：** 乘法求导法则 $(uv)' = u'v + uv'$，不要漏掉其中一项。$e^0 = 1$，$\sin 0 = 0$，$\cos 0 = 1$。

**💡 解题思路总结：** 含 $e^x$ 与三角函数乘积的求导，用乘法法则后提取 $e^x$，代入特殊值即可。
