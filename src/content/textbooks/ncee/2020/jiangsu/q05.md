**题目：** 在 $\triangle ABC$ 中，$D$ 为 $BC$ 的中点，$\overrightarrow{AB} = \vec{a}$，$\overrightarrow{AC} = \vec{b}$，则 $\overrightarrow{AD} =$

A. $\dfrac{1}{2}(\vec{a} + \vec{b})$

B. $\vec{a} + \vec{b}$

C. $\dfrac{1}{2}(\vec{a} - \vec{b})$

D. $\dfrac{1}{2}(\vec{b} - \vec{a})$

---

**解答：**

**第1步：** 利用中点公式
> 📌 运用知识点：向量的加法

$$\overrightarrow{AD} = \overrightarrow{AB} + \overrightarrow{BD} = \overrightarrow{AB} + \frac{1}{2}\overrightarrow{BC}$$

$$= \vec{a} + \frac{1}{2}(\vec{b} - \vec{a}) = \vec{a} + \frac{1}{2}\vec{b} - \frac{1}{2}\vec{a} = \frac{1}{2}\vec{a} + \frac{1}{2}\vec{b} = \frac{1}{2}(\vec{a} + \vec{b})$$

**答案：A**

**⚠️ 易错提醒：** $\overrightarrow{BC} = \overrightarrow{AC} - \overrightarrow{AB} = \vec{b} - \vec{a}$，不要搞反方向。中点公式 $\overrightarrow{AD} = \dfrac{\overrightarrow{AB} + \overrightarrow{AC}}{2}$ 可以直接使用。

**💡 解题思路总结：** 三角形中线的向量表示：$\overrightarrow{AD} = \dfrac{1}{2}(\vec{a} + \vec{b})$，这是向量加法平行四边形法则的直接应用。
