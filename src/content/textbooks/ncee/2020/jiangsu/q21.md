**题目：** 已知函数 $f(x) = \ln x - ax + 1$（$a \in \mathbb{R}$）。

（1）讨论 $f(x)$ 的单调性；

（2）当 $a > 0$ 时，若 $f(x) \leqslant 0$ 恒成立，求 $a$ 的取值范围。

---

**解答：**

**第1步：** 求导数
> 📌 运用知识点：导数的运算

$f(x) = \ln x - ax + 1$，定义域 $x > 0$。

$$f'(x) = \frac{1}{x} - a$$

**第2步：** 讨论单调性
> 📌 运用知识点：导数与单调性

**当 $a \leqslant 0$ 时：** $f'(x) = \dfrac{1}{x} - a > 0$（因为 $\dfrac{1}{x} > 0$，$-a \geqslant 0$），$f(x)$ 在 $(0, +\infty)$ 上单调递增。

**当 $a > 0$ 时：** 令 $f'(x) = 0$，$x = \dfrac{1}{a}$。

- 当 $0 < x < \dfrac{1}{a}$ 时 $f'(x) > 0$，$f(x)$ 单调递增；
- 当 $x > \dfrac{1}{a}$ 时 $f'(x) < 0$，$f(x)$ 单调递减。

$$\boxed{a \leqslant 0 \text{ 时 } f(x) \text{ 在 } (0,+\infty) \text{ 上递增；} a > 0 \text{ 时 } f(x) \text{ 在 } \left(0, \frac{1}{a}\right) \text{ 递增，在 } \left(\frac{1}{a}, +\infty\right) \text{ 递减}}$$

**第3步：** 恒成立条件
> 📌 运用知识点：导数与最值

当 $a > 0$ 时，$f(x)$ 在 $x = \dfrac{1}{a}$ 处取最大值：

$$f\left(\frac{1}{a}\right) = \ln\frac{1}{a} - a \cdot \frac{1}{a} + 1 = -\ln a - 1 + 1 = -\ln a$$

$f(x) \leqslant 0$ 恒成立 $\iff f(x)_{\max} \leqslant 0 \iff -\ln a \leqslant 0 \iff \ln a \geqslant 0 \iff a \geqslant 1$。

$$\boxed{a \geqslant 1}$$

**⚠️ 易错提醒：** 讨论单调性时不能漏掉 $a \leqslant 0$ 的情况。恒成立问题转化为最大值 $\leqslant 0$，最大值在极值点取到。

**💡 解题思路总结：** 含参函数的单调性讨论需要分类讨论（参数的正负）。恒成立问题转化为"最大值 $\leqslant 0$"，先求最大值再解不等式。
