**题目：** 在四棱锥 $P\text{-}ABCD$ 中，底面 $ABCD$ 是矩形，$PA \perp$ 底面 $ABCD$，$PA = AB = 2$，$AD = 4$，$E$ 为 $PD$ 的中点。

（1）求证：$PB \parallel$ 平面 $ACE$；

（2）求直线 $CE$ 与平面 $PAD$ 所成角的正弦值。

---

**解答：**

**第1步：** 建立空间直角坐标系
> 📌 运用知识点：空间向量坐标

以 $A$ 为原点，$\overrightarrow{AB}$、$\overrightarrow{AD}$、$\overrightarrow{AP}$ 分别为 $x$、$y$、$z$ 轴正方向。

$A(0,0,0)$，$B(2,0,0)$，$C(2,4,0)$，$D(0,4,0)$，$P(0,0,2)$。

$E$ 为 $PD$ 中点：$E = (0, 2, 1)$。

**第2步：** 证明 $PB \parallel$ 平面 $ACE$
> 📌 运用知识点：空间向量证明平行

$\overrightarrow{PB} = (2, 0, -2)$

$\overrightarrow{AC} = (2, 4, 0)$，$\overrightarrow{AE} = (0, 2, 1)$

设平面 $ACE$ 的法向量 $\vec{n} = (x, y, z)$：

$$\begin{cases} 2x + 4y = 0 \\ 2y + z = 0 \end{cases}$$

取 $y = -1$，则 $x = 2$，$z = 2$，$\vec{n} = (2, -1, 2)$。

$\overrightarrow{PB} \cdot \vec{n} = 4 + 0 - 4 = 0$

所以 $\overrightarrow{PB} \perp \vec{n}$。又 $P \notin$ 平面 $ACE$，故 $PB \parallel$ 平面 $ACE$。

$$\boxed{PB \parallel \text{平面 } ACE}$$

**第3步：** 求直线 $CE$ 与平面 $PAD$ 所成角的正弦值
> 📌 运用知识点：空间向量求线面角

$\overrightarrow{CE} = (-2, -2, 1)$

平面 $PAD$ 由 $\overrightarrow{AD} = (0, 4, 0)$ 和 $\overrightarrow{AP} = (0, 0, 2)$ 张成，法向量 $\vec{m} = (1, 0, 0)$。

设直线 $CE$ 与平面 $PAD$ 所成角为 $\theta$：

$$\sin\theta = \frac{|\overrightarrow{CE} \cdot \vec{m}|}{|\overrightarrow{CE}| \cdot |\vec{m}|} = \frac{|-2|}{\sqrt{4+4+1} \times 1} = \frac{2}{3}$$

$$\boxed{\sin\theta = \frac{2}{3}}$$

**⚠️ 易错提醒：** 线面角的正弦值公式是 $\sin\theta = \dfrac{|\vec{v} \cdot \vec{n}|}{|\vec{v}||\vec{n}|}$（方向向量与法向量的点积取绝对值），不是余弦。

**💡 解题思路总结：** 建系求法向量后，线面平行的判定转化为方向向量与法向量垂直；线面角转化为方向向量与法向量夹角的余角。
