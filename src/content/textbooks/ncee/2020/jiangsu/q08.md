**题目：** 已知不等式 $ax^2 + bx + 2 > 0$ 的解集为 $\left(-\dfrac{1}{2}, \dfrac{1}{3}\right)$，则 $a + b =$

A. $-10$

B. $-14$

C. $10$

D. $14$

---

**解答：**

**第1步：** 分析解集与系数的关系
> 📌 运用知识点：一元二次不等式与方程根的关系

解集为 $\left(-\dfrac{1}{2}, \dfrac{1}{3}\right)$，说明 $a < 0$，且 $-\dfrac{1}{2}$、$\dfrac{1}{3}$ 是方程 $ax^2 + bx + 2 = 0$ 的两个根。

**第2步：** 利用韦达定理

$$-\frac{1}{2} + \frac{1}{3} = -\frac{b}{a} \implies -\frac{1}{6} = -\frac{b}{a} \implies \frac{b}{a} = \frac{1}{6}$$

$$\left(-\frac{1}{2}\right) \times \frac{1}{3} = \frac{2}{a} \implies -\frac{1}{6} = \frac{2}{a} \implies a = -12$$

$$b = \frac{a}{6} = \frac{-12}{6} = -2$$

**第3步：** 计算 $a + b$

$a + b = -12 + (-2) = -14$

**答案：B**

**⚠️ 易错提醒：** 解集为开区间说明 $a < 0$（抛物线开口向下）。韦达定理中根与系数的关系：$x_1 + x_2 = -\dfrac{b}{a}$，$x_1 x_2 = \dfrac{c}{a}$。

**💡 解题思路总结：** 已知二次不等式的解集，利用韦达定理建立系数与根的关系，先求 $a$ 再求 $b$。
