**题目：** 已知集合 $A = \{x \mid x^2 - 2x - 3 < 0\}$，$B = \{x \mid x \geqslant 1\}$，则 $A \cap B =$

A. $\{x \mid 1 \leqslant x < 3\}$

B. $\{x \mid 1 < x < 3\}$

C. $\{x \mid x < 3\}$

D. $\{x \mid x > -1\}$

---

**解答：**

**第1步：** 求集合 $A$
> 📌 运用知识点：一元二次不等式的解法

$x^2 - 2x - 3 < 0 \implies (x-3)(x+1) < 0 \implies -1 < x < 3$

$A = (-1, 3)$

**第2步：** 求 $A \cap B$
> 📌 运用知识点：集合的交集运算

$A = (-1, 3)$，$B = [1, +\infty)$

$A \cap B = [1, 3) = \{x \mid 1 \leqslant x < 3\}$

**答案：A**

**⚠️ 易错提醒：** $A$ 中端点 $-1$ 和 $3$ 取不到（严格不等号），$B$ 中 $1$ 可以取到。交集后 $1$ 取到，$3$ 取不到。

**💡 解题思路总结：** 先解不等式化简集合，再在数轴上取公共部分求交集，注意端点开闭。
