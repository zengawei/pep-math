**题目：** 已知函数 $f(x) = x\ln x$。

(1) 求 $f(x)$ 的最小值；

(2) 若对一切 $x > 0$，$f(x) \geq ax - 1$ 恒成立，求 $a$ 的取值范围。

---

**解答：**

**第1步：** 求导数（第1问）
> 📌 运用知识点：derivative-max-min

定义域 $x > 0$。

$$f'(x) = \ln x + x \cdot \frac{1}{x} = \ln x + 1$$

**第2步：** 找极值点
> 📌 运用知识点：derivative-max-min

令 $f'(x) = 0$：$\ln x = -1 \implies x = \dfrac{1}{\mathrm{e}}$。

$x < \dfrac{1}{\mathrm{e}}$ 时 $f'(x) < 0$（递减），$x > \dfrac{1}{\mathrm{e}}$ 时 $f'(x) > 0$（递增）。

$x = \dfrac{1}{\mathrm{e}}$ 是极小值点（也是最小值点）。

$$f\left(\frac{1}{\mathrm{e}}\right) = \frac{1}{\mathrm{e}} \ln\frac{1}{\mathrm{e}} = \frac{1}{\mathrm{e}} \times (-1) = -\frac{1}{\mathrm{e}}$$

**$f(x)$ 的最小值为 $-\dfrac{1}{\mathrm{e}}$。**

**第3步：** 转化恒成立条件（第2问）
> 📌 运用知识点：derivative-applications

$x\ln x \geq ax - 1$ 对一切 $x > 0$ 恒成立。

设 $g(x) = x\ln x - ax + 1$，需 $g(x) \geq 0$ 对一切 $x > 0$ 恒成立。

即 $g(x)_{\min} \geq 0$。

**第4步：** 求 $g(x)$ 的最小值
> 📌 运用知识点：derivative-max-min

$$g'(x) = \ln x + 1 - a$$

令 $g'(x) = 0$：$\ln x = a - 1 \implies x = \mathrm{e}^{a-1}$。

$x < \mathrm{e}^{a-1}$ 时 $g'(x) < 0$，$x > \mathrm{e}^{a-1}$ 时 $g'(x) > 0$。

$g(x)$ 在 $x = \mathrm{e}^{a-1}$ 处取最小值：

$$g(\mathrm{e}^{a-1}) = \mathrm{e}^{a-1}(a-1) - a\mathrm{e}^{a-1} + 1 = \mathrm{e}^{a-1}(a-1-a) + 1 = 1 - \mathrm{e}^{a-1}$$

**第5步：** 求解不等式
> 📌 运用知识点：basic-inequality

$g(x)_{\min} \geq 0 \implies 1 - \mathrm{e}^{a-1} \geq 0 \implies \mathrm{e}^{a-1} \leq 1 \implies a - 1 \leq 0 \implies a \leq 1$。

**$a$ 的取值范围为 $(-\infty, 1]$。**

**⚠️ 易错提醒：** ①$x\ln x$ 的导数要用乘法法则：$(x\ln x)' = \ln x + 1$。②第2问中构造辅助函数 $g(x)$ 后，需完整分析其最小值，不能跳过求导步骤。

**💡 解题思路总结：** 恒成立问题 ⟺ 最小值 $\geq 0$。构造 $g(x) = f(x) - (ax-1)$，求 $g(x)$ 最小值（含参），令最小值 $\geq 0$ 解出参数范围。
