**题目：** 设 $a, b \in \mathbb{R}$，则 "$a > b > 0$" 是 "$\dfrac{1}{a} < \dfrac{1}{b}$" 的（  ）

A. 充分不必要条件

B. 必要不充分条件

C. 充要条件

D. 既不充分也不必要条件

---

**解答：**

**第1步：** 分析充分性
> 📌 运用知识点：basic-inequality

若 $a > b > 0$，则 $\dfrac{1}{a} - \dfrac{1}{b} = \dfrac{b-a}{ab}$。

因为 $a > b$，$b - a < 0$；$a > 0, b > 0$，$ab > 0$。

所以 $\dfrac{b-a}{ab} < 0$，即 $\dfrac{1}{a} < \dfrac{1}{b}$。充分性成立。

**第2步：** 分析必要性
> 📌 运用知识点：inequality-properties

若 $\dfrac{1}{a} < \dfrac{1}{b}$，不一定有 $a > b > 0$。

反例：$a = 1, b = -1$，$\dfrac{1}{1} = 1 > -1 = \dfrac{1}{-1}$... 这不满足条件。

再试：$a = -1, b = 1$，$\dfrac{1}{-1} = -1 < 1 = \dfrac{1}{1}$。满足 $\dfrac{1}{a} < \dfrac{1}{b}$，但 $a < b$。

所以必要性不成立。

**答案：A**

**⚠️ 易错提醒：** 必要性分析时，$\frac{1}{a} < \frac{1}{b}$ 不能推出 $a > b > 0$，因为 $a, b$ 可能为负数。举反例是判断必要性的有效方法。

**💡 解题思路总结：** 充分性：从条件出发推结论。必要性：尝试从结论推条件，推不出则举反例否定。
