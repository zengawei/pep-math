**题目：** 已知函数 $f(x) = x^2 - 2x + 3$ 在区间 $[0, a]$ 上的最大值为 $3$，最小值为 $2$，则 $a$ 的取值范围为 ______。

---

**解答：**

**第1步：** 分析函数性质
> 📌 运用知识点：quadratic-function

$f(x) = (x-1)^2 + 2$，开口向上，对称轴 $x = 1$，顶点 $(1, 2)$。

$f(0) = 3$。

**第2步：** 确定最小值条件
> 📌 运用知识点：function-properties

最小值为 $2$，即 $f(1) = 2$，要求区间包含 $x = 1$，所以 $a \geq 1$。

**第3步：** 确定最大值条件
> 📌 运用知识点：function-properties

最大值为 $3 = f(0)$。在 $[1, a]$ 上 $f(x)$ 单调递增，需 $f(a) \leq 3$：

$a^2 - 2a + 3 \leq 3 \implies a^2 - 2a \leq 0 \implies a(a-2) \leq 0 \implies 0 \leq a \leq 2$

**第4步：** 综合
> 📌 运用知识点：function-properties

$a \geq 1$ 且 $a \leq 2$，所以 $a \in [1, 2]$。

**答案：$[1, 2]$**

**⚠️ 易错提醒：** 二次函数在闭区间上的最值需要同时考虑端点值和顶点值。最小值在顶点取到要求 $a \geq 1$；最大值在左端点 $x=0$ 取到要求右端点 $f(a) \leq 3$。

**💡 解题思路总结：** 含参二次函数在闭区间上的最值问题：画出函数图像，分析对称轴与区间的关系，分别利用最大值和最小值条件列不等式。
