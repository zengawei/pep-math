**题目：** 已知等差数列 $\{a_n\}$ 中，$a_1 = 1$，$a_3 + a_5 = 8$，则 $a_7 = $（  ）

A. $5$

B. $6$

C. $7$

D. $8$

---

**解答：**

**第1步：** 利用等差数列性质
> 📌 运用知识点：arithmetic-sequence

$a_3 + a_5 = (a_1 + 2d) + (a_1 + 4d) = 2a_1 + 6d = 2 + 6d = 8$

$6d = 6 \implies d = 1$

**第2步：** 求 $a_7$
> 📌 运用知识点：arithmetic-sequence-sum

$$a_7 = a_1 + 6d = 1 + 6 = 7$$

**答案：C**

**⚠️ 易错提醒：** 也可利用等差数列性质 $a_3 + a_5 = 2a_4 = 8$，$a_4 = 4$，$d = a_4 - a_1 = 3$... 不对，$a_4 = a_1 + 3d = 1 + 3d = 4$，$d = 1$。结果一致。

**💡 解题思路总结：** 等差数列中 $a_m + a_n = 2a_{(m+n)/2}$（$m+n$ 为偶数时），利用对称性可简化计算。
