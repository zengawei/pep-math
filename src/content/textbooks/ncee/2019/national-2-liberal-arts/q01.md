**题目：** 已知集合 $A = \{1, 2, 3, 4, 5, 6, 7\}$，$B = \{x \mid x^2 - 4x + 3 \leq 0\}$，则 $A \cap B = $（  ）

A. $\{1, 2, 3\}$

B. $\{1, 2, 3, 4\}$

C. $\{x \mid 1 \leq x \leq 3\}$

D. $\{x \mid 1 \leq x \leq 4\}$

---

**解答：**

**第1步：** 求解集合 $B$
> 📌 运用知识点：set-operations

解不等式 $x^2 - 4x + 3 \leq 0$：

$(x-1)(x-3) \leq 0$

所以 $B = \{x \mid 1 \leq x \leq 3\}$。

**第2步：** 求 $A \cap B$
> 📌 运用知识点：set-operations

$A = \{1, 2, 3, 4, 5, 6, 7\}$，$B = \{x \mid 1 \leq x \leq 3\}$。

$A \cap B$ 取 $A$ 中满足 $1 \leq x \leq 3$ 的整数元素：$\{1, 2, 3\}$。

**答案：A**

**⚠️ 易错提醒：** 注意 $B$ 是实数集合（区间），而 $A$ 是离散整数集合，交集结果应取 $A$ 中属于 $B$ 的元素，不要混淆写成区间形式（选项 C 是陷阱）。

**💡 解题思路总结：** 先解不等式确定集合 $B$ 的范围，再从集合 $A$ 中筛选满足条件的元素，注意交集结果的形式要与题目选项一致。
