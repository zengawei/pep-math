**题目：**

已知函数 $f(x) = \sin\left(2x + \dfrac{\pi}{6}\right)$，则下列结论正确的是

A. $f(x)$ 的最小正周期为 $\pi$

B. $f(x)$ 的图象关于直线 $x = \dfrac{\pi}{6}$ 对称

C. $f(x)$ 的图象关于点 $\left(-\dfrac{\pi}{12}, 0\right)$ 对称

D. $f(x)$ 在 $\left[0, \dfrac{\pi}{3}\right]$ 上单调递增

---

**解答：**

**逐项分析：**

**选项 A：** 求最小正周期

$$T = \frac{2\pi}{\omega} = \frac{2\pi}{2} = \pi$$

✅ A 正确。

> 📌 运用知识点：trig-function

**选项 B：** 判断对称轴

$x = \dfrac{\pi}{6}$ 时：

$$f\left(\frac{\pi}{6}\right) = \sin\left(2 \times \frac{\pi}{6} + \frac{\pi}{6}\right) = \sin\left(\frac{\pi}{3} + \frac{\pi}{6}\right) = \sin\frac{\pi}{2} = 1$$

因为 $f\left(\dfrac{\pi}{6}\right) = 1$ 为最大值，所以 $x = \dfrac{\pi}{6}$ 是对称轴。✅ B 正确。

> 📌 运用知识点：trig-graph

**选项 C：** 判断对称中心

$x = -\dfrac{\pi}{12}$ 时：

$$f\left(-\frac{\pi}{12}\right) = \sin\left(2 \times \left(-\frac{\pi}{12}\right) + \frac{\pi}{6}\right) = \sin\left(-\frac{\pi}{6} + \frac{\pi}{6}\right) = \sin 0 = 0$$

函数值为 $0$，且 $\sin$ 函数在零点处图象关于该点中心对称。✅ C 正确。

> 📌 运用知识点：trig-graph

**选项 D：** 判断单调性

当 $x \in \left[0, \dfrac{\pi}{3}\right]$ 时：

$$2x + \frac{\pi}{6} \in \left[\frac{\pi}{6}, \frac{2\pi}{3} + \frac{\pi}{6}\right] = \left[\frac{\pi}{6}, \frac{5\pi}{6}\right]$$

$\sin t$ 在 $\left[\dfrac{\pi}{6}, \dfrac{\pi}{2}\right]$ 上单调递增，在 $\left[\dfrac{\pi}{2}, \dfrac{5\pi}{6}\right]$ 上单调递减。

所以 $f(x)$ 在 $\left[0, \dfrac{\pi}{3}\right]$ 上不是单调递增的。❌ D 错误。

> 📌 运用知识点：trig-function

**答案：A、B、C**

**⚠️ 易错提醒：** 判断对称轴时，需验证函数在该点取到最大值或最小值（即 $\pm 1$），而不仅仅是函数值存在。判断单调性时，需要将 $x$ 的范围转化为 $\omega x + \varphi$ 的范围，再结合 $\sin$ 函数的单调区间判断。

**💡 解题思路总结：** 三角函数 $y = A\sin(\omega x + \varphi)$ 的性质分析：周期 $T = \dfrac{2\pi}{|\omega|}$；对称轴对应 $\omega x + \varphi = \dfrac{\pi}{2} + k\pi$；对称中心对应 $\omega x + \varphi = k\pi$；单调性需将 $x$ 的范围转化为整体相位的范围来判断。
