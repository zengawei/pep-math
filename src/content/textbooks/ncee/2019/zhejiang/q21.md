**题目：**

已知椭圆 $C: \dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$）的离心率为 $\dfrac{1}{2}$，且椭圆的右焦点到右顶点的距离为 $1$。

（1）求椭圆 $C$ 的方程；

（2）设过椭圆 $C$ 的右焦点 $F_2$ 的直线 $l$ 交椭圆于 $A$，$B$ 两点，$M(4, 0)$，求 $\triangle ABM$ 面积的取值范围。

---

**解答：**

**（1）**

**第1步:** 利用已知条件列方程

离心率 $e = \dfrac{c}{a} = \dfrac{1}{2}$，所以 $c = \dfrac{a}{2}$。

右焦点 $(c, 0)$ 到右顶点 $(a, 0)$ 的距离为 $a - c = 1$。

> 📌 运用知识点：ellipse-properties

**第2步:** 求解参数

$$a - c = a - \frac{a}{2} = \frac{a}{2} = 1 \implies a = 2$$

$$c = 1, \quad b^2 = a^2 - c^2 = 4 - 1 = 3$$

椭圆方程为：

$$\frac{x^2}{4} + \frac{y^2}{3} = 1$$

> 📌 运用知识点：ellipse-properties

**（2）**

**第3步:** 设直线方程并联立

右焦点 $F_2(1, 0)$。设直线 $l: x = my + 1$（包含斜率不存在的情况）。

代入椭圆方程：

$$\frac{(my+1)^2}{4} + \frac{y^2}{3} = 1$$

$$3(my+1)^2 + 4y^2 = 12$$

$$3m^2y^2 + 6my + 3 + 4y^2 = 12$$

$$(3m^2 + 4)y^2 + 6my - 9 = 0$$

> 📌 运用知识点：conic-section-line

**第4步:** 利用韦达定理

设 $A(x_1, y_1)$，$B(x_2, y_2)$，则：

$$y_1 + y_2 = \frac{-6m}{3m^2 + 4}, \quad y_1 y_2 = \frac{-9}{3m^2 + 4}$$

$$|y_1 - y_2|^2 = (y_1 + y_2)^2 - 4y_1 y_2 = \frac{36m^2}{(3m^2+4)^2} + \frac{36}{3m^2+4} = \frac{36m^2 + 36(3m^2+4)}{(3m^2+4)^2} = \frac{144m^2 + 144}{(3m^2+4)^2} = \frac{144(m^2+1)}{(3m^2+4)^2}$$

$$|y_1 - y_2| = \frac{12\sqrt{m^2+1}}{3m^2+4}$$

> 📌 运用知识点：conic-section-line

**第5步:** 计算面积

点 $M(4, 0)$ 到直线 $x - my - 1 = 0$ 的距离：

$$d = \frac{|4 - 0 - 1|}{\sqrt{1 + m^2}} = \frac{3}{\sqrt{1 + m^2}}$$

$$|AB| = \sqrt{1 + m^2} \cdot |y_1 - y_2| = \sqrt{1+m^2} \cdot \frac{12\sqrt{m^2+1}}{3m^2+4} = \frac{12(m^2+1)}{3m^2+4}$$

$$S = \frac{1}{2} |AB| \cdot d = \frac{1}{2} \cdot \frac{12(m^2+1)}{3m^2+4} \cdot \frac{3}{\sqrt{m^2+1}} = \frac{18\sqrt{m^2+1}}{3m^2+4}$$

> 📌 运用知识点：ellipse-properties

**第6步:** 求面积的范围

令 $t = \sqrt{m^2 + 1} \geq 1$，则 $m^2 = t^2 - 1$，$3m^2 + 4 = 3t^2 + 1$。

$$S = \frac{18t}{3t^2 + 1}$$

设 $g(t) = \dfrac{t}{3t^2 + 1}$（$t \geq 1$），求导：

$$g'(t) = \frac{(3t^2+1) - t \cdot 6t}{(3t^2+1)^2} = \frac{1 - 3t^2}{(3t^2+1)^2}$$

当 $t \geq 1$ 时，$1 - 3t^2 \leq 1 - 3 = -2 < 0$，所以 $g(t)$ 在 $[1, +\infty)$ 上单调递减。

$$g(1) = \frac{1}{4}, \quad \lim_{t \to +\infty} g(t) = 0$$

所以 $S \in \left(0, \dfrac{18}{4}\right] = \left(0, \dfrac{9}{2}\right]$。

> 📌 运用知识点：conic-section-line

**答案：**

（1）$\boxed{\dfrac{x^2}{4} + \dfrac{y^2}{3} = 1}$

（2）$\boxed{\left(0, \dfrac{9}{2}\right]}$

**⚠️ 易错提醒：** （1）"右焦点到右顶点的距离"是 $a - c$（不是 $a + c$）。（2）设直线时用 $x = my + 1$ 而非 $y = k(x-1)$，可以包含斜率不存在的情况。（3）求范围时换元 $t = \sqrt{m^2+1} \geq 1$，注意 $t$ 的下界是 $1$（当 $m = 0$ 时取到），不是 $0$。

**💡 解题思路总结：** 解析几何综合题的标准解法：（1）由离心率和几何条件求椭圆参数；（2）联立直线与椭圆方程，利用韦达定理求弦长，再用点到直线距离求面积，最后通过换元和求导确定面积范围。设直线方程时注意包含所有情况。
