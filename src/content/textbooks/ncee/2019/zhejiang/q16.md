**题目：**

已知等比数列 $\{a_n\}$ 中，$a_1 = 1$，$a_3 = 4$，则前 $4$ 项的和 $S_4 =$ \_\_\_\_\_\_。

---

**解答：**

**第1步:** 求公比 $q$

由等比数列通项公式 $a_n = a_1 q^{n-1}$：

$$a_3 = a_1 q^2 = q^2 = 4$$

所以 $q = 2$ 或 $q = -2$。

> 📌 运用知识点：geometric-sequence-sum

**第2步:** 分情况求 $S_4$

利用等比数列前 $n$ 项和公式 $S_n = \dfrac{a_1(1 - q^n)}{1 - q}$：

**当 $q = 2$ 时：**

$$S_4 = \frac{1 \times (1 - 2^4)}{1 - 2} = \frac{1 - 16}{-1} = \frac{-15}{-1} = 15$$

**当 $q = -2$ 时：**

$$S_4 = \frac{1 \times (1 - (-2)^4)}{1 - (-2)} = \frac{1 - 16}{3} = \frac{-15}{3} = -5$$

> 📌 运用知识点：geometric-sequence-sum

**答案：** $\boxed{15 \text{ 或 } -5}$

**⚠️ 易错提醒：** 由 $q^2 = 4$ 求 $q$ 时，容易只取 $q = 2$ 而遗漏 $q = -2$。等比数列的公比可以是负数，必须分情况讨论。

**💡 解题思路总结：** 等比数列中已知某一项求公比时，注意公比可能有两个值（正负各一个）。求和时分别代入公式计算，不要遗漏情况。
