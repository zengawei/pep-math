**题目：**

若正数 $a$，$b$ 满足 $a + b = 2$，则 $\dfrac{1}{a} + \dfrac{1}{b}$ 的最小值为

A. $2$

B. $3$

C. $4$

D. $5$

---

**解答：**

**第1步:** 通分化简

$$\frac{1}{a} + \frac{1}{b} = \frac{a + b}{ab} = \frac{2}{ab}$$

因此，要求 $\dfrac{1}{a} + \dfrac{1}{b}$ 的最小值，等价于求 $ab$ 的最大值。

> 📌 运用知识点：basic-inequality

**第2步:** 利用均值不等式求 $ab$ 的最大值

由均值不等式：

$$ab \leq \left(\frac{a + b}{2}\right)^2 = \left(\frac{2}{2}\right)^2 = 1$$

等号成立条件：$a = b = 1$。

> 📌 运用知识点：basic-inequality

**第3步:** 求最小值

$$\frac{1}{a} + \frac{1}{b} = \frac{2}{ab} \geq \frac{2}{1} = 2$$

当 $a = b = 1$ 时取等号，满足 $a + b = 2$ 且 $a, b > 0$。

> 📌 运用知识点：basic-inequality

**答案：A**

**⚠️ 易错提醒：** 使用均值不等式时容易忽略等号成立的条件验证。本题中 $a = b = 1$ 满足 $a + b = 2$ 且 $a, b > 0$，等号可以取到。另外注意通分后转化为求 $ab$ 的最大值，思路更清晰。

**💡 解题思路总结：** 已知 $a + b$ 为定值，求 $\dfrac{1}{a} + \dfrac{1}{b}$ 的最值，可以先通分转化为 $\dfrac{a+b}{ab}$，再利用均值不等式求 $ab$ 的范围。也可以用"乘1法"：$\dfrac{1}{a} + \dfrac{1}{b} = \dfrac{1}{2}(a+b)\left(\dfrac{1}{a} + \dfrac{1}{b}\right) = \dfrac{1}{2}\left(2 + \dfrac{b}{a} + \dfrac{a}{b}\right) \geq \dfrac{1}{2}(2+2) = 2$。
