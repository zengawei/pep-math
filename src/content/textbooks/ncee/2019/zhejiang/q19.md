**题目：**

如图，在长方体 $ABCD\text{-}A_1B_1C_1D_1$ 中，$AB = 2$，$AD = 2$，$AA_1 = 2$。

（1）证明：$A_1C \perp BD$；

（2）求二面角 $A_1\text{-}BD\text{-}C$ 的余弦值。

---

**解答：**

**（1）**

**第1步:** 建立空间直角坐标系

以 $D$ 为原点，$\overrightarrow{DA}$、$\overrightarrow{DC}$、$\overrightarrow{DD_1}$ 分别为 $x$、$y$、$z$ 轴正方向，建立空间直角坐标系。

各点坐标为：
- $D(0, 0, 0)$
- $A(2, 0, 0)$
- $B(2, 2, 0)$
- $C(0, 2, 0)$
- $A_1(2, 0, 2)$
- $B_1(2, 2, 2)$
- $C_1(0, 2, 2)$
- $D_1(0, 0, 2)$

> 📌 运用知识点：space-vector-coordinate

**第2步:** 求向量并计算数量积

$$\overrightarrow{A_1C} = C - A_1 = (0-2, 2-0, 0-2) = (-2, 2, -2)$$

$$\overrightarrow{BD} = D - B = (0-2, 0-2, 0-0) = (-2, -2, 0)$$

$$\overrightarrow{A_1C} \cdot \overrightarrow{BD} = (-2)(-2) + (2)(-2) + (-2)(0) = 4 - 4 + 0 = 0$$

因为 $\overrightarrow{A_1C} \cdot \overrightarrow{BD} = 0$，所以 $A_1C \perp BD$。

> 📌 运用知识点：space-vector-coordinate

**（2）**

**第3步:** 求平面 $A_1BD$ 的法向量

$$\overrightarrow{BA_1} = A_1 - B = (0, -2, 2)$$

$$\overrightarrow{BD} = (-2, -2, 0)$$

设平面 $A_1BD$ 的法向量 $\vec{n_1} = (x, y, z)$，则：

$$\begin{cases} \vec{n_1} \cdot \overrightarrow{BA_1} = -2y + 2z = 0 \\ \vec{n_1} \cdot \overrightarrow{BD} = -2x - 2y = 0 \end{cases}$$

由第一式：$y = z$；由第二式：$x = -y$。

取 $y = 1$，则 $\vec{n_1} = (-1, 1, 1)$。

> 📌 运用知识点：space-vector-coordinate

**第4步:** 求平面 $CBD$ 的法向量

$$\overrightarrow{BC} = C - B = (-2, 0, 0)$$

$$\overrightarrow{BD} = (-2, -2, 0)$$

设平面 $CBD$ 的法向量 $\vec{n_2} = (x, y, z)$，则：

$$\begin{cases} \vec{n_2} \cdot \overrightarrow{BC} = -2x = 0 \\ \vec{n_2} \cdot \overrightarrow{BD} = -2x - 2y = 0 \end{cases}$$

由第一式：$x = 0$；由第二式：$y = 0$。$z$ 可取任意值。

取 $z = 1$，则 $\vec{n_2} = (0, 0, 1)$。

> 📌 运用知识点：space-vector-coordinate

**第5步:** 求二面角的余弦值

$$\cos\theta = \frac{|\vec{n_1} \cdot \vec{n_2}|}{|\vec{n_1}||\vec{n_2}|} = \frac{|(-1)(0) + (1)(0) + (1)(1)|}{\sqrt{1+1+1} \times \sqrt{1}} = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}$$

> 📌 运用知识点：spatial-angle

**答案：**

（1）证明见解答过程。

（2）$\boxed{\dfrac{\sqrt{3}}{3}}$

**⚠️ 易错提醒：** 建立坐标系时容易搞混各点的坐标，特别是长方体中上下底面对应点的 $z$ 坐标。求法向量时，方程组的求解要仔细，注意取特殊值时不要取到零向量。二面角的余弦值需要判断正负——取法向量夹角或其补角取决于二面角的方向。

**💡 解题思路总结：** 空间向量法解立体几何问题的标准流程：（1）建立合适的坐标系，写出各点坐标；（2）证明垂直用数量积为零；（3）求二面角先求两个半平面的法向量，再用公式求夹角余弦。坐标法是解决立体几何问题的通法。
