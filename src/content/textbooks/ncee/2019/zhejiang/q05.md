**题目：**

记 $S_n$ 为等差数列 $\{a_n\}$ 的前 $n$ 项和。若 $a_3 + a_7 = 10$，则 $S_9 =$

A. $35$

B. $45$

C. $55$

D. $65$

---

**解答：**

**第1步:** 利用等差数列性质

在等差数列中，$a_3 + a_7 = a_1 + 2d + a_1 + 6d = 2a_1 + 8d = 2(a_1 + 4d) = 2a_5$

所以 $2a_5 = 10$，即 $a_5 = 5$。

> 📌 运用知识点：arithmetic-sequence

**第2步:** 利用前 $n$ 项和公式

$$S_9 = \frac{9(a_1 + a_9)}{2} = \frac{9 \times 2a_5}{2} = 9a_5 = 9 \times 5 = 45$$

> 📌 运用知识点：arithmetic-sequence

**答案：B**

**⚠️ 易错提醒：** 容易忘记利用等差数列的对称性质 $a_3 + a_7 = 2a_5$，而试图分别求出 $a_1$ 和 $d$，但条件不足无法分别确定。关键是利用 $S_9 = 9a_5$ 这一性质。

**💡 解题思路总结：** 等差数列中，若 $m + n = p + q$，则 $a_m + a_n = a_p + a_q$。前 $n$ 项和 $S_{2k-1} = (2k-1)a_k$，即奇数项的前 $n$ 项和等于项数乘以中间项。灵活运用这些性质可以大大简化计算。
