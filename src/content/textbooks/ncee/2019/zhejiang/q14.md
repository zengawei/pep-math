**题目：**

已知函数 $f(x) = x^3 - 3x^2 + 2$，则下列结论正确的是

A. $f(x)$ 的极小值为 $-2$

B. $f(x)$ 在 $[0, 3]$ 上的最大值为 $2$

C. $f(x)$ 在 $[0, 3]$ 上的最小值为 $-4$

D. $f(x)$ 的极大值为 $2$

---

**解答：**

**预备工作：** 求导并分析

$$f'(x) = 3x^2 - 6x = 3x(x - 2)$$

令 $f'(x) = 0$，得 $x = 0$ 或 $x = 2$。

> 📌 运用知识点：derivative-extrema

**逐项分析：**

**选项 A：** 判断极小值

分析 $f'(x)$ 的符号变化：
- 当 $x < 0$ 时，$f'(x) > 0$，$f(x)$ 单调递增
- 当 $0 < x < 2$ 时，$f'(x) < 0$，$f(x)$ 单调递减
- 当 $x > 2$ 时，$f'(x) > 0$，$f(x)$ 单调递增

$x = 2$ 是极小值点：

$$f(2) = 8 - 12 + 2 = -2$$

✅ A 正确。

> 📌 运用知识点：derivative-extrema

**选项 B：** 求 $[0, 3]$ 上的最大值

在 $[0, 3]$ 上，比较极值点和端点的函数值：

- $f(0) = 2$（极大值点/左端点）
- $f(2) = -2$（极小值点）
- $f(3) = 27 - 27 + 2 = 2$

最大值为 $\max\{2, -2, 2\} = 2$。✅ B 正确。

> 📌 运用知识点：derivative-max-min

**选项 C：** 求 $[0, 3]$ 上的最小值

由选项 B 的分析，最小值为 $\min\{2, -2, 2\} = -2 \neq -4$。

❌ C 错误。

> 📌 运用知识点：derivative-max-min

**选项 D：** 判断极大值

$x = 0$ 是极大值点：

$$f(0) = 0 - 0 + 2 = 2$$

✅ D 正确。

> 📌 运用知识点：derivative-extrema

**答案：A、B、D**

**⚠️ 易错提醒：** 求闭区间上函数的最值时，需要比较所有极值点和端点的函数值，不能遗漏端点。极值点不一定是最值点，最值点也不一定是极值点（可能在端点取到）。本题中 $f(0) = f(3) = 2$，最大值在两个位置同时取到。

**💡 解题思路总结：** 利用导数研究函数的极值和最值：先求 $f'(x)$ 并找出零点，判断各零点两侧 $f'(x)$ 的符号变化确定极大值和极小值；闭区间上的最值需比较极值和端点值，取最大/最小者。
