**题目：**

已知 $\sin\alpha + \cos\alpha = \dfrac{\sqrt{2}}{2}$，则 $\sin 2\alpha =$ \_\_\_\_\_\_。

---

**解答：**

**第1步:** 对已知等式两边平方

$$(\sin\alpha + \cos\alpha)^2 = \left(\frac{\sqrt{2}}{2}\right)^2$$

展开左边：

$$\sin^2\alpha + 2\sin\alpha\cos\alpha + \cos^2\alpha = \frac{1}{2}$$

> 📌 运用知识点：trig-identity

**第2步:** 利用基本恒等式化简

因为 $\sin^2\alpha + \cos^2\alpha = 1$，代入得：

$$1 + 2\sin\alpha\cos\alpha = \frac{1}{2}$$

$$2\sin\alpha\cos\alpha = -\frac{1}{2}$$

> 📌 运用知识点：trig-identity

**第3步:** 利用二倍角公式

$$\sin 2\alpha = 2\sin\alpha\cos\alpha = -\frac{1}{2}$$

> 📌 运用知识点：trig-identity

**答案：** $\boxed{-\dfrac{1}{2}}$

**⚠️ 易错提醒：** 两边平方时右边容易算错：$\left(\dfrac{\sqrt{2}}{2}\right)^2 = \dfrac{2}{4} = \dfrac{1}{2}$，不是 $\dfrac{\sqrt{2}}{2}$ 或 $2$。另外 $\sin 2\alpha = 2\sin\alpha\cos\alpha$ 是二倍角公式的直接应用，不要与 $\sin^2\alpha$ 混淆。

**💡 解题思路总结：** 已知 $\sin\alpha \pm \cos\alpha$ 的值，求 $\sin 2\alpha$ 的标准方法：两边平方，利用 $\sin^2\alpha + \cos^2\alpha = 1$ 化简，再用二倍角公式得出结论。这是三角恒等变换中最常用的技巧之一。
