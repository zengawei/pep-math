**题目：**

设随机变量 $X \sim B\left(4, \dfrac{1}{3}\right)$，则下列结论正确的是

A. $P(X = 0) = \dfrac{8}{27}$

B. $E(X) = \dfrac{4}{3}$

C. $E(2X + 1) = \dfrac{11}{3}$

D. $D(X) = \dfrac{8}{9}$

---

**解答：**

**逐项分析：**

**选项 A：** 计算 $P(X = 0)$

$$P(X = 0) = \binom{4}{0} \left(\frac{1}{3}\right)^0 \left(\frac{2}{3}\right)^4 = 1 \times 1 \times \frac{16}{81} = \frac{16}{81}$$

而 $\dfrac{8}{27} = \dfrac{24}{81} \neq \dfrac{16}{81}$。❌ A 错误。

> 📌 运用知识点：binomial-distribution

**选项 B：** 计算 $E(X)$

$$E(X) = np = 4 \times \frac{1}{3} = \frac{4}{3}$$

✅ B 正确。

> 📌 运用知识点：discrete-random-variable

**选项 C：** 计算 $E(2X + 1)$

$$E(2X + 1) = 2E(X) + 1 = 2 \times \frac{4}{3} + 1 = \frac{8}{3} + 1 = \frac{11}{3}$$

✅ C 正确。

> 📌 运用知识点：discrete-random-variable

**选项 D：** 计算 $D(X)$

$$D(X) = np(1-p) = 4 \times \frac{1}{3} \times \frac{2}{3} = \frac{8}{9}$$

✅ D 正确。

> 📌 运用知识点：binomial-distribution

**答案：B、C、D**

**⚠️ 易错提醒：** 计算 $P(X = 0)$ 时容易将 $\left(\dfrac{2}{3}\right)^4$ 算错为 $\dfrac{8}{27}$（实际是 $\dfrac{16}{81}$）。二项分布的概率公式 $P(X=k) = \binom{n}{k}p^k(1-p)^{n-k}$ 中每一项都要仔细计算。

**💡 解题思路总结：** 二项分布 $X \sim B(n, p)$ 的核心公式：$E(X) = np$，$D(X) = np(1-p)$，$E(aX+b) = aE(X)+b$。概率计算需严格使用二项分布公式，注意组合数和幂次的计算。
