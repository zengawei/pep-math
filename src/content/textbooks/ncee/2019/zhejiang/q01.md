**题目：**

已知集合 $A = \{x \mid -1 < x < 3\}$，$B = \{x \mid 0 < x < 4\}$，则 $A \cap B =$

A. $\{x \mid -1 < x < 4\}$

B. $\{x \mid 0 < x < 3\}$

C. $\{x \mid -1 < x < 0\}$

D. $\{x \mid 3 < x < 4\}$

---

**解答：**

**第1步:** 在数轴上表示集合 $A$ 和 $B$

集合 $A = \{x \mid -1 < x < 3\}$ 表示数轴上 $-1$ 到 $3$ 之间的开区间。

集合 $B = \{x \mid 0 < x < 4\}$ 表示数轴上 $0$ 到 $4$ 之间的开区间。

> 📌 运用知识点：set-operations

**第2步:** 求交集 $A \cap B$

交集取两个集合的公共部分：

$$A \cap B = \{x \mid -1 < x < 3\} \cap \{x \mid 0 < x < 4\} = \{x \mid 0 < x < 3\}$$

即左端点取较大值 $\max(-1, 0) = 0$，右端点取较小值 $\min(3, 4) = 3$。

> 📌 运用知识点：set-operations

**答案：B**

**⚠️ 易错提醒：** 求交集时容易将端点取错，注意交集取"公共部分"——左端点取大、右端点取小。混淆交集与并集是常见错误。

**💡 解题思路总结：** 集合的交集运算，借助数轴直观表示各集合的范围，取重叠部分即可。对于区间型集合的交、并运算，数轴法是最直接有效的方法。
