**题目：** 已知函数 $f(x) = \sin 2x + \sqrt{3}\cos 2x$，则

A. $f(x)$ 的最小正周期为 $\pi$

B. $f(x)$ 的图像关于直线 $x = \dfrac{\pi}{6}$ 对称

C. $f(x)$ 的最大值为 $2$

D. $f(x)$ 在 $\left(0, \dfrac{\pi}{6}\right)$ 上单调递增

在每小题给出的选项中，有多项符合题目要求．全部选对的得5分，部分选对的得2分，有选错的得0分．

---

**解答：**

**第1步：** 化简函数
> 📌 运用知识点：辅助角公式

$$f(x) = \sin 2x + \sqrt{3}\cos 2x = 2\left(\frac{1}{2}\sin 2x + \frac{\sqrt{3}}{2}\cos 2x\right) = 2\sin\left(2x + \frac{\pi}{3}\right)$$

**第2步：** 逐项判断

**A：** $T = \dfrac{2\pi}{2} = \pi$。**A 正确。**

**B：** 对称轴处函数取最值，即 $\sin\left(2x + \dfrac{\pi}{3}\right) = \pm 1$。

当 $x = \dfrac{\pi}{6}$ 时，$2x + \dfrac{\pi}{3} = \dfrac{\pi}{3} + \dfrac{\pi}{3} = \dfrac{2\pi}{3}$。

$\sin\dfrac{2\pi}{3} = \dfrac{\sqrt{3}}{2} \neq \pm 1$，所以 $x = \dfrac{\pi}{6}$ 不是对称轴。**B 错误。**

**C：** $f(x)$ 的最大值为 $2 \times 1 = 2$。**C 正确。**

**D：** 当 $x \in \left(0, \dfrac{\pi}{6}\right)$ 时，$2x + \dfrac{\pi}{3} \in \left(\dfrac{\pi}{3}, \dfrac{2\pi}{3}\right)$。

在此区间内 $\sin$ 先增后减（在 $\dfrac{\pi}{2}$ 处取最大值），所以 $f(x)$ 不单调递增。**D 错误。**

**答案：AC**

**⚠️ 易错提醒：** 辅助角公式中系数的处理：$a\sin x + b\cos x = \sqrt{a^2+b^2}\sin(x+\varphi)$，其中 $\tan\varphi = \dfrac{b}{a}$。

**💡 解题思路总结：** 三角函数综合题先将函数化为 $A\sin(\omega x + \varphi)$ 的标准形式，再逐一分析周期、对称性、最值和单调性。
