**题目：** 已知向量 $\vec{a} = (2, 1)$，$\vec{b} = (1, -1)$，则 $|2\vec{a} - \vec{b}| = $ ______。

---

**解答：**

**第1步：** 计算 $2\vec{a} - \vec{b}$
> 📌 运用知识点：向量的坐标运算

$$2\vec{a} - \vec{b} = 2(2, 1) - (1, -1) = (4, 2) - (1, -1) = (3, 3)$$

**第2步：** 求模

$$|2\vec{a} - \vec{b}| = \sqrt{3^2 + 3^2} = \sqrt{9 + 9} = \sqrt{18} = 3\sqrt{2}$$

**答案：$3\sqrt{2}$**

**⚠️ 易错提醒：** 向量的数乘是对每个分量分别乘以该数，不要只乘一个分量。

**💡 解题思路总结：** 先进行向量的线性运算得到结果向量的坐标，再用模长公式 $|\vec{v}| = \sqrt{x^2 + y^2}$ 求模。
