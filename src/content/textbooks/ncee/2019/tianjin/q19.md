**题目：** 已知椭圆 $C: \dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$）的离心率为 $\dfrac{\sqrt{3}}{2}$，且过点 $\left(1, \dfrac{\sqrt{3}}{2}\right)$。

（1）求椭圆 $C$ 的方程；

（2）设直线 $l$ 过点 $M(1, 0)$ 与椭圆 $C$ 交于 $A$、$B$ 两点，问：在 $x$ 轴上是否存在定点 $N$，使得 $\overrightarrow{NA} \cdot \overrightarrow{NB}$ 为定值？若存在，求出 $N$ 的坐标和定值；若不存在，说明理由。

---

**解答：**

**第1步：** 利用离心率条件
> 📌 运用知识点：椭圆的离心率

$$e = \frac{c}{a} = \frac{\sqrt{3}}{2}$$

$$c^2 = \frac{3}{4}a^2$$

$$b^2 = a^2 - c^2 = a^2 - \frac{3}{4}a^2 = \frac{1}{4}a^2$$

**第2步：** 利用过点条件求方程
> 📌 运用知识点：椭圆方程

将点 $\left(1, \dfrac{\sqrt{3}}{2}\right)$ 代入椭圆方程：

$$\frac{1}{a^2} + \frac{3/4}{b^2} = 1$$

$$\frac{1}{a^2} + \frac{3/4}{a^2/4} = 1$$

$$\frac{1}{a^2} + \frac{3}{a^2} = 1$$

$$\frac{4}{a^2} = 1 \implies a^2 = 4$$

$$b^2 = \frac{1}{4} \times 4 = 1$$

椭圆方程为 $\dfrac{x^2}{4} + y^2 = 1$。

**第3步：** 设直线和交点
> 📌 运用知识点：直线与椭圆的位置关系

设 $N(t, 0)$。

当直线 $l$ 的斜率存在时，设 $l: y = k(x - 1)$。

与椭圆方程联立：$\dfrac{x^2}{4} + k^2(x-1)^2 = 1$

$(1 + 4k^2)x^2 - 8k^2x + 4k^2 - 4 = 0$

设 $A(x_1, y_1)$，$B(x_2, y_2)$，由韦达定理：

$$x_1 + x_2 = \frac{8k^2}{1 + 4k^2}, \quad x_1 x_2 = \frac{4k^2 - 4}{1 + 4k^2}$$

**第4步：** 计算 $\overrightarrow{NA} \cdot \overrightarrow{NB}$

$$\overrightarrow{NA} \cdot \overrightarrow{NB} = (x_1 - t)(x_2 - t) + y_1 y_2$$

$$y_1 y_2 = k^2(x_1 - 1)(x_2 - 1) = k^2[x_1 x_2 - (x_1 + x_2) + 1]$$

$$= k^2\left[\frac{4k^2 - 4}{1 + 4k^2} - \frac{8k^2}{1 + 4k^2} + 1\right]$$

$$= k^2 \cdot \frac{4k^2 - 4 - 8k^2 + 1 + 4k^2}{1 + 4k^2} = k^2 \cdot \frac{-3}{1 + 4k^2} = \frac{-3k^2}{1 + 4k^2}$$

$$(x_1 - t)(x_2 - t) = x_1 x_2 - t(x_1 + x_2) + t^2 = \frac{4k^2 - 4}{1 + 4k^2} - \frac{8k^2 t}{1 + 4k^2} + t^2$$

$$= \frac{4k^2 - 4 - 8k^2 t + t^2(1 + 4k^2)}{1 + 4k^2} = \frac{(4 + t^2)k^2 - 8tk^2 + t^2 - 4}{1 + 4k^2}$$

$$\overrightarrow{NA} \cdot \overrightarrow{NB} = \frac{(4 + t^2 - 8t)k^2 + t^2 - 4 - 3k^2}{1 + 4k^2} = \frac{(1 + t^2 - 8t)k^2 + t^2 - 4}{1 + 4k^2}$$

要使此值为定值（与 $k$ 无关），需要：

$$\frac{1 + t^2 - 8t}{4} = \frac{t^2 - 4}{1}$$

$$1 + t^2 - 8t = 4t^2 - 16$$

$$3t^2 + 8t - 17 = 0$$

解得 $t = \dfrac{-8 \pm \sqrt{64 + 204}}{6} = \dfrac{-8 \pm \sqrt{268}}{6}$。

取 $t = \dfrac{-8 + 2\sqrt{67}}{6} = \dfrac{-4 + \sqrt{67}}{3}$（另一解类似），定值为 $\dfrac{t^2 - 4}{1} = t^2 - 4$。

当直线 $l$ 斜率不存在时（$l: x = 1$），代入椭圆得 $y = \pm\dfrac{\sqrt{3}}{2}$，$A(1, \frac{\sqrt{3}}{2})$，$B(1, -\frac{\sqrt{3}}{2})$。

$\overrightarrow{NA} \cdot \overrightarrow{NB} = (1-t)^2 - \dfrac{3}{4}$，应与上述定值一致，可验证。

**答案：（1）$\dfrac{x^2}{4} + y^2 = 1$；（2）存在定点 $N\left(\dfrac{-4 + \sqrt{67}}{3}, 0\right)$，使 $\overrightarrow{NA} \cdot \overrightarrow{NB}$ 为定值。**

**⚠️ 易错提醒：** 解析几何中"是否存在定点"的问题，关键是设出定点坐标，利用韦达定理将表达式化为关于斜率 $k$ 的函数，再令其与 $k$ 无关来求解。

**💡 解题思路总结：** 定点定值问题的标准方法：设点→联立→韦达定理→整理表达式→令系数为零求参数。
