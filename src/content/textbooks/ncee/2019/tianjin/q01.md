**题目：** 设集合 $A = \{1, 2, 3, 4\}$，$B = \{2, 3, 4, 5\}$，则 $A \cap B =$

A. $\{2, 3\}$

B. $\{2, 3, 4\}$

C. $\{1, 2, 3, 4, 5\}$

D. $\{1, 5\}$

---

**解答：**

**第1步：** 求交集
> 📌 运用知识点：集合的交集运算

$A \cap B$ 是由既属于 $A$ 又属于 $B$ 的所有元素组成的集合。

$A = \{1, 2, 3, 4\}$，$B = \{2, 3, 4, 5\}$

公共元素为 $2, 3, 4$。

所以 $A \cap B = \{2, 3, 4\}$。

**答案：B**

**⚠️ 易错提醒：** 交集取公共元素，不要与并集混淆。并集 $A \cup B = \{1, 2, 3, 4, 5\}$ 是选项 C。

**💡 解题思路总结：** 交集运算就是找两个集合的公共元素，逐一检查即可。
