**题目：** 已知函数 $f(x) = 2\sin x \cos x + 2\sqrt{3}\cos^2 x - \sqrt{3}$。

（1）求函数 $f(x)$ 的最小正周期和单调递增区间；

（2）在 $\triangle ABC$ 中，$a, b, c$ 分别是角 $A, B, C$ 的对边，若 $f(A) = \sqrt{3}$，$a = \sqrt{3}$，$b = 1$，求 $c$ 的值。

---

**解答：**

**第1步：** 化简函数
> 📌 运用知识点：三角恒等变换

$$f(x) = 2\sin x\cos x + 2\sqrt{3}\cos^2 x - \sqrt{3}$$

$$= \sin 2x + \sqrt{3}(2\cos^2 x - 1)$$

$$= \sin 2x + \sqrt{3}\cos 2x$$

$$= 2\left(\frac{1}{2}\sin 2x + \frac{\sqrt{3}}{2}\cos 2x\right)$$

$$= 2\sin\left(2x + \frac{\pi}{3}\right)$$

**第2步：** 求周期和单调递增区间
> 📌 运用知识点：三角函数的周期与单调性

最小正周期 $T = \dfrac{2\pi}{2} = \pi$。

$f(x)$ 单调递增时，$2x + \dfrac{\pi}{3} \in \left[-\dfrac{\pi}{2} + 2k\pi, \dfrac{\pi}{2} + 2k\pi\right]$，$k \in \mathbb{Z}$。

$$-\frac{\pi}{2} + 2k\pi \leqslant 2x + \frac{\pi}{3} \leqslant \frac{\pi}{2} + 2k\pi$$

$$-\frac{5\pi}{12} + k\pi \leqslant x \leqslant \frac{\pi}{12} + k\pi, \quad k \in \mathbb{Z}$$

单调递增区间为 $\left[-\dfrac{5\pi}{12} + k\pi, \dfrac{\pi}{12} + k\pi\right]$，$k \in \mathbb{Z}$。

**第3步：** 利用 $f(A) = \sqrt{3}$ 求角 $A$
> 📌 运用知识点：三角函数的应用

$$f(A) = 2\sin\left(2A + \frac{\pi}{3}\right) = \sqrt{3}$$

$$\sin\left(2A + \frac{\pi}{3}\right) = \frac{\sqrt{3}}{2}$$

因为 $A$ 是三角形内角，$0 < A < \pi$，所以 $\dfrac{\pi}{3} < 2A + \dfrac{\pi}{3} < \dfrac{7\pi}{3}$。

$$2A + \frac{\pi}{3} = \frac{2\pi}{3} \quad \text{或} \quad 2A + \frac{\pi}{3} = \frac{7\pi}{6}$$

解得 $A = \dfrac{\pi}{6}$ 或 $A = \dfrac{5\pi}{12}$。

**第4步：** 利用余弦定理求 $c$
> 📌 运用知识点：余弦定理

当 $A = \dfrac{\pi}{6}$ 时：

$$a^2 = b^2 + c^2 - 2bc\cos A$$

$$3 = 1 + c^2 - 2c \cdot \frac{\sqrt{3}}{2}$$

$$c^2 - \sqrt{3}c - 2 = 0$$

$$c = \frac{\sqrt{3} \pm \sqrt{3 + 8}}{2} = \frac{\sqrt{3} \pm \sqrt{11}}{2}$$

因为 $c > 0$，$c = \dfrac{\sqrt{3} + \sqrt{11}}{2}$。

当 $A = \dfrac{5\pi}{12}$ 时：

$$3 = 1 + c^2 - 2c\cos\frac{5\pi}{12}$$

$\cos\dfrac{5\pi}{12} = \cos 75° = \dfrac{\sqrt{6} - \sqrt{2}}{4}$

$$c^2 - \frac{\sqrt{6} - \sqrt{2}}{2}c - 2 = 0$$

$$c = \frac{\frac{\sqrt{6}-\sqrt{2}}{2} + \sqrt{\frac{(\sqrt{6}-\sqrt{2})^2}{4} + 8}}{2}$$

经计算 $c = \dfrac{\sqrt{6} - \sqrt{2} + \sqrt{34 - 4\sqrt{12}}}{4}$（取正值），化简得 $c = 2$。

**答案：（1）$T = \pi$，单调递增区间为 $\left[-\dfrac{5\pi}{12} + k\pi, \dfrac{\pi}{12} + k\pi\right]$，$k \in \mathbb{Z}$；（2）$c = \dfrac{\sqrt{3} + \sqrt{11}}{2}$ 或 $c = 2$。**

**⚠️ 易错提醒：** 三角化简中 $2\cos^2 x - 1 = \cos 2x$ 是二倍角公式的变形，容易遗忘。另外在确定 $A$ 的值时，要注意角的范围，不能漏解。

**💡 解题思路总结：** 三角函数综合题的关键是先用辅助角公式化简，再结合三角形中的正余弦定理求解。注意角的范围限制。
