**题目：** $i$ 是虚数单位，复数 $\dfrac{2 + i}{1 - i} =$

A. $\dfrac{1}{2} + \dfrac{3}{2}i$

B. $\dfrac{3}{2} + \dfrac{1}{2}i$

C. $\dfrac{1}{2} - \dfrac{3}{2}i$

D. $\dfrac{3}{2} - \dfrac{1}{2}i$

---

**解答：**

**第1步：** 分子分母同乘共轭复数
> 📌 运用知识点：复数的除法运算

$$\frac{2 + i}{1 - i} = \frac{(2 + i)(1 + i)}{(1 - i)(1 + i)}$$

**第2步：** 展开计算

分子：$(2 + i)(1 + i) = 2 + 2i + i + i^2 = 2 + 3i - 1 = 1 + 3i$

分母：$(1 - i)(1 + i) = 1 - i^2 = 1 + 1 = 2$

**第3步：** 得出结果

$$\frac{1 + 3i}{2} = \frac{1}{2} + \frac{3}{2}i$$

**答案：A**

**⚠️ 易错提醒：** 复数除法的关键是分子分母同乘分母的共轭复数，注意 $i^2 = -1$。

**💡 解题思路总结：** 复数除法 $\dfrac{a+bi}{c+di}$ 的标准方法是分子分母同乘 $c-di$，化简为 $a'+b'i$ 的形式。
