**题目：** 某工厂生产的产品按质量分为一等品、二等品、三等品和次品四个等级。已知某批次产品中，一等品、二等品、三等品和次品的比例分别为 $0.6$、$0.25$、$0.1$、$0.05$。现从该批次产品中随机抽取 $3$ 件。

（1）求取出的 $3$ 件产品中恰有 $1$ 件一等品的概率；

（2）设取出的 $3$ 件产品中一等品的件数为 $X$，求 $X$ 的分布列和数学期望。

---

**解答：**

**第1步：** 明确模型
> 📌 运用知识点：二项分布

由于产品数量很大，可近似看作有放回抽样，每次抽到一等品的概率 $p = 0.6$。

$X$ 为 $3$ 次抽取中一等品的件数，$X \sim B(3, 0.6)$。

**第2步：** 求 $P(X = 1)$
> 📌 运用知识点：二项分布概率

$$P(X = 1) = C_3^1 \times 0.6^1 \times 0.4^2 = 3 \times 0.6 \times 0.16 = 0.288$$

**第3步：** 求分布列
> 📌 运用知识点：离散随机变量的分布列

$$P(X = 0) = C_3^0 \times 0.6^0 \times 0.4^3 = 0.064$$

$$P(X = 1) = 0.288$$

$$P(X = 2) = C_3^2 \times 0.6^2 \times 0.4^1 = 3 \times 0.36 \times 0.4 = 0.432$$

$$P(X = 3) = C_3^3 \times 0.6^3 \times 0.4^0 = 0.216$$

$X$ 的分布列为：

| $X$ | $0$ | $1$ | $2$ | $3$ |
|-----|-----|-----|-----|-----|
| $P$ | $0.064$ | $0.288$ | $0.432$ | $0.216$ |

**第4步：** 求数学期望
> 📌 运用知识点：数学期望

$$E(X) = np = 3 \times 0.6 = 1.8$$

验证：$E(X) = 0 \times 0.064 + 1 \times 0.288 + 2 \times 0.432 + 3 \times 0.216 = 0 + 0.288 + 0.864 + 0.648 = 1.8$ ✓

**答案：（1）$P(X=1) = 0.288$；（2）分布列见解答，$E(X) = 1.8$。**

**⚠️ 易错提醒：** 当总体数量很大时，不放回抽样可近似为有放回抽样（二项分布），这是概率题中常见的近似处理。

**💡 解题思路总结：** 识别二项分布模型后，直接用公式 $P(X=k) = C_n^k p^k(1-p)^{n-k}$ 计算各项概率，期望可直接用 $E(X) = np$。
