**题目：** 已知数列 $\{a_n\}$ 满足 $a_1 = 1$，$a_{n+1} = \dfrac{a_n}{1 + a_n}$。

（1）求 $\{a_n\}$ 的通项公式；

（2）设 $b_n = a_n \cdot a_{n+1}$，求 $\{b_n\}$ 的前 $n$ 项和 $T_n$；

（3）证明：$\displaystyle\sum_{k=1}^{n} a_k^2 < 2$。

---

**解答：**

**第1步：** 求通项公式
> 📌 运用知识点：递推数列

由 $a_{n+1} = \dfrac{a_n}{1 + a_n}$，两边取倒数：

$$\frac{1}{a_{n+1}} = \frac{1 + a_n}{a_n} = \frac{1}{a_n} + 1$$

设 $c_n = \dfrac{1}{a_n}$，则 $c_{n+1} = c_n + 1$，$c_1 = \dfrac{1}{a_1} = 1$。

$\{c_n\}$ 是首项为 $1$、公差为 $1$ 的等差数列，$c_n = n$。

$$\boxed{a_n = \frac{1}{n}}$$

**第2步：** 求 $T_n$
> 📌 运用知识点：裂项求和

$$b_n = a_n \cdot a_{n+1} = \frac{1}{n} \cdot \frac{1}{n+1} = \frac{1}{n(n+1)} = \frac{1}{n} - \frac{1}{n+1}$$

$$T_n = \left(1 - \frac{1}{2}\right) + \left(\frac{1}{2} - \frac{1}{3}\right) + \cdots + \left(\frac{1}{n} - \frac{1}{n+1}\right) = 1 - \frac{1}{n+1} = \frac{n}{n+1}$$

$$\boxed{T_n = \frac{n}{n+1}}$$

**第3步：** 证明 $\displaystyle\sum_{k=1}^{n} a_k^2 < 2$
> 📌 运用知识点：数列不等式证明

$$\sum_{k=1}^{n} a_k^2 = \sum_{k=1}^{n} \frac{1}{k^2}$$

当 $k \geqslant 2$ 时：$\dfrac{1}{k^2} < \dfrac{1}{k(k-1)} = \dfrac{1}{k-1} - \dfrac{1}{k}$

$$\sum_{k=1}^{n} \frac{1}{k^2} = 1 + \sum_{k=2}^{n} \frac{1}{k^2} < 1 + \sum_{k=2}^{n} \left(\frac{1}{k-1} - \frac{1}{k}\right) = 1 + 1 - \frac{1}{n} = 2 - \frac{1}{n} < 2$$

$$\boxed{\sum_{k=1}^{n} a_k^2 < 2}$$

**⚠️ 易错提醒：** 第（3）问中放缩的方向要注意：$\dfrac{1}{k^2} < \dfrac{1}{k(k-1)}$（$k \geqslant 2$），是"放大"而非"缩小"。第一项 $a_1^2 = 1$ 单独处理，不能放入裂项中。

**💡 解题思路总结：** 递推数列取倒数转化为等差数列是经典方法。证明数列求和不等式时，常用裂项放缩法：将 $\dfrac{1}{k^2}$ 放大为 $\dfrac{1}{k(k-1)}$ 后裂项求和。
