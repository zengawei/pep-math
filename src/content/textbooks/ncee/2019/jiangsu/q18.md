**题目：** 如图，在四棱锥 $P\text{-}ABCD$ 中，底面 $ABCD$ 是边长为 $2$ 的正方形，$PA \perp$ 底面 $ABCD$，$PA = 2$，$E$ 为 $PD$ 的中点。

（1）求证：$PB \parallel$ 平面 $ACE$；

（2）求直线 $CE$ 与平面 $PAD$ 所成角的正弦值。

---

**解答：**

**第1步：** 建立空间直角坐标系
> 📌 运用知识点：空间向量坐标

以 $A$ 为原点，$\overrightarrow{AB}$、$\overrightarrow{AD}$、$\overrightarrow{AP}$ 分别为 $x$、$y$、$z$ 轴正方向。

$A(0,0,0)$，$B(2,0,0)$，$C(2,2,0)$，$D(0,2,0)$，$P(0,0,2)$。

$E$ 为 $PD$ 中点：$E = (0, 1, 1)$。

**第2步：** 证明 $PB \parallel$ 平面 $ACE$
> 📌 运用知识点：空间向量证明平行

$\overrightarrow{PB} = (2, 0, -2)$

平面 $ACE$ 中：$\overrightarrow{AC} = (2, 2, 0)$，$\overrightarrow{AE} = (0, 1, 1)$

设平面 $ACE$ 的法向量 $\vec{n} = (x, y, z)$：

$$\begin{cases} \vec{n} \cdot \overrightarrow{AC} = 2x + 2y = 0 \\ \vec{n} \cdot \overrightarrow{AE} = y + z = 0 \end{cases}$$

取 $y = -1$，则 $x = 1$，$z = 1$，$\vec{n} = (1, -1, 1)$。

$\overrightarrow{PB} \cdot \vec{n} = 2 \times 1 + 0 \times (-1) + (-2) \times 1 = 0$

所以 $\overrightarrow{PB} \perp \vec{n}$。又 $P \notin$ 平面 $ACE$，故 $PB \parallel$ 平面 $ACE$。

$$\boxed{PB \parallel \text{平面 } ACE}$$

**第3步：** 求直线 $CE$ 与平面 $PAD$ 所成角
> 📌 运用知识点：空间向量求角

$\overrightarrow{CE} = (-2, -1, 1)$

平面 $PAD$ 由 $\overrightarrow{AD} = (0, 2, 0)$ 和 $\overrightarrow{AP} = (0, 0, 2)$ 张成，法向量 $\vec{m} = (1, 0, 0)$。

设直线 $CE$ 与平面 $PAD$ 所成角为 $\theta$：

$$\sin\theta = \frac{|\overrightarrow{CE} \cdot \vec{m}|}{|\overrightarrow{CE}| \cdot |\vec{m}|} = \frac{|-2|}{\sqrt{4+1+1} \times 1} = \frac{2}{\sqrt{6}} = \frac{\sqrt{6}}{3}$$

$$\boxed{\sin\theta = \frac{\sqrt{6}}{3}}$$

**⚠️ 易错提醒：** 证明线面平行需要两个条件：①方向向量与法向量垂直（点积为零）；②直线不在平面内。求线面角用 $\sin\theta = \dfrac{|\vec{v} \cdot \vec{n}|}{|\vec{v}||\vec{n}|}$，不是 $\cos$。

**💡 解题思路总结：** 建系后用法向量统一处理。线面平行转化为方向向量与法向量垂直；线面角转化为方向向量与法向量夹角的余角。
