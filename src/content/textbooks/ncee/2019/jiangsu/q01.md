**题目：** 已知集合 $A = \{x \mid x^2 - 3x + 2 \leqslant 0\}$，$B = \{x \mid 1 < x < 3\}$，则 $A \cap B =$

A. $\{x \mid 1 < x \leqslant 2\}$

B. $\{x \mid 1 \leqslant x < 3\}$

C. $\{x \mid 1 < x < 2\}$

D. $\{x \mid 1 \leqslant x \leqslant 2\}$

---

**解答：**

**第1步：** 求集合 $A$
> 📌 运用知识点：一元二次不等式的解法

$x^2 - 3x + 2 \leqslant 0$

$(x-1)(x-2) \leqslant 0$

解得 $1 \leqslant x \leqslant 2$，即 $A = [1, 2]$。

**第2步：** 求 $A \cap B$
> 📌 运用知识点：集合的交集运算

$A = [1, 2]$，$B = (1, 3)$

$A \cap B = (1, 2] = \{x \mid 1 < x \leqslant 2\}$

**答案：A**

**⚠️ 易错提醒：** 注意集合 $A$ 中 $x=1$ 和 $x=2$ 都能取到（含等号），而集合 $B$ 中 $x=1$ 取不到，交集后 $x=1$ 不能取到，$x=2$ 可以取到。

**💡 解题思路总结：** 先解一元二次不等式化简集合 $A$，再求交集。交集取公共部分，端点需逐一判断能否取到。
