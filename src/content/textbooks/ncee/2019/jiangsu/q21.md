**题目：** 已知函数 $f(x) = x \ln x - ax^2 + a$（$a \in \mathbb{R}$）。

（1）当 $a = 0$ 时，求 $f(x)$ 的极值；

（2）若对任意 $x \geqslant 1$，$f(x) \leqslant 0$ 恒成立，求 $a$ 的取值范围。

---

**解答：**

**第1步：** 当 $a = 0$ 时求极值
> 📌 运用知识点：导数与极值

$f(x) = x\ln x$，定义域 $x > 0$。

$f'(x) = \ln x + 1$

令 $f'(x) = 0$：$\ln x = -1 \implies x = \dfrac{1}{e}$

当 $0 < x < \dfrac{1}{e}$ 时 $f'(x) < 0$（递减），当 $x > \dfrac{1}{e}$ 时 $f'(x) > 0$（递增）。

所以 $f(x)$ 在 $x = \dfrac{1}{e}$ 处取极小值：

$$f\left(\frac{1}{e}\right) = \frac{1}{e} \ln \frac{1}{e} = \frac{1}{e} \times (-1) = -\frac{1}{e}$$

$$\boxed{f(x) \text{ 的极小值为 } -\dfrac{1}{e} \text{（无极大值）}}$$

**第2步：** 分析 $f(x) \leqslant 0$ 的条件
> 📌 运用知识点：导数与恒成立问题

$f(x) = x\ln x - ax^2 + a \leqslant 0$，即 $x\ln x \leqslant a(x^2 - 1)$。

当 $x = 1$ 时：$0 \leqslant 0$，恒成立。

当 $x > 1$ 时：$x^2 - 1 > 0$，需 $a \geqslant \dfrac{x\ln x}{x^2 - 1}$。

设 $g(x) = \dfrac{x\ln x}{x^2 - 1}$（$x > 1$），需 $a \geqslant g(x)_{\max}$。

**第3步：** 求 $g(x)$ 的最大值

$$g'(x) = \frac{(\ln x + 1)(x^2 - 1) - x\ln x \cdot 2x}{(x^2 - 1)^2} = \frac{(\ln x + 1)(x^2 - 1) - 2x^2 \ln x}{(x^2 - 1)^2}$$

分子 $= x^2 \ln x - \ln x + x^2 - 1 - 2x^2 \ln x = -x^2 \ln x - \ln x + x^2 - 1$

$= -(x^2 + 1)\ln x + (x^2 - 1)$

设 $h(x) = (x^2 - 1) - (x^2 + 1)\ln x$：

$h'(x) = 2x - 2x\ln x - (x^2+1) \cdot \dfrac{1}{x} = 2x - 2x\ln x - x - \dfrac{1}{x} = x - 2x\ln x - \dfrac{1}{x}$

当 $x \to 1^+$ 时：$h(1) = 0 - 0 = 0$，$h'(1) = 1 - 0 - 1 = 0$。

分析可知 $h(x) < 0$（$x > 1$），所以 $g'(x) < 0$，$g(x)$ 在 $(1, +\infty)$ 上单调递减。

$$\lim_{x \to 1^+} g(x) = \lim_{x \to 1^+} \frac{x\ln x}{x^2 - 1} = \lim_{x \to 1^+} \frac{\ln x + 1}{2x} = \frac{1}{2}$$

（用洛必达法则）

所以 $g(x) < \dfrac{1}{2}$（$x > 1$），$a \geqslant \dfrac{1}{2}$。

$$\boxed{a \geqslant \frac{1}{2}}$$

**⚠️ 易错提醒：** 分离参数后需要求 $g(x)$ 的上确界（极限值），而非最大值。$g(x)$ 在 $(1,+\infty)$ 上递减，上确界为 $x \to 1^+$ 时的极限 $\dfrac{1}{2}$。

**💡 解题思路总结：** 恒成立问题常用"分离参数法"，将问题转化为求函数最值（或上确界）。当 $g(x)$ 单调递减时，上确界在端点处取到（可能是极限值）。
