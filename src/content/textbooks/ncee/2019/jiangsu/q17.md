**题目：** 已知函数 $f(x) = 2\sin(\omega x + \varphi)$（$\omega > 0$，$|\varphi| < \dfrac{\pi}{2}$），其图象相邻两条对称轴之间的距离为 $\pi$，且图象过点 $\left(\dfrac{\pi}{6}, 2\right)$。

（1）求 $f(x)$ 的解析式；

（2）求 $f(x)$ 在 $\left[0, \dfrac{\pi}{2}\right]$ 上的值域。

---

**解答：**

**第1步：** 求 $\omega$
> 📌 运用知识点：三角函数的图象与周期

相邻两条对称轴之间的距离等于半个周期，即 $\dfrac{T}{2} = \pi$，所以 $T = 2\pi$。

$$T = \frac{2\pi}{\omega} = 2\pi \implies \omega = 1$$

**第2步：** 求 $\varphi$
> 📌 运用知识点：三角函数的图象

$f(x) = 2\sin(x + \varphi)$，图象过点 $\left(\dfrac{\pi}{6}, 2\right)$：

$$2\sin\left(\frac{\pi}{6} + \varphi\right) = 2 \implies \sin\left(\frac{\pi}{6} + \varphi\right) = 1$$

$$\frac{\pi}{6} + \varphi = \frac{\pi}{2} + 2k\pi \implies \varphi = \frac{\pi}{3} + 2k\pi$$

因为 $|\varphi| < \dfrac{\pi}{2}$，所以 $\varphi = \dfrac{\pi}{3}$。

$$\boxed{f(x) = 2\sin\left(x + \frac{\pi}{3}\right)}$$

**第3步：** 求值域
> 📌 运用知识点：三角函数的值域

当 $x \in \left[0, \dfrac{\pi}{2}\right]$ 时：

$$x + \frac{\pi}{3} \in \left[\frac{\pi}{3}, \frac{5\pi}{6}\right]$$

在 $\left[\dfrac{\pi}{3}, \dfrac{5\pi}{6}\right]$ 上，$\sin$ 的值：
- 当 $x + \dfrac{\pi}{3} = \dfrac{\pi}{2}$ 时取最大值 $1$
- 当 $x + \dfrac{\pi}{3} = \dfrac{5\pi}{6}$ 时取最小值 $\sin\dfrac{5\pi}{6} = \dfrac{1}{2}$

所以 $f(x) \in [2 \times \dfrac{1}{2}, 2 \times 1] = [1, 2]$。

$$\boxed{f(x) \text{ 在 } \left[0, \frac{\pi}{2}\right] \text{ 上的值域为 } [1, 2]}$$

**⚠️ 易错提醒：** 相邻对称轴间距是半周期（不是全周期）。求值域时要先确定整体角 $x + \dfrac{\pi}{3}$ 的范围，再在该范围内找 $\sin$ 的最值。

**💡 解题思路总结：** 由周期条件求 $\omega$，由特殊点求 $\varphi$，求值域时先确定复合角的范围，再结合正弦函数图象确定最值。
