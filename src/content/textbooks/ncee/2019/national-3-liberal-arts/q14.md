**题目：**

若 $x > 0$，$y > 0$，且 $x + y = 4$，则 $\dfrac{1}{x} + \dfrac{1}{y}$ 的最小值为 ______。

---

**解答：**

**第1步：** 利用"乘 $1$ 法"。
> 📌 运用知识点：基本不等式

$$\frac{1}{x} + \frac{1}{y} = \frac{x + y}{4}\left(\frac{1}{x} + \frac{1}{y}\right) = \frac{1}{4}\left(1 + \frac{y}{x} + \frac{x}{y} + 1\right) = \frac{1}{4}\left(2 + \frac{y}{x} + \frac{x}{y}\right)$$

**第2步：** 利用基本不等式。

$$\frac{y}{x} + \frac{x}{y} \geqslant 2\sqrt{\frac{y}{x} \cdot \frac{x}{y}} = 2$$

$$\frac{1}{x} + \frac{1}{y} \geqslant \frac{1}{4}(2 + 2) = 1$$

等号成立条件：$\dfrac{y}{x} = \dfrac{x}{y}$，即 $x = y = 2$。

**正确答案：** $1$

**⚠️ 易错提醒：** "乘 $1$ 法"是利用 $x + y = 4$ 这一条件，将 $\dfrac{1}{x} + \dfrac{1}{y}$ 乘以 $\dfrac{x+y}{4} = 1$，展开后用基本不等式。

**💡 解题思路总结：** 已知 $x + y$ 为常数求 $\dfrac{1}{x} + \dfrac{1}{y}$ 的最小值，核心技巧是"乘 $1$ 法"——将常数条件与目标式相乘后展开，利用基本不等式求最值。
