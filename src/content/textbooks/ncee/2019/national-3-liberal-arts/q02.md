**题目：**

复数 $z = \dfrac{1 + \mathrm{i}}{1 - \mathrm{i}}$ 的模 $|z| = $（）

(A) $\dfrac{1}{2}$  (B) $1$  (C) $\sqrt{2}$  (D) $2$

---

**解答：**

**第1步：** 化简复数 $z$。
> 📌 运用知识点：复数的除法运算

分子分母同乘分母的共轭复数 $1 + \mathrm{i}$：

$$z = \frac{(1 + \mathrm{i})(1 + \mathrm{i})}{(1 - \mathrm{i})(1 + \mathrm{i})} = \frac{1 + 2\mathrm{i} + \mathrm{i}^2}{1 - \mathrm{i}^2} = \frac{1 + 2\mathrm{i} - 1}{1 + 1} = \frac{2\mathrm{i}}{2} = \mathrm{i}$$

**第2步：** 求模。

$$|z| = |\mathrm{i}| = 1$$

**正确答案：** (B)

**⚠️ 易错提醒：** 也可以直接利用模的性质 $|z| = \dfrac{|1+\mathrm{i}|}{|1-\mathrm{i}|} = \dfrac{\sqrt{2}}{\sqrt{2}} = 1$，更快捷。

**💡 解题思路总结：** 复数除法化简的核心是分母实数化；求模时也可以利用 $|z_1/z_2| = |z_1|/|z_2|$ 的性质直接计算。
