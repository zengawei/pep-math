**题目：**

函数 $y = 2\sin\left(2x + \dfrac{\pi}{3}\right)$ 的图象的一条对称轴方程为（）

(A) $x = \dfrac{\pi}{6}$  (B) $x = \dfrac{\pi}{12}$  (C) $x = \dfrac{\pi}{3}$  (D) $x = -\dfrac{\pi}{6}$

---

**解答：**

**第1步：** 确定对称轴条件。
> 📌 运用知识点：三角函数图象的对称性

$y = 2\sin\left(2x + \dfrac{\pi}{3}\right)$ 的对称轴满足：

$$2x + \frac{\pi}{3} = \frac{\pi}{2} + k\pi \quad (k \in \mathbb{Z})$$

**第2步：** 求解 $x$。

$$2x = \frac{\pi}{2} - \frac{\pi}{3} + k\pi = \frac{\pi}{6} + k\pi$$

$$x = \frac{\pi}{12} + \frac{k\pi}{2}$$

取 $k = 0$：$x = \dfrac{\pi}{12}$。

**正确答案：** (B)

**⚠️ 易错提醒：** 正弦函数的对称轴在波峰和波谷处，即相位角为 $\dfrac{\pi}{2} + k\pi$，不是 $k\pi$。

**💡 解题思路总结：** $y = A\sin(\omega x + \varphi)$ 的对称轴由 $\omega x + \varphi = \dfrac{\pi}{2} + k\pi$ 确定。
