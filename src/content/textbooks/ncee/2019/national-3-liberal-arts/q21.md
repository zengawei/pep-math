**题目：**

已知函数 $f(x) = x^3 - 3x + 1$。

（1）求 $f(x)$ 的单调区间；

（2）求 $f(x)$ 在区间 $[-2, 3]$ 上的最大值和最小值。

---

**解答：**

**第1步：** 求导数。
> 📌 运用知识点：导数的运算

$$f'(x) = 3x^2 - 3 = 3(x^2 - 1) = 3(x + 1)(x - 1)$$

**第2步：** 确定单调区间。
> 📌 运用知识点：导数与单调性

$f'(x) > 0$：$x < -1$ 或 $x > 1$，$f(x)$ 单调递增。

$f'(x) < 0$：$-1 < x < 1$，$f(x)$ 单调递减。

单调递增区间：$(-\infty, -1)$ 和 $(1, +\infty)$。

单调递减区间：$(-1, 1)$。

**第3步：** 第（2）问，比较临界点和端点的函数值。
> 📌 运用知识点：函数的最大值与最小值

$$f(-2) = -8 + 6 + 1 = -1$$
$$f(-1) = -1 + 3 + 1 = 3 \quad \text{（极大值）}$$
$$f(1) = 1 - 3 + 1 = -1 \quad \text{（极小值）}$$
$$f(3) = 27 - 9 + 1 = 19$$

**第4步：** 确定最值。

最大值为 $f(3) = 19$，最小值为 $f(-2) = f(1) = -1$。

**正确答案：** （1）递增区间 $(-\infty, -1)$ 和 $(1, +\infty)$，递减区间 $(-1, 1)$；（2）最大值 $19$，最小值 $-1$。

**⚠️ 易错提醒：**
1. 闭区间上的最值需要比较所有临界点和端点的函数值。
2. $f(-2) = f(1) = -1$，最小值在两个点同时取得。

**💡 解题思路总结：** 利用导数求闭区间上函数最值的标准步骤：①求导找临界点；②计算临界点和端点的函数值；③比较得出最大值和最小值。
