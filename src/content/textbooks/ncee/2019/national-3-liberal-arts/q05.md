**题目：**

已知等差数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n$，且 $a_3 + a_7 = 10$，则 $S_9 = $（）

(A) $40$  (B) $45$  (C) $50$  (D) $55$

---

**解答：**

**第1步：** 利用等差数列性质化简。
> 📌 运用知识点：等差数列的性质

$a_3 + a_7 = a_1 + 2d + a_1 + 6d = 2a_1 + 8d = 2(a_1 + 4d) = 2a_5 = 10$

所以 $a_5 = 5$。

**第2步：** 求 $S_9$。
> 📌 运用知识点：等差数列的前 $n$ 项和

$$S_9 = \frac{9(a_1 + a_9)}{2} = \frac{9 \times 2a_5}{2} = 9a_5 = 9 \times 5 = 45$$

**正确答案：** (B)

**⚠️ 易错提醒：** 等差数列中 $a_3 + a_7 = 2a_5$（下标之和相等的两项之和等于中间项的两倍），不要逐项展开。

**💡 解题思路总结：** 等差数列中利用"下标对称性"：$a_m + a_n = 2a_{\frac{m+n}{2}}$，$S_n = \dfrac{n(a_1 + a_n)}{2} = na_{\frac{n+1}{2}}$（$n$ 为奇数时）。
