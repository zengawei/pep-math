**题目：** 若 $x, y$ 满足 $\begin{cases} x + y \leqslant 3 \\ x - y \geqslant -1 \\ y \geqslant 0 \end{cases}$，则 $z = 2x + y$ 的最大值为

A. $3$

B. $5$

C. $6$

D. $8$

---

**解答：**

**第1步：** 确定可行域的顶点
> 📌 运用知识点：线性规划

三条边界线：$x + y = 3$，$x - y = -1$，$y = 0$。

求交点：
- $x + y = 3$ 与 $y = 0$：$x = 3$，交点 $(3, 0)$
- $x - y = -1$ 与 $y = 0$：$x = -1$，交点 $(-1, 0)$
- $x + y = 3$ 与 $x - y = -1$：相加得 $2x = 2$，$x = 1$，$y = 2$，交点 $(1, 2)$

**第2步：** 在各顶点处计算目标函数

- $z(3, 0) = 2 \times 3 + 0 = 6$
- $z(-1, 0) = 2 \times (-1) + 0 = -2$
- $z(1, 2) = 2 \times 1 + 2 = 4$

**第3步：** 确定最大值

$z_{\max} = 6$，在点 $(3, 0)$ 处取得。

**答案：C**

**⚠️ 易错提醒：** 线性规划问题中，最优值一定在可行域的顶点处取得，需要验证每个顶点。注意不等号方向决定可行域的位置。

**💡 解题思路总结：** 线性规划的解题步骤：画可行域 → 求顶点 → 代入目标函数比较。
