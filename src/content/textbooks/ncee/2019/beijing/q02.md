**题目：** 若复数 $z = (1 + \text{i})(2 - \text{i})$（其中 $\text{i}$ 为虚数单位），则 $|z| =$

A. $\sqrt{5}$

B. $\sqrt{10}$

C. $5$

D. $10$

---

**解答：**

**第1步：** 展开复数乘法
> 📌 运用知识点：复数的运算

$z = (1 + \text{i})(2 - \text{i}) = 2 - \text{i} + 2\text{i} - \text{i}^2 = 2 + \text{i} + 1 = 3 + \text{i}$

**第2步：** 求模
> 📌 运用知识点：复数的模

$|z| = \sqrt{3^2 + 1^2} = \sqrt{9 + 1} = \sqrt{10}$

**答案：B**

**⚠️ 易错提醒：** 注意 $\text{i}^2 = -1$，展开时不要漏掉负号。

**💡 解题思路总结：** 复数乘法按多项式展开，注意 $\text{i}^2 = -1$。模的公式为 $|a + b\text{i}| = \sqrt{a^2 + b^2}$。
