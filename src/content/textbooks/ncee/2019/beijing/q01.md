**题目：** 已知集合 $A = \{x \mid -1 < x < 2\}$，$B = \{x \mid x^2 \leqslant 1\}$，则 $A \cup B =$

A. $\{x \mid -1 \leqslant x < 2\}$

B. $\{x \mid -1 \leqslant x \leqslant 2\}$

C. $\{x \mid -1 < x \leqslant 1\}$

D. $\{x \mid -1 \leqslant x < 2\}$

---

**解答：**

**第1步：** 求集合 $B$
> 📌 运用知识点：一元二次不等式的解法

$x^2 \leqslant 1 \implies -1 \leqslant x \leqslant 1$

所以 $B = \{x \mid -1 \leqslant x \leqslant 1\} = [-1, 1]$。

**第2步：** 求 $A \cup B$
> 📌 运用知识点：集合的并集运算

$A = (-1, 2)$，$B = [-1, 1]$

$A \cup B = [-1, 2) = \{x \mid -1 \leqslant x < 2\}$

**答案：A**

**⚠️ 易错提醒：** 注意集合 $A$ 中 $-1$ 取不到（开区间），而集合 $B$ 中 $-1$ 可以取到（闭区间），并集后 $-1$ 可以取到。

**💡 解题思路总结：** 先化简各集合，再求并集。求并集时取各集合范围的"最大覆盖"，注意端点的开闭。
