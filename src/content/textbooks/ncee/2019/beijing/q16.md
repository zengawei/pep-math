**题目：** 如图，在四棱锥 $P\text{-}ABCD$ 中，底面 $ABCD$ 为正方形，$PA \perp$ 底面 $ABCD$，$PA = AB = 2$。

（1）求证：$BD \perp PC$；

（2）求二面角 $P\text{-}BD\text{-}A$ 的大小。

---

**解答：**

**第1步：** 建立空间直角坐标系
> 📌 运用知识点：空间向量坐标

以 $A$ 为原点，$\overrightarrow{AB}$、$\overrightarrow{AD}$、$\overrightarrow{AP}$ 分别为 $x$、$y$、$z$ 轴正方向。

$A(0,0,0)$，$B(2,0,0)$，$C(2,2,0)$，$D(0,2,0)$，$P(0,0,2)$。

**第2步：** 证明 $BD \perp PC$
> 📌 运用知识点：向量证明垂直

$\overrightarrow{BD} = D - B = (-2, 2, 0)$

$\overrightarrow{PC} = C - P = (2, 2, -2)$

$\overrightarrow{BD} \cdot \overrightarrow{PC} = (-2)(2) + (2)(2) + (0)(-2) = -4 + 4 + 0 = 0$

所以 $\overrightarrow{BD} \perp \overrightarrow{PC}$，即 $BD \perp PC$。$\blacksquare$

**第3步：** 求二面角 $P\text{-}BD\text{-}A$
> 📌 运用知识点：空间向量求二面角

需要求平面 $PBD$ 和平面 $ABD$ 的法向量。

$\overrightarrow{BD} = (-2, 2, 0)$，$\overrightarrow{BP} = (-2, 0, 2)$

设平面 $PBD$ 的法向量 $\vec{n_1} = (x, y, z)$：

$\vec{n_1} \cdot \overrightarrow{BD} = -2x + 2y = 0 \implies x = y$

$\vec{n_1} \cdot \overrightarrow{BP} = -2x + 2z = 0 \implies x = z$

取 $\vec{n_1} = (1, 1, 1)$。

平面 $ABD$ 即底面 $xOy$，法向量 $\vec{n_2} = (0, 0, 1)$。

**第4步：** 计算二面角

$$\cos\theta = \frac{|\vec{n_1} \cdot \vec{n_2}|}{|\vec{n_1}||\vec{n_2}|} = \frac{|1|}{\sqrt{3} \times 1} = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}$$

$$\boxed{\theta = \arccos\frac{\sqrt{3}}{3}}$$

**⚠️ 易错提醒：** 建系时注意三条互相垂直的棱的方向。求法向量时方程组要有两个独立方程，取特解即可。

**💡 解题思路总结：** 空间向量法证明垂直只需证点积为 $0$；求二面角先求两个面的法向量，再用夹角公式。
