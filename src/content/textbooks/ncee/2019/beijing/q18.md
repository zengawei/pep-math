**题目：** 已知椭圆 $C: \dfrac{x^2}{4} + y^2 = 1$，过点 $M(1, 0)$ 的直线 $l$ 与椭圆 $C$ 交于 $A$、$B$ 两点。

（1）若直线 $l$ 的斜率为 $1$，求 $|AB|$ 的值；

（2）设 $O$ 为原点，求 $\triangle OAB$ 面积的最大值。

---

**解答：**

**第1步：** 写出直线方程
> 📌 运用知识点：直线方程

直线 $l$ 过 $M(1, 0)$，斜率为 $1$：$y = x - 1$。

**第2步：** 联立直线与椭圆
> 📌 运用知识点：直线与椭圆的位置关系

将 $y = x - 1$ 代入 $\dfrac{x^2}{4} + y^2 = 1$：

$$\frac{x^2}{4} + (x-1)^2 = 1$$

$$\frac{x^2}{4} + x^2 - 2x + 1 = 1$$

$$\frac{5x^2}{4} - 2x = 0$$

$$x\left(\frac{5x}{4} - 2\right) = 0$$

$x_1 = 0$，$x_2 = \dfrac{8}{5}$。

**第3步：** 求 $|AB|$

$A(0, -1)$，$B\left(\dfrac{8}{5}, \dfrac{3}{5}\right)$

$$|AB| = \sqrt{\left(\frac{8}{5}\right)^2 + \left(\frac{3}{5} + 1\right)^2} = \sqrt{\frac{64}{25} + \frac{64}{25}} = \sqrt{\frac{128}{25}} = \frac{8\sqrt{2}}{5}$$

$$\boxed{|AB| = \frac{8\sqrt{2}}{5}}$$

**第4步：** 求面积最大值
> 📌 运用知识点：圆锥曲线的最值问题

设直线 $l: x = my + 1$（包含斜率不存在的情况）。

代入椭圆方程：$\dfrac{(my+1)^2}{4} + y^2 = 1$

$(m^2 + 4)y^2 + 2my - 3 = 0$

$y_1 + y_2 = \dfrac{-2m}{m^2 + 4}$，$y_1 y_2 = \dfrac{-3}{m^2 + 4}$

**第5步：** 计算面积

$O$ 到直线 $x - my - 1 = 0$ 的距离 $d = \dfrac{1}{\sqrt{1 + m^2}}$

$|AB| = \sqrt{1 + m^2} \cdot |y_1 - y_2|$

$|y_1 - y_2|^2 = (y_1 + y_2)^2 - 4y_1 y_2 = \dfrac{4m^2}{(m^2+4)^2} + \dfrac{12}{m^2+4} = \dfrac{4m^2 + 12(m^2+4)}{(m^2+4)^2} = \dfrac{16m^2 + 48}{(m^2+4)^2}$

$$S = \frac{1}{2} |AB| \cdot d = \frac{1}{2} \sqrt{1+m^2} \cdot \frac{4\sqrt{m^2+3}}{m^2+4} \cdot \frac{1}{\sqrt{1+m^2}} = \frac{2\sqrt{m^2+3}}{m^2+4}$$

**第6步：** 求最大值

令 $t = m^2 + 3 \geqslant 3$，则 $S = \dfrac{2\sqrt{t}}{t + 1}$。

$S^2 = \dfrac{4t}{(t+1)^2}$

令 $f(t) = \dfrac{t}{(t+1)^2}$，$f'(t) = \dfrac{(t+1)^2 - 2t(t+1)}{(t+1)^4} = \dfrac{1-t}{(t+1)^3}$

当 $t \geqslant 3$ 时 $f'(t) < 0$，$f(t)$ 递减。

$f(t)$ 在 $t = 3$ 时取最大值：$f(3) = \dfrac{3}{16}$

$S_{\max}^2 = 4 \times \dfrac{3}{16} = \dfrac{3}{4}$，$S_{\max} = \dfrac{\sqrt{3}}{2}$

$$\boxed{S_{\max} = \frac{\sqrt{3}}{2}}$$

**⚠️ 易错提醒：** 设直线时注意讨论斜率是否存在。面积表达式化简时要仔细，求最值时注意换元的范围。

**💡 解题思路总结：** 直线与椭圆联立是解析几何的核心方法。面积最值问题通常转化为关于斜率参数的函数最值，利用导数或均值不等式求解。
