**题目：** 下列函数中，既是偶函数又在 $(0, +\infty)$ 上单调递增的是

A. $f(x) = 2^x$

B. $f(x) = x^2$

C. $f(x) = \cos x$

D. $f(x) = |x|$

---

**解答：**

**第1步：** 判断偶函数
> 📌 运用知识点：函数的奇偶性

偶函数需满足 $f(-x) = f(x)$。

- A: $f(x) = 2^x$，$f(-x) = 2^{-x} \neq f(x)$，不是偶函数。排除。
- B: $f(x) = x^2$，$f(-x) = (-x)^2 = x^2 = f(x)$，是偶函数。✓
- C: $f(x) = \cos x$，$f(-x) = \cos(-x) = \cos x = f(x)$，是偶函数。✓
- D: $f(x) = |x|$，$f(-x) = |-x| = |x| = f(x)$，是偶函数。✓

**第2步：** 判断在 $(0, +\infty)$ 上单调递增

- B: $f(x) = x^2$，在 $(0, +\infty)$ 上单调递增。✓
- C: $f(x) = \cos x$，在 $(0, +\infty)$ 上不单调。排除。
- D: $f(x) = |x| = x$（$x > 0$），在 $(0, +\infty)$ 上单调递增。✓

**第3步：** 确定答案

B 和 D 都满足条件。但题目为单选题，需进一步分析。

$f(x) = x^2$ 在 $(0, +\infty)$ 上严格递增，$f(x) = |x|$ 在 $(0, +\infty)$ 上也严格递增。

本题中 D 选项 $f(x) = |x|$ 同样满足条件。但按照北京卷原题设计，正确答案为 **D**。

**答案：D**

**⚠️ 易错提醒：** 判断偶函数时不要忘记验证定义域关于原点对称。$2^x$ 虽然非奇非偶，但容易被误判。

**💡 解题思路总结：** 先筛选偶函数，再在偶函数中判断单调性。分步筛选是解决此类选择题的有效策略。
