**题目：** 已知数列 $\{a_n\}$ 满足 $a_1 = 1$，$a_{n+1} = 2a_n + 1$（$n \geqslant 1$）。

（1）求 $\{a_n\}$ 的通项公式；

（2）设 $b_n = \dfrac{a_n}{2^n}$，求数列 $\{b_n\}$ 的前 $n$ 项和 $T_n$。

---

**解答：**

**第1步：** 构造等比数列
> 📌 运用知识点：递推数列

$a_{n+1} = 2a_n + 1$

设 $a_{n+1} + c = 2(a_n + c)$，则 $a_{n+1} = 2a_n + c$，比较得 $c = 1$。

所以 $a_{n+1} + 1 = 2(a_n + 1)$。

**第2步：** 求通项

令 $c_n = a_n + 1$，则 $c_{n+1} = 2c_n$，$\{c_n\}$ 是公比为 $2$ 的等比数列。

$c_1 = a_1 + 1 = 2$

$c_n = 2 \cdot 2^{n-1} = 2^n$

$$\boxed{a_n = 2^n - 1}$$

**第3步：** 求 $b_n$
> 📌 运用知识点：数列求和

$$b_n = \frac{a_n}{2^n} = \frac{2^n - 1}{2^n} = 1 - \frac{1}{2^n}$$

**第4步：** 求 $T_n$

$$T_n = \sum_{k=1}^n b_k = \sum_{k=1}^n \left(1 - \frac{1}{2^k}\right) = n - \sum_{k=1}^n \frac{1}{2^k}$$

$$\sum_{k=1}^n \frac{1}{2^k} = \frac{\frac{1}{2}(1 - \frac{1}{2^n})}{1 - \frac{1}{2}} = 1 - \frac{1}{2^n}$$

$$\boxed{T_n = n - 1 + \frac{1}{2^n}}$$

**⚠️ 易错提醒：** 递推关系 $a_{n+1} = pa_n + q$ 型的处理方法是构造等比数列，注意常数 $c$ 的求法。求和时不要漏掉各项。

**💡 解题思路总结：** 线性递推数列通过"加常数"构造等比数列是经典方法。求和时将 $b_n$ 拆分，分别求和。
