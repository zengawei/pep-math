**题目：**

设等比数列 $\{a_n\}$ 的首项 $a_1 = 1$，前 $n$ 项和为 $S_n$，且 $S_3 = a_2 + a_3 + a_1$。若 $a_4 + a_5 + a_6 = 8(a_1 + a_2 + a_3)$，则公比 $q = $ ______。

---

**解答：**

**第1步：** 利用等比数列的性质化简条件。
> 📌 运用知识点：等比数列的性质

$a_4 + a_5 + a_6 = a_1 q^3 + a_2 q^3 + a_3 q^3 = q^3(a_1 + a_2 + a_3)$

**第2步：** 代入已知条件求 $q$。

$$q^3(a_1 + a_2 + a_3) = 8(a_1 + a_2 + a_3)$$

因为 $a_1 = 1 \neq 0$，所以 $a_1 + a_2 + a_3 \neq 0$（可验证），两边约去：

$$q^3 = 8 \implies q = 2$$

**正确答案：** $2$

**⚠️ 易错提醒：** 注意 $a_4 + a_5 + a_6 = q^3(a_1 + a_2 + a_3)$ 这个等比数列的重要性质，不要逐项展开计算。

**💡 解题思路总结：** 等比数列中，连续等长的段之间成等比关系：$a_4 + a_5 + a_6 = q^3(a_1 + a_2 + a_3)$，利用这一性质可以直接求出公比。
