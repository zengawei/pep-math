**题目：**

已知函数 $f(x) = x^3 - ax^2 + ax$（$a \in \mathbb{R}$）。

（1）讨论 $f(x)$ 的单调性；

（2）若 $f(x)$ 存在极大值 $f(x_1)$ 和极小值 $f(x_2)$，且 $f(x_1) + f(x_2) = 0$，求 $a$ 的值。

---

**解答：**

**第1步：** 求导数。
> 📌 运用知识点：导数的运算

$$f'(x) = 3x^2 - 2ax + a$$

**第2步：** 讨论 $\Delta$。
> 📌 运用知识点：导数与单调性

$\Delta = 4a^2 - 12a = 4a(a - 3)$。

- 当 $\Delta \leqslant 0$，即 $0 \leqslant a \leqslant 3$ 时，$f'(x) \geqslant 0$ 恒成立，$f(x)$ 在 $\mathbb{R}$ 上单调递增。

- 当 $\Delta > 0$，即 $a < 0$ 或 $a > 3$ 时，$f'(x) = 0$ 有两个不等实根 $x_1 < x_2$：

$$x_1 = \frac{a - \sqrt{a^2 - 3a}}{3}, \quad x_2 = \frac{a + \sqrt{a^2 - 3a}}{3}$$

$f(x)$ 在 $(-\infty, x_1)$ 上单调递增，在 $(x_1, x_2)$ 上单调递减，在 $(x_2, +\infty)$ 上单调递增。

**第3步：** 第（2）问，利用韦达定理。
> 📌 运用知识点：韦达定理

$f(x)$ 存在极值，则 $a < 0$ 或 $a > 3$。

$x_1 + x_2 = \dfrac{2a}{3}$，$x_1 x_2 = \dfrac{a}{3}$。

**第4步：** 计算 $f(x_1) + f(x_2)$。

$$f(x_1) + f(x_2) = (x_1^3 + x_2^3) - a(x_1^2 + x_2^2) + a(x_1 + x_2)$$

其中：

$$x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1 x_2 = \frac{4a^2}{9} - \frac{2a}{3}$$

$$x_1^3 + x_2^3 = (x_1 + x_2)[(x_1 + x_2)^2 - 3x_1 x_2] = \frac{2a}{3}\left(\frac{4a^2}{9} - a\right) = \frac{8a^3 - 18a^2}{27}$$

代入：

$$f(x_1) + f(x_2) = \frac{8a^3 - 18a^2}{27} - a\left(\frac{4a^2}{9} - \frac{2a}{3}\right) + a \cdot \frac{2a}{3}$$

$$= \frac{8a^3 - 18a^2}{27} - \frac{4a^3}{9} + \frac{2a^2}{3} + \frac{2a^2}{3}$$

$$= \frac{8a^3 - 18a^2 - 12a^3}{27} + \frac{4a^2}{3}$$

$$= \frac{-4a^3 - 18a^2 + 36a^2}{27} = \frac{-4a^3 + 18a^2}{27} = \frac{2a^2(9 - 2a)}{27}$$

**第5步：** 令 $f(x_1) + f(x_2) = 0$ 求 $a$。

$$\frac{2a^2(9 - 2a)}{27} = 0$$

$a = 0$ 或 $a = \dfrac{9}{2}$。

$a = 0$ 不满足 $a < 0$ 或 $a > 3$（此时 $\Delta = 0$，无极值），舍去。

$a = \dfrac{9}{2} > 3$，满足存在极值的条件。

**正确答案：** （1）当 $0 \leqslant a \leqslant 3$ 时 $f(x)$ 在 $\mathbb{R}$ 上单调递增；当 $a < 0$ 或 $a > 3$ 时在 $(-\infty, x_1)$ 和 $(x_2, +\infty)$ 上递增，在 $(x_1, x_2)$ 上递减。（2）$a = \dfrac{9}{2}$。

**⚠️ 易错提醒：**
1. 讨论单调性时必须对 $\Delta$ 分类讨论。
2. 求出 $a$ 的值后必须验证是否满足存在极值的条件（$a < 0$ 或 $a > 3$）。

**💡 解题思路总结：** 含参函数单调性讨论的核心是分析 $f'(x) = 0$ 的根的情况。极值之和的计算利用韦达定理避免求具体根，将 $f(x_1) + f(x_2)$ 表示为关于 $x_1 + x_2$ 和 $x_1 x_2$ 的表达式。
