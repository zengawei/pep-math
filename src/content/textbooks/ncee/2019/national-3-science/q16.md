**题目：**

已知三棱锥 $P\text{-}ABC$ 的四个顶点均在球 $O$ 的球面上，$\triangle ABC$ 是边长为 $2$ 的正三角形，$PA \perp$ 平面 $ABC$，$PA = 2$，则球 $O$ 的表面积为 ______。

---

**解答：**

**第1步：** 求 $\triangle ABC$ 的外接圆半径。
> 📌 运用知识点：正三角形的外接圆

$\triangle ABC$ 是边长为 $2$ 的正三角形，其外接圆半径：

$$r = \frac{2}{\sqrt{3}} = \frac{2\sqrt{3}}{3}$$

**第2步：** 确定球心位置。
> 📌 运用知识点：球的性质

设 $\triangle ABC$ 的外接圆圆心为 $O_1$，球心 $O$ 在过 $O_1$ 且垂直于平面 $ABC$ 的直线上。

设球心高度为 $z$（以平面 $ABC$ 为基准），由 $|OA| = |OP|$：

$$r^2 + z^2 = r^2 + (2 - z)^2$$

$$z^2 = 4 - 4z + z^2 \implies z = 1$$

**第3步：** 求球的半径和表面积。

$$R^2 = r^2 + z^2 = \frac{4}{3} + 1 = \frac{7}{3}$$

$$S = 4\pi R^2 = 4\pi \times \frac{7}{3} = \frac{28\pi}{3}$$

**正确答案：** $\dfrac{28\pi}{3}$

**⚠️ 易错提醒：** 正三角形外接圆半径 $r = \dfrac{a}{\sqrt{3}}$（不是 $\dfrac{a}{2}$）。球心位置由 $|OA| = |OP|$ 确定，不要想当然认为球心在 $PA$ 中点。

**💡 解题思路总结：** 求外接球半径的核心方法：①求底面外接圆半径 $r$；②利用球心到各顶点等距确定球心在垂直方向的位置 $z$；③由 $R^2 = r^2 + z^2$ 求球的半径。
