**题目：**

已知抛物线 $C: y^2 = 4x$ 的焦点为 $F$，过 $F$ 的直线 $l$ 与抛物线 $C$ 交于 $A$，$B$ 两点。

（1）若 $|AF| = 3|BF|$，求直线 $l$ 的方程；

（2）若 $|AB| = 8$，求直线 $l$ 的斜率。

---

**解答：**

**第1步：** 确定焦点坐标。

抛物线 $y^2 = 4x$，$2p = 4$，$p = 2$，焦点 $F(1, 0)$。

**第2步：** 设直线 $l$ 并联立抛物线方程。
> 📌 运用知识点：抛物线与直线的位置关系

设直线 $l: x = my + 1$（过焦点 $F(1, 0)$），代入 $y^2 = 4x$：

$$y^2 = 4(my + 1) \implies y^2 - 4my - 4 = 0$$

设 $A(x_1, y_1)$，$B(x_2, y_2)$，由韦达定理：$y_1 + y_2 = 4m$，$y_1 y_2 = -4$。

**第3步：** 利用 $|AF| = 3|BF|$ 求解。
> 📌 运用知识点：抛物线的焦半径

由焦半径公式：$|AF| = x_1 + 1$，$|BF| = x_2 + 1$。

$$x_1 + 1 = 3(x_2 + 1) \implies x_1 = 3x_2 + 2$$

由 $y_1^2 = 4x_1$，$y_2^2 = 4x_2$，$y_1 y_2 = -4$，得 $y_1 = \dfrac{-4}{y_2}$。

$$\frac{y_1^2}{4} = 3 \cdot \frac{y_2^2}{4} + 2 \implies y_1^2 = 3y_2^2 + 8$$

代入 $y_1 = \dfrac{-4}{y_2}$：

$$\frac{16}{y_2^2} = 3y_2^2 + 8 \implies 3y_2^4 + 8y_2^2 - 16 = 0$$

令 $t = y_2^2$：$3t^2 + 8t - 16 = 0$，解得 $t = \dfrac{4}{3}$（取正值）。

$y_2 = \pm \dfrac{2}{\sqrt{3}}$，$y_1 = \mp 2\sqrt{3}$。

$$y_1 + y_2 = \mp 2\sqrt{3} \pm \frac{2}{\sqrt{3}} = \mp \frac{4\sqrt{3}}{3} = 4m \implies m = \mp \frac{\sqrt{3}}{3}$$

直线 $l$：$y = \pm\sqrt{3}(x - 1)$。

**第4步：** 第（2）问，利用焦点弦长公式。
> 📌 运用知识点：抛物线的焦点弦

$$|AB| = x_1 + x_2 + p = m(y_1 + y_2) + 2 + 2 = 4m^2 + 4$$

$$4m^2 + 4 = 8 \implies m^2 = 1 \implies m = \pm 1$$

斜率 $k = \dfrac{1}{m} = \pm 1$。

**正确答案：** （1）$y = \pm\sqrt{3}(x - 1)$；（2）$k = \pm 1$。

**⚠️ 易错提醒：**
1. 抛物线 $y^2 = 4x$ 的焦半径为 $|PF| = x + 1$（不是 $x + 2$）。
2. 焦点弦长公式 $|AB| = x_1 + x_2 + p$ 只适用于过焦点的弦。

**💡 解题思路总结：** 抛物线焦点弦问题：①设直线 $x = my + 1$ 避免讨论斜率不存在的情况；②联立后利用韦达定理；③焦半径和弦长公式是核心工具。
