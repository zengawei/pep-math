**题目：**

已知函数 $f(x) = 2\sin(\omega x + \varphi)$（$\omega > 0$，$|\varphi| < \dfrac{\pi}{2}$）的图象关于直线 $x = \dfrac{\pi}{6}$ 对称，且相邻两个零点之间的距离为 $\dfrac{\pi}{2}$，则 $\varphi = $（）

(A) $\dfrac{\pi}{6}$  (B) $-\dfrac{\pi}{6}$  (C) $\dfrac{\pi}{3}$  (D) $-\dfrac{\pi}{3}$

---

**解答：**

**第1步：** 由相邻零点间距求 $\omega$。
> 📌 运用知识点：三角函数的周期

相邻两个零点之间的距离为半个周期：$\dfrac{T}{2} = \dfrac{\pi}{2}$，所以 $T = \pi$。

$$T = \frac{2\pi}{\omega} = \pi \implies \omega = 2$$

**第2步：** 利用对称轴条件求 $\varphi$。
> 📌 运用知识点：三角函数的对称性

$f(x)$ 关于 $x = \dfrac{\pi}{6}$ 对称，说明 $x = \dfrac{\pi}{6}$ 处取极值，即：

$$2 \times \frac{\pi}{6} + \varphi = \frac{\pi}{2} + k\pi \quad (k \in \mathbb{Z})$$

$$\frac{\pi}{3} + \varphi = \frac{\pi}{2} + k\pi$$

$$\varphi = \frac{\pi}{6} + k\pi$$

**第3步：** 由 $|\varphi| < \dfrac{\pi}{2}$ 确定 $\varphi$。

取 $k = 0$，$\varphi = \dfrac{\pi}{6}$，满足 $|\varphi| < \dfrac{\pi}{2}$。

**正确答案：** (A)

**⚠️ 易错提醒：** 相邻零点间距是半个周期而非一个周期。对称轴处函数取极值，此时相位角为 $\dfrac{\pi}{2} + k\pi$。

**💡 解题思路总结：** 三角函数 $y = A\sin(\omega x + \varphi)$ 的图象问题：①由零点间距或最值间距确定周期和 $\omega$；②由对称轴或对称中心确定 $\varphi$；③利用 $\varphi$ 的范围筛选唯一解。
