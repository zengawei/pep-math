**题目：**

已知 $\sin\left(\alpha + \dfrac{\pi}{4}\right) = \dfrac{\sqrt{2}}{4}$，则 $\sin 2\alpha = $ ______。

---

**解答：**

**第1步：** 展开 $\sin\left(\alpha + \dfrac{\pi}{4}\right)$。
> 📌 运用知识点：两角和的正弦公式

$$\sin\left(\alpha + \frac{\pi}{4}\right) = \sin\alpha \cos\frac{\pi}{4} + \cos\alpha \sin\frac{\pi}{4} = \frac{\sqrt{2}}{2}(\sin\alpha + \cos\alpha)$$

由已知：$\dfrac{\sqrt{2}}{2}(\sin\alpha + \cos\alpha) = \dfrac{\sqrt{2}}{4}$

$$\sin\alpha + \cos\alpha = \frac{1}{2}$$

**第2步：** 两边平方求 $\sin 2\alpha$。
> 📌 运用知识点：二倍角公式

$$(\sin\alpha + \cos\alpha)^2 = \frac{1}{4}$$

$$\sin^2\alpha + 2\sin\alpha\cos\alpha + \cos^2\alpha = \frac{1}{4}$$

$$1 + \sin 2\alpha = \frac{1}{4}$$

$$\sin 2\alpha = -\frac{3}{4}$$

**正确答案：** $-\dfrac{3}{4}$

**⚠️ 易错提醒：** 展开 $\sin\left(\alpha + \dfrac{\pi}{4}\right)$ 时不要遗漏 $\cos\dfrac{\pi}{4} = \sin\dfrac{\pi}{4} = \dfrac{\sqrt{2}}{2}$。平方后利用 $\sin^2\alpha + \cos^2\alpha = 1$ 化简。

**💡 解题思路总结：** 已知含 $\alpha + \dfrac{\pi}{4}$ 的三角函数值求 $\sin 2\alpha$：①先用和角公式展开得到 $\sin\alpha + \cos\alpha$ 的值；②两边平方，利用基本恒等式和二倍角公式求解。
