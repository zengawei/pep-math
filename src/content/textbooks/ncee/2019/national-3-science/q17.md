**题目：**

$\triangle ABC$ 的内角 $A$，$B$，$C$ 的对边分别为 $a$，$b$，$c$。已知 $a\cos B + b\cos A = 2c\cos C$。

（1）求 $C$；

（2）若 $c = 2$，求 $\triangle ABC$ 的周长的取值范围。

---

**解答：**

**第1步：** 利用射影定理化简已知条件。
> 📌 运用知识点：射影定理（正弦定理的推论）

由射影定理：$a\cos B + b\cos A = c$（恒等式）。

代入已知条件：$c = 2c\cos C$。

因为 $c > 0$，所以 $\cos C = \dfrac{1}{2}$。

$$C = \frac{\pi}{3}$$

**第2步：** 利用余弦定理建立关系。
> 📌 运用知识点：余弦定理

$c = 2$，$C = \dfrac{\pi}{3}$，由余弦定理：

$$c^2 = a^2 + b^2 - 2ab\cos C \implies 4 = a^2 + b^2 - ab$$

**第3步：** 求 $a + b$ 的范围。
> 📌 运用知识点：基本不等式

设 $s = a + b$，则 $s^2 = a^2 + 2ab + b^2 = (a^2 + b^2 - ab) + 3ab = 4 + 3ab$。

由基本不等式 $ab \leqslant \dfrac{(a+b)^2}{4} = \dfrac{s^2}{4}$：

$$s^2 = 4 + 3ab \leqslant 4 + \frac{3s^2}{4}$$

$$\frac{s^2}{4} \leqslant 4 \implies s^2 \leqslant 16 \implies s \leqslant 4$$

等号成立条件：$a = b = 2$（等边三角形）。

又 $s > c = 2$（三角形两边之和大于第三边），且 $a, b > 0$ 要求 $ab = \dfrac{s^2 - 4}{3} > 0$，即 $s > 2$。

因此 $s \in (2, 4]$。

**第4步：** 求周长范围。

周长 $L = a + b + c = s + 2 \in (4, 6]$。

**正确答案：** $C = \dfrac{\pi}{3}$；周长的取值范围为 $(4, 6]$。

**⚠️ 易错提醒：**
1. 射影定理 $a\cos B + b\cos A = c$ 是恒等式，可以直接使用。
2. 求 $a+b$ 的范围时，上界由基本不等式得到，下界由三角形不等式得到，两端都要验证。

**💡 解题思路总结：** 三角形周长范围问题的解题框架：①利用已知条件确定角的大小；②用余弦定理建立边长关系；③利用基本不等式求上界，利用三角形不等式求下界。
