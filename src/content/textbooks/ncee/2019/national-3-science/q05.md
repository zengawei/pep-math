**题目：**

设等比数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n$，且 $a_1 = 1$，$S_3 = 7$，则 $S_6 = $（）

(A) $63$  (B) $64$  (C) $65$  (D) $127$

---

**解答：**

**第1步：** 利用 $S_3$ 求公比 $q$。
> 📌 运用知识点：等比数列的前 $n$ 项和

$$S_3 = a_1(1 + q + q^2) = 1 + q + q^2 = 7$$

$$q^2 + q - 6 = 0 \implies (q + 3)(q - 2) = 0$$

解得 $q = 2$ 或 $q = -3$。

**第2步：** 分别计算 $S_6$，排除不合选项。
> 📌 运用知识点：等比数列的前 $n$ 项和

当 $q = 2$ 时：$S_6 = \dfrac{2^6 - 1}{2 - 1} = 63$。

当 $q = -3$ 时：$S_6 = \dfrac{(-3)^6 - 1}{-3 - 1} = \dfrac{728}{-4} = -182$（不在选项中，舍去）。

**正确答案：** (A)

**⚠️ 易错提醒：** 等比数列求和公式 $S_n = \dfrac{a_1(q^n - 1)}{q - 1}$ 要求 $q \neq 1$。本题 $q = 2$，公式适用。注意 $q = -3$ 时 $S_6$ 为负值，不在选项中。

**💡 解题思路总结：** 等比数列已知首项和前 $n$ 项和求公比时，利用 $S_n$ 的公式建立关于 $q$ 的方程，解出 $q$ 后代入求其他项的和。
