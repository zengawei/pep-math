**题目：**

已知集合 $A = \{x \mid x^2 - 3x - 4 < 0\}$，$B = \{-4, 1, 3, 5\}$，则 $A \cap B = $（）

(A) $\{-4, 1\}$  (B) $\{1, 5\}$  (C) $\{1, 3\}$  (D) $\{3, 5\}$

---

**解答：**

**第1步：** 求集合 $A$。
> 📌 运用知识点：一元二次不等式的解法

解不等式 $x^2 - 3x - 4 < 0$，因式分解得 $(x - 4)(x + 1) < 0$，解得 $-1 < x < 4$。

因此 $A = (-1, 4)$。

**第2步：** 求 $A \cap B$。
> 📌 运用知识点：集合的交集运算

$B = \{-4, 1, 3, 5\}$ 中，在 $(-1, 4)$ 内的元素为 $1$ 和 $3$。

因此 $A \cap B = \{1, 3\}$。

**正确答案：** (C)

**⚠️ 易错提醒：** 注意不等式是严格小于号，端点 $-1$ 和 $4$ 不在集合 $A$ 中。检查 $B$ 中元素时要逐一判断是否在区间内。

**💡 解题思路总结：** 集合交集问题的解题步骤：①先解不等式确定集合 $A$ 的范围；②逐一检验集合 $B$ 中各元素是否属于 $A$；③取公共部分即为交集。
