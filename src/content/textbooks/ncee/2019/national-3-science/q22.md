**题目：**

在直角坐标系 $xOy$ 中，曲线 $C$ 的参数方程为 $\begin{cases} x = 2 + \cos\alpha \\ y = \sin\alpha \end{cases}$（$\alpha$ 为参数）。以坐标原点为极点，$x$ 轴正半轴为极轴建立极坐标系，直线 $l$ 的极坐标方程为 $\rho\cos\theta + \sqrt{3}\rho\sin\theta = 4$。

（1）求曲线 $C$ 的普通方程和直线 $l$ 的直角坐标方程；

（2）求曲线 $C$ 上的点到直线 $l$ 的距离的最大值。

---

**解答：**

**第1步：** 求曲线 $C$ 的普通方程。
> 📌 运用知识点：参数方程化为普通方程

由参数方程：$x - 2 = \cos\alpha$，$y = \sin\alpha$。

$$(x - 2)^2 + y^2 = \cos^2\alpha + \sin^2\alpha = 1$$

曲线 $C$ 是以 $(2, 0)$ 为圆心、$1$ 为半径的圆。

**第2步：** 求直线 $l$ 的直角坐标方程。
> 📌 运用知识点：极坐标方程化为直角坐标方程

$\rho\cos\theta = x$，$\rho\sin\theta = y$，代入：

$$x + \sqrt{3}y = 4$$

**第3步：** 求曲线 $C$ 上的点到直线 $l$ 的距离最大值。
> 📌 运用知识点：点到直线的距离

圆心 $(2, 0)$ 到直线 $x + \sqrt{3}y - 4 = 0$ 的距离：

$$d = \frac{|2 + 0 - 4|}{\sqrt{1 + 3}} = \frac{2}{2} = 1$$

曲线 $C$ 上的点到直线 $l$ 的距离最大值为 $d + r = 1 + 1 = 2$。

**正确答案：** （1）$(x - 2)^2 + y^2 = 1$，$x + \sqrt{3}y = 4$；（2）最大距离为 $2$。

**⚠️ 易错提醒：**
1. 参数方程消参时利用 $\cos^2\alpha + \sin^2\alpha = 1$。
2. 圆上的点到直线的距离最大值 = 圆心到直线的距离 + 半径（当直线与圆不相交时）。

**💡 解题思路总结：** 参数方程与极坐标问题的核心转化：①参数方程利用三角恒等式消参；②极坐标方程利用 $\rho\cos\theta = x$，$\rho\sin\theta = y$ 转化；③圆上点到直线距离的最值用圆心距加减半径。
