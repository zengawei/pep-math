**题目：** 在四棱锥 $P\text{-}ABCD$ 中，底面 $ABCD$ 为矩形，$PA \perp$ 底面 $ABCD$，$PA = AB = 2$，$AD = 4$。$M$ 为 $PD$ 的中点。

(1) 求证：$PB \parallel$ 平面 $MAC$；

(2) 求二面角 $M\text{-}AC\text{-}D$ 的大小。

---

**解答：**

**第1步：** 建立空间直角坐标系
> 📌 运用知识点：space-vector-coordinate

以 $A$ 为原点，$\overrightarrow{AB}$ 方向为 $x$ 轴，$\overrightarrow{AD}$ 方向为 $y$ 轴，$\overrightarrow{AP}$ 方向为 $z$ 轴。

$A(0,0,0)$，$B(2,0,0)$，$C(2,4,0)$，$D(0,4,0)$，$P(0,0,2)$

$M$ 为 $PD$ 中点：$M = \left(\dfrac{0+0}{2}, \dfrac{0+4}{2}, \dfrac{2+0}{2}\right) = (0, 2, 1)$

**第2步：** 证明 $PB \parallel$ 平面 $MAC$（第1问）
> 📌 运用知识点：space-vector-coordinate

$\overrightarrow{PB} = (2, 0, -2)$

平面 $MAC$ 内两个向量：$\overrightarrow{AC} = (2, 4, 0)$，$\overrightarrow{AM} = (0, 2, 1)$

设平面 $MAC$ 的法向量 $\vec{n} = (a, b, c)$：

$\vec{n} \cdot \overrightarrow{AC} = 2a + 4b = 0 \implies a = -2b$

$\vec{n} \cdot \overrightarrow{AM} = 2b + c = 0 \implies c = -2b$

取 $b = -1$：$\vec{n} = (2, -1, 2)$

验证：$\overrightarrow{PB} \cdot \vec{n} = 2\times2 + 0\times(-1) + (-2)\times2 = 4 - 4 = 0$

所以 $\overrightarrow{PB} \perp \vec{n}$，即 $PB \parallel$ 平面 $MAC$。

又 $P(0,0,2)$ 不在平面 $MAC$ 上（$\vec{n}\cdot\overrightarrow{AP} = 2\times0+(-1)\times0+2\times2 = 4 \neq 0$），故 $PB \parallel$ 平面 $MAC$。$\blacksquare$

**第3步：** 求二面角 $M\text{-}AC\text{-}D$（第2问）
> 📌 运用知识点：spatial-angle

二面角 $M\text{-}AC\text{-}D$ 即平面 $MAC$ 与平面 $ACD$ 的夹角。

平面 $ACD$（即 $xy$ 平面）的法向量：$\vec{n_1} = (0, 0, 1)$

平面 $MAC$ 的法向量：$\vec{n_2} = (2, -1, 2)$

$$\cos\theta = \frac{|\vec{n_1} \cdot \vec{n_2}|}{|\vec{n_1}||\vec{n_2}|} = \frac{|2|}{1 \times \sqrt{4+1+4}} = \frac{2}{3}$$

二面角 $M\text{-}AC\text{-}D$ 的大小为 $\arccos\dfrac{2}{3}$。

**⚠️ 易错提醒：** ①证明线面平行需同时验证 $\overrightarrow{PB}\cdot\vec{n}=0$ 且点不在平面上。②求二面角时注意法向量方向，取绝对值确保得到正确的夹角。

**💡 解题思路总结：** 建系后利用向量法：线面平行 ⟺ 方向向量与法向量垂直；二面角 ⟺ 两平面法向量的夹角（取绝对值）。
