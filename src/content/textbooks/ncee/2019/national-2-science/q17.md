**题目：** $\triangle ABC$ 的内角 $A, B, C$ 的对边分别为 $a, b, c$。已知 $b\sin A + a\cos B = 0$。

(1) 求 $B$；

(2) 若 $b = \sqrt{3}$，$a + c = 3$，求 $\triangle ABC$ 的面积。

---

**解答：**

**第1步：** 利用正弦定理转化（第1问）
> 📌 运用知识点：trig-function

由正弦定理 $\dfrac{a}{\sin A} = \dfrac{b}{\sin B}$，得 $b\sin A = a\sin B$。

代入已知条件：$a\sin B + a\cos B = 0$。

因为 $a > 0$，所以 $\sin B + \cos B = 0$。

**第2步：** 求解 $B$
> 📌 运用知识点：trig-identity

$\sin B = -\cos B$，即 $\tan B = -1$。

因为 $B \in (0, \pi)$，$\tan B = -1$ 在第二象限，所以 $B = \dfrac{3\pi}{4}$。

**第3步：** 利用余弦定理（第2问）
> 📌 运用知识点：trig-function

$b^2 = a^2 + c^2 - 2ac\cos B$

$3 = a^2 + c^2 - 2ac\cos\dfrac{3\pi}{4} = a^2 + c^2 + \sqrt{2}ac$

**第4步：** 利用 $a + c = 3$ 求 $ac$
> 📌 运用知识点：basic-inequality

$(a+c)^2 = a^2 + 2ac + c^2 = 9$，所以 $a^2 + c^2 = 9 - 2ac$。

代入：$3 = 9 - 2ac + \sqrt{2}ac = 9 - ac(2 - \sqrt{2})$

$ac(2 - \sqrt{2}) = 6$

$ac = \dfrac{6}{2 - \sqrt{2}} = \dfrac{6(2 + \sqrt{2})}{(2-\sqrt{2})(2+\sqrt{2})} = \dfrac{6(2+\sqrt{2})}{2} = 3(2+\sqrt{2})$

**第5步：** 计算面积
> 📌 运用知识点：trig-identity

$$S = \frac{1}{2}ac\sin B = \frac{1}{2} \times 3(2+\sqrt{2}) \times \sin\frac{3\pi}{4} = \frac{3(2+\sqrt{2})}{2} \times \frac{\sqrt{2}}{2} = \frac{3\sqrt{2}(2+\sqrt{2})}{4} = \frac{6\sqrt{2}+6}{4} = \frac{3(\sqrt{2}+1)}{2}$$

**⚠️ 易错提醒：** ①由 $\tan B = -1$ 求 $B$ 时注意 $B$ 的范围是 $(0, \pi)$，应取 $B = \frac{3\pi}{4}$ 而非 $-\frac{\pi}{4}$。②分母有理化时不要出错。

**💡 解题思路总结：** 解三角形问题的核心工具是正弦定理和余弦定理。先用正弦定理将边角关系统一，再用余弦定理建立方程求未知量，最后代入面积公式。
