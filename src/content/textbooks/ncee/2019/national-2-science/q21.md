**题目：** 已知函数 $f(x) = \ln x - ax^2 + (2-a)x$（$a > 0$）。

(1) 讨论 $f(x)$ 的单调性；

(2) 若 $f(x) \leq 0$ 恒成立，求 $a$ 的取值范围。

---

**解答：**

**第1步：** 求导并化简（第1问）
> 📌 运用知识点：derivative-operations

定义域：$x > 0$。

$$f'(x) = \frac{1}{x} - 2ax + (2-a) = \frac{-2ax^2 + (2-a)x + 1}{x}$$

**第2步：** 分析分子
> 📌 运用知识点：derivative-monotonicity

设 $g(x) = -2ax^2 + (2-a)x + 1$。

解 $g(x) = 0$：判别式 $\Delta = (2-a)^2 + 8a = a^2 + 4a + 4 = (a+2)^2$。

$$x = \frac{-(2-a) \pm (a+2)}{-4a}$$

$x_1 = \dfrac{-(2-a)+(a+2)}{-4a} = \dfrac{2a}{-4a} = -\dfrac{1}{2}$（不在定义域内，舍去）

$x_2 = \dfrac{-(2-a)-(a+2)}{-4a} = \dfrac{-4}{-4a} = \dfrac{1}{a}$

等等，让我重新计算：

$x = \dfrac{(2-a) \pm (a+2)}{4a}$（用 $2ax^2 - (2-a)x - 1 = 0$ 的正根）

$x_1 = \dfrac{(2-a)+(a+2)}{4a} = \dfrac{4}{4a} = \dfrac{1}{a}$

不对，$g(x) = -2ax^2 + (2-a)x + 1 = 0$ 即 $2ax^2 - (2-a)x - 1 = 0$。

$x = \dfrac{(2-a) \pm \sqrt{(a+2)^2}}{4a} = \dfrac{(2-a) \pm (a+2)}{4a}$

$x_1 = \dfrac{(2-a)+(a+2)}{4a} = \dfrac{4}{4a} = \dfrac{1}{a}$... 不对

让我再算：$x = \dfrac{(2-a) \pm (a+2)}{4a}$

取 $+$：$x = \dfrac{2-a+a+2}{4a} = \dfrac{4}{4a} = \dfrac{1}{a}$... 嗯不对

实际上 $g(x) = -2ax^2 + (2-a)x + 1$，令 $g(x) = 0$，即 $2ax^2 - (2-a)x - 1 = 0$。

分解：$(2ax + 1)(x - 1) = 2ax^2 - 2ax + x - 1$... 不对

尝试：$2ax^2 - (2-a)x - 1 = 0$

$x = \frac{(2-a) \pm (a+2)}{4a}$

取 $+$：$x = \frac{4}{4a} = \frac{1}{a}$... 不对

让我直接代入验证：$x = \frac{1}{2}$

$g(1/2) = -2a(1/4) + (2-a)(1/2) + 1 = -a/2 + 1 - a/2 + 1 = 2 - a$

这不为零（除非 $a=2$）。让我重新算。

$2ax^2 - (2-a)x - 1 = 0$

$\Delta = (2-a)^2 + 4 \cdot 2a \cdot 1 = 4 - 4a + a^2 + 8a = a^2 + 4a + 4 = (a+2)^2$

$x = \frac{(2-a) \pm (a+2)}{4a}$

$x_1 = \frac{(2-a)+(a+2)}{4a} = \frac{4}{4a} = \frac{1}{a}$

嗯不对，分母是 $2 \times 2a = 4a$，分子 $(2-a)+(a+2) = 4$。所以 $x_1 = \frac{1}{a}$。

$x_2 = \frac{(2-a)-(a+2)}{4a} = \frac{-2a}{4a} = -\frac{1}{2}$

所以 $g(x) = -2a(x - 1/a)(x + 1/2) = -(2ax+1)(x - 1/a)$... 

验证：$-(2ax+1)(x-1/a) = -(2ax^2 - 2x + x - 1/a) = -(2ax^2 - x - 1/a) = -2ax^2 + x + 1/a$

这不等于 $g(x)$。让我直接分解 $2ax^2 - (2-a)x - 1$。

试 $x = 1$: $2a - (2-a) - 1 = 2a - 2 + a - 1 = 3a - 3$。当 $a=1$ 时为零。

所以因式分解取决于 $a$ 的值。用求根公式更可靠：

$g(x) = -2a\left(x - \frac{1}{a}\right)\left(x + \frac{1}{2}\right)$... 让我验证

$-2a(x - 1/a)(x + 1/2) = -2a[x^2 + x/2 - x/a - 1/(2a)] = -2ax^2 - ax + 2x + 1 = -2ax^2 + (2-a)x + 1$ ✓

所以 $g(x) = -2a(x - \frac{1}{a})(x + \frac{1}{2})$。

**第3步：** 确定单调区间
> 📌 运用知识点：derivative-monotonicity

因为 $x > 0$，$x + \frac{1}{2} > 0$，$-2a < 0$。

$f'(x) = \frac{g(x)}{x} = \frac{-2a(x - 1/a)(x + 1/2)}{x}$

当 $0 < x < \frac{1}{a}$ 时：$x - \frac{1}{a} < 0$，$f'(x) = \frac{(-)(-)(+)}{(+)} > 0$，$f(x)$ 单调递增。

当 $x > \frac{1}{a}$ 时：$x - \frac{1}{a} > 0$，$f'(x) = \frac{(-)(+)(+)}{(+)} < 0$，$f(x)$ 单调递减。

**结论：** $f(x)$ 在 $\left(0, \dfrac{1}{a}\right)$ 上单调递增，在 $\left(\dfrac{1}{a}, +\infty\right)$ 上单调递减。

**第4步：** 求 $f(x) \leq 0$ 恒成立的条件（第2问）
> 📌 运用知识点：derivative-max-min

$f(x) \leq 0$ 恒成立 ⟺ $f(x)_{\max} \leq 0$。

由第1问知 $f(x)$ 在 $x = \frac{1}{a}$ 处取最大值。

$$f\left(\frac{1}{a}\right) = \ln\frac{1}{a} - a \cdot \frac{1}{a^2} + (2-a) \cdot \frac{1}{a} = -\ln a - \frac{1}{a} + \frac{2}{a} - 1 = -\ln a + \frac{1}{a} - 1$$

要求 $-\ln a + \dfrac{1}{a} - 1 \leq 0$，即 $\ln a \geq \dfrac{1}{a} - 1$。

**第5步：** 求解不等式
> 📌 运用知识点：derivative-applications

设 $h(a) = \ln a - \dfrac{1}{a} + 1$（$a > 0$）。

$h'(a) = \dfrac{1}{a} + \dfrac{1}{a^2} > 0$，$h(a)$ 在 $(0, +\infty)$ 上单调递增。

$h(1) = 0 - 1 + 1 = 0$。

所以 $h(a) \geq 0 \iff a \geq 1$。

**$a$ 的取值范围为 $[1, +\infty)$。**

**⚠️ 易错提醒：** ①求导后分子的因式分解要仔细验证。②第2问中需构造辅助函数 $h(a)$ 并分析其单调性，不能直接猜测 $a \geq 1$。

**💡 解题思路总结：** 含参函数的恒成立问题：先利用导数找到最值点的表达式，再将"最值 ≤ 0"转化为关于参数的不等式，必要时构造辅助函数再次利用导数分析。
