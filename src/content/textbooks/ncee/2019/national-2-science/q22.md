**题目：** 在直角坐标系 $xOy$ 中，曲线 $C$ 的参数方程为 $\begin{cases} x = 2\cos\theta \\ y = \sin\theta \end{cases}$（$\theta$ 为参数），以原点为极点，$x$ 轴正半轴为极轴建立极坐标系，直线 $l$ 的极坐标方程为 $\rho\cos\!\left(\theta - \dfrac{\pi}{4}\right) = \sqrt{2}$。

(1) 求曲线 $C$ 的普通方程和直线 $l$ 的直角坐标方程；

(2) 设点 $P$ 为曲线 $C$ 上的点，求 $P$ 到直线 $l$ 的距离的最大值和最小值。

---

**解答：**

**第1步：** 消参求普通方程（第1问）
> 📌 运用知识点：curve-equation-method

由参数方程：$\cos\theta = \dfrac{x}{2}$，$\sin\theta = y$。

利用 $\cos^2\theta + \sin^2\theta = 1$：

$$\frac{x^2}{4} + y^2 = 1$$

**第2步：** 展开极坐标方程
> 📌 运用知识点：coordinate-method

$\rho\cos\left(\theta - \dfrac{\pi}{4}\right) = \sqrt{2}$

$\rho\left(\cos\theta\cos\dfrac{\pi}{4} + \sin\theta\sin\dfrac{\pi}{4}\right) = \sqrt{2}$

$\rho \cdot \dfrac{\sqrt{2}}{2}(\cos\theta + \sin\theta) = \sqrt{2}$

$\rho(\cos\theta + \sin\theta) = 2$

即 $x + y = 2$。

**第3步：** 求距离表达式（第2问）
> 📌 运用知识点：conic-section-optimization

设 $P(2\cos\theta, \sin\theta)$，到直线 $x + y - 2 = 0$ 的距离：

$$d = \frac{|2\cos\theta + \sin\theta - 2|}{\sqrt{2}}$$

**第4步：** 利用辅助角公式求最值
> 📌 运用知识点：trig-identity

$2\cos\theta + \sin\theta = \sqrt{5}\sin(\theta + \varphi)$，其中 $\tan\varphi = 2$。

$2\cos\theta + \sin\theta$ 的值域为 $[-\sqrt{5}, \sqrt{5}]$。

**第5步：** 确定最大和最小距离
> 📌 运用知识点：conic-section-optimization

令 $u = 2\cos\theta + \sin\theta$，$u \in [-\sqrt{5}, \sqrt{5}]$。

$d = \dfrac{|u - 2|}{\sqrt{2}}$

因为 $\sqrt{5} \approx 2.236 > 2$，$u$ 可以取到 $2$（此时 $d = 0$）。

**最小值：** 当 $u = 2$ 时，$d_{\min} = 0$。

**最大值：** 当 $u = -\sqrt{5}$ 时，$d_{\max} = \dfrac{|-\sqrt{5} - 2|}{\sqrt{2}} = \dfrac{\sqrt{5} + 2}{\sqrt{2}} = \dfrac{\sqrt{10} + 2\sqrt{2}}{2}$。

**$P$ 到直线 $l$ 的距离的最大值为 $\dfrac{\sqrt{10} + 2\sqrt{2}}{2}$，最小值为 $0$。**

**⚠️ 易错提醒：** ①极坐标展开时注意和角公式 $\cos(\alpha-\beta)$ 的正确使用。②辅助角公式 $a\cos\theta + b\sin\theta = \sqrt{a^2+b^2}\sin(\theta+\varphi)$ 中振幅为 $\sqrt{a^2+b^2}$。③判断 $d_{\min}$ 时需确认 $u = 2$ 是否在值域内。

**💡 解题思路总结：** 参数方程 + 距离问题的标准解法：将距离表示为参数的函数 → 利用辅助角公式求三角函数的最值 → 代入得距离的最值。
