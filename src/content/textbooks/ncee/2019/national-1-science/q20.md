**题目：** 已知椭圆 $C: \dfrac{x^2}{4} + y^2 = 1$，$F_1$、$F_2$ 分别为 $C$ 的左、右焦点，过 $F_1$ 的直线 $l$ 与 $C$ 交于 $A$、$B$ 两点。

（1）若 $l \perp x$ 轴，求 $|AB|$；

（2）求 $\triangle ABF_2$ 面积的最大值。

---

**解答：**

**第1步：** 确定椭圆基本参数
> 📌 运用知识点：椭圆的基本性质

$a^2 = 4$，$b^2 = 1$，$c^2 = a^2 - b^2 = 3$。

$F_1(-\sqrt{3}, 0)$，$F_2(\sqrt{3}, 0)$。

**第2步：** $l \perp x$ 轴时求 $|AB|$
> 📌 运用知识点：圆锥曲线与直线

$l: x = -\sqrt{3}$，代入椭圆方程：

$$\frac{3}{4} + y^2 = 1 \implies y^2 = \frac{1}{4} \implies y = \pm\frac{1}{2}$$

$$|AB| = 2 \times \frac{1}{2} = 1$$

**第3步：** 设直线方程并联立
> 📌 运用知识点：直线与椭圆的位置关系

设 $l: x = my - \sqrt{3}$（这样可以包含斜率不存在的情况）。

代入椭圆方程：

$$\frac{(my - \sqrt{3})^2}{4} + y^2 = 1$$

$$(my - \sqrt{3})^2 + 4y^2 = 4$$

$$m^2y^2 - 2\sqrt{3}my + 3 + 4y^2 = 4$$

$$(m^2 + 4)y^2 - 2\sqrt{3}my - 1 = 0$$

**第4步：** 利用韦达定理

$$y_1 + y_2 = \frac{2\sqrt{3}m}{m^2 + 4}, \quad y_1 y_2 = \frac{-1}{m^2 + 4}$$

**第5步：** 计算 $|y_1 - y_2|$

$$(y_1 - y_2)^2 = (y_1 + y_2)^2 - 4y_1 y_2 = \frac{12m^2}{(m^2 + 4)^2} + \frac{4}{m^2 + 4}$$

$$= \frac{12m^2 + 4(m^2 + 4)}{(m^2 + 4)^2} = \frac{16m^2 + 16}{(m^2 + 4)^2} = \frac{16(m^2 + 1)}{(m^2 + 4)^2}$$

$$|y_1 - y_2| = \frac{4\sqrt{m^2 + 1}}{m^2 + 4}$$

**第6步：** 表示面积
> 📌 运用知识点：面积的最值

$$S = \frac{1}{2}|F_1 F_2| \cdot |y_1 - y_2| = \frac{1}{2} \times 2\sqrt{3} \times \frac{4\sqrt{m^2 + 1}}{m^2 + 4} = \frac{4\sqrt{3}\sqrt{m^2 + 1}}{m^2 + 4}$$

**第7步：** 求最大值

令 $t = \sqrt{m^2 + 1} \geqslant 1$，则 $m^2 + 4 = t^2 + 3$。

$$S = \frac{4\sqrt{3}t}{t^2 + 3} = \frac{4\sqrt{3}}{t + \dfrac{3}{t}}$$

由基本不等式，$t + \dfrac{3}{t} \geqslant 2\sqrt{3}$（当 $t = \sqrt{3}$ 时取等号）。

因为 $t \geqslant 1$ 且 $\sqrt{3} > 1$，等号可以取到。

$$S \leqslant \frac{4\sqrt{3}}{2\sqrt{3}} = 2$$

**答案：**（1）$|AB| = 1$；（2）$\triangle ABF_2$ 面积的最大值为 $2$。

**⚠️ 易错提醒：** 设直线方程时用 $x = my - \sqrt{3}$ 而不是 $y = k(x + \sqrt{3})$，这样可以包含斜率不存在的情况。求最值时注意换元后 $t$ 的范围，验证等号能否取到。

**💡 解题思路总结：** 圆锥曲线中面积最值问题的标准解法：联立直线与曲线方程→韦达定理→表示面积→利用基本不等式或函数方法求最值。
