**题目：** 函数 $f(x) = x^3 - 3x + 1$ 在闭区间 $[-2, 2]$ 上的最大值为

A. $1$

B. $3$

C. $-1$

D. $2$

---

**解答：**

**第1步：** 求导并找驻点
> 📌 运用知识点：导数与极值

$$f'(x) = 3x^2 - 3 = 3(x^2 - 1) = 3(x - 1)(x + 1)$$

令 $f'(x) = 0$，得 $x = 1$ 或 $x = -1$，均在 $[-2, 2]$ 内。

**第2步：** 比较端点值和驻点值
> 📌 运用知识点：闭区间上求最值

$$f(-2) = (-2)^3 - 3(-2) + 1 = -8 + 6 + 1 = -1$$

$$f(-1) = (-1)^3 - 3(-1) + 1 = -1 + 3 + 1 = 3$$

$$f(1) = 1^3 - 3(1) + 1 = 1 - 3 + 1 = -1$$

$$f(2) = 2^3 - 3(2) + 1 = 8 - 6 + 1 = 3$$

**第3步：** 确定最大值

比较得 $f(-1) = f(2) = 3$ 为最大值。

**答案：B**

**⚠️ 易错提醒：** 闭区间上的最值需要比较所有驻点和端点的函数值，不能只看驻点。

**💡 解题思路总结：** 求闭区间上连续函数的最值：①求导找驻点；②比较驻点和端点的函数值；③最大者为最大值，最小者为最小值。
