**题目：** 如图，在正方体 $ABCD\text{-}A_1B_1C_1D_1$ 中，$E$ 为 $BB_1$ 的中点，则异面直线 $AE$ 与 $D_1C$ 所成角的余弦值为

A. $\dfrac{\sqrt{10}}{10}$

B. $\dfrac{\sqrt{5}}{5}$

C. $\dfrac{\sqrt{10}}{5}$

D. $\dfrac{\sqrt{2}}{2}$

---

**解答：**

**第1步：** 建立空间直角坐标系
> 📌 运用知识点：空间向量坐标

设正方体棱长为 $2$，以 $A$ 为原点，$\overrightarrow{AB}$、$\overrightarrow{AD}$、$\overrightarrow{AA_1}$ 分别为 $x$、$y$、$z$ 轴正方向。

各点坐标：$A(0,0,0)$，$B(2,0,0)$，$D(0,2,0)$，$D_1(0,2,2)$，$C(2,2,0)$，$B_1(2,0,2)$。

$E$ 为 $BB_1$ 中点，$E = (2, 0, 1)$。

**第2步：** 求方向向量

$$\overrightarrow{AE} = (2, 0, 1)$$

$$\overrightarrow{D_1C} = C - D_1 = (2, 2, 0) - (0, 2, 2) = (2, 0, -2)$$

**第3步：** 计算夹角余弦
> 📌 运用知识点：空间角的计算

$$\cos\theta = \frac{|\overrightarrow{AE} \cdot \overrightarrow{D_1C}|}{|\overrightarrow{AE}| \cdot |\overrightarrow{D_1C}|}$$

$$\overrightarrow{AE} \cdot \overrightarrow{D_1C} = 2 \times 2 + 0 \times 0 + 1 \times (-2) = 4 - 2 = 2$$

$$|\overrightarrow{AE}| = \sqrt{4 + 0 + 1} = \sqrt{5}$$

$$|\overrightarrow{D_1C}| = \sqrt{4 + 0 + 4} = \sqrt{8} = 2\sqrt{2}$$

$$\cos\theta = \frac{2}{\sqrt{5} \times 2\sqrt{2}} = \frac{2}{2\sqrt{10}} = \frac{1}{\sqrt{10}} = \frac{\sqrt{10}}{10}$$

**答案：A**

**⚠️ 易错提醒：** 异面直线所成角取锐角或直角，所以余弦值取绝对值。建立坐标系时注意各点坐标的正确性。

**💡 解题思路总结：** 求异面直线所成角的标准方法：建系→求方向向量→用点积公式计算余弦值。注意异面直线所成角范围为 $(0°, 90°]$。
