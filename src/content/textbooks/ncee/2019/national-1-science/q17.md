**题目：** 在 $\triangle ABC$ 中，内角 $A$、$B$、$C$ 的对边分别为 $a$、$b$、$c$。已知 $2\cos C(a\cos B + b\cos A) = c$。

（1）求 $C$；

（2）若 $c = \sqrt{7}$，$\triangle ABC$ 的面积为 $\dfrac{3\sqrt{3}}{2}$，求 $a + b$。

---

**解答：**

**第1步：** 利用正弦定理转化
> 📌 运用知识点：正弦定理

由正弦定理 $\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C}$，将边替换为角：

$$2\cos C(\sin A\cos B + \sin B\cos A) = \sin C$$

**第2步：** 利用和角公式化简
> 📌 运用知识点：三角恒等变换

$$\sin A\cos B + \sin B\cos A = \sin(A + B)$$

因为 $A + B + C = \pi$，所以 $\sin(A + B) = \sin(\pi - C) = \sin C$。

代入得：

$$2\cos C \cdot \sin C = \sin C$$

**第3步：** 求解 $C$

因为 $\sin C \neq 0$（$C$ 为三角形内角），两边除以 $\sin C$：

$$2\cos C = 1 \implies \cos C = \frac{1}{2}$$

$$\boxed{C = \frac{\pi}{3}}$$

**第4步：** 利用面积公式求 $ab$
> 📌 运用知识点：三角形面积公式

$$S = \frac{1}{2}ab\sin C = \frac{1}{2}ab\sin\frac{\pi}{3} = \frac{\sqrt{3}}{4}ab = \frac{3\sqrt{3}}{2}$$

$$ab = 6$$

**第5步：** 利用余弦定理求 $a^2 + b^2$
> 📌 运用知识点：余弦定理

$$c^2 = a^2 + b^2 - 2ab\cos C$$

$$7 = a^2 + b^2 - 2 \times 6 \times \frac{1}{2} = a^2 + b^2 - 6$$

$$a^2 + b^2 = 13$$

**第6步：** 求 $a + b$

$$(a + b)^2 = a^2 + b^2 + 2ab = 13 + 12 = 25$$

$$\boxed{a + b = 5}$$

**⚠️ 易错提醒：** 第（1）问中利用正弦定理将边转化为角时，注意 $\sin(A+B) = \sin C$ 的推导。第（2）问中利用面积和余弦定理联立求解时，注意 $(a+b)^2 = a^2 + b^2 + 2ab$ 的整体代换技巧。

**💡 解题思路总结：** 三角形中的边角关系问题，常用正弦定理和余弦定理。面积公式 $S = \frac{1}{2}ab\sin C$ 可以建立 $ab$ 的方程，再与余弦定理联立，利用整体代换求 $a + b$。
