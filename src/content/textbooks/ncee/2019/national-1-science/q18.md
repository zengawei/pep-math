**题目：** 如图，四棱锥 $P\text{-}ABCD$ 中，$PA \perp$ 底面 $ABCD$，$AD \parallel BC$，$AB = AD = AC = 3$，$PA = BC = 4$，$M$ 为线段 $AD$ 上一点，$AM = 2MD$，$N$ 为 $PC$ 的中点。

（1）证明：$MN \parallel$ 平面 $PAB$；

（2）求直线 $AN$ 与平面 $PMN$ 所成角的正弦值。

---

**解答：**

**第1步：** 建立空间直角坐标系
> 📌 运用知识点：空间向量坐标

以 $A$ 为原点，$\overrightarrow{AD}$ 方向为 $x$ 轴正方向。

因为 $PA \perp$ 底面 $ABCD$，$\overrightarrow{AP}$ 方向为 $z$ 轴正方向。

$A = (0, 0, 0)$，$P = (0, 0, 4)$。

由 $AD = 3$，$D = (3, 0, 0)$。

$M$ 在 $AD$ 上，$AM = 2MD$，$AM = 2$，$M = (2, 0, 0)$。

**第2步：** 确定 $B$、$C$ 的坐标

设 $B = (x_B, y_B, 0)$，由 $AB = 3$：$x_B^2 + y_B^2 = 9$。

由 $AC = 3$，$BC = 4$，$AD \parallel BC$。

设 $C = (x_C, y_C, 0)$，由 $AC = 3$：$x_C^2 + y_C^2 = 9$。

$\overrightarrow{BC} \parallel \overrightarrow{AD}$，即 $\overrightarrow{BC}$ 沿 $x$ 轴方向。

$\overrightarrow{BC} = (x_C - x_B, y_C - y_B, 0)$，$y_C = y_B$。

$|BC| = |x_C - x_B| = 4$。

由 $AB = AC = 3$ 且 $y_B = y_C$：$x_B^2 = x_C^2$，即 $x_C = -x_B$（$x_C \neq x_B$）。

$x_C - x_B = -2x_B = 4$（取正值），$x_B = -2$... 

重新分析：取 $x_C - x_B = 4$，$x_C = x_B + 4$。

$x_B^2 + y_B^2 = 9$，$(x_B + 4)^2 + y_B^2 = 9$

$(x_B + 4)^2 - x_B^2 = 0$，$8x_B + 16 = 0$，$x_B = -2$

$y_B^2 = 9 - 4 = 5$，$y_B = \sqrt{5}$

$B = (-2, \sqrt{5}, 0)$，$C = (2, \sqrt{5}, 0)$

**第3步：** 求 $N$ 的坐标

$N$ 为 $PC$ 中点：

$$N = \frac{P + C}{2} = \frac{(0, 0, 4) + (2, \sqrt{5}, 0)}{2} = \left(1, \frac{\sqrt{5}}{2}, 2\right)$$

**第4步：** 证明 $MN \parallel$ 平面 $PAB$
> 📌 运用知识点：空间向量与平面的位置关系

$$\overrightarrow{MN} = N - M = \left(1 - 2, \frac{\sqrt{5}}{2}, 2\right) = \left(-1, \frac{\sqrt{5}}{2}, 2\right)$$

平面 $PAB$ 内的向量：$\overrightarrow{AB} = (-2, \sqrt{5}, 0)$，$\overrightarrow{AP} = (0, 0, 4)$。

设平面 $PAB$ 的法向量 $\boldsymbol{n_1} = (a, b, c)$：

$\boldsymbol{n_1} \cdot \overrightarrow{AB} = -2a + \sqrt{5}b = 0$

$\boldsymbol{n_1} \cdot \overrightarrow{AP} = 4c = 0 \implies c = 0$

取 $a = \sqrt{5}$，$b = 2$，$\boldsymbol{n_1} = (\sqrt{5}, 2, 0)$。

验证：$\overrightarrow{MN} \cdot \boldsymbol{n_1} = -\sqrt{5} + \sqrt{5} + 0 = 0$ ✓

$M$ 不在平面 $PAB$ 内（$M = (2, 0, 0)$，代入平面方程 $\sqrt{5}x + 2y = 0$ 得 $2\sqrt{5} \neq 0$）。

所以 $MN \parallel$ 平面 $PAB$。$\blacksquare$

**第5步：** 求平面 $PMN$ 的法向量
> 📌 运用知识点：空间向量运算

$\overrightarrow{PM} = M - P = (2, 0, -4)$

$\overrightarrow{PN} = N - P = \left(1, \frac{\sqrt{5}}{2}, -2\right)$

设法向量 $\boldsymbol{n} = (a, b, c)$：

$\boldsymbol{n} \cdot \overrightarrow{PM} = 2a - 4c = 0 \implies a = 2c$

$\boldsymbol{n} \cdot \overrightarrow{PN} = a + \frac{\sqrt{5}}{2}b - 2c = 0$

代入 $a = 2c$：$2c + \frac{\sqrt{5}}{2}b - 2c = 0 \implies b = 0$

取 $c = 1$，$a = 2$，$\boldsymbol{n} = (2, 0, 1)$。

**第6步：** 求直线 $AN$ 与平面 $PMN$ 所成角

$$\overrightarrow{AN} = N - A = \left(1, \frac{\sqrt{5}}{2}, 2\right)$$

$$\sin\theta = \frac{|\overrightarrow{AN} \cdot \boldsymbol{n}|}{|\overrightarrow{AN}| \cdot |\boldsymbol{n}|}$$

$$\overrightarrow{AN} \cdot \boldsymbol{n} = 2 + 0 + 2 = 4$$

$$|\overrightarrow{AN}| = \sqrt{1 + \frac{5}{4} + 4} = \sqrt{\frac{25}{4}} = \frac{5}{2}$$

$$|\boldsymbol{n}| = \sqrt{4 + 0 + 1} = \sqrt{5}$$

$$\sin\theta = \frac{4}{\frac{5}{2} \times \sqrt{5}} = \frac{4}{\frac{5\sqrt{5}}{2}} = \frac{8}{5\sqrt{5}} = \frac{8\sqrt{5}}{25}$$

**答案：** 直线 $AN$ 与平面 $PMN$ 所成角的正弦值为 $\dfrac{8\sqrt{5}}{25}$。

**⚠️ 易错提醒：** 证明线面平行时，需要验证两点：①向量与法向量垂直；②直线不在平面内。求线面角时用的是 $\sin\theta = \frac{|\overrightarrow{AN} \cdot \boldsymbol{n}|}{|\overrightarrow{AN}||\boldsymbol{n}|}$，不要与线线角混淆。

**💡 解题思路总结：** 空间向量法解立体几何题的步骤：建系→求坐标→求法向量→代入公式。注意建系时要充分利用垂直关系。
