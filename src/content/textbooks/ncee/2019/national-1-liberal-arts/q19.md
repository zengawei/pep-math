**题目：** 某工厂为了对新研发的一种产品进行合理定价，将该产品按事先拟定的价格进行试销售，得到如下数据：

| 单价 $x$（元） | $8$   | $8.2$ | $8.4$ | $8.6$ | $8.8$ | $9$   |
|----------------|-------|-------|-------|-------|-------|-------|
| 销量 $y$（件） | $90$  | $84$  | $83$  | $80$  | $75$  | $68$  |

（1）求回归直线方程 $\hat{y} = \hat{b}x + \hat{a}$；

（2）预计在今后的销售中，销量与单价之间还服从（1）中的关系，且该产品的成本是 $4$ 元/件，为使工厂获得最大利润，该产品的单价应定为多少元？（利润 $=$ 销售收入 $-$ 成本）

---

**解答：**

**第1步：** 计算基本统计量
> 📌 运用知识点：回归分析

$$\bar{x} = \frac{8 + 8.2 + 8.4 + 8.6 + 8.8 + 9}{6} = \frac{51}{6} = 8.5$$

$$\bar{y} = \frac{90 + 84 + 83 + 80 + 75 + 68}{6} = \frac{480}{6} = 80$$

**第2步：** 计算 $\hat{b}$

$$\sum_{i=1}^{6} x_i y_i = 8 \times 90 + 8.2 \times 84 + 8.4 \times 83 + 8.6 \times 80 + 8.8 \times 75 + 9 \times 68$$

$$= 720 + 688.8 + 697.2 + 688 + 660 + 612 = 4066$$

$$\sum_{i=1}^{6} x_i^2 = 64 + 67.24 + 70.56 + 73.96 + 77.44 + 81 = 434.2$$

$$\hat{b} = \frac{\sum x_i y_i - n\bar{x}\bar{y}}{\sum x_i^2 - n\bar{x}^2} = \frac{4066 - 6 \times 8.5 \times 80}{434.2 - 6 \times 8.5^2}$$

$$= \frac{4066 - 4080}{434.2 - 433.5} = \frac{-14}{0.7} = -20$$

**第3步：** 计算 $\hat{a}$

$$\hat{a} = \bar{y} - \hat{b}\bar{x} = 80 - (-20) \times 8.5 = 80 + 170 = 250$$

**第4步：** 写出回归方程

$$\boxed{\hat{y} = -20x + 250}$$

**第5步：** 建立利润函数
> 📌 运用知识点：导数求最值

利润 $L = (x - 4)y = (x - 4)(-20x + 250)$

$$L = -20x^2 + 250x + 80x - 1000 = -20x^2 + 330x - 1000$$

**第6步：** 求利润最大值

$$L' = -40x + 330 = 0$$

$$x = \frac{330}{40} = \frac{33}{4} = 8.25$$

$L'' = -40 < 0$，所以 $x = 8.25$ 时 $L$ 取最大值。

$$\boxed{\text{单价应定为 } 8.25 \text{ 元}}$$

**⚠️ 易错提醒：** 回归直线公式中 $\hat{b}$ 和 $\hat{a}$ 的计算要仔细，注意小数运算的准确性。利润函数是二次函数，也可以用顶点公式求最值。

**💡 解题思路总结：** 统计与导数的综合题：先用回归分析建立线性模型，再利用导数（或二次函数性质）求利润最大值。
