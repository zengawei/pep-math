**题目：** 已知等比数列 $\{a_n\}$ 的各项均为正数，$a_1 = 1$，$a_2 \cdot a_4 = 16$。

（1）求 $\{a_n\}$ 的通项公式；

（2）设 $b_n = \log_2 a_n$，求数列 $\{b_n\}$ 的前 $n$ 项和 $S_n$。

---

**解答：**

**第1步：** 利用等比数列性质求公比
> 📌 运用知识点：等比数列的通项公式

设公比为 $q$（$q > 0$，因为各项均为正数）。

$a_2 = a_1 q = q$，$a_4 = a_1 q^3 = q^3$

$$a_2 \cdot a_4 = q \cdot q^3 = q^4 = 16$$

$$q = 2$$

**第2步：** 写出通项公式

$$\boxed{a_n = a_1 \cdot q^{n-1} = 2^{n-1}}$$

**第3步：** 求 $b_n$
> 📌 运用知识点：对数运算

$$b_n = \log_2 a_n = \log_2 2^{n-1} = n - 1$$

**第4步：** 判断 $\{b_n\}$ 的类型并求和
> 📌 运用知识点：等差数列的前n项和

$b_n = n - 1$，$\{b_n\}$ 是首项为 $0$、公差为 $1$ 的等差数列。

$$S_n = \sum_{k=1}^{n}(k - 1) = 0 + 1 + 2 + \cdots + (n - 1) = \frac{n(n - 1)}{2}$$

$$\boxed{S_n = \frac{n(n - 1)}{2}}$$

**⚠️ 易错提醒：** 等比数列中 $a_2 \cdot a_4 = a_1^2 q^4$，不要算成 $a_1 q^6$。对数运算 $\log_2 2^{n-1} = n - 1$ 要熟练。

**💡 解题思路总结：** 等比数列与对数结合的题目：先求等比数列的通项，再利用对数运算将其转化为等差数列，最后用等差数列求和公式。
