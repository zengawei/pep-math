**题目：** 已知椭圆 $E$：$\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$）的离心率为 $\dfrac{\sqrt{3}}{2}$，点 $\left(1, \dfrac{\sqrt{3}}{2}\right)$ 在椭圆 $E$ 上。

（1）求椭圆 $E$ 的方程；

（2）设 $A$ 为椭圆 $E$ 的右顶点，过点 $T(1, 0)$ 的直线 $l$ 与椭圆 $E$ 交于 $B$、$D$ 两点（$B$、$D$ 不在 $x$ 轴上）。证明：直线 $AB$ 与直线 $AD$ 的斜率之积为定值。

---

**解答：**

**（1）求椭圆方程**

**第1步：** 利用离心率条件
> 📌 运用知识点：ellipse-definition

离心率 $e = \dfrac{c}{a} = \dfrac{\sqrt{3}}{2}$，所以 $c^2 = \dfrac{3}{4}a^2$。

$$b^2 = a^2 - c^2 = a^2 - \frac{3}{4}a^2 = \frac{1}{4}a^2$$

**第2步：** 代入已知点求 $a^2$
> 📌 运用知识点：ellipse-definition

将点 $\left(1, \dfrac{\sqrt{3}}{2}\right)$ 代入椭圆方程：

$$\frac{1}{a^2} + \frac{3}{4b^2} = 1$$

将 $b^2 = \dfrac{a^2}{4}$ 代入：

$$\frac{1}{a^2} + \frac{3}{4 \cdot \dfrac{a^2}{4}} = \frac{1}{a^2} + \frac{3}{a^2} = \frac{4}{a^2} = 1$$

$$a^2 = 4, \quad b^2 = 1$$

$$\boxed{\frac{x^2}{4} + y^2 = 1}$$

**（2）证明斜率之积为定值**

**第3步：** 设定坐标和直线方程
> 📌 运用知识点：conic-section-line

椭圆 $\dfrac{x^2}{4} + y^2 = 1$，右顶点 $A(2, 0)$。

设直线 $l$ 过 $T(1, 0)$。当 $l$ 不垂直于 $x$ 轴时，设 $l: y = k(x - 1)$（$k \neq 0$）。

**第4步：** 联立直线与椭圆方程
> 📌 运用知识点：conic-section-line

将 $y = k(x-1)$ 代入 $\dfrac{x^2}{4} + y^2 = 1$：

$$\frac{x^2}{4} + k^2(x-1)^2 = 1$$

$$x^2 + 4k^2(x^2 - 2x + 1) = 4$$

$$(1 + 4k^2)x^2 - 8k^2 x + 4k^2 - 4 = 0$$

**第5步：** 韦达定理
> 📌 运用知识点：conic-section-line

设 $B(x_1, y_1)$，$D(x_2, y_2)$，则：

$$x_1 + x_2 = \frac{8k^2}{1 + 4k^2}, \quad x_1 x_2 = \frac{4k^2 - 4}{1 + 4k^2}$$

**第6步：** 计算斜率之积的分子
> 📌 运用知识点：conic-section-line

$$y_1 y_2 = k^2(x_1 - 1)(x_2 - 1) = k^2[x_1 x_2 - (x_1 + x_2) + 1]$$

$$= k^2\left[\frac{4k^2 - 4}{1 + 4k^2} - \frac{8k^2}{1 + 4k^2} + 1\right] = k^2 \cdot \frac{4k^2 - 4 - 8k^2 + 1 + 4k^2}{1 + 4k^2} = \frac{-3k^2}{1 + 4k^2}$$

**第7步：** 计算斜率之积的分母
> 📌 运用知识点：conic-section-line

$$(x_1 - 2)(x_2 - 2) = x_1 x_2 - 2(x_1 + x_2) + 4$$

$$= \frac{4k^2 - 4}{1 + 4k^2} - \frac{16k^2}{1 + 4k^2} + \frac{4(1 + 4k^2)}{1 + 4k^2} = \frac{4k^2 - 4 - 16k^2 + 4 + 16k^2}{1 + 4k^2} = \frac{4k^2}{1 + 4k^2}$$

**第8步：** 得出定值
> 📌 运用知识点：conic-section-line

$$k_{AB} \cdot k_{AD} = \frac{y_1}{x_1 - 2} \cdot \frac{y_2}{x_2 - 2} = \frac{y_1 y_2}{(x_1 - 2)(x_2 - 2)} = \frac{\dfrac{-3k^2}{1 + 4k^2}}{\dfrac{4k^2}{1 + 4k^2}} = \frac{-3k^2}{4k^2} = -\frac{3}{4}$$

**第9步：** 讨论特殊情况
> 📌 运用知识点：conic-section-line

当 $l \perp x$ 轴时，$l: x = 1$，代入椭圆得 $y = \pm\dfrac{\sqrt{3}}{2}$。

$$k_{AB} \cdot k_{AD} = \frac{\dfrac{\sqrt{3}}{2}}{1 - 2} \cdot \frac{-\dfrac{\sqrt{3}}{2}}{1 - 2} = \left(-\frac{\sqrt{3}}{2}\right) \times \frac{\sqrt{3}}{2} = -\frac{3}{4}$$

综上，直线 $AB$ 与 $AD$ 的斜率之积恒为定值 $-\dfrac{3}{4}$。$\blacksquare$

$$\boxed{k_{AB} \cdot k_{AD} = -\dfrac{3}{4}}$$

**⚠️ 易错提醒：**
1. 第（1）问中，由 $e = \dfrac{\sqrt{3}}{2}$ 推导 $b^2 = \dfrac{a^2}{4}$ 时，注意 $c^2 = a^2 - b^2$ 的关系。
2. 第（2）问中，联立后要用韦达定理，不要试图解出具体交点坐标。
3. 斜率之积的化简中，分子分母通分要仔细，$(x_1 - 2)(x_2 - 2)$ 展开时注意符号。
4. 不要忘记讨论直线 $l$ 垂直于 $x$ 轴的特殊情况。

**💡 解题思路总结：** 解析几何综合题的核心方法是"设而不求"——设出直线方程和交点坐标，利用韦达定理建立交点坐标间的关系，再代入目标表达式化简。关键是计算细心，善于整体代换简化运算。
