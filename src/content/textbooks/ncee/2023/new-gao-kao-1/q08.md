**题目：** 下列函数中，既是偶函数又在 $(0, +\infty)$ 上单调递减的是（  ）

A. $f(x) = x^2$

B. $f(x) = 2^x$

C. $f(x) = \dfrac{1}{|x|}$

D. $f(x) = \ln|x|$

---

**解答：**

**第1步：** 判断各选项是否为偶函数
> 📌 运用知识点：function-properties

偶函数需满足 $f(-x) = f(x)$。

- **A：** $f(x) = x^2$，$f(-x) = (-x)^2 = x^2 = f(x)$，是偶函数。
- **B：** $f(x) = 2^x$，$f(-x) = 2^{-x} \neq f(x)$，不是偶函数。排除 B。
- **C：** $f(x) = \dfrac{1}{|x|}$，$f(-x) = \dfrac{1}{|-x|} = \dfrac{1}{|x|} = f(x)$，是偶函数。
- **D：** $f(x) = \ln|x|$，$f(-x) = \ln|-x| = \ln|x| = f(x)$，是偶函数。

**第2步：** 在 $(0, +\infty)$ 上判断单调性
> 📌 运用知识点：logarithmic-function

在 $(0, +\infty)$ 上：

- **A：** $f(x) = x^2$，单调递增。❌
- **C：** $f(x) = \dfrac{1}{|x|} = \dfrac{1}{x}$，单调递减。✅
- **D：** $f(x) = \ln|x| = \ln x$，单调递增。❌

综上，满足条件的函数为 $f(x) = \dfrac{1}{|x|}$。

**答案：C**
