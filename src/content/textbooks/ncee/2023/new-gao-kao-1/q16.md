**题目：** 在四棱锥 $P\text{-}ABCD$ 中，底面 $ABCD$ 为矩形，$PC \perp$ 底面 $ABCD$，$PC = 2$，$BC = 4$，$AB = 2$，$M$ 为 $PD$ 的中点。

（1）证明：$BC \perp PD$；

（2）求直线 $AM$ 与平面 $PAB$ 所成角的正弦值。

---

**解答：**

**（1）证明 $BC \perp PD$**

**第1步：** 建立空间直角坐标系
> 📌 运用知识点：space-vector-coordinate

以 $C$ 为原点，$\overrightarrow{CD}$、$\overrightarrow{CB}$、$\overrightarrow{CP}$ 分别为 $x$、$y$、$z$ 轴正方向建立空间直角坐标系。

各点坐标：$C(0,0,0)$，$D(2,0,0)$，$B(0,4,0)$，$A(2,4,0)$，$P(0,0,2)$。

**第2步：** 计算向量点积
> 📌 运用知识点：space-vector-coordinate

$$\overrightarrow{BC} = C - B = (0, -4, 0)$$

$$\overrightarrow{PD} = D - P = (2, 0, -2)$$

$$\overrightarrow{BC} \cdot \overrightarrow{PD} = 0 \times 2 + (-4) \times 0 + 0 \times (-2) = 0$$

所以 $BC \perp PD$。$\blacksquare$

**（2）求直线 $AM$ 与平面 $PAB$ 所成角的正弦值**

**第3步：** 确定相关点和向量
> 📌 运用知识点：space-vector-coordinate

$M$ 为 $PD$ 中点：$M = \dfrac{P + D}{2} = (1, 0, 1)$

$$\overrightarrow{AM} = M - A = (1-2, 0-4, 1-0) = (-1, -4, 1)$$

平面 $PAB$ 中两个不共线向量：

$$\overrightarrow{PA} = A - P = (2, 4, -2), \quad \overrightarrow{PB} = B - P = (0, 4, -2)$$

**第4步：** 求平面 $PAB$ 的法向量
> 📌 运用知识点：space-vector-coordinate

设法向量 $\vec{n} = (a, b, c)$，则：

$$\begin{cases} \vec{n} \cdot \overrightarrow{PA} = 2a + 4b - 2c = 0 \\ \vec{n} \cdot \overrightarrow{PB} = 4b - 2c = 0 \end{cases}$$

由第二式得 $c = 2b$，代入第一式得 $2a + 4b - 4b = 0$，即 $a = 0$。

取 $b = 1$，得 $\vec{n} = (0, 1, 2)$。

**第5步：** 计算线面角的正弦值
> 📌 运用知识点：spatial-angle

设直线 $AM$ 与平面 $PAB$ 所成角为 $\theta$，则：

$$\sin\theta = \frac{|\overrightarrow{AM} \cdot \vec{n}|}{|\overrightarrow{AM}| \cdot |\vec{n}|}$$

计算各量：

$$\overrightarrow{AM} \cdot \vec{n} = (-1)(0) + (-4)(1) + (1)(2) = -2$$

$$|\overrightarrow{AM}| = \sqrt{(-1)^2 + (-4)^2 + 1^2} = \sqrt{18} = 3\sqrt{2}$$

$$|\vec{n}| = \sqrt{0^2 + 1^2 + 2^2} = \sqrt{5}$$

$$\sin\theta = \frac{|-2|}{3\sqrt{2} \times \sqrt{5}} = \frac{2}{3\sqrt{10}} = \frac{2\sqrt{10}}{30} = \frac{\sqrt{10}}{15}$$

$$\boxed{\sin\theta = \dfrac{\sqrt{10}}{15}}$$

**⚠️ 易错提醒：**
1. 建系时确保三条轴两两垂直：$CD \perp CB$（矩形），$PC \perp CD$，$PC \perp CB$（$PC \perp$ 底面）。
2. 线面角的正弦值等于方向向量与法向量夹角余弦的绝对值：$\sin\theta = |\cos\langle\vec{d}, \vec{n}\rangle|$，不要与二面角公式混淆。
3. 求法向量后要验证：$\vec{n} \cdot \overrightarrow{PA} = 0 + 4 - 4 = 0$ ✅，$\vec{n} \cdot \overrightarrow{PB} = 0 + 4 - 4 = 0$ ✅。

**💡 解题思路总结：** 立体几何证明垂直用向量点积为零；求线面角用法向量与方向向量的关系。坐标法的关键是正确建系和准确写出各点坐标。
