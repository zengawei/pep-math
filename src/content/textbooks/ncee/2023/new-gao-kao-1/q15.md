**题目：** 在 $\triangle ABC$ 中，角 $A$，$B$，$C$ 的对边分别为 $a$，$b$，$c$。已知 $b\cos C + c\cos B = 2a\sin A$。

（1）求角 $A$ 的大小；

（2）若 $a = 2$，$b + c = 2\sqrt{3}$，求 $\triangle ABC$ 的面积。

---

**解答：**

**（1）求角 $A$**

**第1步：** 利用正弦定理将边转化为角
> 📌 运用知识点：trig-identity

由正弦定理 $a = 2R\sin A$，$b = 2R\sin B$，$c = 2R\sin C$，代入已知等式：

$$\sin B\cos C + \sin C\cos B = 2\sin^2 A$$

**第2步：** 利用和角公式化简
> 📌 运用知识点：trig-identity

左边 $= \sin(B + C)$。因为 $A + B + C = \pi$，所以 $\sin(B + C) = \sin(\pi - A) = \sin A$。

$$\sin A = 2\sin^2 A$$

$$\sin A(1 - 2\sin A) = 0$$

因为 $A \in (0, \pi)$，$\sin A > 0$，所以 $\sin A = \dfrac{1}{2}$。

$$A = \frac{\pi}{3} \quad \text{或} \quad A = \frac{5\pi}{6}$$

**第3步：** 验证取舍
> 📌 运用知识点：trig-function

若 $A = \dfrac{5\pi}{6}$，由第（2）问条件 $a = 2$，$b + c = 2\sqrt{3}$，利用余弦定理：

$$a^2 = b^2 + c^2 - 2bc\cos\frac{5\pi}{6} = b^2 + c^2 + \sqrt{3}bc$$

$$4 = (b+c)^2 - 2bc + \sqrt{3}bc = 12 + (\sqrt{3} - 2)bc$$

$$bc = \frac{-8}{\sqrt{3} - 2} = \frac{8}{2 - \sqrt{3}} = 8(2 + \sqrt{3}) \approx 29.9$$

但 $bc \leqslant \left(\dfrac{b+c}{2}\right)^2 = 3$，矛盾。故 $A = \dfrac{5\pi}{6}$ 舍去。

$$\boxed{A = \dfrac{\pi}{3}}$$

**（2）求面积**

**第4步：** 利用余弦定理求 $bc$
> 📌 运用知识点：trig-identity

由余弦定理：

$$a^2 = b^2 + c^2 - 2bc\cos A$$

$$4 = b^2 + c^2 - 2bc\cos\frac{\pi}{3} = b^2 + c^2 - bc$$

又 $(b + c)^2 = b^2 + 2bc + c^2 = 12$，所以 $b^2 + c^2 = 12 - 2bc$。

$$4 = 12 - 2bc - bc = 12 - 3bc$$

$$3bc = 8 \implies bc = \frac{8}{3}$$

**第5步：** 计算面积
> 📌 运用知识点：trig-function

$$S_{\triangle ABC} = \frac{1}{2}bc\sin A = \frac{1}{2} \times \frac{8}{3} \times \sin\frac{\pi}{3} = \frac{1}{2} \times \frac{8}{3} \times \frac{\sqrt{3}}{2} = \frac{2\sqrt{3}}{3}$$

$$\boxed{S_{\triangle ABC} = \dfrac{2\sqrt{3}}{3}}$$

**⚠️ 易错提醒：**
1. 利用正弦定理"边化角"时，注意 $\sin(B+C) = \sin A$ 的推导，不要遗漏 $A+B+C = \pi$。
2. $\sin A = \dfrac{1}{2}$ 对应两个可能的角，必须结合题意验证取舍。
3. 利用 $(b+c)^2$ 与 $b^2+c^2$ 的关系求 $bc$ 时，注意 $-2bc\cos\dfrac{\pi}{3} = -bc$ 的化简。

**💡 解题思路总结：** 第（1）问核心是"边化角"后用和角公式简化。第（2）问关键是将余弦定理与完全平方公式结合，通过整体代换求 $bc$，避免分别求 $b$ 和 $c$。
