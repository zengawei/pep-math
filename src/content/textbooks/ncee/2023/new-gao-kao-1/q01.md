**题目：** 已知集合 $A = \{1, 2, 3, 4, 5\}$，$B = \{x \mid x^2 - 3x \leqslant 0\}$，则 $A \cap B = $（  ）

A. $\{1, 2, 3\}$

B. $\{1, 2\}$

C. $\{0, 1, 2, 3\}$

D. $\{0, 1, 2\}$

---

**解答：**

**第1步：** 求解集合 $B$
> 📌 运用知识点：set-operations

解不等式 $x^2 - 3x \leqslant 0$：

$$x(x - 3) \leqslant 0$$

解得 $0 \leqslant x \leqslant 3$。

所以 $B = \{x \mid 0 \leqslant x \leqslant 3\} = [0, 3]$。

**第2步：** 求 $A \cap B$
> 📌 运用知识点：set-operations

$A = \{1, 2, 3, 4, 5\}$，$B = [0, 3]$。

$A$ 中满足 $0 \leqslant x \leqslant 3$ 的元素为 $1, 2, 3$。

$$A \cap B = \{1, 2, 3\}$$

**答案：A**
