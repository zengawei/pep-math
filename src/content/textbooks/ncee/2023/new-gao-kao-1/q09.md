**题目：** 已知 $\cos(\alpha + \beta) = \dfrac{1}{2}$，$\cos(\alpha - \beta) = \dfrac{1}{2}$，则下列结论一定正确的是（  ）

A. $\sin(2\alpha) + \sin(2\beta) = \dfrac{\sqrt{3}}{2}$

B. $\cos(2\alpha) + \cos(2\beta) = \dfrac{1}{2}$

C. $\cos(2\alpha) - \cos(2\beta) = 0$

D. $\cos^2\alpha - \sin^2\beta = \dfrac{1}{4}$

---

**解答：**

**第1步：** 验证 A 选项
> 📌 运用知识点：trig-identity

利用和差化积公式：

$$\sin(2\alpha) + \sin(2\beta) = 2\sin(\alpha + \beta)\cos(\alpha - \beta)$$

由 $\cos(\alpha + \beta) = \dfrac{1}{2}$，得 $\sin(\alpha + \beta) = \pm\dfrac{\sqrt{3}}{2}$。

$$\sin(2\alpha) + \sin(2\beta) = 2 \times \left(\pm\frac{\sqrt{3}}{2}\right) \times \frac{1}{2} = \pm\frac{\sqrt{3}}{2}$$

结果不是确定值，A 不一定正确。❌

**第2步：** 验证 B 选项
> 📌 运用知识点：trig-identity

利用和差化积公式：

$$\cos(2\alpha) + \cos(2\beta) = 2\cos(\alpha + \beta)\cos(\alpha - \beta) = 2 \times \frac{1}{2} \times \frac{1}{2} = \frac{1}{2}$$

B 正确。✅

**第3步：** 验证 C 选项
> 📌 运用知识点：trig-identity

$$\cos(2\alpha) - \cos(2\beta) = -2\sin(\alpha + \beta)\sin(\alpha - \beta)$$

由 $\cos(\alpha - \beta) = \dfrac{1}{2}$，得 $\sin(\alpha - \beta) = \pm\dfrac{\sqrt{3}}{2}$。

$$\cos(2\alpha) - \cos(2\beta) = -2 \times \left(\pm\frac{\sqrt{3}}{2}\right) \times \left(\pm\frac{\sqrt{3}}{2}\right)$$

结果不确定（可能为 $\pm\dfrac{3}{2}$ 或 $0$，取决于符号组合），C 不一定正确。❌

**第4步：** 验证 D 选项
> 📌 运用知识点：trig-identity

利用积化和差公式：

$$\cos(\alpha + \beta)\cos(\alpha - \beta) = \frac{1}{2}[\cos(2\alpha) + \cos(2\beta)]$$

展开左边：

$$\cos(\alpha+\beta)\cos(\alpha-\beta) = (\cos\alpha\cos\beta - \sin\alpha\sin\beta)(\cos\alpha\cos\beta + \sin\alpha\sin\beta)$$
$$= \cos^2\alpha\cos^2\beta - \sin^2\alpha\sin^2\beta = \cos^2\alpha - \sin^2\beta$$

因此：

$$\cos^2\alpha - \sin^2\beta = \cos(\alpha+\beta)\cos(\alpha-\beta) = \frac{1}{2} \times \frac{1}{2} = \frac{1}{4}$$

D 正确。✅

**答案：B、D**
