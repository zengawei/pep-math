**题目：** 甲、乙、丙三人参加体能测试，达标的概率分别为 $0.6$，$0.5$，$0.6$，且三人是否达标相互独立。设事件 $A$ = "甲达标"，$B$ = "乙达标"，$C$ = "丙达标"，则下列结论正确的是（  ）

A. $P(A|\bar{B}) = \dfrac{3}{5}$

B. $P(\overline{A \cup B}) = 0.2$

C. $P(A \cup B \cup C) = 0.96$

D. $P(A|A \cup B) = \dfrac{3}{4}$

---

**解答：**

**第1步：** 验证 A 选项
> 📌 运用知识点：event-independence

$A$ 与 $B$ 独立，故 $A$ 与 $\bar{B}$ 也独立。

$$P(A|\bar{B}) = \frac{P(A \cap \bar{B})}{P(\bar{B})} = \frac{P(A) \cdot P(\bar{B})}{P(\bar{B})} = P(A) = 0.6 = \frac{3}{5} \quad ✅$$

**第2步：** 验证 B 选项
> 📌 运用知识点：probability-addition-multiplication

$$P(\overline{A \cup B}) = P(\bar{A} \cap \bar{B}) = P(\bar{A}) \cdot P(\bar{B}) = (1 - 0.6)(1 - 0.5) = 0.4 \times 0.5 = 0.2 \quad ✅$$

**第3步：** 验证 C 选项
> 📌 运用知识点：probability-addition-multiplication

$$P(A \cup B \cup C) = 1 - P(\bar{A})P(\bar{B})P(\bar{C}) = 1 - 0.4 \times 0.5 \times 0.4 = 1 - 0.08 = 0.92$$

$0.92 \neq 0.96$，C 不正确。❌

**第4步：** 验证 D 选项
> 📌 运用知识点：event-independence

因为 $A \subset (A \cup B)$，所以 $A \cap (A \cup B) = A$。

$$P(A|A \cup B) = \frac{P(A)}{P(A \cup B)} = \frac{P(A)}{1 - P(\overline{A \cup B})} = \frac{0.6}{1 - 0.2} = \frac{0.6}{0.8} = \frac{3}{4} \quad ✅$$

**答案：A、B、D**
