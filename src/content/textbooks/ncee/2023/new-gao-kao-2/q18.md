**题目：**（17分）

已知椭圆 $E: \dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$）的右焦点到原点的距离为 $1$，离心率为 $\dfrac{1}{2}$。

（1）求椭圆 $E$ 的方程；

（2）设右焦点为 $F_2$，过 $F_2$ 的直线 $l$ 交椭圆 $E$ 于 $A$、$B$ 两点，$P(4, 0)$，求 $\triangle ABP$ 面积的最大值。

---

**解答：**

**第1步：** 利用已知条件求 $a$、$b$、$c$
> 📌 运用知识点：ellipse-definition

右焦点到原点的距离为 $c = 1$。

离心率 $e = \dfrac{c}{a} = \dfrac{1}{2}$，所以 $a = 2c = 2$。

$$b^2 = a^2 - c^2 = 4 - 1 = 3$$

**第2步：** 写出椭圆方程
> 📌 运用知识点：ellipse-properties

$$\frac{x^2}{4} + \frac{y^2}{3} = 1$$

**第3步：** 设直线 $l$ 的方程并联立
> 📌 运用知识点：conic-section-line

右焦点 $F_2(1, 0)$。设直线 $l: x = my + 1$（此形式可包含斜率不存在的情况）。

代入椭圆方程：

$$\frac{(my+1)^2}{4} + \frac{y^2}{3} = 1$$

两边乘以 $12$：

$$3(my+1)^2 + 4y^2 = 12$$

$$3m^2y^2 + 6my + 3 + 4y^2 = 12$$

$$(3m^2 + 4)y^2 + 6my - 9 = 0$$

**第4步：** 利用韦达定理
> 📌 运用知识点：conic-section-line

设 $A(x_1, y_1)$，$B(x_2, y_2)$，则：

$$y_1 + y_2 = \frac{-6m}{3m^2 + 4}, \quad y_1 y_2 = \frac{-9}{3m^2 + 4}$$

**第5步：** 计算 $|AB|$
> 📌 运用知识点：conic-section-line

$$|y_1 - y_2|^2 = (y_1 + y_2)^2 - 4y_1 y_2 = \frac{36m^2}{(3m^2+4)^2} + \frac{36}{3m^2+4} = \frac{36m^2 + 36(3m^2+4)}{(3m^2+4)^2} = \frac{144(m^2+1)}{(3m^2+4)^2}$$

因为 $x_1 - x_2 = m(y_1 - y_2)$：

$$|AB|^2 = (1+m^2)|y_1-y_2|^2 = \frac{144(m^2+1)^2}{(3m^2+4)^2}$$

$$|AB| = \frac{12(m^2+1)}{3m^2+4}$$

**第6步：** 计算 $P$ 到直线 $l$ 的距离
> 📌 运用知识点：conic-section-line

直线 $l: x - my - 1 = 0$，$P(4, 0)$ 到 $l$ 的距离：

$$d = \frac{|4 - 0 - 1|}{\sqrt{1 + m^2}} = \frac{3}{\sqrt{1+m^2}}$$

**第7步：** 表示面积并求最大值
> 📌 运用知识点：conic-section-optimization

$$S = \frac{1}{2}|AB| \cdot d = \frac{1}{2} \cdot \frac{12(m^2+1)}{3m^2+4} \cdot \frac{3}{\sqrt{m^2+1}} = \frac{18\sqrt{m^2+1}}{3m^2+4}$$

令 $t = \sqrt{m^2+1} \geqslant 1$，则 $m^2 = t^2 - 1$：

$$S = \frac{18t}{3(t^2-1)+4} = \frac{18t}{3t^2+1}$$

对 $S(t)$ 求导：

$$S'(t) = \frac{18(3t^2+1) - 18t \cdot 6t}{(3t^2+1)^2} = \frac{18(1 - 3t^2)}{(3t^2+1)^2}$$

当 $t \geqslant 1$ 时，$1 - 3t^2 \leqslant 1 - 3 = -2 < 0$，所以 $S'(t) < 0$，$S(t)$ 在 $[1, +\infty)$ 上单调递减。

因此 $S$ 在 $t = 1$（即 $m = 0$）时取最大值：

$$S_{\max} = \frac{18 \times 1}{3 \times 1 + 1} = \frac{18}{4} = \frac{9}{2}$$

当 $m = 0$ 时，直线 $l$ 为 $x = 1$（垂直于 $x$ 轴），此时 $A$、$B$ 的纵坐标满足 $\dfrac{1}{4} + \dfrac{y^2}{3} = 1$，$y^2 = \dfrac{9}{4}$，$y = \pm\dfrac{3}{2}$，$|AB| = 3$。

验证：$S = \dfrac{1}{2} \times 3 \times 3 = \dfrac{9}{2}$ ✓

**⚠️ 易错提醒：**
1. 设直线方程时用 $x = my + 1$ 而非 $y = k(x-1)$，前者可以包含斜率不存在（即直线垂直于 $x$ 轴）的情况，避免漏解。
2. 换元 $t = \sqrt{m^2+1} \geqslant 1$ 时，注意 $t$ 的取值范围，不能忽略 $t \geqslant 1$ 的约束。
3. 利用导数判断单调性时，注意 $S'(t)$ 的符号分析，在 $t \geqslant 1$ 上恒为负，所以最大值在端点取得。

**💡 解题思路总结：** 解析几何综合题的核心策略是"设而不求"。第一问利用椭圆基本量关系求方程；第二问的关键步骤是：设直线→联立椭圆→韦达定理→表示弦长和距离→建立面积函数→求最值。面积最值的求解中，通过换元将问题转化为单变量函数的最值，再利用导数判断单调性。

**答案：**（1）$\dfrac{x^2}{4} + \dfrac{y^2}{3} = 1$；（2）$S_{\max} = \dfrac{9}{2}$
