**题目：**（15分）

如图，在三棱柱 $ABC\text{-}A_1B_1C_1$ 中，$CA \perp CB$，$CA = CB = CC_1 = 2$，侧面 $BCC_1B_1$ 为矩形，$E$ 为 $A_1B_1$ 的中点。

（1）求直线 $CE$ 与 $A_1C$ 所成角的余弦值；

（2）$D$ 为棱 $BB_1$ 上的动点，设 $BD = t$（$0 \leqslant t \leqslant 2$），求平面 $CA_1D$ 与平面 $CA_1B_1$ 所成二面角的正弦值（用 $t$ 表示）。

---

**解答：**

**第1步：** 建立空间直角坐标系
> 📌 运用知识点：space-vector-coordinate

因为 $CA \perp CB$，且侧面 $BCC_1B_1$ 为矩形（即 $CC_1 \perp$ 底面 $ABC$），所以 $CA$、$CB$、$CC_1$ 两两垂直。

以 $C$ 为原点，$\vec{CA}$、$\vec{CB}$、$\vec{CC_1}$ 的方向分别为 $x$、$y$、$z$ 轴正方向，建立空间直角坐标系。

各点坐标为：
$$C(0,0,0),\quad A(2,0,0),\quad B(0,2,0),\quad A_1(2,0,2),\quad B_1(0,2,2),\quad C_1(0,0,2)$$

$E$ 为 $A_1B_1$ 的中点：

$$E = \left(\frac{2+0}{2},\, \frac{0+2}{2},\, \frac{2+2}{2}\right) = (1, 1, 2)$$

**第2步：** 求直线 $CE$ 与 $A_1C$ 所成角的余弦值
> 📌 运用知识点：spatial-angle

$$\vec{CE} = (1, 1, 2),\quad \vec{A_1C} = (0-2,\, 0-0,\, 0-2) = (-2, 0, -2)$$

$$\vec{CE} \cdot \vec{A_1C} = 1 \times (-2) + 1 \times 0 + 2 \times (-2) = -6$$

$$|\vec{CE}| = \sqrt{1^2 + 1^2 + 2^2} = \sqrt{6}$$

$$|\vec{A_1C}| = \sqrt{(-2)^2 + 0^2 + (-2)^2} = \sqrt{8} = 2\sqrt{2}$$

直线所成角 $\theta$ 的余弦值（取绝对值）：

$$\cos\theta = \frac{|\vec{CE} \cdot \vec{A_1C}|}{|\vec{CE}| \cdot |\vec{A_1C}|} = \frac{6}{\sqrt{6} \times 2\sqrt{2}} = \frac{6}{2\sqrt{12}} = \frac{6}{4\sqrt{3}} = \frac{3}{2\sqrt{3}} = \frac{\sqrt{6}}{6}$$

**第3步：** 设 $D$ 的坐标
> 📌 运用知识点：space-vector-coordinate

$D$ 在棱 $BB_1$ 上，$B(0,2,0)$，$B_1(0,2,2)$，$BD = t$，所以 $D = (0, 2, t)$，其中 $0 \leqslant t \leqslant 2$。

**第4步：** 求平面 $CA_1D$ 的法向量 $\vec{n_1}$
> 📌 运用知识点：space-vector-operations

$$\vec{CA_1} = (2, 0, 2),\quad \vec{CD} = (0, 2, t)$$

设法向量 $\vec{n_1} = (a, b, c)$，则：

$$\begin{cases} \vec{n_1} \cdot \vec{CA_1} = 2a + 2c = 0 \\ \vec{n_1} \cdot \vec{CD} = 2b + tc = 0 \end{cases}$$

由第一式：$a = -c$。由第二式：$b = -\dfrac{tc}{2}$。

取 $c = -2$，则 $a = 2$，$b = t$。所以 $\vec{n_1} = (2, t, -2)$。

**第5步：** 求平面 $CA_1B_1$ 的法向量 $\vec{n_2}$
> 📌 运用知识点：space-vector-operations

$$\vec{CA_1} = (2, 0, 2),\quad \vec{CB_1} = (0, 2, 2)$$

设法向量 $\vec{n_2} = (a, b, c)$，则：

$$\begin{cases} 2a + 2c = 0 \\ 2b + 2c = 0 \end{cases} \implies a = -c,\; b = -c$$

取 $c = 1$，则 $\vec{n_2} = (-1, -1, 1)$。

**第6步：** 求二面角的正弦值
> 📌 运用知识点：space-vector-fundamental-theorem

$$\vec{n_1} \cdot \vec{n_2} = 2 \times (-1) + t \times (-1) + (-2) \times 1 = -2 - t - 2 = -(4 + t)$$

$$|\vec{n_1}| = \sqrt{4 + t^2 + 4} = \sqrt{t^2 + 8}$$

$$|\vec{n_2}| = \sqrt{1 + 1 + 1} = \sqrt{3}$$

设二面角为 $\alpha$，则：

$$\cos\alpha = \frac{|\vec{n_1} \cdot \vec{n_2}|}{|\vec{n_1}| \cdot |\vec{n_2}|} = \frac{4 + t}{\sqrt{3} \cdot \sqrt{t^2 + 8}}$$

（因为 $0 \leqslant t \leqslant 2$，所以 $4 + t > 0$。）

$$\sin\alpha = \sqrt{1 - \cos^2\alpha} = \sqrt{1 - \frac{(4+t)^2}{3(t^2+8)}}$$

$$= \sqrt{\frac{3(t^2+8) - (4+t)^2}{3(t^2+8)}} = \sqrt{\frac{3t^2 + 24 - 16 - 8t - t^2}{3(t^2+8)}} = \sqrt{\frac{2t^2 - 8t + 8}{3(t^2+8)}}$$

$$= \sqrt{\frac{2(t-2)^2}{3(t^2+8)}} = \frac{(2-t)\sqrt{2}}{\sqrt{3(t^2+8)}}$$

（因为 $0 \leqslant t \leqslant 2$，所以 $|t - 2| = 2 - t$。）

**⚠️ 易错提醒：**
1. 建立坐标系时必须验证三条轴两两垂直——本题中 $CA \perp CB$ 是已知条件，$CC_1 \perp$ 底面由矩形侧面保证。
2. 求法向量时注意检验：法向量应与平面内两个不共线向量都垂直，代入点积验证。
3. 直线所成角取余弦的绝对值，二面角的正弦值需注意化简根号内的表达式。

**💡 解题思路总结：** 本题的关键是正确建立空间直角坐标系。由于 $CA$、$CB$、$CC_1$ 两两垂直，以 $C$ 为原点建系最为自然。第一问直接用向量夹角公式求直线所成角（注意取绝对值）；第二问设出动点参数 $t$，分别求两个平面的法向量，再利用法向量夹角公式表示二面角的正弦值。

**答案：**（1）$\dfrac{\sqrt{6}}{6}$；（2）$\sin\alpha = \dfrac{(2-t)\sqrt{2}}{\sqrt{3(t^2+8)}}$（$0 \leqslant t \leqslant 2$）
