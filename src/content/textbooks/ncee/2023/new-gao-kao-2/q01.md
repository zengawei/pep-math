**题目：** 已知集合 $A = \{x \mid x^2 - 3x < 0\}$，$B = \{-1, 0, 1, 2, 3\}$，则 $A \cap B = $（ ）

A. $\{1, 2\}$

B. $\{0, 1, 2\}$

C. $\{1, 2, 3\}$

D. $\{-1, 0, 1\}$

---

**解答：**

**第1步：** 求解集合 $A$
> 📌 运用知识点：set-operations

解不等式 $x^2 - 3x < 0$：

$$x(x - 3) < 0$$

因为 $x$ 与 $(x-3)$ 异号，且 $x < x - 3$ 不成立，所以 $x > 0$ 且 $x - 3 < 0$，即 $0 < x < 3$。

所以 $A = (0, 3)$。

**第2步：** 求 $A \cap B$
> 📌 运用知识点：set-operations

$B = \{-1, 0, 1, 2, 3\}$，逐一检验 $B$ 中元素是否属于 $A = (0, 3)$：

- $-1 \notin (0, 3)$
- $0 \notin (0, 3)$（开区间不含端点）
- $1 \in (0, 3)$ ✓
- $2 \in (0, 3)$ ✓
- $3 \notin (0, 3)$（开区间不含端点）

所以 $A \cap B = \{1, 2\}$。

**答案：A**
