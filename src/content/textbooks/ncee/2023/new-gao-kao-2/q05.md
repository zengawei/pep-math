**题目：** 已知等比数列 $\{a_n\}$ 满足 $a_1 + a_2 = 3$，$a_2 + a_3 = 6$，则 $S_4 = $（ ）

A. $15$

B. $12$

C. $10$

D. $7$

---

**解答：**

**第1步：** 求公比 $q$
> 📌 运用知识点：geometric-sequence

设等比数列的公比为 $q$，则：

$$\frac{a_2 + a_3}{a_1 + a_2} = \frac{a_1 q + a_1 q^2}{a_1 + a_1 q} = \frac{a_1 q(1 + q)}{a_1(1 + q)} = q$$

所以：

$$q = \frac{6}{3} = 2$$

**第2步：** 求首项 $a_1$
> 📌 运用知识点：geometric-sequence

由 $a_1 + a_2 = a_1(1 + q) = 3$：

$$a_1(1 + 2) = 3 \implies a_1 = 1$$

**第3步：** 计算 $S_4$
> 📌 运用知识点：geometric-sequence-sum

$$S_4 = \frac{a_1(1 - q^4)}{1 - q} = \frac{1 \times (1 - 16)}{1 - 2} = \frac{-15}{-1} = 15$$

**答案：A**
