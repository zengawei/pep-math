**题目：** 已知复数 $z = \dfrac{1 + 3i}{1 - i}$（其中 $i$ 为虚数单位），则 $z$ 在复平面内对应的点位于（ ）

A. 第一象限

B. 第二象限

C. 第三象限

D. 第四象限

---

**解答：**

**第1步：** 化简复数 $z$
> 📌 运用知识点：complex-number-operations

分子分母同乘以分母的共轭复数 $1 + i$：

$$z = \frac{1 + 3i}{1 - i} \cdot \frac{1 + i}{1 + i} = \frac{(1 + 3i)(1 + i)}{(1 - i)(1 + i)}$$

**第2步：** 计算分子和分母
> 📌 运用知识点：complex-number-operations

分母：$(1 - i)(1 + i) = 1 - i^2 = 1 - (-1) = 2$

分子：$(1 + 3i)(1 + i) = 1 + i + 3i + 3i^2 = 1 + 4i + 3(-1) = -2 + 4i$

所以：

$$z = \frac{-2 + 4i}{2} = -1 + 2i$$

**第3步：** 判断象限
> 📌 运用知识点：complex-number-concept

$z = -1 + 2i$ 对应的点为 $(-1, 2)$，实部为 $-1 < 0$，虚部为 $2 > 0$，位于第二象限。

**答案：B**
