**题目：** 函数 $f(x) = \sin\left(2x - \dfrac{\pi}{6}\right)$ 的图像的一条对称轴为

A. $x = \dfrac{\pi}{12}$

B. $x = \dfrac{5\pi}{12}$

C. $x = \dfrac{\pi}{6}$

D. $x = \dfrac{\pi}{3}$

---

**解答：**

**第1步：** 确定正弦函数对称轴的条件
> 📌 运用知识点：三角函数图像的对称性

正弦函数 $y = \sin u$ 的对称轴满足 $u = k\pi + \dfrac{\pi}{2}$（$k \in \mathbb{Z}$），即函数取最大值或最小值时的位置。

**第2步：** 令 $2x - \dfrac{\pi}{6} = k\pi + \dfrac{\pi}{2}$

$$2x = k\pi + \frac{\pi}{2} + \frac{\pi}{6} = k\pi + \frac{3\pi}{6} + \frac{\pi}{6} = k\pi + \frac{4\pi}{6} = k\pi + \frac{2\pi}{3}$$

$$x = \frac{k\pi}{2} + \frac{\pi}{3}$$

**第3步：** 代入不同的 $k$ 值

- $k = 0$：$x = \dfrac{\pi}{3}$
- $k = -1$：$x = -\dfrac{\pi}{2} + \dfrac{\pi}{3} = -\dfrac{\pi}{6}$
- $k = 1$：$x = \dfrac{\pi}{2} + \dfrac{\pi}{3} = \dfrac{5\pi}{6}$

在选项中，$x = \dfrac{\pi}{3}$ 对应选项 D。

验证：$f\left(\dfrac{\pi}{3}\right) = \sin\left(\dfrac{2\pi}{3} - \dfrac{\pi}{6}\right) = \sin\left(\dfrac{\pi}{2}\right) = 1$（取最大值，确为对称轴）。

**答案：D**

**⚠️ 易错提醒：** 正弦函数的对称轴是函数取最值（$\pm 1$）的位置，不是零点位置。零点位置是对称中心的横坐标，不要混淆。

**💡 解题思路总结：** 求 $y = \sin(\omega x + \varphi)$ 的对称轴，令 $\omega x + \varphi = k\pi + \dfrac{\pi}{2}$，解出 $x$，再与选项对照。
