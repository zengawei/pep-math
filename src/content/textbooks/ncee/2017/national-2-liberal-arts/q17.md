**题目：** 在 $\triangle ABC$ 中，角 $A, B, C$ 的对边分别为 $a, b, c$，已知 $a = 2$，$b = 3$，$\cos C = \dfrac{1}{4}$。

（1）求 $c$ 的值；

（2）求 $\sin A$ 的值。

---

**解答：**

**（1）求 $c$ 的值**

**第1步：** 利用余弦定理
> 📌 运用知识点：余弦定理

$$c^2 = a^2 + b^2 - 2ab\cos C$$

$$c^2 = 2^2 + 3^2 - 2 \times 2 \times 3 \times \frac{1}{4}$$

$$c^2 = 4 + 9 - 3 = 10$$

$$c = \sqrt{10}$$

**（2）求 $\sin A$ 的值**

**第2步：** 求 $\sin C$

$$\sin C = \sqrt{1 - \cos^2 C} = \sqrt{1 - \frac{1}{16}} = \sqrt{\frac{15}{16}} = \frac{\sqrt{15}}{4}$$

**第3步：** 利用正弦定理
> 📌 运用知识点：正弦定理

$$\frac{a}{\sin A} = \frac{c}{\sin C}$$

$$\sin A = \frac{a \sin C}{c} = \frac{2 \times \dfrac{\sqrt{15}}{4}}{\sqrt{10}} = \frac{\dfrac{\sqrt{15}}{2}}{\sqrt{10}} = \frac{\sqrt{15}}{2\sqrt{10}} = \frac{\sqrt{15}}{2\sqrt{10}} \times \frac{\sqrt{10}}{\sqrt{10}} = \frac{\sqrt{150}}{20} = \frac{5\sqrt{6}}{20} = \frac{\sqrt{6}}{4}$$

**答案：**（1）$c = \sqrt{10}$；（2）$\sin A = \dfrac{\sqrt{6}}{4}$

**⚠️ 易错提醒：** ①余弦定理中 $2ab\cos C$ 不要漏掉系数 $2$。②$\sin C$ 取正值（因为 $C \in (0, \pi)$）。③化简 $\dfrac{\sqrt{15}}{2\sqrt{10}}$ 时需要有理化分母，$\sqrt{150} = \sqrt{25 \times 6} = 5\sqrt{6}$。

**💡 解题思路总结：** 已知两边及夹角，先用余弦定理求第三边，再用正弦定理求角的正弦值。这是解三角形问题的基本思路。
