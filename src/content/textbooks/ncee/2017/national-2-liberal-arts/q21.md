**题目：** 已知抛物线 $C: y^2 = 4x$ 的焦点为 $F$，过 $F$ 的直线 $l$ 交 $C$ 于 $A, B$ 两点。

（1）若 $|AF| = 3|BF|$，求直线 $l$ 的斜率；

（2）求 $|AF| \cdot |BF|$ 的最小值。

---

**解答：**

**（1）求直线 $l$ 的斜率**

**第1步：** 确定焦点坐标
> 📌 运用知识点：抛物线的标准方程

抛物线 $y^2 = 4x$ 中，$2p = 4$，$p = 2$，焦点 $F(1, 0)$。

**第2步：** 设直线方程并联立

设直线 $l: x = my + 1$（过焦点 $(1, 0)$），代入 $y^2 = 4x$：

$$y^2 = 4(my + 1) \implies y^2 - 4my - 4 = 0$$

设 $A(x_1, y_1)$，$B(x_2, y_2)$，由韦达定理：

$$y_1 + y_2 = 4m, \quad y_1 y_2 = -4$$

**第3步：** 利用焦半径公式
> 📌 运用知识点：抛物线的焦半径

抛物线上一点 $(x_0, y_0)$ 到焦点的距离为 $|PF| = x_0 + \dfrac{p}{2} = x_0 + 1$。

$$|AF| = x_1 + 1 = my_1 + 2, \quad |BF| = x_2 + 1 = my_2 + 2$$

**第4步：** 由 $|AF| = 3|BF|$ 列方程

$$my_1 + 2 = 3(my_2 + 2) \implies my_1 - 3my_2 = 4 \implies m(y_1 - 3y_2) = 4$$

由 $y_1 = 4m - y_2$ 代入：

$$m(4m - 4y_2) = 4 \implies m(m - y_2) = 1 \implies y_2 = m - \frac{1}{m}$$

$$y_1 = 4m - y_2 = 3m + \frac{1}{m}$$

**第5步：** 利用 $y_1 y_2 = -4$

$$\left(3m + \frac{1}{m}\right)\left(m - \frac{1}{m}\right) = -4$$

$$3m^2 - 3 + 1 - \frac{1}{m^2} = -4 \implies 3m^2 - \frac{1}{m^2} = -2$$

设 $t = m^2 > 0$：

$$3t^2 + 2t - 1 = 0 \implies (3t - 1)(t + 1) = 0 \implies t = \frac{1}{3}$$

$$m^2 = \frac{1}{3} \implies m = \pm\frac{1}{\sqrt{3}}$$

$$k = \frac{1}{m} = \pm\sqrt{3}$$

**（2）求 $|AF| \cdot |BF|$ 的最小值**

**第6步：** 计算 $|AF| \cdot |BF|$

$$|AF| \cdot |BF| = (my_1 + 2)(my_2 + 2) = m^2 y_1 y_2 + 2m(y_1 + y_2) + 4$$

代入韦达定理的结果：

$$= m^2 \times (-4) + 2m \times 4m + 4 = -4m^2 + 8m^2 + 4 = 4m^2 + 4$$

**第7步：** 求最小值

$$|AF| \cdot |BF| = 4m^2 + 4 \geqslant 4$$

当 $m = 0$（即直线 $l$ 垂直于 $x$ 轴）时取等号。

此时直线 $l: x = 1$，$A(1, 2)$，$B(1, -2)$，$|AF| = |BF| = 2$，$|AF| \cdot |BF| = 4$。✓

**答案：**（1）$k = \pm\sqrt{3}$；（2）$|AF| \cdot |BF|$ 的最小值为 $4$

**⚠️ 易错提醒：** ①焦半径公式 $|PF| = x_0 + \dfrac{p}{2}$，不要与到准线的距离混淆（两者相等）。②利用韦达定理时，注意 $y_1 y_2 = -4 < 0$，说明 $y_1, y_2$ 异号，即 $A, B$ 在 $x$ 轴两侧。③解关于 $m^2$ 的方程时，注意舍去负根。

**💡 解题思路总结：** 抛物线焦点弦问题的核心工具：①焦半径公式；②联立直线与抛物线方程后用韦达定理。求最值时，将目标表达式化为关于参数 $m$ 的函数，利用二次函数性质求最值。
