**题目：**

已知椭圆 $C: \dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$）的左焦点为 $F_1(-1, 0)$，右焦点为 $F_2(1, 0)$，且椭圆过点 $\left(1, \dfrac{3}{2}\right)$。

（1）求椭圆 $C$ 的方程；

（2）过点 $F_2$ 的直线 $l$ 与椭圆 $C$ 交于 $A$，$B$ 两点，求 $\triangle F_1AB$ 面积的最大值。

---

**解答：**

**（1）**

**第1步:** 确定 $c$

$c = 1$（焦点到原点的距离）。

> 📌 运用知识点：椭圆的性质

**第2步:** 利用椭圆定义求 $a$

点 $\left(1, \dfrac{3}{2}\right)$ 到两焦点的距离之和等于 $2a$：

$$|PF_1| = \sqrt{(1+1)^2 + \left(\frac{3}{2}\right)^2} = \sqrt{4 + \frac{9}{4}} = \sqrt{\frac{25}{4}} = \frac{5}{2}$$

$$|PF_2| = \sqrt{(1-1)^2 + \left(\frac{3}{2}\right)^2} = \frac{3}{2}$$

$$2a = |PF_1| + |PF_2| = \frac{5}{2} + \frac{3}{2} = 4 \implies a = 2$$

$$b^2 = a^2 - c^2 = 4 - 1 = 3$$

椭圆方程为 $\dfrac{x^2}{4} + \dfrac{y^2}{3} = 1$。

> 📌 运用知识点：椭圆的性质

**（2）**

**第3步:** 设直线方程

过 $F_2(1, 0)$ 的直线 $l$。

当 $l$ 斜率存在时，设 $l: y = k(x - 1)$。

代入椭圆方程：

$$\frac{x^2}{4} + \frac{k^2(x-1)^2}{3} = 1$$

$$3x^2 + 4k^2(x-1)^2 = 12$$

$$(3 + 4k^2)x^2 - 8k^2 x + 4k^2 - 12 = 0$$

由韦达定理：

$$x_1 + x_2 = \frac{8k^2}{3 + 4k^2}, \quad x_1 x_2 = \frac{4k^2 - 12}{3 + 4k^2}$$

> 📌 运用知识点：圆锥曲线与直线

**第4步:** 求面积

$F_1(-1, 0)$ 到直线 $l: kx - y - k = 0$ 的距离：

$$d = \frac{|k(-1) - 0 - k|}{\sqrt{k^2 + 1}} = \frac{2|k|}{\sqrt{k^2 + 1}}$$

$$|AB| = \sqrt{1+k^2} \cdot |x_1 - x_2|$$

$$(x_1 - x_2)^2 = (x_1+x_2)^2 - 4x_1 x_2 = \frac{64k^4}{(3+4k^2)^2} - \frac{4(4k^2-12)}{3+4k^2} = \frac{64k^4 - 4(4k^2-12)(3+4k^2)}{(3+4k^2)^2}$$

$$= \frac{64k^4 - 4(12k^2 + 16k^4 - 36 - 48k^2)}{(3+4k^2)^2} = \frac{64k^4 - 64k^4 + 144k^2 + 144}{(3+4k^2)^2} = \frac{144(k^2+1)}{(3+4k^2)^2}$$

$$|AB| = \sqrt{1+k^2} \cdot \frac{12\sqrt{k^2+1}}{3+4k^2} = \frac{12(k^2+1)}{3+4k^2}$$

$$S = \frac{1}{2} |AB| \cdot d = \frac{1}{2} \cdot \frac{12(k^2+1)}{3+4k^2} \cdot \frac{2|k|}{\sqrt{k^2+1}} = \frac{12|k|\sqrt{k^2+1}}{3+4k^2}$$

> 📌 运用知识点：圆锥曲线与直线

**第5步:** 求最大值

令 $t = k^2 > 0$：

$$S^2 = \frac{144t(t+1)}{(3+4t)^2}$$

设 $g(t) = \dfrac{t(t+1)}{(3+4t)^2} = \dfrac{t^2+t}{16t^2+24t+9}$。

$$g'(t) = \frac{(2t+1)(16t^2+24t+9) - (t^2+t)(32t+24)}{(16t^2+24t+9)^2}$$

分子：$(2t+1)(16t^2+24t+9) - (t^2+t)(32t+24)$

$= 32t^3 + 48t^2 + 18t + 16t^2 + 24t + 9 - 32t^3 - 24t^2 - 32t^2 - 24t$

$= (48+16-24-32)t^2 + (18+24-24)t + 9 = 8t^2 + 18t + 9$

因为 $8t^2 + 18t + 9 > 0$ 对所有 $t > 0$，$g(t)$ 在 $t > 0$ 上单调递增。

当 $t \to +\infty$ 时，$g(t) \to \dfrac{1}{16}$。

但 $g(t) < \dfrac{1}{16}$，$S^2 < \dfrac{144}{16} = 9$，$S < 3$。

当 $l$ 垂直于 $x$ 轴时（$x = 1$）：

$$\frac{1}{4} + \frac{y^2}{3} = 1 \implies y^2 = \frac{9}{4} \implies y = \pm\frac{3}{2}$$

$|AB| = 3$，$d = 2$（$F_1$ 到 $x=1$ 的距离）。

$S = \dfrac{1}{2} \times 3 \times 2 = 3$。

所以面积最大值为 $3$。

> 📌 运用知识点：圆锥曲线的最值

**答案：**

（1）$\boxed{\dfrac{x^2}{4} + \dfrac{y^2}{3} = 1}$

（2）$\boxed{S_{\max} = 3}$

**⚠️ 易错提醒：** 过焦点的直线需要讨论斜率是否存在。当 $l$ 垂直于 $x$ 轴时要单独计算。面积表达式的求最值可以用换元法或导数法。

**💡 解题思路总结：** 圆锥曲线面积最值问题：（1）联立直线与椭圆方程；（2）用韦达定理表示弦长；（3）写出面积关于参数的函数；（4）求最值时注意讨论特殊情况（斜率不存在）。
