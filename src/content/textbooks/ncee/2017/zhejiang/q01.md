**题目：**

已知集合 $A = \{x \mid -1 < x < 2\}$，$B = \{x \mid x > 1\}$，则 $A \cup B =$

A. $\{x \mid -1 < x < 2\}$

B. $\{x \mid x > -1\}$

C. $\{x \mid x > 1\}$

D. $\{x \mid 1 < x < 2\}$

---

**解答：**

**第1步:** 在数轴上表示集合 $A$ 和 $B$

$A = \{x \mid -1 < x < 2\}$ 表示区间 $(-1, 2)$。

$B = \{x \mid x > 1\}$ 表示区间 $(1, +\infty)$。

> 📌 运用知识点：集合的运算

**第2步:** 求并集

$$A \cup B = (-1, 2) \cup (1, +\infty) = (-1, +\infty) = \{x \mid x > -1\}$$

> 📌 运用知识点：集合的运算

**答案：B**

**⚠️ 易错提醒：** 并集取"所有部分"，不是"公共部分"（那是交集）。注意 $A$ 和 $B$ 有重叠区间 $(1, 2)$，并集要将它们合并为一个连续区间。

**💡 解题思路总结：** 集合的并集运算借助数轴最直观——将两个集合覆盖的所有区域合并即可。
