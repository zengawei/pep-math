**题目：**

下列函数中，既是偶函数又在 $(0, +\infty)$ 上单调递增的是

A. $f(x) = x^3$

B. $f(x) = |x| + 1$

C. $f(x) = -x^2 + 1$

D. $f(x) = 2^{-|x|}$

---

**解答：**

**第1步:** 逐一判断偶函数条件

偶函数要求 $f(-x) = f(x)$。

A. $f(x) = x^3$：$f(-x) = -x^3 = -f(x)$，奇函数，不满足。

B. $f(x) = |x| + 1$：$f(-x) = |-x| + 1 = |x| + 1 = f(x)$，偶函数。✓

C. $f(x) = -x^2 + 1$：$f(-x) = -(-x)^2 + 1 = -x^2 + 1 = f(x)$，偶函数。✓

D. $f(x) = 2^{-|x|}$：$f(-x) = 2^{-|-x|} = 2^{-|x|} = f(x)$，偶函数。✓

> 📌 运用知识点：函数的性质

**第2步:** 判断在 $(0, +\infty)$ 上的单调性

B. 当 $x > 0$ 时，$f(x) = x + 1$，单调递增。✓

C. 当 $x > 0$ 时，$f(x) = -x^2 + 1$，单调递减。✗

D. 当 $x > 0$ 时，$f(x) = 2^{-x} = \left(\dfrac{1}{2}\right)^x$，单调递减。✗

> 📌 运用知识点：函数的性质

**答案：B**

**⚠️ 易错提醒：** 判断偶函数时注意 $f(-x)$ 的完整计算，特别是含绝对值的函数。单调性需要在指定区间上判断，不能想当然。

**💡 解题思路总结：** 先筛选偶函数（$f(-x) = f(x)$），再在偶函数中判断指定区间的单调性，两步排除即可得到答案。
