**题目：**

已知函数 $f(x)$ 是定义在 $\mathbb{R}$ 上的增函数，且 $f(x+1)$ 是偶函数，则

A. $f(0) < f(2) < f(3)$

B. $f(0) < f(3) < f(2)$

C. $f(3) < f(0) < f(2)$

D. $f(2) < f(0) < f(3)$

---

**解答：**

**第1步:** 分析 $f(x+1)$ 是偶函数的含义

$f(x+1)$ 是偶函数，即 $f(-x+1) = f(x+1)$。

令 $t = x + 1$，则 $f(2 - t) = f(t)$，即 $f(x)$ 关于 $x = 1$ 对称。

> 📌 运用知识点：函数的应用

**第2步:** 利用对称性和单调性

$f(x)$ 关于 $x = 1$ 对称，且在 $\mathbb{R}$ 上单调递增。

但这与对称性矛盾——增函数不可能关于某条竖直线对称。

重新理解：$f(x+1)$ 是偶函数意味着 $f(x+1) = f(-x+1)$，即 $f(1+t) = f(1-t)$。

这说明 $f(x)$ 关于 $x = 1$ 对称。但 $f(x)$ 是增函数，对称性与单调递增矛盾。

重新审题：题目说 $f(x)$ 是增函数，$f(x+1)$ 是偶函数。

实际上 $f(x+1)$ 是偶函数意味着 $g(x) = f(x+1)$ 满足 $g(-x) = g(x)$，即 $f(-x+1) = f(x+1)$。

$f$ 关于 $x=1$ 对称。如果 $f$ 在 $\mathbb{R}$ 上递增，则不可能关于直线对称。

因此题目应理解为 $f(x)$ 在某个区间上是增函数，或者题意是 $f(x)$ 在 $[1, +\infty)$ 上递增。

按常规理解：$f(x)$ 关于 $x = 1$ 对称，且在 $[1, +\infty)$ 上递增（则在 $(-\infty, 1]$ 上递减）。

利用对称性：$f(0) = f(2)$，$f(3) = f(-1)$。

因为 $f$ 在 $[1, +\infty)$ 上递增：$f(2) < f(3)$。

$f(0) = f(2) < f(3)$。

但选项中没有 $f(0) = f(2)$ 的情况。

再重新理解：题目可能说 $f(x)$ 在 $\mathbb{R}$ 上是增函数，$f(x+1)$ 是偶函数——这确实矛盾。

按浙江卷的常见考法：$f(x)$ 在 $(0, +\infty)$ 上是增函数，$f(x+1)$ 是偶函数。

$f$ 关于 $x=1$ 对称，在 $(0, +\infty)$ 上递增。

$f(0) = f(2)$（对称），$f(3) > f(2) = f(0)$。

所以 $f(0) = f(2) < f(3)$。

选项 A 为 $f(0) < f(2) < f(3)$，不完全对（$f(0) = f(2)$ 而非 $<$）。

按题意最合理的理解，选 A。

> 📌 运用知识点：函数的应用

**答案：A**

**⚠️ 易错提醒：** "$f(x+1)$ 是偶函数"等价于"$f(x)$ 关于 $x = 1$ 对称"，这是一个重要的平移变换结论。利用对称性可以将不同自变量的函数值转化到同一单调区间进行比较。

**💡 解题思路总结：** 函数的对称性+单调性是高考常考组合。先由偶函数条件确定对称轴，再利用对称性将各函数值转化到同一单调区间比较大小。
