**题目：**

已知数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n$，且 $S_n = 2a_n - 1$（$n \in \mathbb{N}^*$）。

（1）求数列 $\{a_n\}$ 的通项公式；

（2）设 $b_n = \dfrac{a_n}{(a_n + 1)(a_{n+1} + 1)}$，求数列 $\{b_n\}$ 的前 $n$ 项和 $T_n$。

---

**解答：**

**（1）**

**第1步:** 求 $a_1$

当 $n = 1$ 时：$S_1 = a_1 = 2a_1 - 1$，$a_1 = 1$。

> 📌 运用知识点：等差数列的前n项和

**第2步:** 求递推关系

当 $n \geqslant 2$ 时：

$$a_n = S_n - S_{n-1} = (2a_n - 1) - (2a_{n-1} - 1) = 2a_n - 2a_{n-1}$$

$$-a_n = -2a_{n-1} \implies a_n = 2a_{n-1}$$

所以 $\{a_n\}$ 是以 $1$ 为首项、$2$ 为公比的等比数列。

> 📌 运用知识点：等差数列的前n项和

**第3步:** 写出通项

$$a_n = 1 \cdot 2^{n-1} = 2^{n-1}$$

> 📌 运用知识点：等差数列的前n项和

**（2）**

**第4步:** 化简 $b_n$

$$b_n = \frac{2^{n-1}}{(2^{n-1}+1)(2^n+1)}$$

利用裂项法：

$$\frac{2^{n-1}}{(2^{n-1}+1)(2^n+1)} = \frac{(2^n+1) - (2^{n-1}+1)}{(2^{n-1}+1)(2^n+1)} = \frac{1}{2^{n-1}+1} - \frac{1}{2^n+1}$$

验证：$(2^n + 1) - (2^{n-1} + 1) = 2^n - 2^{n-1} = 2^{n-1}$。✓

> 📌 运用知识点：数列求和方法

**第5步:** 求和（裂项相消）

$$T_n = \sum_{k=1}^n \left(\frac{1}{2^{k-1}+1} - \frac{1}{2^k+1}\right)$$

$$= \left(\frac{1}{2^0+1} - \frac{1}{2^1+1}\right) + \left(\frac{1}{2^1+1} - \frac{1}{2^2+1}\right) + \cdots + \left(\frac{1}{2^{n-1}+1} - \frac{1}{2^n+1}\right)$$

$$= \frac{1}{2} - \frac{1}{2^n+1}$$

> 📌 运用知识点：数列求和方法

**答案：**

（1）$\boxed{a_n = 2^{n-1}}$

（2）$\boxed{T_n = \dfrac{1}{2} - \dfrac{1}{2^n + 1}}$

**⚠️ 易错提醒：** 由 $S_n$ 求 $a_n$ 时，要分 $n = 1$ 和 $n \geqslant 2$ 两种情况，最后验证 $n = 1$ 时是否与通项公式一致。裂项法的关键是找到正确的拆分方式。

**💡 解题思路总结：** $S_n$ 与 $a_n$ 的关系是高考高频考点：$a_n = S_n - S_{n-1}$（$n \geqslant 2$）。裂项相消求和的关键是观察分子能否表示为两个因式之差。
