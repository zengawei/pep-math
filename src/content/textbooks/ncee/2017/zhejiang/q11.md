**题目：**

已知函数 $y = A\sin(\omega x + \varphi)$（$A > 0$，$\omega > 0$，$|\varphi| < \dfrac{\pi}{2}$）的部分图像如图所示，其相邻的最高点和最低点的坐标分别为 $\left(\dfrac{\pi}{6}, 2\right)$ 和 $\left(\dfrac{2\pi}{3}, -2\right)$，则 $\varphi =$

A. $\dfrac{\pi}{6}$

B. $\dfrac{\pi}{3}$

C. $-\dfrac{\pi}{6}$

D. $-\dfrac{\pi}{3}$

---

**解答：**

**第1步:** 确定 $A$

最高点的纵坐标为 $2$，所以 $A = 2$。

> 📌 运用知识点：三角函数的图像

**第2步:** 确定 $\omega$

相邻最高点和最低点的横坐标之差为半个周期：

$$\frac{T}{2} = \frac{2\pi}{3} - \frac{\pi}{6} = \frac{4\pi - \pi}{6} = \frac{3\pi}{6} = \frac{\pi}{2}$$

$$T = \pi, \quad \omega = \frac{2\pi}{T} = \frac{2\pi}{\pi} = 2$$

> 📌 运用知识点：三角函数的图像

**第3步:** 确定 $\varphi$

最高点处 $\sin(\omega x + \varphi) = 1$：

$$2 \cdot \frac{\pi}{6} + \varphi = \frac{\pi}{2} + 2k\pi$$

$$\frac{\pi}{3} + \varphi = \frac{\pi}{2}$$

$$\varphi = \frac{\pi}{2} - \frac{\pi}{3} = \frac{\pi}{6}$$

> 📌 运用知识点：三角函数的图像

**答案：A**

**⚠️ 易错提醒：** 相邻最高点与最低点的横坐标差是半个周期（$\dfrac{T}{2}$），不是一个周期。求 $\varphi$ 时注意利用 $|\varphi| < \dfrac{\pi}{2}$ 的条件确定 $k$ 值。

**💡 解题思路总结：** 由图像确定 $y = A\sin(\omega x + \varphi)$ 的参数：$A$ 看振幅，$\omega$ 看周期（最高点与最低点间距为半周期），$\varphi$ 代入特殊点坐标求解。
