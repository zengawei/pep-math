**题目：**

已知椭圆 $C: \dfrac{x^2}{4} + \dfrac{y^2}{3} = 1$，$F_1$，$F_2$ 分别为左、右焦点，过 $F_2$ 的直线 $l$ 与椭圆交于 $A$，$B$ 两点。

（1）求 $|AF_1| + |BF_1|$ 的最大值；

（2）若 $\overrightarrow{F_1A} \cdot \overrightarrow{F_1B} = 0$，求直线 $l$ 的方程。

---

**解答：**

**（1）求最大值**

**第1步：** 利用椭圆定义转化
> 📌 运用知识点：椭圆定义

$a = 2$，$|AF_1| + |AF_2| = 4$，$|BF_1| + |BF_2| = 4$。

$$|AF_1| + |BF_1| = 8 - (|AF_2| + |BF_2|) = 8 - |AB|$$

要使 $|AF_1| + |BF_1|$ 最大，需 $|AB|$ 最小。

**第2步：** 求最短弦
> 📌 运用知识点：椭圆性质

过焦点的最短弦为通径（垂直于长轴）：$|AB|_{\min} = \dfrac{2b^2}{a} = \dfrac{6}{2} = 3$。

$$\boxed{(|AF_1| + |BF_1|)_{\max} = 8 - 3 = 5}$$

---

**（2）求直线方程**

**第3步：** 联立方程
> 📌 运用知识点：圆锥曲线与直线

$F_1(-1, 0)$，$F_2(1, 0)$。设 $l: y = k(x - 1)$。

代入椭圆：$(3 + 4k^2)x^2 - 8k^2 x + 4k^2 - 12 = 0$。

$$x_A + x_B = \frac{8k^2}{3 + 4k^2}, \quad x_A x_B = \frac{4k^2 - 12}{3 + 4k^2}$$

**第4步：** 运用垂直条件
> 📌 运用知识点：圆锥曲线综合

$\overrightarrow{F_1A} \cdot \overrightarrow{F_1B} = (x_A + 1)(x_B + 1) + y_A y_B = 0$

$y_A y_B = k^2(x_A - 1)(x_B - 1) = k^2[x_A x_B - (x_A + x_B) + 1]$

展开整理：

$$(1 + k^2)x_A x_B + (1 - k^2)(x_A + x_B) + 1 + k^2 = 0$$

代入韦达定理，化简得：

$$7k^2 - 9 = 0 \implies k^2 = \frac{9}{7} \implies k = \pm\frac{3\sqrt{7}}{7}$$

验证竖直线 $x = 1$：$A(1, \frac{3}{2})$，$B(1, -\frac{3}{2})$，$\overrightarrow{F_1A} \cdot \overrightarrow{F_1B} = 4 - \frac{9}{4} = \frac{7}{4} \neq 0$。

**答案：**（1）最大值为 $5$；（2）$l: y = \pm\dfrac{3\sqrt{7}}{7}(x - 1)$。

**⚠️ 易错提醒：** 过焦点最短弦是通径而非任意弦；垂直条件展开时 $y_A y_B$ 的计算容易出错。

**💡 解题思路总结：** 椭圆定义转化求最值；垂直条件用韦达定理联立，注意验证斜率不存在的情况。
