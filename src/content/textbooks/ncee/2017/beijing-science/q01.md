**题目：** 已知集合 $A = \{x \mid |x| < 1\}$，$B = \{x \mid x^2 - 2x \leqslant 0\}$，则 $A \cup B =$（）

A. $\{x \mid 0 \leqslant x < 1\}$

B. $\{x \mid -1 < x \leqslant 2\}$

C. $\{x \mid 0 \leqslant x \leqslant 2\}$

D. $\{x \mid -1 < x \leqslant 0\}$

---

**解答：**

**第1步：** 求各集合
> 📌 运用知识点：集合运算

$A = (-1, 1)$。$x^2 - 2x \leqslant 0 \implies x(x - 2) \leqslant 0 \implies B = [0, 2]$。

**第2步：** 求并集

$$A \cup B = (-1, 1) \cup [0, 2] = (-1, 2]$$

**答案：** B
