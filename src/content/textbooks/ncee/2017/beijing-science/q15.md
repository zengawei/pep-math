**题目：**

在 $\triangle ABC$ 中，$a$，$b$，$c$ 分别为角 $A$，$B$，$C$ 的对边，已知 $a = 2$，$b = 3$，$\cos C = \dfrac{1}{3}$。

（1）求 $c$ 的值；

（2）求 $\sin(B + C)$ 的值。

---

**解答：**

**（1）求 $c$**

**第1步：** 运用余弦定理
> 📌 运用知识点：余弦定理

$$c^2 = a^2 + b^2 - 2ab\cos C = 4 + 9 - 2 \times 2 \times 3 \times \frac{1}{3} = 13 - 4 = 9$$

$$\boxed{c = 3}$$

---

**（2）求 $\sin(B + C)$**

**第2步：** 转化
> 📌 运用知识点：三角恒等变换

$$\sin(B + C) = \sin(\pi - A) = \sin A$$

**第3步：** 求 $\sin A$
> 📌 运用知识点：正弦定理

$\cos C = \dfrac{1}{3}$，$\sin C = \sqrt{1 - \dfrac{1}{9}} = \dfrac{2\sqrt{2}}{3}$。

由正弦定理：$\dfrac{a}{\sin A} = \dfrac{c}{\sin C}$

$$\sin A = \frac{a \sin C}{c} = \frac{2 \times \dfrac{2\sqrt{2}}{3}}{3} = \frac{4\sqrt{2}}{9}$$

**答案：**（1）$c = 3$；（2）$\sin(B + C) = \dfrac{4\sqrt{2}}{9}$。

**⚠️ 易错提醒：** $\sin(B+C) = \sin A$ 的转化不要遗漏；求 $\sin C$ 时注意 $C \in (0, \pi)$，$\sin C > 0$。

**💡 解题思路总结：** 余弦定理求边，正弦定理求角；利用三角形内角和关系 $\sin(B+C) = \sin A$ 简化计算。
