**题目：**

已知数列 $\{a_n\}$ 满足 $a_1 = 1$，$a_{n+1} = \dfrac{a_n}{1 + 2a_n}$（$n \geqslant 1$）。

（1）求 $a_2$，$a_3$，并猜想 $\{a_n\}$ 的通项公式；

（2）证明你的猜想。

---

**解答：**

**（1）计算与猜想**

**第1步：** 逐项计算
> 📌 运用知识点：数列概念

$$a_2 = \frac{1}{1 + 2} = \frac{1}{3}, \quad a_3 = \frac{\frac{1}{3}}{1 + \frac{2}{3}} = \frac{\frac{1}{3}}{\frac{5}{3}} = \frac{1}{5}$$

观察规律：$a_1 = \dfrac{1}{1}$，$a_2 = \dfrac{1}{3}$，$a_3 = \dfrac{1}{5}$。

猜想：$\boxed{a_n = \dfrac{1}{2n - 1}}$。

---

**（2）证明**

**第2步：** 构造辅助数列
> 📌 运用知识点：等差数列

令 $b_n = \dfrac{1}{a_n}$，则 $b_1 = 1$。

$$b_{n+1} = \frac{1}{a_{n+1}} = \frac{1 + 2a_n}{a_n} = \frac{1}{a_n} + 2 = b_n + 2$$

**第3步：** 求通项
> 📌 运用知识点：等差数列

$\{b_n\}$ 是以 $1$ 为首项、$2$ 为公差的等差数列。

$$b_n = 1 + 2(n - 1) = 2n - 1$$

$$a_n = \frac{1}{b_n} = \frac{1}{2n - 1}$$

猜想得证。$\blacksquare$

**答案：**（1）$a_2 = \dfrac{1}{3}$，$a_3 = \dfrac{1}{5}$，$a_n = \dfrac{1}{2n-1}$；（2）证明见解答。

**⚠️ 易错提醒：** 取倒数构造辅助数列是处理 $a_{n+1} = \dfrac{a_n}{1 + ka_n}$ 型递推的标准方法；不要遗漏验证 $b_1$ 的值。

**💡 解题思路总结：** 分式递推取倒数转化为等差数列，是数列求通项的重要技巧。
