**题目：** 已知集合 $A = \{1, 2, 3, 4\}$，$B = \{x \mid 1 < x < 4\}$，则 $A \cap B =$（）

A. $\{2, 3\}$

B. $\{1, 2, 3\}$

C. $\{2, 3, 4\}$

D. $\{1, 2, 3, 4\}$

---

**解答：**

**第1步：** 求交集
> 📌 运用知识点：集合运算

$B = (1, 4)$，从 $A$ 中筛选满足 $1 < x < 4$ 的元素：$2, 3$。

**答案：** A
