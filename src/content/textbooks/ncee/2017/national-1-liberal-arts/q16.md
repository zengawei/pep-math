**题目：** 已知函数 $f(x) = x \ln x$，则 $f(x)$ 在 $x = 1$ 处的切线方程为 ______。

---

**解答：**

**第1步：** 求 $f(1)$
> 📌 运用知识点：derivative-operations

$$f(1) = 1 \times \ln 1 = 1 \times 0 = 0$$

切点为 $(1, 0)$。

**第2步：** 求 $f'(x)$ 及 $f'(1)$
> 📌 运用知识点：derivative-operations

$$f'(x) = \ln x + x \times \frac{1}{x} = \ln x + 1$$

$$f'(1) = \ln 1 + 1 = 0 + 1 = 1$$

切线斜率 $k = 1$。

**第3步：** 写出切线方程
> 📌 运用知识点：derivative-operations

$$y - 0 = 1 \times (x - 1)$$

$$y = x - 1$$

**答案：** $y = x - 1$
