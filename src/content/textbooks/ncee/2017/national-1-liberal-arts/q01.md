**题目：** 已知集合 $A = \{1, 2, 3, 4\}$，$B = \{x \mid x = n^2,\ n \in A\}$，则 $A \cap B = $（  ）

A. $\{1, 4\}$

B. $\{2, 3\}$

C. $\{1, 2\}$

D. $\{1, 9\}$

---

**解答：**

**第1步：** 求集合 $B$
> 📌 运用知识点：set-operations

将 $A = \{1, 2, 3, 4\}$ 中每个元素平方：

$$1^2 = 1,\quad 2^2 = 4,\quad 3^2 = 9,\quad 4^2 = 16$$

所以 $B = \{1, 4, 9, 16\}$。

**第2步：** 求 $A \cap B$
> 📌 运用知识点：set-operations

$A = \{1, 2, 3, 4\}$，$B = \{1, 4, 9, 16\}$。

两个集合的公共元素为 $1$ 和 $4$。

$$A \cap B = \{1, 4\}$$

**答案：A**
