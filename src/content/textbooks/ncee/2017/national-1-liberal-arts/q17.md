**题目：** 已知等差数列 $\{a_n\}$ 满足 $a_2 = 3$，$a_4 + a_5 = 16$。

（1）求 $\{a_n\}$ 的通项公式；

（2）设 $b_n = 2^{a_n}$，求数列 $\{b_n\}$ 的前 $n$ 项和 $T_n$。

---

**解答：**

**（1）求通项公式**

**第1步：** 设首项为 $a_1$，公差为 $d$，列方程组
> 📌 运用知识点：arithmetic-sequence

$$a_2 = a_1 + d = 3 \quad \cdots (1)$$

$$a_4 + a_5 = (a_1 + 3d) + (a_1 + 4d) = 2a_1 + 7d = 16 \quad \cdots (2)$$

**第2步：** 解方程组
> 📌 运用知识点：arithmetic-sequence

由 $(1)$ 得 $a_1 = 3 - d$，代入 $(2)$：

$$2(3 - d) + 7d = 16$$

$$6 - 2d + 7d = 16$$

$$5d = 10 \implies d = 2$$

$$a_1 = 3 - 2 = 1$$

**第3步：** 写出通项公式
> 📌 运用知识点：arithmetic-sequence

$$a_n = a_1 + (n - 1)d = 1 + (n - 1) \times 2 = 2n - 1$$

**（2）求 $T_n$**

**第4步：** 求 $b_n$ 的表达式
> 📌 运用知识点：geometric-sequence-sum

$$b_n = 2^{a_n} = 2^{2n - 1}$$

验证 $\{b_n\}$ 为等比数列：

$$b_1 = 2^1 = 2,\quad b_2 = 2^3 = 8,\quad \frac{b_2}{b_1} = \frac{8}{2} = 4$$

公比 $q = 4$，首项 $b_1 = 2$。

**第5步：** 求前 $n$ 项和
> 📌 运用知识点：geometric-sequence-sum

$$T_n = \frac{b_1(q^n - 1)}{q - 1} = \frac{2(4^n - 1)}{4 - 1} = \frac{2(4^n - 1)}{3}$$

$$\boxed{T_n = \dfrac{2(4^n - 1)}{3}}$$

**⚠️ 易错提醒：**
1. 求等差数列通项时，注意 $a_4 + a_5$ 需要展开为 $2a_1 + 7d$，不要误写为 $2a_1 + 9d$。
2. 判断 $\{b_n\}$ 为等比数列时，需验证公比为常数，不能仅凭前两项就下结论。
3. 等比数列求和公式中注意 $q \neq 1$ 的条件。

**💡 解题思路总结：** 第一问用基本量法（设 $a_1, d$）列方程组求解。第二问的关键是发现 $b_n = 2^{a_n}$ 构成等比数列——利用指数运算性质，相邻两项之比 $\frac{b_{n+1}}{b_n} = 2^{a_{n+1} - a_n} = 2^d$ 为常数。
