**题目：** 已知 $f(x) = \begin{cases} 2^x, & x > 0 \\ x + 1, & x \leqslant 0 \end{cases}$，则 $f(f(-1)) = $（  ）

A. $\dfrac{1}{2}$

B. $1$

C. $2$

D. $4$

---

**解答：**

**第1步：** 求 $f(-1)$
> 📌 运用知识点：function-concept

因为 $-1 \leqslant 0$，使用第二段 $f(x) = x + 1$：

$$f(-1) = -1 + 1 = 0$$

**第2步：** 求 $f(f(-1)) = f(0)$
> 📌 运用知识点：function-concept

因为 $0 \leqslant 0$，仍使用第二段 $f(x) = x + 1$：

$$f(0) = 0 + 1 = 1$$

所以 $f(f(-1)) = 1$。

**答案：B**
