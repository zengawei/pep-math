**题目：** 若 $x, y$ 满足约束条件 $\begin{cases} x + y \leqslant 4 \\ x - y \leqslant 2 \\ x \geqslant 0 \\ y \geqslant 0 \end{cases}$，则 $z = x + 2y$ 的最大值为（  ）

A. $4$

B. $6$

C. $8$

D. $10$

---

**解答：**

**第1步：** 确定可行域的顶点
> 📌 运用知识点：basic-inequality

联立各约束条件求交点：

- $x = 0, y = 0$：顶点 $(0, 0)$
- $y = 0, x - y = 2$：顶点 $(2, 0)$
- $x + y = 4, x - y = 2$：解得 $x = 3, y = 1$，顶点 $(3, 1)$
- $x = 0, x + y = 4$：顶点 $(0, 4)$

**第2步：** 计算各顶点处的目标函数值
> 📌 运用知识点：basic-inequality

| 顶点 | $z = x + 2y$ |
|:---:|:---:|
| $(0, 0)$ | $0$ |
| $(2, 0)$ | $2$ |
| $(3, 1)$ | $5$ |
| $(0, 4)$ | $8$ |

**第3步：** 确定最大值
> 📌 运用知识点：basic-inequality

$z$ 的最大值为 $8$，在点 $(0, 4)$ 处取得。

**答案：C**
