**题目：** 已知抛物线 $C: x^2 = 4y$，过点 $P(0, 2)$ 作直线 $l$ 与 $C$ 交于 $A$，$B$ 两点。

（1）若 $|AB| = 4\sqrt{6}$，求直线 $l$ 的方程；

（2）设 $M$ 为 $AB$ 的中点，求 $M$ 的轨迹方程。

---

**解答：**

**（1）求直线 $l$ 的方程**

**第1步：** 设直线方程并联立
> 📌 运用知识点：conic-section-line

直线 $l$ 过点 $P(0, 2)$，设 $l: y = kx + 2$（竖直线 $x = 0$ 与抛物线仅有一个交点，不合题意）。

代入 $x^2 = 4y$：

$$x^2 = 4(kx + 2) \implies x^2 - 4kx - 8 = 0$$

设 $A(x_1, y_1)$，$B(x_2, y_2)$，由韦达定理：

$$x_1 + x_2 = 4k,\quad x_1 x_2 = -8$$

**第2步：** 利用弦长公式
> 📌 运用知识点：parabola-properties

$$|AB|^2 = (1 + k^2)[(x_1 + x_2)^2 - 4x_1 x_2]$$

$$= (1 + k^2)[16k^2 - 4(-8)] = (1 + k^2)(16k^2 + 32) = 16(1 + k^2)(k^2 + 2)$$

由 $|AB| = 4\sqrt{6}$：

$$16(1 + k^2)(k^2 + 2) = 96$$

$$(1 + k^2)(k^2 + 2) = 6$$

**第3步：** 解方程求 $k$
> 📌 运用知识点：conic-section-line

令 $t = k^2 \geqslant 0$：

$$(1 + t)(t + 2) = 6 \implies t^2 + 3t + 2 = 6 \implies t^2 + 3t - 4 = 0$$

$$(t + 4)(t - 1) = 0$$

$t = 1$（$t = -4$ 舍去），即 $k^2 = 1$，$k = \pm 1$。

$$\boxed{l: y = x + 2 \quad \text{或} \quad y = -x + 2}$$

**（2）求 $M$ 的轨迹方程**

**第4步：** 求中点坐标
> 📌 运用知识点：parabola-properties

$$x_M = \frac{x_1 + x_2}{2} = \frac{4k}{2} = 2k$$

$$y_M = kx_M + 2 = k(2k) + 2 = 2k^2 + 2$$

**第5步：** 消去参数 $k$
> 📌 运用知识点：conic-section-line

由 $x_M = 2k$ 得 $k = \dfrac{x_M}{2}$，代入 $y_M$：

$$y_M = 2\left(\frac{x_M}{2}\right)^2 + 2 = \frac{x_M^2}{2} + 2$$

因为判别式 $\Delta = 16k^2 + 32 > 0$ 对任意 $k$ 恒成立，所以 $k$ 可取任意实数，$x_M$ 可取任意实数。

$$\boxed{y = \dfrac{x^2}{2} + 2}$$

**⚠️ 易错提醒：**
1. 设直线方程时不能遗漏斜率不存在的情况（$x = 0$），需单独验证后排除。
2. 弦长公式 $|AB| = \sqrt{1+k^2} \cdot |x_1 - x_2|$ 中，$|x_1 - x_2| = \sqrt{(x_1+x_2)^2 - 4x_1x_2}$，注意不要遗漏根号。
3. 求轨迹方程时，需验证参数的取值范围，确认轨迹的完整性。

**💡 解题思路总结：** 抛物线与直线联立是解析几何的经典题型。第一问用韦达定理配合弦长公式建立关于 $k$ 的方程。第二问用参数法——以斜率 $k$ 为参数表示中点坐标，再消参得到轨迹方程。注意判别式恒正，轨迹为完整的抛物线。
