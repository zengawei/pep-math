**题目：** 如图，在四棱锥 $P\text{-}ABCD$ 中，底面 $ABCD$ 为矩形，$PA \perp$ 底面 $ABCD$，$PA = AB = 2$，$AD = 4$，$M$ 为 $PD$ 的中点。

（1）求直线 $AM$ 与平面 $PCD$ 所成角的大小；

（2）求二面角 $A\text{-}PC\text{-}D$ 的余弦值。

---

**解答：**

**第1步：** 建立空间直角坐标系
> 📌 运用知识点：空间直角坐标系

以 $A$ 为原点，$\overrightarrow{AB}$，$\overrightarrow{AD}$，$\overrightarrow{AP}$ 分别为 $x$，$y$，$z$ 轴正方向。

$$A(0, 0, 0),\quad B(2, 0, 0),\quad C(2, 4, 0),\quad D(0, 4, 0),\quad P(0, 0, 2)$$

$M$ 为 $PD$ 的中点：

$$M = \left(\frac{0+0}{2},\ \frac{0+4}{2},\ \frac{2+0}{2}\right) = (0, 2, 1)$$

**（1）求直线 $AM$ 与平面 $PCD$ 所成角**

**第2步：** 求平面 $PCD$ 的法向量
> 📌 运用知识点：空间向量法求线面角

$$\overrightarrow{PC} = (2, 4, -2),\quad \overrightarrow{PD} = (0, 4, -2)$$

设平面 $PCD$ 的法向量 $\vec{n} = (x, y, z)$：

$$\begin{cases} \vec{n} \cdot \overrightarrow{PC} = 2x + 4y - 2z = 0 \\ \vec{n} \cdot \overrightarrow{PD} = 4y - 2z = 0 \end{cases}$$

由第二式 $z = 2y$，代入第一式 $2x + 4y - 4y = 0$，得 $x = 0$。

取 $y = 1$，则 $\vec{n} = (0, 1, 2)$。

**第3步：** 计算线面角
> 📌 运用知识点：空间向量法求线面角

$\overrightarrow{AM} = (0, 2, 1)$，设直线 $AM$ 与平面 $PCD$ 所成角为 $\theta$：

$$\sin\theta = \frac{|\overrightarrow{AM} \cdot \vec{n}|}{|\overrightarrow{AM}| \cdot |\vec{n}|} = \frac{|0 + 2 + 2|}{\sqrt{5} \cdot \sqrt{5}} = \frac{4}{5}$$

$$\boxed{\theta = \arcsin\dfrac{4}{5}}$$

**（2）求二面角 $A\text{-}PC\text{-}D$ 的余弦值**

**第4步：** 求平面 $APC$ 的法向量
> 📌 运用知识点：空间向量法求二面角

$$\overrightarrow{AP} = (0, 0, 2),\quad \overrightarrow{AC} = (2, 4, 0)$$

设平面 $APC$ 的法向量 $\vec{n_1} = (x, y, z)$：

$$\begin{cases} \vec{n_1} \cdot \overrightarrow{AP} = 2z = 0 \implies z = 0 \\ \vec{n_1} \cdot \overrightarrow{AC} = 2x + 4y = 0 \implies x = -2y \end{cases}$$

取 $y = 1$，则 $\vec{n_1} = (-2, 1, 0)$。

平面 $DPC$ 的法向量已求得：$\vec{n_2} = (0, 1, 2)$。

**第5步：** 用投影法确定二面角
> 📌 运用知识点：空间向量法求二面角

将 $\overrightarrow{PA}$ 和 $\overrightarrow{PD}$ 分别投影到与棱 $\overrightarrow{PC}$ 垂直的方向上。

$\overrightarrow{PC} = (2, 4, -2)$，$|\overrightarrow{PC}|^2 = 24$。

$\overrightarrow{PA} = (0, 0, -2)$，$\overrightarrow{PD} = (0, 4, -2)$。

$\overrightarrow{PA}$ 在 $\overrightarrow{PC}$ 上的投影分量：

$$\text{proj}_{\overrightarrow{PC}}\overrightarrow{PA} = \frac{\overrightarrow{PA} \cdot \overrightarrow{PC}}{|\overrightarrow{PC}|^2}\overrightarrow{PC} = \frac{4}{24}(2, 4, -2) = \left(\frac{1}{3},\ \frac{2}{3},\ -\frac{1}{3}\right)$$

$$\overrightarrow{PA_\perp} = \overrightarrow{PA} - \text{proj} = \left(-\frac{1}{3},\ -\frac{2}{3},\ -\frac{5}{3}\right)$$

$\overrightarrow{PD}$ 在 $\overrightarrow{PC}$ 上的投影分量：

$$\text{proj}_{\overrightarrow{PC}}\overrightarrow{PD} = \frac{\overrightarrow{PD} \cdot \overrightarrow{PC}}{|\overrightarrow{PC}|^2}\overrightarrow{PC} = \frac{20}{24}(2, 4, -2) = \left(\frac{5}{3},\ \frac{10}{3},\ -\frac{5}{3}\right)$$

$$\overrightarrow{PD_\perp} = \overrightarrow{PD} - \text{proj} = \left(-\frac{5}{3},\ \frac{2}{3},\ -\frac{1}{3}\right)$$

**第6步：** 计算二面角的余弦值

$$\overrightarrow{PA_\perp} \cdot \overrightarrow{PD_\perp} = \frac{5}{9} - \frac{4}{9} + \frac{5}{9} = \frac{6}{9} = \frac{2}{3}$$

$$|\overrightarrow{PA_\perp}| = \sqrt{\frac{1 + 4 + 25}{9}} = \frac{\sqrt{30}}{3},\quad |\overrightarrow{PD_\perp}| = \sqrt{\frac{25 + 4 + 1}{9}} = \frac{\sqrt{30}}{3}$$

$$\cos\theta = \frac{\dfrac{2}{3}}{\dfrac{\sqrt{30}}{3} \cdot \dfrac{\sqrt{30}}{3}} = \frac{\dfrac{2}{3}}{\dfrac{30}{9}} = \frac{\dfrac{2}{3}}{\dfrac{10}{3}} = \frac{1}{5}$$

$$\boxed{\cos\theta = \dfrac{1}{5}}$$

**⚠️ 易错提醒：**
1. 建系时要充分利用 $PA \perp$ 底面的条件，以 $A$ 为原点，三条互相垂直的棱作为坐标轴。
2. 求线面角时，公式为 $\sin\theta = \dfrac{|\vec{d} \cdot \vec{n}|}{|\vec{d}||\vec{n}|}$，注意是正弦而非余弦。
3. 求二面角时，需要判断二面角是锐角还是钝角。本题用投影法直接得到 $\cos\theta > 0$，说明二面角为锐角。

**💡 解题思路总结：** 立体几何计算题的标准方法：建系 → 坐标化 → 向量运算。求线面角用法向量与方向向量的夹角（取正弦），求二面角可用法向量夹角或投影法。投影法的关键是将两个半平面内的向量投影到与棱垂直的方向上，再求夹角。
