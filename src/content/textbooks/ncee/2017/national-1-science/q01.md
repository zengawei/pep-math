**题目：** 已知集合 $A = \{x \mid x < 1\}$，$B = \{x \mid 3^x > 1\}$，则 $A \cap B =$

A. $\{x \mid 0 < x < 1\}$

B. $\mathbb{R}$

C. $\{x \mid x > 0\}$

D. $\emptyset$

---

**解答：**

**第1步：** 求集合 $B$
> 📌 运用知识点：指数函数的性质

$3^x > 1 = 3^0$，因为底数 $3 > 1$，指数函数单调递增，所以 $x > 0$。

即 $B = \{x \mid x > 0\}$。

**第2步：** 求 $A \cap B$
> 📌 运用知识点：集合的交集运算

$$A \cap B = \{x \mid x < 1\} \cap \{x \mid x > 0\} = \{x \mid 0 < x < 1\}$$

**答案：A**
