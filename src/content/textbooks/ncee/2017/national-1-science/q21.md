**题目：** 已知函数 $f(x) = (x - 2)e^x + a(x - 1)^2$，$a \in \mathbb{R}$。

（1）当 $a = 0$ 时，求 $f(x)$ 的单调区间；

（2）若 $f(x)$ 有两个零点，求 $a$ 的取值范围。

---

**解答：**

**第1步：** 求导数（$a = 0$）
> 📌 运用知识点：导数的运算

当 $a = 0$ 时，$f(x) = (x - 2)e^x$。

$$f'(x) = e^x + (x - 2)e^x = (x - 1)e^x$$

**第2步：** 确定单调区间
> 📌 运用知识点：导数与函数的单调性

因为 $e^x > 0$ 恒成立，$f'(x)$ 的符号由 $(x - 1)$ 决定：

- $f'(x) > 0 \iff x > 1$：$f(x)$ 在 $(1, +\infty)$ 上单调递增
- $f'(x) < 0 \iff x < 1$：$f(x)$ 在 $(-\infty, 1)$ 上单调递减

**第3步：** 分析 $f(x)$ 有两个零点的条件
> 📌 运用知识点：导数与函数零点

$$f'(x) = (x - 1)e^x + 2a(x - 1) = (x - 1)(e^x + 2a)$$

**情况 1：$a \geqslant 0$**

$e^x + 2a > 0$ 恒成立，$f'(x) = 0$ 仅当 $x = 1$。

$f(x)$ 在 $(-\infty, 1)$ 递减，在 $(1, +\infty)$ 递增。$f(1) = -e < 0$。

当 $x \to +\infty$ 时，$f(x) \to +\infty$。

当 $x \to -\infty$ 时，若 $a > 0$：$f(x) \to +\infty$（$a(x-1)^2$ 主导），$f(x)$ 在 $(-\infty, 1)$ 和 $(1, +\infty)$ 各有一个零点，共两个。✓

若 $a = 0$：$f(x) \to 0$（$x \to -\infty$），仅一个零点。✗

**情况 2：$a < 0$**

$e^x + 2a = 0 \implies x = \ln(-2a)$。

经分析各子情况（$\ln(-2a)$ 与 $1$ 的大小关系），极大值 $f(\ln(-2a)) < 0$，$f(x)$ 至多一个零点。✗

**第4步：** 综合结论

$f(x)$ 有两个零点当且仅当 $a > 0$。

$$\boxed{a \in (0, +\infty)}$$

**⚠️ 易错提醒：** 第（2）问需要对 $a$ 进行分类讨论，关键是分析 $f'(x) = (x-1)(e^x + 2a)$ 的零点分布。注意 $a < 0$ 时 $\ln(-2a)$ 与 $1$ 的大小关系决定了极值点的相对位置。

**💡 解题思路总结：** 含参函数的零点问题，标准流程为：求导 → 分类讨论确定单调性 → 分析极值的正负 → 结合极限行为判断零点个数。本题的核心在于 $f'(x)$ 可以因式分解为 $(x-1)(e^x + 2a)$。
