**题目：** 已知函数 $f(x) = x^3 - 3x^2 + 2$，则 $f(x)$ 在 $[-1, 3]$ 上的最大值为

A. $-2$

B. $0$

C. $2$

D. $4$

---

**解答：**

**第1步：** 求导数并找极值点
> 📌 运用知识点：导数的运算

$$f'(x) = 3x^2 - 6x = 3x(x - 2)$$

令 $f'(x) = 0$，得 $x = 0$ 或 $x = 2$。

**第2步：** 比较函数值
> 📌 运用知识点：导数与函数的最值

$$f(-1) = -1 - 3 + 2 = -2$$
$$f(0) = 0 - 0 + 2 = 2$$
$$f(2) = 8 - 12 + 2 = -2$$
$$f(3) = 27 - 27 + 2 = 2$$

最大值为 $2$。

**答案：C**
