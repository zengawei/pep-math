**题目：** 记 $S_n$ 为等比数列 $\{a_n\}$ 的前 $n$ 项和。已知 $S_2 = 2$，$S_3 = -6$。

（1）求 $\{a_n\}$ 的通项公式；

（2）判断 $S_{n+1}$，$S_n$，$S_{n+2}$ 是否成等差数列，并说明理由。

---

**解答：**

**（1）求通项公式**

**第1步：** 设首项和公比，列方程
> 📌 运用知识点：等比数列的性质

设首项为 $a_1$，公比为 $q$（$q \neq 0$）。

$$S_2 = a_1(1 + q) = 2 \quad \cdots ①$$

$$S_3 = a_1(1 + q + q^2) = -6 \quad \cdots ②$$

**第2步：** 求公比 $q$
> 📌 运用知识点：等比数列的前n项和

② $\div$ ①：

$$\frac{1 + q + q^2}{1 + q} = -3$$

$$1 + q + q^2 = -3 - 3q$$

$$q^2 + 4q + 4 = 0$$

$$(q + 2)^2 = 0 \implies q = -2$$

**第3步：** 求首项 $a_1$ 并写出通项公式
> 📌 运用知识点：等比数列的通项公式

代入①：$a_1(1 - 2) = 2$，$-a_1 = 2$，$a_1 = -2$。

$$\boxed{a_n = (-2) \times (-2)^{n-1} = (-2)^n}$$

**（2）判断 $S_{n+1}$，$S_n$，$S_{n+2}$ 是否成等差数列**

**第4步：** 求 $S_n$ 的表达式
> 📌 运用知识点：等比数列的前n项和

$$S_n = \frac{a_1(1 - q^n)}{1 - q} = \frac{-2(1 - (-2)^n)}{1 - (-2)} = \frac{-2(1 - (-2)^n)}{3} = \frac{2((-2)^n - 1)}{3}$$

**第5步：** 验证 $2S_n = S_{n+1} + S_{n+2}$
> 📌 运用知识点：等差数列的判定

三个数 $S_{n+1}$，$S_n$，$S_{n+2}$ 成等差数列的充要条件为 $2S_n = S_{n+1} + S_{n+2}$。

$$S_{n+1} + S_{n+2} = \frac{2((-2)^{n+1} - 1)}{3} + \frac{2((-2)^{n+2} - 1)}{3}$$

$$= \frac{2}{3}\left[(-2)^{n+1} + (-2)^{n+2} - 2\right]$$

$$= \frac{2}{3}\left[(-2)^{n+1}(1 + (-2)) - 2\right]$$

$$= \frac{2}{3}\left[-(-2)^{n+1} - 2\right]$$

因为 $-(-2)^{n+1} = -(-2) \cdot (-2)^n = 2 \cdot (-2)^n$，所以：

$$S_{n+1} + S_{n+2} = \frac{2}{3}\left[2 \cdot (-2)^n - 2\right] = \frac{4((-2)^n - 1)}{3} = 2S_n$$

因此 $2S_n = S_{n+1} + S_{n+2}$ 成立。

$$\boxed{S_{n+1},\ S_n,\ S_{n+2} \text{ 成等差数列}}$$

**⚠️ 易错提醒：** 第（2）问中，判断三个数是否成等差数列，需要验证中间项的两倍是否等于两边项之和。注意题目中三者的顺序是 $S_{n+1}$，$S_n$，$S_{n+2}$，因此需验证 $2S_n = S_{n+1} + S_{n+2}$，而非 $2S_{n+1} = S_n + S_{n+2}$。

**💡 解题思路总结：** 等比数列的综合问题，先利用已知条件求出首项和公比，再代入通项公式和前 $n$ 项和公式进行判断。判断等差数列时，关键是验证等差中项关系。
