**题目：** 已知椭圆 $C$：$\dfrac{x^2}{4} + \dfrac{y^2}{3} = 1$，点 $P$ 是 $C$ 上的动点，$F_1$，$F_2$ 分别为 $C$ 的左、右焦点。

（1）求 $|PF_1| \cdot |PF_2|$ 的最大值和最小值；

（2）过 $F_1$ 的直线 $l$ 与 $C$ 交于 $A$，$B$ 两点，求 $\triangle ABF_2$ 面积的最大值。

---

**解答：**

**第1步：** 确定椭圆参数
> 📌 运用知识点：椭圆的性质

$a^2 = 4$，$b^2 = 3$，$c^2 = 1$。$a = 2$，$c = 1$。$F_1(-1, 0)$，$F_2(1, 0)$。

**第2步：** 求 $|PF_1| \cdot |PF_2|$ 的最值
> 📌 运用知识点：椭圆的定义

由椭圆定义：$|PF_1| + |PF_2| = 2a = 4$。

设 $|PF_1| = m$，则 $|PF_2| = 4 - m$，其中 $a - c \leqslant m \leqslant a + c$，即 $1 \leqslant m \leqslant 3$。

$$|PF_1| \cdot |PF_2| = m(4 - m) = -(m - 2)^2 + 4$$

当 $m = 2$ 时取最大值 $4$；当 $m = 1$ 或 $m = 3$ 时取最小值 $3$。

$$\boxed{\text{最大值为 } 4，\text{最小值为 } 3}$$

**第3步：** 求 $\triangle ABF_2$ 面积的最大值
> 📌 运用知识点：圆锥曲线与直线的位置关系

设 $l$：$x = my - 1$（包含斜率不存在的情况），代入椭圆方程：

$$\frac{(my - 1)^2}{4} + \frac{y^2}{3} = 1$$

$$3(my - 1)^2 + 4y^2 = 12$$

$$(3m^2 + 4)y^2 - 6my - 9 = 0$$

设 $A(x_1, y_1)$，$B(x_2, y_2)$，则 $y_1 + y_2 = \dfrac{6m}{3m^2 + 4}$，$y_1 y_2 = \dfrac{-9}{3m^2 + 4}$。

$$|y_1 - y_2| = \sqrt{(y_1 + y_2)^2 - 4y_1 y_2} = \sqrt{\frac{36m^2}{(3m^2 + 4)^2} + \frac{36}{3m^2 + 4}} = \frac{12\sqrt{m^2 + 1}}{3m^2 + 4}$$

$\triangle ABF_2$ 的面积 $S = \dfrac{1}{2} |AB| \cdot d(F_2, l)$。

更简便地：$S = \dfrac{1}{2} |F_1F_2| \cdot |y_1 - y_2| = \dfrac{1}{2} \times 2 \times |y_1 - y_2| = |y_1 - y_2|$。

$$S = \frac{12\sqrt{m^2 + 1}}{3m^2 + 4}$$

设 $t = \sqrt{m^2 + 1} \geqslant 1$，则 $m^2 = t^2 - 1$：

$$S = \frac{12t}{3(t^2 - 1) + 4} = \frac{12t}{3t^2 + 1}$$

$$S' = \frac{12(3t^2 + 1) - 12t \cdot 6t}{(3t^2 + 1)^2} = \frac{12 - 36t^2}{(3t^2 + 1)^2}$$

当 $t^2 = \dfrac{1}{3}$ 时 $S' = 0$，但 $t \geqslant 1$，所以 $S' < 0$（$t \geqslant 1$ 时），$S$ 在 $t = 1$（即 $m = 0$）时取最大值。

$$S_{\max} = \frac{12 \times 1}{3 + 1} = 3$$

$$\boxed{S_{\max} = 3}$$

**⚠️ 易错提醒：** 第（2）问中，设直线方程时要注意包含斜率不存在的情况。利用 $S = \dfrac{1}{2}|F_1F_2| \cdot |y_1 - y_2|$ 可以简化计算，避免直接求弦长。

**💡 解题思路总结：** 椭圆中的最值问题，关键是利用椭圆定义建立目标函数的表达式，再通过代数方法（换元、求导等）求最值。面积问题中，利用焦点到直线的距离和弦长的关系可以简化计算。
