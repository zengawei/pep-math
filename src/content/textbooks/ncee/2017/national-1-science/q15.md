**题目：** 在 $\triangle ABC$ 中，$a, b, c$ 分别为角 $A, B, C$ 的对边，已知 $b = 2$，$B = \dfrac{\pi}{3}$，则 $a + c$ 的最大值为 ______。

---

**解答：**

**第1步：** 利用余弦定理
> 📌 运用知识点：余弦定理

$$b^2 = a^2 + c^2 - 2ac\cos B \implies 4 = a^2 + c^2 - ac$$

**第2步：** 利用基本不等式
> 📌 运用知识点：基本不等式

因为 $a^2 + c^2 \geqslant \dfrac{(a + c)^2}{2}$，且 $ac \leqslant \dfrac{(a + c)^2}{4}$，所以：

$$4 = a^2 + c^2 - ac \geqslant \frac{(a + c)^2}{2} - \frac{(a + c)^2}{4} = \frac{(a + c)^2}{4}$$

$$(a + c)^2 \leqslant 16 \implies a + c \leqslant 4$$

**第3步：** 验证等号成立条件

当 $a = c$ 时，$4 = 2a^2 - a^2 = a^2$，$a = 2$，$a + c = 4$。此时三角形为等边三角形，满足条件。

**答案：$4$**
