**题目：** 已知 $F$ 为抛物线 $C: y^2 = 4x$ 的焦点，过 $F$ 的直线 $l$ 与 $C$ 交于 $A, B$ 两点，$|AF| = 3$，则 $|BF| = $ ______。

---

**解答：**

**第1步：** 确定焦点和准线
> 📌 运用知识点：parabola-definition

$y^2 = 4x$，$2p = 4$，$p = 2$。

焦点 $F(1, 0)$，准线 $x = -1$。

**第2步：** 利用焦半径公式
> 📌 运用知识点：parabola-properties

设 $A(x_1, y_1)$，$B(x_2, y_2)$。

由焦半径公式：$|AF| = x_1 + 1 = 3$，所以 $x_1 = 2$。

$y_1^2 = 4 \times 2 = 8$，$y_1 = \pm 2\sqrt{2}$。

**第3步：** 利用焦点弦性质
> 📌 运用知识点：parabola-properties

过焦点的直线与抛物线交于两点，满足：

$$\frac{1}{|AF|} + \frac{1}{|BF|} = \frac{2}{p} = \frac{2}{2} = 1$$

$$\frac{1}{3} + \frac{1}{|BF|} = 1$$

$$\frac{1}{|BF|} = 1 - \frac{1}{3} = \frac{2}{3}$$

$$|BF| = \frac{3}{2}$$

**答案：$\dfrac{3}{2}$**

**⚠️ 易错提醒：** ①抛物线 $y^2 = 4x$ 中 $p = 2$（不是 $p = 4$），焦半径公式为 $|AF| = x_1 + \dfrac{p}{2} = x_1 + 1$。②焦点弦性质 $\dfrac{1}{|AF|} + \dfrac{1}{|BF|} = \dfrac{2}{p}$ 是抛物线的重要结论，可以直接使用。

**💡 解题思路总结：** 抛物线焦点弦问题中，焦半径公式和焦点弦性质 $\dfrac{1}{|AF|} + \dfrac{1}{|BF|} = \dfrac{2}{p}$ 是核心工具。已知一个焦半径，可直接求另一个。
