**题目：** 若 $f(x) = \cos\left(2x + \dfrac{\pi}{3}\right)$，则 $f(x)$ 的一条对称轴为（  ）

A. $x = \dfrac{\pi}{6}$

B. $x = \dfrac{\pi}{3}$

C. $x = -\dfrac{\pi}{6}$

D. $x = \dfrac{\pi}{12}$

---

**解答：**

**第1步：** 确定对称轴的条件
> 📌 运用知识点：trig-graph

$y = \cos x$ 的对称轴为 $x = k\pi$（$k \in \mathbb{Z}$），即 $\cos$ 取极值的位置。

所以 $f(x) = \cos\left(2x + \dfrac{\pi}{3}\right)$ 的对称轴满足：

$$2x + \frac{\pi}{3} = k\pi \quad (k \in \mathbb{Z})$$

**第2步：** 求解对称轴
> 📌 运用知识点：trig-function

$$2x = k\pi - \frac{\pi}{3}$$

$$x = \frac{k\pi}{2} - \frac{\pi}{6}$$

当 $k = 0$ 时：$x = -\dfrac{\pi}{6}$

当 $k = 1$ 时：$x = \dfrac{\pi}{2} - \dfrac{\pi}{6} = \dfrac{\pi}{3}$

**第3步：** 对照选项
> 📌 运用知识点：trig-graph

$x = -\dfrac{\pi}{6}$ 对应选项 C，$x = \dfrac{\pi}{3}$ 对应选项 B。

验证选项 B：$f\left(\dfrac{\pi}{3}\right) = \cos\left(\dfrac{2\pi}{3} + \dfrac{\pi}{3}\right) = \cos\pi = -1$（极值），✓

验证选项 C：$f\left(-\dfrac{\pi}{6}\right) = \cos\left(-\dfrac{\pi}{3} + \dfrac{\pi}{3}\right) = \cos 0 = 1$（极值），✓

选项 B 和 C 都是对称轴。取选项 B。

**答案：B**

**⚠️ 易错提醒：** 余弦函数的对称轴是函数取极值（$\pm 1$）的位置，即 $\cos$ 内部等于 $k\pi$，不是 $k\pi + \dfrac{\pi}{2}$（那是零点/对称中心）。

**💡 解题思路总结：** 求 $y = \cos(\omega x + \varphi)$ 的对称轴，令 $\omega x + \varphi = k\pi$，解出 $x$ 即可。
