**题目：** 等比数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n$，已知 $S_1, S_3, S_2$ 成等差数列，则 $\{a_n\}$ 的公比 $q = $ ______。

---

**解答：**

**第1步：** 建立等差关系
> 📌 运用知识点：geometric-sequence

$S_1, S_3, S_2$ 成等差数列，所以 $2S_3 = S_1 + S_2$。

**第2步：** 用 $a_1$ 和 $q$ 表示
> 📌 运用知识点：geometric-sequence-sum

$S_1 = a_1$

$S_2 = a_1 + a_1 q = a_1(1 + q)$

$S_3 = a_1 + a_1 q + a_1 q^2 = a_1(1 + q + q^2)$

代入等差条件：

$$2a_1(1 + q + q^2) = a_1 + a_1(1 + q)$$

因为 $a_1 \neq 0$，两边除以 $a_1$：

$$2(1 + q + q^2) = 1 + 1 + q = 2 + q$$

$$2 + 2q + 2q^2 = 2 + q$$

$$2q^2 + q = 0$$

$$q(2q + 1) = 0$$

**第3步：** 确定 $q$
> 📌 运用知识点：geometric-sequence

$q \neq 0$（否则不是等比数列），所以 $2q + 1 = 0$，$q = -\dfrac{1}{2}$。

**答案：$-\dfrac{1}{2}$**

**⚠️ 易错提醒：** ①"$S_1, S_3, S_2$ 成等差数列"意味着 $2S_3 = S_1 + S_2$（中间项的两倍等于两端之和），不要搞错顺序。②$q = 0$ 要舍去，因为等比数列的公比不为零。

**💡 解题思路总结：** 等差数列条件转化为等式，用 $a_1$ 和 $q$ 表示各项和，化简求解。注意检验 $q$ 的合理性。
