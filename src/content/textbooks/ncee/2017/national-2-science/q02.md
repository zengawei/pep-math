**题目：** 复数 $\dfrac{1 + 2\text{i}}{1 + \text{i}}$ 的模为（  ）

A. $\dfrac{\sqrt{10}}{2}$

B. $\dfrac{\sqrt{5}}{2}$

C. $\sqrt{5}$

D. $\sqrt{10}$

---

**解答：**

**第1步：** 化简复数
> 📌 运用知识点：complex-number-operations

分子分母同乘分母的共轭复数 $1 - \text{i}$：

$$\frac{1 + 2\text{i}}{1 + \text{i}} = \frac{(1 + 2\text{i})(1 - \text{i})}{(1 + \text{i})(1 - \text{i})}$$

分母：$(1 + \text{i})(1 - \text{i}) = 1 - \text{i}^2 = 1 + 1 = 2$

分子：$(1 + 2\text{i})(1 - \text{i}) = 1 - \text{i} + 2\text{i} - 2\text{i}^2 = 1 + \text{i} + 2 = 3 + \text{i}$

所以 $\dfrac{1 + 2\text{i}}{1 + \text{i}} = \dfrac{3 + \text{i}}{2} = \dfrac{3}{2} + \dfrac{1}{2}\text{i}$

**第2步：** 求模
> 📌 运用知识点：complex-number-operations

$$\left|\frac{3 + \text{i}}{2}\right| = \frac{|3 + \text{i}|}{|2|} = \frac{\sqrt{9 + 1}}{2} = \frac{\sqrt{10}}{2}$$

**答案：A**

**⚠️ 易错提醒：** 分子展开时 $\text{i}^2 = -1$，不要漏掉负号。$-2\text{i}^2 = -2 \times (-1) = 2$。

**💡 解题思路总结：** 复数除法的核心操作是分子分母同乘分母的共轭复数，使分母变为实数。求模可以直接对化简后的复数计算，也可以利用 $|z_1/z_2| = |z_1|/|z_2|$ 的性质。
