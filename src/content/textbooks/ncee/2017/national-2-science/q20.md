**题目：** 已知椭圆 $C: \dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$）的左顶点为 $A(-2, 0)$，右焦点为 $F(1, 0)$。

(1) 求椭圆 $C$ 的方程；

(2) 设过点 $F$ 的直线 $l$ 交 $C$ 于 $M, N$ 两点，若 $\triangle AMN$ 的面积为 $\dfrac{18\sqrt{2}}{7}$，求 $l$ 的方程。

---

**解答：**

**第1步：** 求椭圆方程（第1问）
> 📌 运用知识点：ellipse-properties

左顶点 $A(-2, 0)$，所以 $a = 2$。

右焦点 $F(1, 0)$，所以 $c = 1$。

$b^2 = a^2 - c^2 = 4 - 1 = 3$。

**椭圆 $C$ 的方程为 $\dfrac{x^2}{4} + \dfrac{y^2}{3} = 1$。**

**第2步：** 设直线方程并联立（第2问）
> 📌 运用知识点：conic-section-line

当 $l$ 斜率不存在时，$l: x = 1$，代入椭圆得 $y = \pm\dfrac{3}{2}$。

$|MN| = 3$，$A(-2,0)$ 到 $x = 1$ 的距离 $d = 3$，$S = \dfrac{1}{2} \times 3 \times 3 = \dfrac{9}{2} \neq \dfrac{18\sqrt{2}}{7}$。

所以斜率存在，设 $l: y = k(x - 1)$。

代入椭圆方程：

$$\frac{x^2}{4} + \frac{k^2(x-1)^2}{3} = 1$$

$$3x^2 + 4k^2(x-1)^2 = 12$$

$$(3 + 4k^2)x^2 - 8k^2 x + 4k^2 - 12 = 0$$

**第3步：** 利用韦达定理和弦长公式
> 📌 运用知识点：conic-section-line

设 $M(x_1, y_1)$，$N(x_2, y_2)$：

$$x_1 + x_2 = \frac{8k^2}{3 + 4k^2}, \quad x_1 x_2 = \frac{4k^2 - 12}{3 + 4k^2}$$

$$(x_1 - x_2)^2 = (x_1+x_2)^2 - 4x_1 x_2 = \frac{64k^4}{(3+4k^2)^2} - \frac{4(4k^2-12)}{3+4k^2}$$

$$= \frac{64k^4 - 4(4k^2-12)(3+4k^2)}{(3+4k^2)^2} = \frac{64k^4 - 4(12k^2 + 16k^4 - 36 - 48k^2)}{(3+4k^2)^2}$$

$$= \frac{64k^4 - 64k^4 + 144k^2 + 144}{(3+4k^2)^2} = \frac{144(k^2+1)}{(3+4k^2)^2}$$

$$|MN| = \sqrt{1+k^2} \cdot |x_1 - x_2| = \sqrt{1+k^2} \cdot \frac{12\sqrt{k^2+1}}{3+4k^2} = \frac{12(k^2+1)}{3+4k^2}$$

**第4步：** 利用面积条件求 $k$
> 📌 运用知识点：conic-section-optimization

$A(-2, 0)$ 到直线 $kx - y - k = 0$ 的距离：

$$d = \frac{|-2k - 0 - k|}{\sqrt{k^2+1}} = \frac{3|k|}{\sqrt{k^2+1}}$$

$$S = \frac{1}{2} |MN| \cdot d = \frac{1}{2} \cdot \frac{12(k^2+1)}{3+4k^2} \cdot \frac{3|k|}{\sqrt{k^2+1}} = \frac{18|k|\sqrt{k^2+1}}{3+4k^2}$$

令 $S = \dfrac{18\sqrt{2}}{7}$：

$$\frac{18|k|\sqrt{k^2+1}}{3+4k^2} = \frac{18\sqrt{2}}{7}$$

$$\frac{|k|\sqrt{k^2+1}}{3+4k^2} = \frac{\sqrt{2}}{7}$$

两边平方：

$$\frac{k^2(k^2+1)}{(3+4k^2)^2} = \frac{2}{49}$$

$$49k^2(k^2+1) = 2(3+4k^2)^2 = 2(9 + 24k^2 + 16k^4)$$

$$49k^4 + 49k^2 = 18 + 48k^2 + 32k^4$$

$$17k^4 + k^2 - 18 = 0$$

$$(17k^2 + 18)(k^2 - 1) = 0$$

因为 $17k^2 + 18 > 0$，所以 $k^2 = 1$，$k = \pm 1$。

**答案：(1) $\dfrac{x^2}{4} + \dfrac{y^2}{3} = 1$；(2) $l: y = x - 1$ 或 $y = -(x - 1)$**

**⚠️ 易错提醒：** ①设直线时要考虑斜率不存在的情况。②弦长公式 $|MN| = \sqrt{1+k^2}|x_1 - x_2|$ 中不要漏掉 $\sqrt{1+k^2}$。③最后解方程 $(17k^2+18)(k^2-1) = 0$ 时注意 $17k^2+18 > 0$ 恒成立。

**💡 解题思路总结：** 椭圆与直线综合问题的标准流程：设直线 → 联立方程 → 韦达定理 → 弦长公式 → 面积公式 → 解方程求参数。因式分解是关键一步。
