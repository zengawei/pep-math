**题目：** 已知集合 $A = \{x \mid x^2 - x - 2 \leqslant 0\}$，$B = \{x \mid x < 1\}$，则 $A \cap B = $（  ）

A. $\{-1, 0\}$

B. $\{-1, 0, 1\}$

C. $\{x \mid -1 \leqslant x < 1\}$

D. $\{x \mid -1 \leqslant x \leqslant 2\}$

---

**解答：**

**第1步：** 求解集合 $A$
> 📌 运用知识点：set-operations

解不等式 $x^2 - x - 2 \leqslant 0$。

因式分解：$(x - 2)(x + 1) \leqslant 0$

令 $(x-2)(x+1) = 0$，得 $x = -1$ 或 $x = 2$。

由二次函数图像（开口向上），不等式的解为 $-1 \leqslant x \leqslant 2$。

所以 $A = \{x \mid -1 \leqslant x \leqslant 2\}$。

**第2步：** 求 $A \cap B$
> 📌 运用知识点：set-operations

$A = \{x \mid -1 \leqslant x \leqslant 2\}$，$B = \{x \mid x < 1\}$。

$A \cap B = \{x \mid -1 \leqslant x \leqslant 2 \text{ 且 } x < 1\} = \{x \mid -1 \leqslant x < 1\}$。

**答案：C**

**⚠️ 易错提醒：** 注意集合 $B$ 的条件是 $x < 1$（严格小于），所以 $x = 1$ 不属于 $B$，交集右端为开区间。另外集合 $A$ 的端点 $x = -1$ 和 $x = 2$ 都取到（$\leqslant$）。

**💡 解题思路总结：** 先解一元二次不等式确定集合 $A$，再与集合 $B$ 取交集。注意端点的开闭。
