**题目：** $\triangle ABC$ 的内角 $A, B, C$ 的对边分别为 $a, b, c$，已知 $b = 2$，$B = \dfrac{\pi}{3}$，$\sin A + \sin C = 2\sin B$。

(1) 求 $a + c$ 的值；

(2) 求 $\triangle ABC$ 的面积的最大值。

---

**解答：**

**第1步：** 利用正弦定理求 $a + c$（第1问）
> 📌 运用知识点：trig-function

由正弦定理 $\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C} = 2R$：

$\sin A = \dfrac{a}{2R}$，$\sin C = \dfrac{c}{2R}$，$\sin B = \dfrac{b}{2R}$

代入 $\sin A + \sin C = 2\sin B$：

$$\frac{a}{2R} + \frac{c}{2R} = 2 \cdot \frac{b}{2R}$$

$$a + c = 2b = 2 \times 2 = 4$$

**第2步：** 利用余弦定理建立 $ac$ 的关系
> 📌 运用知识点：trig-identity

由余弦定理：$b^2 = a^2 + c^2 - 2ac\cos B$

$$4 = a^2 + c^2 - 2ac\cos\frac{\pi}{3} = a^2 + c^2 - ac$$

又 $(a + c)^2 = a^2 + 2ac + c^2 = 16$，所以 $a^2 + c^2 = 16 - 2ac$。

代入：$4 = 16 - 2ac - ac = 16 - 3ac$

$$3ac = 12 \implies ac = 4$$

**第3步：** 求面积最大值（第2问）
> 📌 运用知识点：trig-identity

$$S = \frac{1}{2}ac\sin B = \frac{1}{2} \times 4 \times \sin\frac{\pi}{3} = \frac{1}{2} \times 4 \times \frac{\sqrt{3}}{2} = \sqrt{3}$$

验证：$a + c = 4$，$ac = 4$，则 $a, c$ 是方程 $t^2 - 4t + 4 = 0$ 的根，$(t-2)^2 = 0$，$a = c = 2$。

此时 $\triangle ABC$ 为等边三角形，满足条件。

**答案：(1) $a + c = 4$；(2) $S_{\max} = \sqrt{3}$**

**⚠️ 易错提醒：** ①正弦定理的边角互化是解三角形的第一步。②余弦定理中 $\cos\dfrac{\pi}{3} = \dfrac{1}{2}$，不要算错。③本题中 $ac$ 的值是确定的（$ac = 4$），所以面积也是确定值，不需要用均值不等式求最值。

**💡 解题思路总结：** 解三角形问题中，正弦定理实现边角互化，余弦定理建立边的关系。面积公式 $S = \dfrac{1}{2}ac\sin B$ 需要 $ac$ 的值。
