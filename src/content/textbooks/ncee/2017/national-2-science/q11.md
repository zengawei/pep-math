**题目：** 等差数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n$，已知 $a_3 = 3$，$S_4 = 10$，则 $\displaystyle\sum_{k=1}^{n} \dfrac{1}{S_k} = $（  ）

A. $\dfrac{n}{n+1}$

B. $\dfrac{2n}{n+1}$

C. $\dfrac{n}{2(n+1)}$

D. $\dfrac{2n}{n+2}$

---

**解答：**

**第1步：** 求等差数列的通项公式
> 📌 运用知识点：arithmetic-sequence-sum

设首项为 $a_1$，公差为 $d$。

$a_3 = a_1 + 2d = 3$

$S_4 = 4a_1 + 6d = 10$，即 $2a_1 + 3d = 5$

由 $a_1 + 2d = 3$ 得 $a_1 = 3 - 2d$，代入：

$2(3 - 2d) + 3d = 5 \implies 6 - 4d + 3d = 5 \implies d = 1$

$a_1 = 3 - 2 = 1$

所以 $a_n = n$。

**第2步：** 求 $S_n$
> 📌 运用知识点：arithmetic-sequence-sum

$$S_n = \frac{n(a_1 + a_n)}{2} = \frac{n(1 + n)}{2} = \frac{n(n+1)}{2}$$

**第3步：** 裂项求和
> 📌 运用知识点：sequence-sum-methods

$$\frac{1}{S_k} = \frac{2}{k(k+1)} = 2\left(\frac{1}{k} - \frac{1}{k+1}\right)$$

$$\sum_{k=1}^{n} \frac{1}{S_k} = 2\sum_{k=1}^{n}\left(\frac{1}{k} - \frac{1}{k+1}\right)$$

$$= 2\left[\left(1 - \frac{1}{2}\right) + \left(\frac{1}{2} - \frac{1}{3}\right) + \cdots + \left(\frac{1}{n} - \frac{1}{n+1}\right)\right]$$

$$= 2\left(1 - \frac{1}{n+1}\right) = 2 \cdot \frac{n}{n+1} = \frac{2n}{n+1}$$

**答案：B**

**⚠️ 易错提醒：** ①裂项时 $\dfrac{2}{k(k+1)} = 2\left(\dfrac{1}{k} - \dfrac{1}{k+1}\right)$，系数 $2$ 不要遗漏。②消项后只剩首尾两项，中间全部消去。

**💡 解题思路总结：** 等差数列求通项 → 求 $S_n$ → 对 $\dfrac{1}{S_n}$ 裂项 → 裂项相消求和。这是高考中数列求和的经典方法。
