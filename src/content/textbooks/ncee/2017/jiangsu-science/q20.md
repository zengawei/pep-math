**题目：** 某公司的利润函数为 $L(x) = -x^3 + 9x^2 - 15x - 2$（万元），其中 $x$ 为产量（万件），$x \in (0, 6]$。

（1）求利润函数 $L(x)$ 的单调区间；

（2）当产量为多少时，利润最大？最大利润是多少？

---

**解答：**

**第1步：** 求导数
> 📌 运用知识点：导数的运算

$$L'(x) = -3x^2 + 18x - 15 = -3(x^2 - 6x + 5) = -3(x - 1)(x - 5)$$

**第2步：** 确定单调区间
> 📌 运用知识点：导数与单调性

$L'(x) > 0$：$(x-1)(x-5) < 0 \implies 1 < x < 5$。递增区间 $(1, 5)$。

$L'(x) < 0$：$x < 1$ 或 $x > 5$。递减区间 $(0, 1)$ 和 $(5, 6]$。

**第3步：** 求最大利润
> 📌 运用知识点：导数与最值

$L(x)$ 在 $x = 5$ 处取极大值（也是最大值）：

$$L(5) = -125 + 225 - 75 - 2 = 23$$

$$\boxed{\text{当产量为 } 5 \text{ 万件时，最大利润为 } 23 \text{ 万元}}$$

**⚠️ 易错提醒：** 注意定义域是 $(0, 6]$，需要检查端点 $x = 6$：$L(6) = -216 + 324 - 90 - 2 = 16 < 23$。

**💡 解题思路总结：** 实际应用题求最值：求导 → 确定单调区间 → 比较极值和端点值。
