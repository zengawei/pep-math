**题目：** 已知某几何体是一个长方体，其三视图表明该长方体的长、宽、高分别为 $4, 4, 3$，则该长方体的外接球的表面积为 ______。

---

**解答：**

**第1步：** 求外接球半径
> 📌 运用知识点：长方体的外接球

长方体的外接球直径等于体对角线：

$$2R = \sqrt{4^2 + 4^2 + 3^2} = \sqrt{16 + 16 + 9} = \sqrt{41}$$

$$R = \frac{\sqrt{41}}{2}$$

**第2步：** 求表面积

$$S = 4\pi R^2 = 4\pi \times \frac{41}{4} = 41\pi$$

**答案：$\boxed{41\pi}$**

**⚠️ 易错提醒：** 长方体外接球的直径 = 体对角线长 = $\sqrt{a^2 + b^2 + c^2}$。

**💡 解题思路总结：** 长方体外接球问题直接用体对角线公式。
