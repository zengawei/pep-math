**题目：** 已知函数 $f(x) = x^3 - 3x + 1$ 在区间 $[-1, 2]$ 上的最大值为 $M$，最小值为 $m$，则 $M + m =$

A. $0$

B. $1$

C. $2$

D. $-1$

---

**解答：**

**第1步：** 求临界点
> 📌 运用知识点：导数与最值

$f'(x) = 3x^2 - 3 = 3(x+1)(x-1)$。临界点 $x = -1, 1$。

**第2步：** 比较函数值
> 📌 运用知识点：导数与最值

$$f(-1) = -1 + 3 + 1 = 3$$
$$f(1) = 1 - 3 + 1 = -1$$
$$f(2) = 8 - 6 + 1 = 3$$

$M = 3$，$m = -1$。$M + m = 2$。

**答案：C**

**⚠️ 易错提醒：** 闭区间最值需要比较所有临界点和端点的函数值。$f(-1) = f(2) = 3$。

**💡 解题思路总结：** 闭区间最值 = 比较临界点和端点值。
