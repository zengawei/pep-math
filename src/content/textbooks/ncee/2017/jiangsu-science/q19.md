**题目：** 如图，在四棱锥 $P\text{-}ABCD$ 中，底面 $ABCD$ 是正方形，$PA \perp$ 底面 $ABCD$，$PA = AB = 2$，$E$ 是 $PB$ 的中点。

（1）求证：$PD \parallel$ 平面 $EAC$；

（2）求直线 $PC$ 与平面 $EAC$ 所成角的正弦值。

---

**解答：**

**第1步：** 建系求坐标
> 📌 运用知识点：空间直角坐标系

$A = (0, 0, 0)$，$B = (2, 0, 0)$，$C = (2, 2, 0)$，$D = (0, 2, 0)$，$P = (0, 0, 2)$。

$E$ 为 $PB$ 中点：$E = (1, 0, 1)$。

**第2步：** 证明 $PD \parallel$ 平面 $EAC$
> 📌 运用知识点：空间向量

$\vec{PD} = (0, 2, -2)$。$\vec{AC} = (2, 2, 0)$，$\vec{AE} = (1, 0, 1)$。

设 $\vec{PD} = \alpha \vec{AC} + \beta \vec{AE}$：$(0, 2, -2) = (2\alpha + \beta, 2\alpha, \beta)$。

$\beta = -2$，$2\alpha = 2 \implies \alpha = 1$。验证：$2(1) + (-2) = 0$ ✓。

$\vec{PD}$ 可由 $\vec{AC}, \vec{AE}$ 线性表示，且 $P \notin$ 平面 $EAC$，所以 $PD \parallel$ 平面 $EAC$。$\blacksquare$

**第3步：** 求线面角
> 📌 运用知识点：空间向量求线面角

平面 $EAC$ 的法向量 $\vec{n} = \vec{AC} \times \vec{AE} = (2, 2, 0) \times (1, 0, 1) = (2, -2, -2)$。

化简取 $\vec{n} = (1, -1, -1)$。

$\vec{PC} = (2, 2, -2)$。

$$\sin\theta = \frac{|\vec{PC} \cdot \vec{n}|}{|\vec{PC}| \cdot |\vec{n}|} = \frac{|2 - 2 + 2|}{\sqrt{12} \cdot \sqrt{3}} = \frac{2}{6} = \frac{1}{3}$$

$$\boxed{\sin\theta = \dfrac{1}{3}}$$

**⚠️ 易错提醒：** 证明线面平行需要验证点不在平面内。线面角的正弦 = 方向向量与法向量夹角余弦的绝对值。

**💡 解题思路总结：** 向量法证明平行：目标向量可被平面内两向量线性表示。线面角用 $\sin\theta = \dfrac{|\vec{v} \cdot \vec{n}|}{|\vec{v}||\vec{n}|}$。
