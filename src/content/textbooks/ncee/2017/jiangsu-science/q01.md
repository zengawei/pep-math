**题目：** 已知集合 $A = \{x \mid -1 < x < 3\}$，$B = \{x \mid 0 < x < 4\}$，则 $A \cap B =$

A. $(0, 3)$

B. $(1, 4)$

C. $(0, 4)$

D. $(-1, 3)$

---

**解答：**

**第1步：** 求交集
> 📌 运用知识点：集合的交集运算

$A = (-1, 3)$，$B = (0, 4)$。取公共部分：

$$A \cap B = (0, 3)$$

**答案：A**

**⚠️ 易错提醒：** 交集取两个区间的重叠部分，左端点取较大的，右端点取较小的。

**💡 解题思路总结：** 区间交集在数轴上直观表示即可。
