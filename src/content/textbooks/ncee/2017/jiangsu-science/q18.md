**题目：** 已知数列 $\{a_n\}$ 满足 $a_1 = 1$，$a_{n+1} = 2a_n + 1$（$n \in \mathbb{N}^*$）。

（1）求数列 $\{a_n\}$ 的通项公式；

（2）设 $b_n = \dfrac{a_n}{2^n}$，求数列 $\{b_n\}$ 的前 $n$ 项和 $T_n$。

---

**解答：**

**第1步：** 求通项公式
> 📌 运用知识点：数列的递推公式

$a_{n+1} + 1 = 2(a_n + 1)$。设 $c_n = a_n + 1$，则 $c_{n+1} = 2c_n$，$c_1 = 2$。

$\{c_n\}$ 是等比数列：$c_n = 2 \times 2^{n-1} = 2^n$。

$$\boxed{a_n = 2^n - 1}$$

**第2步：** 求 $T_n$
> 📌 运用知识点：数列求和

$$b_n = \frac{a_n}{2^n} = \frac{2^n - 1}{2^n} = 1 - \frac{1}{2^n}$$

$$T_n = \sum_{k=1}^{n} \left(1 - \frac{1}{2^k}\right) = n - \sum_{k=1}^{n} \frac{1}{2^k} = n - \frac{\frac{1}{2}(1 - \frac{1}{2^n})}{1 - \frac{1}{2}} = n - 1 + \frac{1}{2^n}$$

$$\boxed{T_n = n - 1 + \frac{1}{2^n}}$$

**⚠️ 易错提醒：** 构造 $c_n = a_n + 1$ 是处理 $a_{n+1} = pa_n + q$ 型递推的标准方法。$b_n$ 的求和分成 $n$ 个 $1$ 减去等比数列求和。

**💡 解题思路总结：** 线性递推 $a_{n+1} = pa_n + q$：加常数构造等比数列。求和时拆分简化。
