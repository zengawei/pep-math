设集合 $A = \{x \mid x > 0\}$，$B = \{x \mid x^2 - x - 2 \leq 0\}$，则 $A \cap B = $（）

(A) $(0, 2]$

(B) $[-1, 2]$

(C) $(0, 1]$

(D) $[0, 2]$

---

**解题过程：**

解不等式 $x^2 - x - 2 \leq 0$：

$$x^2 - x - 2 = (x - 2)(x + 1) \leq 0$$

解得 $-1 \leq x \leq 2$，即 $B = [-1, 2]$。

又 $A = (0, +\infty)$，所以

$$A \cap B = (0, +\infty) \cap [-1, 2] = (0, 2]$$

> 📌 运用知识点：集合的交集运算、一元二次不等式求解

**正确答案：** (A)
