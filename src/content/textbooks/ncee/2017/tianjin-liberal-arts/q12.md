已知向量 $\boldsymbol{a} = (2, 1)$，$\boldsymbol{b} = (-1, 3)$，若 $\boldsymbol{c} = 2\boldsymbol{a} - \boldsymbol{b}$，则 $|\boldsymbol{c}| = $ ______。

---

**解题过程：**

先求向量 $\boldsymbol{c}$ 的坐标：

$$\boldsymbol{c} = 2\boldsymbol{a} - \boldsymbol{b} = 2(2, 1) - (-1, 3) = (4, 2) - (-1, 3) = (4 + 1, 2 - 3) = (5, -1)$$

再求模：

$$|\boldsymbol{c}| = \sqrt{5^2 + (-1)^2} = \sqrt{25 + 1} = \sqrt{26}$$

> 📌 运用知识点：向量的坐标运算、向量模的计算

**正确答案：** $\sqrt{26}$
