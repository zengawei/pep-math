已知椭圆 $C: \dfrac{x^2}{4} + \dfrac{y^2}{3} = 1$。

（1）求椭圆 $C$ 的离心率；

（2）过点 $P(1, 0)$ 的直线 $l$ 与椭圆 $C$ 交于 $A, B$ 两点，若 $|AB| = \dfrac{24}{7}$，求直线 $l$ 的方程。

---

**解题过程：**

**（1）求离心率**

由椭圆方程 $\dfrac{x^2}{4} + \dfrac{y^2}{3} = 1$，得 $a^2 = 4$，$b^2 = 3$。

$$c^2 = a^2 - b^2 = 4 - 3 = 1$$

$$e = \frac{c}{a} = \frac{1}{2}$$

**（2）求直线 $l$ 的方程**

设直线 $l$ 的方程为 $x = my + 1$（设为此形式可同时包含斜率存在和不存在的情况）。

代入椭圆方程：

$$\frac{(my + 1)^2}{4} + \frac{y^2}{3} = 1$$

两边乘 $12$：

$$3(my + 1)^2 + 4y^2 = 12$$

$$3m^2y^2 + 6my + 3 + 4y^2 = 12$$

$$(3m^2 + 4)y^2 + 6my - 9 = 0$$

设 $A(x_1, y_1)$，$B(x_2, y_2)$，由韦达定理：

$$y_1 + y_2 = \frac{-6m}{3m^2 + 4}, \quad y_1 y_2 = \frac{-9}{3m^2 + 4}$$

计算 $(y_1 - y_2)^2$：

$$(y_1 - y_2)^2 = (y_1 + y_2)^2 - 4y_1 y_2 = \frac{36m^2}{(3m^2 + 4)^2} + \frac{36}{3m^2 + 4} = \frac{36m^2 + 36(3m^2 + 4)}{(3m^2 + 4)^2} = \frac{144(m^2 + 1)}{(3m^2 + 4)^2}$$

弦长公式：

$$|AB|^2 = (1 + m^2)(y_1 - y_2)^2 \quad \text{（注意此处 } x = my+1 \text{，所以 } \Delta x = m\Delta y\text{）}$$

等等，修正：因为 $x = my + 1$，所以 $x_1 - x_2 = m(y_1 - y_2)$，

$$|AB|^2 = (x_1 - x_2)^2 + (y_1 - y_2)^2 = (m^2 + 1)(y_1 - y_2)^2$$

$$|AB|^2 = (m^2 + 1) \cdot \frac{144(m^2 + 1)}{(3m^2 + 4)^2} = \frac{144(m^2 + 1)^2}{(3m^2 + 4)^2}$$

$$|AB| = \frac{12(m^2 + 1)}{3m^2 + 4}$$

令 $|AB| = \dfrac{24}{7}$：

$$\frac{12(m^2 + 1)}{3m^2 + 4} = \frac{24}{7}$$

$$84(m^2 + 1) = 24(3m^2 + 4)$$

$$84m^2 + 84 = 72m^2 + 96$$

$$12m^2 = 12 \implies m^2 = 1 \implies m = \pm 1$$

当 $m = 1$ 时，$l: x = y + 1$，即 $y = x - 1$。

当 $m = -1$ 时，$l: x = -y + 1$，即 $y = -(x - 1) = -x + 1$。

**验证判别式**：当 $m = \pm 1$ 时，$(3m^2 + 4)y^2 + 6my - 9 = 7y^2 \pm 6y - 9 = 0$，$\Delta = 36 + 252 = 288 > 0$。✅

**⚠️ 易错提醒：**
- 设直线方程时，用 $x = my + 1$ 可以同时讨论斜率存在与不存在的情况，避免漏解。
- 弦长公式中注意 $x = my + 1$ 时 $|AB|^2 = (1 + m^2)(y_1 - y_2)^2$，不要与 $y = kx + b$ 的公式混淆。
- 最后要验证判别式 $\Delta > 0$，确保直线与椭圆确实有两个交点。

**💡 解题思路总结：**
- 第（1）问直接利用 $a, b, c$ 的关系求离心率。
- 第（2）问是典型的"直线与圆锥曲线"联立问题：设线 → 联立 → 韦达定理 → 弦长公式 → 解方程求参数。

**答案：**
（1）$e = \dfrac{1}{2}$；（2）直线 $l$ 的方程为 $y = x - 1$ 或 $y = -x + 1$。
