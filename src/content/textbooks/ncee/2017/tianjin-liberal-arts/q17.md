如图，在四棱锥 $P\text{-}ABCD$ 中，底面 $ABCD$ 是正方形，$PA \perp$ 底面 $ABCD$，$PA = AB = 2$，$E$ 是 $PB$ 的中点。

（1）求证：$PD \parallel$ 平面 $EAC$；

（2）求直线 $PC$ 与平面 $EAC$ 所成角的正弦值。

---

**解题过程：**

以 $A$ 为原点，$\overrightarrow{AB}, \overrightarrow{AD}, \overrightarrow{AP}$ 分别为 $x, y, z$ 轴正方向建立空间直角坐标系。

各点坐标为：$A(0,0,0)$，$B(2,0,0)$，$C(2,2,0)$，$D(0,2,0)$，$P(0,0,2)$。

$E$ 是 $PB$ 的中点，$E = \left(\dfrac{0+2}{2}, \dfrac{0+0}{2}, \dfrac{2+0}{2}\right) = (1, 0, 1)$。

**（1）证明 $PD \parallel$ 平面 $EAC$**

$$\overrightarrow{PD} = D - P = (0, 2, -2)$$

平面 $EAC$ 内两个向量：

$$\overrightarrow{EA} = A - E = (-1, 0, -1), \quad \overrightarrow{EC} = C - E = (1, 2, -1)$$

设平面 $EAC$ 的法向量 $\boldsymbol{n} = (x, y, z)$，则

$$\begin{cases} \boldsymbol{n} \cdot \overrightarrow{EA} = -x - z = 0 \\ \boldsymbol{n} \cdot \overrightarrow{EC} = x + 2y - z = 0 \end{cases}$$

由第一式 $z = -x$，代入第二式 $x + 2y + x = 0$，即 $2x + 2y = 0$，$y = -x$。

取 $x = 1$，得 $\boldsymbol{n} = (1, -1, -1)$。

验证 $\overrightarrow{PD} \cdot \boldsymbol{n} = 0 \times 1 + 2 \times (-1) + (-2) \times (-1) = 0 - 2 + 2 = 0$。

所以 $\overrightarrow{PD} \perp \boldsymbol{n}$，即 $PD$ 平行于平面 $EAC$ 或 $PD$ 在平面 $EAC$ 内。

又 $P(0,0,2)$ 不在平面 $EAC$ 上（验证：$\overrightarrow{EP} = (-1, 0, 1)$，$\overrightarrow{EP} \cdot \boldsymbol{n} = -1 + 0 - 1 = -2 \neq 0$），

所以 $PD \parallel$ 平面 $EAC$。$\blacksquare$

**（2）求直线 $PC$ 与平面 $EAC$ 所成角的正弦值**

$$\overrightarrow{PC} = C - P = (2, 2, -2), \quad |\overrightarrow{PC}| = \sqrt{4 + 4 + 4} = 2\sqrt{3}$$

$$|\boldsymbol{n}| = \sqrt{1 + 1 + 1} = \sqrt{3}$$

设直线 $PC$ 与平面 $EAC$ 所成角为 $\theta$，则

$$\sin\theta = \frac{|\overrightarrow{PC} \cdot \boldsymbol{n}|}{|\overrightarrow{PC}| \cdot |\boldsymbol{n}|} = \frac{|2 \times 1 + 2 \times (-1) + (-2) \times (-1)|}{2\sqrt{3} \times \sqrt{3}} = \frac{|2 - 2 + 2|}{6} = \frac{2}{6} = \frac{1}{3}$$

**⚠️ 易错提醒：**
- 证明线面平行时，除了验证方向向量与法向量垂直，还需说明该直线不在平面内。
- 线面角的正弦值等于方向向量与法向量夹角余弦的绝对值，注意公式是 $\sin\theta = \dfrac{|\boldsymbol{v} \cdot \boldsymbol{n}|}{|\boldsymbol{v}||\boldsymbol{n}|}$，不要与余弦值混淆。

**💡 解题思路总结：**
- 建系求坐标 → 求法向量 → 利用向量关系证明平行 → 利用向量夹角公式求线面角。
- 空间向量法是解决立体几何证明和计算问题的通用方法。

**答案：**
（1）证明见上；（2）直线 $PC$ 与平面 $EAC$ 所成角的正弦值为 $\dfrac{1}{3}$。
