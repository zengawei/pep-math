已知函数 $f(x) = x^3 - ax^2 + 1$（$a \in \mathbb{R}$）。

（1）当 $a = 3$ 时，求 $f(x)$ 的单调区间和极值；

（2）若 $f(x) \geq 0$ 在 $[0, +\infty)$ 上恒成立，求 $a$ 的取值范围。

---

**解题过程：**

$$f'(x) = 3x^2 - 2ax = x(3x - 2a)$$

**（1）当 $a = 3$ 时**

$$f'(x) = 3x^2 - 6x = 3x(x - 2)$$

令 $f'(x) = 0$，得 $x = 0$ 或 $x = 2$。

列表分析：

| $x$ | $(-\infty, 0)$ | $0$ | $(0, 2)$ | $2$ | $(2, +\infty)$ |
|-----|----------------|-----|----------|-----|----------------|
| $f'(x)$ | $+$ | $0$ | $-$ | $0$ | $+$ |
| $f(x)$ | 递增 | 极大值 | 递减 | 极小值 | 递增 |

- **单调递增区间**：$(-\infty, 0)$ 和 $(2, +\infty)$
- **单调递减区间**：$(0, 2)$
- **极大值**：$f(0) = 0 - 0 + 1 = 1$
- **极小值**：$f(2) = 8 - 12 + 1 = -3$

**（2）求 $a$ 的取值范围**

$f(x) \geq 0$ 在 $[0, +\infty)$ 上恒成立。

当 $x = 0$ 时，$f(0) = 1 \geq 0$，对任意 $a$ 成立。

当 $x > 0$ 时，$f(x) = x^3 - ax^2 + 1 \geq 0$，即

$$a \leq \frac{x^3 + 1}{x^2} = x + \frac{1}{x^2}$$

令 $g(x) = x + \dfrac{1}{x^2}$（$x > 0$），则需要 $a \leq g(x)_{\min}$。

$$g'(x) = 1 - \frac{2}{x^3} = \frac{x^3 - 2}{x^3}$$

令 $g'(x) = 0$，得 $x^3 = 2$，即 $x = \sqrt[3]{2}$。

- 当 $0 < x < \sqrt[3]{2}$ 时，$g'(x) < 0$，$g(x)$ 单调递减；
- 当 $x > \sqrt[3]{2}$ 时，$g'(x) > 0$，$g(x)$ 单调递增。

所以 $g(x)$ 在 $x = \sqrt[3]{2}$ 处取得最小值：

$$g(\sqrt[3]{2}) = \sqrt[3]{2} + \frac{1}{(\sqrt[3]{2})^2} = \sqrt[3]{2} + \frac{1}{\sqrt[3]{4}} = \sqrt[3]{2} + \frac{\sqrt[3]{2}}{2} = \frac{3\sqrt[3]{2}}{2}$$

因此 $a \leq \dfrac{3\sqrt[3]{2}}{2}$。

**⚠️ 易错提醒：**
- 第（2）问分离参数时，注意 $x > 0$ 才能除以 $x^2$，$x = 0$ 需单独讨论。
- 求 $g(x) = x + \dfrac{1}{x^2}$ 的最小值时，化简 $\dfrac{1}{(\sqrt[3]{2})^2} = \dfrac{1}{2^{2/3}} = 2^{-2/3} = \dfrac{2^{1/3}}{2} = \dfrac{\sqrt[3]{2}}{2}$，不要算错。

**💡 解题思路总结：**
- 第（1）问：求导 → 列表分析单调性和极值，属于基础题型。
- 第（2）问：恒成立问题 → 分离参数 → 转化为求函数最小值 → 利用导数求最值。这是导数压轴题的核心方法。

**答案：**
（1）单调递增区间为 $(-\infty, 0)$ 和 $(2, +\infty)$，单调递减区间为 $(0, 2)$；极大值 $f(0) = 1$，极小值 $f(2) = -3$；
（2）$a$ 的取值范围为 $a \leq \dfrac{3\sqrt[3]{2}}{2}$。
