在 $\triangle ABC$ 中，角 $A, B, C$ 的对边分别为 $a, b, c$，已知 $b \cos C + c \cos B = 2a \sin A$。

（1）求 $A$ 的值；

（2）若 $a = 2$，$b + c = 4$，求 $\triangle ABC$ 的面积。

---

**解题过程：**

**（1）求 $A$ 的值**

由正弦定理 $\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C} = 2R$，得 $a = 2R\sin A$，$b = 2R\sin B$，$c = 2R\sin C$。

代入已知等式 $b\cos C + c\cos B = 2a\sin A$：

$$2R\sin B\cos C + 2R\sin C\cos B = 2 \cdot 2R\sin A \cdot \sin A$$

两边除以 $2R$：

$$\sin B\cos C + \sin C\cos B = 2\sin^2 A$$

左边由和角公式化简：

$$\sin(B + C) = 2\sin^2 A$$

因为 $A + B + C = \pi$，所以 $\sin(B + C) = \sin(\pi - A) = \sin A$。

$$\sin A = 2\sin^2 A$$

$$\sin A(1 - 2\sin A) = 0$$

因为 $A \in (0, \pi)$，所以 $\sin A \neq 0$，故 $\sin A = \dfrac{1}{2}$。

$$A = \frac{\pi}{6} \quad \text{或} \quad A = \frac{5\pi}{6}$$

**（2）求 $\triangle ABC$ 的面积**

已知 $a = 2$，$b + c = 4$。

由余弦定理 $a^2 = b^2 + c^2 - 2bc\cos A$：

$$4 = (b + c)^2 - 2bc - 2bc\cos A = 16 - 2bc(1 + \cos A)$$

**当 $A = \dfrac{\pi}{6}$ 时**，$\cos A = \dfrac{\sqrt{3}}{2}$：

$$4 = 16 - 2bc\left(1 + \frac{\sqrt{3}}{2}\right) = 16 - bc(2 + \sqrt{3})$$

$$bc = \frac{12}{2 + \sqrt{3}} = \frac{12(2 - \sqrt{3})}{(2 + \sqrt{3})(2 - \sqrt{3})} = 12(2 - \sqrt{3})$$

验证：$bc = 12(2 - \sqrt{3}) \approx 3.22$，$(b+c)^2 - 4bc = 16 - 4 \times 12(2-\sqrt{3}) = 16 - 48(2-\sqrt{3}) \approx 16 - 12.86 = 3.14 > 0$，$b, c$ 有实数解。✅

面积 $S = \dfrac{1}{2}bc\sin A = \dfrac{1}{2} \times 12(2 - \sqrt{3}) \times \dfrac{1}{2} = 3(2 - \sqrt{3})$。

**当 $A = \dfrac{5\pi}{6}$ 时**，$\cos A = -\dfrac{\sqrt{3}}{2}$：

$$4 = 16 - 2bc\left(1 - \frac{\sqrt{3}}{2}\right) = 16 - bc(2 - \sqrt{3})$$

$$bc = \frac{12}{2 - \sqrt{3}} = 12(2 + \sqrt{3}) \approx 44.8$$

验证：$(b+c)^2 - 4bc = 16 - 4 \times 12(2+\sqrt{3}) < 0$，$b, c$ 无实数解。❌

综上，$A = \dfrac{\pi}{6}$，$\triangle ABC$ 的面积为 $3(2 - \sqrt{3})$。

**⚠️ 易错提醒：**
- 利用正弦定理将边的关系转化为角的关系时，注意 $\sin(B+C) = \sin A$ 的运用。
- 求 $A$ 时得到两个值，必须代入第二问验证 $b, c$ 是否为正实数，排除不合题意的解。

**💡 解题思路总结：**
- 第（1）问：正弦定理边角转化 → 和角公式化简 → 解三角方程。
- 第（2）问：余弦定理配合已知条件求 $bc$ → 面积公式求面积 → 注意验证解的合理性。

**答案：**
（1）$A = \dfrac{\pi}{6}$；（2）$\triangle ABC$ 的面积为 $3(2 - \sqrt{3})$。
