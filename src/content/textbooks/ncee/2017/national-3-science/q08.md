**题目：**

执行如图所示的程序框图，如果输入的 $n = 10$，则输出的 $S = $（）

（程序框图描述：初始 $S = 0$，$i = 1$。循环体：$S = S + \dfrac{1}{i(i+1)}$，$i = i + 1$。判断条件 $i > n$？若是则输出 $S$，否则继续循环。）

(A) $\dfrac{10}{11}$  (B) $\dfrac{9}{10}$  (C) $\dfrac{11}{12}$  (D) $\dfrac{10}{9}$

---

**解答：**

**第1步：** 分析程序框图的计算过程。
> 📌 运用知识点：数列求和

程序计算的是：

$$S = \sum_{i=1}^{10} \frac{1}{i(i+1)} = \frac{1}{1 \times 2} + \frac{1}{2 \times 3} + \cdots + \frac{1}{10 \times 11}$$

**第2步：** 利用裂项法求和。
> 📌 运用知识点：数列求和方法

$$\frac{1}{i(i+1)} = \frac{1}{i} - \frac{1}{i+1}$$

$$S = \left(1 - \frac{1}{2}\right) + \left(\frac{1}{2} - \frac{1}{3}\right) + \cdots + \left(\frac{1}{10} - \frac{1}{11}\right) = 1 - \frac{1}{11} = \frac{10}{11}$$

**正确答案：** (A)

**⚠️ 易错提醒：** 裂项求和时注意消项的规律，首项保留 $1$，末项保留 $-\dfrac{1}{11}$。注意循环次数是 $10$ 次（$i$ 从 $1$ 到 $10$）。

**💡 解题思路总结：** 程序框图与数列求和的结合：①读懂程序框图，明确求和表达式；②识别裂项求和的结构 $\frac{1}{n(n+1)} = \frac{1}{n} - \frac{1}{n+1}$；③利用消项法计算结果。
