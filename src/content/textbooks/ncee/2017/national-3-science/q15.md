**题目：**

$\triangle ABC$ 中，$C = \dfrac{\pi}{3}$，$a^2 + b^2 - ab = 4$，则 $a + b$ 的最大值为 ______。

---

**解答：**

**第1步：** 利用余弦定理验证条件。
> 📌 运用知识点：余弦定理

$c^2 = a^2 + b^2 - 2ab\cos C = a^2 + b^2 - 2ab \cdot \dfrac{1}{2} = a^2 + b^2 - ab = 4$。

所以 $c = 2$。

**第2步：** 利用基本不等式求 $a + b$ 的最大值。
> 📌 运用知识点：基本不等式

设 $s = a + b$，$p = ab$。

由 $a^2 + b^2 - ab = 4$：$s^2 - 2p - p = 4$，即 $s^2 - 3p = 4$，$p = \dfrac{s^2 - 4}{3}$。

由基本不等式 $p \leqslant \dfrac{s^2}{4}$：

$$\frac{s^2 - 4}{3} \leqslant \frac{s^2}{4}$$

$$4(s^2 - 4) \leqslant 3s^2$$

$$4s^2 - 16 \leqslant 3s^2$$

$$s^2 \leqslant 16 \implies s \leqslant 4$$

**第3步：** 验证等号成立条件。

等号成立条件：$a = b$ 时，$a^2 + a^2 - a^2 = 4 \implies a^2 = 4 \implies a = b = 2$。

验证：$a + b = 4$，$C = \dfrac{\pi}{3}$，$c = 2$，构成等边三角形。满足所有条件。

**正确答案：** $4$

**⚠️ 易错提醒：** 利用基本不等式 $ab \leqslant \dfrac{(a+b)^2}{4}$ 时，需要验证等号成立条件（$a = b = 2$）是否满足原方程和三角形条件。

**💡 解题思路总结：** 三角形中求边的和的最大值：①利用已知条件建立 $a+b$ 与 $ab$ 的关系；②利用基本不等式 $ab \leqslant \frac{(a+b)^2}{4}$ 建立不等式；③验证等号成立条件。
