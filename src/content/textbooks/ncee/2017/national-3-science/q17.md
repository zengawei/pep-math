**题目：**

$\triangle ABC$ 的内角 $A$，$B$，$C$ 的对边分别为 $a$，$b$，$c$。已知 $a^2 + b^2 - ab = c^2$。

（1）求 $C$；

（2）若 $a + b = 4$，求 $\triangle ABC$ 面积的最大值。

---

**解答：**

**（1）求 $C$**

**第1步：** 利用余弦定理。
> 📌 运用知识点：余弦定理

由余弦定理 $c^2 = a^2 + b^2 - 2ab\cos C$，与已知条件 $c^2 = a^2 + b^2 - ab$ 对比：

$$a^2 + b^2 - 2ab\cos C = a^2 + b^2 - ab$$

$$-2ab\cos C = -ab$$

$$\cos C = \frac{1}{2}$$

因为 $C \in (0, \pi)$，所以 $C = \dfrac{\pi}{3}$。

**（2）求面积最大值**

**第2步：** 建立面积表达式。
> 📌 运用知识点：三角形面积公式

$$S = \frac{1}{2}ab\sin C = \frac{1}{2}ab\sin\frac{\pi}{3} = \frac{\sqrt{3}}{4}ab$$

**第3步：** 利用基本不等式求 $ab$ 的最大值。
> 📌 运用知识点：基本不等式

由 $a + b = 4$ 和基本不等式：

$$ab \leqslant \left(\frac{a+b}{2}\right)^2 = \left(\frac{4}{2}\right)^2 = 4$$

等号成立条件：$a = b = 2$。

验证：$a^2 + b^2 - ab = 4 + 4 - 4 = 4 = c^2$，$c = 2$。满足条件。

**第4步：** 计算面积最大值。

$$S_{\max} = \frac{\sqrt{3}}{4} \times 4 = \sqrt{3}$$

**正确答案：** （1）$C = \dfrac{\pi}{3}$；（2）面积的最大值为 $\sqrt{3}$。

**⚠️ 易错提醒：**
1. 余弦定理对比时注意 $2\cos C$ 与系数的对应关系。
2. 利用基本不等式后必须验证等号成立条件是否满足原方程。

**💡 解题思路总结：** 三角形面积最值问题：①由已知条件（结合余弦定理）确定角；②写出面积关于边的表达式；③利用基本不等式或已知条件求最值。
