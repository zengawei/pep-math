**题目：**

已知函数 $f(x) = \ln(x + 1) - \dfrac{x^2}{x + 1}$。

（1）求 $f(x)$ 的单调区间；

（2）若 $f(x) \leqslant a$ 对 $x \in (-1, +\infty)$ 恒成立，求 $a$ 的最小值。

---

**解答：**

**（1）求单调区间**

**第1步：** 求导数。
> 📌 运用知识点：导数的运算

$$f'(x) = \frac{1}{x+1} - \frac{2x(x+1) - x^2 \cdot 1}{(x+1)^2} = \frac{1}{x+1} - \frac{x^2 + 2x}{(x+1)^2}$$

通分：

$$f'(x) = \frac{x + 1 - x^2 - 2x}{(x+1)^2} = \frac{-x^2 - x + 1}{(x+1)^2}$$

**第2步：** 分析 $f'(x)$ 的符号。
> 📌 运用知识点：导数与单调性

分母 $(x+1)^2 > 0$（$x > -1$），$f'(x)$ 的符号由分子 $g(x) = -x^2 - x + 1$ 决定。

令 $-x^2 - x + 1 = 0$，即 $x^2 + x - 1 = 0$：

$$x = \frac{-1 \pm \sqrt{5}}{2}$$

$x_1 = \dfrac{-1 - \sqrt{5}}{2} \approx -1.618 < -1$（不在定义域内），$x_2 = \dfrac{-1 + \sqrt{5}}{2} = \dfrac{\sqrt{5} - 1}{2}$。

$g(x)$ 为开口向下的抛物线，在 $x_2$ 左侧为正，右侧为负。

- 当 $-1 < x < \dfrac{\sqrt{5}-1}{2}$ 时，$f'(x) > 0$，$f(x)$ **单调递增**。
- 当 $x > \dfrac{\sqrt{5}-1}{2}$ 时，$f'(x) < 0$，$f(x)$ **单调递减**。

**（2）求 $a$ 的最小值**

**第3步：** 求 $f(x)$ 的最大值。
> 📌 运用知识点：导数与最值

$f(x)$ 在 $x_0 = \dfrac{\sqrt{5}-1}{2}$ 处取最大值。

注意 $x_0$ 满足 $x_0^2 + x_0 - 1 = 0$，即 $x_0^2 = 1 - x_0$。

$x_0 + 1 = \dfrac{\sqrt{5}+1}{2}$。

$$f(x_0) = \ln(x_0 + 1) - \frac{x_0^2}{x_0 + 1} = \ln\frac{\sqrt{5}+1}{2} - \frac{1 - x_0}{x_0 + 1}$$

计算 $\dfrac{1 - x_0}{x_0 + 1}$：

$$1 - x_0 = 1 - \frac{\sqrt{5}-1}{2} = \frac{3 - \sqrt{5}}{2}$$

$$\frac{1 - x_0}{x_0 + 1} = \frac{\frac{3-\sqrt{5}}{2}}{\frac{\sqrt{5}+1}{2}} = \frac{3-\sqrt{5}}{\sqrt{5}+1} = \frac{(3-\sqrt{5})(\sqrt{5}-1)}{(\sqrt{5}+1)(\sqrt{5}-1)} = \frac{3\sqrt{5} - 3 - 5 + \sqrt{5}}{4} = \frac{4\sqrt{5} - 8}{4} = \sqrt{5} - 2$$

因此：

$$f(x_0) = \ln\frac{\sqrt{5}+1}{2} - (\sqrt{5} - 2) = \ln\frac{\sqrt{5}+1}{2} + 2 - \sqrt{5}$$

$f(x) \leqslant a$ 恒成立，即 $a \geqslant f(x)_{\max} = f(x_0)$。

$a$ 的最小值为 $\ln\dfrac{\sqrt{5}+1}{2} + 2 - \sqrt{5}$。

**正确答案：** （1）递增区间 $\left(-1, \dfrac{\sqrt{5}-1}{2}\right)$，递减区间 $\left(\dfrac{\sqrt{5}-1}{2}, +\infty\right)$；（2）$a$ 的最小值为 $\ln\dfrac{\sqrt{5}+1}{2} + 2 - \sqrt{5}$。

**⚠️ 易错提醒：**
1. 求导时注意 $\dfrac{x^2}{x+1}$ 是商的形式，需要用商的求导法则。
2. 化简 $f'(x)$ 后注意分母恒正，只需分析分子 $-x^2 - x + 1$ 的符号。
3. 求最大值时利用 $x_0^2 + x_0 - 1 = 0$ 进行代换化简，避免复杂的数值计算。有理化分母时注意运算准确性。

**💡 解题思路总结：** 含对数的函数最值问题：①正确求导并化简；②令 $f'(x) = 0$ 求极值点；③利用极值点满足的方程进行代换化简，求最大值；④恒成立问题转化为 $a \geqslant f(x)_{\max}$。
