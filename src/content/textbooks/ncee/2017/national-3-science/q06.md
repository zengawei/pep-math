**题目：**

已知 $a = \log_2 \dfrac{3}{4}$，$b = \ln \dfrac{4}{3}$，$c = 2^{-\frac{1}{3}}$，则（）

(A) $a < b < c$  (B) $b < a < c$  (C) $c < b < a$  (D) $a < c < b$

---

**解答：**

**第1步：** 判断各值的正负和范围。
> 📌 运用知识点：指数函数与对数函数的性质

- $a = \log_2 \dfrac{3}{4}$：因为 $\dfrac{3}{4} < 1$，所以 $a < 0$。
- $b = \ln \dfrac{4}{3}$：因为 $\dfrac{4}{3} > 1$，所以 $b > 0$。又 $\dfrac{4}{3} < \mathrm{e}$，所以 $0 < b < 1$。
- $c = 2^{-1/3} = \dfrac{1}{\sqrt[3]{2}}$：因为 $\sqrt[3]{2} > 1$，所以 $0 < c < 1$。

**第2步：** 比较 $b$ 和 $c$ 的大小。
> 📌 运用知识点：基本不等式与估算

$b = \ln \dfrac{4}{3} \approx 0.288$

$c = 2^{-1/3} \approx \dfrac{1}{1.26} \approx 0.794$

因此 $c > b$。

综合：$a < 0 < b < c$，即 $a < b < c$。

**正确答案：** (A)

**⚠️ 易错提醒：** 比较不同底数的对数和指数值时，先判断正负，再利用特殊值（如 $0, 1$）作为参照进行比较。

**💡 解题思路总结：** 比较不同类型数的大小：①先按正负分类；②正数之间利用估算或与特殊值比较确定大小关系。
