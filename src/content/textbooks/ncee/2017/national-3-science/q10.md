**题目：**

已知 $F$ 为抛物线 $y^2 = 8x$ 的焦点，过 $F$ 的直线交该抛物线于 $A$，$B$ 两点，且 $|AF| + |BF| = 10$，则 $AB$ 的中点到 $y$ 轴的距离为（）

(A) $2$  (B) $3$  (C) $4$  (D) $5$

---

**解答：**

**第1步：** 确定抛物线的焦点和准线。
> 📌 运用知识点：抛物线的性质

抛物线 $y^2 = 8x$ 中，$2p = 8$，$p = 4$。焦点 $F(2, 0)$，准线 $x = -2$。

**第2步：** 利用抛物线的焦半径公式。
> 📌 运用知识点：抛物线的性质

设 $A(x_1, y_1)$，$B(x_2, y_2)$。由抛物线的焦半径公式：

$$|AF| = x_1 + \frac{p}{2} = x_1 + 2, \quad |BF| = x_2 + 2$$

$$|AF| + |BF| = x_1 + x_2 + 4 = 10$$

$$x_1 + x_2 = 6$$

**第3步：** 求中点到 $y$ 轴的距离。
> 📌 运用知识点：抛物线的性质

$AB$ 中点的横坐标为：

$$x_M = \frac{x_1 + x_2}{2} = \frac{6}{2} = 3$$

中点到 $y$ 轴的距离为 $3$。

**正确答案：** (B)

**⚠️ 易错提醒：** 抛物线 $y^2 = 2px$ 的焦半径为 $|PF| = x_0 + \dfrac{p}{2}$，注意 $y^2 = 8x$ 中 $p = 4$，$\dfrac{p}{2} = 2$。

**💡 解题思路总结：** 抛物线焦点弦问题：①利用焦半径公式将 $|AF| + |BF|$ 转化为 $x_1 + x_2$ 的表达式；②中点到 $y$ 轴的距离即为中点横坐标。
