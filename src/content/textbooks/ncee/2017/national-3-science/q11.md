**题目：**

已知双曲线 $C: \dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$（$a > 0$，$b > 0$）的离心率为 $\dfrac{\sqrt{5}}{2}$，左焦点为 $F$，点 $A(0, 2b)$，$C$ 为线段 $OA$ 的中点（$O$ 为原点），直线 $AF$ 与双曲线交于点 $D$，则 $\triangle ACD$ 的面积为（）

(A) $\dfrac{\sqrt{5}}{4}a^2$  (B) $\dfrac{\sqrt{5}}{2}a^2$  (C) $\dfrac{\sqrt{5}}{8}a^2$  (D) $\sqrt{5}a^2$

---

**解答：**

**第1步：** 由离心率确定 $a$，$b$，$c$ 的关系。
> 📌 运用知识点：双曲线的性质

$$e = \frac{c}{a} = \frac{\sqrt{5}}{2} \implies c^2 = \frac{5}{4}a^2$$

$$b^2 = c^2 - a^2 = \frac{5}{4}a^2 - a^2 = \frac{1}{4}a^2 \implies b = \frac{a}{2}$$

**第2步：** 确定各点坐标。
> 📌 运用知识点：双曲线的性质

$A(0, 2b) = (0, a)$，$C$ 为 $OA$ 中点，$C = \left(0, \dfrac{a}{2}\right)$。

左焦点 $F(-c, 0) = \left(-\dfrac{\sqrt{5}}{2}a, 0\right)$。

**第3步：** 求直线 $AF$ 与双曲线的交点 $D$。
> 📌 运用知识点：双曲线与直线的交点

直线 $AF$ 的斜率 $k = \dfrac{a - 0}{0 - \left(-\frac{\sqrt{5}}{2}a\right)} = \dfrac{2}{\sqrt{5}}$。

直线方程：$y = \dfrac{2}{\sqrt{5}}x + a$。

双曲线方程化为 $x^2 - 4y^2 = a^2$（代入 $b^2 = \frac{a^2}{4}$）。

代入直线方程：

$$x^2 - 4\left(\frac{2}{\sqrt{5}}x + a\right)^2 = a^2$$

$$x^2 - \frac{16}{5}x^2 - \frac{16a}{\sqrt{5}}x - 4a^2 = a^2$$

$$-\frac{11}{5}x^2 - \frac{16a}{\sqrt{5}}x - 5a^2 = 0 \implies 11x^2 + 16\sqrt{5}ax + 25a^2 = 0$$

$$(x + \sqrt{5}a)(11x + 5\sqrt{5}a) = 0$$

取 $D(-\sqrt{5}a, -a)$（另一交点在 $A$、$F$ 之间）。

验证：$(-\sqrt{5}a)^2 - 4(-a)^2 = 5a^2 - 4a^2 = a^2$ ✓

**第4步：** 计算 $\triangle ACD$ 的面积。
> 📌 运用知识点：三角形面积

以 $AC = \dfrac{a}{2}$ 为底（在 $y$ 轴上），$D$ 到 $y$ 轴的距离 $|x_D| = \sqrt{5}a$ 为高：

$$S_{\triangle ACD} = \frac{1}{2} \times \frac{a}{2} \times \sqrt{5}a = \frac{\sqrt{5}}{4}a^2$$

**正确答案：** (A)

**⚠️ 易错提醒：** 注意由离心率推导 $b = \frac{a}{2}$ 的过程。直线与双曲线有两个交点，需要根据题意选取正确的交点 $D$。代入验证交点在双曲线上。

**💡 解题思路总结：** 双曲线综合题：①由离心率建立 $a, b, c$ 关系；②求直线方程并与双曲线联立；③利用坐标计算三角形面积。
