**题目：**

设复数 $z$ 满足 $(1+\mathrm{i})z = 2\mathrm{i}$，则 $|z| = $（）

(A) $\dfrac{1}{2}$  (B) $\dfrac{\sqrt{2}}{2}$  (C) $\sqrt{2}$  (D) $2$

---

**解答：**

**第1步：** 求解复数 $z$。
> 📌 运用知识点：复数的运算

$$z = \frac{2\mathrm{i}}{1+\mathrm{i}} = \frac{2\mathrm{i}(1-\mathrm{i})}{(1+\mathrm{i})(1-\mathrm{i})} = \frac{2\mathrm{i} - 2\mathrm{i}^2}{1 - \mathrm{i}^2} = \frac{2 + 2\mathrm{i}}{2} = 1 + \mathrm{i}$$

**第2步：** 求复数的模。
> 📌 运用知识点：复数的模

$$|z| = |1 + \mathrm{i}| = \sqrt{1^2 + 1^2} = \sqrt{2}$$

**正确答案：** (C)

**⚠️ 易错提醒：** 复数除法需要分子分母同乘分母的共轭复数。注意 $\mathrm{i}^2 = -1$。也可利用 $|z| = \dfrac{|2\mathrm{i}|}{|1+\mathrm{i}|} = \dfrac{2}{\sqrt{2}} = \sqrt{2}$ 直接求解。

**💡 解题思路总结：** 求复数模的方法：①先化简复数为 $a + b\mathrm{i}$ 的标准形式；②再用公式 $|z| = \sqrt{a^2 + b^2}$ 求模。
