**题目：** 已知函数 $f(x) = x^3 + ax^2 + bx$ 在 $x = 1$ 处有极大值，在 $x = 3$ 处有极小值，则 $a + b = $ ______。

---

**解答：**

**第1步：** 利用极值条件列方程
> 📌 运用知识点：极值点处导数为零

$$f'(x) = 3x^2 + 2ax + b$$

$x = 1$ 和 $x = 3$ 是 $f'(x) = 0$ 的两个根，由韦达定理：

$$1 + 3 = -\frac{2a}{3} \implies a = -6$$

$$1 \times 3 = \frac{b}{3} \implies b = 9$$

**第2步：** 验证

$$f'(x) = 3x^2 - 12x + 9 = 3(x - 1)(x - 3)$$

- 当 $x < 1$ 时，$f'(x) > 0$；$1 < x < 3$ 时，$f'(x) < 0$ → $x = 1$ 为极大值点 ✓
- 当 $x > 3$ 时，$f'(x) > 0$ → $x = 3$ 为极小值点 ✓

$$a + b = -6 + 9 = 3$$

**正确答案：** $3$
