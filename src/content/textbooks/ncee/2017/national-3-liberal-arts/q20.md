**题目：** 已知抛物线 $C$：$y^2 = 4x$ 的焦点为 $F$，过 $F$ 的直线 $l$ 与 $C$ 交于 $A$，$B$ 两点。

（1）若 $|AF| = 3$，求直线 $l$ 的方程；

（2）设 $M$ 为线段 $AB$ 的中点，求 $M$ 的轨迹方程。

---

**解答：**

**第1步：** 确定焦点坐标
> 📌 运用知识点：抛物线的基本性质

$y^2 = 4x$ 中，$2p = 4$，$p = 2$，焦点 $F(1, 0)$。

**第2步：** 求 $A$ 点坐标
> 📌 运用知识点：抛物线的焦半径公式

由抛物线焦半径公式 $|AF| = x_A + \dfrac{p}{2} = x_A + 1 = 3$，得 $x_A = 2$。

代入 $y^2 = 4x$：$y_A^2 = 8$，$y_A = \pm 2\sqrt{2}$。

不妨设 $A(2, 2\sqrt{2})$（$A(2, -2\sqrt{2})$ 的情况对称）。

**第3步：** 求直线 $l$ 的方程
> 📌 运用知识点：直线方程

直线 $l$ 过 $F(1, 0)$ 和 $A(2, 2\sqrt{2})$：

$$k = \frac{2\sqrt{2} - 0}{2 - 1} = 2\sqrt{2}$$

$$l: y = 2\sqrt{2}(x - 1)$$

同理，当 $A(2, -2\sqrt{2})$ 时，$l: y = -2\sqrt{2}(x - 1)$。

直线 $l$ 的方程为 $y = \pm 2\sqrt{2}(x - 1)$。

**第4步：** 求中点 $M$ 的轨迹方程
> 📌 运用知识点：抛物线与直线的位置关系、中点轨迹

设直线 $l: x = my + 1$（过焦点 $F(1, 0)$，设 $x$ 关于 $y$ 的表达式可避免斜率不存在的讨论）。

代入 $y^2 = 4x$：

$$y^2 = 4(my + 1) \implies y^2 - 4my - 4 = 0$$

设 $A(x_1, y_1)$，$B(x_2, y_2)$，由韦达定理：

$$y_1 + y_2 = 4m, \quad y_1 y_2 = -4$$

设 $M(x_0, y_0)$：

$$y_0 = \frac{y_1 + y_2}{2} = 2m$$

$$x_0 = \frac{x_1 + x_2}{2} = \frac{my_1 + 1 + my_2 + 1}{2} = \frac{m(y_1 + y_2) + 2}{2} = \frac{4m^2 + 2}{2} = 2m^2 + 1$$

**第5步：** 消去参数 $m$
> 📌 运用知识点：参数方程消参

由 $y_0 = 2m$ 得 $m = \dfrac{y_0}{2}$，代入 $x_0$：

$$x_0 = 2 \left(\frac{y_0}{2}\right)^2 + 1 = \frac{y_0^2}{2} + 1$$

$$y_0^2 = 2(x_0 - 1)$$

$M$ 的轨迹方程为 $y^2 = 2(x - 1)$。

**⚠️ 易错提醒：**
1. 焦半径公式 $|AF| = x_A + \dfrac{p}{2}$ 仅适用于开口向右的抛物线 $y^2 = 2px$，注意不要记错。
2. 设直线时，若用 $y = k(x-1)$ 会漏掉斜率不存在的情况（即 $x = 1$），而设 $x = my + 1$ 则不会遗漏。
3. 消参后要注意轨迹的范围：由于 $y_1 y_2 = -4 < 0$，$A$、$B$ 在 $x$ 轴两侧，$M$ 不会与 $F$ 重合，轨迹需满足 $x > 1$（即 $m \neq 0$ 时 $x_0 > 1$；$m = 0$ 时 $x_0 = 1, y_0 = 0$，此时 $A$、$B$ 关于 $x$ 轴对称，$M = F$，也满足方程）。

**💡 解题思路总结：**
第一问利用抛物线焦半径公式快速求出 $A$ 点横坐标，再由两点式求直线方程。第二问是经典的轨迹问题，关键在于合理设直线方程（$x = my + 1$ 优于 $y = k(x-1)$），利用韦达定理得到中点坐标的参数表达式，最后消参得到轨迹方程。
