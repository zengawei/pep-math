**题目：** 在直角坐标系 $xOy$ 中，曲线 $C$ 的参数方程为 $\begin{cases} x = 2\cos \theta \\ y = 2\sin \theta \end{cases}$（$\theta$ 为参数）。以坐标原点为极点，$x$ 轴正半轴为极轴建立极坐标系，直线 $l$ 的极坐标方程为 $\rho \cos\!\left(\theta - \dfrac{\pi}{4}\right) = \sqrt{2}$。

（1）求曲线 $C$ 的普通方程和直线 $l$ 的直角坐标方程；

（2）求直线 $l$ 与曲线 $C$ 的交点坐标。

---

**解答：**

**第1步：** 求曲线 $C$ 的普通方程
> 📌 运用知识点：参数方程化为普通方程

由 $x = 2\cos \theta$，$y = 2\sin \theta$，利用 $\cos^2 \theta + \sin^2 \theta = 1$：

$$\left(\frac{x}{2}\right)^2 + \left(\frac{y}{2}\right)^2 = 1$$

$$x^2 + y^2 = 4$$

曲线 $C$ 是以原点为圆心、$2$ 为半径的圆。

**第2步：** 求直线 $l$ 的直角坐标方程
> 📌 运用知识点：极坐标方程化为直角坐标方程

展开 $\rho \cos\!\left(\theta - \dfrac{\pi}{4}\right) = \sqrt{2}$：

$$\rho \left(\cos \theta \cos \frac{\pi}{4} + \sin \theta \sin \frac{\pi}{4}\right) = \sqrt{2}$$

$$\rho \left(\frac{\sqrt{2}}{2} \cos \theta + \frac{\sqrt{2}}{2} \sin \theta\right) = \sqrt{2}$$

$$\frac{\sqrt{2}}{2} (\rho \cos \theta + \rho \sin \theta) = \sqrt{2}$$

利用 $x = \rho \cos \theta$，$y = \rho \sin \theta$：

$$\frac{\sqrt{2}}{2}(x + y) = \sqrt{2}$$

$$x + y = 2$$

**第3步：** 求交点坐标
> 📌 运用知识点：直线与圆的位置关系

联立方程组：

$$\begin{cases} x + y = 2 \\ x^2 + y^2 = 4 \end{cases}$$

由第一式得 $y = 2 - x$，代入第二式：

$$x^2 + (2 - x)^2 = 4$$

$$x^2 + 4 - 4x + x^2 = 4$$

$$2x^2 - 4x = 0$$

$$2x(x - 2) = 0$$

$x = 0$ 或 $x = 2$。

- $x = 0$ 时，$y = 2$，交点 $(0, 2)$
- $x = 2$ 时，$y = 0$，交点 $(2, 0)$

直线 $l$ 与曲线 $C$ 的交点坐标为 $(0, 2)$ 和 $(2, 0)$。

**⚠️ 易错提醒：**
1. 极坐标展开时，$\cos\!\left(\theta - \dfrac{\pi}{4}\right)$ 要用两角差的余弦公式展开，不要漏掉 $\sin$ 项。
2. 参数方程消参时，注意利用 $\sin^2\theta + \cos^2\theta = 1$ 这一基本恒等式。
3. 代入消元后展开 $(2-x)^2$ 时不要漏掉中间项 $-4x$。

**💡 解题思路总结：**
第一问分别将参数方程和极坐标方程转化为直角坐标方程：参数方程利用三角恒等式消参，极坐标方程利用 $x = \rho\cos\theta$、$y = \rho\sin\theta$ 的替换关系。第二问是直线与圆的交点问题，用代入消元法解方程组即可。
