**题目：** 已知等差数列 $\{a_n\}$ 中，$a_3 = 5$，$a_7 = 13$。

（1）求 $\{a_n\}$ 的通项公式；

（2）设 $b_n = \dfrac{1}{a_n \cdot a_{n+1}}$，求 $\{b_n\}$ 的前 $n$ 项和 $T_n$。

---

**解答：**

**第1步：** 求首项和公差
> 📌 运用知识点：等差数列通项公式

设首项为 $a_1$，公差为 $d$，则：

$$\begin{cases} a_1 + 2d = 5 \\ a_1 + 6d = 13 \end{cases}$$

两式相减：$4d = 8$，得 $d = 2$。

代入第一式：$a_1 + 4 = 5$，得 $a_1 = 1$。

**第2步：** 写出通项公式
> 📌 运用知识点：等差数列通项公式

$$a_n = a_1 + (n - 1)d = 1 + (n - 1) \times 2 = 2n - 1$$

**第3步：** 对 $b_n$ 进行裂项
> 📌 运用知识点：裂项相消法

$$b_n = \frac{1}{a_n \cdot a_{n+1}} = \frac{1}{(2n - 1)(2n + 1)}$$

利用裂项公式：

$$b_n = \frac{1}{2} \left( \frac{1}{2n - 1} - \frac{1}{2n + 1} \right)$$

**第4步：** 求前 $n$ 项和（裂项相消）
> 📌 运用知识点：数列求和——裂项相消法

$$T_n = \frac{1}{2} \left[ \left(\frac{1}{1} - \frac{1}{3}\right) + \left(\frac{1}{3} - \frac{1}{5}\right) + \cdots + \left(\frac{1}{2n - 1} - \frac{1}{2n + 1}\right) \right]$$

中间项依次相消：

$$T_n = \frac{1}{2} \left( 1 - \frac{1}{2n + 1} \right) = \frac{1}{2} \times \frac{2n}{2n + 1} = \frac{n}{2n + 1}$$

**⚠️ 易错提醒：**
1. 裂项时系数 $\dfrac{1}{2}$ 容易遗漏，注意 $(2n+1) - (2n-1) = 2$，所以需要除以 $2$。
2. 验证 $T_1 = b_1$：$T_1 = \dfrac{1}{3}$，$b_1 = \dfrac{1}{1 \times 3} = \dfrac{1}{3}$，一致。

**💡 解题思路总结：**
本题第一问利用等差数列基本量法（列方程组求 $a_1$ 和 $d$）求通项公式；第二问是典型的裂项相消求和，关键是将 $\dfrac{1}{(2n-1)(2n+1)}$ 拆成两项之差，使中间项相互抵消，最终只剩首尾两项。
