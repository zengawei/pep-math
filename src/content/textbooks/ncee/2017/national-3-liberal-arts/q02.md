**题目：** 复数 $z = \dfrac{2 + \text{i}}{1 - \text{i}}$，则 $z$ 的虚部为（  ）

(A) $\dfrac{1}{2}$

(B) $\dfrac{3}{2}$

(C) $-\dfrac{1}{2}$

(D) $-\dfrac{3}{2}$

---

**解答：**

**第1步：** 复数除法——分子分母同乘共轭复数
> 📌 运用知识点：复数的除法运算

$$z = \frac{2 + \text{i}}{1 - \text{i}} = \frac{(2 + \text{i})(1 + \text{i})}{(1 - \text{i})(1 + \text{i})}$$

**第2步：** 展开计算
> 📌 运用知识点：复数的乘法运算

分母：$(1 - \text{i})(1 + \text{i}) = 1 - \text{i}^2 = 1 + 1 = 2$

分子：$(2 + \text{i})(1 + \text{i}) = 2 + 2\text{i} + \text{i} + \text{i}^2 = 2 + 3\text{i} - 1 = 1 + 3\text{i}$

$$z = \frac{1 + 3\text{i}}{2} = \frac{1}{2} + \frac{3}{2}\text{i}$$

虚部为 $\dfrac{3}{2}$。

**正确答案：** (B)
