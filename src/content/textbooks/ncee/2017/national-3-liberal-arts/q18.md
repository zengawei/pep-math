**题目：** 如图，在四棱锥 $P\text{-}ABCD$ 中，底面 $ABCD$ 是矩形，$PA \perp$ 底面 $ABCD$，$PA = AB = 2$，$BC = 4$。$E$ 是 $PB$ 的中点。

（1）求证：$AE \perp PC$；

（2）求三棱锥 $E\text{-}ABC$ 的体积。

---

**解答：**

**第1步：** 建立空间直角坐标系
> 📌 运用知识点：空间向量坐标法

以 $A$ 为原点，$\overrightarrow{AB}$、$\overrightarrow{AD}$、$\overrightarrow{AP}$ 分别为 $x$、$y$、$z$ 轴正方向建立坐标系。

各点坐标：$A(0, 0, 0)$，$B(2, 0, 0)$，$C(2, 4, 0)$，$D(0, 4, 0)$，$P(0, 0, 2)$

$E$ 为 $PB$ 中点：$E = \left(\dfrac{0+2}{2}, \dfrac{0+0}{2}, \dfrac{2+0}{2}\right) = (1, 0, 1)$

**第2步：** 证明 $AE \perp PC$
> 📌 运用知识点：空间向量证明垂直

$$\overrightarrow{AE} = (1, 0, 1)$$

$$\overrightarrow{PC} = C - P = (2 - 0, 4 - 0, 0 - 2) = (2, 4, -2)$$

$$\overrightarrow{AE} \cdot \overrightarrow{PC} = 1 \times 2 + 0 \times 4 + 1 \times (-2) = 2 + 0 - 2 = 0$$

$\therefore \overrightarrow{AE} \perp \overrightarrow{PC}$，即 $AE \perp PC$。

**第3步：** 求三棱锥 $E\text{-}ABC$ 的体积
> 📌 运用知识点：棱锥体积公式

底面 $\triangle ABC$ 的面积：

$$S_{\triangle ABC} = \frac{1}{2} \times AB \times BC = \frac{1}{2} \times 2 \times 4 = 4$$

$E$ 到平面 $ABC$（即 $xOy$ 平面）的距离等于 $E$ 的 $z$ 坐标：$h = 1$

$$V_{E\text{-}ABC} = \frac{1}{3} \times S_{\triangle ABC} \times h = \frac{1}{3} \times 4 \times 1 = \frac{4}{3}$$

**⚠️ 易错提醒：**
1. 建系时注意 $PA \perp$ 底面，所以 $PA$ 方向为 $z$ 轴，不要搞混坐标轴方向。
2. 求 $E$ 到平面 $ABC$ 的距离时，因为 $PA \perp$ 底面，$E$ 的 $z$ 坐标就是高，不需要再用距离公式。
3. 注意 $E$ 是 $PB$ 的中点，坐标要取 $P$ 和 $B$ 坐标的平均值。

**💡 解题思路总结：**
本题利用 $PA \perp$ 底面的条件建立空间直角坐标系，将几何证明转化为向量数量积运算。证明垂直只需验证数量积为零；求体积时关键是找到高——由于底面在 $xOy$ 平面上，$E$ 的 $z$ 坐标即为高。
