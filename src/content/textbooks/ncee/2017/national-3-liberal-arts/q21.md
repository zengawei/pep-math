**题目：** 已知函数 $f(x) = x \ln x$。

（1）求 $f(x)$ 的最小值；

（2）若对任意 $x > 0$，$f(x) \geqslant ax - 1$ 恒成立，求 $a$ 的取值范围。

---

**解答：**

**第1步：** 求导数
> 📌 运用知识点：导数的运算（乘法法则）

$$f'(x) = \ln x + x \cdot \frac{1}{x} = \ln x + 1$$

定义域为 $x > 0$。

**第2步：** 求最小值
> 📌 运用知识点：导数与单调性、极值

令 $f'(x) = 0$：$\ln x + 1 = 0$，$\ln x = -1$，$x = \dfrac{1}{\text{e}}$。

- 当 $0 < x < \dfrac{1}{\text{e}}$ 时，$\ln x < -1$，$f'(x) < 0$，$f(x)$ 单调递减；
- 当 $x > \dfrac{1}{\text{e}}$ 时，$\ln x > -1$，$f'(x) > 0$，$f(x)$ 单调递增。

$x = \dfrac{1}{\text{e}}$ 是极小值点，也是最小值点。

$$f\left(\frac{1}{\text{e}}\right) = \frac{1}{\text{e}} \ln \frac{1}{\text{e}} = \frac{1}{\text{e}} \times (-1) = -\frac{1}{\text{e}}$$

$f(x)$ 的最小值为 $-\dfrac{1}{\text{e}}$。

**第3步：** 转化第二问的条件
> 📌 运用知识点：导数的应用——恒成立问题

$x \ln x \geqslant ax - 1$ 对任意 $x > 0$ 恒成立。

设 $g(x) = x \ln x - ax + 1$，则需 $g(x) \geqslant 0$ 对任意 $x > 0$ 恒成立。

**第4步：** 求 $g(x)$ 的最小值
> 📌 运用知识点：导数与最值

$$g'(x) = \ln x + 1 - a$$

令 $g'(x) = 0$：$\ln x = a - 1$，$x = \text{e}^{a-1}$。

- 当 $0 < x < \text{e}^{a-1}$ 时，$g'(x) < 0$，$g(x)$ 单调递减；
- 当 $x > \text{e}^{a-1}$ 时，$g'(x) > 0$，$g(x)$ 单调递增。

$g(x)$ 在 $x = \text{e}^{a-1}$ 处取最小值：

$$g(\text{e}^{a-1}) = \text{e}^{a-1} \cdot (a - 1) - a \cdot \text{e}^{a-1} + 1 = \text{e}^{a-1}(a - 1 - a) + 1 = 1 - \text{e}^{a-1}$$

**第5步：** 由最小值 $\geqslant 0$ 求 $a$ 的范围
> 📌 运用知识点：指数不等式

$$1 - \text{e}^{a-1} \geqslant 0$$

$$\text{e}^{a-1} \leqslant 1 = \text{e}^0$$

$$a - 1 \leqslant 0$$

$$a \leqslant 1$$

$a$ 的取值范围为 $(-\infty, 1]$。

**⚠️ 易错提醒：**
1. $f(x) = x \ln x$ 的定义域是 $x > 0$，求导时注意 $\ln x$ 的导数为 $\dfrac{1}{x}$，用乘法法则 $(uv)' = u'v + uv'$。
2. 第二问构造辅助函数 $g(x)$ 时，不要遗漏常数项 $+1$。
3. 求 $g(\text{e}^{a-1})$ 时，$\text{e}^{a-1} \cdot \ln \text{e}^{a-1} = \text{e}^{a-1} \cdot (a-1)$，注意不要算成 $\text{e}^{a-1} \cdot a$。
4. 最终结果 $a \leqslant 1$ 要写成集合或区间形式。

**💡 解题思路总结：**
第一问是基础的求导求最值问题。第二问是"恒成立"类型题，核心思路是将不等式转化为求函数最小值的问题：构造 $g(x) = x\ln x - ax + 1$，求其最小值并令最小值 $\geqslant 0$。这类题的关键在于正确构造辅助函数、准确求出最小值点、合理求解不等式。
