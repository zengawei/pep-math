**题目：** 已知集合 $A = \{x \mid x^2 - 2x - 3 < 0\}$，$B = \{x \mid x > 1\}$，则 $A \cap B = $（  ）

(A) $\{x \mid 1 < x < 3\}$

(B) $\{x \mid 1 < x < 2\}$

(C) $\{x \mid -1 < x < 3\}$

(D) $\{x \mid -1 < x < 2\}$

---

**解答：**

**第1步：** 解一元二次不等式，求集合 $A$
> 📌 运用知识点：一元二次不等式

解不等式 $x^2 - 2x - 3 < 0$：

因式分解得 $(x - 3)(x + 1) < 0$

解得 $-1 < x < 3$，即 $A = \{x \mid -1 < x < 3\}$

**第2步：** 求 $A \cap B$
> 📌 运用知识点：集合的交集运算

$A = (-1, 3)$，$B = (1, +\infty)$

$A \cap B = \{x \mid -1 < x < 3\} \cap \{x \mid x > 1\} = \{x \mid 1 < x < 3\}$

**答案：** $(1, 3)$

**正确答案：** (A)
