**题目：** 某学校为了了解学生的课外阅读情况，随机调查了甲、乙两个班级各 $10$ 名学生的每日课外阅读时间（单位：分钟），数据如下：

甲班：$20, 25, 30, 35, 40, 42, 45, 50, 55, 60$

乙班：$15, 20, 25, 30, 35, 40, 45, 50, 55, 65$

（1）分别求甲、乙两班学生每日课外阅读时间的平均数；

（2）从甲班每日课外阅读时间超过 $40$ 分钟的学生中随机选取 $2$ 人，求这 $2$ 人的阅读时间之和不超过 $110$ 分钟的概率。

---

**解答：**

**第1步：** 求甲班平均数
> 📌 运用知识点：样本平均数

$$\bar{x}_{\text{甲}} = \frac{20 + 25 + 30 + 35 + 40 + 42 + 45 + 50 + 55 + 60}{10} = \frac{402}{10} = 40.2 \text{（分钟）}$$

**第2步：** 求乙班平均数
> 📌 运用知识点：样本平均数

$$\bar{x}_{\text{乙}} = \frac{15 + 20 + 25 + 30 + 35 + 40 + 45 + 50 + 55 + 65}{10} = \frac{380}{10} = 38 \text{（分钟）}$$

**第3步：** 确定超过 $40$ 分钟的学生
> 📌 运用知识点：古典概型

甲班超过 $40$ 分钟的学生有 $5$ 人，阅读时间分别为：$42, 45, 50, 55, 60$。

从中选 $2$ 人，共有 $C_5^2 = 10$ 种选法。

**第4步：** 列举满足条件的组合
> 📌 运用知识点：古典概型——列举法

逐一计算各组合的和：

| 组合 | 和 | 是否 $\leqslant 110$ |
|------|------|------|
| $\{42, 45\}$ | $87$ | ✓ |
| $\{42, 50\}$ | $92$ | ✓ |
| $\{42, 55\}$ | $97$ | ✓ |
| $\{42, 60\}$ | $102$ | ✓ |
| $\{45, 50\}$ | $95$ | ✓ |
| $\{45, 55\}$ | $100$ | ✓ |
| $\{45, 60\}$ | $105$ | ✓ |
| $\{50, 55\}$ | $105$ | ✓ |
| $\{50, 60\}$ | $110$ | ✓ |
| $\{55, 60\}$ | $115$ | ✗ |

满足条件的有 $9$ 种。

$$P = \frac{9}{10}$$

**⚠️ 易错提醒：**
1. "超过 $40$ 分钟"是严格大于 $40$，不包括 $40$ 本身，所以 $40$ 不计入。
2. 列举时要有条理，避免遗漏或重复。建议按从小到大顺序枚举。
3. 注意 $50 + 60 = 110$ 恰好等于 $110$，"不超过"包含等号，应计入。

**💡 解题思路总结：**
第一问直接利用平均数公式计算；第二问是古典概型问题，关键是确定样本空间（从 $5$ 人中选 $2$ 人共 $10$ 种）和满足条件的事件数。采用系统列举法，按顺序枚举所有组合并逐一验证，确保不重不漏。
