**题目：** 已知抛物线 $C: y^2 = 4x$ 的焦点为 $F$。

（1）求焦点 $F$ 的坐标和准线方程；

（2）过 $F$ 的直线 $l$ 与 $C$ 交于 $A, B$ 两点，若 $|AB| = 8$，求直线 $l$ 的方程。

---

**解答：**

**第1步：** 确定焦点和准线
> 📌 运用知识点：抛物线的性质

$y^2 = 4x$，$2p = 4$，$p = 2$。

焦点 $F(1, 0)$，准线 $x = -1$。

**第2步：** 联立求弦长
> 📌 运用知识点：抛物线的焦点弦

设 $l: x = my + 1$。代入 $y^2 = 4x$：$y^2 = 4(my + 1)$，$y^2 - 4my - 4 = 0$。

$y_1 + y_2 = 4m$，$y_1 y_2 = -4$。

由抛物线焦半径公式：$|AB| = x_1 + x_2 + 2 = m(y_1 + y_2) + 2 + 2 = 4m^2 + 4$。

**第3步：** 解方程
> 📌 运用知识点：代数运算

$$4m^2 + 4 = 8 \implies m^2 = 1 \implies m = \pm 1$$

$l: x = y + 1$ 或 $x = -y + 1$。

$$\boxed{l: y = x - 1 \text{ 或 } y = -x + 1}$$

**⚠️ 易错提醒：** 抛物线 $y^2 = 2px$ 的焦点弦长 $|AB| = x_1 + x_2 + p$。设 $x = my + 1$ 可以包含竖直线。

**💡 解题思路总结：** 抛物线焦点弦问题用焦半径公式 $|AF| = x_A + p/2$ 最简洁。
