**题目：** 已知 $\sin\alpha = \dfrac{3}{5}$，$\alpha \in \left(\dfrac{\pi}{2}, \pi\right)$。

（1）求 $\cos\alpha$ 和 $\tan\alpha$ 的值；

（2）求 $\sin\left(\alpha + \dfrac{\pi}{4}\right)$ 的值。

---

**解答：**

**第1步：** 求 $\cos\alpha$
> 📌 运用知识点：三角恒等变换

$\alpha$ 在第二象限，$\cos\alpha < 0$。

$$\cos\alpha = -\sqrt{1 - \sin^2\alpha} = -\sqrt{1 - \frac{9}{25}} = -\sqrt{\frac{16}{25}} = -\frac{4}{5}$$

$$\tan\alpha = \frac{\sin\alpha}{\cos\alpha} = \frac{3/5}{-4/5} = -\frac{3}{4}$$

**第2步：** 求 $\sin\left(\alpha + \dfrac{\pi}{4}\right)$
> 📌 运用知识点：三角恒等变换（和角公式）

$$\sin\left(\alpha + \frac{\pi}{4}\right) = \sin\alpha\cos\frac{\pi}{4} + \cos\alpha\sin\frac{\pi}{4}$$

$$= \frac{3}{5} \times \frac{\sqrt{2}}{2} + \left(-\frac{4}{5}\right) \times \frac{\sqrt{2}}{2} = \frac{3\sqrt{2} - 4\sqrt{2}}{10} = -\frac{\sqrt{2}}{10}$$

$$\boxed{\cos\alpha = -\dfrac{4}{5}, \quad \tan\alpha = -\dfrac{3}{4}, \quad \sin\left(\alpha + \dfrac{\pi}{4}\right) = -\dfrac{\sqrt{2}}{10}}$$

**⚠️ 易错提醒：** 第二象限 $\cos < 0$。和角公式不要遗漏符号。

**💡 解题思路总结：** 已知 $\sin$ 求 $\cos$：用 $\sin^2 + \cos^2 = 1$，注意象限判断符号。
