**题目：** 已知 $f(x) = x^3 + ax^2 + bx + a^2$ 在 $x = 1$ 处有极值 $10$，则 $a + b =$

A. $-7$

B. $-15$

C. $-7$ 或 $-15$

D. $7$ 或 $-15$

---

**解答：**

**第1步：** 列方程
> 📌 运用知识点：导数与极值

$f'(x) = 3x^2 + 2ax + b$。$f'(1) = 0$：$3 + 2a + b = 0 \implies b = -2a - 3$。

$f(1) = 10$：$1 + a + b + a^2 = 10$。

代入 $b$：$1 + a - 2a - 3 + a^2 = 10 \implies a^2 - a - 12 = 0 \implies (a - 4)(a + 3) = 0$。

$a = 4$ 或 $a = -3$。

**第2步：** 验证
> 📌 运用知识点：导数与极值

$a = 4$，$b = -11$：$f'(x) = 3x^2 + 8x - 11 = (3x + 11)(x - 1)$。$x = 1$ 处 $f'$ 由负变正，是极小值 ✓。

$a = -3$，$b = 3$：$f'(x) = 3x^2 - 6x + 3 = 3(x - 1)^2 \geqslant 0$。$f'$ 不变号，不是极值 ✗。

所以 $a = 4$，$b = -11$，$a + b = -7$。

**答案：A**

**⚠️ 易错提醒：** 必须验证 $f'$ 在 $x = 1$ 处变号。$a = -3$ 时 $f'(x) = 3(x-1)^2 \geqslant 0$，$x = 1$ 不是极值点。

**💡 解题思路总结：** 极值点条件：$f'(x_0) = 0$ 且 $f'$ 在 $x_0$ 两侧变号。
