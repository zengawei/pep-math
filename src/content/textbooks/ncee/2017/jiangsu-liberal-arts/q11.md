**题目：** 已知不等式 $ax^2 + bx + 2 > 0$ 的解集为 $\left(-\dfrac{1}{2}, \dfrac{1}{3}\right)$，则 $a + b =$

A. $-14$

B. $14$

C. $-10$

D. $10$

---

**解答：**

**第1步：** 利用韦达定理
> 📌 运用知识点：一元二次不等式与方程的关系

解集为 $\left(-\dfrac{1}{2}, \dfrac{1}{3}\right)$，说明 $-\dfrac{1}{2}$ 和 $\dfrac{1}{3}$ 是 $ax^2 + bx + 2 = 0$ 的两根，且 $a < 0$。

$$\text{积} = \left(-\frac{1}{2}\right) \times \frac{1}{3} = -\frac{1}{6} = \frac{2}{a} \implies a = -12$$

$$\text{和} = -\frac{1}{2} + \frac{1}{3} = -\frac{1}{6} = -\frac{b}{a} \implies b = \frac{a}{6} = -2$$

$$a + b = -12 + (-2) = -14$$

**答案：A**

**⚠️ 易错提醒：** 解集是有限区间，说明 $a < 0$（开口向下）。韦达定理中积 $= c/a = 2/a$。

**💡 解题思路总结：** 一元二次不等式的解集端点就是对应方程的根，用韦达定理求参数。
