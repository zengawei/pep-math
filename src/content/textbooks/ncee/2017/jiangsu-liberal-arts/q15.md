**题目：** 函数 $y = 2\sin\left(2x + \dfrac{\pi}{3}\right)$ 的图象的一条对称轴方程为 ______。

---

**解答：**

**第1步：** 求对称轴
> 📌 运用知识点：三角函数的图象

对称轴满足 $2x + \dfrac{\pi}{3} = \dfrac{\pi}{2} + k\pi$（$k \in \mathbb{Z}$）。

$$x = \frac{\pi}{12} + \frac{k\pi}{2}$$

取 $k = 0$：$x = \dfrac{\pi}{12}$。

**答案：$\boxed{x = \dfrac{\pi}{12}}$**

**⚠️ 易错提醒：** 正弦函数的对称轴在 $\sin$ 取最值处，即角度 $= \dfrac{\pi}{2} + k\pi$。

**💡 解题思路总结：** $y = A\sin(\omega x + \varphi)$ 的对称轴：$\omega x + \varphi = \dfrac{\pi}{2} + k\pi$。
