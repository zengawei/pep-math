设集合 $A = \{x \mid -1 < x < 3\}$，$B = \{x \mid x^2 - 4 \leq 0\}$，则 $A \cap B = $（）

(A) $(-1, 2]$

(B) $[-2, 3)$

(C) $[-2, 2]$

(D) $(-1, 2)$

---

**解题步骤：**

**第一步：求集合 $B$**

解不等式 $x^2 - 4 \leq 0$，即 $x^2 \leq 4$，得 $-2 \leq x \leq 2$。

所以 $B = [-2, 2]$。

**第二步：求 $A \cap B$**

$A = (-1, 3)$，$B = [-2, 2]$。

取两个集合的公共部分：
$$A \cap B = (-1, 3) \cap [-2, 2] = (-1, 2]$$

> 📌 运用知识点：集合的交集运算

**正确答案：** (A)
