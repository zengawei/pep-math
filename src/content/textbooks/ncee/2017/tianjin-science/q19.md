已知抛物线 $C: y^2 = 4x$ 的焦点为 $F$，过点 $F$ 的直线 $l$ 与抛物线 $C$ 交于 $A, B$ 两点。

（1）若 $l$ 的斜率为 $1$，求 $|AB|$；

（2）若 $\overrightarrow{AF} = 2\overrightarrow{FB}$，求直线 $l$ 的方程。

---

**解题步骤：**

由 $y^2 = 4x$ 知 $2p = 4$，$p = 2$，焦点 $F(1, 0)$。

**（1）求 $|AB|$**

直线 $l$ 的斜率为 $1$，过 $F(1, 0)$，方程为 $y = x - 1$。

代入 $y^2 = 4x$：
$$(x - 1)^2 = 4x \implies x^2 - 2x + 1 = 4x \implies x^2 - 6x + 1 = 0$$

设 $A(x_1, y_1)$，$B(x_2, y_2)$，由韦达定理：
$$x_1 + x_2 = 6, \quad x_1 x_2 = 1$$

由抛物线的焦半径公式 $|AF| = x_1 + 1$，$|BF| = x_2 + 1$：
$$|AB| = |AF| + |BF| = x_1 + x_2 + 2 = 6 + 2 = 8$$

**（2）求直线 $l$ 的方程**

设直线 $l: x = my + 1$（包含斜率不存在的情形），代入 $y^2 = 4x$：
$$y^2 = 4(my + 1) \implies y^2 - 4my - 4 = 0$$

由韦达定理：
$$y_1 + y_2 = 4m, \quad y_1 y_2 = -4$$

由 $\overrightarrow{AF} = 2\overrightarrow{FB}$：
$$F - A = 2(B - F) \implies (1 - x_1, -y_1) = 2(x_2 - 1, y_2)$$

由 $y$ 分量：$-y_1 = 2y_2$，即 $y_1 = -2y_2$。

代入韦达定理：
$$y_1 + y_2 = -2y_2 + y_2 = -y_2 = 4m \implies y_2 = -4m$$

$$y_1 y_2 = (-2y_2)(y_2) = -2y_2^2 = -4 \implies y_2^2 = 2 \implies y_2 = \pm\sqrt{2}$$

当 $y_2 = \sqrt{2}$ 时：$-4m = \sqrt{2} \implies m = -\dfrac{\sqrt{2}}{4}$。

当 $y_2 = -\sqrt{2}$ 时：$-4m = -\sqrt{2} \implies m = \dfrac{\sqrt{2}}{4}$。

直线方程为 $x = my + 1$，即 $y = \dfrac{1}{m}(x - 1)$：

当 $m = -\dfrac{\sqrt{2}}{4}$ 时，$\dfrac{1}{m} = -2\sqrt{2}$，$l: y = -2\sqrt{2}(x - 1)$。

当 $m = \dfrac{\sqrt{2}}{4}$ 时，$\dfrac{1}{m} = 2\sqrt{2}$，$l: y = 2\sqrt{2}(x - 1)$。

> 📌 运用知识点：抛物线的焦点与焦半径、韦达定理、向量条件转化

**⚠️ 易错提醒：** ①过焦点的直线设为 $x = my + 1$ 可以包含斜率不存在（即 $m = 0$，直线为 $x = 1$）的情形，避免漏解。②向量条件 $\overrightarrow{AF} = 2\overrightarrow{FB}$ 表示 $F$ 在 $A$、$B$ 之间且 $|AF| = 2|FB|$，注意方向关系。

**💡 解题思路总结：** 第一问直接用韦达定理和焦半径公式求弦长；第二问将向量条件转化为坐标关系，结合韦达定理求参数。抛物线焦点弦问题的核心工具是韦达定理和焦半径公式。

**答案：** （1）$|AB| = 8$；（2）直线 $l$ 的方程为 $y = 2\sqrt{2}(x - 1)$ 或 $y = -2\sqrt{2}(x - 1)$。
