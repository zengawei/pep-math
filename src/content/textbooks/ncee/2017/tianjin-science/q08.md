已知函数 $f(x) = \begin{cases} x^2 + 1, & x \leq 0 \\ -2x + 1, & x > 0 \end{cases}$，若 $f(a) = 2$，则 $a$ 的值为（）

(A) $-1$

(B) $-1$ 或 $\dfrac{1}{2}$

(C) $\dfrac{1}{2}$

(D) $-1$ 或 $0$

---

**解题步骤：**

**第一步：当 $a \leq 0$ 时**

$f(a) = a^2 + 1 = 2$，解得 $a^2 = 1$，即 $a = 1$ 或 $a = -1$。

因为 $a \leq 0$，所以 $a = 1$ 舍去，取 $a = -1$。

**第二步：当 $a > 0$ 时**

$f(a) = -2a + 1 = 2$，解得 $-2a = 1$，即 $a = -\dfrac{1}{2}$。

因为 $a > 0$，所以 $a = -\dfrac{1}{2}$ 舍去。

**第三步：综合结论**

满足条件的 $a$ 只有 $a = -1$。

> 📌 运用知识点：分段函数的求值

**正确答案：** (A)
