已知数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n$，且 $S_n = 2a_n - 1$（$n \geq 1$）。

（1）求 $\{a_n\}$ 的通项公式；

（2）设 $b_n = \dfrac{n}{a_n}$，求数列 $\{b_n\}$ 的前 $n$ 项和 $T_n$。

---

**解题步骤：**

**（1）求通项公式**

当 $n = 1$ 时：$S_1 = a_1 = 2a_1 - 1$，解得 $a_1 = 1$。

当 $n \geq 2$ 时：
$$a_n = S_n - S_{n-1} = (2a_n - 1) - (2a_{n-1} - 1) = 2a_n - 2a_{n-1}$$

整理得：
$$-a_n = -2a_{n-1} \implies a_n = 2a_{n-1}$$

即 $\dfrac{a_n}{a_{n-1}} = 2$（常数），所以 $\{a_n\}$ 是首项为 $1$、公比为 $2$ 的等比数列。

$$a_n = 2^{n-1}$$

**（2）求 $T_n$**

$$b_n = \frac{n}{a_n} = \frac{n}{2^{n-1}}$$

$$T_n = \frac{1}{1} + \frac{2}{2} + \frac{3}{4} + \frac{4}{8} + \cdots + \frac{n}{2^{n-1}}$$

用**错位相减法**，将 $T_n$ 乘以公比 $\dfrac{1}{2}$：

$$\frac{1}{2}T_n = \frac{1}{2} + \frac{2}{4} + \frac{3}{8} + \cdots + \frac{n-1}{2^{n-1}} + \frac{n}{2^n}$$

两式相减：
$$T_n - \frac{1}{2}T_n = 1 + \left(\frac{2}{2} - \frac{1}{2}\right) + \left(\frac{3}{4} - \frac{2}{4}\right) + \cdots + \left(\frac{n}{2^{n-1}} - \frac{n-1}{2^{n-1}}\right) - \frac{n}{2^n}$$

$$\frac{1}{2}T_n = 1 + \frac{1}{2} + \frac{1}{4} + \cdots + \frac{1}{2^{n-1}} - \frac{n}{2^n}$$

前面是等比数列求和：
$$1 + \frac{1}{2} + \frac{1}{4} + \cdots + \frac{1}{2^{n-1}} = \frac{1 - \left(\frac{1}{2}\right)^n}{1 - \frac{1}{2}} = 2\left(1 - \frac{1}{2^n}\right) = 2 - \frac{2}{2^n}$$

所以：
$$\frac{1}{2}T_n = 2 - \frac{2}{2^n} - \frac{n}{2^n} = 2 - \frac{n+2}{2^n}$$

$$T_n = 4 - \frac{n+2}{2^{n-1}}$$

**验证：** $T_1 = 4 - \dfrac{3}{1} = 1 = \dfrac{1}{2^0}$ ✓，$T_2 = 4 - \dfrac{4}{2} = 2 = 1 + 1$ ✓

> 📌 运用知识点：$S_n$ 与 $a_n$ 的关系、等比数列通项公式、错位相减法求和

**⚠️ 易错提醒：** ①由 $S_n$ 求 $a_n$ 时必须分 $n=1$ 和 $n \geq 2$ 两种情况讨论，并验证 $n=1$ 时的值是否满足 $n \geq 2$ 时的通项公式。②错位相减法中，对齐项相减后中间的等比数列项数为 $n-1$ 项，不要数错。

**💡 解题思路总结：** 第一问利用 $a_n = S_n - S_{n-1}$ 将前 $n$ 项和递推关系转化为通项递推关系；第二问识别 $\{b_n\}$ 为"等差 $\times$ 等比"型，使用错位相减法。

**答案：** （1）$a_n = 2^{n-1}$；（2）$T_n = 4 - \dfrac{n+2}{2^{n-1}}$。
