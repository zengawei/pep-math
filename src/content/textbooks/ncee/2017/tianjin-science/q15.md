在 $\triangle ABC$ 中，角 $A, B, C$ 的对边分别为 $a, b, c$，已知 $a = \sqrt{3}$，$b = 1$，$B = \dfrac{\pi}{6}$。

（1）求 $A$ 的值；

（2）求 $\triangle ABC$ 的面积。

---

**解题步骤：**

**（1）求 $A$ 的值**

由正弦定理：
$$\frac{a}{\sin A} = \frac{b}{\sin B}$$

代入已知条件：
$$\frac{\sqrt{3}}{\sin A} = \frac{1}{\sin \dfrac{\pi}{6}} = \frac{1}{\dfrac{1}{2}} = 2$$

解得：
$$\sin A = \frac{\sqrt{3}}{2}$$

因为 $A \in (0, \pi)$，所以 $A = \dfrac{\pi}{3}$ 或 $A = \dfrac{2\pi}{3}$。

**验证两个解是否都成立：**

- 当 $A = \dfrac{\pi}{3}$ 时，$C = \pi - \dfrac{\pi}{3} - \dfrac{\pi}{6} = \dfrac{\pi}{2} > 0$ ✓
- 当 $A = \dfrac{2\pi}{3}$ 时，$C = \pi - \dfrac{2\pi}{3} - \dfrac{\pi}{6} = \dfrac{\pi}{6} > 0$ ✓

两个解均成立。

**（2）求 $\triangle ABC$ 的面积**

**当 $A = \dfrac{\pi}{3}$，$C = \dfrac{\pi}{2}$ 时：**

$$S = \frac{1}{2} ab \sin C = \frac{1}{2} \times \sqrt{3} \times 1 \times \sin\frac{\pi}{2} = \frac{\sqrt{3}}{2}$$

**当 $A = \dfrac{2\pi}{3}$，$C = \dfrac{\pi}{6}$ 时：**

$$S = \frac{1}{2} ab \sin C = \frac{1}{2} \times \sqrt{3} \times 1 \times \sin\frac{\pi}{6} = \frac{1}{2} \times \sqrt{3} \times \frac{1}{2} = \frac{\sqrt{3}}{4}$$

> 📌 运用知识点：正弦定理、三角形面积公式、分类讨论

**⚠️ 易错提醒：** 已知两边和其中一边的对角（SSA 情形），利用正弦定理求角时可能有两解，必须逐一验证每个解是否满足三角形内角和为 $\pi$ 的条件，不能遗漏。

**💡 解题思路总结：** 先用正弦定理求 $\sin A$，再由 $A$ 的范围确定 $A$ 的所有可能值，逐一验证后分别计算面积。SSA 问题是高考高频易错点。

**答案：** （1）$A = \dfrac{\pi}{3}$ 或 $A = \dfrac{2\pi}{3}$；（2）$\triangle ABC$ 的面积为 $\dfrac{\sqrt{3}}{2}$ 或 $\dfrac{\sqrt{3}}{4}$。
