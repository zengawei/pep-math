**题目：** 在 $\triangle ABC$ 中，内角 $A$、$B$、$C$ 的对边分别为 $a$、$b$、$c$，已知 $b\cos C + c\cos B = 2a\cos B$。

（1）求 $B$；

（2）若 $b = \sqrt{3}$，$a + c = 2b$，求 $\triangle ABC$ 的面积。

---

**解答：**

**第1步：** 利用正弦定理转化边角关系
> 📌 运用知识点：正弦定理

由正弦定理 $\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C}$，将边替换为角：

$$\sin B\cos C + \sin C\cos B = 2\sin A\cos B$$

**第2步：** 利用和角公式化简
> 📌 运用知识点：三角恒等变换

左边 $= \sin(B + C)$。因为 $A + B + C = \pi$，所以 $\sin(B + C) = \sin(\pi - A) = \sin A$。

$$\sin A = 2\sin A\cos B$$

因为 $\sin A \neq 0$（$A$ 为三角形内角），两边除以 $\sin A$：

$$\cos B = \frac{1}{2}$$

$$\boxed{B = \frac{\pi}{3}}$$

**第3步：** 利用已知条件求 $ac$
> 📌 运用知识点：余弦定理

由 $a + c = 2b = 2\sqrt{3}$。

由余弦定理 $b^2 = a^2 + c^2 - 2ac\cos B$：

$$3 = (a + c)^2 - 2ac - 2ac\cos\frac{\pi}{3} = 12 - 2ac - ac = 12 - 3ac$$

$$3ac = 9 \implies ac = 3$$

**第4步：** 计算面积
> 📌 运用知识点：三角形面积公式

$$\boxed{S = \frac{1}{2}ac\sin B = \frac{1}{2} \times 3 \times \frac{\sqrt{3}}{2} = \frac{3\sqrt{3}}{4}}$$

**⚠️ 易错提醒：** 第（1）问中利用正弦定理将边转化为角时，注意 $\sin(B+C) = \sin A$ 的推导。第（2）问中利用余弦定理时，注意 $(a+c)^2 = a^2 + c^2 + 2ac$ 的整体代换技巧，不要遗漏 $2ac$ 项。

**💡 解题思路总结：** 三角形中的边角关系问题，常用正弦定理和余弦定理。面积公式 $S = \frac{1}{2}ac\sin B$ 可以建立 $ac$ 的方程，再与余弦定理联立，利用整体代换求解。
