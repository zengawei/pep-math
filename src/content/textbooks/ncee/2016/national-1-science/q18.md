**题目：** 如图，四棱锥 $P$-$ABCD$ 中，底面 $ABCD$ 为菱形，$\angle ABC = 60°$，$PA = PD$，平面 $PAD \perp$ 底面 $ABCD$。

（1）证明：$PO \perp$ 底面 $ABCD$（$O$ 为 $AD$ 的中点）；

（2）若 $AB = PA = 2$，求二面角 $A$-$PB$-$D$ 的余弦值。

---

**解答：**

**第1步：** 证明 $PO \perp$ 底面
> 📌 运用知识点：空间位置关系——面面垂直的性质

因为 $PA = PD$，$O$ 为 $AD$ 中点，所以 $PO \perp AD$。

又因为平面 $PAD \perp$ 底面 $ABCD$，平面 $PAD \cap$ 底面 $ABCD = AD$，$PO \subset$ 平面 $PAD$，$PO \perp AD$，

由面面垂直的性质定理：$PO \perp$ 底面 $ABCD$。$\blacksquare$

**第2步：** 建立空间直角坐标系
> 📌 运用知识点：空间直角坐标系的建立

以 $O$ 为原点，$\overrightarrow{OD}$ 方向为 $x$ 轴正方向，在底面内过 $O$ 作 $AD$ 的垂线为 $y$ 轴，$\overrightarrow{OP}$ 方向为 $z$ 轴正方向。

底面 $ABCD$ 为菱形，$AB = 2$，$\angle ABC = 60°$，则 $\angle BAD = 120°$。

$AD = 2$，$O$ 为 $AD$ 中点，$OA = OD = 1$。

各点坐标：
- $A(-1, 0, 0)$，$D(1, 0, 0)$
- $B$：从 $A$ 出发，$\overrightarrow{AB}$ 与 $\overrightarrow{AD}$ 夹角 $120°$，$|\overrightarrow{AB}| = 2$

$$B = A + 2(\cos 120°, \sin 120°, 0) = (-1, 0, 0) + (-1, \sqrt{3}, 0) = (-2, \sqrt{3}, 0)$$

- $C = D + \overrightarrow{AB} = (1, 0, 0) + (-1, \sqrt{3}, 0) = (0, \sqrt{3}, 0)$
- $PA = 2$，$PO = \sqrt{PA^2 - OA^2} = \sqrt{4 - 1} = \sqrt{3}$

$$P = (0, 0, \sqrt{3})$$

**第3步：** 求二面角 $A$-$PB$-$D$ 的余弦值
> 📌 运用知识点：空间向量求二面角

$$\overrightarrow{PB} = B - P = (-2, \sqrt{3}, -\sqrt{3})$$

$$\overrightarrow{PA} = A - P = (-1, 0, -\sqrt{3})$$

$$\overrightarrow{PD} = D - P = (1, 0, -\sqrt{3})$$

平面 $PAB$ 的法向量 $\vec{n_1} = \overrightarrow{PB} \times \overrightarrow{PA}$：

$$\vec{n_1} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ -2 & \sqrt{3} & -\sqrt{3} \\ -1 & 0 & -\sqrt{3} \end{vmatrix} = (-3, -\sqrt{3}, \sqrt{3})$$

平面 $PBD$ 的法向量 $\vec{n_2} = \overrightarrow{PB} \times \overrightarrow{PD}$：

$$\vec{n_2} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ -2 & \sqrt{3} & -\sqrt{3} \\ 1 & 0 & -\sqrt{3} \end{vmatrix} = (-3, -3\sqrt{3}, -\sqrt{3})$$

$$\vec{n_1} \cdot \vec{n_2} = (-3)(-3) + (-\sqrt{3})(-3\sqrt{3}) + (\sqrt{3})(-\sqrt{3}) = 9 + 9 - 3 = 15$$

$$|\vec{n_1}| = \sqrt{9 + 3 + 3} = \sqrt{15}$$

$$|\vec{n_2}| = \sqrt{9 + 27 + 3} = \sqrt{39}$$

$$\cos\theta = \frac{|\vec{n_1} \cdot \vec{n_2}|}{|\vec{n_1}||\vec{n_2}|} = \frac{15}{\sqrt{15} \times \sqrt{39}} = \frac{15}{\sqrt{585}} = \frac{15}{3\sqrt{65}} = \frac{5}{\sqrt{65}} = \frac{5\sqrt{65}}{65} = \frac{\sqrt{65}}{13}$$

嗯，这个结果不够简洁。让我重新计算叉积。

$\vec{n_1} = \overrightarrow{PB} \times \overrightarrow{PA}$：

$i$：$\sqrt{3} \times (-\sqrt{3}) - (-\sqrt{3}) \times 0 = -3 - 0 = -3$

$j$：$-[(-2) \times (-\sqrt{3}) - (-\sqrt{3}) \times (-1)] = -[2\sqrt{3} - \sqrt{3}] = -\sqrt{3}$

$k$：$(-2) \times 0 - \sqrt{3} \times (-1) = 0 + \sqrt{3} = \sqrt{3}$

$\vec{n_1} = (-3, -\sqrt{3}, \sqrt{3})$ ✓

$\vec{n_2} = \overrightarrow{PB} \times \overrightarrow{PD}$：

$i$：$\sqrt{3} \times (-\sqrt{3}) - (-\sqrt{3}) \times 0 = -3$

$j$：$-[(-2) \times (-\sqrt{3}) - (-\sqrt{3}) \times 1] = -[2\sqrt{3} + \sqrt{3}] = -3\sqrt{3}$

$k$：$(-2) \times 0 - \sqrt{3} \times 1 = -\sqrt{3}$

$\vec{n_2} = (-3, -3\sqrt{3}, -\sqrt{3})$ ✓

$\vec{n_1} \cdot \vec{n_2} = 9 + 3\cdot 3 + (-\sqrt{3})(-\sqrt{3}) = 9 + 9 - 3 = 15$

等等：$(-\sqrt{3})(-3\sqrt{3}) = 3 \times 3 = 9$。$(\sqrt{3})(-\sqrt{3}) = -3$。

$\vec{n_1} \cdot \vec{n_2} = 9 + 9 - 3 = 15$ ✓

$|\vec{n_1}| = \sqrt{9 + 3 + 3} = \sqrt{15}$ ✓

$|\vec{n_2}| = \sqrt{9 + 27 + 3} = \sqrt{39}$ ✓

$\cos\theta = \frac{15}{\sqrt{15 \times 39}} = \frac{15}{\sqrt{585}}$

$585 = 9 \times 65$，$\sqrt{585} = 3\sqrt{65}$

$\cos\theta = \frac{15}{3\sqrt{65}} = \frac{5}{\sqrt{65}} = \frac{5\sqrt{65}}{65} = \frac{\sqrt{65}}{13}$

这个结果虽然不特别简洁，但在高考范围内是可接受的。

$$\boxed{\cos\theta = \frac{\sqrt{65}}{13}}$$

**⚠️ 易错提醒：** 建立空间直角坐标系时，要准确确定各顶点的坐标。利用面面垂直的性质定理找到 $PO \perp$ 底面是关键。计算叉积时注意符号，尤其是 $j$ 分量要取负号。

**💡 解题思路总结：** 立体几何中求二面角的标准方法：建立空间直角坐标系，求出两个半平面的法向量，利用法向量的夹角求二面角。关键是找到合适的坐标系和准确的坐标。
