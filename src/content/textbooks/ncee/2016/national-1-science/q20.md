**题目：** 在直角坐标系 $xOy$ 中，椭圆 $C: \dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$）的离心率为 $\dfrac{\sqrt{3}}{2}$，过左焦点 $F_1$ 的直线 $l$ 交椭圆于 $A$、$B$ 两点，$\triangle ABF_2$ 的周长为 8（$F_2$ 为右焦点）。

（1）求椭圆 $C$ 的方程；

（2）设直线 $l$ 的斜率为 1，求 $\triangle ABF_2$ 的面积。

---

**解答：**

**第1步：** 利用周长条件求 $a$
> 📌 运用知识点：椭圆的定义

由椭圆定义：$|AF_1| + |AF_2| = 2a$，$|BF_1| + |BF_2| = 2a$。

$\triangle ABF_2$ 的周长 $= |AB| + |AF_2| + |BF_2|$

$= (|AF_1| + |BF_1|) + |AF_2| + |BF_2|$

$= (|AF_1| + |AF_2|) + (|BF_1| + |BF_2|) = 2a + 2a = 4a$

$$4a = 8 \implies a = 2$$

**第2步：** 利用离心率求 $b$
> 📌 运用知识点：椭圆离心率

$$e = \frac{c}{a} = \frac{\sqrt{3}}{2} \implies c = \sqrt{3}$$

$$b^2 = a^2 - c^2 = 4 - 3 = 1$$

$$\boxed{\frac{x^2}{4} + y^2 = 1}$$

**第3步：** 求直线 $l$ 与椭圆的交点
> 📌 运用知识点：直线与椭圆的位置关系

左焦点 $F_1(-\sqrt{3}, 0)$，直线 $l$ 斜率为 1：$y = x + \sqrt{3}$。

代入椭圆方程：

$$\frac{x^2}{4} + (x + \sqrt{3})^2 = 1$$

$$\frac{x^2}{4} + x^2 + 2\sqrt{3}x + 3 = 1$$

$$\frac{5x^2}{4} + 2\sqrt{3}x + 2 = 0$$

$$5x^2 + 8\sqrt{3}x + 8 = 0$$

$$x = \frac{-8\sqrt{3} \pm \sqrt{192 - 160}}{10} = \frac{-8\sqrt{3} \pm \sqrt{32}}{10} = \frac{-8\sqrt{3} \pm 4\sqrt{2}}{10} = \frac{-4\sqrt{3} \pm 2\sqrt{2}}{5}$$

**第4步：** 求 $|AB|$

$$x_1 + x_2 = -\frac{8\sqrt{3}}{5}, \quad x_1 x_2 = \frac{8}{5}$$

$$|x_1 - x_2| = \sqrt{(x_1 + x_2)^2 - 4x_1 x_2} = \sqrt{\frac{192}{25} - \frac{32}{5}} = \sqrt{\frac{192 - 160}{25}} = \sqrt{\frac{32}{25}} = \frac{4\sqrt{2}}{5}$$

因为直线斜率为 1：

$$|AB| = \sqrt{1 + 1^2} \cdot |x_1 - x_2| = \sqrt{2} \cdot \frac{4\sqrt{2}}{5} = \frac{8}{5}$$

**第5步：** 求 $F_2$ 到直线 $l$ 的距离
> 📌 运用知识点：点到直线的距离

$F_2(\sqrt{3}, 0)$，直线 $l: x - y + \sqrt{3} = 0$。

$$d = \frac{|\sqrt{3} - 0 + \sqrt{3}|}{\sqrt{1 + 1}} = \frac{2\sqrt{3}}{\sqrt{2}} = \sqrt{6}$$

**第6步：** 计算面积

$$S_{\triangle ABF_2} = \frac{1}{2} |AB| \cdot d = \frac{1}{2} \times \frac{8}{5} \times \sqrt{6} = \boxed{\frac{4\sqrt{6}}{5}}$$

**⚠️ 易错提醒：** 第（1）问中利用椭圆定义将三角形周长转化为 $4a$ 是关键技巧。第（2）问中直线与椭圆联立时，注意韦达定理的正确使用，以及弦长公式中 $\sqrt{1+k^2}$ 的系数不要遗漏。

**💡 解题思路总结：** 椭圆问题中，焦点三角形周长 $= 4a$ 是椭圆定义的直接应用。求面积时，先求弦长 $|AB|$（联立方程 + 韦达定理 + 弦长公式），再求对顶点到直线的距离，最后用 $\frac{1}{2} \times$ 底 $\times$ 高。
