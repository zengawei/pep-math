**题目：** 已知函数 $f(x) = (x - 2)e^x + a(x - 1)^2$，$a \in \mathbb{R}$。

（1）当 $a = 0$ 时，求 $f(x)$ 的单调区间；

（2）若 $f(x)$ 有两个零点，求 $a$ 的取值范围。

---

**解答：**

**第1步：** 求导数（$a = 0$）
> 📌 运用知识点：导数的运算

当 $a = 0$ 时，$f(x) = (x - 2)e^x$。

$$f'(x) = e^x + (x - 2)e^x = (x - 1)e^x$$

**第2步：** 确定单调区间
> 📌 运用知识点：导数与函数的单调性

因为 $e^x > 0$ 恒成立，$f'(x)$ 的符号由 $(x - 1)$ 决定：

- $f'(x) > 0 \iff x > 1$：$f(x)$ 在 $(1, +\infty)$ 上单调递增
- $f'(x) < 0 \iff x < 1$：$f(x)$ 在 $(-\infty, 1)$ 上单调递减

$$\text{单调递增区间：}(1, +\infty)；\text{单调递减区间：}(-\infty, 1)$$

**第3步：** 分析 $f(x)$ 有两个零点的条件
> 📌 运用知识点：导数与函数零点

$$f'(x) = (x - 1)e^x + 2a(x - 1) = (x - 1)(e^x + 2a)$$

**情况 1：$a \geqslant 0$**

$e^x + 2a > 0$ 恒成立，$f'(x) = 0$ 仅当 $x = 1$。

$f(x)$ 在 $(-\infty, 1)$ 递减，在 $(1, +\infty)$ 递增。

$f(1) = (1 - 2)e + 0 = -e < 0$

当 $x \to +\infty$ 时，$f(x) \to +\infty$（$(x-2)e^x$ 主导）。

当 $x \to -\infty$ 时，$f(x) = (x-2)e^x + a(x-1)^2 \to 0 + a \cdot (+\infty)$。

若 $a > 0$：$f(x) \to +\infty$（$x \to -\infty$），$f(1) = -e < 0$，$f(x) \to +\infty$（$x \to +\infty$）。

由零点存在定理，$f(x)$ 在 $(-\infty, 1)$ 和 $(1, +\infty)$ 各有一个零点，共两个零点。✓

若 $a = 0$：$f(1) = -e < 0$，$f(x) \to 0$（$x \to -\infty$），$f(x) \to +\infty$（$x \to +\infty$）。

$f(x)$ 在 $(-\infty, 1)$ 上从 0 递减到 $-e$，无零点；在 $(1, +\infty)$ 上从 $-e$ 递增到 $+\infty$，一个零点。共一个零点。✗

**情况 2：$a < 0$**

$e^x + 2a = 0 \implies x = \ln(-2a)$（需 $-2a > 0$，即 $a < 0$）。

$f'(x) = 0$ 的两个根：$x = 1$ 和 $x = \ln(-2a)$。

**子情况 2a：$\ln(-2a) = 1$，即 $a = -\dfrac{e}{2}$**

$f'(x) = (x - 1)(e^x - e) \geqslant 0$（当 $x \geqslant 1$ 时两项同号，当 $x < 1$ 时也同号）。

$f(x)$ 单调递增（除 $x = 1$ 处 $f' = 0$），至多一个零点。✗

**子情况 2b：$\ln(-2a) > 1$，即 $a < -\dfrac{e}{2}$**

$f(x)$ 在 $(-\infty, 1)$ 递增，在 $(1, \ln(-2a))$ 递减，在 $(\ln(-2a), +\infty)$ 递增。

$f(1) = -e + 0 = -e < 0$（因为 $a(x-1)^2$ 在 $x=1$ 处为 0）。

极大值 $f(1) = -e < 0$，所以 $f(x)$ 在 $(-\infty, \ln(-2a))$ 上无零点。

在 $(\ln(-2a), +\infty)$ 上，$f(x) \to +\infty$，有一个零点。共一个零点。✗

**子情况 2c：$\ln(-2a) < 1$，即 $-\dfrac{e}{2} < a < 0$**

$f(x)$ 在 $(-\infty, \ln(-2a))$ 递增，在 $(\ln(-2a), 1)$ 递减，在 $(1, +\infty)$ 递增。

极大值 $f(\ln(-2a))$：

设 $x_0 = \ln(-2a)$，$e^{x_0} = -2a$。

$$f(x_0) = (x_0 - 2)(-2a) + a(x_0 - 1)^2$$

$$= -2a(x_0 - 2) + a(x_0 - 1)^2$$

$$= a[-2(x_0 - 2) + (x_0 - 1)^2]$$

$$= a[-2x_0 + 4 + x_0^2 - 2x_0 + 1]$$

$$= a[x_0^2 - 4x_0 + 5]$$

因为 $x_0^2 - 4x_0 + 5 = (x_0 - 2)^2 + 1 > 0$，且 $a < 0$：

$f(x_0) = a \cdot (\text{正数}) < 0$。

极大值 $< 0$，所以 $f(x)$ 至多一个零点。✗

**第4步：** 综合结论

$f(x)$ 有两个零点当且仅当 $a > 0$。

$$\boxed{a \in (0, +\infty)}$$

**⚠️ 易错提醒：** 第（2）问需要对 $a$ 进行分类讨论，关键是分析 $f'(x) = (x-1)(e^x + 2a)$ 的零点分布。注意 $a < 0$ 时 $\ln(-2a)$ 与 1 的大小关系决定了极值点的相对位置。判断零点个数时，要结合极值的正负和函数的极限行为。

**💡 解题思路总结：** 含参函数的零点问题，标准流程为：求导 → 分类讨论确定单调性 → 分析极值的正负 → 结合极限行为判断零点个数。本题的核心在于 $f'(x)$ 可以因式分解为 $(x-1)(e^x + 2a)$，大大简化了分析。
