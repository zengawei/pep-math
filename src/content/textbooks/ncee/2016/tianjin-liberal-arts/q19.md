**题目：**

已知椭圆 $C: \dfrac{x^2}{4} + y^2 = 1$。

（1）求椭圆 $C$ 的离心率；

（2）过点 $M(1, 0)$ 的直线 $l$ 与椭圆 $C$ 交于 $A, B$ 两点，若 $\overrightarrow{OA} \cdot \overrightarrow{OB} = 0$（$O$ 为原点），求直线 $l$ 的方程。

---

**解答：**

**（1）求离心率**

**第1步：** 确定椭圆参数
> 📌 运用知识点：椭圆的标准方程与基本参数

由椭圆方程知 $a^2 = 4$，$b^2 = 1$，故 $c^2 = a^2 - b^2 = 3$。

$$e = \frac{c}{a} = \frac{\sqrt{3}}{2}$$

**（2）求直线 $l$ 的方程**

**第2步：** 设直线方程并联立
> 📌 运用知识点：直线与椭圆的位置关系

设直线 $l: x = my + 1$（过点 $M(1,0)$）。

代入椭圆方程：

$$\frac{(my+1)^2}{4} + y^2 = 1$$

$$(my+1)^2 + 4y^2 = 4$$

$$m^2y^2 + 2my + 1 + 4y^2 = 4$$

$$(m^2 + 4)y^2 + 2my - 3 = 0$$

**第3步：** 利用韦达定理
> 📌 运用知识点：韦达定理

设 $A(x_1, y_1)$，$B(x_2, y_2)$，则：

$$y_1 + y_2 = \frac{-2m}{m^2 + 4}, \quad y_1 y_2 = \frac{-3}{m^2 + 4}$$

**第4步：** 利用 $\overrightarrow{OA} \cdot \overrightarrow{OB} = 0$
> 📌 运用知识点：向量数量积

$$\overrightarrow{OA} \cdot \overrightarrow{OB} = x_1 x_2 + y_1 y_2 = 0$$

计算 $x_1 x_2$：

$$x_1 x_2 = (my_1 + 1)(my_2 + 1) = m^2 y_1 y_2 + m(y_1 + y_2) + 1$$

$$= m^2 \cdot \frac{-3}{m^2 + 4} + m \cdot \frac{-2m}{m^2 + 4} + 1 = \frac{-3m^2 - 2m^2}{m^2 + 4} + 1 = \frac{-5m^2 + m^2 + 4}{m^2 + 4} = \frac{-4m^2 + 4}{m^2 + 4}$$

因此：

$$\overrightarrow{OA} \cdot \overrightarrow{OB} = \frac{-4m^2 + 4}{m^2 + 4} + \frac{-3}{m^2 + 4} = \frac{-4m^2 + 1}{m^2 + 4} = 0$$

$$-4m^2 + 1 = 0 \implies m^2 = \frac{1}{4} \implies m = \pm\frac{1}{2}$$

**第5步：** 写出直线方程

$$x = \pm\frac{1}{2}y + 1 \implies y = \pm 2(x - 1)$$

**验证判别式：** $\Delta = 4m^2 + 12(m^2 + 4) = 1 + 12 \times \dfrac{17}{4} = 1 + 51 = 52 > 0$ ✓

**⚠️ 易错提醒：** 设直线时注意讨论斜率是否存在。本题若设 $y = k(x-1)$，需单独讨论斜率不存在的情况（$x = 1$）。使用 $x = my + 1$ 可避免此问题。

**💡 解题思路总结：** 圆锥曲线综合题的核心方法：设线联立→韦达定理→利用条件建立方程。$\overrightarrow{OA} \cdot \overrightarrow{OB} = 0$ 等价于 $x_1x_2 + y_1y_2 = 0$，将坐标用韦达定理表达后解关于参数的方程。

**答案：** （1）$e = \dfrac{\sqrt{3}}{2}$；（2）$y = \pm 2(x - 1)$
