**题目：**

如图，在四棱锥 $P\text{-}ABCD$ 中，底面 $ABCD$ 是矩形，$PA \perp$ 底面 $ABCD$，$PA = AB = 1$，$BC = 2$，$E$ 是 $PB$ 的中点。

（1）求证：$PD \parallel$ 平面 $EAC$；

（2）求直线 $PC$ 与平面 $EAC$ 所成角的正弦值。

---

**解答：**

**建立空间直角坐标系**

以 $A$ 为原点，$\overrightarrow{AB}$、$\overrightarrow{AD}$、$\overrightarrow{AP}$ 分别为 $x$、$y$、$z$ 轴正方向。

各点坐标：$A(0,0,0)$，$B(1,0,0)$，$C(1,2,0)$，$D(0,2,0)$，$P(0,0,1)$。

$E$ 为 $PB$ 中点：$E = \left(\dfrac{1}{2}, 0, \dfrac{1}{2}\right)$。

**（1）证明 $PD \parallel$ 平面 $EAC$**

**第1步：** 求相关向量
> 📌 运用知识点：空间向量的线性运算

$$\overrightarrow{PD} = D - P = (0, 2, -1)$$

$$\overrightarrow{EA} = A - E = \left(-\frac{1}{2}, 0, -\frac{1}{2}\right)$$

$$\overrightarrow{EC} = C - E = \left(\frac{1}{2}, 2, -\frac{1}{2}\right)$$

**第2步：** 验证 $\overrightarrow{PD}$ 可由 $\overrightarrow{EA}$、$\overrightarrow{EC}$ 线性表示
> 📌 运用知识点：向量共面的判定

设 $\overrightarrow{PD} = \alpha \overrightarrow{EA} + \beta \overrightarrow{EC}$，即：

$$(0, 2, -1) = \alpha\left(-\frac{1}{2}, 0, -\frac{1}{2}\right) + \beta\left(\frac{1}{2}, 2, -\frac{1}{2}\right)$$

由第二个分量：$2\beta = 2 \implies \beta = 1$。

由第一个分量：$-\dfrac{\alpha}{2} + \dfrac{1}{2} = 0 \implies \alpha = 1$。

验证第三个分量：$-\dfrac{1}{2} - \dfrac{1}{2} = -1$ ✓

因此 $\overrightarrow{PD} = \overrightarrow{EA} + \overrightarrow{EC}$，$\overrightarrow{PD}$ 与平面 $EAC$ 平行。

**第3步：** 验证 $P$ 不在平面 $EAC$ 上

$$\overrightarrow{EP} = P - E = \left(-\frac{1}{2}, 0, \frac{1}{2}\right)$$

若 $\overrightarrow{EP} = \alpha \overrightarrow{EA} + \beta \overrightarrow{EC}$，由第二分量 $2\beta = 0 \implies \beta = 0$，由第一分量 $-\alpha/2 = -1/2 \implies \alpha = 1$，但第三分量 $-\alpha/2 = 1/2 \implies \alpha = -1$，矛盾。

故 $P$ 不在平面 $EAC$ 上，从而 $PD \parallel$ 平面 $EAC$。

**（2）求直线 $PC$ 与平面 $EAC$ 所成角的正弦值**

**第4步：** 求平面 $EAC$ 的法向量
> 📌 运用知识点：向量叉积求法向量

$$\boldsymbol{n} = \overrightarrow{EA} \times \overrightarrow{EC} = \begin{vmatrix} \boldsymbol{i} & \boldsymbol{j} & \boldsymbol{k} \\ -\frac{1}{2} & 0 & -\frac{1}{2} \\ \frac{1}{2} & 2 & -\frac{1}{2} \end{vmatrix}$$

$$n_x = 0 \times \left(-\frac{1}{2}\right) - \left(-\frac{1}{2}\right) \times 2 = 1$$

$$n_y = \left(-\frac{1}{2}\right) \times \frac{1}{2} - \left(-\frac{1}{2}\right) \times \left(-\frac{1}{2}\right) = -\frac{1}{4} - \frac{1}{4} = -\frac{1}{2}$$

$$n_z = \left(-\frac{1}{2}\right) \times 2 - 0 \times \frac{1}{2} = -1$$

取 $\boldsymbol{n} = (1, -\frac{1}{2}, -1)$，即 $\boldsymbol{n} = (2, -1, -2)$。

$|\boldsymbol{n}| = \sqrt{4 + 1 + 4} = 3$。

**第5步：** 计算线面角的正弦值
> 📌 运用知识点：线面角公式 $\sin\theta = \dfrac{|\overrightarrow{PC} \cdot \boldsymbol{n}|}{|\overrightarrow{PC}| \cdot |\boldsymbol{n}|}$

$$\overrightarrow{PC} = C - P = (1, 2, -1)$$

$$|\overrightarrow{PC}| = \sqrt{1 + 4 + 1} = \sqrt{6}$$

$$\overrightarrow{PC} \cdot \boldsymbol{n} = 1 \times 2 + 2 \times (-1) + (-1) \times (-2) = 2 - 2 + 2 = 2$$

$$\sin\theta = \frac{|2|}{\sqrt{6} \times 3} = \frac{2}{3\sqrt{6}} = \frac{2\sqrt{6}}{18} = \frac{\sqrt{6}}{9}$$

**⚠️ 易错提醒：** 证明线面平行时，不仅要验证方向向量与平面平行，还需说明直线上的点不在平面内。求线面角用的是 $\sin\theta = \dfrac{|\cos\langle\overrightarrow{PC}, \boldsymbol{n}\rangle| \cdot |\overrightarrow{PC}|}{|\overrightarrow{PC}|}$，注意与二面角公式区分。

**💡 解题思路总结：** 建系后用向量法处理立体几何问题：线面平行转化为方向向量与平面法向量垂直（或方向向量可被平面内两向量线性表示）；线面角用 $\sin\theta = \dfrac{|\vec{v} \cdot \boldsymbol{n}|}{|\vec{v}||\boldsymbol{n}|}$。

**答案：** （1）证明见上；（2）$\sin\theta = \dfrac{\sqrt{6}}{9}$
