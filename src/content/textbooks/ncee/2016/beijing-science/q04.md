**题目：** 下列函数中，既是偶函数又在 $(0, +\infty)$ 上单调递增的是（）

A. $f(x) = x^3$

B. $f(x) = \cos x$

C. $f(x) = |x| + 1$

D. $f(x) = \dfrac{1}{x^2}$

---

**解答：**

**第1步：** 逐一判断奇偶性
> 📌 运用知识点：函数性质

- A：$f(-x) = -x^3 = -f(x)$，奇函数，排除。
- B：$f(-x) = \cos(-x) = \cos x = f(x)$，偶函数。但在 $(0, \pi)$ 上递减，排除。
- C：$f(-x) = |-x| + 1 = |x| + 1 = f(x)$，偶函数。在 $(0, +\infty)$ 上 $f(x) = x + 1$，递增。✓
- D：$f(-x) = \dfrac{1}{(-x)^2} = \dfrac{1}{x^2} = f(x)$，偶函数。但在 $(0, +\infty)$ 上递减，排除。

**答案：** C
