**题目：**

如图，在四棱锥 $P\text{-}ABCD$ 中，底面 $ABCD$ 为正方形，$PA \perp$ 底面 $ABCD$，$PA = AB = 2$。

（1）求证：$BD \perp PC$；

（2）求二面角 $B\text{-}PC\text{-}D$ 的大小。

---

**解答：**

**（1）证明 $BD \perp PC$**

**第1步：** 建立空间直角坐标系
> 📌 运用知识点：空间向量坐标

以 $A$ 为原点，$\overrightarrow{AB}$，$\overrightarrow{AD}$，$\overrightarrow{AP}$ 分别为 $x$，$y$，$z$ 轴正方向。

$$A(0,0,0),\ B(2,0,0),\ C(2,2,0),\ D(0,2,0),\ P(0,0,2)$$

**第2步：** 计算向量点积
> 📌 运用知识点：空间向量运算

$$\overrightarrow{BD} = (-2, 2, 0), \quad \overrightarrow{PC} = (2, 2, -2)$$

$$\overrightarrow{BD} \cdot \overrightarrow{PC} = (-2)(2) + (2)(2) + (0)(-2) = -4 + 4 + 0 = 0$$

所以 $BD \perp PC$。$\blacksquare$

---

**（2）求二面角 $B\text{-}PC\text{-}D$**

**第3步：** 求平面 $BPC$ 的法向量
> 📌 运用知识点：空间向量法求角

$\overrightarrow{BP} = (-2, 0, 2)$，$\overrightarrow{BC} = (0, 2, 0)$。

设平面 $BPC$ 的法向量 $\vec{n_1} = (x, y, z)$：

$$\begin{cases} -2x + 2z = 0 \\ 2y = 0 \end{cases} \implies \vec{n_1} = (1, 0, 1)$$

**第4步：** 求平面 $DPC$ 的法向量
> 📌 运用知识点：空间向量法求角

$\overrightarrow{DP} = (0, -2, 2)$，$\overrightarrow{DC} = (2, 0, 0)$。

设平面 $DPC$ 的法向量 $\vec{n_2} = (x, y, z)$：

$$\begin{cases} -2y + 2z = 0 \\ 2x = 0 \end{cases} \implies \vec{n_2} = (0, 1, 1)$$

**第5步：** 计算二面角
> 📌 运用知识点：空间向量法求角

$$\cos\theta = \frac{|\vec{n_1} \cdot \vec{n_2}|}{|\vec{n_1}||\vec{n_2}|} = \frac{|0 + 0 + 1|}{\sqrt{2} \cdot \sqrt{2}} = \frac{1}{2}$$

所以二面角 $B\text{-}PC\text{-}D$ 的大小为 $\dfrac{\pi}{3}$。

**答案：**（1）证明见解答；（2）二面角 $B\text{-}PC\text{-}D$ 的大小为 $\dfrac{\pi}{3}$。

**⚠️ 易错提醒：** 建系时注意三条互相垂直的边的选取；求法向量时方程组不要解错；二面角与法向量夹角的关系需注意判断锐角还是钝角。

**💡 解题思路总结：** 立体几何证明垂直用向量点积为零；求二面角用法向量夹角公式，注意根据图形判断二面角是锐角还是钝角。
