**题目：**

已知函数 $f(x) = x\ln x - ax$（$a \in \mathbb{R}$，$x > 0$）。

（1）当 $a = 0$ 时，求 $f(x)$ 的单调区间；

（2）若 $f(x) \geqslant -1$ 对一切 $x > 0$ 成立，求 $a$ 的取值范围。

---

**解答：**

**（1）求单调区间**

**第1步：** 求导分析
> 📌 运用知识点：导数与单调性

$a = 0$ 时，$f(x) = x\ln x$。

$$f'(x) = \ln x + x \cdot \frac{1}{x} = \ln x + 1$$

令 $f'(x) = 0$：$\ln x = -1$，$x = \dfrac{1}{e}$。

- 当 $0 < x < \dfrac{1}{e}$ 时，$f'(x) < 0$，$f(x)$ 单调递减；
- 当 $x > \dfrac{1}{e}$ 时，$f'(x) > 0$，$f(x)$ 单调递增。

单调递减区间 $\left(0, \dfrac{1}{e}\right)$，单调递增区间 $\left(\dfrac{1}{e}, +\infty\right)$。

---

**（2）求 $a$ 的取值范围**

**第2步：** 转化不等式
> 📌 运用知识点：导数与恒成立

$f(x) \geqslant -1$ 即 $x\ln x - ax \geqslant -1$，即 $x\ln x + 1 \geqslant ax$。

因为 $x > 0$，两边除以 $x$：

$$a \leqslant \ln x + \frac{1}{x}$$

需 $a \leqslant g(x)_{\min}$，其中 $g(x) = \ln x + \dfrac{1}{x}$。

**第3步：** 求 $g(x)$ 的最小值
> 📌 运用知识点：导数与最值

$$g'(x) = \frac{1}{x} - \frac{1}{x^2} = \frac{x - 1}{x^2}$$

$g'(x) = 0$ 时 $x = 1$。

- 当 $0 < x < 1$ 时，$g'(x) < 0$，$g(x)$ 递减；
- 当 $x > 1$ 时，$g'(x) > 0$，$g(x)$ 递增。

$g(x)$ 在 $x = 1$ 处取最小值：$g(1) = 0 + 1 = 1$。

**第4步：** 确定 $a$ 的范围

$$a \leqslant 1$$

验证 $a = 1$：$f(x) = x\ln x - x$，$f(x) + 1 = x\ln x - x + 1$。令 $h(x) = x\ln x - x + 1$，$h'(x) = \ln x$，$h'(x) = 0$ 时 $x = 1$，$h(1) = 0$ 为最小值。$h(x) \geqslant 0$ ✓。

**答案：**（1）递减区间 $\left(0, \dfrac{1}{e}\right)$，递增区间 $\left(\dfrac{1}{e}, +\infty\right)$；（2）$a \leqslant 1$。

**⚠️ 易错提醒：** 分离参数时注意 $x > 0$ 才能除以 $x$ 不变号；求 $g(x) = \ln x + \dfrac{1}{x}$ 最小值时不要算错导数。

**💡 解题思路总结：** 恒成立问题的标准方法：分离参数，转化为求函数最值。关键是构造函数 $g(x) = \ln x + \dfrac{1}{x}$ 并求其最小值。
