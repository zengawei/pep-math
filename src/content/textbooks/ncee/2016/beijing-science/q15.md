**题目：**

在 $\triangle ABC$ 中，$a$，$b$，$c$ 分别为角 $A$，$B$，$C$ 的对边，且 $\dfrac{\cos B}{\cos C} = \dfrac{b}{2a - c}$。

（1）求角 $B$；

（2）若 $b = \sqrt{13}$，$a + c = 4$，求 $\triangle ABC$ 的面积。

---

**解答：**

**（1）求角 $B$**

**第1步：** 运用正弦定理转化
> 📌 运用知识点：正弦定理

由正弦定理 $\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C}$，将边化为角：

$$\frac{\cos B}{\cos C} = \frac{\sin B}{2\sin A - \sin C}$$

**第2步：** 交叉相乘化简
> 📌 运用知识点：三角恒等变换

$$\cos B(2\sin A - \sin C) = \sin B \cos C$$

$$2\sin A \cos B - \sin C \cos B = \sin B \cos C$$

$$2\sin A \cos B = \sin B \cos C + \sin C \cos B = \sin(B + C)$$

因为 $B + C = \pi - A$，所以 $\sin(B + C) = \sin A$。

$$2\sin A \cos B = \sin A$$

因为 $\sin A \neq 0$，所以 $\cos B = \dfrac{1}{2}$，$B = \dfrac{\pi}{3}$。

---

**（2）求面积**

**第3步：** 运用余弦定理
> 📌 运用知识点：余弦定理

$$b^2 = a^2 + c^2 - 2ac\cos B$$

$$13 = a^2 + c^2 - 2ac \cdot \frac{1}{2} = a^2 + c^2 - ac$$

又 $a^2 + c^2 = (a + c)^2 - 2ac = 16 - 2ac$，代入：

$$13 = 16 - 2ac - ac = 16 - 3ac$$

$$ac = 1$$

**第4步：** 计算面积
> 📌 运用知识点：三角形面积

$$S = \frac{1}{2}ac\sin B = \frac{1}{2} \times 1 \times \frac{\sqrt{3}}{2} = \frac{\sqrt{3}}{4}$$

**答案：**（1）$B = \dfrac{\pi}{3}$；（2）$S = \dfrac{\sqrt{3}}{4}$。

**⚠️ 易错提醒：** 利用正弦定理将边化为角时，注意 $\sin(B+C) = \sin A$ 的转化；余弦定理中 $\cos B = \dfrac{1}{2}$ 不要遗漏。

**💡 解题思路总结：** 第一问通过正弦定理将边角关系转化为纯角的关系，利用 $\sin(B+C) = \sin A$ 化简求角；第二问利用余弦定理建立关于 $a, c$ 的方程组，结合 $a + c$ 求出 $ac$，再用面积公式。
