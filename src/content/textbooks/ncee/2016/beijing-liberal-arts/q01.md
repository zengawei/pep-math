**题目：** 已知集合 $A = \{-2, -1, 0, 1, 2\}$，$B = \{x \mid -1 < x \leqslant 2\}$，则 $A \cap B =$（）

A. $\{-1, 0, 1, 2\}$

B. $\{0, 1, 2\}$

C. $\{-1, 0, 1\}$

D. $\{0, 1\}$

---

**解答：**

**第1步：** 求交集
> 📌 运用知识点：集合运算

$B = (-1, 2]$，从集合 $A$ 中筛选满足 $-1 < x \leqslant 2$ 的元素：$0, 1, 2$。

$$A \cap B = \{0, 1, 2\}$$

**答案：** B
