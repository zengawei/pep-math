**题目：**

已知椭圆 $C: \dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$）的离心率为 $\dfrac{\sqrt{3}}{2}$，短轴长为 $2$。

（1）求椭圆 $C$ 的方程；

（2）过点 $M(0, 2)$ 的直线 $l$ 与椭圆 $C$ 交于 $A$，$B$ 两点，若 $\overrightarrow{MA} = 2\overrightarrow{MB}$，求直线 $l$ 的方程。

---

**解答：**

**（1）求椭圆方程**

**第1步：** 确定参数
> 📌 运用知识点：椭圆定义

$2b = 2$，$b = 1$。$e = \dfrac{c}{a} = \dfrac{\sqrt{3}}{2}$，$c^2 = a^2 - b^2 = a^2 - 1$。

$$c = \frac{\sqrt{3}}{2}a \implies c^2 = \frac{3}{4}a^2 \implies a^2 - 1 = \frac{3}{4}a^2 \implies \frac{1}{4}a^2 = 1 \implies a^2 = 4$$

$$\boxed{C: \frac{x^2}{4} + y^2 = 1}$$

---

**（2）求直线方程**

**第2步：** 联立方程
> 📌 运用知识点：圆锥曲线与直线

设 $l: y = kx + 2$。代入椭圆：

$$\frac{x^2}{4} + (kx + 2)^2 = 1 \implies (1 + 4k^2)x^2 + 16kx + 12 = 0$$

$$x_A + x_B = \frac{-16k}{1 + 4k^2}, \quad x_A x_B = \frac{12}{1 + 4k^2}$$

判别式 $\Delta = 256k^2 - 48(1 + 4k^2) = 64k^2 - 48 > 0$，需 $k^2 > \dfrac{3}{4}$。

**第3步：** 利用向量条件
> 📌 运用知识点：圆锥曲线综合

$\overrightarrow{MA} = 2\overrightarrow{MB}$ 意味着 $x_A = 2x_B$。

$$3x_B = \frac{-16k}{1 + 4k^2} \implies x_B = \frac{-16k}{3(1 + 4k^2)}$$

$$2x_B^2 = \frac{12}{1 + 4k^2} \implies x_B^2 = \frac{6}{1 + 4k^2}$$

**第4步：** 求解 $k$
> 📌 运用知识点：圆锥曲线综合

$$\left(\frac{16k}{3(1 + 4k^2)}\right)^2 = \frac{6}{1 + 4k^2}$$

$$\frac{256k^2}{9(1 + 4k^2)^2} = \frac{6}{1 + 4k^2} \implies 256k^2 = 54(1 + 4k^2)$$

$$256k^2 = 54 + 216k^2 \implies 40k^2 = 54 \implies k^2 = \frac{27}{20}$$

$k^2 = \dfrac{27}{20} > \dfrac{3}{4}$ ✓。$k = \pm\dfrac{3\sqrt{15}}{10}$。

**答案：**（1）$\dfrac{x^2}{4} + y^2 = 1$；（2）$l: y = \pm\dfrac{3\sqrt{15}}{10}x + 2$。

**⚠️ 易错提醒：** 向量条件 $\overrightarrow{MA} = 2\overrightarrow{MB}$ 转化为 $x_A = 2x_B$ 时注意方向；判别式条件 $k^2 > \dfrac{3}{4}$ 不要遗漏验证。

**💡 解题思路总结：** 先由离心率和短轴长确定椭圆方程；再利用韦达定理和向量条件建立关于 $k$ 的方程求解。
