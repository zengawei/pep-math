**题目：** 已知椭圆 $C: \dfrac{x^2}{4} + y^2 = 1$，$F_1, F_2$ 分别是其左、右焦点。

（1）求椭圆 $C$ 的离心率；

（2）过 $F_2$ 的直线 $l$ 与椭圆 $C$ 交于 $A, B$ 两点，若 $\triangle F_1AB$ 的面积为 $\dfrac{4\sqrt{2}}{3}$，求直线 $l$ 的方程。

---

**解答：**

**第1步：** 求离心率
> 📌 运用知识点：椭圆的性质

$a^2 = 4$，$b^2 = 1$，$c^2 = a^2 - b^2 = 3$，$c = \sqrt{3}$。

$$e = \frac{c}{a} = \frac{\sqrt{3}}{2}$$

**第2步：** 设直线并联立
> 📌 运用知识点：直线与椭圆的位置关系

$F_1(-\sqrt{3}, 0)$，$F_2(\sqrt{3}, 0)$。设 $l: x = my + \sqrt{3}$。

代入 $\dfrac{x^2}{4} + y^2 = 1$：

$$(m^2 + 4)y^2 + 2\sqrt{3}my - 1 = 0$$

$$y_1 + y_2 = \frac{-2\sqrt{3}m}{m^2 + 4}, \quad y_1 y_2 = \frac{-1}{m^2 + 4}$$

**第3步：** 求 $|AB|$ 和面积
> 📌 运用知识点：弦长公式

$$|y_1 - y_2| = \sqrt{(y_1 + y_2)^2 - 4y_1 y_2} = \sqrt{\frac{12m^2 + 4(m^2 + 4)}{(m^2 + 4)^2}} = \frac{4\sqrt{m^2 + 1}}{m^2 + 4}$$

$$|AB| = \sqrt{1 + m^2} \cdot |y_1 - y_2| = \frac{4(m^2 + 1)}{m^2 + 4}$$

$F_1$ 到 $l$ 的距离 $d = \dfrac{2\sqrt{3}}{\sqrt{1 + m^2}}$。

$$S = \frac{1}{2} |AB| \cdot d = \frac{4\sqrt{3}\sqrt{m^2 + 1}}{m^2 + 4}$$

**第4步：** 解方程
> 📌 运用知识点：代数运算

$$\frac{4\sqrt{3}\sqrt{m^2 + 1}}{m^2 + 4} = \frac{4\sqrt{2}}{3}$$

设 $t = \sqrt{m^2 + 1} \geqslant 1$：

$$\frac{\sqrt{3} t}{t^2 + 3} = \frac{\sqrt{2}}{3}$$

$$3\sqrt{3} t = \sqrt{2}(t^2 + 3)$$

平方：$27t^2 = 2(t^2 + 3)^2 = 2t^4 + 12t^2 + 18$

$$2t^4 - 15t^2 + 18 = 0 \implies t^2 = \frac{15 \pm 9}{4}$$

$t^2 = 6$ 或 $t^2 = \dfrac{3}{2}$。

$m^2 = 5$ 或 $m^2 = \dfrac{1}{2}$。$m = \pm\sqrt{5}$ 或 $m = \pm\dfrac{\sqrt{2}}{2}$。

$$\boxed{l: x = \pm\sqrt{5}y + \sqrt{3} \text{ 或 } x = \pm\frac{\sqrt{2}}{2}y + \sqrt{3}}$$

即 $y = \pm\dfrac{\sqrt{5}}{5}(x - \sqrt{3})$ 或 $y = \pm\sqrt{2}(x - \sqrt{3})$。

**⚠️ 易错提醒：** 设 $x = my + \sqrt{3}$ 可以包含竖直线（$m = 0$），比设 $y = k(x - \sqrt{3})$ 更全面。解方程后需要验证。

**💡 解题思路总结：** 椭圆焦点弦面积问题：联立 → 韦达定理 → 弦长公式 → 点到直线距离 → 面积公式 → 解方程。
