**题目：** 已知函数 $f(x) = x^3 + ax^2 + bx + c$ 在 $x = 1$ 处取得极大值 $2$，在 $x = 3$ 处取得极小值，则 $f(0) =$

A. $-2$

B. $0$

C. $2$

D. $4$

---

**解答：**

**第1步：** 利用极值条件
> 📌 运用知识点：导数与极值

$f'(x) = 3x^2 + 2ax + b$。$x = 1$ 和 $x = 3$ 是 $f'(x) = 0$ 的两个根。

$$f'(1) = 3 + 2a + b = 0 \quad \cdots (1)$$
$$f'(3) = 27 + 6a + b = 0 \quad \cdots (2)$$

$(2) - (1)$：$24 + 4a = 0 \implies a = -6$。代入 $(1)$：$b = 9$。

**第2步：** 求 $c$
> 📌 运用知识点：导数与极值

$$f(1) = 1 - 6 + 9 + c = 4 + c = 2 \implies c = -2$$

**第3步：** 求 $f(0)$
> 📌 运用知识点：函数的求值

$$f(0) = c = -2$$

**答案：A**

**⚠️ 易错提醒：** $x = 1$ 处取极大值，$x = 3$ 处取极小值，说明 $f'$ 在 $x = 1$ 处由正变负，在 $x = 3$ 处由负变正。需要验证 $f''(1) < 0$：$f''(x) = 6x - 12$，$f''(1) = -6 < 0$ ✓。

**💡 解题思路总结：** 极值点就是导数的零点。利用韦达定理或直接列方程组求参数。
