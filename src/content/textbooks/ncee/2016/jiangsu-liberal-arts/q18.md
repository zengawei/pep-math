**题目：** 已知等差数列 $\{a_n\}$ 中，$a_2 = 3$，$a_5 = 9$。

（1）求数列 $\{a_n\}$ 的通项公式；

（2）设 $b_n = \dfrac{1}{a_n \cdot a_{n+1}}$，求数列 $\{b_n\}$ 的前 $n$ 项和 $T_n$。

---

**解答：**

**第1步：** 求公差和首项
> 📌 运用知识点：等差数列的通项公式

$$d = \frac{a_5 - a_2}{5 - 2} = \frac{9 - 3}{3} = 2$$

$$a_1 = a_2 - d = 3 - 2 = 1$$

$$\boxed{a_n = 1 + (n - 1) \times 2 = 2n - 1}$$

**第2步：** 裂项求和
> 📌 运用知识点：数列求和——裂项法

$$b_n = \frac{1}{(2n - 1)(2n + 1)} = \frac{1}{2}\left(\frac{1}{2n - 1} - \frac{1}{2n + 1}\right)$$

$$T_n = \frac{1}{2}\left[\left(1 - \frac{1}{3}\right) + \left(\frac{1}{3} - \frac{1}{5}\right) + \cdots + \left(\frac{1}{2n - 1} - \frac{1}{2n + 1}\right)\right]$$

$$= \frac{1}{2}\left(1 - \frac{1}{2n + 1}\right) = \frac{1}{2} \times \frac{2n}{2n + 1} = \frac{n}{2n + 1}$$

$$\boxed{T_n = \dfrac{n}{2n + 1}}$$

**⚠️ 易错提醒：** 裂项时系数 $\dfrac{1}{2}$ 不要遗漏。裂项后中间项全部消去，只剩首尾。

**💡 解题思路总结：** $\dfrac{1}{n(n+d)}$ 型用裂项法：$\dfrac{1}{n(n+d)} = \dfrac{1}{d}\left(\dfrac{1}{n} - \dfrac{1}{n+d}\right)$。
