**题目：** 已知函数 $f(x) = x^3 - 3x + a$（$a \in \mathbb{R}$）。

（1）当 $a = 0$ 时，求 $f(x)$ 的极值；

（2）若 $f(x) \geqslant 0$ 对一切 $x \in [0, 2]$ 恒成立，求 $a$ 的取值范围。

---

**解答：**

**第1步：** 求导数和临界点
> 📌 运用知识点：导数与极值

$$f'(x) = 3x^2 - 3 = 3(x + 1)(x - 1)$$

令 $f'(x) = 0$，$x = -1$ 或 $x = 1$。

**第2步：** 判断极值
> 📌 运用知识点：导数与极值

- $x = -1$：$f'$ 由正变负，极大值 $f(-1) = -1 + 3 = 2$
- $x = 1$：$f'$ 由负变正，极小值 $f(1) = 1 - 3 = -2$

$$\boxed{\text{极大值 } 2 \text{（} x = -1 \text{ 处）}, \quad \text{极小值 } -2 \text{（} x = 1 \text{ 处）}}$$

**第3步：** 求 $a$ 的范围
> 📌 运用知识点：导数与最值

$f(x) \geqslant 0$ 在 $[0, 2]$ 上恒成立，即 $a \geqslant -x^3 + 3x$ 在 $[0, 2]$ 上恒成立。

设 $g(x) = -x^3 + 3x$，$g'(x) = -3x^2 + 3 = -3(x - 1)(x + 1)$。

在 $[0, 2]$ 上：$g'(x) > 0$（$0 \leqslant x < 1$），$g'(x) < 0$（$1 < x \leqslant 2$）。

$g(0) = 0$，$g(1) = 2$，$g(2) = -8 + 6 = -2$。

$g(x)$ 在 $[0, 2]$ 上的最大值为 $g(1) = 2$。

$$a \geqslant 2$$

$$\boxed{a \geqslant 2}$$

**⚠️ 易错提醒：** 第（2）问将 $f(x) \geqslant 0$ 转化为 $a \geqslant g(x)$，需要求 $g(x)$ 的最大值（不是最小值）。

**💡 解题思路总结：** 恒成立问题转化为最值问题：$f(x) \geqslant 0$ 恒成立 $\iff f(x)_{\min} \geqslant 0$。分离参数后求另一端函数的最值。
