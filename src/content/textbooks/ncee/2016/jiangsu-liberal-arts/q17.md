**题目：** 已知函数 $f(x) = \sqrt{3}\sin 2x - 2\sin^2 x + 1$。

（1）求 $f(x)$ 的最小正周期和单调递增区间；

（2）若 $f\left(\dfrac{\alpha}{2}\right) = \dfrac{\sqrt{3}}{2}$，$\alpha \in \left(0, \dfrac{\pi}{2}\right)$，求 $\sin\alpha$ 的值。

---

**解答：**

**第1步：** 化简函数
> 📌 运用知识点：三角恒等变换

$$f(x) = \sqrt{3}\sin 2x - (1 - \cos 2x) + 1 = \sqrt{3}\sin 2x + \cos 2x$$

$$f(x) = 2\sin\left(2x + \frac{\pi}{6}\right)$$

**第2步：** 求周期和递增区间
> 📌 运用知识点：三角函数的周期与单调性

$$T = \frac{2\pi}{2} = \pi$$

递增区间：$-\dfrac{\pi}{2} + 2k\pi \leqslant 2x + \dfrac{\pi}{6} \leqslant \dfrac{\pi}{2} + 2k\pi$

$$-\frac{\pi}{3} + k\pi \leqslant x \leqslant \frac{\pi}{6} + k\pi \quad (k \in \mathbb{Z})$$

递增区间为 $\left[-\dfrac{\pi}{3} + k\pi, \dfrac{\pi}{6} + k\pi\right]$（$k \in \mathbb{Z}$）。

**第3步：** 求 $\sin\alpha$
> 📌 运用知识点：三角函数的求值

$$f\left(\frac{\alpha}{2}\right) = 2\sin\left(\alpha + \frac{\pi}{6}\right) = \frac{\sqrt{3}}{2}$$

$$\sin\left(\alpha + \frac{\pi}{6}\right) = \frac{\sqrt{3}}{4}$$

因为 $\alpha \in \left(0, \dfrac{\pi}{2}\right)$，所以 $\alpha + \dfrac{\pi}{6} \in \left(\dfrac{\pi}{6}, \dfrac{2\pi}{3}\right)$。

$$\cos\left(\alpha + \frac{\pi}{6}\right) = \pm\sqrt{1 - \frac{3}{16}} = \pm\frac{\sqrt{13}}{4}$$

因为 $\sin\left(\alpha + \dfrac{\pi}{6}\right) = \dfrac{\sqrt{3}}{4} < \dfrac{1}{2} = \sin\dfrac{\pi}{6}$，而 $\alpha + \dfrac{\pi}{6} > \dfrac{\pi}{6}$，所以 $\alpha + \dfrac{\pi}{6} \in \left(\dfrac{\pi}{6}, \dfrac{5\pi}{6}\right)$ 且 $\sin$ 值较小，说明 $\alpha + \dfrac{\pi}{6} \in \left(\dfrac{\pi}{2}, \dfrac{2\pi}{3}\right)$，$\cos < 0$。

$$\cos\left(\alpha + \frac{\pi}{6}\right) = -\frac{\sqrt{13}}{4}$$

$$\sin\alpha = \sin\left[\left(\alpha + \frac{\pi}{6}\right) - \frac{\pi}{6}\right] = \sin\left(\alpha + \frac{\pi}{6}\right)\cos\frac{\pi}{6} - \cos\left(\alpha + \frac{\pi}{6}\right)\sin\frac{\pi}{6}$$

$$= \frac{\sqrt{3}}{4} \times \frac{\sqrt{3}}{2} - \left(-\frac{\sqrt{13}}{4}\right) \times \frac{1}{2} = \frac{3}{8} + \frac{\sqrt{13}}{8} = \frac{3 + \sqrt{13}}{8}$$

$$\boxed{\sin\alpha = \dfrac{3 + \sqrt{13}}{8}}$$

**⚠️ 易错提醒：** 化简时 $-2\sin^2 x + 1 = \cos 2x$（降幂公式），不要遗漏。求 $\cos$ 值时要根据角的范围判断正负。

**💡 解题思路总结：** 三角函数化简用辅助角公式。求值时注意角的范围，用差角公式展开。
