**题目：** 已知抛物线 $C: x^2 = 4y$ 的焦点为 $F$，过 $F$ 的直线与 $C$ 交于 $A, B$ 两点，$|AF| = 3$，则 $|BF| =$

A. $\dfrac{3}{2}$

B. $\dfrac{4}{3}$

C. $\dfrac{3}{4}$

D. $\dfrac{2}{3}$

---

**解答：**

**第1步：** 确定焦点
> 📌 运用知识点：抛物线的性质

$x^2 = 4y$，$2p = 4$，$p = 2$。焦点 $F(0, 1)$，准线 $y = -1$。

**第2步：** 求 $A$ 的坐标
> 📌 运用知识点：抛物线的焦半径

$|AF| = y_A + 1 = 3 \implies y_A = 2$。$x_A^2 = 8 \implies x_A = \pm 2\sqrt{2}$。

**第3步：** 利用焦半径性质
> 📌 运用知识点：抛物线的焦点弦

设直线 $AB$ 的斜率为 $k$，过 $F(0, 1)$：$y = kx + 1$。

代入 $x^2 = 4y$：$x^2 - 4kx - 4 = 0$。$x_A x_B = -4$。

$$x_B = \frac{-4}{x_A} = \frac{-4}{\pm 2\sqrt{2}} = \mp \sqrt{2}$$

$$y_B = \frac{x_B^2}{4} = \frac{2}{4} = \frac{1}{2}$$

$$|BF| = y_B + 1 = \frac{1}{2} + 1 = \frac{3}{2}$$

**答案：A**

**⚠️ 易错提醒：** 抛物线 $x^2 = 2py$ 的焦半径公式是 $|PF| = y_P + \dfrac{p}{2}$，不要与 $y^2 = 2px$ 的公式混淆。

**💡 解题思路总结：** 抛物线焦点弦问题，利用焦半径公式和韦达定理是标准方法。
