**题目：**

已知三棱锥 $S\text{-}ABC$ 中，$SA \perp$ 底面 $ABC$，$SA = 2$，底面 $ABC$ 是边长为 $2$ 的等边三角形，则三棱锥 $S\text{-}ABC$ 的外接球的表面积为 ______。

---

**解答：**

**第1步：** 建立空间直角坐标系
> 📌 运用知识点：坐标法

以 $A$ 为原点，$AB$ 方向为 $x$ 轴，底面内垂直于 $AB$ 的方向为 $y$ 轴，$AS$ 方向为 $z$ 轴。

$$A = (0, 0, 0), \quad B = (2, 0, 0), \quad C = (1, \sqrt{3}, 0), \quad S = (0, 0, 2)$$

**第2步：** 确定外接球球心
> 📌 运用知识点：外接球球心到各顶点距离相等

底面 $ABC$ 的外心（等边三角形重心）为 $G = \left(1, \dfrac{\sqrt{3}}{3}, 0\right)$。

由于 $SA \perp$ 底面，球心在 $G$ 正上方，$z$ 坐标为 $\dfrac{SA}{2} = 1$。

球心 $O = \left(1, \dfrac{\sqrt{3}}{3}, 1\right)$。

**第3步：** 计算半径

$$r^2 = |OA|^2 = 1^2 + \left(\frac{\sqrt{3}}{3}\right)^2 + 1^2 = 1 + \frac{1}{3} + 1 = \frac{7}{3}$$

**第4步：** 计算表面积

$$S = 4\pi r^2 = 4\pi \cdot \frac{7}{3} = \frac{28\pi}{3}$$

**正确答案：** $\dfrac{28\pi}{3}$
