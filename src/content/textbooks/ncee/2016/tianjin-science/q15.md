**题目：**

在 $\triangle ABC$ 中，内角 $A, B, C$ 的对边分别为 $a, b, c$，已知 $a = 2$，$b = 3$，$\cos C = \dfrac{1}{3}$。

（1）求 $c$ 的值；

（2）求 $\sin A$ 的值。

---

**解答：**

**第1步：** 利用余弦定理求 $c$
> 📌 运用知识点：余弦定理 $c^2 = a^2 + b^2 - 2ab\cos C$

$$c^2 = 2^2 + 3^2 - 2 \times 2 \times 3 \times \frac{1}{3} = 4 + 9 - 4 = 9$$

$$c = 3$$

**第2步：** 求 $\sin C$
> 📌 运用知识点：同角三角函数基本关系

$$\sin C = \sqrt{1 - \cos^2 C} = \sqrt{1 - \frac{1}{9}} = \sqrt{\frac{8}{9}} = \frac{2\sqrt{2}}{3}$$

**第3步：** 利用正弦定理求 $\sin A$
> 📌 运用知识点：正弦定理 $\dfrac{a}{\sin A} = \dfrac{c}{\sin C}$

$$\sin A = \frac{a \sin C}{c} = \frac{2 \times \dfrac{2\sqrt{2}}{3}}{3} = \frac{4\sqrt{2}}{9}$$

**⚠️ 易错提醒：**
1. 余弦定理中注意 $\cos C$ 的符号，本题 $\cos C > 0$，$C$ 为锐角。
2. 正弦定理求 $\sin A$ 时，注意 $A$ 的范围：因为 $a < c$，所以 $A < C$，$A$ 为锐角，$\sin A$ 取正值。

**💡 解题思路总结：**
先用余弦定理求第三边，再利用同角关系求 $\sin C$，最后用正弦定理求 $\sin A$。这是解三角形的标准流程：已知两边夹角 → 余弦定理求第三边 → 正弦定理求角。

**答案：** （1）$c = 3$；（2）$\sin A = \dfrac{4\sqrt{2}}{9}$
