**题目：**

已知椭圆 $C: \dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$）的左顶点为 $A$，右焦点为 $F$，$|AF| = 3$，离心率 $e = \dfrac{1}{2}$。

（1）求椭圆 $C$ 的方程；

（2）过点 $F$ 的直线 $l$ 与椭圆 $C$ 交于 $P, Q$ 两点，若 $\overrightarrow{AP} \cdot \overrightarrow{AQ} = \dfrac{9}{2}$，求直线 $l$ 的方程。

---

**解答：**

**第1步：** 求椭圆方程
> 📌 运用知识点：椭圆的基本量关系

$A = (-a, 0)$，$F = (c, 0)$。

$$|AF| = a + c = 3, \quad e = \frac{c}{a} = \frac{1}{2} \implies c = \frac{a}{2}$$

$$a + \frac{a}{2} = 3 \implies \frac{3a}{2} = 3 \implies a = 2, \quad c = 1$$

$$b^2 = a^2 - c^2 = 4 - 1 = 3$$

$$\text{椭圆方程：} \frac{x^2}{4} + \frac{y^2}{3} = 1$$

**第2步：** 设直线并联立
> 📌 运用知识点：直线与椭圆的位置关系（韦达定理）

$F = (1, 0)$，$A = (-2, 0)$。设 $l: x = my + 1$（包含斜率不存在的情况）。

代入椭圆方程：

$$\frac{(my + 1)^2}{4} + \frac{y^2}{3} = 1$$

$$3(my + 1)^2 + 4y^2 = 12$$

$$(3m^2 + 4)y^2 + 6my - 9 = 0$$

设 $P(x_1, y_1)$，$Q(x_2, y_2)$，由韦达定理：

$$y_1 + y_2 = \frac{-6m}{3m^2 + 4}, \quad y_1 y_2 = \frac{-9}{3m^2 + 4}$$

**第3步：** 计算 $\overrightarrow{AP} \cdot \overrightarrow{AQ}$
> 📌 运用知识点：向量数量积的坐标运算

$$\overrightarrow{AP} = (x_1 + 2, y_1), \quad \overrightarrow{AQ} = (x_2 + 2, y_2)$$

$$x_i + 2 = my_i + 3 \quad (i = 1, 2)$$

$$\overrightarrow{AP} \cdot \overrightarrow{AQ} = (my_1 + 3)(my_2 + 3) + y_1 y_2 = (m^2 + 1)y_1 y_2 + 3m(y_1 + y_2) + 9$$

代入韦达定理的结果：

$$= (m^2 + 1) \cdot \frac{-9}{3m^2 + 4} + 3m \cdot \frac{-6m}{3m^2 + 4} + 9$$

$$= \frac{-9m^2 - 9 - 18m^2}{3m^2 + 4} + 9 = \frac{-27m^2 - 9}{3m^2 + 4} + 9$$

$$= \frac{-27m^2 - 9 + 27m^2 + 36}{3m^2 + 4} = \frac{27}{3m^2 + 4}$$

**第4步：** 解方程求 $m$

$$\frac{27}{3m^2 + 4} = \frac{9}{2}$$

$$54 = 9(3m^2 + 4) = 27m^2 + 36$$

$$27m^2 = 18 \implies m^2 = \frac{2}{3} \implies m = \pm \frac{\sqrt{6}}{3}$$

**第5步：** 写出直线方程

$$x = \pm \frac{\sqrt{6}}{3} y + 1 \implies y = \pm \frac{\sqrt{6}}{2}(x - 1)$$

**⚠️ 易错提醒：**
1. 设直线时要用 $x = my + 1$ 而非 $y = k(x-1)$，否则遗漏斜率不存在的情况。
2. 韦达定理代入时注意符号，特别是 $y_1 y_2 < 0$ 不要漏掉负号。

**💡 解题思路总结：**
第一问用基本量关系求椭圆方程。第二问是解析几何的经典题型：设线 → 联立 → 韦达定理 → 向量条件转化为坐标关系 → 解方程。关键是合理设线（$x = my + t$ 形式）和准确计算。

**答案：** （1）$\dfrac{x^2}{4} + \dfrac{y^2}{3} = 1$；（2）$y = \pm \dfrac{\sqrt{6}}{2}(x - 1)$
