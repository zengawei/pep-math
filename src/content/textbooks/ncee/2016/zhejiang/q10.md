**题目：**

已知 $x > 0$，$y > 0$，且 $x + 2y = 4$，则 $\dfrac{1}{x} + \dfrac{1}{y}$ 的最小值为

A. $\dfrac{3}{4}$

B. $\dfrac{3}{4} + \dfrac{\sqrt{2}}{2}$

C. $\dfrac{3 + 2\sqrt{2}}{4}$

D. $1$

---

**解答：**

**第1步:** 利用"乘1法"

因为 $x + 2y = 4$，所以 $\dfrac{x + 2y}{4} = 1$。

$$\frac{1}{x} + \frac{1}{y} = \left(\frac{1}{x} + \frac{1}{y}\right) \times 1 = \left(\frac{1}{x} + \frac{1}{y}\right) \cdot \frac{x + 2y}{4}$$

> 📌 运用知识点：基本不等式

**第2步:** 展开并化简

$$= \frac{1}{4}\left(\frac{x + 2y}{x} + \frac{x + 2y}{y}\right) = \frac{1}{4}\left(1 + \frac{2y}{x} + \frac{x}{y} + 2\right) = \frac{1}{4}\left(3 + \frac{2y}{x} + \frac{x}{y}\right)$$

> 📌 运用知识点：基本不等式

**第3步:** 利用均值不等式

由均值不等式：

$$\frac{2y}{x} + \frac{x}{y} \geqslant 2\sqrt{\frac{2y}{x} \cdot \frac{x}{y}} = 2\sqrt{2}$$

等号成立条件：$\dfrac{2y}{x} = \dfrac{x}{y}$，即 $x^2 = 2y^2$，$x = \sqrt{2}y$。

代入 $x + 2y = 4$：$\sqrt{2}y + 2y = 4$，$y = \dfrac{4}{\sqrt{2}+2} = \dfrac{4(2-\sqrt{2})}{2} = 4 - 2\sqrt{2}$，$x = \sqrt{2}(4-2\sqrt{2}) = 4\sqrt{2} - 4$。

验证 $x > 0$：$4\sqrt{2} - 4 \approx 5.66 - 4 = 1.66 > 0$，满足。

$$\frac{1}{x} + \frac{1}{y} \geqslant \frac{1}{4}(3 + 2\sqrt{2}) = \frac{3 + 2\sqrt{2}}{4}$$

> 📌 运用知识点：基本不等式

**答案：C**

**⚠️ 易错提醒：** "乘1法"是条件最值问题的常用技巧，关键是构造出能用均值不等式的形式。等号成立条件必须验证，确保在约束条件下可以取到。

**💡 解题思路总结：** 已知 $ax + by = c$ 求 $\dfrac{m}{x} + \dfrac{n}{y}$ 的最小值，标准方法是"乘1法"——将 $\dfrac{m}{x} + \dfrac{n}{y}$ 乘以 $\dfrac{ax+by}{c} = 1$，展开后用均值不等式求最小值。
