**题目：**

已知函数 $f(x) = \sqrt{3}\sin 2x + \cos 2x$。

（1）求 $f(x)$ 的最小正周期和单调递增区间；

（2）在 $\triangle ABC$ 中，角 $A$，$B$，$C$ 所对的边分别为 $a$，$b$，$c$，若 $f(A) = 2$，$b = 1$，$\triangle ABC$ 的面积为 $\dfrac{\sqrt{3}}{2}$，求 $a$ 的值。

---

**解答：**

**（1）**

**第1步:** 辅助角公式化简

$$f(x) = \sqrt{3}\sin 2x + \cos 2x = 2\left(\frac{\sqrt{3}}{2}\sin 2x + \frac{1}{2}\cos 2x\right) = 2\sin\left(2x + \frac{\pi}{6}\right)$$

> 📌 运用知识点：三角恒等变换

**第2步:** 求周期

$$T = \frac{2\pi}{2} = \pi$$

> 📌 运用知识点：三角函数

**第3步:** 求单调递增区间

$f(x) = 2\sin\left(2x + \dfrac{\pi}{6}\right)$ 的单调递增区间满足：

$$-\frac{\pi}{2} + 2k\pi \leqslant 2x + \frac{\pi}{6} \leqslant \frac{\pi}{2} + 2k\pi, \quad k \in \mathbb{Z}$$

$$-\frac{\pi}{2} - \frac{\pi}{6} + 2k\pi \leqslant 2x \leqslant \frac{\pi}{2} - \frac{\pi}{6} + 2k\pi$$

$$-\frac{2\pi}{3} + 2k\pi \leqslant 2x \leqslant \frac{\pi}{3} + 2k\pi$$

$$-\frac{\pi}{3} + k\pi \leqslant x \leqslant \frac{\pi}{6} + k\pi, \quad k \in \mathbb{Z}$$

单调递增区间为 $\left[-\dfrac{\pi}{3} + k\pi, \dfrac{\pi}{6} + k\pi\right]$，$k \in \mathbb{Z}$。

> 📌 运用知识点：三角函数的图像与性质

**（2）**

**第4步:** 由 $f(A) = 2$ 求角 $A$

$$f(A) = 2\sin\left(2A + \frac{\pi}{6}\right) = 2$$

$$\sin\left(2A + \frac{\pi}{6}\right) = 1$$

因为 $A$ 是三角形内角，$0 < A < \pi$，所以 $\dfrac{\pi}{6} < 2A + \dfrac{\pi}{6} < 2\pi + \dfrac{\pi}{6}$。

$$2A + \frac{\pi}{6} = \frac{\pi}{2} \implies A = \frac{\pi}{6}$$

> 📌 运用知识点：三角函数

**第5步:** 利用面积公式求 $c$

$$S_{\triangle ABC} = \frac{1}{2}bc\sin A = \frac{1}{2} \times 1 \times c \times \sin\frac{\pi}{6} = \frac{1}{2} \times c \times \frac{1}{2} = \frac{c}{4}$$

已知面积为 $\dfrac{\sqrt{3}}{2}$：

$$\frac{c}{4} = \frac{\sqrt{3}}{2} \implies c = 2\sqrt{3}$$

> 📌 运用知识点：三角恒等变换

**第6步:** 利用余弦定理求 $a$

$$a^2 = b^2 + c^2 - 2bc\cos A = 1^2 + (2\sqrt{3})^2 - 2 \times 1 \times 2\sqrt{3} \times \cos\frac{\pi}{6}$$

$$= 1 + 12 - 4\sqrt{3} \times \frac{\sqrt{3}}{2} = 13 - 6 = 7$$

$$a = \sqrt{7}$$

> 📌 运用知识点：三角恒等变换

**答案：**

（1）最小正周期 $T = \pi$，单调递增区间为 $\left[-\dfrac{\pi}{3} + k\pi, \dfrac{\pi}{6} + k\pi\right]$，$k \in \mathbb{Z}$。

（2）$\boxed{a = \sqrt{7}}$

**⚠️ 易错提醒：** 辅助角公式中，$a\sin x + b\cos x = \sqrt{a^2+b^2}\sin(x+\varphi)$，其中 $\tan\varphi = \dfrac{b}{a}$，注意 $\varphi$ 的象限。由 $f(A)=2$ 求 $A$ 时，不要忘记 $A$ 的范围限制。

**💡 解题思路总结：** 三角函数综合题的标准流程：（1）辅助角公式化为 $A\sin(\omega x + \varphi)$ 形式；（2）由最值条件确定角度；（3）结合面积公式和余弦定理求解三角形。
