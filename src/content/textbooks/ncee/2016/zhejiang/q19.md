**题目：**

一个袋中装有 $5$ 个球，其中 $3$ 个红球，$2$ 个白球，从中随机取出 $2$ 个球，记取出的红球个数为 $X$。

（1）求 $X$ 的分布列；

（2）求 $X$ 的数学期望 $E(X)$ 和方差 $D(X)$。

---

**解答：**

**（1）**

**第1步:** 确定 $X$ 的可能取值

$X$ 的可能取值为 $0, 1, 2$。

从 $5$ 个球中取 $2$ 个的总取法：$\dbinom{5}{2} = 10$。

> 📌 运用知识点：分布列

**第2步:** 计算各概率

$$P(X = 0) = \frac{\binom{2}{2}}{\binom{5}{2}} = \frac{1}{10}$$

$$P(X = 1) = \frac{\binom{3}{1}\binom{2}{1}}{\binom{5}{2}} = \frac{3 \times 2}{10} = \frac{6}{10} = \frac{3}{5}$$

$$P(X = 2) = \frac{\binom{3}{2}}{\binom{5}{2}} = \frac{3}{10}$$

验证：$\dfrac{1}{10} + \dfrac{6}{10} + \dfrac{3}{10} = 1$。✓

$X$ 的分布列为：

| $X$ | $0$ | $1$ | $2$ |
|-----|-----|-----|-----|
| $P$ | $\dfrac{1}{10}$ | $\dfrac{3}{5}$ | $\dfrac{3}{10}$ |

> 📌 运用知识点：分布列

**（2）**

**第3步:** 求 $E(X)$

$$E(X) = 0 \times \frac{1}{10} + 1 \times \frac{3}{5} + 2 \times \frac{3}{10} = 0 + \frac{3}{5} + \frac{3}{5} = \frac{6}{5}$$

> 📌 运用知识点：期望与方差

**第4步:** 求 $D(X)$

$$E(X^2) = 0^2 \times \frac{1}{10} + 1^2 \times \frac{3}{5} + 2^2 \times \frac{3}{10} = 0 + \frac{3}{5} + \frac{12}{10} = \frac{3}{5} + \frac{6}{5} = \frac{9}{5}$$

$$D(X) = E(X^2) - [E(X)]^2 = \frac{9}{5} - \left(\frac{6}{5}\right)^2 = \frac{9}{5} - \frac{36}{25} = \frac{45}{25} - \frac{36}{25} = \frac{9}{25}$$

> 📌 运用知识点：期望与方差

**答案：**

（1）分布列见解答过程。

（2）$\boxed{E(X) = \dfrac{6}{5}, \quad D(X) = \dfrac{9}{25}}$

**⚠️ 易错提醒：** 超几何分布的概率计算中，分子是"从红球中取 $k$ 个 × 从白球中取 $2-k$ 个"，不要遗漏组合数的乘法。验证概率之和为 $1$ 是检查计算正确性的好方法。

**💡 解题思路总结：** 不放回抽样中取出某类物品个数服从超几何分布。求分布列需逐一计算各取值的概率，再验证总和为 $1$。期望和方差可直接用定义公式计算。
