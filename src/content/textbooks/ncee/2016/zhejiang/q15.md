**题目：**

已知圆 $C: x^2 + y^2 = 4$，直线 $l: x + y - 2 = 0$，则直线 $l$ 被圆 $C$ 所截得的弦长为 \_\_\_\_\_\_。

---

**解答：**

**第1步:** 确定圆的参数

圆 $C: x^2 + y^2 = 4$ 的圆心为 $O(0, 0)$，半径 $r = 2$。

> 📌 运用知识点：直线与圆的位置关系

**第2步:** 求圆心到直线的距离

$$d = \frac{|0 + 0 - 2|}{\sqrt{1^2 + 1^2}} = \frac{2}{\sqrt{2}} = \sqrt{2}$$

> 📌 运用知识点：直线与圆的位置关系

**第3步:** 利用勾股定理求弦长

设弦长为 $L$，由半弦、圆心距、半径构成直角三角形：

$$\left(\frac{L}{2}\right)^2 + d^2 = r^2$$

$$\left(\frac{L}{2}\right)^2 = r^2 - d^2 = 4 - 2 = 2$$

$$\frac{L}{2} = \sqrt{2}$$

$$L = 2\sqrt{2}$$

> 📌 运用知识点：直线与圆的位置关系

**答案：** $\boxed{2\sqrt{2}}$

**⚠️ 易错提醒：** 弦长公式 $L = 2\sqrt{r^2 - d^2}$ 中，$d$ 是圆心到直线的距离，不是原点到直线的距离（除非圆心在原点）。计算距离时注意分母是 $\sqrt{A^2 + B^2}$。

**💡 解题思路总结：** 直线截圆的弦长问题，核心方法是"半弦-圆心距-半径"构成的直角三角形关系：$\left(\dfrac{L}{2}\right)^2 + d^2 = r^2$。
