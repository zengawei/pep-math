**题目：**

如图，在四棱锥 $P\text{-}ABCD$ 中，底面 $ABCD$ 是正方形，$PA \perp$ 底面 $ABCD$，$PA = AB = 2$。

（1）证明：$BD \perp PC$；

（2）求二面角 $P\text{-}BD\text{-}A$ 的余弦值。

---

**解答：**

**（1）**

**第1步:** 建立空间直角坐标系

以 $A$ 为原点，$\overrightarrow{AB}$、$\overrightarrow{AD}$、$\overrightarrow{AP}$ 分别为 $x$、$y$、$z$ 轴正方向。

各点坐标：
- $A(0, 0, 0)$
- $B(2, 0, 0)$
- $C(2, 2, 0)$
- $D(0, 2, 0)$
- $P(0, 0, 2)$

> 📌 运用知识点：空间向量坐标

**第2步:** 计算向量并验证垂直

$$\overrightarrow{BD} = D - B = (-2, 2, 0)$$

$$\overrightarrow{PC} = C - P = (2, 2, -2)$$

$$\overrightarrow{BD} \cdot \overrightarrow{PC} = (-2)(2) + (2)(2) + (0)(-2) = -4 + 4 + 0 = 0$$

因为 $\overrightarrow{BD} \cdot \overrightarrow{PC} = 0$，所以 $BD \perp PC$。

> 📌 运用知识点：空间向量坐标

**（2）**

**第3步:** 求平面 $PBD$ 的法向量

$$\overrightarrow{BP} = P - B = (-2, 0, 2)$$

$$\overrightarrow{BD} = (-2, 2, 0)$$

设平面 $PBD$ 的法向量 $\vec{n_1} = (x, y, z)$：

$$\begin{cases} \vec{n_1} \cdot \overrightarrow{BP} = -2x + 2z = 0 \\ \vec{n_1} \cdot \overrightarrow{BD} = -2x + 2y = 0 \end{cases}$$

由第一式：$x = z$；由第二式：$x = y$。

取 $x = 1$，则 $\vec{n_1} = (1, 1, 1)$。

> 📌 运用知识点：空间向量坐标

**第4步:** 求平面 $ABD$ 的法向量

平面 $ABD$ 即底面 $ABCD$ 所在平面（$z = 0$ 平面），其法向量为 $\vec{n_2} = (0, 0, 1)$。

> 📌 运用知识点：空间向量坐标

**第5步:** 求二面角的余弦值

$$\cos\theta = \frac{|\vec{n_1} \cdot \vec{n_2}|}{|\vec{n_1}||\vec{n_2}|} = \frac{|(1)(0) + (1)(0) + (1)(1)|}{\sqrt{3} \times 1} = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}$$

由图可知二面角 $P\text{-}BD\text{-}A$ 为锐角，所以余弦值为正。

> 📌 运用知识点：空间角

**答案：**

（1）证明见解答过程。

（2）$\boxed{\dfrac{\sqrt{3}}{3}}$

**⚠️ 易错提醒：** 建系时要确保三条轴两两垂直。求法向量时方程组求解要仔细，取特殊值时确保不是零向量。二面角的余弦值正负需要根据图形判断。

**💡 解题思路总结：** 空间向量法解题三步曲：（1）建系写坐标；（2）证垂直用数量积为零；（3）求二面角先求两半平面法向量，再用夹角公式。
