**题目：**

已知集合 $A = \{x \mid x^2 - 4x + 3 < 0\}$，$B = \{x \mid 1 < x < 3\}$，则 $A \cap B =$

A. $\{x \mid 1 < x < 3\}$

B. $\{x \mid 1 < x < 4\}$

C. $\{x \mid -1 < x < 3\}$

D. $\{x \mid -1 < x < 1\}$

---

**解答：**

**第1步:** 求集合 $A$

解不等式 $x^2 - 4x + 3 < 0$：

$$x^2 - 4x + 3 = (x-1)(x-3) < 0$$

因此 $A = \{x \mid 1 < x < 3\}$。

> 📌 运用知识点：集合的运算

**第2步:** 求 $A \cap B$

$$A = \{x \mid 1 < x < 3\}, \quad B = \{x \mid 1 < x < 3\}$$

$$A \cap B = \{x \mid 1 < x < 3\}$$

> 📌 运用知识点：集合的运算

**答案：A**

**⚠️ 易错提醒：** 解一元二次不等式时，注意开口方向和根的大小关系。$(x-1)(x-3)<0$ 取两根之间的部分，不要搞反区间方向。

**💡 解题思路总结：** 先解不等式确定集合，再利用数轴求交集。当两个集合完全相同时，交集就是其本身。
