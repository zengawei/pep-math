**题目：**

已知等差数列 $\{a_n\}$ 的公差为 $2$，若 $a_1$，$a_3$，$a_4$ 成等比数列，则 $a_2 =$

A. $-6$

B. $-4$

C. $-2$

D. $0$

---

**解答：**

**第1步:** 用 $a_1$ 和公差表示各项

公差 $d = 2$，则：

$$a_3 = a_1 + 2d = a_1 + 4$$
$$a_4 = a_1 + 3d = a_1 + 6$$

> 📌 运用知识点：等差数列

**第2步:** 利用等比数列条件

$a_1$，$a_3$，$a_4$ 成等比数列，则 $a_3^2 = a_1 \cdot a_4$：

$$(a_1 + 4)^2 = a_1(a_1 + 6)$$

$$a_1^2 + 8a_1 + 16 = a_1^2 + 6a_1$$

$$2a_1 = -16 \implies a_1 = -8$$

> 📌 运用知识点：等差数列

**第3步:** 求 $a_2$

$$a_2 = a_1 + d = -8 + 2 = -6$$

> 📌 运用知识点：等差数列

**答案：A**

**⚠️ 易错提醒：** 等比中项的条件是 $b^2 = ac$，不要写成 $b^2 = a + c$（那是等差中项）。展开 $(a_1+4)^2$ 时不要漏项。

**💡 解题思路总结：** 等差数列中所有项都可以用首项 $a_1$ 和公差 $d$ 表示。结合等比条件列方程，解出 $a_1$ 后即可求任意项。
