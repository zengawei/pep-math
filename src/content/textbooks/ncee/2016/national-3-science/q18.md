**题目：** 在 $\triangle ABC$ 中，角 $A$，$B$，$C$ 的对边分别为 $a$，$b$，$c$。已知 $b^2 = ac$，$a^2 - c^2 = ac - bc$。

（1）求角 $A$ 的大小；

（2）若 $a = \sqrt{3}$，求 $\triangle ABC$ 面积的最大值。

---

**解答：**

**（1）求角 $A$**

**第1步：** 利用余弦定理
> 📌 运用知识点：三角恒等变换

$$\cos A = \frac{b^2 + c^2 - a^2}{2bc}$$

由 $b^2 = ac$，代入分子：

$$b^2 + c^2 - a^2 = ac + c^2 - a^2$$

由 $a^2 - c^2 = ac - bc$，得 $c^2 - a^2 = bc - ac$，即：

$$ac + c^2 - a^2 = ac + (bc - ac) = bc$$

**第2步：** 计算 $\cos A$

$$\cos A = \frac{bc}{2bc} = \frac{1}{2}$$

因为 $A \in (0, \pi)$，所以 $\boxed{A = \dfrac{\pi}{3}}$。

---

**（2）求面积最大值**

**第3步：** 建立约束关系
> 📌 运用知识点：基本不等式

由余弦定理：$a^2 = b^2 + c^2 - 2bc\cos A$

代入 $a = \sqrt{3}$，$A = \dfrac{\pi}{3}$：

$$3 = b^2 + c^2 - 2bc \cdot \frac{1}{2} = b^2 + c^2 - bc$$

**第4步：** 利用均值不等式
> 📌 运用知识点：基本不等式

由 $b^2 + c^2 \geq 2bc$：

$$3 = b^2 + c^2 - bc \geq 2bc - bc = bc$$

即 $bc \leq 3$，等号成立当且仅当 $b = c$。

当 $b = c$ 时：$3 = 2b^2 - b^2 = b^2$，$b = c = \sqrt{3}$。✓

**第5步：** 计算面积最大值

$$S = \frac{1}{2}bc\sin A = \frac{1}{2}bc \cdot \frac{\sqrt{3}}{2} = \frac{\sqrt{3}}{4}bc \leq \frac{\sqrt{3}}{4} \times 3 = \frac{3\sqrt{3}}{4}$$

$$\boxed{S_{\max} = \dfrac{3\sqrt{3}}{4}}$$

---

**⚠️ 易错提醒：**
1. 利用均值不等式求最值时，必须验证等号成立条件（$b = c$）是否满足所有约束。
2. 余弦定理中 $\cos A$ 的符号容易出错，注意 $A = \dfrac{\pi}{3}$ 时 $\cos A = \dfrac{1}{2}$。

**💡 解题思路总结：** 第一问通过余弦定理和已知等式直接求角；第二问利用余弦定理建立 $b, c$ 的约束关系，再用均值不等式求 $bc$ 的最大值，进而求面积最大值。
