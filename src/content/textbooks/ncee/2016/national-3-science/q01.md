**题目：** 设集合 $A = \{x \mid x^2 - 2x - 3 \leq 0\}$，$B = \{x \mid x \leq 2\}$，则 $A \cap B = $（）

(A) $[-1, 2]$

(B) $[1, 2]$

(C) $[0, 2]$

(D) $[-1, 3]$

---

**解答：**

**第1步：** 求解集合 $A$
> 📌 运用知识点：一元二次不等式

解不等式 $x^2 - 2x - 3 \leq 0$：

$$(x - 3)(x + 1) \leq 0$$

解得 $-1 \leq x \leq 3$，即 $A = [-1, 3]$。

**第2步：** 求 $A \cap B$
> 📌 运用知识点：集合运算

$$A \cap B = [-1, 3] \cap (-\infty, 2] = [-1, 2]$$

**正确答案：** (A)
