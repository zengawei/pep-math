**题目：** 如图，在三棱柱 $ABC\text{-}A_1B_1C_1$ 中，底面 $ABC$ 为等边三角形，侧面 $AA_1B_1B$ 为矩形，所有棱长均为 $2$，$D$ 为 $AB$ 的中点，$B_1$ 在底面 $ABC$ 上的投影恰好为 $D$。

（1）求证：平面 $B_1CD \perp$ 平面 $AA_1B_1B$；

（2）求二面角 $B\text{-}A_1D\text{-}C$ 的余弦值。

---

**解答：**

**（1）证明平面 $B_1CD \perp$ 平面 $AA_1B_1B$**

**第1步：** 分析几何关系
> 📌 运用知识点：空间位置关系

$B_1$ 在底面 $ABC$ 上的投影为 $D$，因此 $B_1D \perp$ 平面 $ABC$。

因为 $AB \subset$ 平面 $ABC$，所以 $B_1D \perp AB$。

**第2步：** 证明面面垂直
> 📌 运用知识点：空间位置关系

$D$ 为 $AB$ 中点，$B_1D \perp AB$，且 $B_1D \subset$ 平面 $B_1CD$。

$AB$ 为平面 $B_1CD$ 与平面 $AA_1B_1B$ 的交线（$D \in AB$，$B_1 \in$ 平面 $AA_1B_1B$）。

由面面垂直判定定理：一个平面过另一个平面的垂线，则两平面垂直。

$$\boxed{\text{平面 } B_1CD \perp \text{ 平面 } AA_1B_1B}$$

---

**（2）求二面角 $B\text{-}A_1D\text{-}C$ 的余弦值**

**第3步：** 建立空间直角坐标系
> 📌 运用知识点：空间向量坐标

以 $D$ 为原点，$\overrightarrow{DB}$ 为 $x$ 轴正方向，$\overrightarrow{DC}$ 为 $y$ 轴正方向，$\overrightarrow{DB_1}$ 为 $z$ 轴正方向。

$D$ 为 $AB$ 中点，$AB = 2$，$DB = 1$。

$\triangle ABC$ 为等边三角形，边长 $2$：$DC = \sqrt{3}$。

$B_1D = \sqrt{BB_1^2 - BD^2} = \sqrt{4 - 1} = \sqrt{3}$。

各点坐标：

$$D = (0, 0, 0),\quad B = (1, 0, 0),\quad A = (-1, 0, 0),\quad C = (0, \sqrt{3}, 0),\quad B_1 = (0, 0, \sqrt{3})$$

$\overrightarrow{AA_1} = \overrightarrow{BB_1} = B_1 - B = (-1, 0, \sqrt{3})$

$$A_1 = A + \overrightarrow{AA_1} = (-1, 0, 0) + (-1, 0, \sqrt{3}) = (-2, 0, \sqrt{3})$$

验证：$|AA_1| = \sqrt{1 + 3} = 2$。✓

**第4步：** 求法向量
> 📌 运用知识点：空间向量运算

二面角 $B\text{-}A_1D\text{-}C$：以 $A_1D$ 为棱，$B$ 和 $C$ 分别在两个半平面上。

$\overrightarrow{DA_1} = (-2, 0, \sqrt{3})$。

**半平面 $BA_1D$**：含 $\overrightarrow{DB} = (1, 0, 0)$ 和 $\overrightarrow{DA_1} = (-2, 0, \sqrt{3})$。

$$\vec{n_1} = \overrightarrow{DB} \times \overrightarrow{DA_1} = (0 \cdot \sqrt{3} - 0 \cdot 0,\; 0 \cdot (-2) - 1 \cdot \sqrt{3},\; 1 \cdot 0 - 0 \cdot (-2)) = (0, -\sqrt{3}, 0)$$

取 $\vec{n_1} = (0, 1, 0)$。

**半平面 $CA_1D$**：含 $\overrightarrow{DC} = (0, \sqrt{3}, 0)$ 和 $\overrightarrow{DA_1} = (-2, 0, \sqrt{3})$。

$$\vec{n_2} = \overrightarrow{DC} \times \overrightarrow{DA_1} = (\sqrt{3} \cdot \sqrt{3} - 0 \cdot 0,\; 0 \cdot (-2) - 0 \cdot \sqrt{3},\; 0 \cdot 0 - \sqrt{3} \cdot (-2)) = (3, 0, 2\sqrt{3})$$

**第5步：** 计算余弦值

$$\cos\theta = \frac{|\vec{n_1} \cdot \vec{n_2}|}{|\vec{n_1}| \cdot |\vec{n_2}|} = \frac{|0 \times 3 + 1 \times 0 + 0 \times 2\sqrt{3}|}{1 \times \sqrt{9 + 0 + 12}} = \frac{0}{\sqrt{21}} = 0$$

二面角 $B\text{-}A_1D\text{-}C$ 的余弦值为 $0$，即二面角为直角。

$$\boxed{\cos\theta = 0}$$

---

**⚠️ 易错提醒：**
1. 建系时要准确确定各顶点坐标，尤其是斜棱柱中顶点的投影关系。
2. 求二面角时注意法向量方向，判断二面角是锐角还是钝角。
3. 本题中 $B, A_1, D, B_1$ 四点共面（$y$ 坐标均为 $0$），因此半平面 $BA_1D$ 就是 $xz$ 平面。

**💡 解题思路总结：** 利用投影条件建立空间直角坐标系，通过向量叉积求法向量，再用点积公式求二面角的余弦值。本题结果为 $0$，说明二面角为直角。
