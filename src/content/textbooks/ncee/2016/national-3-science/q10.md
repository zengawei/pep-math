**题目：** 已知 $a > 0$，$b > 0$，且 $a + 2b = 2$，则 $\dfrac{2}{a} + \dfrac{1}{b}$ 的最小值为（）

(A) $4$

(B) $3$

(C) $2$

(D) $1$

---

**解答：**

**第1步：** 利用乘"1"法
> 📌 运用知识点：基本不等式

因为 $a + 2b = 2$，所以 $\dfrac{a + 2b}{2} = 1$。

$$\frac{2}{a} + \frac{1}{b} = \left(\frac{2}{a} + \frac{1}{b}\right) \times 1 = \left(\frac{2}{a} + \frac{1}{b}\right) \cdot \frac{a + 2b}{2}$$

**第2步：** 展开并应用均值不等式

$$= \frac{1}{2}\left(2 + \frac{4b}{a} + \frac{a}{b} + 2\right) = \frac{1}{2}\left(4 + \frac{4b}{a} + \frac{a}{b}\right)$$

由均值不等式：

$$\frac{4b}{a} + \frac{a}{b} \geq 2\sqrt{\frac{4b}{a} \cdot \frac{a}{b}} = 2\sqrt{4} = 4$$

因此：

$$\frac{2}{a} + \frac{1}{b} \geq \frac{1}{2}(4 + 4) = 4$$

**第3步：** 验证等号成立条件

等号成立当且仅当 $\dfrac{4b}{a} = \dfrac{a}{b}$，即 $a^2 = 4b^2$，$a = 2b$。

代入 $a + 2b = 2$：$2b + 2b = 2$，$b = \dfrac{1}{2}$，$a = 1$。

验证：$\dfrac{2}{1} + \dfrac{1}{1/2} = 2 + 2 = 4$。✓

**正确答案：** (A)
