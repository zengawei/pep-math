**题目：** 执行如图所示的程序框图。初始 $S = 0$，$n = 1$。每次循环先执行 $S = S + \dfrac{1}{n(n+2)}$，$n = n + 2$，然后判断 $S < \dfrac{10}{21}$ 是否成立：若成立则继续循环，否则输出 $M = n$ 并结束。则输出的 $M = $（）

(A) $17$

(B) $19$

(C) $21$

(D) $23$

---

**解答：**

**第1步：** 分析累加规律
> 📌 运用知识点：数列求和方法

利用裂项：$\dfrac{1}{n(n+2)} = \dfrac{1}{2}\!\left(\dfrac{1}{n} - \dfrac{1}{n+2}\right)$

第 $k$ 轮循环后（$n$ 从 $1$ 取到 $2k-1$，步长为 $2$）：

$$S_k = \frac{1}{2}\left[\left(1 - \frac{1}{3}\right) + \left(\frac{1}{3} - \frac{1}{5}\right) + \cdots + \left(\frac{1}{2k-1} - \frac{1}{2k+1}\right)\right] = \frac{1}{2}\left(1 - \frac{1}{2k+1}\right) = \frac{k}{2k+1}$$

**第2步：** 判断退出条件
> 📌 运用知识点：程序逻辑

判断 $S_k < \dfrac{10}{21}$：

$$\frac{k}{2k+1} < \frac{10}{21} \iff 21k < 10(2k+1) = 20k + 10 \iff k < 10$$

- $k = 1, 2, \ldots, 9$：$S_k < \dfrac{10}{21}$，继续循环。
- $k = 10$：$S_{10} = \dfrac{10}{21} \not< \dfrac{10}{21}$，退出循环。

**第3步：** 确定输出值

第 $10$ 轮循环后 $n = 1 + 2 \times 10 = 21$，输出 $M = 21$。

**正确答案：** (C)
