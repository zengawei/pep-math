**题目：** 已知抛物线 $y^2 = 4x$ 的焦点为 $F$，过 $F$ 的直线交抛物线于 $A$，$B$ 两点，若 $A$，$B$ 两点的横坐标之和为 $6$，则 $|AB| = $（）

(A) $6$

(B) $7$

(C) $8$

(D) $9$

---

**解答：**

**第1步：** 确定焦点和准线
> 📌 运用知识点：抛物线性质

抛物线 $y^2 = 4x$ 中，$2p = 4$，$p = 2$。

焦点 $F = (1, 0)$，准线 $x = -1$。

**第2步：** 利用焦半径公式
> 📌 运用知识点：抛物线性质

设 $A = (x_1, y_1)$，$B = (x_2, y_2)$。

由抛物线的焦半径公式：

$$|AF| = x_1 + \frac{p}{2} = x_1 + 1$$

$$|BF| = x_2 + \frac{p}{2} = x_2 + 1$$

**第3步：** 计算 $|AB|$

$$|AB| = |AF| + |BF| = (x_1 + 1) + (x_2 + 1) = x_1 + x_2 + 2$$

已知 $x_1 + x_2 = 6$：

$$|AB| = 6 + 2 = 8$$

**正确答案：** (C)
