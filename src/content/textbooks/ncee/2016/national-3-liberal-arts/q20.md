**题目：** 已知抛物线 $C$：$y^2 = 2px$（$p > 0$）的焦点为 $F$，过 $F$ 的直线 $l$ 与 $C$ 交于 $A$，$B$ 两点，且 $|AF| + |BF| = 8$。

（1）求 $C$ 的方程；

（2）设 $M$ 为 $AB$ 的中点，若 $|MF| = 3$，求直线 $l$ 的方程。

---

**解答：**

**第1步：** 利用抛物线的焦半径公式
> 📌 运用知识点：抛物线的定义

抛物线 $y^2 = 2px$ 的焦点 $F\left(\dfrac{p}{2}, 0\right)$，准线 $x = -\dfrac{p}{2}$。

设 $A(x_1, y_1)$，$B(x_2, y_2)$。由焦半径公式：

$$|AF| = x_1 + \frac{p}{2}, \quad |BF| = x_2 + \frac{p}{2}$$

$$|AF| + |BF| = x_1 + x_2 + p = 8$$

**第2步：** 利用直线与抛物线的关系

设直线 $l$：$x = my + \dfrac{p}{2}$（过焦点），代入 $y^2 = 2px$：

$$y^2 = 2p\left(my + \frac{p}{2}\right) = 2pmy + p^2$$

$$y^2 - 2pmy - p^2 = 0$$

由韦达定理：$y_1 + y_2 = 2pm$，$y_1 y_2 = -p^2$。

$$x_1 + x_2 = m(y_1 + y_2) + p = 2pm^2 + p$$

代入 $x_1 + x_2 + p = 8$：

$$2pm^2 + p + p = 8 \implies 2pm^2 + 2p = 8 \implies pm^2 + p = 4 \quad \cdots (*)$$

**第3步：** 利用 $|MF| = 3$ 的条件

$M$ 为 $AB$ 中点，$M$ 的坐标为：

$$x_M = \frac{x_1 + x_2}{2} = \frac{2pm^2 + p}{2} = pm^2 + \frac{p}{2}$$

$$y_M = \frac{y_1 + y_2}{2} = pm$$

$$|MF|^2 = \left(pm^2 + \frac{p}{2} - \frac{p}{2}\right)^2 + (pm)^2 = p^2m^4 + p^2m^2 = p^2m^2(m^2 + 1)$$

$$|MF| = pm\sqrt{m^2 + 1} = 3$$

由 $(*)$：$p(m^2 + 1) = 4$，所以 $p = \dfrac{4}{m^2 + 1}$。

代入：

$$\frac{4}{m^2 + 1} \cdot m \cdot \sqrt{m^2 + 1} = 3$$

$$\frac{4m}{\sqrt{m^2 + 1}} = 3$$

$$16m^2 = 9(m^2 + 1)$$

$$7m^2 = 9 \implies m^2 = \frac{9}{7} \implies m = \pm\frac{3}{\sqrt{7}}$$

$$p = \frac{4}{\frac{9}{7} + 1} = \frac{4}{\frac{16}{7}} = \frac{7}{4}$$

**第4步：** 写出结果

$$\boxed{C: y^2 = \frac{7}{2}x}$$

直线 $l$ 的方程：$x = \pm\dfrac{3}{\sqrt{7}}y + \dfrac{7}{8}$，即 $y = \pm\dfrac{\sqrt{7}}{3}\left(x - \dfrac{7}{8}\right)$。

化简：$x = \pm\dfrac{3\sqrt{7}}{7}y + \dfrac{7}{8}$

$$\boxed{l: y = \frac{\sqrt{7}}{3}x - \frac{7\sqrt{7}}{24} \text{ 或 } y = -\frac{\sqrt{7}}{3}x + \frac{7\sqrt{7}}{24}}$$

**⚠️ 易错提醒：** 抛物线的焦半径公式 $|PF| = x_0 + \dfrac{p}{2}$ 是解题的关键。设直线时注意讨论斜率存在与否的情况。韦达定理和中点坐标公式的配合使用是解析几何的常见技巧。

**💡 解题思路总结：** 抛物线焦点弦问题的核心工具：焦半径公式、韦达定理、中点坐标公式。将几何条件（弦长、中点距离）转化为关于参数的方程求解。
