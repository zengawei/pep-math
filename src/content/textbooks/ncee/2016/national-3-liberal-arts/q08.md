**题目：** 函数 $f(x) = x^3 - 3x + 1$ 在区间 $[-2, 2]$ 上的最大值为

A. $-1$

B. $1$

C. $3$

D. $-3$

---

**解答：**

**第1步：** 求导数并找驻点
> 📌 运用知识点：导数的运算

$$f'(x) = 3x^2 - 3 = 3(x^2 - 1) = 3(x + 1)(x - 1)$$

令 $f'(x) = 0$，得 $x = -1$ 或 $x = 1$，均在 $[-2, 2]$ 内。

**第2步：** 计算各关键点的函数值
> 📌 运用知识点：函数的最值

端点值：
$$f(-2) = (-2)^3 - 3(-2) + 1 = -8 + 6 + 1 = -1$$
$$f(2) = 2^3 - 3 \times 2 + 1 = 8 - 6 + 1 = 3$$

驻点值：
$$f(-1) = (-1)^3 - 3(-1) + 1 = -1 + 3 + 1 = 3$$
$$f(1) = 1^3 - 3 \times 1 + 1 = 1 - 3 + 1 = -1$$

**第3步：** 比较各值

$f(-2) = -1$，$f(-1) = 3$，$f(1) = -1$，$f(2) = 3$

最大值为 $3$。

**答案：C**

**⚠️ 易错提醒：** 求闭区间上的最值，必须比较端点值和驻点值，不能遗漏端点。本题中 $f(-1) = f(2) = 3$，最大值在两个点同时取到。

**💡 解题思路总结：** 闭区间上连续函数的最值求法：求导找驻点，比较驻点值和端点值，取最大（小）者。
