**题目：** 在 $\triangle ABC$ 中，$B = \dfrac{\pi}{4}$，$BC$ 边上的高等于 $\dfrac{1}{3}BC$，则 $\sin A = $ ______。

---

**解答：**

**第1步：** 建立几何关系
> 📌 运用知识点：三角形的高

设 $BC$ 边上的高为 $h$，则 $h = \dfrac{1}{3}BC$。

设 $BC = a$，则 $h = \dfrac{a}{3}$。

设高从 $A$ 落在 $BC$ 上的点为 $D$，则 $AD = \dfrac{a}{3}$。

**第2步：** 利用 $B = \dfrac{\pi}{4}$ 求 $BD$
> 📌 运用知识点：直角三角形中的三角函数

在直角 $\triangle ABD$ 中，$\angle B = \dfrac{\pi}{4}$，$AD = \dfrac{a}{3}$：

$$\tan B = \frac{AD}{BD} \implies \tan\frac{\pi}{4} = 1 = \frac{a/3}{BD}$$

$$BD = \frac{a}{3}$$

**第3步：** 求 $AB$ 和 $\sin A$
> 📌 运用知识点：正弦定理

$$AB = \frac{AD}{\sin B} = \frac{a/3}{\sin(\pi/4)} = \frac{a/3}{\sqrt{2}/2} = \frac{a\sqrt{2}}{3}$$

$DC = BC - BD = a - \dfrac{a}{3} = \dfrac{2a}{3}$

在直角 $\triangle ADC$ 中：

$$AC = \sqrt{AD^2 + DC^2} = \sqrt{\frac{a^2}{9} + \frac{4a^2}{9}} = \sqrt{\frac{5a^2}{9}} = \frac{a\sqrt{5}}{3}$$

由正弦定理 $\dfrac{BC}{\sin A} = \dfrac{AC}{\sin B}$：

$$\frac{a}{\sin A} = \frac{a\sqrt{5}/3}{\sqrt{2}/2} = \frac{a\sqrt{5}}{3} \cdot \frac{2}{\sqrt{2}} = \frac{a\sqrt{10}}{3}$$

$$\sin A = \frac{a}{a\sqrt{10}/3} = \frac{3}{\sqrt{10}} = \frac{3\sqrt{10}}{10}$$

**正确答案：** $\dfrac{3\sqrt{10}}{10}$
