**题目：** 已知 $a = 2^{\frac{4}{3}}$，$b = 3^{\frac{2}{3}}$，$c = 25^{\frac{1}{3}}$，则

A. $b < a < c$

B. $a < b < c$

C. $c < b < a$

D. $c < a < b$

---

**解答：**

**第1步：** 统一指数形式
> 📌 运用知识点：指数运算

将三个数都化为 $\frac{1}{3}$ 次方的形式：

$$a = 2^{\frac{4}{3}} = (2^4)^{\frac{1}{3}} = 16^{\frac{1}{3}}$$

$$b = 3^{\frac{2}{3}} = (3^2)^{\frac{1}{3}} = 9^{\frac{1}{3}}$$

$$c = 25^{\frac{1}{3}}$$

**第2步：** 比较大小
> 📌 运用知识点：幂函数的单调性

因为 $y = x^{\frac{1}{3}}$ 在 $(0, +\infty)$ 上是增函数，且 $9 < 16 < 25$，所以：

$$9^{\frac{1}{3}} < 16^{\frac{1}{3}} < 25^{\frac{1}{3}}$$

即 $b < a < c$。

**答案：A**

**⚠️ 易错提醒：** 比较不同底数、不同指数的幂的大小时，关键是统一指数（或统一底数），再利用幂函数（或指数函数）的单调性进行比较。

**💡 解题思路总结：** 统一指数为相同值后，底数越大，幂越大（正指数时）。这是比较幂大小的常用技巧。
