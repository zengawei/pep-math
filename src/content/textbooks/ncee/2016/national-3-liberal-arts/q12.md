**题目：** 已知函数 $f(x) = x^3 + ax^2 + bx + c$ 有两个极值点 $x_1$，$x_2$，且 $x_1 < x_2$，$f(x_1) = x_1 < x_2$，则

A. $2a^2 - 9b \geqslant 0$

B. $2a^2 - 9b > 0$

C. $a^2 - 3b > 0$

D. $a^2 - 3b \geqslant 0$

---

**解答：**

**第1步：** 分析极值点条件
> 📌 运用知识点：导数与极值

$$f'(x) = 3x^2 + 2ax + b$$

$f(x)$ 有两个极值点 $x_1, x_2$，即 $f'(x) = 0$ 有两个不等实根 $x_1, x_2$。

判别式 $\Delta = 4a^2 - 12b > 0$，即 $a^2 - 3b > 0$。

**第2步：** 利用韦达定理
> 📌 运用知识点：韦达定理

$$x_1 + x_2 = -\frac{2a}{3}, \quad x_1 x_2 = \frac{b}{3}$$

**第3步：** 分析条件 $f(x_1) = x_1$
> 📌 运用知识点：极值与函数值的关系

因为 $x_1$ 是 $f'(x) = 0$ 的根，所以 $3x_1^2 + 2ax_1 + b = 0$，即 $b = -3x_1^2 - 2ax_1$。

$$f(x_1) = x_1^3 + ax_1^2 + bx_1 + c = x_1$$

将 $b$ 代入：

$$x_1^3 + ax_1^2 + (-3x_1^2 - 2ax_1)x_1 + c = x_1$$

$$x_1^3 + ax_1^2 - 3x_1^3 - 2ax_1^2 + c = x_1$$

$$-2x_1^3 - ax_1^2 + c = x_1$$

$$c = 2x_1^3 + ax_1^2 + x_1$$

**第4步：** 确定正确选项

由第1步的分析，$f'(x) = 0$ 有两个不等实根的充要条件是 $\Delta > 0$，即：

$$4a^2 - 12b > 0 \implies a^2 - 3b > 0$$

**答案：C**

**⚠️ 易错提醒：** 有两个极值点意味着导数有两个不等实根，判别式严格大于零（不能等于零）。注意区分 $> 0$ 和 $\geqslant 0$。

**💡 解题思路总结：** 函数有两个极值点 $\Leftrightarrow$ 导函数有两个不等实根 $\Leftrightarrow$ 判别式 $\Delta > 0$。这是极值点存在性的基本条件。
