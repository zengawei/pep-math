**题目：** 在 $\triangle ABC$ 中，内角 $A$，$B$，$C$ 的对边分别为 $a$，$b$，$c$。已知 $\cos B = \dfrac{3}{5}$，$b = 2$，$\triangle ABC$ 的面积为 $\dfrac{4}{3}$。

（1）求 $a + c$ 的值；

（2）求 $\sin(B + C)$ 的值。

---

**解答：**

**第1步：** 由 $\cos B$ 求 $\sin B$
> 📌 运用知识点：同角三角函数基本关系

$$\sin B = \sqrt{1 - \cos^2 B} = \sqrt{1 - \frac{9}{25}} = \sqrt{\frac{16}{25}} = \frac{4}{5}$$

**第2步：** 利用面积公式求 $ac$
> 📌 运用知识点：三角形面积公式

$$S = \frac{1}{2}ac\sin B = \frac{4}{3}$$

$$\frac{1}{2} \cdot ac \cdot \frac{4}{5} = \frac{4}{3}$$

$$ac = \frac{4}{3} \times \frac{5}{2} = \frac{10}{3}$$

**第3步：** 利用余弦定理求 $a^2 + c^2$
> 📌 运用知识点：余弦定理

$$b^2 = a^2 + c^2 - 2ac\cos B$$

$$4 = a^2 + c^2 - 2 \times \frac{10}{3} \times \frac{3}{5} = a^2 + c^2 - 4$$

$$a^2 + c^2 = 8$$

**第4步：** 求 $a + c$

$$(a + c)^2 = a^2 + c^2 + 2ac = 8 + 2 \times \frac{10}{3} = 8 + \frac{20}{3} = \frac{44}{3}$$

$$\boxed{a + c = \frac{2\sqrt{33}}{3}}$$

**第5步：** 求 $\sin(B + C)$
> 📌 运用知识点：三角恒等变换

因为 $A + B + C = \pi$，所以 $B + C = \pi - A$，因此：

$$\sin(B + C) = \sin(\pi - A) = \sin A$$

由正弦定理：

$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{2}{4/5} = \frac{5}{2}$$

$$\sin A = \frac{2a}{5}$$

需要求 $a$ 的值。由 $a + c = \dfrac{2\sqrt{33}}{3}$，$ac = \dfrac{10}{3}$，$a$ 和 $c$ 是方程 $t^2 - \dfrac{2\sqrt{33}}{3}t + \dfrac{10}{3} = 0$ 的两根。

利用正弦定理的另一种方式：

$$\sin(B + C) = \sin A = \frac{a \sin B}{b} = \frac{a \times \frac{4}{5}}{2} = \frac{2a}{5}$$

同时，$\sin(B+C) = \sin B\cos C + \cos B\sin C$。

更直接地，利用 $A + B + C = \pi$：

$$\sin(B + C) = \sin A$$

由正弦定理 $\dfrac{b}{\sin B} = \dfrac{a}{\sin A}$，得 $\sin A = \dfrac{a \sin B}{b}$。

但 $a$ 有两个可能的值（$a$ 和 $c$ 可互换），所以：

$$\sin A = \frac{2a}{5}$$

由 $a + c = \dfrac{2\sqrt{33}}{3}$ 和 $ac = \dfrac{10}{3}$，解方程：

$$t^2 - \frac{2\sqrt{33}}{3}t + \frac{10}{3} = 0$$

$$t = \frac{\frac{2\sqrt{33}}{3} \pm \sqrt{\frac{44}{3} - \frac{40}{3}}}{2} = \frac{\frac{2\sqrt{33}}{3} \pm \sqrt{\frac{4}{3}}}{2} = \frac{\frac{2\sqrt{33}}{3} \pm \frac{2}{\sqrt{3}}}{2}$$

$$= \frac{\sqrt{33}}{3} \pm \frac{1}{\sqrt{3}} = \frac{\sqrt{33}}{3} \pm \frac{\sqrt{3}}{3} = \frac{\sqrt{33} \pm \sqrt{3}}{3}$$

取 $a = \dfrac{\sqrt{33} + \sqrt{3}}{3}$（或 $a = \dfrac{\sqrt{33} - \sqrt{3}}{3}$），则：

$$\sin(B + C) = \sin A = \frac{2a}{5} = \frac{2(\sqrt{33} \pm \sqrt{3})}{15}$$

由于 $a$ 和 $c$ 的对称性，$\sin A$ 有两个值。但题目要求 $\sin(B+C)$，而 $\sin(B+C) = \sin A$。

实际上，$\sin(B+C) = \sin A$，且由正弦定理：

$$\sin A = \frac{a}{b}\sin B$$

由于 $a$ 有两种取值，$\sin(B+C)$ 也有两种取值：

$$\boxed{\sin(B + C) = \frac{2(\sqrt{33} + \sqrt{3})}{15} \text{ 或 } \frac{2(\sqrt{33} - \sqrt{3})}{15}}$$

**⚠️ 易错提醒：** 第（2）问中 $\sin(B+C) = \sin A$ 的转化是关键。利用余弦定理和面积公式联立求 $a+c$ 时，注意 $(a+c)^2 = a^2 + c^2 + 2ac$ 的整体代换技巧。

**💡 解题思路总结：** 三角形中边角关系的综合问题，核心工具是余弦定理和面积公式。求 $a+c$ 时利用整体代换避免求单个边长，求 $\sin(B+C)$ 时利用 $A+B+C=\pi$ 转化为 $\sin A$。
