**题目：** 已知圆 $C$：$x^2 + y^2 - 2x - 4y + 1 = 0$，直线 $l$：$x + y + a = 0$，若直线 $l$ 被圆 $C$ 截得的弦长为 $2\sqrt{2}$，则 $a = $ ______。

---

**解答：**

**第1步：** 将圆的方程化为标准形式
> 📌 运用知识点：圆的标准方程

$$x^2 - 2x + y^2 - 4y + 1 = 0$$

$$(x - 1)^2 - 1 + (y - 2)^2 - 4 + 1 = 0$$

$$(x - 1)^2 + (y - 2)^2 = 4$$

圆心 $C(1, 2)$，半径 $r = 2$。

**第2步：** 求圆心到直线的距离
> 📌 运用知识点：点到直线的距离

$$d = \frac{|1 + 2 + a|}{\sqrt{1^2 + 1^2}} = \frac{|3 + a|}{\sqrt{2}}$$

**第3步：** 利用弦长公式求 $a$
> 📌 运用知识点：直线与圆的位置关系

弦长 $= 2\sqrt{r^2 - d^2} = 2\sqrt{2}$，所以：

$$r^2 - d^2 = 2$$

$$4 - \frac{(3 + a)^2}{2} = 2$$

$$\frac{(3 + a)^2}{2} = 2$$

$$(3 + a)^2 = 4$$

$$3 + a = \pm 2$$

$$a = -1 \text{ 或 } a = -5$$

**正确答案：** $-1$ 或 $-5$
