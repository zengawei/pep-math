**题目：** 设集合 $A = \{x \mid -1 \leqslant x \leqslant 3\}$，$B = \{x \mid 2 < x < 4\}$，则 $A \cup B =$

A. $\{x \mid -1 \leqslant x < 4\}$

B. $\{x \mid 2 < x \leqslant 3\}$

C. $\{x \mid -1 \leqslant x \leqslant 4\}$

D. $\{x \mid 2 < x < 4\}$

---

**解答：**

**第1步：** 分析集合 $A$ 和 $B$
> 📌 运用知识点：集合的表示

$A = \{x \mid -1 \leqslant x \leqslant 3\} = [-1, 3]$

$B = \{x \mid 2 < x < 4\} = (2, 4)$

**第2步：** 求 $A \cup B$
> 📌 运用知识点：集合的并集运算

在数轴上表示两个集合：

$A = [-1, 3]$，$B = (2, 4)$

两个区间有重叠部分 $(2, 3]$，合并后取最左端点和最右端点：

$A \cup B = [-1, 3] \cup (2, 4) = [-1, 4) = \{x \mid -1 \leqslant x < 4\}$

**答案：A**

**⚠️ 易错提醒：** 注意并集运算中端点的开闭：$x = 4$ 不属于 $B$，所以 $4$ 不属于并集；$x = -1$ 属于 $A$，所以 $-1$ 属于并集。

**💡 解题思路总结：** 求并集时，在数轴上标出两个集合的范围，取所有覆盖的部分。注意端点开闭由所属集合决定。
