**题目：** 某公司为了解用户对其产品的满意度，随机抽取了 $20$ 名用户进行评分调查，评分结果如下茎叶图所示：

| 茎 | 叶 |
|:---:|:---|
| 6 | 5, 8 |
| 7 | 2, 3, 5, 6, 8, 9 |
| 8 | 0, 1, 2, 3, 5, 6 |
| 9 | 0, 2, 5, 7, 9, 8 |

（1）求这 $20$ 名用户评分的平均分和中位数；

（2）将评分不低于 $80$ 分的用户称为"满意用户"，求从这 $20$ 名用户中随机抽取 $1$ 人，该用户为"满意用户"的概率。

---

**解答：**

**第1步：** 整理数据
> 📌 运用知识点：样本估计总体

由茎叶图，$20$ 名用户的评分数据为：

$6$ 行：$65, 68$（$2$ 个）

$7$ 行：$72, 73, 75, 76, 78, 79$（$6$ 个）

$8$ 行：$80, 81, 82, 83, 85, 86$（$6$ 个）

$9$ 行：$90, 92, 95, 97, 98, 99$（$6$ 个）

共 $2 + 6 + 6 + 6 = 20$ 个数据。

**第2步：** 计算平均分
> 📌 运用知识点：样本的平均数

$$\bar{x} = \frac{1}{20}(65 + 68 + 72 + 73 + 75 + 76 + 78 + 79 + 80 + 81 + 82 + 83 + 85 + 86 + 90 + 92 + 95 + 97 + 98 + 99) = \frac{1644}{20} = 82.2$$

**第3步：** 求中位数
> 📌 运用知识点：样本估计总体

$20$ 个数据排序后，中位数为第 $10$ 和第 $11$ 个数据的平均值。

第 $10$ 个：$81$，第 $11$ 个：$82$

$$\text{中位数} = \frac{81 + 82}{2} = 81.5$$

**第4步：** 求"满意用户"的概率
> 📌 运用知识点：随机事件的概率

评分不低于 $80$ 的用户有：$80, 81, 82, 83, 85, 86, 90, 92, 95, 97, 98, 99$，共 $12$ 人。

$$P = \frac{12}{20} = \frac{3}{5}$$

**答案：**

（1）平均分为 $82.2$，中位数为 $81.5$。

（2）"满意用户"的概率为 $\dfrac{3}{5}$。

**⚠️ 易错提醒：** 读茎叶图时要注意每个"叶"代表一个数据点，不要遗漏。求中位数时注意数据个数为偶数时取中间两个数的平均值。

**💡 解题思路总结：** 茎叶图保留了原始数据的所有信息，读取时要逐行逐叶计数。平均数、中位数是描述数据集中趋势的基本统计量。
