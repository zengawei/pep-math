**题目：** 已知等差数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n$，$a_2 = 2$，$a_5 = 8$，则 $S_6 = $ ______。

---

**解答：**

**第1步：** 利用已知条件求首项和公差
> 📌 运用知识点：等差数列的通项公式

设首项为 $a_1$，公差为 $d$。

$$a_2 = a_1 + d = 2 \quad \cdots (1)$$
$$a_5 = a_1 + 4d = 8 \quad \cdots (2)$$

$(2) - (1)$：$3d = 6$，所以 $d = 2$。

代入 $(1)$：$a_1 = 2 - 2 = 0$。

**第2步：** 求 $S_6$
> 📌 运用知识点：等差数列的前 $n$ 项和

$$S_6 = \frac{6}{2}(2a_1 + 5d) = 3(0 + 10) = 30$$

**正确答案：** $30$
