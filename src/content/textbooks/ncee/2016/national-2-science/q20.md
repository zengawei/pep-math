**题目：** 已知椭圆 $C: \dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$）的离心率为 $\dfrac{\sqrt{3}}{2}$，过右焦点 $F$ 且斜率为 $1$ 的直线交 $C$ 于 $A, B$ 两点，$|AB| = \dfrac{8}{5}$。

(1) 求椭圆 $C$ 的方程；

(2) 设 $M$ 为椭圆 $C$ 的左顶点，求 $\triangle MAB$ 的面积。

---

**解答：**

**第1步：** 由离心率确定 $a, b$ 关系（第1问）
> 📌 运用知识点：ellipse-definition

$e = \dfrac{c}{a} = \dfrac{\sqrt{3}}{2}$，所以 $c = \dfrac{\sqrt{3}}{2}a$。

$$b^2 = a^2 - c^2 = a^2 - \frac{3}{4}a^2 = \frac{1}{4}a^2$$

即 $b = \dfrac{a}{2}$，椭圆方程为 $x^2 + 4y^2 = a^2$。

**第2步：** 联立直线与椭圆方程
> 📌 运用知识点：conic-section-line

右焦点 $F\left(\dfrac{\sqrt{3}}{2}a, 0\right)$，直线 $AB$：$y = x - \dfrac{\sqrt{3}}{2}a$。

代入 $x^2 + 4y^2 = a^2$：

$$x^2 + 4\left(x - \frac{\sqrt{3}}{2}a\right)^2 = a^2$$

$$x^2 + 4x^2 - 4\sqrt{3}ax + 3a^2 = a^2$$

$$5x^2 - 4\sqrt{3}ax + 2a^2 = 0$$

**第3步：** 利用弦长公式求 $a$
> 📌 运用知识点：conic-section-line

设 $A(x_1, y_1)$，$B(x_2, y_2)$，由韦达定理：

$$x_1 + x_2 = \frac{4\sqrt{3}a}{5}, \quad x_1 x_2 = \frac{2a^2}{5}$$

$$(x_1 - x_2)^2 = (x_1+x_2)^2 - 4x_1 x_2 = \frac{48a^2}{25} - \frac{8a^2}{5} = \frac{48a^2 - 40a^2}{25} = \frac{8a^2}{25}$$

$$|AB| = \sqrt{1+k^2} \cdot |x_1 - x_2| = \sqrt{2} \cdot \frac{2\sqrt{2}a}{5} = \frac{4a}{5}$$

由题意 $\dfrac{4a}{5} = \dfrac{8}{5}$，解得 $a = 2$，$b = 1$。

**椭圆 $C$ 的方程为 $\dfrac{x^2}{4} + y^2 = 1$。**

**第4步：** 求 $\triangle MAB$ 的面积（第2问）
> 📌 运用知识点：conic-section-optimization

左顶点 $M(-2, 0)$。直线 $AB$：$y = x - \sqrt{3}$，即 $x - y - \sqrt{3} = 0$。

$M$ 到直线 $AB$ 的距离：

$$d = \frac{|-2 - 0 - \sqrt{3}|}{\sqrt{1^2 + (-1)^2}} = \frac{2 + \sqrt{3}}{\sqrt{2}}$$

$$S_{\triangle MAB} = \frac{1}{2} |AB| \cdot d = \frac{1}{2} \times \frac{8}{5} \times \frac{2+\sqrt{3}}{\sqrt{2}} = \frac{4(2+\sqrt{3})}{5\sqrt{2}} = \frac{4\sqrt{2}(2+\sqrt{3})}{10} = \frac{2\sqrt{2}(2+\sqrt{3})}{5}$$

**答案：(1) $\dfrac{x^2}{4} + y^2 = 1$；(2) $S_{\triangle MAB} = \dfrac{2\sqrt{2}(2+\sqrt{3})}{5}$**

**⚠️ 易错提醒：** ①弦长公式 $|AB| = \sqrt{1+k^2}|x_1 - x_2|$ 中不要漏掉 $\sqrt{1+k^2}$。②点到直线距离公式中注意绝对值的处理。③最终结果需分母有理化。

**💡 解题思路总结：** 椭圆与直线综合问题的标准流程：由离心率确定参数关系 → 联立方程用韦达定理 → 弦长公式确定参数值 → 点到直线距离求面积。
