**题目：** 已知抛物线 $C: y^2 = 2px$（$p > 0$）的焦点为 $F$，过 $F$ 的直线交 $C$ 于 $M, N$ 两点，$O$ 为原点。

(1) 若 $\overrightarrow{OM} \cdot \overrightarrow{ON} = -3$ 对任意过 $F$ 的直线均成立，求 $p$ 的值及抛物线 $C$ 的方程；

(2) 在 (1) 的条件下，若线段 $MN$ 的中点纵坐标为 $1$，求直线 $MN$ 的方程。

---

**解答：**

**第1步：** 设直线并联立（第1问）
> 📌 运用知识点：conic-section-line

焦点 $F\left(\dfrac{p}{2}, 0\right)$。设过 $F$ 的直线为 $x = ty + \dfrac{p}{2}$（$t$ 为参数，可表示所有过焦点的直线）。

代入 $y^2 = 2px$：

$$y^2 = 2p\left(ty + \frac{p}{2}\right) = 2pty + p^2$$

$$y^2 - 2pty - p^2 = 0$$

设 $M(x_1, y_1)$，$N(x_2, y_2)$，由韦达定理：

$$y_1 + y_2 = 2pt, \quad y_1 y_2 = -p^2$$

**第2步：** 计算 $\overrightarrow{OM} \cdot \overrightarrow{ON}$
> 📌 运用知识点：parabola-properties

$$x_1 x_2 = \left(ty_1 + \frac{p}{2}\right)\left(ty_2 + \frac{p}{2}\right) = t^2 y_1 y_2 + \frac{pt}{2}(y_1+y_2) + \frac{p^2}{4}$$

$$= t^2(-p^2) + \frac{pt}{2}(2pt) + \frac{p^2}{4} = -p^2 t^2 + p^2 t^2 + \frac{p^2}{4} = \frac{p^2}{4}$$

$$\overrightarrow{OM} \cdot \overrightarrow{ON} = x_1 x_2 + y_1 y_2 = \frac{p^2}{4} + (-p^2) = -\frac{3p^2}{4}$$

**第3步：** 求 $p$
> 📌 运用知识点：parabola-definition

注意到 $\overrightarrow{OM} \cdot \overrightarrow{ON} = -\dfrac{3p^2}{4}$ 与 $t$ 无关（对任意过焦点的直线恒成立）。

令 $-\dfrac{3p^2}{4} = -3$，解得 $p^2 = 4$，$p = 2$。

**抛物线 $C$ 的方程为 $y^2 = 4x$。**

**第4步：** 利用中点条件求直线（第2问）
> 📌 运用知识点：conic-section-line

$p = 2$ 时，方程为 $y^2 - 4ty - 4 = 0$。

$y_1 + y_2 = 4t$，中点纵坐标为 $\dfrac{y_1+y_2}{2} = 2t$。

由题意 $2t = 1$，解得 $t = \dfrac{1}{2}$。

**第5步：** 写出直线方程
> 📌 运用知识点：parabola-properties

直线 $MN$：$x = \dfrac{1}{2}y + 1$，即 $2x - y - 2 = 0$。

验证：$y^2 - 2y - 4 = 0$，$\Delta = 4 + 16 = 20 > 0$，有两交点。✓

**答案：(1) $p = 2$，$y^2 = 4x$；(2) $2x - y - 2 = 0$**

**⚠️ 易错提醒：** ①设直线为 $x = ty + \frac{p}{2}$ 而非 $y = k(x - \frac{p}{2})$，前者可以表示斜率不存在（竖直）的情况。②$\overrightarrow{OM} \cdot \overrightarrow{ON}$ 的结果与 $t$ 无关是抛物线的重要性质。③中点纵坐标条件直接确定 $t$ 的值。

**💡 解题思路总结：** 抛物线与直线综合：设 $x = ty + \frac{p}{2}$ 联立抛物线方程，利用韦达定理求 $y_1 y_2$ 和 $x_1 x_2$，进而计算向量点积。中点条件转化为 $y_1 + y_2$ 的等式，快速确定参数。
