**题目：** 已知函数 $f(x) = (x+1)\ln x - a(x-1)$。

(1) 当 $a = 2$ 时，求 $f(x)$ 的单调区间；

(2) 若 $f(x) > 0$ 对 $x \in (1, +\infty)$ 恒成立，求 $a$ 的取值范围。

---

**解答：**

**第1步：** 求导（第1问，$a = 2$）
> 📌 运用知识点：derivative-operations

$f(x) = (x+1)\ln x - 2(x-1)$，定义域 $x > 0$。

$$f'(x) = \ln x + (x+1) \cdot \frac{1}{x} - 2 = \ln x + 1 + \frac{1}{x} - 2 = \ln x + \frac{1}{x} - 1$$

**第2步：** 分析 $f'(x)$ 的符号
> 📌 运用知识点：derivative-monotonicity

设 $g(x) = \ln x + \dfrac{1}{x} - 1$。

$$g'(x) = \frac{1}{x} - \frac{1}{x^2} = \frac{x-1}{x^2}$$

- 当 $0 < x < 1$ 时，$g'(x) < 0$，$g(x)$ 递减
- 当 $x > 1$ 时，$g'(x) > 0$，$g(x)$ 递增

$g(x)$ 在 $x = 1$ 处取最小值：$g(1) = 0 + 1 - 1 = 0$。

所以 $g(x) \geq 0$（等号仅在 $x = 1$ 时成立），即 $f'(x) \geq 0$。

**结论：** $f(x)$ 在 $(0, +\infty)$ 上单调递增。

单调递增区间为 $(0, +\infty)$，无单调递减区间。

**第3步：** 分析 $f(x) > 0$ 恒成立的条件（第2问）
> 📌 运用知识点：derivative-max-min

$f(x) = (x+1)\ln x - a(x-1)$

$$f'(x) = \ln x + \frac{x+1}{x} - a = \ln x + 1 + \frac{1}{x} - a$$

设 $h(x) = \ln x + 1 + \dfrac{1}{x} - a$，则 $h'(x) = \dfrac{1}{x} - \dfrac{1}{x^2} = \dfrac{x-1}{x^2}$。

当 $x > 1$ 时 $h'(x) > 0$，$h(x)$ 在 $(1, +\infty)$ 上递增。

$h(1) = 0 + 1 + 1 - a = 2 - a$。

**第4步：** 分类讨论
> 📌 运用知识点：derivative-monotonicity

**情况一：** $a \leq 2$ 时，$h(1) = 2 - a \geq 0$。

因为 $h(x)$ 在 $(1, +\infty)$ 上递增，所以 $h(x) > h(1) \geq 0$，即 $f'(x) > 0$。

$f(x)$ 在 $(1, +\infty)$ 上递增，$f(x) > f(1) = 2\ln 1 - 0 = 0$。✓

**情况二：** $a > 2$ 时，$h(1) = 2 - a < 0$。

当 $x \to +\infty$ 时，$h(x) \to +\infty$。

由零点存在定理，存在 $x_0 \in (1, +\infty)$ 使 $h(x_0) = 0$。

当 $x \in (1, x_0)$ 时 $h(x) < 0$，即 $f'(x) < 0$，$f(x)$ 递减。

$f(x) < f(1) = 0$，不满足 $f(x) > 0$。✗

**第5步：** 结论
> 📌 运用知识点：derivative-extrema

$a$ 的取值范围为 $a \leq 2$，即 $a \in (-\infty, 2]$。

**答案：(1) $f(x)$ 在 $(0, +\infty)$ 上单调递增；(2) $a \leq 2$**

**⚠️ 易错提醒：** ①第1问中 $f'(x) \geq 0$ 且等号仅在孤立点 $x=1$ 处成立，不影响单调性，$f(x)$ 仍为严格递增。②第2问中对 $f'(x)$ 的最小值分析是关键，需判断 $f'(x)$ 在 $(1, +\infty)$ 上的符号。

**💡 解题思路总结：** 含参不等式恒成立问题：先求导分析导函数的单调性，再根据参数取值分类讨论导函数的符号，最终确定使原函数恒正的参数范围。核心是"构造函数 → 求导 → 分析最值"。
