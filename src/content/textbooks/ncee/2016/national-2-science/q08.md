**题目：** 已知 $a = 2^{0.3}$，$b = 0.3^2$，$c = \log_2 0.3$，则 $a, b, c$ 的大小关系为（  ）

A. $c < b < a$

B. $c < a < b$

C. $b < c < a$

D. $b < a < c$

---

**解答：**

**第1步：** 判断各值的大致范围
> 📌 运用知识点：exponential-function

$a = 2^{0.3}$：因为 $0.3 > 0$，所以 $2^{0.3} > 2^0 = 1$，即 $a > 1$。

**第2步：** 判断 $b$ 的范围
> 📌 运用知识点：power-function

$b = 0.3^2 = 0.09$，显然 $0 < b < 1$。

**第3步：** 判断 $c$ 的范围
> 📌 运用知识点：logarithmic-function

$c = \log_2 0.3$：因为 $0.3 < 1$，所以 $\log_2 0.3 < \log_2 1 = 0$，即 $c < 0$。

**第4步：** 比较大小
> 📌 运用知识点：exponential-function

综合：$c < 0 < b < 1 < a$，即 $c < b < a$。

**答案：A**

**⚠️ 易错提醒：** 比较不同类函数值的大小时，关键是找到它们与 $0$ 和 $1$ 的关系，利用指数函数和对数函数的单调性判断范围。

**💡 解题思路总结：** 指数函数 $a^x$（$a > 1$）的值恒正且 $x > 0$ 时大于 $1$；幂函数 $x^2$（$0 < x < 1$）的值在 $(0, 1)$ 之间；对数函数 $\log_a x$（$a > 1$）当 $0 < x < 1$ 时为负。利用这些性质快速定位各值的范围。
