**题目：** 已知集合 $A = \{1, 2, 3, 4, 5, 6, 7\}$，$B = \{x \mid (x-1)(x-3) > 0\}$，则 $A \cap B = $（  ）

A. $\{1, 2, 3\}$

B. $\{4, 5, 6, 7\}$

C. $\{2, 3, 4, 5\}$

D. $\{1, 2, 3, 4, 5, 6, 7\}$

---

**解答：**

**第1步：** 求解集合 $B$
> 📌 运用知识点：set-operations

解不等式 $(x-1)(x-3) > 0$。

令 $(x-1)(x-3) = 0$，得 $x = 1$ 或 $x = 3$。

由二次函数图像（开口向上），$(x-1)(x-3) > 0$ 的解为 $x < 1$ 或 $x > 3$。

所以 $B = \{x \mid x < 1 \text{ 或 } x > 3\}$。

**第2步：** 求 $A \cap B$
> 📌 运用知识点：set-operations

$A = \{1, 2, 3, 4, 5, 6, 7\}$，从中筛选满足 $x < 1$ 或 $x > 3$ 的元素：

- $x = 1$：$(1-1)(1-3) = 0$，不满足 $> 0$，不属于 $B$
- $x = 2$：$(2-1)(2-3) = -1 < 0$，不属于 $B$
- $x = 3$：$(3-1)(3-3) = 0$，不属于 $B$
- $x = 4, 5, 6, 7$：均满足 $x > 3$，属于 $B$

所以 $A \cap B = \{4, 5, 6, 7\}$。

**答案：B**

**⚠️ 易错提醒：** 注意不等式是严格大于零（$> 0$），所以 $x = 1$ 和 $x = 3$ 不属于集合 $B$。另外 $x = 2$ 使乘积为负，也不属于 $B$。

**💡 解题思路总结：** 先解一元二次不等式确定集合 $B$ 的范围，再从集合 $A$ 中逐一检验哪些元素满足条件，取交集。
