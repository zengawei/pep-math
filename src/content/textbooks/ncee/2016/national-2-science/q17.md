**题目：** $\triangle ABC$ 的内角 $A, B, C$ 的对边分别为 $a, b, c$，已知 $2\cos C(a\cos B + b\cos A) = c$。

(1) 求 $C$；

(2) 若 $c = \sqrt{7}$，$\triangle ABC$ 的面积为 $\dfrac{3\sqrt{3}}{2}$，求 $a + b$ 的值。

---

**解答：**

**第1步：** 利用正弦定理转化（第1问）
> 📌 运用知识点：trig-function

由正弦定理 $\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C}$，将 $a, b, c$ 用 $\sin A, \sin B, \sin C$ 表示：

$$2\cos C(\sin A\cos B + \sin B\cos A) = \sin C$$

**第2步：** 化简求 $C$
> 📌 运用知识点：trig-identity

由和角公式：$\sin A\cos B + \sin B\cos A = \sin(A+B)$。

因为 $A + B + C = \pi$，所以 $\sin(A+B) = \sin(\pi - C) = \sin C$。

代入：$2\cos C \cdot \sin C = \sin C$

因为 $\sin C > 0$（$C \in (0, \pi)$），两边除以 $\sin C$：

$$2\cos C = 1 \implies \cos C = \frac{1}{2}$$

因为 $C \in (0, \pi)$，所以 $C = \dfrac{\pi}{3}$。

**第3步：** 利用面积条件（第2问）
> 📌 运用知识点：trig-identity

$$S = \frac{1}{2}ab\sin C = \frac{1}{2}ab\sin\frac{\pi}{3} = \frac{1}{2}ab \cdot \frac{\sqrt{3}}{2} = \frac{\sqrt{3}}{4}ab = \frac{3\sqrt{3}}{2}$$

解得 $ab = 6$。

**第4步：** 利用余弦定理求 $a + b$
> 📌 运用知识点：trig-function

$$c^2 = a^2 + b^2 - 2ab\cos C$$

$$7 = a^2 + b^2 - 2 \times 6 \times \frac{1}{2} = a^2 + b^2 - 6$$

$$a^2 + b^2 = 13$$

$$(a+b)^2 = a^2 + 2ab + b^2 = 13 + 12 = 25$$

$$a + b = 5$$

**答案：(1) $C = \dfrac{\pi}{3}$；(2) $a + b = 5$**

**⚠️ 易错提醒：** ①第1问中利用 $\sin(A+B) = \sin C$ 是关键转化。②第2问中 $(a+b)^2 = a^2 + b^2 + 2ab$，注意是加号。③$a+b > 0$，所以 $(a+b)^2 = 25$ 开方取正值。

**💡 解题思路总结：** 解三角形的两大工具：正弦定理（边角互化）和余弦定理（建立边的关系）。面积公式 $S = \frac{1}{2}ab\sin C$ 可求 $ab$，再结合余弦定理求 $a+b$。
