**题目：** 如图，在三棱锥 $P\text{-}ABC$ 中，$PA \perp$ 底面 $ABC$，$PA = AB = AC = 2$，$\angle BAC = 90°$。

（1）证明：$AB \perp PC$；

（2）求点 $A$ 到平面 $PBC$ 的距离；

（3）求直线 $PC$ 与平面 $PAB$ 所成角的大小。

---

**解答：**

以 $A$ 为原点，$\overrightarrow{AB}$、$\overrightarrow{AC}$、$\overrightarrow{AP}$ 分别为 $x$、$y$、$z$ 轴正方向建立空间直角坐标系。

各点坐标：$A(0, 0, 0)$，$B(2, 0, 0)$，$C(0, 2, 0)$，$P(0, 0, 2)$。

**（1）证明 $AB \perp PC$**

**第1步：** 证明 $AB \perp$ 平面 $PAC$
> 📌 运用知识点：线面垂直的判定

$\overrightarrow{AB} = (2, 0, 0)$

$\overrightarrow{PA} = (0, 0, -2)$，$\overrightarrow{AC} = (0, 2, 0)$

$$\overrightarrow{AB} \cdot \overrightarrow{PA} = 0 \implies AB \perp PA$$

$$\overrightarrow{AB} \cdot \overrightarrow{AC} = 0 \implies AB \perp AC$$

$PA$ 与 $AC$ 是平面 $PAC$ 内两条相交直线（交于点 $A$），所以 $AB \perp$ 平面 $PAC$。

**第2步：** 推出 $AB \perp PC$

因为 $PC \subset$ 平面 $PAC$，且 $AB \perp$ 平面 $PAC$，所以 $AB \perp PC$。$\blacksquare$

**（2）求点 $A$ 到平面 $PBC$ 的距离**

**第3步：** 求平面 $PBC$ 的法向量
> 📌 运用知识点：空间向量法求平面法向量

$\overrightarrow{PB} = B - P = (2, 0, -2)$，$\overrightarrow{PC} = C - P = (0, 2, -2)$

设法向量 $\vec{n} = (x, y, z)$：

$$\begin{cases} \vec{n} \cdot \overrightarrow{PB} = 2x - 2z = 0 \\ \vec{n} \cdot \overrightarrow{PC} = 2y - 2z = 0 \end{cases} \implies x = z,\; y = z$$

取 $z = 1$，得 $\vec{n} = (1, 1, 1)$

**第4步：** 计算距离
> 📌 运用知识点：点到平面的距离公式

$$d = \frac{|\overrightarrow{AP} \cdot \vec{n}|}{|\vec{n}|} = \frac{|(0, 0, 2) \cdot (1, 1, 1)|}{\sqrt{1^2 + 1^2 + 1^2}} = \frac{2}{\sqrt{3}} = \frac{2\sqrt{3}}{3}$$

**（3）求直线 $PC$ 与平面 $PAB$ 所成角**

**第5步：** 求平面 $PAB$ 的法向量
> 📌 运用知识点：坐标法求线面角

$\overrightarrow{AB} = (2, 0, 0)$，$\overrightarrow{AP} = (0, 0, 2)$

法向量 $\vec{m} = \overrightarrow{AB} \times \overrightarrow{AP}$，取 $\vec{m} = (0, 1, 0)$

**第6步：** 计算线面角

$\overrightarrow{PC} = (0, 2, -2)$，$|\overrightarrow{PC}| = \sqrt{0 + 4 + 4} = 2\sqrt{2}$

$$\sin\theta = \frac{|\overrightarrow{PC} \cdot \vec{m}|}{|\overrightarrow{PC}| \cdot |\vec{m}|} = \frac{|0 \times 0 + 2 \times 1 + (-2) \times 0|}{2\sqrt{2} \times 1} = \frac{2}{2\sqrt{2}} = \frac{\sqrt{2}}{2}$$

$$\theta = \frac{\pi}{4}$$

**答案：**（1）证明见上；（2）点 $A$ 到平面 $PBC$ 的距离为 $\dfrac{2\sqrt{3}}{3}$；（3）直线 $PC$ 与平面 $PAB$ 所成角为 $\dfrac{\pi}{4}$

**⚠️ 易错提醒：** 第（1）问的关键是发现 $AB$ 同时垂直于 $PA$ 和 $AC$（由 $\angle BAC = 90°$ 和 $PA \perp$ 底面），从而 $AB \perp$ 平面 $PAC$。第（3）问求线面角用 $\sin\theta$（不是 $\cos\theta$），公式为 $\sin\theta = \dfrac{|\vec{v} \cdot \vec{n}|}{|\vec{v}||\vec{n}|}$。

**💡 解题思路总结：** 利用 $PA \perp$ 底面和 $\angle BAC = 90°$ 三个互相垂直的方向建立空间直角坐标系，将几何证明和度量计算统一转化为向量运算。
