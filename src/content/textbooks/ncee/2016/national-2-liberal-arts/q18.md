**题目：** $\triangle ABC$ 的内角 $A$，$B$，$C$ 的对边分别为 $a$，$b$，$c$，已知 $(2a - c)\cos B = b\cos C$。

（1）求角 $B$ 的大小；

（2）若 $b = \sqrt{3}$，求 $\triangle ABC$ 面积的最大值。

---

**解答：**

**（1）求角 $B$**

**第1步：** 利用正弦定理转化
> 📌 运用知识点：正弦定理

由正弦定理 $\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C}$，将边转化为角：

$$(2\sin A - \sin C)\cos B = \sin B \cos C$$

**第2步：** 展开整理

$$2\sin A \cos B - \sin C \cos B = \sin B \cos C$$

$$2\sin A \cos B = \sin B \cos C + \sin C \cos B$$

**第3步：** 利用和角公式
> 📌 运用知识点：三角恒等变换

右边 $= \sin(B + C) = \sin(\pi - A) = \sin A$

$$2\sin A \cos B = \sin A$$

因为 $\sin A \neq 0$（$A$ 为三角形内角），所以：

$$\cos B = \frac{1}{2} \implies B = \frac{\pi}{3}$$

**（2）求面积最大值**

**第4步：** 利用余弦定理建立关系
> 📌 运用知识点：余弦定理

$b^2 = a^2 + c^2 - 2ac\cos B$，代入 $b = \sqrt{3}$，$\cos B = \dfrac{1}{2}$：

$$3 = a^2 + c^2 - 2ac \cdot \frac{1}{2} = a^2 + c^2 - ac$$

**第5步：** 利用基本不等式
> 📌 运用知识点：基本不等式

由 $a^2 + c^2 \geqslant 2ac$，得：

$$3 = a^2 + c^2 - ac \geqslant 2ac - ac = ac$$

所以 $ac \leqslant 3$，等号在 $a = c$ 时成立。

**第6步：** 求面积最大值

$$S = \frac{1}{2}ac\sin B = \frac{1}{2}ac \cdot \frac{\sqrt{3}}{2} = \frac{\sqrt{3}}{4}ac \leqslant \frac{\sqrt{3}}{4} \times 3 = \frac{3\sqrt{3}}{4}$$

等号在 $a = c = \sqrt{3}$ 时成立（此时为等边三角形）。

**答案：**（1）$B = \dfrac{\pi}{3}$；（2）面积最大值为 $\dfrac{3\sqrt{3}}{4}$

**⚠️ 易错提醒：** 第（1）问中利用正弦定理将边转化为角后，注意 $\sin(B + C) = \sin A$（而非 $\cos A$），因为 $B + C = \pi - A$。第（2）问中使用基本不等式时，需验证等号成立的条件。

**💡 解题思路总结：** 边角混合等式优先用正弦定理统一为角的关系；求面积最值时，先用余弦定理建立约束，再用基本不等式求积的最大值。
