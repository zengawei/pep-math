**题目：** 已知 $\triangle ABC$ 中，$a = \sqrt{3}$，$b = 1$，$A = 2B$，则 $\cos B =$

A. $\dfrac{\sqrt{3}}{3}$

B. $\dfrac{\sqrt{3}}{2}$

C. $\dfrac{1}{2}$

D. $\dfrac{\sqrt{2}}{2}$

---

**解答：**

**第1步：** 利用正弦定理建立关系
> 📌 运用知识点：正弦定理

由正弦定理 $\dfrac{a}{\sin A} = \dfrac{b}{\sin B}$，代入已知条件：

$$\frac{\sqrt{3}}{\sin 2B} = \frac{1}{\sin B}$$

**第2步：** 利用二倍角公式化简
> 📌 运用知识点：二倍角公式

$\sin 2B = 2\sin B \cos B$，代入得：

$$\frac{\sqrt{3}}{2\sin B \cos B} = \frac{1}{\sin B}$$

因为 $\sin B \neq 0$，两边约去 $\sin B$：

$$\frac{\sqrt{3}}{2\cos B} = 1 \implies \cos B = \frac{\sqrt{3}}{2}$$

**第3步：** 验证

$\cos B = \dfrac{\sqrt{3}}{2} \implies B = \dfrac{\pi}{6}$，则 $A = 2B = \dfrac{\pi}{3}$，$C = \pi - A - B = \dfrac{\pi}{2}$

验证：$a = \sqrt{3}$，$b = 1$，$c = 2$（直角三角形斜边），满足 $a^2 + b^2 = 3 + 1 = 4 = c^2$ ✓

**答案：B**

**⚠️ 易错提醒：** 利用正弦定理将边的关系转化为角的关系时，注意 $\sin 2B = 2\sin B\cos B$ 的展开，不要遗漏系数 $2$。

**💡 解题思路总结：** 已知边角关系 $A = 2B$ 时，利用正弦定理将边比转化为角的关系，再用二倍角公式求解。
