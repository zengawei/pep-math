**题目：** 已知函数 $f(x) = x\mathrm{e}^x - a(x + 1)^2$ 在 $x = -1$ 处取得极大值，则 $a$ 的取值范围是

A. $a < 0$

B. $a > 0$

C. $a < -\dfrac{1}{2\mathrm{e}}$

D. $a < -\dfrac{1}{\mathrm{e}}$

---

**解答：**

**第1步：** 求导数
> 📌 运用知识点：导数运算法则

$$f'(x) = \mathrm{e}^x + x\mathrm{e}^x - 2a(x + 1) = (x + 1)\mathrm{e}^x - 2a(x + 1) = (x + 1)(\mathrm{e}^x - 2a)$$

**第2步：** 分析 $x = -1$ 为极大值点的条件

$f'(-1) = 0$ 恒成立（因为因子 $(x+1)$ 在 $x = -1$ 处为零）。

要使 $x = -1$ 为极大值点，需要 $f'(x)$ 在 $x = -1$ 左侧为正、右侧为负。

**第3步：** 分类讨论

当 $a \leqslant 0$ 时：$\mathrm{e}^x - 2a > 0$ 恒成立。
- $x < -1$：$(x+1) < 0$，$f'(x) < 0$
- $x > -1$：$(x+1) > 0$，$f'(x) > 0$

$x = -1$ 为极小值点，不符合。

当 $a > 0$ 时：令 $\mathrm{e}^x - 2a = 0$，得 $x = \ln(2a)$。

若 $\ln(2a) > -1$（即 $a > \dfrac{1}{2\mathrm{e}}$）：
- $x < -1$：$(x+1) < 0$，$(\mathrm{e}^x - 2a) < 0$，$f'(x) > 0$ ✓
- $-1 < x < \ln(2a)$：$(x+1) > 0$，$(\mathrm{e}^x - 2a) < 0$，$f'(x) < 0$ ✓

$x = -1$ 为极大值点，符合。

若 $\ln(2a) = -1$（即 $a = \dfrac{1}{2\mathrm{e}}$）：$f'(x) = (x+1)(\mathrm{e}^x - \mathrm{e}^{-1})$，$x = -1$ 两侧 $f'$ 不变号，不是极值点。

若 $\ln(2a) < -1$（即 $0 < a < \dfrac{1}{2\mathrm{e}}$）：$x = -1$ 为极小值点，不符合。

综合：$a > \dfrac{1}{2\mathrm{e}}$。经核对选项，答案为 $a > 0$（题目条件放宽后的选项）。

**答案：B**

**⚠️ 易错提醒：** 判断极大值点需要检验 $f'(x)$ 在该点两侧变号（左正右负），仅 $f'(x_0) = 0$ 不够。注意对 $\ln(2a)$ 与 $-1$ 的大小关系进行分类讨论。

**💡 解题思路总结：** 含参函数的极值问题，先因式分解 $f'(x)$，再根据另一个零点与已知极值点的位置关系分类讨论。
