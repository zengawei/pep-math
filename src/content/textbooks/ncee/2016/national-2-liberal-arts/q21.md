**题目：** 已知椭圆 $C$：$\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$）的离心率为 $\dfrac{\sqrt{3}}{2}$，焦距为 $2\sqrt{3}$。

（1）求椭圆 $C$ 的方程；

（2）设直线 $l$ 过右焦点 $F_2$ 与椭圆 $C$ 交于 $A$，$B$ 两点，$O$ 为原点，求 $\triangle AOB$ 面积的最大值。

---

**解答：**

**（1）求椭圆方程**

**第1步：** 求 $c$
> 📌 运用知识点：椭圆的基本参数

$$2c = 2\sqrt{3} \implies c = \sqrt{3}$$

**第2步：** 求 $a$
> 📌 运用知识点：离心率公式

$$e = \frac{c}{a} = \frac{\sqrt{3}}{2} \implies a = \frac{\sqrt{3}}{\dfrac{\sqrt{3}}{2}} = 2$$

**第3步：** 求 $b^2$

$$b^2 = a^2 - c^2 = 4 - 3 = 1$$

$$\boxed{\frac{x^2}{4} + y^2 = 1}$$

**（2）求 $\triangle AOB$ 面积的最大值**

**第4步：** 讨论直线斜率不存在的情况

右焦点 $F_2(\sqrt{3}, 0)$。当 $l$：$x = \sqrt{3}$ 时：

$$\frac{3}{4} + y^2 = 1 \implies y = \pm\frac{1}{2}$$

$$S = \frac{1}{2} \times 1 \times \sqrt{3} = \frac{\sqrt{3}}{2}$$

**第5步：** 设 $l$：$y = k(x - \sqrt{3})$，联立椭圆方程
> 📌 运用知识点：直线与椭圆的位置关系

$$\frac{x^2}{4} + k^2(x - \sqrt{3})^2 = 1$$

$$(1 + 4k^2)x^2 - 8\sqrt{3}k^2 x + 12k^2 - 4 = 0$$

判别式 $\Delta = 192k^4 - 4(1 + 4k^2)(12k^2 - 4) = 16(1 + k^2) > 0$ ✓

由韦达定理：

$$x_1 + x_2 = \frac{8\sqrt{3}k^2}{1 + 4k^2}, \quad x_1 x_2 = \frac{12k^2 - 4}{1 + 4k^2}$$

**第6步：** 计算弦长 $|AB|$

$$(x_1 - x_2)^2 = \frac{\Delta}{(1 + 4k^2)^2} = \frac{16(1 + k^2)}{(1 + 4k^2)^2}$$

$$|AB|^2 = (1 + k^2)(x_1 - x_2)^2 = \frac{16(1 + k^2)^2}{(1 + 4k^2)^2}$$

**第7步：** 计算面积

原点 $O$ 到直线 $kx - y - \sqrt{3}k = 0$ 的距离：

$$d = \frac{\sqrt{3}|k|}{\sqrt{1 + k^2}}$$

$$S = \frac{1}{2}|AB| \cdot d = \frac{1}{2} \cdot \frac{4(1 + k^2)}{1 + 4k^2} \cdot \frac{\sqrt{3}|k|}{\sqrt{1 + k^2}} = \frac{2\sqrt{3}|k|\sqrt{1 + k^2}}{1 + 4k^2}$$

**第8步：** 求最大值
> 📌 运用知识点：函数最值

$$S^2 = \frac{12k^2(1 + k^2)}{(1 + 4k^2)^2}$$

令 $t = k^2$（$t \geqslant 0$），$f(t) = \dfrac{12t(1 + t)}{(1 + 4t)^2}$：

$$f'(t) = 12 \cdot \frac{(1 + 2t)(1 + 4t) - 8t(1 + t)}{(1 + 4t)^3} = 12 \cdot \frac{1 - 2t}{(1 + 4t)^3}$$

$f'(t) = 0 \implies t = \dfrac{1}{2}$

$f'(t) > 0$（$t < \frac{1}{2}$），$f'(t) < 0$（$t > \frac{1}{2}$），$t = \dfrac{1}{2}$ 为极大值点。

$$f\!\left(\frac{1}{2}\right) = \frac{12 \times \dfrac{1}{2} \times \dfrac{3}{2}}{3^2} = \frac{9}{9} = 1$$

$S_{\max}^2 = 1 \implies S_{\max} = 1$

比较：$1 > \dfrac{\sqrt{3}}{2}$，故面积最大值为 $1$。

**答案：**（1）$\dfrac{x^2}{4} + y^2 = 1$；（2）$\triangle AOB$ 面积的最大值为 $1$

**⚠️ 易错提醒：** 需讨论直线斜率不存在的情况。计算弦长时 $|AB| = \sqrt{1 + k^2}\,|x_1 - x_2|$。求最值时注意 $f'(t)$ 的符号变化以确认极大值。

**💡 解题思路总结：** 联立直线与椭圆方程 → 韦达定理表示弦长 → 距离公式表示面积 → 换元求导求最值。这是解析几何面积最值问题的标准流程。
