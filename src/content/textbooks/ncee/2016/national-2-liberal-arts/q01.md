**题目：** 已知集合 $A = \{1, 2, 3\}$，$B = \{x \mid x^2 < 9\}$，则 $A \cap B =$

A. $\{1, 2, 3\}$

B. $\{1, 2\}$

C. $\{3\}$

D. $\{-2, -1, 0, 1, 2, 3\}$

---

**解答：**

**第1步：** 求集合 $B$
> 📌 运用知识点：一元二次不等式的解法

$x^2 < 9 \implies -3 < x < 3$

所以 $B = \{x \mid -3 < x < 3\} = (-3, 3)$

**第2步：** 求 $A \cap B$

$A = \{1, 2, 3\}$，$B = (-3, 3)$

检查 $A$ 中各元素是否属于 $B$：
- $1 \in (-3, 3)$ ✓
- $2 \in (-3, 3)$ ✓
- $3 \notin (-3, 3)$（因为 $3$ 不满足 $x < 3$）

$A \cap B = \{1, 2\}$

**答案：B**

**⚠️ 易错提醒：** $x^2 < 9$ 的解是 $-3 < x < 3$（开区间），$x = 3$ 不满足严格不等式，因此 $3 \notin B$。

**💡 解题思路总结：** 先解不等式求出集合 $B$，再逐一检验集合 $A$ 中的元素是否属于 $B$，取公共部分。
