**题目：** 已知函数 $f(x) = \sin(2x + \varphi)$（$|\varphi| < \dfrac{\pi}{2}$）的图象关于直线 $x = \dfrac{\pi}{6}$ 对称，则 $\varphi =$

A. $-\dfrac{\pi}{6}$

B. $-\dfrac{\pi}{3}$

C. $\dfrac{\pi}{6}$

D. $\dfrac{\pi}{3}$

---

**解答：**

**第1步：** 利用对称轴条件
> 📌 运用知识点：三角函数的图象

正弦函数 $y = \sin t$ 的对称轴在 $t = \dfrac{\pi}{2} + k\pi$（$k \in \mathbb{Z}$）处。

因此 $x = \dfrac{\pi}{6}$ 是对称轴，意味着：

$$2 \times \frac{\pi}{6} + \varphi = \frac{\pi}{2} + k\pi$$

**第2步：** 求解 $\varphi$
> 📌 运用知识点：三角函数的图象

$$\frac{\pi}{3} + \varphi = \frac{\pi}{2} + k\pi$$

$$\varphi = \frac{\pi}{6} + k\pi$$

因为 $|\varphi| < \dfrac{\pi}{2}$，取 $k = 0$，得 $\varphi = \dfrac{\pi}{6}$。

**答案：C**

**⚠️ 易错提醒：** 正弦函数的对称轴对应的是函数取最值的点（即 $\sin t = \pm 1$），不是零点对。不要将对称轴和对称中心混淆。

**💡 解题思路总结：** $y = A\sin(\omega x + \varphi)$ 的对称轴满足 $\omega x + \varphi = \dfrac{\pi}{2} + k\pi$，对称中心满足 $\omega x + \varphi = k\pi$。
