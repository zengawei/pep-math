**题目：** 已知 $F_1, F_2$ 是椭圆 $\dfrac{x^2}{25} + \dfrac{y^2}{9} = 1$ 的两个焦点，$P$ 为椭圆上一点，则 $|PF_1| \cdot |PF_2|$ 的最大值为

A. $9$

B. $16$

C. $25$

D. $50$

---

**解答：**

**第1步：** 确定椭圆基本参数
> 📌 运用知识点：椭圆的定义

$a^2 = 25$，$b^2 = 9$，$a = 5$。由椭圆定义：$|PF_1| + |PF_2| = 2a = 10$。

**第2步：** 利用均值不等式
> 📌 运用知识点：基本不等式

设 $|PF_1| = m$，$|PF_2| = n$，则 $m + n = 10$，$m, n > 0$。

由均值不等式：

$$mn \leqslant \left(\frac{m + n}{2}\right)^2 = 25$$

等号成立条件：$m = n = 5$，即 $P$ 在短轴端点时取等。

**答案：C**

**⚠️ 易错提醒：** 需要验证等号能否取到。当 $P$ 在短轴端点时，$|PF_1| = |PF_2| = a = 5$，满足条件。

**💡 解题思路总结：** 椭圆上点到两焦点的距离之和为定值 $2a$，求积的最值用均值不等式。这是椭圆中的经典题型。
