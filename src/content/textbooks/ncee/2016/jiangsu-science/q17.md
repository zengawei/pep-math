**题目：** 已知函数 $f(x) = 2\sin x \cos x + 2\sqrt{3}\cos^2 x - \sqrt{3}$。

（1）求 $f(x)$ 的最小正周期；

（2）在 $\triangle ABC$ 中，$a, b, c$ 分别是角 $A, B, C$ 的对边，若 $f(A) = \sqrt{3}$，$a = \sqrt{3}$，$b = \sqrt{3}$，求 $\triangle ABC$ 的面积。

---

**解答：**

**第1步：** 化简函数
> 📌 运用知识点：三角恒等变换

$$f(x) = \sin 2x + 2\sqrt{3} \cdot \frac{1 + \cos 2x}{2} - \sqrt{3} = \sin 2x + \sqrt{3}\cos 2x$$

$$f(x) = 2\sin\left(2x + \frac{\pi}{3}\right)$$

**第2步：** 求周期
> 📌 运用知识点：三角函数的周期

$$T = \frac{2\pi}{2} = \pi$$

**第3步：** 由 $f(A) = \sqrt{3}$ 求角 $A$
> 📌 运用知识点：三角函数的求值

$$2\sin\left(2A + \frac{\pi}{3}\right) = \sqrt{3} \implies \sin\left(2A + \frac{\pi}{3}\right) = \frac{\sqrt{3}}{2}$$

因为 $A \in (0, \pi)$，所以 $2A + \dfrac{\pi}{3} \in \left(\dfrac{\pi}{3}, \dfrac{7\pi}{3}\right)$。

$$2A + \frac{\pi}{3} = \frac{2\pi}{3} \implies A = \frac{\pi}{6}$$

**第4步：** 求面积
> 📌 运用知识点：正弦定理、三角形面积公式

由正弦定理：$\dfrac{a}{\sin A} = \dfrac{b}{\sin B}$

$$\frac{\sqrt{3}}{\sin\frac{\pi}{6}} = \frac{\sqrt{3}}{\sin B} \implies \sin B = \frac{1}{2}$$

$B = \dfrac{\pi}{6}$ 或 $B = \dfrac{5\pi}{6}$。

若 $B = \dfrac{5\pi}{6}$，则 $A + B = \pi$，$C = 0$，不合题意。

所以 $B = \dfrac{\pi}{6}$，$C = \pi - \dfrac{\pi}{6} - \dfrac{\pi}{6} = \dfrac{2\pi}{3}$。

$$S = \frac{1}{2} ab \sin C = \frac{1}{2} \times \sqrt{3} \times \sqrt{3} \times \sin\frac{2\pi}{3} = \frac{3}{2} \times \frac{\sqrt{3}}{2} = \frac{3\sqrt{3}}{4}$$

$$\boxed{S_{\triangle ABC} = \dfrac{3\sqrt{3}}{4}}$$

**⚠️ 易错提醒：** 化简 $f(x)$ 时要用二倍角公式 $\sin 2x = 2\sin x\cos x$ 和降幂公式 $\cos^2 x = \dfrac{1+\cos 2x}{2}$。求 $B$ 时要排除不合题意的解。

**💡 解题思路总结：** 三角函数综合题的标准流程：辅助角公式化简 → 由条件求角 → 正弦/余弦定理求边 → 面积公式。
