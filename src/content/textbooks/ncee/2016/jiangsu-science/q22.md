**题目：** 已知数列 $\{a_n\}$ 满足 $a_1 = 1$，$a_{n+1} = \dfrac{a_n}{1 + a_n}$（$n \in \mathbb{N}^*$）。

（1）求 $a_n$ 的通项公式；

（2）证明：对任意 $n \in \mathbb{N}^*$，$a_1^2 + a_2^2 + \cdots + a_n^2 < 2$。

---

**解答：**

**第1步：** 求通项公式
> 📌 运用知识点：数列的递推公式

对递推式两边取倒数：

$$\frac{1}{a_{n+1}} = \frac{1 + a_n}{a_n} = \frac{1}{a_n} + 1$$

所以 $\left\{\dfrac{1}{a_n}\right\}$ 是等差数列，公差为 $1$，首项 $\dfrac{1}{a_1} = 1$。

$$\frac{1}{a_n} = n \implies \boxed{a_n = \frac{1}{n}}$$

**第2步：** 证明不等式
> 📌 运用知识点：放缩法

$$a_1^2 + a_2^2 + \cdots + a_n^2 = 1 + \frac{1}{4} + \frac{1}{9} + \cdots + \frac{1}{n^2}$$

对 $k \geqslant 2$，利用放缩：

$$\frac{1}{k^2} < \frac{1}{k(k-1)} = \frac{1}{k-1} - \frac{1}{k}$$

因此：

$$\sum_{k=1}^{n} \frac{1}{k^2} = 1 + \sum_{k=2}^{n} \frac{1}{k^2} < 1 + \sum_{k=2}^{n} \left(\frac{1}{k-1} - \frac{1}{k}\right)$$

$$= 1 + \left(1 - \frac{1}{2}\right) + \left(\frac{1}{2} - \frac{1}{3}\right) + \cdots + \left(\frac{1}{n-1} - \frac{1}{n}\right) = 1 + 1 - \frac{1}{n} = 2 - \frac{1}{n} < 2$$

$$\boxed{a_1^2 + a_2^2 + \cdots + a_n^2 < 2}$$

**⚠️ 易错提醒：** 取倒数是处理 $a_{n+1} = \dfrac{a_n}{1 + a_n}$ 型递推的关键技巧。放缩时 $\dfrac{1}{k^2} < \dfrac{1}{k(k-1)}$ 只对 $k \geqslant 2$ 成立，第一项 $1$ 要单独保留。

**💡 解题思路总结：** 递推数列求通项：取倒数转化为等差数列。证明不等式：裂项放缩法是处理 $\sum \dfrac{1}{k^2}$ 的经典方法。
