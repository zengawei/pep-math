**题目：** 已知函数 $f(x) = x^3 - 3x^2 + 2$ 在区间 $[-1, 3]$ 上的最大值与最小值分别为 $M$ 和 $m$，则 $M + m =$

A. $0$

B. $2$

C. $4$

D. $-2$

---

**解答：**

**第1步：** 求导数并找临界点
> 📌 运用知识点：导数的运算

$$f'(x) = 3x^2 - 6x = 3x(x - 2)$$

令 $f'(x) = 0$，得 $x = 0$ 或 $x = 2$，均在 $[-1, 3]$ 内。

**第2步：** 比较各关键点的函数值
> 📌 运用知识点：导数与函数的最值

$$f(-1) = -1 - 3 + 2 = -2$$
$$f(0) = 0 - 0 + 2 = 2$$
$$f(2) = 8 - 12 + 2 = -2$$
$$f(3) = 27 - 27 + 2 = 2$$

**第3步：** 确定最大值和最小值
> 📌 运用知识点：导数与函数的最值

$M = 2$（在 $x = 0$ 和 $x = 3$ 处取到），$m = -2$（在 $x = -1$ 和 $x = 2$ 处取到）。

$$M + m = 2 + (-2) = 0$$

**答案：A**

**⚠️ 易错提醒：** 闭区间上的最值需要比较所有临界点和端点的函数值，不能只看临界点。本题中 $f(-1) = f(2) = -2$，$f(0) = f(3) = 2$，呈现对称性。

**💡 解题思路总结：** 闭区间上连续函数的最值 = 比较临界点值和端点值。注意 $f(x) = x^3 - 3x^2 + 2$ 关于点 $(1, 0)$ 中心对称，因此 $M + m = 0$。
