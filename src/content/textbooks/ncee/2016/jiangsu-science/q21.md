**题目：** 已知椭圆 $C: \dfrac{x^2}{4} + y^2 = 1$，过点 $M(1, 0)$ 的直线 $l$ 与椭圆 $C$ 交于 $A, B$ 两点。

（1）若 $\vec{OA} \cdot \vec{OB} = 0$（$O$ 为原点），求直线 $l$ 的方程；

（2）设点 $N(4, 0)$，求证：$\angle ANM = \angle BNM$。

---

**解答：**

**第1步：** 设直线方程并联立
> 📌 运用知识点：直线与椭圆的位置关系

设 $l: y = k(x - 1)$，代入 $\dfrac{x^2}{4} + y^2 = 1$：

$$x^2 + 4k^2(x - 1)^2 = 4$$

$$(1 + 4k^2)x^2 - 8k^2 x + 4k^2 - 4 = 0$$

$$x_1 + x_2 = \frac{8k^2}{1 + 4k^2}, \quad x_1 x_2 = \frac{4k^2 - 4}{1 + 4k^2}$$

**第2步：** 由 $\vec{OA} \cdot \vec{OB} = 0$ 求 $k$
> 📌 运用知识点：向量的数量积

$$\vec{OA} \cdot \vec{OB} = x_1 x_2 + y_1 y_2 = 0$$

$$y_1 y_2 = k^2(x_1 - 1)(x_2 - 1) = k^2\left(x_1 x_2 - (x_1 + x_2) + 1\right) = k^2 \cdot \frac{-3}{1 + 4k^2} = \frac{-3k^2}{1 + 4k^2}$$

$$x_1 x_2 + y_1 y_2 = \frac{4k^2 - 4 - 3k^2}{1 + 4k^2} = \frac{k^2 - 4}{1 + 4k^2} = 0$$

解得 $k^2 = 4$，$k = \pm 2$。

$$\boxed{l: y = 2(x - 1) \text{ 或 } y = -2(x - 1)}$$

**第3步：** 证明 $\angle ANM = \angle BNM$
> 📌 运用知识点：直线与椭圆的位置关系

需证 $NA$ 与 $NB$ 关于 $x$ 轴对称，即 $k_{NA} + k_{NB} = 0$。

$$k_{NA} + k_{NB} = \frac{y_1}{x_1 - 4} + \frac{y_2}{x_2 - 4} = \frac{y_1(x_2 - 4) + y_2(x_1 - 4)}{(x_1 - 4)(x_2 - 4)}$$

分子：

$$k(x_1 - 1)(x_2 - 4) + k(x_2 - 1)(x_1 - 4) = k[2x_1 x_2 - 5(x_1 + x_2) + 8]$$

$$= k\left[\frac{2(4k^2 - 4)}{1 + 4k^2} - \frac{40k^2}{1 + 4k^2} + \frac{8(1 + 4k^2)}{1 + 4k^2}\right] = k \cdot \frac{8k^2 - 8 - 40k^2 + 8 + 32k^2}{1 + 4k^2} = 0$$

所以 $k_{NA} + k_{NB} = 0$，即 $\angle ANM = \angle BNM$。$\blacksquare$

**⚠️ 易错提醒：** 第（1）问需要验证判别式 $\Delta > 0$。第（2）问的关键是将角度相等转化为斜率之和为零。

**💡 解题思路总结：** 解析几何证明题的核心是"翻译"——将几何条件翻译为代数表达式。$\angle ANM = \angle BNM$ 等价于两直线关于 $x$ 轴对称，即斜率互为相反数。
