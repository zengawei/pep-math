**题目：**

已知等差数列 $\{a_n\}$ 中，$S_3 = 9$，$a_4 = 5$。

（1）求数列 $\{a_n\}$ 的通项公式；

（2）求数列 $\{a_n\}$ 的前 $8$ 项和 $S_8$。

---

**解答：**

**（1）**

**第1步：** 利用前 $n$ 项和公式
> 📌 运用知识点：等差数列的前n项和

$$S_3 = \frac{3(a_1 + a_3)}{2} = 3a_2 = 9$$

所以 $a_2 = 3$。

**第2步：** 求公差
> 📌 运用知识点：等差数列的通项公式

$$a_4 = a_2 + 2d \implies 5 = 3 + 2d \implies d = 1$$

**第3步：** 求首项和通项公式

$$a_1 = a_2 - d = 3 - 1 = 2$$

$$a_n = a_1 + (n-1)d = 2 + (n-1) \times 1 = n + 1$$

**（2）**

**第4步：** 求前 $8$ 项和
> 📌 运用知识点：等差数列的前n项和

$$S_8 = \frac{8(a_1 + a_8)}{2} = \frac{8(2 + 9)}{2} = 4 \times 11 = 44$$

**⚠️ 易错提醒：** $S_3 = 3a_2$ 是等差数列的重要性质（奇数项和等于项数乘以中间项），注意利用此性质简化计算。求公差时注意 $a_4 - a_2 = 2d$（不是 $d$）。

**💡 解题思路总结：** 等差数列问题中，利用 $S_n$ 的对称性可以快速求出中间项，再结合通项公式求公差和首项。求前 $n$ 项和时直接用公式 $S_n = \dfrac{n(a_1 + a_n)}{2}$。
