**题目：** 已知集合 $A = \{1, 2, 3, 4\}$，$B = \{x \mid x = 2n,\ n \in A\}$，则 $A \cap B =$

A. $\{2, 4\}$

B. $\{2\}$

C. $\{1, 2, 3, 4\}$

D. $\{1, 4\}$

---

**解答：**

**第1步：** 确定集合 $B$ 的元素
> 📌 运用知识点：集合的表示

将 $A = \{1, 2, 3, 4\}$ 中的元素逐一代入 $x = 2n$：

- $n = 1$ 时，$x = 2$
- $n = 2$ 时，$x = 4$
- $n = 3$ 时，$x = 6$
- $n = 4$ 时，$x = 8$

所以 $B = \{2, 4, 6, 8\}$。

**第2步：** 求 $A \cap B$
> 📌 运用知识点：集合的交集运算

$A = \{1, 2, 3, 4\}$，$B = \{2, 4, 6, 8\}$

$A \cap B$ 取两个集合的公共元素：

$$A \cap B = \{2, 4\}$$

**答案：A**
