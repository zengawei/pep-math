**题目：** 执行下面的程序框图，如果输入的 $t = 3$，则输出的 $S =$

（程序框图描述：初始化 $S = 0$，$n = 1$。循环体：$S = S + \dfrac{1}{n(n+1)}$，$n = n + 1$。判断条件 $n > t$，若成立则输出 $S$ 并结束，否则继续循环。）

A. $\dfrac{1}{2}$

B. $\dfrac{2}{3}$

C. $\dfrac{3}{4}$

D. $\dfrac{4}{5}$

---

**解答：**

**第1步：** 逐步执行程序
> 📌 运用知识点：程序框图的循环结构

初始值：$S = 0$，$n = 1$，$t = 3$。

**第1次循环：** $n = 1 \leqslant 3$，执行循环体：
$$S = 0 + \frac{1}{1 \times 2} = \frac{1}{2},\quad n = 2$$

**第2次循环：** $n = 2 \leqslant 3$，执行循环体：
$$S = \frac{1}{2} + \frac{1}{2 \times 3} = \frac{1}{2} + \frac{1}{6} = \frac{2}{3},\quad n = 3$$

**第3次循环：** $n = 3 \leqslant 3$，执行循环体：
$$S = \frac{2}{3} + \frac{1}{3 \times 4} = \frac{2}{3} + \frac{1}{12} = \frac{3}{4},\quad n = 4$$

**第4步：** 判断退出

$n = 4 > 3 = t$，退出循环，输出 $S = \dfrac{3}{4}$。

**答案：C**
