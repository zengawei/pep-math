**题目：** 三棱锥 $P$-$ABC$ 中，$PA \perp$ 底面 $ABC$，$AB \perp AC$，$PA = AB = 2$，$AC = 1$。则该三棱锥的外接球的表面积为 \_\_\_\_\_\_。

---

**解答：**

**第1步：** 建立坐标系
> 📌 运用知识点：空间直角坐标系

以 $A$ 为原点，$\overrightarrow{AB}$ 方向为 $x$ 轴，$\overrightarrow{AC}$ 方向为 $y$ 轴，$\overrightarrow{AP}$ 方向为 $z$ 轴。

各顶点坐标：$A(0,0,0)$，$B(2,0,0)$，$C(0,1,0)$，$P(0,0,2)$。

**第2步：** 求外接球球心
> 📌 运用知识点：球的方程

设球心 $O(x_0, y_0, z_0)$，由 $|OA|^2 = |OB|^2 = |OC|^2 = |OP|^2$：

- $|OA|^2 = |OB|^2$：$x_0^2 + y_0^2 + z_0^2 = (x_0-2)^2 + y_0^2 + z_0^2$，得 $x_0 = 1$。
- $|OA|^2 = |OC|^2$：$x_0^2 + y_0^2 + z_0^2 = x_0^2 + (y_0-1)^2 + z_0^2$，得 $y_0 = \dfrac{1}{2}$。
- $|OA|^2 = |OP|^2$：$x_0^2 + y_0^2 + z_0^2 = x_0^2 + y_0^2 + (z_0-2)^2$，得 $z_0 = 1$。

球心 $O\!\left(1, \dfrac{1}{2}, 1\right)$。

**第3步：** 计算半径和表面积

$$R^2 = 1^2 + \left(\frac{1}{2}\right)^2 + 1^2 = 1 + \frac{1}{4} + 1 = \frac{9}{4}$$

$$S = 4\pi R^2 = 4\pi \times \frac{9}{4} = 9\pi$$

**答案：** $\boxed{9\pi}$
