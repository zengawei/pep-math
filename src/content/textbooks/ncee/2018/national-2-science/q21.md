**题目：** 已知抛物线 $C$：$y^2 = 4x$ 的焦点为 $F$，过 $F$ 的直线 $l$ 交 $C$ 于 $A$，$B$ 两点，且 $|AF| = 4|BF|$。

（1）求直线 $l$ 的斜率；

（2）求 $|AB|$。

---

**解答：**

**第1步：** 确定焦点坐标
> 📌 运用知识点：抛物线的定义与性质

抛物线 $y^2 = 4x$ 中 $2p = 4$，$p = 2$，焦点 $F(1, 0)$。

**第2步：** 设点并利用焦半径
> 📌 运用知识点：抛物线的性质

设 $B(t^2, 2t)$（$t > 0$），则 $|BF| = t^2 + 1$。

由 $|AF| = 4|BF|$，$|AF| = 4(t^2 + 1)$。

因为 $A$、$B$ 在焦点两侧（$A$ 在 $x$ 轴下方），设 $A = \left(\dfrac{1}{t^2}, -\dfrac{2}{t}\right)$。

（由焦点弦性质 $x_1 x_2 = \dfrac{p^2}{4} = 1$，$y_1 y_2 = -p^2 = -4$。）

$$|AF| = \frac{1}{t^2} + 1 = \frac{1 + t^2}{t^2}$$

**第3步：** 由 $|AF| = 4|BF|$ 求 $t$

$$\frac{1 + t^2}{t^2} = 4(t^2 + 1)$$

$$\frac{1}{t^2} = 4 \implies t^2 = \frac{1}{4} \implies t = \frac{1}{2}$$

**第4步：** 求各点坐标和斜率
> 📌 运用知识点：直线方程

$$B = \left(\frac{1}{4}, 1\right), \quad A = (4, -4)$$

$$k = \frac{-4 - 1}{4 - \frac{1}{4}} = \frac{-5}{\frac{15}{4}} = -\frac{4}{3}$$

由对称性，斜率也可为 $\dfrac{4}{3}$。

**第5步：** 求 $|AB|$

$$|AB| = |AF| + |BF| = \left(4 + 1\right) + \left(\frac{1}{4} + 1\right) = 5 + \frac{5}{4} = \frac{25}{4}$$

验证：$|AB| = \sqrt{\left(4 - \frac{1}{4}\right)^2 + (-4-1)^2} = \sqrt{\frac{225}{16} + 25} = \sqrt{\frac{625}{16}} = \frac{25}{4}$ ✓

**⚠️ 易错提醒：** 利用焦点弦性质 $x_1 x_2 = \dfrac{p^2}{4}$ 和 $y_1 y_2 = -p^2$ 可以简化计算。注意斜率有正负两个值。

**💡 解题思路总结：** 利用抛物线焦半径公式和焦点弦性质，将 $|AF| = 4|BF|$ 转化为关于参数的方程，求出各点坐标后计算斜率和距离。

**答案：（1）$k = \pm\dfrac{4}{3}$；（2）$|AB| = \dfrac{25}{4}$**
