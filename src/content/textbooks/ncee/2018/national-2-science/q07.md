**题目：** 在 $\triangle ABC$ 中，$(2a - c)\cos B = b\cos C$，则 $B =$

A. $\dfrac{\pi}{6}$

B. $\dfrac{\pi}{3}$

C. $\dfrac{2\pi}{3}$

D. $\dfrac{5\pi}{6}$

---

**解答：**

**第1步：** 利用正弦定理转化
> 📌 运用知识点：正弦定理

由正弦定理 $a = 2R\sin A$，$b = 2R\sin B$，$c = 2R\sin C$，代入原式：

$$(2\sin A - \sin C)\cos B = \sin B \cos C$$

**第2步：** 化简求解
> 📌 运用知识点：三角恒等变换

展开整理：

$$2\sin A \cos B = \sin B \cos C + \sin C \cos B = \sin(B + C)$$

因为 $A + B + C = \pi$，所以 $\sin(B + C) = \sin A$。

$$2\sin A \cos B = \sin A$$

因为 $\sin A \neq 0$，所以 $\cos B = \dfrac{1}{2}$，即 $B = \dfrac{\pi}{3}$。

**答案：B**
