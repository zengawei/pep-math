**题目：** 在等比数列 $\{a_n\}$ 中，$a_1 + a_2 + a_3 = 26$，$a_1 a_2 a_3 = 216$。

（1）求数列 $\{a_n\}$ 的通项公式；

（2）设 $b_n = \log_3 a_n$，求数列 $\{b_n\}$ 的前 $n$ 项和 $T_n$。

---

**解答：**

**第1步：** 利用等比数列性质求 $a_2$
> 📌 运用知识点：等比数列

由等比数列性质 $a_1 a_3 = a_2^2$，代入 $a_1 a_2 a_3 = 216$：

$$a_2^3 = 216 \implies a_2 = 6$$

**第2步：** 求公比 $q$
> 📌 运用知识点：等比数列

设公比为 $q$，则 $a_1 = \dfrac{6}{q}$，$a_3 = 6q$。

代入 $a_1 + a_2 + a_3 = 26$：

$$\frac{6}{q} + 6 + 6q = 26 \implies \frac{6}{q} + 6q = 20$$

$$6q^2 - 20q + 6 = 0 \implies 3q^2 - 10q + 3 = 0$$

$$(3q - 1)(q - 3) = 0 \implies q = 3 \text{ 或 } q = \frac{1}{3}$$

**第3步：** 写出通项公式
> 📌 运用知识点：等比数列

当 $q = 3$ 时，$a_1 = 2$，$a_n = 2 \cdot 3^{n-1}$；

当 $q = \dfrac{1}{3}$ 时，$a_1 = 18$，$a_n = 18 \cdot \left(\dfrac{1}{3}\right)^{n-1}$。

**第4步：** 求 $T_n$（以 $q = 3$ 为例）
> 📌 运用知识点：等差数列求和

$$b_n = \log_3 a_n = \log_3(2 \cdot 3^{n-1}) = \log_3 2 + (n-1)$$

$\{b_n\}$ 是首项为 $\log_3 2$，公差为 $1$ 的等差数列。

$$T_n = n\log_3 2 + \frac{n(n-1)}{2}$$

（当 $q = \dfrac{1}{3}$ 时，$b_n = \log_3 18 - (n-1) = 2 + \log_3 2 - (n-1) = 3 + \log_3 2 - n$，$T_n = n(3 + \log_3 2) - \dfrac{n(n+1)}{2}$。）

**⚠️ 易错提醒：** 等比数列中 $a_1 a_3 = a_2^2$ 是常用性质，注意不要遗漏 $q = \dfrac{1}{3}$ 的情况。

**💡 解题思路总结：** 利用等比数列的积的性质 $a_1 a_3 = a_2^2$ 快速求出 $a_2$，再转化为关于 $q$ 的方程求解。第二问将对数运算与等差数列求和结合。

**答案：（1）$a_n = 2 \cdot 3^{n-1}$ 或 $a_n = 18 \cdot \left(\dfrac{1}{3}\right)^{n-1}$；（2）$T_n = n\log_3 2 + \dfrac{n(n-1)}{2}$（对应 $q=3$ 的情况）**
