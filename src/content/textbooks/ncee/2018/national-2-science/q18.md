**题目：** 在 $\triangle ABC$ 中，$(2a - c)\cos B = b\cos C$。

（1）求角 $B$ 的大小；

（2）若 $b = \sqrt{7}$，$a + c = 4$，求 $\triangle ABC$ 的面积。

---

**解答：**

**第1步：** 利用正弦定理转化
> 📌 运用知识点：正弦定理

由正弦定理，$a = 2R\sin A$，$b = 2R\sin B$，$c = 2R\sin C$，代入原式：

$$(2\sin A - \sin C)\cos B = \sin B \cos C$$

**第2步：** 化简求解角 $B$
> 📌 运用知识点：三角恒等变换

展开整理：

$$2\sin A \cos B = \sin C \cos B + \sin B \cos C = \sin(B + C)$$

因为 $A + B + C = \pi$，所以 $\sin(B + C) = \sin(\pi - A) = \sin A$。

$$2\sin A \cos B = \sin A$$

因为 $\sin A \neq 0$，所以 $\cos B = \dfrac{1}{2}$，即 $B = \dfrac{\pi}{3}$。

**第3步：** 利用余弦定理求 $ac$
> 📌 运用知识点：余弦定理

由余弦定理 $b^2 = a^2 + c^2 - 2ac\cos B$：

$$7 = a^2 + c^2 - 2ac \cdot \frac{1}{2} = a^2 + c^2 - ac$$

又 $a + c = 4$，所以 $a^2 + c^2 = (a+c)^2 - 2ac = 16 - 2ac$。

$$7 = 16 - 2ac - ac = 16 - 3ac$$

$$ac = 3$$

**第4步：** 计算面积

$$S = \frac{1}{2}ac\sin B = \frac{1}{2} \times 3 \times \frac{\sqrt{3}}{2} = \frac{3\sqrt{3}}{4}$$

**⚠️ 易错提醒：** 利用正弦定理将边的关系转化为角的关系时，注意 $\sin(B+C) = \sin A$ 这一常用等式。第二问中注意利用 $(a+c)^2 = a^2 + c^2 + 2ac$ 整体代换，避免分别求 $a$、$c$。

**💡 解题思路总结：** 第一问用正弦定理实现"边化角"，再利用三角恒等变换求解；第二问用余弦定理配合整体代换求 $ac$，最后用面积公式。

**答案：（1）$B = \dfrac{\pi}{3}$；（2）$S = \dfrac{3\sqrt{3}}{4}$**
