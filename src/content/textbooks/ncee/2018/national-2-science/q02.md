**题目：** 已知集合 $A = \{x \mid x^2 - x - 2 > 0\}$，则 $\complement_{\mathbb{R}} A =$

A. $\{x \mid -1 < x < 2\}$

B. $\{x \mid -1 \leqslant x \leqslant 2\}$

C. $\{x \mid x < -1 \text{ 或 } x > 2\}$

D. $\{x \mid x \leqslant -1 \text{ 或 } x \geqslant 2\}$

---

**解答：**

**第1步：** 求解集合 $A$
> 📌 运用知识点：集合运算

解不等式 $x^2 - x - 2 > 0$：

$$(x-2)(x+1) > 0$$

解得 $x < -1$ 或 $x > 2$，即 $A = \{x \mid x < -1 \text{ 或 } x > 2\}$。

**第2步：** 求补集
> 📌 运用知识点：集合运算

$$\complement_{\mathbb{R}} A = \{x \mid -1 \leqslant x \leqslant 2\}$$

**答案：B**
