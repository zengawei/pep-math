**题目：** 运行如下所示的伪代码，输出的结果是

```
S ← 0
I ← 1
While I ≤ 4
    S ← S + I × (I + 1)
    I ← I + 1
End While
Print S
```

A. 10

B. 20

C. 30

D. 40

---

**解答：**

**第1步：** 逐步执行循环
> 📌 运用知识点：循环结构的执行过程

初始值：$S = 0$，$I = 1$。

**第2步：** 逐次计算每次循环的结果
> 📌 运用知识点：累加求和

- 第1次循环：$I = 1 \leq 4$，$S = 0 + 1 \times 2 = 2$，$I = 2$
- 第2次循环：$I = 2 \leq 4$，$S = 2 + 2 \times 3 = 8$，$I = 3$
- 第3次循环：$I = 3 \leq 4$，$S = 8 + 3 \times 4 = 20$，$I = 4$
- 第4次循环：$I = 4 \leq 4$，$S = 20 + 4 \times 5 = 40$，$I = 5$
- 第5次判断：$I = 5 > 4$，退出循环

**第3步：** 输出结果
> 📌 运用知识点：程序输出

输出 $S = 40$。

**答案：** D

**⚠️ 易错提醒：** 注意循环条件是 $I \leq 4$（含等号），不要漏掉最后一次循环。计算 $I \times (I+1)$ 时注意运算优先级。

**💡 解题思路总结：** 对于循环结构的伪代码题，最好的方法是列表逐步跟踪变量的变化，确保不遗漏、不多算任何一次循环。
