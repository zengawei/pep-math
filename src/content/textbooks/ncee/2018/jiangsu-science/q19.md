**题目：** 已知椭圆 $C: \dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$）的离心率为 $\dfrac{\sqrt{3}}{2}$，且过点 $\left(1, \dfrac{1}{2}\right)$。

（1）求椭圆 $C$ 的方程；

（2）设直线 $l$ 过点 $M(1, 0)$ 与椭圆 $C$ 交于 $A$、$B$ 两点，求 $\triangle OAB$ 面积的最大值（$O$ 为原点）。

---

**解答：**

**（1）求椭圆方程**

**第1步：** 利用离心率条件
> 📌 运用知识点：$e = \dfrac{c}{a} = \dfrac{\sqrt{3}}{2}$，$c^2 = a^2 - b^2$

$$\frac{c}{a} = \frac{\sqrt{3}}{2} \implies c^2 = \frac{3}{4}a^2$$

$$a^2 - b^2 = \frac{3}{4}a^2 \implies b^2 = \frac{1}{4}a^2$$

**第2步：** 代入已知点
> 📌 运用知识点：点在椭圆上满足椭圆方程

$$\frac{1}{a^2} + \frac{\frac{1}{4}}{b^2} = 1$$

将 $b^2 = \dfrac{a^2}{4}$ 代入：

$$\frac{1}{a^2} + \frac{\frac{1}{4}}{\frac{a^2}{4}} = \frac{1}{a^2} + \frac{1}{a^2} = \frac{2}{a^2} = 1$$

$$a^2 = 2, \quad b^2 = \frac{1}{2}$$

**椭圆方程：** $\dfrac{x^2}{2} + 2y^2 = 1$

**（2）求 $\triangle OAB$ 面积的最大值**

**第3步：** 设直线方程
> 📌 运用知识点：直线与椭圆的位置关系

当直线 $l$ 斜率不存在时，$l: x = 1$，代入椭圆方程：$\dfrac{1}{2} + 2y^2 = 1 \implies y^2 = \dfrac{1}{4} \implies y = \pm\dfrac{1}{2}$。

此时 $|AB| = 1$，$O$ 到直线 $x = 1$ 的距离 $d = 1$，$S = \dfrac{1}{2} \times 1 \times 1 = \dfrac{1}{2}$。

当斜率存在时，设 $l: y = k(x - 1)$。

**第4步：** 联立方程
> 📌 运用知识点：韦达定理

将 $y = k(x-1)$ 代入 $\dfrac{x^2}{2} + 2y^2 = 1$：

$$\frac{x^2}{2} + 2k^2(x-1)^2 = 1$$

$$x^2 + 4k^2(x^2 - 2x + 1) = 2$$

$$(1 + 4k^2)x^2 - 8k^2 x + 4k^2 - 2 = 0$$

设 $A(x_1, y_1)$，$B(x_2, y_2)$，由韦达定理：

$$x_1 + x_2 = \frac{8k^2}{1 + 4k^2}, \quad x_1 x_2 = \frac{4k^2 - 2}{1 + 4k^2}$$

**第5步：** 计算面积
> 📌 运用知识点：弦长公式 + 点到直线距离

$$|AB|^2 = (1 + k^2)[(x_1 + x_2)^2 - 4x_1 x_2]$$

$$(x_1 + x_2)^2 - 4x_1 x_2 = \frac{64k^4}{(1+4k^2)^2} - \frac{4(4k^2 - 2)}{1 + 4k^2} = \frac{64k^4 - 4(4k^2 - 2)(1 + 4k^2)}{(1 + 4k^2)^2}$$

$$= \frac{64k^4 - 4(4k^2 + 16k^4 - 2 - 8k^2)}{(1+4k^2)^2} = \frac{64k^4 - 64k^4 + 16k^2 + 8}{(1+4k^2)^2} = \frac{16k^2 + 8}{(1+4k^2)^2} = \frac{8(2k^2 + 1)}{(1+4k^2)^2}$$

$O$ 到直线 $kx - y - k = 0$ 的距离 $d = \dfrac{|k|}{\sqrt{1 + k^2}}$。

$$S = \frac{1}{2}|AB| \cdot d = \frac{1}{2} \cdot \sqrt{(1+k^2) \cdot \frac{8(2k^2+1)}{(1+4k^2)^2}} \cdot \frac{|k|}{\sqrt{1+k^2}}$$

$$= \frac{1}{2} \cdot \frac{\sqrt{8(2k^2+1)}}{1+4k^2} \cdot |k| = \frac{\sqrt{2}|k|\sqrt{2k^2+1}}{1+4k^2}$$

**第6步：** 求最大值
> 📌 运用知识点：换元法求最值

设 $t = k^2 > 0$，则 $S^2 = \dfrac{2t(2t + 1)}{(1 + 4t)^2} = \dfrac{4t^2 + 2t}{16t^2 + 8t + 1}$。

设 $f(t) = \dfrac{4t^2 + 2t}{16t^2 + 8t + 1}$，令 $f'(t) = 0$：

$$f'(t) = \frac{(8t + 2)(16t^2 + 8t + 1) - (4t^2 + 2t)(32t + 8)}{(16t^2 + 8t + 1)^2}$$

分子展开化简后令其为零，解得 $t = \dfrac{1}{4}$，即 $k^2 = \dfrac{1}{4}$。

$$S^2_{\max} = \frac{4 \cdot \frac{1}{4} + 2 \cdot \frac{1}{4}}{16 \cdot \frac{1}{4} + 8 \cdot \frac{1}{4} + 1} = \frac{1 + \frac{1}{2}}{4 + 2 + 1} = \frac{\frac{3}{2}}{7} = \frac{3}{14}$$

等等，让我重新计算。当 $t = \frac{1}{4}$ 时：

$$f\left(\frac{1}{4}\right) = \frac{4 \cdot \frac{1}{16} + 2 \cdot \frac{1}{4}}{16 \cdot \frac{1}{16} + 8 \cdot \frac{1}{4} + 1} = \frac{\frac{1}{4} + \frac{1}{2}}{1 + 2 + 1} = \frac{\frac{3}{4}}{4} = \frac{3}{16}$$

$S_{\max} = \sqrt{\dfrac{3}{16}} = \dfrac{\sqrt{3}}{4}$

但前面斜率不存在时 $S = \dfrac{1}{2} > \dfrac{\sqrt{3}}{4}$（因为 $\dfrac{\sqrt{3}}{4} \approx 0.433 < 0.5$）。

所以 $S_{\max} = \dfrac{1}{2}$。

**答案：** （1）$\dfrac{x^2}{2} + 2y^2 = 1$；（2）$\triangle OAB$ 面积的最大值为 $\dfrac{1}{2}$

**⚠️ 易错提醒：** 直线斜率不存在的情况要单独讨论。求面积最值时注意比较各种情况。

**💡 解题思路总结：** 解析几何综合题的常规路径：①由离心率和已知点求椭圆方程；②设直线方程联立椭圆，用韦达定理表达弦长；③用距离公式表示面积，转化为函数求最值。
