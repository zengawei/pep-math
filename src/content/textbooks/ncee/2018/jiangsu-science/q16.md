**题目：** 已知 $\sin\alpha + \cos\alpha = \dfrac{\sqrt{2}}{2}$，则 $\sin 2\alpha = $ ______。

---

**解答：**

**第1步：** 将已知等式两边平方
> 📌 运用知识点：$(\sin\alpha + \cos\alpha)^2 = \sin^2\alpha + 2\sin\alpha\cos\alpha + \cos^2\alpha$

$$(\sin\alpha + \cos\alpha)^2 = \left(\frac{\sqrt{2}}{2}\right)^2$$

$$\sin^2\alpha + 2\sin\alpha\cos\alpha + \cos^2\alpha = \frac{1}{2}$$

**第2步：** 利用基本恒等式化简
> 📌 运用知识点：$\sin^2\alpha + \cos^2\alpha = 1$ 及 $\sin 2\alpha = 2\sin\alpha\cos\alpha$

$$1 + \sin 2\alpha = \frac{1}{2}$$

**第3步：** 求解
> 📌 运用知识点：代数运算

$$\sin 2\alpha = \frac{1}{2} - 1 = -\frac{1}{2}$$

**答案：** $-\dfrac{1}{2}$

**⚠️ 易错提醒：** 平方后右边 $\left(\frac{\sqrt{2}}{2}\right)^2 = \frac{2}{4} = \frac{1}{2}$，不要算成 $\frac{\sqrt{2}}{2}$ 或其他值。注意 $\sin 2\alpha$ 可以为负值。

**💡 解题思路总结：** 已知 $\sin\alpha + \cos\alpha$ 的值求 $\sin 2\alpha$，标准方法是两边平方，利用 $\sin^2\alpha + \cos^2\alpha = 1$ 和 $2\sin\alpha\cos\alpha = \sin 2\alpha$ 建立联系。
