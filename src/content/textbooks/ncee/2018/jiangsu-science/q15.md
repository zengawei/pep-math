**题目：** 已知实数 $x, y$ 满足约束条件 $\begin{cases} x + y \leq 4 \\ x - y \leq 2 \\ x \geq 0 \\ y \geq 0 \end{cases}$，则 $z = 3x + y$ 的最大值为 ______。

---

**解答：**

**第1步：** 确定可行域的顶点
> 📌 运用知识点：线性规划——求可行域顶点

由约束条件求各交点：

- $x = 0, y = 0$：交点 $(0, 0)$
- $x = 0, x + y = 4$：交点 $(0, 4)$
- $y = 0, x - y = 2$：交点 $(2, 0)$
- $x + y = 4$ 与 $x - y = 2$ 联立：$2x = 6 \implies x = 3, y = 1$，交点 $(3, 1)$

验证各点是否满足所有约束：
- $(0, 0)$：✓
- $(0, 4)$：$0 - 4 = -4 \leq 2$ ✓
- $(2, 0)$：$2 + 0 = 2 \leq 4$ ✓
- $(3, 1)$：$3 \geq 0, 1 \geq 0$ ✓

**第2步：** 在各顶点处计算目标函数值
> 📌 运用知识点：线性规划最优解在顶点取得

- $z(0, 0) = 0$
- $z(0, 4) = 4$
- $z(2, 0) = 6$
- $z(3, 1) = 9 + 1 = 10$

**第3步：** 确定最大值
> 📌 运用知识点：比较各顶点值

$z_{\max} = 10$，在点 $(3, 1)$ 处取得。

**答案：** $10$

**⚠️ 易错提醒：** 求可行域顶点时，必须验证每个交点是否满足所有约束条件。计算目标函数值时不要算错。

**💡 解题思路总结：** 线性规划问题的标准解法：①画出可行域（或求出各顶点）；②在各顶点处计算目标函数值；③比较得出最值。
