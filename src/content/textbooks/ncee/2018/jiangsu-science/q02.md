**题目：** 已知 $i$ 为虚数单位，若复数 $z = \dfrac{1 + 2i}{1 - i}$，则 $|z| = $

A. $\dfrac{\sqrt{2}}{2}$

B. $\dfrac{\sqrt{5}}{2}$

C. $\dfrac{\sqrt{10}}{2}$

D. $\sqrt{5}$

---

**解答：**

**第1步：** 化简复数 $z$
> 📌 运用知识点：复数除法——分子分母同乘共轭复数

$$z = \frac{1 + 2i}{1 - i} = \frac{(1 + 2i)(1 + i)}{(1 - i)(1 + i)} = \frac{1 + i + 2i + 2i^2}{1 - i^2} = \frac{1 + 3i - 2}{1 + 1} = \frac{-1 + 3i}{2}$$

**第2步：** 求复数的模
> 📌 运用知识点：复数模的计算 $|a + bi| = \sqrt{a^2 + b^2}$

$$|z| = \left|\frac{-1 + 3i}{2}\right| = \frac{\sqrt{(-1)^2 + 3^2}}{2} = \frac{\sqrt{1 + 9}}{2} = \frac{\sqrt{10}}{2}$$

**答案：** C

**⚠️ 易错提醒：** 复数除法必须分子分母同乘分母的共轭复数。计算 $i^2 = -1$ 时注意符号。

**💡 解题思路总结：** 复数除法化简的标准方法：分子分母同乘分母的共轭复数，将分母化为实数，再求模。也可直接利用 $|z| = \dfrac{|1+2i|}{|1-i|} = \dfrac{\sqrt{5}}{\sqrt{2}} = \dfrac{\sqrt{10}}{2}$。
