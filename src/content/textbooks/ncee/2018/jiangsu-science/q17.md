**题目：** 在 $\triangle ABC$ 中，角 $A, B, C$ 的对边分别为 $a, b, c$，已知 $a = 2$，$b = 3$，$\cos C = \dfrac{1}{4}$。

（1）求 $c$ 的值；

（2）求 $\sin(B + C)$ 的值。

---

**解答：**

**（1）求 $c$ 的值**

**第1步：** 应用余弦定理
> 📌 运用知识点：余弦定理 $c^2 = a^2 + b^2 - 2ab\cos C$

$$c^2 = 2^2 + 3^2 - 2 \times 2 \times 3 \times \frac{1}{4}$$

$$c^2 = 4 + 9 - 3 = 10$$

$$c = \sqrt{10}$$

**（2）求 $\sin(B + C)$ 的值**

**第2步：** 利用三角形内角和
> 📌 运用知识点：$A + B + C = \pi$，所以 $B + C = \pi - A$

$$\sin(B + C) = \sin(\pi - A) = \sin A$$

**第3步：** 求 $\sin C$
> 📌 运用知识点：$\sin^2 C + \cos^2 C = 1$

$$\sin C = \sqrt{1 - \cos^2 C} = \sqrt{1 - \frac{1}{16}} = \sqrt{\frac{15}{16}} = \frac{\sqrt{15}}{4}$$

（因为 $C$ 为三角形内角，$\sin C > 0$）

**第4步：** 用正弦定理求 $\sin A$
> 📌 运用知识点：正弦定理 $\dfrac{a}{\sin A} = \dfrac{c}{\sin C}$

$$\frac{2}{\sin A} = \frac{\sqrt{10}}{\frac{\sqrt{15}}{4}}$$

$$\sin A = \frac{2 \times \frac{\sqrt{15}}{4}}{\sqrt{10}} = \frac{\frac{\sqrt{15}}{2}}{\sqrt{10}} = \frac{\sqrt{15}}{2\sqrt{10}} = \frac{\sqrt{15}}{2\sqrt{10}} \times \frac{\sqrt{10}}{\sqrt{10}} = \frac{\sqrt{150}}{20} = \frac{5\sqrt{6}}{20} = \frac{\sqrt{6}}{4}$$

因此 $\sin(B + C) = \sin A = \dfrac{\sqrt{6}}{4}$。

**答案：** （1）$c = \sqrt{10}$；（2）$\sin(B + C) = \dfrac{\sqrt{6}}{4}$

**⚠️ 易错提醒：** 第（2）问的关键是发现 $B + C = \pi - A$，从而 $\sin(B+C) = \sin A$。正弦定理中注意分母不要搞反。

**💡 解题思路总结：** 解三角形问题中，已知两边和夹角用余弦定理求第三边；求角的三角函数值时，注意利用三角形内角和关系进行转化。
