**题目：** 在 $\triangle ABC$ 中，内角 $A$，$B$，$C$ 的对边分别为 $a$，$b$，$c$，已知 $b\cos C + c\cos B = 2a\cos A$。

（1）求 $A$；

（2）若 $a=2$，$\triangle ABC$ 的面积为 $\sqrt{3}$，求 $b+c$。

---

**解答：**

**第1步：** 利用正弦定理转化（第1问）
> 📌 运用知识点：三角恒等变换

由正弦定理 $\dfrac{a}{\sin A}=\dfrac{b}{\sin B}=\dfrac{c}{\sin C}$，将边化为角：

$$\sin B\cos C + \sin C\cos B = 2\sin A\cos A$$

左边由和角公式：

$$\sin(B+C) = 2\sin A\cos A$$

因为 $B+C = \pi - A$，所以 $\sin(B+C) = \sin A$：

$$\sin A = 2\sin A\cos A$$

因为 $\sin A \neq 0$（$A$ 为三角形内角），两边除以 $\sin A$：

$$1 = 2\cos A \implies \cos A = \frac{1}{2}$$

因为 $A \in (0, \pi)$，所以 $A = \dfrac{\pi}{3}$。

**第2步：** 利用面积条件（第2问）
> 📌 运用知识点：三角函数

$$S = \frac{1}{2}bc\sin A = \frac{1}{2}bc\sin\frac{\pi}{3} = \frac{\sqrt{3}}{4}bc = \sqrt{3}$$

$$bc = 4$$

**第3步：** 利用余弦定理

$$a^2 = b^2 + c^2 - 2bc\cos A$$

$$4 = b^2 + c^2 - 2 \times 4 \times \frac{1}{2} = b^2 + c^2 - 4$$

$$b^2 + c^2 = 8$$

**第4步：** 求 $b+c$

$$(b+c)^2 = b^2 + c^2 + 2bc = 8 + 8 = 16$$

$$b+c = 4$$

**⚠️ 易错提醒：** 第1问中利用正弦定理将边化为角时，要注意 $\sin(B+C)=\sin A$ 的转化，不要遗漏 $B+C=\pi-A$ 的关系。第2问中利用余弦定理时，注意 $bc$ 的值要代入正确。

**💡 解题思路总结：** 三角形中的边角混合问题，优先考虑正弦定理或余弦定理进行转化。面积公式是联系边和角的重要桥梁，$(b+c)^2 = b^2+c^2+2bc$ 的整体代换思想是解题关键。

**答案：** （1）$A = \dfrac{\pi}{3}$；（2）$b+c = 4$
