**题目：** 已知集合 $A=\{x \mid x^2-2x>0\}$，$B=\{x \mid -\sqrt{5}<x<\sqrt{5}\}$，则 $A\cap B=$

A. $\{x \mid -\sqrt{5}<x<0\}$

B. $\{x \mid -\sqrt{5}<x<0 \text{ 或 } 2<x<\sqrt{5}\}$

C. $\{x \mid 0<x<2\}$

D. $\{x \mid 2<x<\sqrt{5}\}$

---

**解答：**

**第1步：** 求解集合A
> 📌 运用知识点：集合的运算

解不等式 $x^2-2x>0$：

$$x(x-2)>0$$

解得 $x<0$ 或 $x>2$，因此 $A=\{x \mid x<0 \text{ 或 } x>2\}$。

**第2步：** 求交集 $A\cap B$

$B=\{x \mid -\sqrt{5}<x<\sqrt{5}\}$

在数轴上取 $A$ 与 $B$ 的公共部分：

- 当 $x<0$ 时，与 $-\sqrt{5}<x<\sqrt{5}$ 的交集为 $-\sqrt{5}<x<0$
- 当 $x>2$ 时，与 $-\sqrt{5}<x<\sqrt{5}$ 的交集为 $2<x<\sqrt{5}$

因此：

$$A\cap B = \{x \mid -\sqrt{5}<x<0 \text{ 或 } 2<x<\sqrt{5}\}$$

**答案：** B
