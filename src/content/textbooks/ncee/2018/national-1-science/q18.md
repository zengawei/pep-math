**题目：** 如图，四棱锥 $P\text{-}ABCD$ 中，底面 $ABCD$ 为正方形，$PA \perp$ 底面 $ABCD$，$PA=AB=2$。

（1）证明：$BD \perp PC$；

（2）求二面角 $B\text{-}PC\text{-}D$ 的大小。

---

**解答：**

**第1步：** 建立空间直角坐标系
> 📌 运用知识点：空间向量坐标

以 $A$ 为原点，$\overrightarrow{AB}$、$\overrightarrow{AD}$、$\overrightarrow{AP}$ 分别为 $x$、$y$、$z$ 轴正方向：

$$A(0,0,0),\; B(2,0,0),\; C(2,2,0),\; D(0,2,0),\; P(0,0,2)$$

**第2步：** 证明 $BD \perp PC$（第1问）

$$\overrightarrow{BD} = D - B = (-2, 2, 0)$$

$$\overrightarrow{PC} = C - P = (2, 2, -2)$$

$$\overrightarrow{BD} \cdot \overrightarrow{PC} = (-2)(2) + (2)(2) + (0)(-2) = -4 + 4 + 0 = 0$$

因此 $BD \perp PC$。$\blacksquare$

**第3步：** 求平面BPC的法向量（第2问）
> 📌 运用知识点：坐标法

$$\overrightarrow{BP} = P - B = (-2, 0, 2), \quad \overrightarrow{BC} = C - B = (0, 2, 0)$$

设平面 $BPC$ 的法向量 $\vec{n_1} = (x, y, z)$：

$$\begin{cases} \vec{n_1} \cdot \overrightarrow{BP} = -2x + 2z = 0 \\ \vec{n_1} \cdot \overrightarrow{BC} = 2y = 0 \end{cases}$$

取 $x=1$，则 $z=1$，$y=0$，$\vec{n_1} = (1, 0, 1)$。

**第4步：** 求平面DPC的法向量

$$\overrightarrow{DP} = P - D = (0, -2, 2), \quad \overrightarrow{DC} = C - D = (2, 0, 0)$$

设平面 $DPC$ 的法向量 $\vec{n_2} = (x, y, z)$：

$$\begin{cases} \vec{n_2} \cdot \overrightarrow{DP} = -2y + 2z = 0 \\ \vec{n_2} \cdot \overrightarrow{DC} = 2x = 0 \end{cases}$$

取 $y=1$，则 $z=1$，$x=0$，$\vec{n_2} = (0, 1, 1)$。

**第5步：** 求二面角

$$\cos\theta = \frac{|\vec{n_1} \cdot \vec{n_2}|}{|\vec{n_1}||\vec{n_2}|} = \frac{|0+0+1|}{\sqrt{2} \cdot \sqrt{2}} = \frac{1}{2}$$

通过判断法向量方向（两法向量均指向四棱锥外侧），二面角 $B\text{-}PC\text{-}D$ 为钝角：

$$\text{二面角} = \pi - \frac{\pi}{3} = \frac{2\pi}{3}$$

**⚠️ 易错提醒：** 求二面角时要注意判断是取锐角还是钝角。两个法向量的夹角可能等于二面角，也可能等于二面角的补角，需要结合几何体的实际形状来判断。

**💡 解题思路总结：** 立体几何中的垂直证明和角度计算，建系法是最通用的方法。关键是选好坐标系，准确计算各点坐标和向量，最后注意二面角的钝锐判断。

**答案：** （1）证明见上；（2）二面角 $B\text{-}PC\text{-}D$ 的大小为 $\dfrac{2\pi}{3}$
