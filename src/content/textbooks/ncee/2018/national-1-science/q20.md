**题目：** 已知椭圆 $C: \dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1$（$a>b>0$）的离心率为 $\dfrac{\sqrt{2}}{2}$，右焦点为 $F(1,0)$。

（1）求 $C$ 的方程；

（2）过 $F$ 的直线 $l$ 交 $C$ 于 $A$，$B$ 两点，若 $\overrightarrow{AF}=2\overrightarrow{FB}$，求 $l$ 的方程。

---

**解答：**

**第1步：** 求椭圆方程（第1问）
> 📌 运用知识点：椭圆的性质

右焦点 $F(1,0)$，所以 $c=1$。

$$e = \frac{c}{a} = \frac{\sqrt{2}}{2} \implies a = \frac{1}{\dfrac{\sqrt{2}}{2}} = \sqrt{2}$$

$$b^2 = a^2 - c^2 = 2 - 1 = 1$$

椭圆方程：

$$\frac{x^2}{2} + y^2 = 1$$

**第2步：** 转化向量条件（第2问）
> 📌 运用知识点：圆锥曲线与直线

设 $A(x_1, y_1)$，$B(x_2, y_2)$。设直线 $l: x = my+1$（过焦点 $F(1,0)$）。

代入椭圆方程：

$$\frac{(my+1)^2}{2} + y^2 = 1$$

$$(m^2+2)y^2 + 2my - 1 = 0$$

由韦达定理：

$$y_1 + y_2 = \frac{-2m}{m^2+2}, \quad y_1 y_2 = \frac{-1}{m^2+2}$$

由 $\overrightarrow{AF} = 2\overrightarrow{FB}$：

$$(1-x_1, -y_1) = 2(x_2-1, y_2)$$

由 $y$ 分量：$-y_1 = 2y_2$，即 $y_1 = -2y_2$。

**第3步：** 利用韦达定理求m

代入 $y_1+y_2$：

$$-2y_2 + y_2 = \frac{-2m}{m^2+2} \implies y_2 = \frac{2m}{m^2+2}$$

代入 $y_1 y_2$：

$$-2y_2^2 = \frac{-1}{m^2+2} \implies y_2^2 = \frac{1}{2(m^2+2)}$$

将 $y_2 = \dfrac{2m}{m^2+2}$ 代入：

$$\frac{4m^2}{(m^2+2)^2} = \frac{1}{2(m^2+2)}$$

$$\frac{4m^2}{m^2+2} = \frac{1}{2}$$

$$8m^2 = m^2 + 2 \implies 7m^2 = 2 \implies m^2 = \frac{2}{7}$$

$$m = \pm\frac{\sqrt{14}}{7}$$

**第4步：** 写出直线方程

直线 $l: x = my+1$，斜率 $k = \dfrac{1}{m} = \pm\dfrac{7}{\sqrt{14}} = \pm\dfrac{\sqrt{14}}{2}$

$$l: y = \pm\frac{\sqrt{14}}{2}(x-1)$$

**⚠️ 易错提醒：** 向量条件 $\overrightarrow{AF}=2\overrightarrow{FB}$ 说明 $F$ 在线段 $AB$ 上且 $F$ 靠近 $B$，这意味着 $y_1$ 和 $y_2$ 异号。设直线为 $x=my+1$ 比 $y=k(x-1)$ 更方便，可以避免讨论斜率不存在的情况。

**💡 解题思路总结：** 圆锥曲线综合题的核心是"设而不求"——设出直线方程和交点坐标，利用韦达定理建立关系式，避免直接求解交点坐标。向量条件的转化是关键步骤。

**答案：** （1）$\dfrac{x^2}{2}+y^2=1$；（2）$l: y=\pm\dfrac{\sqrt{14}}{2}(x-1)$
