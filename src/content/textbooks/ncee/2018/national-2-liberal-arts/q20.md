**题目：** 椭圆 $C: \dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$）的离心率为 $\dfrac{\sqrt{3}}{2}$，且过点 $\left(1, \dfrac{\sqrt{3}}{2}\right)$。

（1）求椭圆 $C$ 的方程；

（2）设直线 $l$ 过点 $M(1, 0)$ 与椭圆 $C$ 交于 $A$，$B$ 两点，求 $\triangle OAB$ 面积的最大值。

---

**解答：**

**（1）求椭圆 $C$ 的方程**

**第1步：** 利用离心率条件
> 📌 运用知识点：椭圆的离心率

$$e = \frac{c}{a} = \frac{\sqrt{3}}{2} \implies c^2 = \frac{3}{4}a^2$$

$$b^2 = a^2 - c^2 = a^2 - \frac{3}{4}a^2 = \frac{1}{4}a^2$$

**第2步：** 代入已知点

椭圆过点 $\left(1, \dfrac{\sqrt{3}}{2}\right)$，代入椭圆方程：

$$\frac{1}{a^2} + \frac{\dfrac{3}{4}}{b^2} = 1$$

将 $b^2 = \dfrac{a^2}{4}$ 代入：

$$\frac{1}{a^2} + \frac{3}{a^2} = 1 \implies \frac{4}{a^2} = 1 \implies a^2 = 4$$

$$b^2 = \frac{4}{4} = 1$$

**第3步：** 写出椭圆方程

$$\frac{x^2}{4} + y^2 = 1$$

**（2）求 $\triangle OAB$ 面积的最大值**

**第4步：** 设直线方程并联立
> 📌 运用知识点：直线与椭圆的位置关系

当直线 $l$ 的斜率不存在时，$l: x = 1$，代入椭圆方程：

$$\frac{1}{4} + y^2 = 1 \implies y^2 = \frac{3}{4} \implies y = \pm\frac{\sqrt{3}}{2}$$

$$|AB| = \sqrt{3},\quad S = \frac{1}{2} \times |OM| \times |AB| = \frac{1}{2} \times 1 \times \sqrt{3} = \frac{\sqrt{3}}{2}$$

当直线 $l$ 的斜率存在时，设 $l: x = my + 1$（过点 $M(1, 0)$），代入椭圆方程：

$$\frac{(my + 1)^2}{4} + y^2 = 1$$

$$(m^2 + 4)y^2 + 2my - 3 = 0$$

**第5步：** 利用韦达定理

$$y_1 + y_2 = \frac{-2m}{m^2 + 4}, \quad y_1 y_2 = \frac{-3}{m^2 + 4}$$

**第6步：** 计算面积
> 📌 运用知识点：三角形面积

$$S = \frac{1}{2} |OM| \cdot |y_1 - y_2| = \frac{1}{2} \times 1 \times \sqrt{(y_1 + y_2)^2 - 4y_1 y_2}$$

$$(y_1 - y_2)^2 = \frac{4m^2}{(m^2 + 4)^2} + \frac{12}{m^2 + 4} = \frac{4m^2 + 12(m^2 + 4)}{(m^2 + 4)^2} = \frac{16(m^2 + 3)}{(m^2 + 4)^2}$$

$$S = \frac{1}{2} \times \frac{4\sqrt{m^2 + 3}}{m^2 + 4} = \frac{2\sqrt{m^2 + 3}}{m^2 + 4}$$

**第7步：** 求最大值

令 $t = m^2 + 3 \geqslant 3$，则 $m^2 + 4 = t + 1$：

$$S = \frac{2\sqrt{t}}{t + 1}$$

令 $u = \sqrt{t} \geqslant \sqrt{3}$：

$$S = \frac{2u}{u^2 + 1}$$

对 $u$ 求导：$S' = \dfrac{2(1 - u^2)}{(u^2 + 1)^2}$

当 $u \geqslant \sqrt{3} > 1$ 时，$S' < 0$，$S$ 单调递减。

所以 $S$ 在 $u = \sqrt{3}$（即 $m = 0$）时取最大值：

$$S_{\max} = \frac{2\sqrt{3}}{3 + 1} = \frac{\sqrt{3}}{2}$$

这与斜率不存在时的结果一致。

**答案：**（1）$\dfrac{x^2}{4} + y^2 = 1$；（2）$\triangle OAB$ 面积的最大值为 $\dfrac{\sqrt{3}}{2}$

**⚠️ 易错提醒：** ①由离心率求 $b^2$ 时，$b^2 = a^2 - c^2 = a^2 - \dfrac{3}{4}a^2 = \dfrac{1}{4}a^2$，不要算错。②设直线 $l: x = my + 1$ 比 $y = k(x-1)$ 更好，因为可以包含斜率不存在的情况。③求最值时换元 $t = m^2 + 3$ 后，注意 $t$ 的范围。

**💡 解题思路总结：** 圆锥曲线综合题的标准思路：①用基本量法求椭圆方程；②设直线方程并联立椭圆方程；③利用韦达定理表示目标量；④通过换元或基本不等式求最值。
