**题目：** $\dfrac{1 + 2\text{i}}{2 - \text{i}} =$

A. $\text{i}$

B. $-\text{i}$

C. $1$

D. $-1$

---

**解答：**

**第1步：** 分子分母同乘分母的共轭复数
> 📌 运用知识点：复数的除法运算

$$\frac{1 + 2\text{i}}{2 - \text{i}} = \frac{(1 + 2\text{i})(2 + \text{i})}{(2 - \text{i})(2 + \text{i})}$$

**第2步：** 计算分母

$$(2 - \text{i})(2 + \text{i}) = 4 - \text{i}^2 = 4 - (-1) = 5$$

**第3步：** 计算分子

$$(1 + 2\text{i})(2 + \text{i}) = 2 + \text{i} + 4\text{i} + 2\text{i}^2 = 2 + 5\text{i} + 2(-1) = 5\text{i}$$

**第4步：** 得出结果

$$\frac{1 + 2\text{i}}{2 - \text{i}} = \frac{5\text{i}}{5} = \text{i}$$

**答案：A**

**⚠️ 易错提醒：** 复数除法的关键是分子分母同乘分母的共轭复数，注意 $\text{i}^2 = -1$，计算分子时不要漏掉交叉项。

**💡 解题思路总结：** 复数除法的标准方法：分子分母同乘分母的共轭复数，将分母化为实数，再化简分子。
