**题目：** 过抛物线 $y^2 = 4x$ 的焦点 $F$ 的直线交抛物线于 $A$，$B$ 两点，若 $|AF| = 3$，则 $|BF| =$

A. $1$

B. $\dfrac{3}{2}$

C. $2$

D. $\dfrac{5}{2}$

---

**解答：**

**第1步：** 确定焦点坐标
> 📌 运用知识点：抛物线的标准方程

抛物线 $y^2 = 4x$ 中，$2p = 4$，$p = 2$，焦点 $F(1, 0)$。

**第2步：** 利用焦半径公式求 $A$ 的坐标
> 📌 运用知识点：抛物线的焦半径

抛物线上一点 $(x_0, y_0)$ 到焦点的距离为 $|PF| = x_0 + \dfrac{p}{2} = x_0 + 1$。

$$|AF| = x_A + 1 = 3 \implies x_A = 2$$

代入 $y^2 = 4x$：$y_A^2 = 8$，$y_A = 2\sqrt{2}$（取正值）。

**第3步：** 求直线方程并联立
> 📌 运用知识点：直线与抛物线的位置关系

直线过 $F(1, 0)$ 和 $A(2, 2\sqrt{2})$，斜率 $k = \dfrac{2\sqrt{2}}{2 - 1} = 2\sqrt{2}$。

直线方程：$y = 2\sqrt{2}(x - 1)$

代入 $y^2 = 4x$：

$$8(x - 1)^2 = 4x \implies 2x^2 - 5x + 2 = 0 \implies (2x - 1)(x - 2) = 0$$

$x = 2$（对应 $A$）或 $x = \dfrac{1}{2}$（对应 $B$）。

**第4步：** 求 $|BF|$

$$|BF| = x_B + 1 = \frac{1}{2} + 1 = \frac{3}{2}$$

**答案：B**

**⚠️ 易错提醒：** ①焦半径公式 $|PF| = x_0 + \dfrac{p}{2}$，不要与到准线的距离混淆（两者相等）。②联立直线与抛物线方程时，注意化简计算。③韦达定理也可快速求解：$x_A \cdot x_B = \dfrac{2}{2} = 1$，所以 $x_B = \dfrac{1}{x_A} = \dfrac{1}{2}$。

**💡 解题思路总结：** 抛物线焦点弦问题的核心工具：①焦半径公式 $|PF| = x_0 + \dfrac{p}{2}$；②联立直线与抛物线方程。利用韦达定理 $x_A x_B = \dfrac{p^2}{4}$ 可以快速求出另一个交点。
