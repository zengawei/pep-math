**题目：** 已知集合 $A = \{1, 3, 5, 7\}$，$B = \{x \mid x^2 - 4x - 5 < 0\}$，则 $A \cap B =$

A. $\{1, 3\}$

B. $\{3, 5\}$

C. $\{5, 7\}$

D. $\{1, 7\}$

---

**解答：**

**第1步：** 求集合 $B$
> 📌 运用知识点：一元二次不等式的解法

解不等式 $x^2 - 4x - 5 < 0$：

$$x^2 - 4x - 5 = (x - 5)(x + 1) < 0$$

解得 $-1 < x < 5$，即 $B = \{x \mid -1 < x < 5\}$。

**第2步：** 求 $A \cap B$
> 📌 运用知识点：集合的交集运算

$A = \{1, 3, 5, 7\}$，$B = \{x \mid -1 < x < 5\}$

逐一检验 $A$ 中的元素是否属于 $B$：
- $1 \in (-1, 5)$ ✓
- $3 \in (-1, 5)$ ✓
- $5 \notin (-1, 5)$（因为 $5$ 不满足严格不等式）✗
- $7 \notin (-1, 5)$ ✗

$A \cap B = \{1, 3\}$

**答案：A**

**⚠️ 易错提醒：** 注意不等式是严格不等号 $<$，所以 $x = 5$ 不属于 $B$。如果误将 $5$ 包含在 $B$ 中，会错选 B。

**💡 解题思路总结：** 先解一元二次不等式求出集合 $B$，再逐一检验集合 $A$ 中的元素是否满足 $B$ 的条件，取公共元素即为交集。
