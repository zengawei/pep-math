**题目：** 已知等差数列 $\{a_n\}$ 满足 $a_3 = 2$，前 $3$ 项的和 $S_3 = 9$。

（1）求 $\{a_n\}$ 的通项公式；

（2）设 $\{b_n\}$ 为等比数列，$b_1 = a_1$，$b_2 = a_4$，求 $\{b_n\}$ 的前 $n$ 项和 $T_n$。

---

**解答：**

**（1）求 $\{a_n\}$ 的通项公式**

**第1步：** 列方程组
> 📌 运用知识点：等差数列的通项公式

设等差数列 $\{a_n\}$ 的首项为 $a_1$，公差为 $d$。

$$a_3 = a_1 + 2d = 2 \quad \cdots (1)$$

$$S_3 = 3a_1 + \frac{3 \times 2}{2}d = 3a_1 + 3d = 9 \implies a_1 + d = 3 \quad \cdots (2)$$

**第2步：** 解方程组

$(1) - (2)$：$d = -1$

代入 $(2)$：$a_1 = 3 - (-1) = 4$

**第3步：** 写出通项公式

$$a_n = a_1 + (n-1)d = 4 + (n-1) \times (-1) = 5 - n$$

**（2）求 $\{b_n\}$ 的前 $n$ 项和 $T_n$**

**第4步：** 确定等比数列的参数
> 📌 运用知识点：等比数列

$$b_1 = a_1 = 4$$

$$a_4 = 5 - 4 = 1 \implies b_2 = 1$$

$$q = \frac{b_2}{b_1} = \frac{1}{4}$$

**第5步：** 求前 $n$ 项和
> 📌 运用知识点：等比数列的前 $n$ 项和公式

$$T_n = \frac{b_1(1 - q^n)}{1 - q} = \frac{4\left(1 - \left(\dfrac{1}{4}\right)^n\right)}{1 - \dfrac{1}{4}} = \frac{4\left(1 - \dfrac{1}{4^n}\right)}{\dfrac{3}{4}} = \frac{16}{3}\left(1 - \frac{1}{4^n}\right)$$

**答案：**（1）$a_n = 5 - n$；（2）$T_n = \dfrac{16}{3}\left(1 - \dfrac{1}{4^n}\right)$

**⚠️ 易错提醒：** ①$S_3 = 3a_1 + 3d$，不要写成 $S_3 = 3a_1 + \dfrac{3 \times 2}{2}d$ 后忘记化简。②求等比数列的公比时，$q = \dfrac{b_2}{b_1} = \dfrac{1}{4}$，不要算错。③等比数列求和公式中 $1 - q = 1 - \dfrac{1}{4} = \dfrac{3}{4}$，除以分数要翻转。

**💡 解题思路总结：** 等差数列的基本量法：设首项 $a_1$ 和公差 $d$，利用已知条件列方程组求解。等比数列求和要准确确定首项和公比，代入公式即可。
