**题目：** 已知 $\sin\alpha + \cos\alpha = \sqrt{2}$，则 $\tan\alpha + \dfrac{1}{\tan\alpha} =$

A. $1$

B. $2$

C. $3$

D. $4$

---

**解答：**

**第1步：** 利用已知条件求 $\sin 2\alpha$
> 📌 运用知识点：三角恒等变换

将 $\sin\alpha + \cos\alpha = \sqrt{2}$ 两边平方：

$$(\sin\alpha + \cos\alpha)^2 = 2$$

$$\sin^2\alpha + 2\sin\alpha\cos\alpha + \cos^2\alpha = 2$$

$$1 + \sin 2\alpha = 2$$

$$\sin 2\alpha = 1$$

**第2步：** 化简目标表达式

$$\tan\alpha + \frac{1}{\tan\alpha} = \frac{\sin\alpha}{\cos\alpha} + \frac{\cos\alpha}{\sin\alpha} = \frac{\sin^2\alpha + \cos^2\alpha}{\sin\alpha\cos\alpha} = \frac{1}{\sin\alpha\cos\alpha}$$

**第3步：** 代入求值

由 $\sin 2\alpha = 2\sin\alpha\cos\alpha = 1$，得 $\sin\alpha\cos\alpha = \dfrac{1}{2}$。

$$\tan\alpha + \frac{1}{\tan\alpha} = \frac{1}{\dfrac{1}{2}} = 2$$

**答案：B**

**⚠️ 易错提醒：** 化简 $\tan\alpha + \dfrac{1}{\tan\alpha}$ 时，通分后分子恰好是 $\sin^2\alpha + \cos^2\alpha = 1$，这是一个常用的恒等变换技巧。注意 $\sin 2\alpha = 1$ 意味着 $2\alpha = \dfrac{\pi}{2}$，即 $\alpha = \dfrac{\pi}{4}$。

**💡 解题思路总结：** 已知 $\sin\alpha \pm \cos\alpha$ 的值，平方后可求 $\sin 2\alpha$。将目标表达式化为关于 $\sin\alpha\cos\alpha$ 的形式，再代入求值。
