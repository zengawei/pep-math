**题目：** 如图，在四棱锥 $P\text{-}ABCD$ 中，底面 $ABCD$ 为正方形，$PA \perp$ 底面 $ABCD$，$PA = AB = 2$。

（1）证明：$BD \perp PC$；

（2）求三棱锥 $P\text{-}BCD$ 的体积。

---

**解答：**

**（1）证明 $BD \perp PC$**

**第1步：** 建立空间直角坐标系
> 📌 运用知识点：空间向量坐标

以 $A$ 为原点，$\overrightarrow{AB}$、$\overrightarrow{AD}$、$\overrightarrow{AP}$ 分别为 $x$、$y$、$z$ 轴正方向建立空间直角坐标系。

各点坐标：
$$A(0, 0, 0),\; B(2, 0, 0),\; C(2, 2, 0),\; D(0, 2, 0),\; P(0, 0, 2)$$

**第2步：** 求向量并计算数量积
> 📌 运用知识点：空间向量的数量积

$$\overrightarrow{BD} = D - B = (-2, 2, 0)$$

$$\overrightarrow{PC} = C - P = (2, 2, -2)$$

$$\overrightarrow{BD} \cdot \overrightarrow{PC} = (-2) \times 2 + 2 \times 2 + 0 \times (-2) = -4 + 4 + 0 = 0$$

**第3步：** 得出结论

因为 $\overrightarrow{BD} \cdot \overrightarrow{PC} = 0$，所以 $BD \perp PC$。$\blacksquare$

**（2）求三棱锥 $P\text{-}BCD$ 的体积**

**第4步：** 确定底面和高
> 📌 运用知识点：三棱锥的体积

三棱锥 $P\text{-}BCD$ 的底面为 $\triangle BCD$，高为点 $P$ 到平面 $BCD$ 的距离。

平面 $BCD$ 即底面 $ABCD$ 所在平面（$z = 0$），$P(0, 0, 2)$ 到该平面的距离为 $h = 2$。

**第5步：** 计算底面积

$$S_{\triangle BCD} = \frac{1}{2} \times BC \times CD = \frac{1}{2} \times 2 \times 2 = 2$$

**第6步：** 计算体积

$$V = \frac{1}{3} \times S_{\triangle BCD} \times h = \frac{1}{3} \times 2 \times 2 = \frac{4}{3}$$

**答案：**（1）证明见上；（2）三棱锥 $P\text{-}BCD$ 的体积为 $\dfrac{4}{3}$

**⚠️ 易错提醒：** ①建系时注意三条互相垂直的棱：$AB \perp AD$（正方形），$PA \perp AB$，$PA \perp AD$（$PA \perp$ 底面）。②$\triangle BCD$ 的面积是正方形 $ABCD$ 面积的一半，不要直接用正方形面积。③$P$ 到底面的距离就是 $PA = 2$。

**💡 解题思路总结：** 立体几何中证明线线垂直，可以用空间向量的数量积为零来证明。求体积时，关键是选好底面和对应的高——本题中底面在正方形的平面上，高就是 $PA$。
