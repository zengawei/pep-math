**题目：** 在等差数列 $\{a_n\}$ 中，$a_2 + a_8 = 10$，则 $S_9 =$

A. $35$

B. $40$

C. $45$

D. $50$

---

**解答：**

**第1步：** 利用等差数列的性质
> 📌 运用知识点：等差数列的性质

在等差数列中，$a_2 + a_8 = a_1 + d + a_1 + 7d = 2a_1 + 8d = 2(a_1 + 4d) = 2a_5$

所以 $2a_5 = 10$，$a_5 = 5$。

**第2步：** 求前 $9$ 项和
> 📌 运用知识点：等差数列的前 $n$ 项和

$$S_9 = \frac{9(a_1 + a_9)}{2} = \frac{9 \times 2a_5}{2} = 9a_5 = 9 \times 5 = 45$$

**答案：C**

**⚠️ 易错提醒：** 等差数列中 $a_m + a_n = a_p + a_q$（当 $m + n = p + q$ 时），利用这个性质可以快速求出中间项。$S_9 = 9a_5$ 是因为 $a_5$ 恰好是前 $9$ 项的中间项。

**💡 解题思路总结：** 等差数列求和问题，关键是利用下标关系 $m + n = p + q \implies a_m + a_n = a_p + a_q$ 求出关键项，再代入求和公式。
