**题目：**

某工厂的某种产品通过两条生产线生产。已知第一条生产线的合格率为 $0.9$，第二条生产线的合格率为 $0.8$。现从两条生产线的产品中各随机抽取 $1$ 件进行检验。

（1）求恰好有 $1$ 件合格品的概率；

（2）记合格品的件数为 $X$，求 $X$ 的分布列和数学期望 $E(X)$。

---

**解答：**

**（1）**

**第1步:** 分析事件

设事件 $A$ = "第一条生产线产品合格"，$P(A) = 0.9$，$P(\bar{A}) = 0.1$。

设事件 $B$ = "第二条生产线产品合格"，$P(B) = 0.8$，$P(\bar{B}) = 0.2$。

$A$ 与 $B$ 相互独立。

> 📌 运用知识点：期望与方差

**第2步:** 计算恰好 $1$ 件合格的概率

$$P(\text{恰好1件合格}) = P(A\bar{B}) + P(\bar{A}B) = P(A)P(\bar{B}) + P(\bar{A})P(B)$$

$$= 0.9 \times 0.2 + 0.1 \times 0.8 = 0.18 + 0.08 = 0.26$$

> 📌 运用知识点：期望与方差

**（2）**

**第3步:** 确定 $X$ 的可能取值和概率

$X$ 的可能取值为 $0, 1, 2$。

$$P(X = 0) = P(\bar{A}\bar{B}) = 0.1 \times 0.2 = 0.02$$

$$P(X = 1) = 0.26$$（由第（1）问）

$$P(X = 2) = P(AB) = 0.9 \times 0.8 = 0.72$$

验证：$0.02 + 0.26 + 0.72 = 1$。✓

分布列：

| $X$ | $0$ | $1$ | $2$ |
|-----|------|------|------|
| $P$ | $0.02$ | $0.26$ | $0.72$ |

> 📌 运用知识点：二项分布

**第4步:** 求 $E(X)$

$$E(X) = 0 \times 0.02 + 1 \times 0.26 + 2 \times 0.72 = 0 + 0.26 + 1.44 = 1.70$$

> 📌 运用知识点：期望与方差

**答案：**

（1）$\boxed{P = 0.26}$

（2）分布列见解答过程，$\boxed{E(X) = 1.7}$

**⚠️ 易错提醒：** 两条生产线的产品检验是相互独立事件，用独立事件的乘法公式。注意 $X$ 不是二项分布（两次抽取的成功概率不同），需要逐一计算各概率。

**💡 解题思路总结：** 独立事件的概率计算：（1）"恰好"问题分类讨论（互斥事件加法）；（2）分布列逐一计算各概率并验证总和为 $1$；（3）期望用定义公式。
