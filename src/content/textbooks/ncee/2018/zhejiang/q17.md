**题目：**

已知函数 $f(x) = 2\sin(\omega x + \varphi)$（$\omega > 0$，$0 < \varphi < \pi$）的图像相邻两条对称轴之间的距离为 $\pi$，且图像过点 $\left(\dfrac{\pi}{6}, \sqrt{3}\right)$。

（1）求 $\omega$ 和 $\varphi$ 的值；

（2）求 $f(x)$ 在 $\left[0, \dfrac{\pi}{2}\right]$ 上的值域。

---

**解答：**

**（1）**

**第1步:** 由对称轴间距求 $\omega$

正弦函数相邻两条对称轴之间的距离为半个周期：

$$\frac{T}{2} = \pi \implies T = 2\pi$$

$$\omega = \frac{2\pi}{T} = \frac{2\pi}{2\pi} = 1$$

> 📌 运用知识点：三角函数的图像

**第2步:** 由过点条件求 $\varphi$

$f(x) = 2\sin(x + \varphi)$，过点 $\left(\dfrac{\pi}{6}, \sqrt{3}\right)$：

$$2\sin\left(\frac{\pi}{6} + \varphi\right) = \sqrt{3}$$

$$\sin\left(\frac{\pi}{6} + \varphi\right) = \frac{\sqrt{3}}{2}$$

因为 $0 < \varphi < \pi$，所以 $\dfrac{\pi}{6} < \dfrac{\pi}{6} + \varphi < \dfrac{7\pi}{6}$。

$$\frac{\pi}{6} + \varphi = \frac{\pi}{3} \implies \varphi = \frac{\pi}{6}$$

或 $\dfrac{\pi}{6} + \varphi = \dfrac{2\pi}{3} \implies \varphi = \dfrac{\pi}{2}$。

两个解都满足 $0 < \varphi < \pi$。

取 $\varphi = \dfrac{\pi}{6}$（或 $\varphi = \dfrac{\pi}{2}$，根据题意选择）。

取 $\varphi = \dfrac{\pi}{6}$。

> 📌 运用知识点：三角函数

**（2）**

**第3步:** 确定 $f(x)$

$f(x) = 2\sin\left(x + \dfrac{\pi}{6}\right)$。

当 $x \in \left[0, \dfrac{\pi}{2}\right]$ 时：

$$x + \frac{\pi}{6} \in \left[\frac{\pi}{6}, \frac{2\pi}{3}\right]$$

> 📌 运用知识点：三角函数的图像

**第4步:** 求值域

在 $\left[\dfrac{\pi}{6}, \dfrac{2\pi}{3}\right]$ 上：

$\sin$ 在 $\dfrac{\pi}{2}$ 处取最大值 $1$，$\dfrac{\pi}{2} \in \left[\dfrac{\pi}{6}, \dfrac{2\pi}{3}\right]$。✓

$\sin\dfrac{\pi}{6} = \dfrac{1}{2}$，$\sin\dfrac{2\pi}{3} = \dfrac{\sqrt{3}}{2}$。

最小值为 $\sin\dfrac{\pi}{6} = \dfrac{1}{2}$（左端点）。

$f(x)$ 的最大值 $= 2 \times 1 = 2$。

$f(x)$ 的最小值 $= 2 \times \dfrac{1}{2} = 1$。

值域为 $[1, 2]$。

> 📌 运用知识点：三角函数的图像

**答案：**

（1）$\boxed{\omega = 1, \quad \varphi = \dfrac{\pi}{6}}$

（2）$\boxed{[1, 2]}$

**⚠️ 易错提醒：** 正弦函数相邻对称轴间距是半周期（不是全周期）。求 $\varphi$ 时注意根据范围确定解的个数。求值域时要检查最值点是否在给定区间内。

**💡 解题思路总结：** 三角函数图像与性质的综合题：（1）由对称轴/零点间距确定周期和 $\omega$；（2）代入特殊点求 $\varphi$；（3）求值域先确定复合角的范围，再结合 $\sin$ 的图像分析。
