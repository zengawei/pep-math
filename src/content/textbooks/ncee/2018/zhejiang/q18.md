**题目：**

如图，在四棱锥 $P\text{-}ABCD$ 中，底面 $ABCD$ 为矩形，$PA \perp$ 底面 $ABCD$，$PA = AB = 2$，$AD = 4$，$E$ 为 $PD$ 的中点。

（1）证明：$PB \parallel$ 平面 $ACE$；

（2）求二面角 $E\text{-}AC\text{-}D$ 的余弦值。

---

**解答：**

**（1）**

**第1步:** 建立空间直角坐标系

以 $A$ 为原点，$\overrightarrow{AB}$ 为 $x$ 轴，$\overrightarrow{AD}$ 为 $y$ 轴，$\overrightarrow{AP}$ 为 $z$ 轴。

各点坐标：
- $A(0, 0, 0)$
- $B(2, 0, 0)$
- $C(2, 4, 0)$
- $D(0, 4, 0)$
- $P(0, 0, 2)$
- $E$ 为 $PD$ 中点：$E\left(0, 2, 1\right)$

> 📌 运用知识点：空间向量坐标

**第2步:** 证明 $PB \parallel$ 平面 $ACE$

$$\overrightarrow{PB} = B - P = (2, 0, -2)$$

取 $BD$ 中点 $F$：$F(1, 2, 0)$。

$$\overrightarrow{AF} = (1, 2, 0)$$

$$\overrightarrow{EF} = F - E = (1, 0, -1)$$

$\overrightarrow{PB} = (2, 0, -2) = 2(1, 0, -1) = 2\overrightarrow{EF}$

所以 $\overrightarrow{PB} \parallel \overrightarrow{EF}$。

$EF \subset$ 平面 $ACE$，$PB \not\subset$ 平面 $ACE$，所以 $PB \parallel$ 平面 $ACE$。

> 📌 运用知识点：空间向量坐标

**（2）**

**第3步:** 求平面 $EAC$ 的法向量

$$\overrightarrow{AC} = (2, 4, 0), \quad \overrightarrow{AE} = (0, 2, 1)$$

设平面 $EAC$ 的法向量 $\vec{n_1} = (x, y, z)$：

$$\begin{cases} 2x + 4y = 0 \\ 2y + z = 0 \end{cases}$$

由第一式：$x = -2y$；由第二式：$z = -2y$。

取 $y = 1$：$\vec{n_1} = (-2, 1, -2)$。

> 📌 运用知识点：空间向量坐标

**第4步:** 求平面 $ACD$ 的法向量

平面 $ACD$ 即底面（$z = 0$ 平面），法向量 $\vec{n_2} = (0, 0, 1)$。

> 📌 运用知识点：空间向量坐标

**第5步:** 求二面角的余弦值

$$\cos\theta = \frac{|\vec{n_1} \cdot \vec{n_2}|}{|\vec{n_1}||\vec{n_2}|} = \frac{|(-2)(0) + (1)(0) + (-2)(1)|}{\sqrt{4+1+4} \times 1} = \frac{2}{3}$$

> 📌 运用知识点：空间角

**答案：**

（1）证明见解答过程。

（2）$\boxed{\dfrac{2}{3}}$

**⚠️ 易错提醒：** 证明线面平行可以通过找平面内的平行线来实现。求二面角时注意判断余弦值的正负——需要观察二面角是锐角还是钝角。

**💡 解题思路总结：** 空间向量法解题：（1）线面平行——找平面内与已知直线平行的向量；（2）二面角——求两半平面的法向量，用夹角公式。
