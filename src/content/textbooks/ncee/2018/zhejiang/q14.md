**题目：**

已知函数 $f(x) = \sin\left(2x + \dfrac{\pi}{3}\right)$，则 $f\left(\dfrac{\pi}{12}\right) =$ \_\_\_\_\_\_。

---

**解答：**

**第1步:** 代入计算

$$f\left(\frac{\pi}{12}\right) = \sin\left(2 \times \frac{\pi}{12} + \frac{\pi}{3}\right) = \sin\left(\frac{\pi}{6} + \frac{\pi}{3}\right) = \sin\left(\frac{\pi}{6} + \frac{2\pi}{6}\right) = \sin\frac{\pi}{2} = 1$$

> 📌 运用知识点：三角函数

**答案：** $\boxed{1}$

**⚠️ 易错提醒：** 代入时注意 $2 \times \dfrac{\pi}{12} = \dfrac{\pi}{6}$，然后 $\dfrac{\pi}{6} + \dfrac{\pi}{3} = \dfrac{\pi}{6} + \dfrac{2\pi}{6} = \dfrac{3\pi}{6} = \dfrac{\pi}{2}$。通分计算不要出错。

**💡 解题思路总结：** 求三角函数在某点的值，直接代入化简即可。注意角度的通分和特殊角的三角函数值。
