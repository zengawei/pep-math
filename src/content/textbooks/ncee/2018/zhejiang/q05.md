**题目：**

已知 $a = \log_2 3$，$b = \log_3 2$，$c = 2^{-1}$，则

A. $a > b > c$

B. $a > c > b$

C. $b > c > a$

D. $c > a > b$

---

**解答：**

**第1步:** 估计各值的范围

$a = \log_2 3$：因为 $2^1 = 2 < 3 < 4 = 2^2$，所以 $1 < a < 2$。

$b = \log_3 2$：因为 $3^0 = 1 < 2 < 3 = 3^1$，所以 $0 < b < 1$。

$c = 2^{-1} = 0.5$。

> 📌 运用知识点：对数函数

**第2步:** 比较 $b$ 和 $c$

$b = \log_3 2$，$c = 0.5 = \log_3 3^{0.5} = \log_3 \sqrt{3}$。

因为 $\sqrt{3} \approx 1.732 < 2$，所以 $\log_3 \sqrt{3} < \log_3 2$，即 $c < b$。

因此 $a > b > c$。

> 📌 运用知识点：对数函数

**答案：A**

**⚠️ 易错提醒：** 比较对数值大小时，可以利用与 $0$、$1$ 的关系先分区间。$b$ 与 $c$ 的比较需要统一底数或利用中间量。$\sqrt{3} \approx 1.732 < 2$ 是关键。

**💡 解题思路总结：** 对数大小的比较：先用 $0$ 和 $1$ 分区间，同区间内用换底公式或统一底数比较。
