**题目：**

已知集合 $A = \{x \mid x^2 - 2x - 3 \leqslant 0\}$，$B = \{x \mid x < 2\}$，则 $A \cap B =$

A. $\{x \mid -1 \leqslant x < 2\}$

B. $\{x \mid -1 < x < 2\}$

C. $\{x \mid -1 \leqslant x \leqslant 3\}$

D. $\{x \mid 2 \leqslant x \leqslant 3\}$

---

**解答：**

**第1步:** 求集合 $A$

解不等式 $x^2 - 2x - 3 \leqslant 0$：

$$x^2 - 2x - 3 = (x-3)(x+1) \leqslant 0$$

$$A = \{x \mid -1 \leqslant x \leqslant 3\}$$

> 📌 运用知识点：集合的运算

**第2步:** 求 $A \cap B$

$$A \cap B = \{x \mid -1 \leqslant x \leqslant 3\} \cap \{x \mid x < 2\} = \{x \mid -1 \leqslant x < 2\}$$

> 📌 运用知识点：集合的运算

**答案：A**

**⚠️ 易错提醒：** 解一元二次不等式 $(x-3)(x+1) \leqslant 0$ 时，等号成立，所以端点 $-1$ 和 $3$ 都包含在集合 $A$ 中。与 $B$ 取交集后，$-1$ 保留（闭），$2$ 不保留（开）。

**💡 解题思路总结：** 集合交集运算的关键：先解不等式确定各集合，再在数轴上取公共部分。注意端点的开闭。
