已知函数 $f(x) = \begin{cases} x + 2, & x \leq 0 \\ -x + 2, & x > 0 \end{cases}$，则 $f(f(-3)) = $（）

(A) $-1$

(B) $1$

(C) $3$

(D) $-3$

---

**解题过程：**

先求 $f(-3)$：因为 $-3 \leq 0$，所以

$$f(-3) = -3 + 2 = -1$$

再求 $f(f(-3)) = f(-1)$：因为 $-1 \leq 0$，所以

$$f(-1) = -1 + 2 = 1$$

因此 $f(f(-3)) = 1$。

> 📌 运用知识点：分段函数求值

**正确答案：** (B)
