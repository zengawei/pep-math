已知椭圆 $C: \dfrac{x^2}{3} + y^2 = 1$。

（1）求椭圆 $C$ 的离心率；

（2）过点 $D(1, 0)$ 的直线 $l$ 与椭圆 $C$ 交于 $A, B$ 两点，若 $|DA| \cdot |DB| = \dfrac{4}{3}$，求直线 $l$ 的方程。

---

**解题过程：**

**（1）求离心率**

由椭圆方程 $\dfrac{x^2}{3} + y^2 = 1$，得 $a^2 = 3$，$b^2 = 1$。

$$c^2 = a^2 - b^2 = 3 - 1 = 2$$

$$e = \frac{c}{a} = \frac{\sqrt{2}}{\sqrt{3}} = \frac{\sqrt{6}}{3}$$

**（2）求直线 $l$ 的方程**

当直线 $l$ 的斜率不存在时，$l: x = 1$，代入椭圆方程得 $\dfrac{1}{3} + y^2 = 1$，$y^2 = \dfrac{2}{3}$，$y = \pm \dfrac{\sqrt{6}}{3}$。

此时 $|DA| \cdot |DB| = \dfrac{\sqrt{6}}{3} \times \dfrac{\sqrt{6}}{3} = \dfrac{6}{9} = \dfrac{2}{3} \neq \dfrac{4}{3}$，不合题意。

当直线 $l$ 的斜率存在时，设 $l: x = my + 1$（其中 $m = \dfrac{1}{k}$），代入椭圆方程：

$$\frac{(my + 1)^2}{3} + y^2 = 1$$

$$(my + 1)^2 + 3y^2 = 3$$

$$m^2 y^2 + 2my + 1 + 3y^2 = 3$$

$$(m^2 + 3)y^2 + 2my - 2 = 0$$

设 $A(x_1, y_1)$，$B(x_2, y_2)$，由韦达定理：

$$y_1 + y_2 = \frac{-2m}{m^2 + 3}, \quad y_1 y_2 = \frac{-2}{m^2 + 3}$$

因为 $A, B$ 在直线 $x = my + 1$ 上，且 $D(1, 0)$，所以

$$|DA| = \sqrt{(x_1 - 1)^2 + y_1^2} = \sqrt{m^2 y_1^2 + y_1^2} = \sqrt{m^2 + 1} \cdot |y_1|$$

同理 $|DB| = \sqrt{m^2 + 1} \cdot |y_2|$。

$$|DA| \cdot |DB| = (m^2 + 1)|y_1 y_2| = (m^2 + 1) \cdot \frac{2}{m^2 + 3}$$

令 $|DA| \cdot |DB| = \dfrac{4}{3}$：

$$\frac{2(m^2 + 1)}{m^2 + 3} = \frac{4}{3}$$

$$6(m^2 + 1) = 4(m^2 + 3)$$

$$6m^2 + 6 = 4m^2 + 12$$

$$2m^2 = 6 \implies m^2 = 3 \implies m = \pm \sqrt{3}$$

因此直线 $l$ 的方程为 $x = \pm \sqrt{3}\, y + 1$，即

$$y = \pm \frac{\sqrt{3}}{3}(x - 1)$$

**⚠️ 易错提醒：** 设直线方程时不要遗漏斜率不存在的情况。利用韦达定理时要注意判别式 $\Delta > 0$ 的验证（本题 $m^2 = 3$ 时 $\Delta = 4m^2 + 8(m^2+3) > 0$，满足条件）。

**💡 解题思路总结：** 第（1）问直接由椭圆参数求离心率。第（2）问设直线为 $x = my + 1$ 的形式（避免讨论斜率是否为 $0$），联立椭圆方程，利用韦达定理和距离公式建立关于 $m$ 的方程求解。

**答案：** （1）$e = \dfrac{\sqrt{6}}{3}$；（2）$y = \pm \dfrac{\sqrt{3}}{3}(x - 1)$
