在 $\triangle ABC$ 中，角 $A, B, C$ 的对边分别为 $a, b, c$，已知 $a = 2$，$b = 3$，$\cos C = \dfrac{1}{4}$。

（1）求 $c$ 的值；

（2）求 $\sin A$ 的值。

---

**解题过程：**

**（1）求 $c$ 的值**

由余弦定理：

$$c^2 = a^2 + b^2 - 2ab \cos C$$

代入 $a = 2$，$b = 3$，$\cos C = \dfrac{1}{4}$：

$$c^2 = 4 + 9 - 2 \times 2 \times 3 \times \frac{1}{4} = 13 - 3 = 10$$

因为 $c > 0$，所以 $c = \sqrt{10}$。

**（2）求 $\sin A$ 的值**

由 $\cos C = \dfrac{1}{4}$，且 $C \in (0, \pi)$，得

$$\sin C = \sqrt{1 - \cos^2 C} = \sqrt{1 - \frac{1}{16}} = \sqrt{\frac{15}{16}} = \frac{\sqrt{15}}{4}$$

由正弦定理 $\dfrac{a}{\sin A} = \dfrac{c}{\sin C}$，得

$$\sin A = \frac{a \sin C}{c} = \frac{2 \times \dfrac{\sqrt{15}}{4}}{\sqrt{10}} = \frac{\sqrt{15}}{2\sqrt{10}} = \frac{\sqrt{15} \cdot \sqrt{10}}{2 \times 10} = \frac{\sqrt{150}}{20} = \frac{5\sqrt{6}}{20} = \frac{\sqrt{6}}{4}$$

**⚠️ 易错提醒：** 由 $\cos C$ 求 $\sin C$ 时注意 $C \in (0, \pi)$，$\sin C > 0$，不要漏掉正号。化简 $\dfrac{\sqrt{150}}{20}$ 时注意 $\sqrt{150} = 5\sqrt{6}$。

**💡 解题思路总结：** 第（1）问直接用余弦定理求边；第（2）问先由 $\cos C$ 求 $\sin C$，再用正弦定理建立边角关系求 $\sin A$。

**答案：** （1）$c = \sqrt{10}$；（2）$\sin A = \dfrac{\sqrt{6}}{4}$
