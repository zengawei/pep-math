如图，在四棱锥 $P\text{-}ABCD$ 中，底面 $ABCD$ 是矩形，$PA \perp$ 底面 $ABCD$，$PA = AD = 2$，$AB = 4$，$M$ 是 $PD$ 的中点。

（1）求证：$PB \parallel$ 平面 $MAC$；

（2）求直线 $PC$ 与平面 $MAC$ 所成角的正弦值。

---

**解题过程：**

以 $A$ 为原点，$\overrightarrow{AB}$、$\overrightarrow{AD}$、$\overrightarrow{AP}$ 分别为 $x$、$y$、$z$ 轴正方向建立空间直角坐标系。

各点坐标为：$A(0, 0, 0)$，$B(4, 0, 0)$，$C(4, 2, 0)$，$D(0, 2, 0)$，$P(0, 0, 2)$。

$M$ 是 $PD$ 的中点，所以 $M = \left(\dfrac{0+0}{2}, \dfrac{0+2}{2}, \dfrac{2+0}{2}\right) = (0, 1, 1)$。

**（1）证明 $PB \parallel$ 平面 $MAC$**

$\overrightarrow{PB} = B - P = (4, 0, -2)$。

平面 $MAC$ 内的两个向量：

$$\overrightarrow{MA} = A - M = (0, -1, -1), \quad \overrightarrow{MC} = C - M = (4, 1, -1)$$

设平面 $MAC$ 的法向量 $\boldsymbol{n} = (x, y, z)$，则

$$\begin{cases} \boldsymbol{n} \cdot \overrightarrow{MA} = -y - z = 0 \\ \boldsymbol{n} \cdot \overrightarrow{MC} = 4x + y - z = 0 \end{cases}$$

由第一式 $z = -y$，代入第二式 $4x + y - (-y) = 4x + 2y = 0$，得 $x = -\dfrac{y}{2}$。

取 $y = -2$，则 $x = 1$，$z = 2$，所以 $\boldsymbol{n} = (1, -2, 2)$。

验证 $\overrightarrow{PB} \cdot \boldsymbol{n}$：

$$\overrightarrow{PB} \cdot \boldsymbol{n} = 4 \times 1 + 0 \times (-2) + (-2) \times 2 = 4 + 0 - 4 = 0$$

所以 $\overrightarrow{PB} \perp \boldsymbol{n}$，即 $\overrightarrow{PB}$ 平行于平面 $MAC$ 或在平面 $MAC$ 内。

又点 $P(0, 0, 2)$ 不在平面 $MAC$ 内（验证：$\overrightarrow{PM} = (0, 1, -1)$，$\overrightarrow{PM} \cdot \boldsymbol{n} = 0 - 2 - 2 = -4 \neq 0$），

因此 $PB \parallel$ 平面 $MAC$。

**（2）求直线 $PC$ 与平面 $MAC$ 所成角的正弦值**

$\overrightarrow{PC} = C - P = (4, 2, -2)$。

$|\overrightarrow{PC}| = \sqrt{16 + 4 + 4} = \sqrt{24} = 2\sqrt{6}$。

$|\boldsymbol{n}| = \sqrt{1 + 4 + 4} = 3$。

设直线 $PC$ 与平面 $MAC$ 所成角为 $\theta$，则

$$\sin \theta = \frac{|\overrightarrow{PC} \cdot \boldsymbol{n}|}{|\overrightarrow{PC}| \cdot |\boldsymbol{n}|} = \frac{|4 \times 1 + 2 \times (-2) + (-2) \times 2|}{2\sqrt{6} \times 3} = \frac{|4 - 4 - 4|}{6\sqrt{6}} = \frac{4}{6\sqrt{6}} = \frac{2}{3\sqrt{6}} = \frac{2\sqrt{6}}{18} = \frac{\sqrt{6}}{9}$$

**⚠️ 易错提醒：** 证明线面平行时，除了验证 $\overrightarrow{PB} \cdot \boldsymbol{n} = 0$，还需说明点 $P$（或 $B$）不在平面 $MAC$ 内。求线面角用的是 $\sin \theta = \dfrac{|\overrightarrow{PC} \cdot \boldsymbol{n}|}{|\overrightarrow{PC}| \cdot |\boldsymbol{n}|}$，不要与向量夹角公式混淆。

**💡 解题思路总结：** 建立空间直角坐标系，用向量法处理立体几何问题。第（1）问验证方向向量与法向量垂直且点不在平面内；第（2）问用线面角公式求解。

**答案：** （1）证明见上；（2）$\sin \theta = \dfrac{\sqrt{6}}{9}$
