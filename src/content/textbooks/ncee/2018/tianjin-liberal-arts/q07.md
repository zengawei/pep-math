已知 $\sin \alpha + \cos \alpha = \dfrac{1}{2}$，则 $\sin 2\alpha = $（）

(A) $-\dfrac{3}{4}$

(B) $\dfrac{3}{4}$

(C) $-\dfrac{3}{8}$

(D) $\dfrac{3}{8}$

---

**解题过程：**

将等式 $\sin \alpha + \cos \alpha = \dfrac{1}{2}$ 两边平方：

$$(\sin \alpha + \cos \alpha)^2 = \frac{1}{4}$$

展开左边：

$$\sin^2 \alpha + 2\sin \alpha \cos \alpha + \cos^2 \alpha = \frac{1}{4}$$

因为 $\sin^2 \alpha + \cos^2 \alpha = 1$，且 $2\sin \alpha \cos \alpha = \sin 2\alpha$，所以

$$1 + \sin 2\alpha = \frac{1}{4}$$

$$\sin 2\alpha = \frac{1}{4} - 1 = -\frac{3}{4}$$

> 📌 运用知识点：二倍角公式

**正确答案：** (A)
