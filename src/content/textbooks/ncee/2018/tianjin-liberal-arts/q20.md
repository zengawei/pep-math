已知函数 $f(x) = x^3 - 3x + a$（$a \in \mathbb{R}$）。

（1）当 $a = 0$ 时，求 $f(x)$ 的极值；

（2）若 $f(x)$ 在 $[-2, 2]$ 上的最大值为 $4$，求 $a$ 的值。

---

**解题过程：**

$$f'(x) = 3x^2 - 3 = 3(x^2 - 1) = 3(x + 1)(x - 1)$$

**（1）当 $a = 0$ 时，求 $f(x)$ 的极值**

当 $a = 0$ 时，$f(x) = x^3 - 3x$。

令 $f'(x) = 0$，得 $x = -1$ 或 $x = 1$。

列表分析：

| $x$ | $(-\infty, -1)$ | $-1$ | $(-1, 1)$ | $1$ | $(1, +\infty)$ |
|:---:|:---:|:---:|:---:|:---:|:---:|
| $f'(x)$ | $+$ | $0$ | $-$ | $0$ | $+$ |
| $f(x)$ | $\nearrow$ | 极大值 | $\searrow$ | 极小值 | $\nearrow$ |

极大值：$f(-1) = (-1)^3 - 3 \times (-1) = -1 + 3 = 2$。

极小值：$f(1) = 1^3 - 3 \times 1 = 1 - 3 = -2$。

**（2）求 $a$ 的值**

$f(x)$ 在 $[-2, 2]$ 上的最大值需要在端点和极值点处比较。

计算各关键点的函数值：

$$f(-2) = (-2)^3 - 3 \times (-2) + a = -8 + 6 + a = -2 + a$$

$$f(-1) = (-1)^3 - 3 \times (-1) + a = -1 + 3 + a = 2 + a$$

$$f(1) = 1^3 - 3 \times 1 + a = 1 - 3 + a = -2 + a$$

$$f(2) = 2^3 - 3 \times 2 + a = 8 - 6 + a = 2 + a$$

比较得最大值为 $2 + a$。

令 $2 + a = 4$，解得 $a = 2$。

**⚠️ 易错提醒：** 求闭区间上的最大值时，必须比较所有极值点和端点的函数值，不能遗漏。本题 $f(-1) = f(2) = 2 + a$，两个点同时取到最大值。

**💡 解题思路总结：** 第（1）问用导数判断单调性，列表求极值。第（2）问在闭区间上比较端点值和极值点的函数值，找出最大值表达式，列方程求 $a$。

**答案：** （1）极大值 $f(-1) = 2$，极小值 $f(1) = -2$；（2）$a = 2$
