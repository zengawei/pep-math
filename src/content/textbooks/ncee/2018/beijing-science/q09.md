**题目：** 已知 $\sin\left(\alpha + \dfrac{\pi}{4}\right) = \dfrac{\sqrt{2}}{4}$，则 $\sin 2\alpha =$ ______。

---

**解答：**

**第1步：** 展开并平方
> 📌 运用知识点：三角恒等变换

$$\sin\left(\alpha + \frac{\pi}{4}\right) = \frac{\sin\alpha + \cos\alpha}{\sqrt{2}} = \frac{\sqrt{2}}{4}$$

$$\sin\alpha + \cos\alpha = \frac{1}{2}$$

两边平方：$1 + 2\sin\alpha\cos\alpha = \dfrac{1}{4}$，即 $1 + \sin 2\alpha = \dfrac{1}{4}$。

$$\sin 2\alpha = -\frac{3}{4}$$

**答案：** $-\dfrac{3}{4}$
