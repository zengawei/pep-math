**题目：**

已知椭圆 $C: \dfrac{x^2}{4} + y^2 = 1$，过点 $P(1, 0)$ 的直线 $l$ 与椭圆 $C$ 交于 $A$，$B$ 两点。

（1）若 $l$ 的斜率为 $1$，求 $|AB|$；

（2）求 $\triangle OAB$ 面积的最大值（$O$ 为原点）。

---

**解答：**

**（1）求 $|AB|$**

**第1步：** 联立方程
> 📌 运用知识点：圆锥曲线与直线

$l: y = x - 1$。代入椭圆：

$$\frac{x^2}{4} + (x-1)^2 = 1 \implies \frac{5x^2}{4} - 2x = 0 \implies x = 0 \text{ 或 } x = \frac{8}{5}$$

$A(0, -1)$，$B\left(\dfrac{8}{5}, \dfrac{3}{5}\right)$。

$$|AB| = \sqrt{\frac{64}{25} + \frac{64}{25}} = \frac{8\sqrt{2}}{5}$$

---

**（2）求面积最大值**

**第2步：** 斜率存在时
> 📌 运用知识点：圆锥曲线综合

设 $l: y = k(x - 1)$。代入椭圆：$(1 + 4k^2)x^2 - 8k^2 x + 4k^2 - 4 = 0$。

原点 $O$ 到 $l$ 的距离 $d = \dfrac{|k|}{\sqrt{1 + k^2}}$。

经计算面积 $S = \dfrac{2|k|\sqrt{3k^2 + 1}}{1 + 4k^2}$。

**第3步：** 竖直线情况
> 📌 运用知识点：圆锥曲线综合

$l: x = 1$ 时：$y^2 = \dfrac{3}{4}$，$y = \pm\dfrac{\sqrt{3}}{2}$。

$$S = \frac{1}{2} \times \sqrt{3} \times 1 = \frac{\sqrt{3}}{2}$$

**第4步：** 比较

对斜率情况，令 $t = k^2$，$S^2 = \dfrac{4t(3t+1)}{(1+4t)^2}$。$S^2$ 关于 $t$ 递增，$\lim_{t \to +\infty} S^2 = \dfrac{3}{4}$。

所以 $S < \dfrac{\sqrt{3}}{2}$（斜率存在时）。最大值在竖直线时取得。

**答案：**（1）$|AB| = \dfrac{8\sqrt{2}}{5}$；（2）面积最大值为 $\dfrac{\sqrt{3}}{2}$。

**⚠️ 易错提醒：** 面积最大值在直线垂直于 $x$ 轴时取得，不能只分析斜率存在的情况而遗漏。

**💡 解题思路总结：** 圆锥曲线面积问题需分斜率存在和不存在两种情况讨论，比较后确定最大值。
