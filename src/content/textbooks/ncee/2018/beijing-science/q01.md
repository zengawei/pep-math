**题目：** 已知全集 $U = \mathbb{R}$，集合 $A = \{x \mid x < -1 \text{ 或 } x > 2\}$，$B = \{x \mid 0 \leqslant x \leqslant 3\}$，则 $(\complement_U A) \cap B =$（）

A. $\{x \mid 0 \leqslant x \leqslant 2\}$

B. $\{x \mid -1 \leqslant x \leqslant 3\}$

C. $\{x \mid 0 \leqslant x < 2\}$

D. $\{x \mid -1 < x \leqslant 3\}$

---

**解答：**

**第1步：** 求补集
> 📌 运用知识点：集合运算

$\complement_U A = [-1, 2]$。

**第2步：** 求交集

$[-1, 2] \cap [0, 3] = [0, 2]$。

**答案：** A
