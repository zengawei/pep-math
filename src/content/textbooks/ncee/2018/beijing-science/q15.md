**题目：**

在 $\triangle ABC$ 中，$a$，$b$，$c$ 分别为角 $A$，$B$，$C$ 的对边，已知 $b\sin A = \sqrt{3}a\cos B$。

（1）求角 $B$ 的大小；

（2）若 $b = 2\sqrt{3}$，$a + c = 4$，求 $\triangle ABC$ 的面积。

---

**解答：**

**（1）求角 $B$**

**第1步：** 运用正弦定理
> 📌 运用知识点：正弦定理

由正弦定理 $b\sin A = a\sin B$，代入已知：

$$a\sin B = \sqrt{3}a\cos B \implies \tan B = \sqrt{3}$$

因为 $B \in (0, \pi)$，所以 $B = \dfrac{\pi}{3}$。

---

**（2）求面积**

**第2步：** 运用余弦定理
> 📌 运用知识点：余弦定理

$$b^2 = a^2 + c^2 - 2ac\cos B$$

$$12 = (a + c)^2 - 2ac - 2ac \cdot \frac{1}{2} = 16 - 3ac$$

$$ac = \frac{4}{3}$$

**第3步：** 计算面积

$$S = \frac{1}{2}ac\sin B = \frac{1}{2} \times \frac{4}{3} \times \frac{\sqrt{3}}{2} = \frac{\sqrt{3}}{3}$$

**答案：**（1）$B = \dfrac{\pi}{3}$；（2）$S = \dfrac{\sqrt{3}}{3}$。

**⚠️ 易错提醒：** 正弦定理将 $b\sin A$ 化为 $a\sin B$ 是关键步骤；余弦定理中 $a^2 + c^2 = (a+c)^2 - 2ac$ 的代换不要出错。

**💡 解题思路总结：** 正弦定理化边角关系求角；余弦定理结合已知条件求 $ac$，再用面积公式。
