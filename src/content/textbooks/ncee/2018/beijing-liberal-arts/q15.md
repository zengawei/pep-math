**题目：** 已知函数 $f(x) = 2\sin x \cos x + 2\sqrt{3}\cos^2 x - \sqrt{3}$。

（1）求 $f(x)$ 的最小正周期和单调递增区间；

（2）当 $x \in \left[-\dfrac{\pi}{6},\, \dfrac{\pi}{3}\right]$ 时，求 $f(x)$ 的最大值和最小值。

---

**解答：**

**第1步：** 化简函数
> 📌 运用知识点：二倍角公式、辅助角公式

$$f(x) = 2\sin x\cos x + 2\sqrt{3}\cos^2 x - \sqrt{3}$$

利用二倍角公式 $\sin 2x = 2\sin x\cos x$，$2\cos^2 x = 1 + \cos 2x$：

$$f(x) = \sin 2x + \sqrt{3}(1 + \cos 2x) - \sqrt{3} = \sin 2x + \sqrt{3}\cos 2x$$

利用辅助角公式：

$$f(x) = 2\left(\frac{1}{2}\sin 2x + \frac{\sqrt{3}}{2}\cos 2x\right) = 2\sin\!\left(2x + \frac{\pi}{3}\right)$$

**第2步：** 求最小正周期和单调递增区间
> 📌 运用知识点：三角函数周期性

最小正周期 $T = \dfrac{2\pi}{2} = \pi$。

单调递增区间：令 $-\dfrac{\pi}{2} + 2k\pi \leqslant 2x + \dfrac{\pi}{3} \leqslant \dfrac{\pi}{2} + 2k\pi$（$k \in \mathbb{Z}$），

解得 $-\dfrac{5\pi}{12} + k\pi \leqslant x \leqslant \dfrac{\pi}{12} + k\pi$（$k \in \mathbb{Z}$）。

所以单调递增区间为 $\left[-\dfrac{5\pi}{12} + k\pi,\; \dfrac{\pi}{12} + k\pi\right]$（$k \in \mathbb{Z}$）。

**第3步：** 求给定区间上的最值
> 📌 运用知识点：三角函数值域

当 $x \in \left[-\dfrac{\pi}{6},\, \dfrac{\pi}{3}\right]$ 时，

$$2x + \frac{\pi}{3} \in \left[0,\; \pi\right]$$

在 $[0, \pi]$ 上，$\sin\!\left(2x + \dfrac{\pi}{3}\right)$ 的最大值为 $1$（当 $2x + \dfrac{\pi}{3} = \dfrac{\pi}{2}$ 即 $x = \dfrac{\pi}{12}$ 时取到），最小值为 $0$（当 $2x + \dfrac{\pi}{3} = 0$ 或 $\pi$ 时取到）。

所以 $f(x)$ 的最大值为 $2 \times 1 = 2$，最小值为 $2 \times 0 = 0$。

**⚠️ 易错提醒：** 化简时容易漏掉常数项 $\sqrt{3}$ 的消去；求最值时注意确定 $2x + \dfrac{\pi}{3}$ 的范围，不能直接套公式。

**💡 解题思路总结：** 先用二倍角公式和辅助角公式将函数化为 $A\sin(\omega x + \varphi)$ 的标准形式，再利用正弦函数的性质求周期、单调区间和最值。
