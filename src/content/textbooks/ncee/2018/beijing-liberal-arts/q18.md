**题目：** 已知椭圆 $C: \dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$）的离心率为 $\dfrac{\sqrt{3}}{2}$，且过点 $(2,\, 1)$。

（1）求椭圆 $C$ 的方程；

（2）设直线 $l$ 过点 $M(0,\, 1)$ 与椭圆 $C$ 交于 $A$，$B$ 两点，求 $\triangle OAB$（$O$ 为原点）面积的最大值。

---

**解答：**

**第1步：** 利用离心率条件
> 📌 运用知识点：椭圆离心率

$e = \dfrac{c}{a} = \dfrac{\sqrt{3}}{2}$，所以 $c^2 = \dfrac{3}{4}a^2$。

又 $b^2 = a^2 - c^2 = a^2 - \dfrac{3}{4}a^2 = \dfrac{1}{4}a^2$。

**第2步：** 代入已知点求方程
> 📌 运用知识点：椭圆标准方程

椭圆过点 $(2, 1)$，代入 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$：

$$\frac{4}{a^2} + \frac{1}{b^2} = 1$$

将 $b^2 = \dfrac{a^2}{4}$ 代入：

$$\frac{4}{a^2} + \frac{4}{a^2} = 1 \implies \frac{8}{a^2} = 1 \implies a^2 = 8$$

$b^2 = \dfrac{8}{4} = 2$。

椭圆方程为 $\dfrac{x^2}{8} + \dfrac{y^2}{2} = 1$。

**第3步：** 设直线方程并联立
> 📌 运用知识点：直线与椭圆的位置关系

直线 $l$ 过 $M(0, 1)$。

**情况一：** 直线斜率不存在时，$l: x = 0$，代入椭圆方程得 $y^2 = 2$，$y = \pm\sqrt{2}$。

$A(0, \sqrt{2})$，$B(0, -\sqrt{2})$，但 $M(0,1)$ 在 $AB$ 上，$O$ 也在 $x=0$ 上，三点共线，面积为 $0$。

**情况二：** 设直线 $l: y = kx + 1$，代入椭圆方程：

$$\frac{x^2}{8} + \frac{(kx+1)^2}{2} = 1$$

$$x^2 + 4(kx+1)^2 = 8$$

$$x^2 + 4k^2x^2 + 8kx + 4 = 8$$

$$(1 + 4k^2)x^2 + 8kx - 4 = 0$$

设 $A(x_1, y_1)$，$B(x_2, y_2)$，由韦达定理：

$$x_1 + x_2 = \frac{-8k}{1 + 4k^2}, \quad x_1 x_2 = \frac{-4}{1 + 4k^2}$$

**第4步：** 求面积最大值
> 📌 运用知识点：三角形面积、均值不等式

$\triangle OAB$ 的面积：

$$S = \frac{1}{2}|OM| \cdot |x_1 - x_2|$$

其中 $|OM| = 1$（$M$ 到原点的距离在 $y$ 轴上的投影，这里 $O$ 到直线 $l$ 的距离需要重新计算）。

$O$ 到直线 $kx - y + 1 = 0$ 的距离 $d = \dfrac{|1|}{\sqrt{k^2 + 1}} = \dfrac{1}{\sqrt{k^2 + 1}}$。

$$|AB| = \sqrt{1 + k^2} \cdot |x_1 - x_2|$$

$$(x_1 - x_2)^2 = (x_1 + x_2)^2 - 4x_1 x_2 = \frac{64k^2}{(1+4k^2)^2} + \frac{16}{1+4k^2} = \frac{64k^2 + 16(1+4k^2)}{(1+4k^2)^2} = \frac{64k^2 + 16 + 64k^2}{(1+4k^2)^2} = \frac{128k^2 + 16}{(1+4k^2)^2}$$

$$= \frac{16(8k^2 + 1)}{(1+4k^2)^2}$$

$$|x_1 - x_2| = \frac{4\sqrt{8k^2+1}}{1+4k^2}$$

$$S = \frac{1}{2} \cdot d \cdot |AB| = \frac{1}{2} \cdot \frac{1}{\sqrt{k^2+1}} \cdot \sqrt{1+k^2} \cdot \frac{4\sqrt{8k^2+1}}{1+4k^2} = \frac{2\sqrt{8k^2+1}}{1+4k^2}$$

令 $t = 4k^2 \geqslant 0$，则 $8k^2 = 2t$：

$$S = \frac{2\sqrt{2t+1}}{1+t}$$

令 $u = \sqrt{2t+1} \geqslant 1$，则 $t = \dfrac{u^2 - 1}{2}$，$1 + t = \dfrac{u^2 + 1}{2}$：

$$S = \frac{2u}{\frac{u^2+1}{2}} = \frac{4u}{u^2+1}$$

对 $f(u) = \dfrac{4u}{u^2+1}$ 求最大值（$u \geqslant 1$）：

$$f'(u) = \frac{4(u^2+1) - 4u \cdot 2u}{(u^2+1)^2} = \frac{4 - 4u^2}{(u^2+1)^2}$$

当 $u = 1$ 时 $f'(u) = 0$，当 $u > 1$ 时 $f'(u) < 0$，所以 $f(u)$ 在 $u \geqslant 1$ 上单调递减。

$f(1) = \dfrac{4}{2} = 2$。

所以 $S$ 的最大值为 $2$，当 $u = 1$ 即 $k = 0$ 时取到。

当 $k = 0$ 时，直线 $l: y = 1$，代入椭圆得 $\dfrac{x^2}{8} + \dfrac{1}{2} = 1$，$x^2 = 4$，$x = \pm 2$。

$A(-2, 1)$，$B(2, 1)$，$|AB| = 4$，$d = 1$，$S = \dfrac{1}{2} \times 4 \times 1 = 2$。✓

**答案：** $\triangle OAB$ 面积的最大值为 $2$。

**⚠️ 易错提醒：** 联立直线与椭圆方程时容易算错系数；求面积时注意用 $O$ 到直线的距离而非 $|OM|$；换元后要注意新变量的取值范围。

**💡 解题思路总结：** 先用离心率和已知点求椭圆方程；再将直线与椭圆联立，利用韦达定理和弦长公式表示面积，通过换元和求导（或均值不等式）求最值。
