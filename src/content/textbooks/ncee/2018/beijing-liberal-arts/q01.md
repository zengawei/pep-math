**题目：** 已知集合 $A = \{0, 1, 2, 3\}$，$B = \{x \mid x^2 \leqslant 4\}$，则 $A \cap B =$（）

A. $\{0, 1, 2\}$

B. $\{0, 1, 2, 3\}$

C. $\{-2, -1, 0, 1, 2\}$

D. $\{1, 2\}$

---

**解答：**

**第1步：** 求交集
> 📌 运用知识点：集合运算

$B = [-2, 2]$。$A \cap B = \{0, 1, 2\}$。

**答案：** A
