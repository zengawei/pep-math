**题目：** 已知数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n$，且满足 $S_n = 2a_n - 2$（$n \in \mathbb{N}^*$）。

（1）求数列 $\{a_n\}$ 的通项公式；

（2）设 $b_n = \dfrac{a_n}{(a_n - 1)(a_{n+1} - 1)}$，求数列 $\{b_n\}$ 的前 $n$ 项和 $T_n$。

---

**解答：**

**第1步：** 求 $a_1$
> 📌 运用知识点：前 $n$ 项和与通项的关系

当 $n = 1$ 时，$S_1 = a_1 = 2a_1 - 2$，解得 $a_1 = 2$。

**第2步：** 求递推关系
> 📌 运用知识点：数列递推公式

当 $n \geqslant 2$ 时，$a_n = S_n - S_{n-1}$：

$$a_n = (2a_n - 2) - (2a_{n-1} - 2) = 2a_n - 2a_{n-1}$$

$$a_n = 2a_{n-1}$$

所以 $\dfrac{a_n}{a_{n-1}} = 2$（$n \geqslant 2$），即 $\{a_n\}$ 是以 $2$ 为首项、$2$ 为公比的等比数列。

**第3步：** 写出通项公式

$$a_n = 2 \times 2^{n-1} = 2^n$$

验证：$S_n = 2 + 4 + \cdots + 2^n = \dfrac{2(2^n - 1)}{2 - 1} = 2^{n+1} - 2 = 2 \cdot 2^n - 2 = 2a_n - 2$。✓

**第4步：** 求 $b_n$ 的表达式
> 📌 运用知识点：裂项求和

$a_n = 2^n$，$a_n - 1 = 2^n - 1$，$a_{n+1} - 1 = 2^{n+1} - 1$。

$$b_n = \frac{2^n}{(2^n - 1)(2^{n+1} - 1)}$$

尝试裂项：设 $\dfrac{2^n}{(2^n - 1)(2^{n+1} - 1)} = \dfrac{A}{2^n - 1} - \dfrac{B}{2^{n+1} - 1}$。

通分：$A(2^{n+1} - 1) - B(2^n - 1) = 2^n$。

令 $2^n = t$：$A(2t - 1) - B(t - 1) = t$。

$(2A - B)t + (-A + B) = t$。

比较系数：$2A - B = 1$，$-A + B = 0$。

由第二式 $A = B$，代入第一式 $2A - A = 1$，$A = 1$，$B = 1$。

$$b_n = \frac{1}{2^n - 1} - \frac{1}{2^{n+1} - 1}$$

**第5步：** 求前 $n$ 项和 $T_n$
> 📌 运用知识点：裂项相消

$$T_n = \sum_{k=1}^{n} b_k = \sum_{k=1}^{n} \left(\frac{1}{2^k - 1} - \frac{1}{2^{k+1} - 1}\right)$$

裂项相消：

$$T_n = \left(\frac{1}{2^1 - 1} - \frac{1}{2^2 - 1}\right) + \left(\frac{1}{2^2 - 1} - \frac{1}{2^3 - 1}\right) + \cdots + \left(\frac{1}{2^n - 1} - \frac{1}{2^{n+1} - 1}\right)$$

$$T_n = 1 - \frac{1}{2^{n+1} - 1}$$

$$T_n = \frac{2^{n+1} - 2}{2^{n+1} - 1}$$

**⚠️ 易错提醒：** 由 $S_n$ 求 $a_n$ 时必须分 $n = 1$ 和 $n \geqslant 2$ 两种情况讨论，并验证 $n = 1$ 时是否与通项公式一致；裂项时注意系数的确定，消项后不要遗漏首尾项。

**💡 解题思路总结：** 第（1）问利用 $a_n = S_n - S_{n-1}$ 将前 $n$ 项和条件转化为递推关系，识别出等比数列求通项；第（2）问通过待定系数法进行裂项，再利用裂项相消求和。
