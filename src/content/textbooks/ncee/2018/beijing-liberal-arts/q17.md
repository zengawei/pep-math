**题目：** 某学校为了解高三学生的数学学习情况，从全年级 $400$ 名学生中随机抽取了 $20$ 名学生，统计他们某次数学测试的成绩（满分 $150$ 分），将数据分组后得到如下频率分布表：

| 成绩区间 | 频数 | 频率 |
|:---:|:---:|:---:|
| $[60, 80)$ | $2$ | $0.10$ |
| $[80, 100)$ | $4$ | $a$ |
| $[100, 120)$ | $b$ | $0.40$ |
| $[120, 140)$ | $6$ | $0.30$ |
| $[140, 150]$ | $2$ | $0.10$ |

（1）求 $a$，$b$ 的值；

（2）从成绩在 $[60, 80)$ 和 $[140, 150]$ 两个区间的学生中各随机抽取 $1$ 人，求这 $2$ 人的成绩之差大于 $50$ 分的概率。

---

**解答：**

**第1步：** 求 $a$，$b$ 的值
> 📌 运用知识点：频率分布表

样本总数为 $20$，各区间频数之和等于 $20$：

$$2 + 4 + b + 6 + 2 = 20 \implies b = 6$$

频率 $a = \dfrac{4}{20} = 0.20$。

验证：$0.10 + 0.20 + 0.30 + 0.30 + 0.10 = 1.00$ ✓

所以 $a = 0.20$，$b = 6$。

**第2步：** 分析概率问题
> 📌 运用知识点：古典概型

$[60, 80)$ 区间有 $2$ 人，记为 $A_1, A_2$；$[140, 150]$ 区间有 $2$ 人，记为 $B_1, B_2$。

从两个区间各取 $1$ 人，基本事件总数为 $2 \times 2 = 4$。

设事件 $C$ 为"两人成绩之差大于 $50$ 分"。

$A$ 区间的成绩范围为 $[60, 80)$，$B$ 区间的成绩范围为 $[140, 150]$。

对于任意 $A$ 区间学生成绩 $x_A \in [60, 80)$ 和 $B$ 区间学生成绩 $x_B \in [140, 150]$：

$$x_B - x_A > 140 - 80 = 60 > 50$$

即 $B$ 区间最低分 $140$ 减去 $A$ 区间最高分（接近 $80$）仍大于 $50$。

所以无论怎样选取，两人成绩之差一定大于 $50$ 分。

因此 $P(C) = \dfrac{4}{4} = 1$。

等等，这太特殊了。让我重新审视——题目要求成绩之差大于 $50$ 分，而 $140 - 80 = 60 > 50$，确实所有组合都满足。

所以 $P(C) = 1$。

**⚠️ 易错提醒：** 注意频率之和必须为 $1$，频数之和必须等于样本总数，两者都要验证。计算概率时要仔细分析成绩范围，不能想当然。

**💡 解题思路总结：** 先利用频率分布表的性质（频率之和为 $1$，频数之和为样本数）求未知量；再列举基本事件，分析满足条件的情况数，用古典概型公式求概率。
