**题目：** 已知数列 $\{a_n\}$ 满足 $a_1 = 1$，$a_{n+1} = \dfrac{a_n}{1 + 2a_n}$（$n \geq 1$）。

（1）设 $b_n = \dfrac{1}{a_n}$，证明 $\{b_n\}$ 是等差数列，并求 $\{a_n\}$ 的通项公式；

（2）设 $c_n = \dfrac{1}{b_n \cdot b_{n+1}}$，求数列 $\{c_n\}$ 的前 $n$ 项和 $T_n$。

---

**解答：**

**第1步：** 证明 $\{b_n\}$ 是等差数列（第1问）
> 📌 运用知识点：等差数列

$$b_{n+1} = \frac{1}{a_{n+1}} = \frac{1 + 2a_n}{a_n} = \frac{1}{a_n} + 2 = b_n + 2$$

因此 $b_{n+1} - b_n = 2$（常数），$\{b_n\}$ 是等差数列，公差 $d = 2$。

**第2步：** 求通项公式

$$b_1 = \frac{1}{a_1} = 1$$

$$b_n = b_1 + (n-1)d = 1 + (n-1) \times 2 = 2n - 1$$

$$a_n = \frac{1}{b_n} = \frac{1}{2n-1}$$

**第3步：** 求 $T_n$（第2问）
> 📌 运用知识点：数列求和（裂项法）

$$c_n = \frac{1}{b_n \cdot b_{n+1}} = \frac{1}{(2n-1)(2n+1)}$$

利用裂项：

$$c_n = \frac{1}{2}\left(\frac{1}{2n-1} - \frac{1}{2n+1}\right)$$

**第4步：** 求和

$$T_n = \sum_{k=1}^{n} c_k = \frac{1}{2}\left[\left(\frac{1}{1} - \frac{1}{3}\right) + \left(\frac{1}{3} - \frac{1}{5}\right) + \cdots + \left(\frac{1}{2n-1} - \frac{1}{2n+1}\right)\right]$$

中间项逐项消去（裂项相消）：

$$T_n = \frac{1}{2}\left(1 - \frac{1}{2n+1}\right) = \frac{1}{2} \cdot \frac{2n}{2n+1} = \frac{n}{2n+1}$$

**⚠️ 易错提醒：** 第1问中取倒数是关键变换，要注意 $a_{n+1} = \dfrac{a_n}{1+2a_n}$ 两边取倒数后化简的过程。第2问裂项时系数 $\dfrac{1}{2}$ 容易遗漏，要验证 $\dfrac{1}{2}\left(\dfrac{1}{2n-1} - \dfrac{1}{2n+1}\right) = \dfrac{1}{(2n-1)(2n+1)}$ 是否正确。

**💡 解题思路总结：** 递推关系 $a_{n+1} = \dfrac{a_n}{1+2a_n}$ 是分式型递推，标准处理方法是取倒数转化为等差数列。裂项求和的核心是 $c_n = \dfrac{1}{(2n-1)(2n+1)} = \dfrac{1}{2}\left(\dfrac{1}{2n-1} - \dfrac{1}{2n+1}\right)$，相邻项相消后只剩首尾。

**答案：** （1）$a_n = \dfrac{1}{2n-1}$；（2）$T_n = \dfrac{n}{2n+1}$
