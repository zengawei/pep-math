**题目：** 在 $\triangle ABC$ 中，角 $A, B, C$ 的对边分别为 $a, b, c$，已知 $c = 2$，$C = \dfrac{\pi}{3}$，$\triangle ABC$ 的面积为 $\sqrt{3}$。

（1）求 $a, b$ 的值；

（2）求 $\sin(A + B)$ 的值。

---

**解答：**

**第1步：** 利用面积公式（第1问）
> 📌 运用知识点：三角函数

$$S = \frac{1}{2}ab\sin C = \frac{1}{2}ab\sin\frac{\pi}{3} = \frac{1}{2}ab \cdot \frac{\sqrt{3}}{2} = \frac{\sqrt{3}}{4}ab = \sqrt{3}$$

$$ab = 4$$

**第2步：** 利用余弦定理
> 📌 运用知识点：三角恒等变换

$$c^2 = a^2 + b^2 - 2ab\cos C$$

$$4 = a^2 + b^2 - 2 \times 4 \times \frac{1}{2} = a^2 + b^2 - 4$$

$$a^2 + b^2 = 8$$

**第3步：** 联立求 $a, b$

$$(a+b)^2 = a^2 + b^2 + 2ab = 8 + 8 = 16 \implies a + b = 4$$

由 $a + b = 4$，$ab = 4$，$a, b$ 是方程 $t^2 - 4t + 4 = 0$ 的两个根：

$$(t-2)^2 = 0 \implies t = 2$$

因此 $a = b = 2$。

**第4步：** 求 $\sin(A+B)$（第2问）
> 📌 运用知识点：三角恒等变换

在三角形中 $A + B + C = \pi$，所以 $A + B = \pi - C$：

$$\sin(A+B) = \sin(\pi - C) = \sin C = \sin\frac{\pi}{3} = \frac{\sqrt{3}}{2}$$

**⚠️ 易错提醒：** 第1问中利用 $(a+b)^2 = a^2+b^2+2ab$ 的整体代换是关键技巧，不要试图分别解 $a$ 和 $b$。第2问中注意 $A+B = \pi - C$ 的转化，不要直接去求角 $A$ 和角 $B$。

**💡 解题思路总结：** 三角形中已知一角及其对边和面积，标准思路是：面积公式求 $ab$，余弦定理求 $a^2+b^2$，再利用完全平方公式求 $a+b$。第二问利用三角形内角和关系直接转化。

**答案：** （1）$a = b = 2$；（2）$\sin(A+B) = \dfrac{\sqrt{3}}{2}$
