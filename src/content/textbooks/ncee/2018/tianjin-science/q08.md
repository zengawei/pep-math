**题目：** 已知函数 $f(x) = x^3 + \sin x + 1$，若 $f(a) = 2$，则 $f(-a) = $（）

(A) $0$

(B) $-1$

(C) $-2$

(D) $1$

---

**解答：**

**第1步：** 分析函数的结构
> 📌 运用知识点：函数的概念与性质

将 $f(x)$ 分解为奇函数部分和常数部分：

$$f(x) = \underbrace{x^3 + \sin x}_{g(x)} + 1$$

其中 $g(x) = x^3 + \sin x$ 是奇函数，因为：

$$g(-x) = (-x)^3 + \sin(-x) = -x^3 - \sin x = -g(x)$$

**第2步：** 利用已知条件

$$f(a) = g(a) + 1 = 2 \implies g(a) = 1$$

即 $a^3 + \sin a = 1$。

**第3步：** 计算 $f(-a)$

$$f(-a) = g(-a) + 1 = -g(a) + 1 = -1 + 1 = 0$$

**正确答案：** (A)
