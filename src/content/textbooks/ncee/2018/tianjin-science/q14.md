**题目：** 已知随机变量 $X \sim N(2, \sigma^2)$，若 $P(X \leq 0) = 0.1$，则 $P(2 < X \leq 4) = $ ______。

---

**解答：**

**第1步：** 利用正态分布的对称性
> 📌 运用知识点：正态分布

$X \sim N(2, \sigma^2)$，均值 $\mu = 2$，正态曲线关于 $x = 2$ 对称。

由对称性：$x = 0$ 和 $x = 4$ 关于 $\mu = 2$ 对称（$2-0 = 4-2 = 2$），因此：

$$P(X \geq 4) = P(X \leq 0) = 0.1$$

**第2步：** 计算中间区间的概率

$$P(0 < X < 4) = 1 - P(X \leq 0) - P(X \geq 4) = 1 - 0.1 - 0.1 = 0.8$$

**第3步：** 利用对称性求目标概率

区间 $(0, 4)$ 关于 $\mu = 2$ 对称，因此：

$$P(2 < X \leq 4) = \frac{1}{2} P(0 < X < 4) = \frac{0.8}{2} = 0.4$$

**正确答案：** $0.4$
