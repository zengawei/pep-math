**题目：** 已知函数 $f(x) = x^3 - 3x + 1$，则 $f(x)$ 在区间 $[-2, 2]$ 上的最大值为 ______。

---

**解答：**

**第1步：** 求导并找驻点
> 📌 运用知识点：导数与单调性

$$f'(x) = 3x^2 - 3 = 3(x^2 - 1) = 3(x+1)(x-1)$$

令 $f'(x) = 0$，得 $x = -1$ 或 $x = 1$，均在区间 $[-2, 2]$ 内。

**第2步：** 计算各关键点的函数值

- $f(-2) = (-2)^3 - 3(-2) + 1 = -8 + 6 + 1 = -1$
- $f(-1) = (-1)^3 - 3(-1) + 1 = -1 + 3 + 1 = 3$
- $f(1) = 1^3 - 3(1) + 1 = 1 - 3 + 1 = -1$
- $f(2) = 2^3 - 3(2) + 1 = 8 - 6 + 1 = 3$

**第3步：** 比较得出最大值

$$f(-1) = f(2) = 3$$

最大值为 $3$。

**正确答案：** $3$
