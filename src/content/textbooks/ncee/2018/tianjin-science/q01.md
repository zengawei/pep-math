**题目：** 设集合 $A = \{1, 3, 5, 7\}$，$B = \{x \mid 2 \leq x \leq 6\}$，则 $A \cap B = $（）

(A) $\{3, 5\}$

(B) $\{1, 3, 5\}$

(C) $\{3, 5, 7\}$

(D) $\{1, 3, 5, 7\}$

---

**解答：**

**第1步：** 理解交集的含义
> 📌 运用知识点：集合的运算

$A \cap B$ 表示既属于 $A$ 又属于 $B$ 的元素组成的集合，即需要满足 $x \in A$ 且 $2 \leq x \leq 6$。

**第2步：** 逐一检验 $A$ 中的元素

- $1 \in A$，但 $1 < 2$，不满足 $2 \leq x \leq 6$，故 $1 \notin B$
- $3 \in A$，且 $2 \leq 3 \leq 6$，故 $3 \in B$ ✓
- $5 \in A$，且 $2 \leq 5 \leq 6$，故 $5 \in B$ ✓
- $7 \in A$，但 $7 > 6$，不满足 $2 \leq x \leq 6$，故 $7 \notin B$

**第3步：** 写出交集

$$A \cap B = \{3, 5\}$$

**正确答案：** (A)
