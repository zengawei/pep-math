**题目：** 已知 $a = \log_3 2$，$b = \log_2 3$，$c = \log_3 4$，则（）

(A) $a < b < c$

(B) $a < c < b$

(C) $c < a < b$

(D) $b < a < c$

---

**解答：**

**第1步：** 估算各值的大小
> 📌 运用知识点：对数函数的性质

**计算 $a$：** $a = \log_3 2$。因为 $3^0 = 1 < 2 < 3 = 3^1$，所以 $0 < a < 1$。精确值 $a \approx 0.631$。

**计算 $b$：** $b = \log_2 3$。因为 $2^1 = 2 < 3 < 4 = 2^2$，所以 $1 < b < 2$。精确值 $b \approx 1.585$。

**计算 $c$：** $c = \log_3 4 = \log_3 2^2 = 2\log_3 2 = 2a$。所以 $c \approx 2 \times 0.631 = 1.262$。

**第2步：** 比较大小

$$a \approx 0.631 < c \approx 1.262 < b \approx 1.585$$

即 $a < c < b$。

**正确答案：** (B)
