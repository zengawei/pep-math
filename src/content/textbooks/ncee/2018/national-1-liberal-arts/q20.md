**题目：** 已知抛物线 $C: y^2 = 4x$，过点 $M(1, 0)$ 的直线 $l$ 与 $C$ 交于 $A$，$B$ 两点，$F$ 为 $C$ 的焦点。

（1）若 $|AF| + |BF| = 8$，求直线 $l$ 的方程；

（2）设 $A$ 关于 $x$ 轴的对称点为 $A'$，证明：直线 $A'B$ 过定点。

---

**解答：**

**（1）求直线 $l$ 的方程**

**第1步：** 确定焦点和设直线方程
> 📌 运用知识点：parabola-properties

抛物线 $y^2 = 4x$ 的焦点 $F(1, 0)$，恰好与 $M$ 重合。

设直线 $l: x = my + 1$（当 $l$ 为 $x$ 轴时，与抛物线仅有一个交点，不合题意）。

**第2步：** 联立抛物线方程
> 📌 运用知识点：conic-section-line

将 $x = my + 1$ 代入 $y^2 = 4x$：

$$y^2 = 4(my + 1) \implies y^2 - 4my - 4 = 0$$

设 $A(x_1, y_1)$，$B(x_2, y_2)$，由韦达定理：

$$y_1 + y_2 = 4m, \quad y_1 y_2 = -4$$

**第3步：** 利用焦半径公式
> 📌 运用知识点：parabola-properties

抛物线 $y^2 = 4x$ 的准线为 $x = -1$，由焦半径公式：

$$|AF| = x_1 + 1, \quad |BF| = x_2 + 1$$

$$|AF| + |BF| = x_1 + x_2 + 2 = 8 \implies x_1 + x_2 = 6$$

**第4步：** 求 $m$ 的值
> 📌 运用知识点：conic-section-line

$$x_1 + x_2 = (my_1 + 1) + (my_2 + 1) = m(y_1 + y_2) + 2 = 4m^2 + 2$$

$$4m^2 + 2 = 6 \implies m^2 = 1 \implies m = \pm 1$$

当 $m = 1$ 时，$l: x = y + 1$，即 $y = x - 1$；

当 $m = -1$ 时，$l: x = -y + 1$，即 $y = -x + 1$。

$$\boxed{l: y = x - 1 \quad \text{或} \quad y = -x + 1}$$

**（2）证明直线 $A'B$ 过定点**

**第5步：** 确定 $A'$ 的坐标
> 📌 运用知识点：parabola-properties

$A(x_1, y_1)$ 关于 $x$ 轴的对称点 $A'(x_1, -y_1)$。

**第6步：** 求直线 $A'B$ 的方程
> 📌 运用知识点：conic-section-line

直线 $A'B$ 的斜率：

$$k = \frac{y_2 - (-y_1)}{x_2 - x_1} = \frac{y_1 + y_2}{x_2 - x_1}$$

因为 $x_i = \dfrac{y_i^2}{4}$：

$$x_2 - x_1 = \frac{y_2^2 - y_1^2}{4} = \frac{(y_2 - y_1)(y_2 + y_1)}{4}$$

$$k = \frac{y_1 + y_2}{\dfrac{(y_2 - y_1)(y_2 + y_1)}{4}} = \frac{4}{y_2 - y_1}$$

**第7步：** 求直线 $A'B$ 与 $x$ 轴的交点
> 📌 运用知识点：conic-section-line

直线 $A'B$ 的方程：$y + y_1 = \dfrac{4}{y_2 - y_1}(x - x_1)$

令 $y = 0$：

$$x = x_1 + \frac{y_1(y_2 - y_1)}{4} = \frac{y_1^2}{4} + \frac{y_1 y_2 - y_1^2}{4} = \frac{y_1 y_2}{4}$$

由韦达定理 $y_1 y_2 = -4$：

$$x = \frac{-4}{4} = -1$$

因此，直线 $A'B$ 恒过定点 $(-1, 0)$。$\blacksquare$

**⚠️ 易错提醒：**
1. 设直线方程时，用 $x = my + 1$ 而非 $y = k(x - 1)$，可以避免讨论斜率不存在的情况。
2. 焦半径公式 $|PF| = x_0 + \dfrac{p}{2}$ 中，$p = 2$（$y^2 = 4x$ 中 $2p = 4$），不要混淆。
3. 证明过定点时，关键是化简交点坐标，利用韦达定理消去参数。

**💡 解题思路总结：** 抛物线与直线联立是解析几何的经典题型。第一问利用焦半径公式将条件转化为韦达定理的形式。第二问的关键是求直线 $A'B$ 与 $x$ 轴的交点，通过韦达定理 $y_1 y_2 = -4$ 发现交点横坐标恒为 $-1$，从而证明过定点。
