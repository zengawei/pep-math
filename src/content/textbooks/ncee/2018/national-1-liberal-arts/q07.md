**题目：** 为计算 $S = 1 + \dfrac{1}{2} + \dfrac{1}{3} + \cdots + \dfrac{1}{100}$，设计了如图所示的程序框图，则空白框中应填入（  ）

A. $S = S + \dfrac{1}{i}$

B. $S = S + \dfrac{1}{i+1}$

C. $S = S + i$

D. $S = S + \dfrac{1}{i-1}$

---

**解答：**

**第1步：** 分析程序框图的逻辑结构
> 📌 运用知识点：counting-principle-addition

程序框图的流程为：
- 初始值：$S = 0$，$i = 1$
- 循环体：先执行空白框中的语句，再执行 $i = i + 1$
- 判断条件：$i \leqslant 100$？若是，继续循环；若否，输出 $S$

**第2步：** 确定空白框中的语句
> 📌 运用知识点：counting-principle-addition

要计算 $S = 1 + \dfrac{1}{2} + \dfrac{1}{3} + \cdots + \dfrac{1}{100}$，每次循环需要将 $\dfrac{1}{i}$ 累加到 $S$ 中。

验证：
- 第1次循环：$S = 0 + \dfrac{1}{1} = 1$，$i = 2$
- 第2次循环：$S = 1 + \dfrac{1}{2}$，$i = 3$
- $\cdots$
- 第100次循环：$S = \cdots + \dfrac{1}{100}$，$i = 101$
- $i = 101 > 100$，退出循环，输出 $S$

因此空白框中应填入 $S = S + \dfrac{1}{i}$。

**答案：A**
