**题目：** 如图，在四棱锥 $P\text{-}ABCD$ 中，底面 $ABCD$ 为正方形，$PA \perp$ 底面 $ABCD$，$PA = AB = 2$。

（1）证明：$BD \perp PC$；

（2）求四棱锥 $P\text{-}ABCD$ 的体积。

---

**解答：**

**（1）证明 $BD \perp PC$**

**第1步：** 建立空间直角坐标系
> 📌 运用知识点：coordinate-method

以 $A$ 为原点，$\vec{AB}$、$\vec{AD}$、$\vec{AP}$ 分别为 $x$、$y$、$z$ 轴正方向，建立空间直角坐标系。

各点坐标：$A(0, 0, 0)$，$B(2, 0, 0)$，$C(2, 2, 0)$，$D(0, 2, 0)$，$P(0, 0, 2)$。

**第2步：** 求向量 $\vec{BD}$ 和 $\vec{PC}$
> 📌 运用知识点：space-vector-operations

$$\vec{BD} = D - B = (0 - 2,\ 2 - 0,\ 0 - 0) = (-2,\ 2,\ 0)$$

$$\vec{PC} = C - P = (2 - 0,\ 2 - 0,\ 0 - 2) = (2,\ 2,\ -2)$$

**第3步：** 计算点积验证垂直
> 📌 运用知识点：space-vector-operations

$$\vec{BD} \cdot \vec{PC} = (-2) \times 2 + 2 \times 2 + 0 \times (-2) = -4 + 4 + 0 = 0$$

因为 $\vec{BD} \cdot \vec{PC} = 0$，所以 $BD \perp PC$。$\blacksquare$

**（2）求体积**

**第4步：** 计算底面积和高
> 📌 运用知识点：solid-surface-area-volume

底面 $ABCD$ 为正方形，边长 $AB = 2$：

$$S_{\text{底}} = AB^2 = 2^2 = 4$$

$PA \perp$ 底面 $ABCD$，所以高 $h = PA = 2$。

**第5步：** 代入体积公式
> 📌 运用知识点：solid-surface-area-volume

$$V = \frac{1}{3} S_{\text{底}} \cdot h = \frac{1}{3} \times 4 \times 2 = \frac{8}{3}$$

$$\boxed{V = \dfrac{8}{3}}$$

**⚠️ 易错提醒：**
1. 建立坐标系时，要注意三条互相垂直的棱（$AB$、$AD$、$AP$），确保各轴方向正确。
2. 证明垂直时，向量点积为零即可，不需要额外说明。
3. 四棱锥体积公式中不要遗漏系数 $\dfrac{1}{3}$。

**💡 解题思路总结：** 本题利用 $PA \perp$ 底面的条件，自然地建立空间直角坐标系，将几何证明转化为向量运算。证明线线垂直只需验证对应向量的点积为零。体积计算直接用 $V = \dfrac{1}{3}Sh$ 公式。
