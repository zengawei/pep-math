**题目：** 已知集合 $A = \{0, 2\}$，$B = \{-2, -1, 0, 1, 2\}$，则 $A \cap B =$（  ）

A. $\{0, 2\}$

B. $\{1, 2\}$

C. $\{0\}$

D. $\{-2, -1, 0, 1, 2\}$

---

**解答：**

**第1步：** 理解交集的定义
> 📌 运用知识点：set-operations

交集 $A \cap B$ 是由同时属于集合 $A$ 和集合 $B$ 的所有元素组成的集合，即：
$$A \cap B = \{x \mid x \in A \text{ 且 } x \in B\}$$

**第2步：** 逐一检验 $A$ 中的元素是否属于 $B$

- 元素 $0$：$0 \in A$，且 $0 \in B = \{-2, -1, 0, 1, 2\}$，所以 $0 \in A \cap B$
- 元素 $2$：$2 \in A$，且 $2 \in B = \{-2, -1, 0, 1, 2\}$，所以 $2 \in A \cap B$

因此 $A \cap B = \{0, 2\}$。

**答案：A**

**⚠️ 易错提醒：** 注意区分交集（$\cap$，取公共元素）与并集（$\cup$，取所有元素）。若求 $A \cup B$ 则结果为 $\{-2, -1, 0, 1, 2\}$，对应选项 D，容易混淆。

**💡 解题思路总结：** 集合的交集运算，核心是逐一检查第一个集合中的每个元素是否也属于第二个集合。对于有限集合的交、并、补运算，直接枚举验证即可。
