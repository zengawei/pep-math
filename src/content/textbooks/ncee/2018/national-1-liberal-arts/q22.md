**题目：** 在直角坐标系 $xOy$ 中，曲线 $C$ 的参数方程为 $\begin{cases} x = 2\cos\theta, \\ y = 2\sin\theta \end{cases}$（$\theta$ 为参数），直线 $l$ 的极坐标方程为 $\rho\cos\theta + \rho\sin\theta = 2$。

（1）求曲线 $C$ 和直线 $l$ 的直角坐标方程；

（2）求曲线 $C$ 上的点到直线 $l$ 的距离的最大值和最小值。

---

**解答：**

**（1）求直角坐标方程**

**第1步：** 求曲线 $C$ 的直角坐标方程
> 📌 运用知识点：circle-equation

由参数方程：

$$x^2 + y^2 = (2\cos\theta)^2 + (2\sin\theta)^2 = 4(\cos^2\theta + \sin^2\theta) = 4$$

$$\boxed{C: x^2 + y^2 = 4}$$

**第2步：** 求直线 $l$ 的直角坐标方程
> 📌 运用知识点：line-equation-application

由 $\rho\cos\theta + \rho\sin\theta = 2$，利用 $x = \rho\cos\theta$，$y = \rho\sin\theta$：

$$\boxed{l: x + y = 2}$$

**（2）求距离的最大值和最小值**

**第3步：** 表示曲线上点到直线的距离
> 📌 运用知识点：line-equation-application

曲线 $C$ 上的点为 $(2\cos\theta, 2\sin\theta)$，到直线 $x + y - 2 = 0$ 的距离：

$$d = \frac{|2\cos\theta + 2\sin\theta - 2|}{\sqrt{1^2 + 1^2}} = \frac{|2\cos\theta + 2\sin\theta - 2|}{\sqrt{2}}$$

**第4步：** 利用辅助角公式化简
> 📌 运用知识点：line-equation-application

$$2\cos\theta + 2\sin\theta = 2\sqrt{2}\sin\!\left(\theta + \frac{\pi}{4}\right)$$

所以：

$$d = \frac{\left|2\sqrt{2}\sin\!\left(\theta + \dfrac{\pi}{4}\right) - 2\right|}{\sqrt{2}}$$

**第5步：** 求最大值和最小值
> 📌 运用知识点：line-equation-application

因为 $\sin\!\left(\theta + \dfrac{\pi}{4}\right) \in [-1, 1]$，所以 $2\sqrt{2}\sin\!\left(\theta + \dfrac{\pi}{4}\right) \in [-2\sqrt{2},\ 2\sqrt{2}]$。

令 $t = 2\sqrt{2}\sin\!\left(\theta + \dfrac{\pi}{4}\right) - 2$，则 $t \in [-2\sqrt{2} - 2,\ 2\sqrt{2} - 2]$。

因为 $-2\sqrt{2} - 2 < 0$ 且 $2\sqrt{2} - 2 > 0$，所以：

- $|t|$ 的最大值 $= 2\sqrt{2} + 2$（当 $\sin(\theta + \frac{\pi}{4}) = -1$ 时取到）
- $|t|$ 的最小值 $= 0$（当 $2\sqrt{2}\sin(\theta + \frac{\pi}{4}) = 2$，即 $\sin(\theta + \frac{\pi}{4}) = \frac{1}{\sqrt{2}}$ 时取到）

因此：

$$d_{\max} = \frac{2\sqrt{2} + 2}{\sqrt{2}} = 2 + \sqrt{2}$$

$$d_{\min} = \frac{0}{\sqrt{2}} = 0$$

$$\boxed{d_{\max} = 2 + \sqrt{2}, \quad d_{\min} = 0}$$

（最小值为 $0$，说明直线 $l$ 与圆 $C$ 相交。）

**⚠️ 易错提醒：**
1. 参数方程化为普通方程时，利用 $\cos^2\theta + \sin^2\theta = 1$ 消去参数。
2. 极坐标方程化为直角坐标方程时，注意 $\rho\cos\theta = x$，$\rho\sin\theta = y$ 的对应关系。
3. 辅助角公式 $a\cos\theta + b\sin\theta = \sqrt{a^2 + b^2}\sin(\theta + \varphi)$ 中，不要算错振幅 $\sqrt{a^2 + b^2}$。
4. 求绝对值的最值时，要注意区间是否跨越零点。

**💡 解题思路总结：** 第一问是参数方程和极坐标方程的基本转化。第二问的关键是用辅助角公式将距离表达式化为单个三角函数的形式，再利用三角函数的有界性求最值。最小值为 $0$ 说明直线与圆相交，也可以通过比较圆心到直线的距离 $d_0 = \sqrt{2} < 2 = r$ 来验证。
