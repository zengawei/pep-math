**题目：** 若 $x$，$y$ 满足约束条件 $\begin{cases} x - y \geqslant 0, \\ x + y \leqslant 2, \\ y \geqslant 0, \end{cases}$ 则 $z = x + 3y$ 的最大值为 ______。

---

**解答：**

**第1步：** 确定可行域的顶点
> 📌 运用知识点：basic-inequality

三条边界线：
- $x - y = 0$，即 $y = x$
- $x + y = 2$
- $y = 0$

求交点：
- $y = x$ 与 $y = 0$：$x = 0$，交点 $O(0, 0)$
- $x + y = 2$ 与 $y = 0$：$x = 2$，交点 $A(2, 0)$
- $y = x$ 与 $x + y = 2$：$2x = 2$，$x = 1$，交点 $B(1, 1)$

可行域为 $\triangle OAB$。

**第2步：** 在各顶点处计算目标函数值
> 📌 运用知识点：basic-inequality

- $O(0, 0)$：$z = 0 + 0 = 0$
- $A(2, 0)$：$z = 2 + 0 = 2$
- $B(1, 1)$：$z = 1 + 3 = 4$

**第3步：** 确定最大值

$z$ 的最大值为 $4$，在点 $B(1, 1)$ 处取得。

**答案：** $4$
