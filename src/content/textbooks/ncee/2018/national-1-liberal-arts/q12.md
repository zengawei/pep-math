**题目：** 已知函数 $f(x) = x^3 - 3x + 1$，则 $f(x)$ 的零点个数为（  ）

A. $0$

B. $1$

C. $2$

D. $3$

---

**解答：**

**第1步：** 求导数并找极值点
> 📌 运用知识点：derivative-monotonicity

$$f'(x) = 3x^2 - 3 = 3(x^2 - 1) = 3(x + 1)(x - 1)$$

令 $f'(x) = 0$，得 $x = -1$ 或 $x = 1$。

**第2步：** 判断单调性和极值
> 📌 运用知识点：derivative-monotonicity

| 区间 | $f'(x)$ | $f(x)$ |
|------|---------|--------|
| $(-\infty, -1)$ | $+$ | 递增 |
| $(-1, 1)$ | $-$ | 递减 |
| $(1, +\infty)$ | $+$ | 递增 |

极大值：$f(-1) = -1 + 3 + 1 = 3 > 0$

极小值：$f(1) = 1 - 3 + 1 = -1 < 0$

**第3步：** 判断零点个数
> 📌 运用知识点：derivative-extrema

- 在 $(-\infty, -1)$ 上，$f(x)$ 递增，$f(-2) = -8 + 6 + 1 = -1 < 0$，$f(-1) = 3 > 0$，由零点存在定理，此区间有1个零点。
- 在 $(-1, 1)$ 上，$f(x)$ 递减，$f(-1) = 3 > 0$，$f(1) = -1 < 0$，此区间有1个零点。
- 在 $(1, +\infty)$ 上，$f(x)$ 递增，$f(1) = -1 < 0$，$f(2) = 8 - 6 + 1 = 3 > 0$，此区间有1个零点。

共3个零点。

**答案：D**
