**题目：** 已知一个正四棱柱的底面边长为 $2$，侧棱长为 $3$，则该正四棱柱的外接球的表面积为（  ）

A. $16\pi$

B. $17\pi$

C. $20\pi$

D. $24\pi$

---

**解答：**

**第1步：** 分析正四棱柱的结构
> 📌 运用知识点：正四棱柱的几何特征

正四棱柱底面为正方形，边长 $a = 2$，高 $h = 3$。

**第2步：** 求外接球的直径
> 📌 运用知识点：长方体的外接球直径等于体对角线

正四棱柱是特殊的长方体，其外接球的直径等于体对角线长。

体对角线长 $d = \sqrt{a^2 + a^2 + h^2} = \sqrt{2^2 + 2^2 + 3^2} = \sqrt{4 + 4 + 9} = \sqrt{17}$

所以外接球半径 $R = \dfrac{\sqrt{17}}{2}$。

**第3步：** 计算表面积

$$S = 4\pi R^2 = 4\pi \times \left(\frac{\sqrt{17}}{2}\right)^2 = 4\pi \times \frac{17}{4} = 17\pi$$

**答案：** B

**⚠️ 易错提醒：** 正四棱柱的外接球直径是体对角线，不是底面对角线，也不是侧棱长。体对角线 $= \sqrt{a^2 + a^2 + h^2}$。

**💡 解题思路总结：** 长方体（含正四棱柱）的外接球直径 = 体对角线长 $= \sqrt{a^2 + b^2 + h^2}$，这是求外接球半径的核心公式。
