**题目：** 函数 $f(x) = 2\sin\left(2x + \dfrac{\pi}{6}\right)$ 的最小正周期为（  ）

A. $\dfrac{\pi}{4}$

B. $\dfrac{\pi}{2}$

C. $\pi$

D. $2\pi$

---

**解答：**

**第1步：** 利用周期公式
> 📌 运用知识点：正弦函数 $y = A\sin(\omega x + \varphi)$ 的周期公式

对于 $f(x) = A\sin(\omega x + \varphi)$，其最小正周期为 $T = \dfrac{2\pi}{|\omega|}$。

本题中 $\omega = 2$，因此：

$$T = \frac{2\pi}{2} = \pi$$

**答案：** C

**⚠️ 易错提醒：** 周期公式中分母是 $|\omega|$（$\omega$ 的绝对值），不是 $2\omega$。振幅 $A$ 和初相 $\varphi$ 不影响周期。

**💡 解题思路总结：** 三角函数 $y = A\sin(\omega x + \varphi)$ 或 $y = A\cos(\omega x + \varphi)$ 的最小正周期只与 $\omega$ 有关，$T = \frac{2\pi}{|\omega|}$。
