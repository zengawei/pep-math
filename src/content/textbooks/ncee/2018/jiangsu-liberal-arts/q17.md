**题目：** 在 $\triangle ABC$ 中，角 $A$，$B$，$C$ 的对边分别为 $a$，$b$，$c$，已知 $a = 2$，$b = 3$，$B = \dfrac{\pi}{3}$。

（1）求 $\sin A$ 的值；

（2）求 $\triangle ABC$ 的面积。

---

**解答：**

**（1）求 $\sin A$**

**第1步：** 利用正弦定理
> 📌 运用知识点：正弦定理 $\dfrac{a}{\sin A} = \dfrac{b}{\sin B}$

由正弦定理：

$$\frac{a}{\sin A} = \frac{b}{\sin B}$$

代入已知数据 $a = 2$，$b = 3$，$B = \dfrac{\pi}{3}$：

$$\frac{2}{\sin A} = \frac{3}{\sin \frac{\pi}{3}} = \frac{3}{\frac{\sqrt{3}}{2}} = \frac{6}{\sqrt{3}} = 2\sqrt{3}$$

**第2步：** 求解 $\sin A$

$$\sin A = \frac{2}{2\sqrt{3}} = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}$$

**（2）求 $\triangle ABC$ 的面积**

**第3步：** 求 $\cos A$
> 📌 运用知识点：$\sin^2 A + \cos^2 A = 1$

因为 $a < b$，所以 $A < B = \dfrac{\pi}{3}$，故 $A$ 为锐角，$\cos A > 0$。

$$\cos A = \sqrt{1 - \sin^2 A} = \sqrt{1 - \frac{1}{3}} = \sqrt{\frac{2}{3}} = \frac{\sqrt{6}}{3}$$

**第4步：** 求角 $C$ 的正弦值
> 📌 运用知识点：$A + B + C = \pi$，$\sin C = \sin(A + B)$

$$\sin C = \sin(A + B) = \sin A \cos B + \cos A \sin B$$

$$= \frac{\sqrt{3}}{3} \cdot \frac{1}{2} + \frac{\sqrt{6}}{3} \cdot \frac{\sqrt{3}}{2} = \frac{\sqrt{3}}{6} + \frac{\sqrt{18}}{6} = \frac{\sqrt{3}}{6} + \frac{3\sqrt{2}}{6} = \frac{\sqrt{3} + 3\sqrt{2}}{6}$$

**第5步：** 利用面积公式
> 📌 运用知识点：$S = \dfrac{1}{2}ab\sin C$

$$S = \frac{1}{2} \cdot a \cdot b \cdot \sin C = \frac{1}{2} \times 2 \times 3 \times \frac{\sqrt{3} + 3\sqrt{2}}{6} = 3 \times \frac{\sqrt{3} + 3\sqrt{2}}{6} = \frac{\sqrt{3} + 3\sqrt{2}}{2}$$

**答案：** （1）$\sin A = \dfrac{\sqrt{3}}{3}$；（2）$S = \dfrac{\sqrt{3} + 3\sqrt{2}}{2}$

**⚠️ 易错提醒：** 用正弦定理求 $\sin A$ 后，判断 $A$ 是锐角还是钝角很关键。因为 $a < b$，所以 $A < B$，$A$ 必为锐角。

**💡 解题思路总结：** 解三角形问题的核心工具是正弦定理和余弦定理。已知两角一边或两边一角时，正弦定理可直接求第三个元素。面积公式 $S = \frac{1}{2}ab\sin C$ 需要知道两边及其夹角。
