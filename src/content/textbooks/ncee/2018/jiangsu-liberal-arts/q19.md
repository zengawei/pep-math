**题目：** 已知椭圆 $C$：$\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$）的离心率为 $\dfrac{\sqrt{3}}{2}$，且过点 $(2, 0)$。

（1）求椭圆 $C$ 的方程；

（2）设直线 $l$ 过点 $(1, 0)$ 与椭圆 $C$ 交于 $A$，$B$ 两点，求 $\triangle OAB$（$O$ 为原点）面积的最大值。

---

**解答：**

**（1）求椭圆方程**

**第1步：** 利用已知条件
> 📌 运用知识点：椭圆的基本性质

椭圆过点 $(2, 0)$，代入方程：$\dfrac{4}{a^2} + 0 = 1$，得 $a^2 = 4$，$a = 2$。

**第2步：** 利用离心率求 $b$
> 📌 运用知识点：$e = \dfrac{c}{a}$，$c^2 = a^2 - b^2$

$$e = \frac{c}{a} = \frac{\sqrt{3}}{2} \implies c = 2 \times \frac{\sqrt{3}}{2} = \sqrt{3}$$

$$b^2 = a^2 - c^2 = 4 - 3 = 1$$

**第3步：** 写出方程

$$\frac{x^2}{4} + y^2 = 1$$

**（2）求 $\triangle OAB$ 面积的最大值**

**第4步：** 讨论直线斜率
> 📌 运用知识点：直线与椭圆的位置关系

**情况一：** 直线斜率不存在，$l: x = 1$。

代入椭圆：$\dfrac{1}{4} + y^2 = 1$，$y^2 = \dfrac{3}{4}$，$y = \pm\dfrac{\sqrt{3}}{2}$。

$|AB| = \sqrt{3}$，$O$ 到直线 $x = 1$ 的距离 $d = 1$。

$$S = \frac{1}{2} \times \sqrt{3} \times 1 = \frac{\sqrt{3}}{2}$$

**情况二：** 直线斜率存在，设 $l: y = k(x - 1)$。

代入椭圆方程：$\dfrac{x^2}{4} + k^2(x-1)^2 = 1$

整理得：$(1 + 4k^2)x^2 - 8k^2 x + 4k^2 - 4 = 0$

**第5步：** 利用韦达定理
> 📌 运用知识点：韦达定理

设 $A(x_1, y_1)$，$B(x_2, y_2)$：

$$x_1 + x_2 = \frac{8k^2}{1 + 4k^2}, \quad x_1 x_2 = \frac{4k^2 - 4}{1 + 4k^2}$$

**第6步：** 计算 $|x_1 - x_2|$

$$(x_1 - x_2)^2 = (x_1 + x_2)^2 - 4x_1 x_2 = \frac{64k^4}{(1+4k^2)^2} - \frac{4(4k^2-4)}{1+4k^2}$$

$$= \frac{64k^4 - 4(4k^2-4)(1+4k^2)}{(1+4k^2)^2} = \frac{64k^4 - (16k^2-16)(1+4k^2)}{(1+4k^2)^2}$$

$$= \frac{64k^4 - 16k^2 - 64k^4 + 16 + 64k^2}{(1+4k^2)^2} = \frac{48k^2 + 16}{(1+4k^2)^2} = \frac{16(3k^2+1)}{(1+4k^2)^2}$$

$$|x_1 - x_2| = \frac{4\sqrt{3k^2+1}}{1+4k^2}$$

**第7步：** 计算面积
> 📌 运用知识点：三角形面积

$O$ 到直线 $kx - y - k = 0$ 的距离 $d = \dfrac{|k|}{\sqrt{1+k^2}}$。

$$S = \frac{1}{2}|AB| \cdot d = \frac{1}{2} \cdot \sqrt{1+k^2} \cdot \frac{4\sqrt{3k^2+1}}{1+4k^2} \cdot \frac{|k|}{\sqrt{1+k^2}} = \frac{2|k|\sqrt{3k^2+1}}{1+4k^2}$$

**第8步：** 求最大值
> 📌 运用知识点：换元求最值

设 $t = k^2 > 0$：

$$S^2 = \frac{4t(3t+1)}{(1+4t)^2} = \frac{12t^2 + 4t}{16t^2 + 8t + 1}$$

令 $f(t) = \dfrac{12t^2 + 4t}{16t^2 + 8t + 1}$，求导：

$$f'(t) = \frac{(24t+4)(16t^2+8t+1) - (12t^2+4t)(32t+8)}{(16t^2+8t+1)^2}$$

分子展开：
- $(24t+4)(16t^2+8t+1) = 384t^3 + 192t^2 + 24t + 64t^2 + 32t + 4 = 384t^3 + 256t^2 + 56t + 4$
- $(12t^2+4t)(32t+8) = 384t^3 + 96t^2 + 128t^2 + 32t = 384t^3 + 224t^2 + 32t$

分子 $= 32t^2 + 24t + 4 = 8(4t^2 + 3t) + 4$

实际上分子 $= (384t^3 + 256t^2 + 56t + 4) - (384t^3 + 224t^2 + 32t) = 32t^2 + 24t + 4 > 0$（$t > 0$）

所以 $f'(t) > 0$，$f(t)$ 在 $t > 0$ 上单调递增。

当 $t \to +\infty$ 时，$f(t) \to \dfrac{12}{16} = \dfrac{3}{4}$，即 $S^2 < \dfrac{3}{4}$，$S < \dfrac{\sqrt{3}}{2}$。

因此情况二中 $S < \dfrac{\sqrt{3}}{2}$，而情况一恰好 $S = \dfrac{\sqrt{3}}{2}$。

综合两种情况，$\triangle OAB$ 面积的最大值为 $\dfrac{\sqrt{3}}{2}$。

**答案：** （1）$\dfrac{x^2}{4} + y^2 = 1$；（2）$\triangle OAB$ 面积的最大值为 $\dfrac{\sqrt{3}}{2}$

**⚠️ 易错提醒：** 直线斜率不存在的情况不能遗漏。求面积最大值时，要分析函数的单调性，判断最值在何处取到。

**💡 解题思路总结：** 解析几何综合题的标准流程：①由条件求曲线方程 → ②讨论直线斜率存在与不存在 → ③联立方程用韦达定理 → ④建立面积的目标函数 → ⑤分析单调性求最值。
