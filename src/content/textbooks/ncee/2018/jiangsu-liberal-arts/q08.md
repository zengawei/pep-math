**题目：** 已知 $x > 0$，$y > 0$，且 $x + 2y = 4$，则 $\dfrac{1}{x} + \dfrac{1}{y}$ 的最小值为（  ）

A. $\dfrac{3}{4}$

B. $\dfrac{3 + 2\sqrt{2}}{4}$

C. $1$

D. $\dfrac{3}{2}$

---

**解答：**

**第1步：** 利用"乘1法"构造基本不等式
> 📌 运用知识点：基本不等式 $a + b \geq 2\sqrt{ab}$

因为 $x + 2y = 4$，所以 $\dfrac{x + 2y}{4} = 1$。

$$\frac{1}{x} + \frac{1}{y} = \left(\frac{1}{x} + \frac{1}{y}\right) \cdot 1 = \left(\frac{1}{x} + \frac{1}{y}\right) \cdot \frac{x + 2y}{4}$$

**第2步：** 展开化简

$$= \frac{1}{4}\left(\frac{x}{x} + \frac{2y}{x} + \frac{x}{y} + \frac{2y}{y}\right) = \frac{1}{4}\left(3 + \frac{2y}{x} + \frac{x}{y}\right)$$

**第3步：** 对 $\dfrac{2y}{x} + \dfrac{x}{y}$ 使用基本不等式

因为 $x > 0$，$y > 0$，所以 $\dfrac{2y}{x} > 0$，$\dfrac{x}{y} > 0$。

$$\frac{2y}{x} + \frac{x}{y} \geq 2\sqrt{\frac{2y}{x} \cdot \frac{x}{y}} = 2\sqrt{2}$$

等号成立条件：$\dfrac{2y}{x} = \dfrac{x}{y}$，即 $x^2 = 2y^2$，$x = \sqrt{2}y$。

代入 $x + 2y = 4$：$\sqrt{2}y + 2y = 4$，$y = \dfrac{4}{\sqrt{2} + 2} = \dfrac{4(2 - \sqrt{2})}{2} = 4 - 2\sqrt{2} > 0$，等号可以取到。

**第4步：** 得出最小值

$$\frac{1}{x} + \frac{1}{y} \geq \frac{1}{4}(3 + 2\sqrt{2}) = \frac{3 + 2\sqrt{2}}{4}$$

**答案：** B

**⚠️ 易错提醒：** 使用基本不等式后，必须验证等号成立条件是否在约束范围内（即 $x > 0, y > 0$ 且 $x + 2y = 4$）。

**💡 解题思路总结：** 已知线性约束求倒数和的最小值，经典方法是"乘1法"——将约束条件化为 $1$ 代入，展开后用基本不等式。
