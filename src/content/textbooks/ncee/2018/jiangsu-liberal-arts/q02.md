**题目：** 已知复数 $z$ 满足 $(1 + i)z = 2i$（其中 $i$ 为虚数单位），则 $|z| = $（  ）

A. $1$

B. $\sqrt{2}$

C. $2$

D. $2\sqrt{2}$

---

**解答：**

**第1步：** 求出复数 $z$
> 📌 运用知识点：复数的除法运算

由 $(1+i)z = 2i$，得：

$$z = \frac{2i}{1+i}$$

分子分母同乘以分母的共轭复数 $1-i$：

$$z = \frac{2i(1-i)}{(1+i)(1-i)} = \frac{2i - 2i^2}{1 - i^2} = \frac{2i - 2(-1)}{1 - (-1)} = \frac{2 + 2i}{2} = 1 + i$$

**第2步：** 求 $z$ 的模
> 📌 运用知识点：复数的模

$$|z| = |1 + i| = \sqrt{1^2 + 1^2} = \sqrt{2}$$

**答案：** B

**⚠️ 易错提醒：** 复数除法必须乘以分母的共轭复数来化简，不能直接除。另外注意 $i^2 = -1$。

**💡 解题思路总结：** 复数除法的核心是"分母实数化"——分子分母同乘分母的共轭复数，再利用 $i^2 = -1$ 化简。
