**题目：** 已知等差数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n$，若 $a_3 + a_7 = 10$，则 $S_9 = $（  ）

A. $40$

B. $45$

C. $50$

D. $55$

---

**解答：**

**第1步：** 利用等差数列性质
> 📌 运用知识点：等差数列性质 $a_m + a_n = a_p + a_q$（当 $m + n = p + q$ 时）

在等差数列中，$a_3 + a_7 = a_1 + a_9$（因为 $3 + 7 = 1 + 9 = 10$）。

所以 $a_1 + a_9 = 10$。

**第2步：** 利用前 $n$ 项和公式
> 📌 运用知识点：$S_n = \dfrac{n(a_1 + a_n)}{2}$

$$S_9 = \frac{9(a_1 + a_9)}{2} = \frac{9 \times 10}{2} = 45$$

**答案：** B

**⚠️ 易错提醒：** 等差数列中 $a_m + a_n = a_p + a_q$ 的条件是 $m + n = p + q$，不是 $m \times n = p \times q$。

**💡 解题思路总结：** 等差数列求和时，善用对称性质 $a_m + a_n = a_p + a_q$（$m+n=p+q$），可以避免求公差和首项，直接得到结果。
