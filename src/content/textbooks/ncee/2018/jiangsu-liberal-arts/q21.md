**题目：** 已知函数 $f(x) = x^3 - 3x^2 + 2$。

（1）求函数 $f(x)$ 的单调区间和极值；

（2）求 $f(x)$ 在区间 $[-1, 3]$ 上的最大值和最小值。

---

**解答：**

**（1）求单调区间和极值**

**第1步：** 求导数
> 📌 运用知识点：导数的运算

$$f'(x) = 3x^2 - 6x = 3x(x - 2)$$

**第2步：** 令 $f'(x) = 0$ 求驻点
> 📌 运用知识点：极值的必要条件

$$3x(x - 2) = 0 \implies x = 0 \text{ 或 } x = 2$$

**第3步：** 分析 $f'(x)$ 的符号变化
> 📌 运用知识点：导数符号与单调性的关系

| 区间 | $(-\infty, 0)$ | $x = 0$ | $(0, 2)$ | $x = 2$ | $(2, +\infty)$ |
|------|:-:|:-:|:-:|:-:|:-:|
| $f'(x)$ | $+$ | $0$ | $-$ | $0$ | $+$ |
| $f(x)$ | ↗ | 极大值 | ↘ | 极小值 | ↗ |

- 单调递增区间：$(-\infty, 0)$ 和 $(2, +\infty)$
- 单调递减区间：$(0, 2)$

**第4步：** 计算极值

极大值：$f(0) = 0 - 0 + 2 = 2$

极小值：$f(2) = 8 - 12 + 2 = -2$

**（2）求 $[-1, 3]$ 上的最值**

**第5步：** 比较端点值和极值点的函数值
> 📌 运用知识点：闭区间上连续函数的最值

需要比较 $f(-1)$、$f(0)$、$f(2)$、$f(3)$：

- $f(-1) = (-1)^3 - 3(-1)^2 + 2 = -1 - 3 + 2 = -2$
- $f(0) = 2$（极大值）
- $f(2) = -2$（极小值）
- $f(3) = 27 - 27 + 2 = 2$

**第6步：** 得出最值

最大值为 $f(0) = f(3) = 2$，最小值为 $f(-1) = f(2) = -2$。

**答案：** （1）单调递增区间为 $(-\infty, 0)$ 和 $(2, +\infty)$，单调递减区间为 $(0, 2)$；极大值 $f(0) = 2$，极小值 $f(2) = -2$。（2）最大值为 $2$，最小值为 $-2$。

**⚠️ 易错提醒：** 闭区间上的最值不一定在极值点取到，必须同时比较端点值。极值是局部概念，最值是全局概念。

**💡 解题思路总结：** 求闭区间上最值的步骤：①求导找驻点 → ②判断单调性和极值 → ③比较所有驻点和端点的函数值 → ④最大的是最大值，最小的是最小值。
