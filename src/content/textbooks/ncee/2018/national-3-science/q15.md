**题目：** 已知双曲线 $x^2 - \dfrac{y^2}{3} = 1$ 的左、右焦点分别为 $F_1$，$F_2$，点 $M\left(0, \dfrac{2\sqrt{3}}{3}\right)$，$P$ 为双曲线左支上的点，$d$ 为点 $P$ 到双曲线右支的距离，则 $|PM| - d$ 的最小值为______。

---

**解答：**

**第1步：** 确定双曲线参数
> 📌 运用知识点：双曲线定义

$a^2 = 1$，$b^2 = 3$，$c^2 = a^2 + b^2 = 4$，所以 $a = 1$，$c = 2$。

$F_1(-2, 0)$，$F_2(2, 0)$。

**第2步：** 利用双曲线定义转化 $d$
> 📌 运用知识点：双曲线定义

$P$ 在左支上，由双曲线定义 $|PF_2| - |PF_1| = 2a = 2$。

点 $P$ 到右支的距离 $d = |PF_2| - a = |PF_2| - 1$。

**第3步：** 转化目标表达式

$$|PM| - d = |PM| - (|PF_2| - 1) = |PM| - |PF_2| + 1$$

**第4步：** 利用三角不等式求最小值
> 📌 运用知识点：双曲线性质

由三角不等式：$|PM| - |PF_2| \geqslant -|MF_2|$

等号在 $P$ 在 $M$ 到 $F_2$ 的连线延长线上时成立。

$$|MF_2| = \sqrt{(0-2)^2 + \left(\frac{2\sqrt{3}}{3}\right)^2} = \sqrt{4 + \frac{4}{3}} = \sqrt{\frac{16}{3}} = \frac{4\sqrt{3}}{3}$$

所以：

$$|PM| - d \geqslant 1 - \frac{4\sqrt{3}}{3}$$

验证等号可取：直线 $MF_2$ 与左支有交点（经计算交点 $x = \dfrac{-1-3\sqrt{3}}{4} < -1$，在左支上），等号成立。

**答案：** $1 - \dfrac{4\sqrt{3}}{3}$
