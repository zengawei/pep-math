**题目：** 已知椭圆 $\dfrac{x^2}{4} + y^2 = 1$ 的左、右焦点分别为 $F_1$，$F_2$，过 $F_1$ 的直线交椭圆于 $A$，$B$ 两点，则 $\triangle ABF_2$ 的周长为（）

A. $2$

B. $4$

C. $6$

D. $8$

---

**解答：**

**第1步：** 确定椭圆参数
> 📌 运用知识点：椭圆定义

椭圆 $\dfrac{x^2}{4} + y^2 = 1$ 中，$a^2 = 4$，$a = 2$，$2a = 4$。

**第2步：** 利用椭圆定义计算周长
> 📌 运用知识点：椭圆定义

由椭圆定义，对椭圆上任意一点 $P$，有 $|PF_1| + |PF_2| = 2a = 4$。

因此：
- $|AF_1| + |AF_2| = 4$
- $|BF_1| + |BF_2| = 4$

$\triangle ABF_2$ 的周长为：

$$|AF_2| + |BF_2| + |AB|$$

由于 $A$，$F_1$，$B$ 三点共线（直线过 $F_1$），且 $F_1$ 在 $A$，$B$ 之间：

$$|AB| = |AF_1| + |BF_1|$$

所以周长为：

$$|AF_2| + |BF_2| + |AF_1| + |BF_1| = (|AF_1| + |AF_2|) + (|BF_1| + |BF_2|) = 4 + 4 = 8$$

**答案：** D
