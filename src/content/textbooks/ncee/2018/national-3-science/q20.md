**题目：**

已知抛物线 $C: y^2 = 2px$（$p > 0$）的焦点为 $F$，$C$ 上的点 $M$ 到 $y$ 轴的距离等于 $|MF| - 1$。

（1）求 $C$ 的方程；

（2）设过 $F$ 的直线 $l$ 交 $C$ 于 $A$，$B$ 两点，若 $\vec{OA} \cdot \vec{OB} = -4$（$O$ 为原点），证明：直线 $l$ 过定点，并求出该定点的坐标。

---

**解答：**

**（1）求抛物线方程**

**第1步：** 利用抛物线的焦半径公式
> 📌 运用知识点：抛物线定义

设 $M(x_0, y_0)$ 在抛物线 $y^2 = 2px$ 上，则 $|MF| = x_0 + \dfrac{p}{2}$（焦半径公式）。

$M$ 到 $y$ 轴的距离为 $x_0$。

由题意：$x_0 = |MF| - 1 = x_0 + \dfrac{p}{2} - 1$

$$0 = \frac{p}{2} - 1 \implies p = 2$$

**第2步：** 写出方程

$$\boxed{y^2 = 4x}$$

---

**（2）证明直线过定点**

**第3步：** 设直线方程
> 📌 运用知识点：抛物线性质

焦点 $F(1, 0)$。设直线 $l: x = my + 1$（过焦点）。

代入 $y^2 = 4x$：

$$y^2 = 4(my + 1) \implies y^2 - 4my - 4 = 0$$

设 $A(x_1, y_1)$，$B(x_2, y_2)$，由韦达定理：

$$y_1 + y_2 = 4m, \quad y_1 y_2 = -4$$

**第4步：** 利用 $\vec{OA} \cdot \vec{OB} = -4$
> 📌 运用知识点：圆锥曲线与直线

$$\vec{OA} \cdot \vec{OB} = x_1 x_2 + y_1 y_2$$

$$x_1 x_2 = (my_1 + 1)(my_2 + 1) = m^2 y_1 y_2 + m(y_1 + y_2) + 1 = -4m^2 + 4m^2 + 1 = 1$$

$$\vec{OA} \cdot \vec{OB} = 1 + y_1 y_2 = 1 + (-4) = -3$$

但题目给出 $\vec{OA} \cdot \vec{OB} = -4$，说明直线不经过焦点。

**修正：** 设直线 $l$ 过点 $(t, 0)$，$l: x = my + t$。

代入 $y^2 = 4x$：

$$y^2 - 4my - 4t = 0$$

$$y_1 + y_2 = 4m, \quad y_1 y_2 = -4t$$

$$x_1 x_2 = (my_1 + t)(my_2 + t) = m^2 y_1 y_2 + mt(y_1 + y_2) + t^2 = -4m^2 t + 4m^2 t + t^2 = t^2$$

$$\vec{OA} \cdot \vec{OB} = t^2 + y_1 y_2 = t^2 - 4t = -4$$

$$t^2 - 4t + 4 = 0 \implies (t-2)^2 = 0 \implies t = 2$$

**第5步：** 确定定点

直线 $l: x = my + 2$，过定点 $(2, 0)$。

但题目说过焦点 $F$，$F = (1, 0)$。

**重新理解题意：** 题目第（2）问中直线 $l$ 不一定过焦点，而是任意直线交抛物线于 $A$，$B$ 两点。

设 $l: x = my + t$，由上述计算 $t = 2$。

$$\boxed{\text{直线 } l \text{ 过定点 } (2, 0)}$$

验证：当 $l$ 过 $(2, 0)$ 时，$x = my + 2$，$y^2 = 4(my+2) = 4my + 8$，$y^2 - 4my - 8 = 0$。

$y_1 y_2 = -8$，$x_1 x_2 = 4$。

$\vec{OA} \cdot \vec{OB} = 4 + (-8) = -4$。✓

**⚠️ 易错提醒：** 设直线方程时注意讨论斜率是否存在；利用韦达定理时注意判别式 $\Delta > 0$ 的条件。

**💡 解题思路总结：** 第（1）问利用焦半径公式直接求 $p$；第（2）问设直线为 $x = my + t$，联立抛物线方程，利用韦达定理和向量数量积条件求 $t$，从而确定定点。
