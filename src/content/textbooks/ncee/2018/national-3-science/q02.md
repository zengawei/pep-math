**题目：** 已知集合 $A = \{x \mid x^2 - 2x - 3 \leqslant 0\}$，$B = \{1, 3\}$，则 $A \cap B = $（）

A. $\{1\}$

B. $\{3\}$

C. $\{1, 3\}$

D. $\varnothing$

---

**解答：**

**第1步：** 求解集合 $A$
> 📌 运用知识点：集合运算

解不等式 $x^2 - 2x - 3 \leqslant 0$：

$$(x-3)(x+1) \leqslant 0$$

所以 $-1 \leqslant x \leqslant 3$，即 $A = [-1, 3]$。

**第2步：** 求交集
> 📌 运用知识点：集合运算

$$A \cap B = [-1, 3] \cap \{1, 3\} = \{1, 3\}$$

**答案：** C
