**题目：** $\triangle ABC$ 的内角 $A$，$B$，$C$ 的对边分别为 $a$，$b$，$c$。若 $b^2 + c^2 - a^2 = bc$，$b + c = 2$，则 $a$ 的最小值为（）

A. $1$

B. $\sqrt{2}$

C. $\sqrt{3}$

D. $2$

---

**解答：**

**第1步：** 利用余弦定理求角 $A$
> 📌 运用知识点：三角恒等变换

由余弦定理 $a^2 = b^2 + c^2 - 2bc\cos A$，结合条件 $b^2 + c^2 - a^2 = bc$：

$$2bc\cos A = bc \implies \cos A = \frac{1}{2} \implies A = \frac{\pi}{3}$$

**第2步：** 用 $bc$ 表示 $a^2$
> 📌 运用知识点：余弦定理、基本不等式

$$a^2 = b^2 + c^2 - bc = (b+c)^2 - 3bc = 4 - 3bc$$

**第3步：** 利用基本不等式求 $bc$ 的范围
> 📌 运用知识点：基本不等式

由均值不等式：

$$bc \leqslant \left(\frac{b+c}{2}\right)^2 = 1$$

等号在 $b = c = 1$ 时成立。

**第4步：** 求 $a$ 的最小值

$$a^2 = 4 - 3bc \geqslant 4 - 3 = 1$$

所以 $a \geqslant 1$，当 $b = c = 1$ 时取等号。

验证：$b = c = 1$，$A = \dfrac{\pi}{3}$，构成等边三角形，$a = 1$。

**答案：** A
