**题目：** 函数 $f(x) = x^3 - 3x^2 + 2$ 的单调递减区间为（  ）

(A) $(-\infty, 0)$

(B) $(0, 2)$

(C) $(2, +\infty)$

(D) $(-\infty, 0)$ 和 $(2, +\infty)$

---

**解答：**

**第1步：** 求导数
> 📌 运用知识点：导数的运算

$$f'(x) = 3x^2 - 6x = 3x(x - 2)$$

**第2步：** 求 $f'(x) < 0$ 的区间
> 📌 运用知识点：导数与单调性

令 $f'(x) < 0$：$3x(x - 2) < 0$

解得 $0 < x < 2$。

所以 $f(x)$ 的单调递减区间为 $(0, 2)$。

**正确答案：** (B)
