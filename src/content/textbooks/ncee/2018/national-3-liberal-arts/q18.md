**题目：** 在 $\triangle ABC$ 中，内角 $A$，$B$，$C$ 的对边分别为 $a$，$b$，$c$。已知 $a = 2$，$b = 3$，$B = \dfrac{\pi}{3}$。

（1）求 $\sin A$ 的值；

（2）求 $\cos C$ 的值。

---

**解答：**

**第1步：** 利用正弦定理求 $\sin A$
> 📌 运用知识点：正弦定理

$$\frac{a}{\sin A} = \frac{b}{\sin B}$$

$$\frac{2}{\sin A} = \frac{3}{\sin \dfrac{\pi}{3}} = \frac{3}{\dfrac{\sqrt{3}}{2}} = 2\sqrt{3}$$

$$\sin A = \frac{2}{2\sqrt{3}} = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}$$

**第2步：** 确定 $A$ 的范围，求 $\cos A$
> 📌 运用知识点：三角函数的基本关系

因为 $a < b$，所以 $A < B = \dfrac{\pi}{3}$，$A$ 为锐角。

$$\cos A = \sqrt{1 - \sin^2 A} = \sqrt{1 - \frac{1}{3}} = \sqrt{\frac{2}{3}} = \frac{\sqrt{6}}{3}$$

**第3步：** 求 $\cos C$
> 📌 运用知识点：三角形内角和与三角恒等变换

$$C = \pi - A - B = \pi - A - \frac{\pi}{3} = \frac{2\pi}{3} - A$$

$$\cos C = \cos\left(\frac{2\pi}{3} - A\right) = \cos\frac{2\pi}{3}\cos A + \sin\frac{2\pi}{3}\sin A$$

$$= \left(-\frac{1}{2}\right) \times \frac{\sqrt{6}}{3} + \frac{\sqrt{3}}{2} \times \frac{\sqrt{3}}{3}$$

$$= -\frac{\sqrt{6}}{6} + \frac{3}{6} = \frac{3 - \sqrt{6}}{6}$$

**⚠️ 易错提醒：**
1. 正弦定理中注意对应关系：$a$ 对应 $\sin A$，$b$ 对应 $\sin B$，不要搞混。
2. 由 $\sin A$ 求 $\cos A$ 时，需要先判断 $A$ 的范围。因为 $a < b$，所以 $A < B$，$A$ 为锐角，$\cos A > 0$。
3. 两角差的余弦公式 $\cos(\alpha - \beta) = \cos\alpha\cos\beta + \sin\alpha\sin\beta$，注意符号。

**💡 解题思路总结：**
第一问直接用正弦定理求 $\sin A$；第二问的关键是利用 $C = \pi - A - B$ 将 $\cos C$ 转化为关于 $A$ 和 $B$ 的三角函数表达式，再用两角差的余弦公式展开求解。注意根据边角关系判断角的范围，确定三角函数值的正负。
