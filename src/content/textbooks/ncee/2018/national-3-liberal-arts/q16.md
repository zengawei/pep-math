**题目：** 已知函数 $f(x) = x^3 + ax^2 + bx + 1$ 的导数 $f'(x)$ 满足 $f'(1) = 0$，$f'(2) = 0$，则 $a + b = $ ______。

---

**解答：**

**第1步：** 求导数
> 📌 运用知识点：导数的运算

$$f'(x) = 3x^2 + 2ax + b$$

**第2步：** 利用已知条件列方程
> 📌 运用知识点：极值点处导数为零

$f'(1) = 0$：$3 + 2a + b = 0$ ①

$f'(2) = 0$：$12 + 4a + b = 0$ ②

**第3步：** 解方程组

② $-$ ①：$9 + 2a = 0$，$a = -\dfrac{9}{2}$。

代入①：$3 + 2 \times \left(-\dfrac{9}{2}\right) + b = 0$，$3 - 9 + b = 0$，$b = 6$。

**第4步：** 求 $a + b$

$$a + b = -\frac{9}{2} + 6 = -\frac{9}{2} + \frac{12}{2} = \frac{3}{2}$$

**正确答案：** $\dfrac{3}{2}$
