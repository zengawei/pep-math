**题目：** 已知椭圆 $C$：$\dfrac{x^2}{4} + y^2 = 1$，$F_1$，$F_2$ 分别为 $C$ 的左、右焦点。

（1）求椭圆 $C$ 的离心率；

（2）过 $F_1$ 的直线 $l$ 与 $C$ 交于 $A$，$B$ 两点，求 $\triangle ABF_2$ 的面积的最大值。

---

**解答：**

**第1步：** 确定椭圆参数
> 📌 运用知识点：椭圆的标准方程

由椭圆方程 $\dfrac{x^2}{4} + y^2 = 1$ 可知：

$a^2 = 4$，$b^2 = 1$，$c^2 = a^2 - b^2 = 4 - 1 = 3$

$a = 2$，$c = \sqrt{3}$

**第2步：** 求离心率

$$e = \frac{c}{a} = \frac{\sqrt{3}}{2}$$

**第3步：** 设直线方程并联立椭圆
> 📌 运用知识点：椭圆与直线的位置关系

$F_1(-\sqrt{3}, 0)$，$F_2(\sqrt{3}, 0)$，$|F_1 F_2| = 2\sqrt{3}$。

设直线 $l$：$x = my - \sqrt{3}$（过 $F_1$，设 $x$ 关于 $y$ 的表达式避免斜率不存在的讨论）。

代入 $\dfrac{x^2}{4} + y^2 = 1$：

$$\frac{(my - \sqrt{3})^2}{4} + y^2 = 1$$

$$(my - \sqrt{3})^2 + 4y^2 = 4$$

$$m^2 y^2 - 2\sqrt{3}my + 3 + 4y^2 = 4$$

$$(m^2 + 4)y^2 - 2\sqrt{3}my - 1 = 0$$

**第4步：** 利用韦达定理
> 📌 运用知识点：韦达定理

设 $A(x_1, y_1)$，$B(x_2, y_2)$，则：

$$y_1 + y_2 = \frac{2\sqrt{3}m}{m^2 + 4}, \quad y_1 y_2 = \frac{-1}{m^2 + 4}$$

$$|y_1 - y_2|^2 = (y_1 + y_2)^2 - 4y_1 y_2 = \frac{12m^2}{(m^2 + 4)^2} + \frac{4}{m^2 + 4} = \frac{12m^2 + 4(m^2 + 4)}{(m^2 + 4)^2} = \frac{16(m^2 + 1)}{(m^2 + 4)^2}$$

$$|y_1 - y_2| = \frac{4\sqrt{m^2 + 1}}{m^2 + 4}$$

**第5步：** 求面积表达式
> 📌 运用知识点：三角形面积

$\triangle ABF_2$ 以 $|F_1 F_2|$ 为底边在 $x$ 轴上的投影，$A$、$B$ 到 $x$ 轴的距离之差决定高：

$$S = \frac{1}{2} |F_1 F_2| \cdot |y_1 - y_2| = \frac{1}{2} \times 2\sqrt{3} \times \frac{4\sqrt{m^2 + 1}}{m^2 + 4} = \frac{4\sqrt{3}\sqrt{m^2 + 1}}{m^2 + 4}$$

**第6步：** 求面积最大值
> 📌 运用知识点：基本不等式

令 $t = \sqrt{m^2 + 1} \geqslant 1$，则 $m^2 + 4 = t^2 + 3$。

$$S = \frac{4\sqrt{3} \cdot t}{t^2 + 3} = \frac{4\sqrt{3}}{t + \dfrac{3}{t}}$$

由均值不等式：$t + \dfrac{3}{t} \geqslant 2\sqrt{t \cdot \dfrac{3}{t}} = 2\sqrt{3}$，等号成立当且仅当 $t = \dfrac{3}{t}$，即 $t = \sqrt{3}$（此时 $m^2 = 2$，$m = \pm\sqrt{2}$）。

$$S_{\max} = \frac{4\sqrt{3}}{2\sqrt{3}} = 2$$

**⚠️ 易错提醒：**
1. 设直线方程时，若用 $y = k(x + \sqrt{3})$ 会漏掉斜率不存在（$x = -\sqrt{3}$）的情况，而设 $x = my - \sqrt{3}$ 则不会遗漏。
2. $\triangle ABF_2$ 的面积不能直接用 $\dfrac{1}{2}|AB| \times d$ 来算（计算复杂），而是利用 $S = \dfrac{1}{2}|F_1F_2| \cdot |y_1 - y_2|$ 更简便。
3. 均值不等式取等条件 $t = \sqrt{3} \geqslant 1$，满足 $t$ 的范围要求，不要忘记验证。

**💡 解题思路总结：**
第一问直接由椭圆参数求离心率。第二问是经典的"焦点弦与面积最值"问题：设直线 $x = my - \sqrt{3}$，联立椭圆方程后用韦达定理得到 $|y_1 - y_2|$ 的表达式，将面积转化为关于 $m$ 的函数，再通过换元 $t = \sqrt{m^2 + 1}$ 并利用均值不等式求最值。核心技巧是合理设线、韦达定理、均值不等式三步配合。
