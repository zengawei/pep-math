**题目：** 若 $a = 2^{0.3}$，$b = \log_2 0.3$，$c = 0.3^2$，则 $a$，$b$，$c$ 的大小关系为（  ）

(A) $b < c < a$

(B) $b < a < c$

(C) $c < b < a$

(D) $c < a < b$

---

**解答：**

**第1步：** 判断各值与 $0$ 和 $1$ 的关系
> 📌 运用知识点：指数函数与对数函数的性质

$a = 2^{0.3}$：因为 $2^{0.3} > 2^0 = 1$，所以 $a > 1$。

$b = \log_2 0.3$：因为 $0.3 < 1$，$\log_2 0.3 < \log_2 1 = 0$，所以 $b < 0$。

$c = 0.3^2 = 0.09$：$0 < c < 1$。

**第2步：** 比较大小
> 📌 运用知识点：实数大小比较

$$b < 0 < c < 1 < a$$

即 $b < c < a$。

**正确答案：** (A)
