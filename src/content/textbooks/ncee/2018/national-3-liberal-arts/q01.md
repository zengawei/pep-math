**题目：** 已知集合 $A = \{0, 1, 2, 3\}$，$B = \{x \mid x^2 - 2x \leqslant 0\}$，则 $A \cap B = $（  ）

(A) $\{0, 1\}$

(B) $\{0, 1, 2\}$

(C) $\{1, 2\}$

(D) $\{1, 2, 3\}$

---

**解答：**

**第1步：** 解不等式，求集合 $B$
> 📌 运用知识点：一元二次不等式

解不等式 $x^2 - 2x \leqslant 0$：

$$x(x - 2) \leqslant 0$$

解得 $0 \leqslant x \leqslant 2$，即 $B = \{x \mid 0 \leqslant x \leqslant 2\} = [0, 2]$。

**第2步：** 求 $A \cap B$
> 📌 运用知识点：集合的交集运算

$A = \{0, 1, 2, 3\}$，$B = [0, 2]$。

$A$ 中属于 $B$ 的元素为 $0, 1, 2$。

$$A \cap B = \{0, 1, 2\}$$

**正确答案：** (B)
