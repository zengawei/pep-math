**题目：**

已知函数 $f(x) = x\ln x - \dfrac{a}{2}x^2$（$a \in \mathbb{R}$）。

（1）当 $a = 1$ 时，求 $f(x)$ 的单调区间和极值；

（2）若 $f(x) \leq 0$ 对一切 $x > 0$ 恒成立，求 $a$ 的取值范围。

---

**解答：**

**（1）**

**第1步：** 当 $a = 1$ 时，$f(x) = x\ln x - \dfrac{1}{2}x^2$，定义域为 $(0, +\infty)$。

求导：

$$f'(x) = \ln x + x \cdot \frac{1}{x} - x = \ln x + 1 - x$$

> 📌 运用知识点：derivative-extrema

**第2步：** 令 $f'(x) = 0$

$\ln x + 1 - x = 0$

观察知 $x = 1$ 是一个解：$\ln 1 + 1 - 1 = 0$ ✓

**第3步：** 分析 $f'(x)$ 的符号

设 $g(x) = \ln x + 1 - x$，则 $g'(x) = \dfrac{1}{x} - 1 = \dfrac{1-x}{x}$。

当 $0 < x < 1$ 时，$g'(x) > 0$，$g(x)$ 单调递增；

当 $x > 1$ 时，$g'(x) < 0$，$g(x)$ 单调递减。

所以 $g(x) \leq g(1) = 0$，即 $f'(x) \leq 0$，等号仅在 $x = 1$ 时成立。

因此 $f(x)$ 在 $(0, +\infty)$ 上单调递减。

等等，让我重新检查。

$f'(x) = \ln x + 1 - x$

$g(x) = \ln x + 1 - x$，$g'(x) = \frac{1}{x} - 1$

$g'(x) = 0 \implies x = 1$

$g(1) = 0 + 1 - 1 = 0$

$g(x)$ 在 $x = 1$ 处取最大值 $0$，所以 $g(x) \leq 0$ 对所有 $x > 0$ 成立。

即 $f'(x) \leq 0$，$f(x)$ 在 $(0, +\infty)$ 上单调递减，无极值。

但让我重新验证：$f'(1) = \ln 1 + 1 - 1 = 0$。

$f'(x) \leq 0$ 恒成立，$f(x)$ 在 $(0, +\infty)$ 上单调递减。

$f(x)$ 无极值（$x=1$ 是拐点而非极值点，因为 $f'$ 不变号）。

实际上，$f'(x) \leq 0$ 且仅在 $x=1$ 处等于零，所以 $f(x)$ 严格单调递减，无极值点。

**修正：** $f(x)$ 在 $(0, +\infty)$ 上单调递减，无极值。

> 📌 运用知识点：derivative-applications

**（2）**

**第4步：** 分析条件

$f(x) \leq 0$ 对所有 $x > 0$ 恒成立，即：

$$x\ln x - \frac{a}{2}x^2 \leq 0$$

$$x\ln x \leq \frac{a}{2}x^2$$

因为 $x > 0$，两边除以 $x$：

$$\ln x \leq \frac{a}{2}x$$

即 $\dfrac{\ln x}{x} \leq \dfrac{a}{2}$ 对所有 $x > 0$ 恒成立。

**第5步：** 求 $h(x) = \dfrac{\ln x}{x}$ 的最大值

$$h'(x) = \frac{\frac{1}{x} \cdot x - \ln x \cdot 1}{x^2} = \frac{1 - \ln x}{x^2}$$

令 $h'(x) = 0$，得 $\ln x = 1$，即 $x = e$。

当 $0 < x < e$ 时，$h'(x) > 0$，$h(x)$ 单调递增；

当 $x > e$ 时，$h'(x) < 0$，$h(x)$ 单调递减。

所以 $h(x)$ 在 $x = e$ 处取最大值：

$$h(e) = \frac{\ln e}{e} = \frac{1}{e}$$

**第6步：** 确定 $a$ 的范围

要使 $\dfrac{\ln x}{x} \leq \dfrac{a}{2}$ 对所有 $x > 0$ 恒成立，需：

$$\frac{a}{2} \geq \frac{1}{e}$$

$$a \geq \frac{2}{e}$$

所以 $a$ 的取值范围为 $\left[\dfrac{2}{e}, +\infty\right)$。

**⚠️ 易错提醒：** 第（1）问中 $f'(x) = \ln x + 1 - x$ 的零点分析需要构造辅助函数 $g(x)$ 并利用 $g'(x)$ 判断，不能直接看出 $f'(x)$ 的符号变化。第（2）问中除以 $x$ 时注意 $x > 0$，不等号方向不变。

**💡 解题思路总结：** 导数综合题的核心方法：（1）求导后若不易判断符号，构造辅助函数再次求导；（2）恒成立问题转化为求函数最值问题，即 $f(x) \leq 0$ 恒成立 $\iff$ $f(x)_{\max} \leq 0$。分离参数法是处理含参恒成立问题的常用技巧。
