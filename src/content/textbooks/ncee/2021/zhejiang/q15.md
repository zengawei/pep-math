**题目：**

已知向量 $\vec{a} = (2, 1)$，$\vec{b} = (1, -1)$，若 $\vec{c} = 2\vec{a} - \vec{b}$，则 $|\vec{c}| = $ \_\_\_\_\_\_。

---

**解答：**

**第1步：** 计算 $2\vec{a}$

$2\vec{a} = 2(2, 1) = (4, 2)$

> 📌 运用知识点：vector-coordinate

**第2步：** 计算 $\vec{c} = 2\vec{a} - \vec{b}$

$\vec{c} = (4, 2) - (1, -1) = (4-1, 2-(-1)) = (3, 3)$

**第3步：** 求模

$$|\vec{c}| = \sqrt{3^2 + 3^2} = \sqrt{9 + 9} = \sqrt{18} = 3\sqrt{2}$$

**答案：** $\boxed{3\sqrt{2}}$

**⚠️ 易错提醒：** 向量减法中 $2 - (-1) = 3$，注意负号的处理。求模时不要忘记开方。

**💡 解题思路总结：** 向量的线性运算按坐标分量进行，先做数乘再做加减，最后用模的公式 $|\vec{c}| = \sqrt{x^2 + y^2}$ 求结果。
