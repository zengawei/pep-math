**题目：**

若实数 $x$，$y$ 满足约束条件 $\begin{cases} x + y \leq 4 \\ x - y \leq 2 \\ x \geq 0 \\ y \geq 0 \end{cases}$，则 $z = 3x + y$ 的最大值为

A. $6$

B. $8$

C. $10$

D. $12$

---

**解答：**

**第1步：** 确定可行域的顶点

联立各约束条件求交点：

- $x = 0, y = 0$：顶点 $(0, 0)$
- $x = 0, x + y = 4$：顶点 $(0, 4)$，但需检查 $x - y = 0 - 4 = -4 \leq 2$ ✓
- $y = 0, x - y = 2$：顶点 $(2, 0)$，检查 $x + y = 2 \leq 4$ ✓
- $y = 0, x + y = 4$：顶点 $(4, 0)$，检查 $x - y = 4 \leq 2$ ✗，不在可行域
- $x + y = 4$ 与 $x - y = 2$ 联立：$2x = 6$，$x = 3, y = 1$，顶点 $(3, 1)$

> 📌 运用知识点：basic-inequality

**第2步：** 计算各顶点处 $z$ 的值

- $z(0, 0) = 0$
- $z(0, 4) = 4$
- $z(2, 0) = 6$
- $z(3, 1) = 9 + 1 = 10$

**第3步：** 比较得最大值

$z_{\max} = 10$，在点 $(3, 1)$ 处取得。

**答案：C**

**⚠️ 易错提醒：** 求可行域顶点时，必须逐一验证每个交点是否满足所有约束条件，不能遗漏检查。

**💡 解题思路总结：** 线性规划问题的最优值一定在可行域的顶点处取得。先求出所有顶点，再代入目标函数比较即可。
