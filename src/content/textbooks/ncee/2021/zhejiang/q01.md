**题目：**

已知集合 $A = \{x \mid x^2 - 3x + 2 \leq 0\}$，$B = \{x \mid 1 < x < 3\}$，则 $A \cap B = $

A. $\{x \mid 1 < x \leq 2\}$

B. $\{x \mid 1 \leq x < 3\}$

C. $\{x \mid 1 < x < 2\}$

D. $\{x \mid 2 \leq x < 3\}$

---

**解答：**

**第1步：** 解不等式 $x^2 - 3x + 2 \leq 0$

因式分解：$(x-1)(x-2) \leq 0$

解得：$1 \leq x \leq 2$

所以 $A = \{x \mid 1 \leq x \leq 2\}$

> 📌 运用知识点：set-operations

**第2步：** 求 $A \cap B$

$A = [1, 2]$，$B = (1, 3)$

$A \cap B = \{x \mid 1 < x \leq 2\}$

**答案：A**

**⚠️ 易错提醒：** 注意集合 $A$ 的端点是否取等号。解二次不等式时要准确判断等号成立的条件，避免与集合 $B$ 的开区间混淆。

**💡 解题思路总结：** 先分别求出两个集合的范围，再根据交集定义找出公共部分。注意端点的开闭情况。
