**题目：**

已知抛物线 $y^2 = 4x$ 的焦点为 $F$，点 $P$ 在该抛物线上，且 $|PF| = 3$，则点 $P$ 的横坐标为

A. $1$

B. $2$

C. $3$

D. $4$

---

**解答：**

**第1步：** 确定抛物线的基本量

$y^2 = 4x$，则 $2p = 4$，$p = 2$。

焦点 $F(1, 0)$，准线方程 $x = -1$。

> 📌 运用知识点：parabola-properties

**第2步：** 利用抛物线的焦半径公式

设 $P(x_0, y_0)$，由抛物线的定义：

$$|PF| = x_0 + \frac{p}{2} = x_0 + 1$$

**第3步：** 求横坐标

$$x_0 + 1 = 3 \implies x_0 = 2$$

**答案：B**

**⚠️ 易错提醒：** 抛物线 $y^2 = 2px$ 的焦半径公式为 $|PF| = x_0 + \frac{p}{2}$，不要与 $x^2 = 2py$ 的公式混淆。注意本题 $2p = 4$，所以 $\frac{p}{2} = 1$。

**💡 解题思路总结：** 抛物线上一点到焦点的距离等于该点到准线的距离（抛物线定义），利用焦半径公式可以直接求出点的坐标。
