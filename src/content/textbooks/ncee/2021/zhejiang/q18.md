**题目：**

在 $\triangle ABC$ 中，角 $A$，$B$，$C$ 的对边分别为 $a$，$b$，$c$，已知 $a = 2$，$b = 3$，$\cos C = \dfrac{1}{4}$。

（1）求 $c$ 的值；

（2）求 $\sin(A + C)$ 的值。

---

**解答：**

**（1）**

**第1步：** 利用余弦定理

$$c^2 = a^2 + b^2 - 2ab\cos C$$

**第2步：** 代入已知数据

$$c^2 = 2^2 + 3^2 - 2 \times 2 \times 3 \times \frac{1}{4} = 4 + 9 - 3 = 10$$

> 📌 运用知识点：trig-identity

**第3步：** 求解

$$c = \sqrt{10}$$

**（2）**

**第4步：** 化简目标表达式

在 $\triangle ABC$ 中，$A + B + C = \pi$，所以 $A + C = \pi - B$。

$$\sin(A + C) = \sin(\pi - B) = \sin B$$

> 📌 运用知识点：trig-function

**第5步：** 先求 $\sin C$

因为 $\cos C = \dfrac{1}{4}$，$C \in (0, \pi)$，所以：

$$\sin C = \sqrt{1 - \cos^2 C} = \sqrt{1 - \frac{1}{16}} = \sqrt{\frac{15}{16}} = \frac{\sqrt{15}}{4}$$

**第6步：** 利用正弦定理求 $\sin B$

$$\frac{b}{\sin B} = \frac{c}{\sin C}$$

$$\sin B = \frac{b \sin C}{c} = \frac{3 \times \dfrac{\sqrt{15}}{4}}{\sqrt{10}} = \frac{3\sqrt{15}}{4\sqrt{10}} = \frac{3\sqrt{15}}{4\sqrt{10}} \times \frac{\sqrt{10}}{\sqrt{10}} = \frac{3\sqrt{150}}{40} = \frac{3 \times 5\sqrt{6}}{40} = \frac{15\sqrt{6}}{40} = \frac{3\sqrt{6}}{8}$$

所以 $\sin(A+C) = \dfrac{3\sqrt{6}}{8}$。

**⚠️ 易错提醒：** 第（2）问中，关键是利用 $A + B + C = \pi$ 将 $\sin(A+C)$ 转化为 $\sin B$，不要直接展开 $\sin(A+C)$。化简 $\frac{\sqrt{15}}{\sqrt{10}}$ 时注意 $\sqrt{\frac{15}{10}} = \sqrt{\frac{3}{2}} = \frac{\sqrt{6}}{2}$。

**💡 解题思路总结：** 解三角形问题的核心工具是正弦定理和余弦定理。注意三角形内角和为 $\pi$ 这一隐含条件的灵活运用。
