**题目：**

如图，在四棱锥 $P\text{-}ABCD$ 中，底面 $ABCD$ 是正方形，$PA \perp$ 底面 $ABCD$，$PA = AB = 2$。

（1）证明：$BD \perp PC$；

（2）求二面角 $P\text{-}BD\text{-}A$ 的余弦值。

---

**解答：**

**（1）**

**第1步：** 建立空间直角坐标系

以 $A$ 为原点，$AB$、$AD$、$AP$ 所在直线分别为 $x$、$y$、$z$ 轴。

各点坐标：$A(0,0,0)$，$B(2,0,0)$，$C(2,2,0)$，$D(0,2,0)$，$P(0,0,2)$。

> 📌 运用知识点：space-vector-coordinate

**第2步：** 求相关向量

$\vec{BD} = D - B = (-2, 2, 0)$

$\vec{PC} = C - P = (2, 2, -2)$

**第3步：** 计算点积

$$\vec{BD} \cdot \vec{PC} = (-2) \times 2 + 2 \times 2 + 0 \times (-2) = -4 + 4 + 0 = 0$$

因为 $\vec{BD} \cdot \vec{PC} = 0$，所以 $BD \perp PC$。

**（2）**

**第4步：** 求二面角 $P\text{-}BD\text{-}A$

需要找两个半平面的法向量。二面角 $P\text{-}BD\text{-}A$ 的棱为 $BD$。

平面 $PBD$ 的法向量 $\vec{n_1}$：

$\vec{BD} = (-2, 2, 0)$，$\vec{BP} = P - B = (-2, 0, 2)$

设 $\vec{n_1} = (x, y, z)$，则：

$\vec{n_1} \cdot \vec{BD} = -2x + 2y = 0 \implies x = y$

$\vec{n_1} \cdot \vec{BP} = -2x + 2z = 0 \implies x = z$

取 $\vec{n_1} = (1, 1, 1)$。

> 📌 运用知识点：spatial-position-relation

**第5步：** 求平面 $ABD$ 的法向量

平面 $ABD$ 即底面 $ABCD$，法向量为 $\vec{n_2} = (0, 0, 1)$（$z$ 轴方向）。

**第6步：** 计算二面角的余弦值

$$\cos\theta = \frac{|\vec{n_1} \cdot \vec{n_2}|}{|\vec{n_1}| \cdot |\vec{n_2}|} = \frac{|1 \times 0 + 1 \times 0 + 1 \times 1|}{\sqrt{3} \times 1} = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}$$

由图可知二面角 $P\text{-}BD\text{-}A$ 为锐角，所以余弦值为 $\dfrac{\sqrt{3}}{3}$。

**⚠️ 易错提醒：** 建系时注意 $PA \perp$ 底面，所以 $PA$ 方向为 $z$ 轴。求法向量时要验证方向是否正确，二面角的余弦值正负取决于两个法向量的方向关系。

**💡 解题思路总结：** 立体几何证明垂直用向量点积为零；求二面角先求两个半平面的法向量，再用夹角公式。建系的关键是找到三条两两垂直的直线。
