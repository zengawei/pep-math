**题目：**

已知函数 $f(x) = x^3 - 3x + 1$，则下列结论正确的是

A. $f(x)$ 在 $(-\infty, -1)$ 上单调递增

B. $f(x)$ 的极大值为 $3$

C. $f(x)$ 有三个零点

D. $f(x)$ 的极小值为 $-1$

---

**解答：**

**第1步：** 求导

$f'(x) = 3x^2 - 3 = 3(x^2 - 1) = 3(x+1)(x-1)$

令 $f'(x) = 0$，得 $x = -1$ 或 $x = 1$。

> 📌 运用知识点：derivative-monotonicity

**第2步：** 分析单调性

当 $x < -1$ 时，$f'(x) > 0$，$f(x)$ 单调递增；

当 $-1 < x < 1$ 时，$f'(x) < 0$，$f(x)$ 单调递减；

当 $x > 1$ 时，$f'(x) > 0$，$f(x)$ 单调递增。

✅ A 正确。

**第3步：** 分析极值

极大值：$f(-1) = (-1)^3 - 3(-1) + 1 = -1 + 3 + 1 = 3$

极小值：$f(1) = 1^3 - 3 \times 1 + 1 = 1 - 3 + 1 = -1$

✅ B 正确。

✅ D 正确。

> 📌 运用知识点：derivative-applications

**第4步：** 分析零点个数

$f(-1) = 3 > 0$（极大值），$f(1) = -1 < 0$（极小值）。

因为 $f(x) \to -\infty$（$x \to -\infty$），$f(-1) = 3 > 0$，在 $(-\infty, -1)$ 有一个零点；

$f(-1) = 3 > 0$，$f(1) = -1 < 0$，在 $(-1, 1)$ 有一个零点；

$f(1) = -1 < 0$，$f(x) \to +\infty$（$x \to +\infty$），在 $(1, +\infty)$ 有一个零点。

共三个零点。

✅ C 正确。

**答案：A、B、C、D**

**⚠️ 易错提醒：** 判断零点个数时，要结合函数的单调性和极值的正负，利用零点存在性定理在每个单调区间上判断。注意极大值不一定是最大值。

**💡 解题思路总结：** 三次函数零点个数的判断方法：求导 → 求极值 → 根据极值正负和函数趋向判断每个单调区间是否有零点。
