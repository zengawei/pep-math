**题目：** 在三棱锥 $P\text{-}ABC$ 中，$PA \perp$ 底面 $ABC$，$AB \perp BC$，$PA = AB = BC = 2$。$D$ 为 $PB$ 的中点。

（1）证明：$AD \perp PC$；

（2）求二面角 $D\text{-}AC\text{-}B$ 的余弦值。

---

**解答：**

**（1）证明 $AD \perp PC$**

**第1步：** 建立空间直角坐标系
> 📌 运用知识点：space-vector-coordinate

以 $A$ 为原点，$\overrightarrow{AB}$ 为 $x$ 轴正方向，$\overrightarrow{AC}$ 在 $xy$ 平面内，$\overrightarrow{AP}$ 为 $z$ 轴正方向。

因为 $AB \perp BC$，$AB = BC = 2$：

$A = (0, 0, 0)$，$B = (2, 0, 0)$，$C = (2, 2, 0)$，$P = (0, 0, 2)$。

$D$ 为 $PB$ 中点：$D = \left(\dfrac{0+2}{2}, \dfrac{0+0}{2}, \dfrac{2+0}{2}\right) = (1, 0, 1)$。

**第2步：** 计算点积
> 📌 运用知识点：space-vector-operations

$\overrightarrow{AD} = (1, 0, 1)$，$\overrightarrow{PC} = C - P = (2, 2, -2)$。

$$\overrightarrow{AD} \cdot \overrightarrow{PC} = 1 \times 2 + 0 \times 2 + 1 \times (-2) = 2 + 0 - 2 = 0$$

所以 $AD \perp PC$。$\boxed{AD \perp PC}$

**（2）求二面角 $D\text{-}AC\text{-}B$ 的余弦值**

**第3步：** 求平面 $DAC$ 的法向量
> 📌 运用知识点：space-vector-coordinate

$\overrightarrow{AC} = (2, 2, 0)$，$\overrightarrow{AD} = (1, 0, 1)$。

设平面 $DAC$ 的法向量 $\vec{n_1} = (x, y, z)$：

$$\begin{cases} 2x + 2y = 0 \\ x + z = 0 \end{cases} \implies y = -x, \; z = -x$$

取 $x = 1$：$\vec{n_1} = (1, -1, -1)$。

**第4步：** 求平面 $ACB$ 的法向量
> 📌 运用知识点：space-vector-coordinate

平面 $ACB$ 即 $xy$ 平面，法向量 $\vec{n_2} = (0, 0, 1)$。

**第5步：** 计算余弦值
> 📌 运用知识点：spatial-angle

$$\cos\theta = \frac{|\vec{n_1} \cdot \vec{n_2}|}{|\vec{n_1}||\vec{n_2}|} = \frac{|-1|}{\sqrt{3} \times 1} = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}$$

$$\boxed{\cos\theta = \dfrac{\sqrt{3}}{3}}$$

**⚠️ 易错提醒：**
1. 建系时注意利用已知的垂直关系，确保三条轴两两垂直。
2. 二面角的余弦值取法向量点积的绝对值（需根据具体几何关系判断正负）。

**💡 解题思路总结：** 空间向量法解决立体几何问题的核心是"建系→求坐标→算点积/法向量"。证明垂直即证点积为零；求二面角即求两平面法向量的夹角。
