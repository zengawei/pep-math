**题目：** 已知 $x > 0$，$y > 0$，且 $x + 2y = 1$，则 $\dfrac{1}{x} + \dfrac{1}{y}$ 的最小值为 ______。

---

**解答：**

**第1步：** 利用"乘 $1$ 法"
> 📌 运用知识点：basic-inequality

$$\frac{1}{x} + \frac{1}{y} = \left(\frac{1}{x} + \frac{1}{y}\right)(x + 2y) = 1 + \frac{2y}{x} + \frac{x}{y} + 2 = 3 + \frac{2y}{x} + \frac{x}{y}$$

**第2步：** 应用基本不等式
> 📌 运用知识点：basic-inequality

$$\frac{2y}{x} + \frac{x}{y} \geqslant 2\sqrt{\frac{2y}{x} \cdot \frac{x}{y}} = 2\sqrt{2}$$

等号成立条件：$\dfrac{2y}{x} = \dfrac{x}{y}$，即 $x^2 = 2y^2$，$x = \sqrt{2}y$。

代入 $x + 2y = 1$：$\sqrt{2}y + 2y = 1$，$y = \dfrac{1}{\sqrt{2} + 2} = \dfrac{2 - \sqrt{2}}{2}$，$x = \sqrt{2} - 1 > 0$。满足条件。

$$\left(\frac{1}{x} + \frac{1}{y}\right)_{\min} = 3 + 2\sqrt{2}$$

**答案：** $3 + 2\sqrt{2}$
