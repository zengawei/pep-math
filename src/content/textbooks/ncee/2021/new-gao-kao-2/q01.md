**题目：** 已知集合 $A = \{1, 2, 3\}$，$B = \{x \mid x^2 - 5x + 6 = 0\}$，则 $A \cup B = $（  ）

A. $\{1, 2, 3\}$

B. $\{2, 3\}$

C. $\{1, 2, 3, 4\}$

D. $\{1, 2, 3, 5\}$

---

**解答：**

**第1步：** 求解集合 $B$
> 📌 运用知识点：set-operations

$x^2 - 5x + 6 = 0 \implies (x-2)(x-3) = 0 \implies x = 2$ 或 $x = 3$。

$B = \{2, 3\}$。

**第2步：** 求 $A \cup B$
> 📌 运用知识点：set-operations

$A \cup B = \{1, 2, 3\} \cup \{2, 3\} = \{1, 2, 3\}$。

**答案：A**
