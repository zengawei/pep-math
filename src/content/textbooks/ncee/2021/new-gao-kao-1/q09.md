**题目：** 已知 $\sin\alpha + \cos\alpha = \dfrac{\sqrt{2}}{2}$，则下列结论一定正确的是（  ）

A. $\sin 2\alpha = -\dfrac{1}{2}$

B. $\sin\alpha \cos\alpha = -\dfrac{1}{4}$

C. $\sin\alpha - \cos\alpha = \pm\dfrac{\sqrt{6}}{2}$

D. $\tan\alpha = -1$

---

**解答：**

**第1步：** 平方已知等式
> 📌 运用知识点：trig-identity

$(\sin\alpha + \cos\alpha)^2 = \dfrac{1}{2}$

$\sin^2\alpha + 2\sin\alpha\cos\alpha + \cos^2\alpha = \dfrac{1}{2}$

$1 + 2\sin\alpha\cos\alpha = \dfrac{1}{2}$

$\sin\alpha\cos\alpha = -\dfrac{1}{4}$

B 正确。✅

**第2步：** 验证 A 选项
> 📌 运用知识点：trig-identity

$\sin 2\alpha = 2\sin\alpha\cos\alpha = 2 \times \left(-\dfrac{1}{4}\right) = -\dfrac{1}{2}$

A 正确。✅

**第3步：** 验证 C 选项
> 📌 运用知识点：trig-identity

$(\sin\alpha - \cos\alpha)^2 = 1 - 2\sin\alpha\cos\alpha = 1 - 2 \times \left(-\dfrac{1}{4}\right) = 1 + \dfrac{1}{2} = \dfrac{3}{2}$

$\sin\alpha - \cos\alpha = \pm\sqrt{\dfrac{3}{2}} = \pm\dfrac{\sqrt{6}}{2}$

C 正确。✅

**第4步：** 验证 D 选项
> 📌 运用知识点：trig-identity

取 $\sin\alpha\cos\alpha = -\dfrac{1}{4}$，$\sin\alpha + \cos\alpha = \dfrac{\sqrt{2}}{2}$。

$\sin\alpha$ 和 $\cos\alpha$ 是方程 $t^2 - \dfrac{\sqrt{2}}{2}t - \dfrac{1}{4} = 0$ 的两根。

$\tan\alpha = \dfrac{\sin\alpha}{\cos\alpha}$ 的值取决于具体根的分配，不一定是 $-1$。

例如取 $\sin\alpha = \dfrac{\sqrt{2}+\sqrt{6}}{4}$，$\cos\alpha = \dfrac{\sqrt{2}-\sqrt{6}}{4}$，则 $\tan\alpha \neq -1$。

D 不一定正确。❌

**答案：A、B、C**

**⚠️ 易错提醒：** 对已知等式平方是处理 $\sin\alpha \pm \cos\alpha$ 问题的基本方法，注意 $\sin^2\alpha + \cos^2\alpha = 1$ 的运用。D 选项容易误判，需要具体验证。

**💡 解题思路总结：** 已知 $\sin\alpha + \cos\alpha$ 的值，通过平方可求 $\sin\alpha\cos\alpha$ 和 $\sin 2\alpha$；再结合 $(\sin\alpha - \cos\alpha)^2 = 1 - 2\sin\alpha\cos\alpha$ 可求 $\sin\alpha - \cos\alpha$。
