**题目：** 在 $\triangle ABC$ 中，角 $A$，$B$，$C$ 的对边分别为 $a$，$b$，$c$，已知 $a\cos C + c\cos A = b\sin B$。

（1）求角 $B$；

（2）若 $b = 2$，$a = 1$，求 $c$ 和 $\triangle ABC$ 的面积。

---

**解答：**

**（1）求角 $B$**

**第1步：** 利用正弦定理将边化为角
> 📌 运用知识点：trig-identity

由正弦定理 $a = 2R\sin A$，$b = 2R\sin B$，$c = 2R\sin C$，代入已知等式：

$$\sin A\cos C + \sin C\cos A = \sin B \cdot \sin B$$

**第2步：** 利用和角公式化简
> 📌 运用知识点：trig-identity

左边 $= \sin(A + C)$。因为 $A + B + C = \pi$，所以 $\sin(A + C) = \sin(\pi - B) = \sin B$。

$$\sin B = \sin^2 B$$

$$\sin B(1 - \sin B) = 0$$

因为 $B \in (0, \pi)$，$\sin B > 0$，所以 $\sin B = 1$。

$$\boxed{B = \dfrac{\pi}{2}}$$

**（2）求 $c$ 和面积**

**第3步：** 利用勾股定理求 $c$
> 📌 运用知识点：trig-function

$B = \dfrac{\pi}{2}$，$b = 2$，$a = 1$。

$$c = \sqrt{b^2 - a^2} = \sqrt{4 - 1} = \sqrt{3}$$

**第4步：** 计算面积
> 📌 运用知识点：trig-function

$$S_{\triangle ABC} = \frac{1}{2}ac\sin B = \frac{1}{2} \times 1 \times \sqrt{3} \times \sin\frac{\pi}{2} = \frac{\sqrt{3}}{2}$$

$$\boxed{c = \sqrt{3}, \quad S_{\triangle ABC} = \dfrac{\sqrt{3}}{2}}$$

**⚠️ 易错提醒：**
1. 正弦定理"边化角"后，注意利用 $A + B + C = \pi$ 将 $\sin(A+C)$ 化为 $\sin B$。
2. $\sin B = 1$ 在 $(0, \pi)$ 上只有唯一解 $B = \dfrac{\pi}{2}$，不需要讨论其他情况。

**💡 解题思路总结：** 第（1）问核心是"边化角"后用和角公式 $\sin(A+C) = \sin B$ 简化。第（2）问在直角三角形中直接用勾股定理求边，再用面积公式求解。
