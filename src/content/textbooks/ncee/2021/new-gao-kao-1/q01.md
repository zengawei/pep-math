**题目：** 已知集合 $A = \{x \mid -1 < x < 3\}$，$B = \{x \mid x^2 - 4x \leqslant 0\}$，则 $A \cap B = $（  ）

A. $\{x \mid 0 \leqslant x < 3\}$

B. $\{x \mid -1 < x \leqslant 4\}$

C. $\{x \mid 0 \leqslant x \leqslant 4\}$

D. $\{x \mid -1 < x \leqslant 0\}$

---

**解答：**

**第1步：** 求解集合 $B$
> 📌 运用知识点：set-operations

解不等式 $x^2 - 4x \leqslant 0$：

$$x(x - 4) \leqslant 0$$

解得 $0 \leqslant x \leqslant 4$，即 $B = [0, 4]$。

**第2步：** 求 $A \cap B$
> 📌 运用知识点：set-operations

$A = (-1, 3)$，$B = [0, 4]$。

$$A \cap B = [0, 3) = \{x \mid 0 \leqslant x < 3\}$$

**答案：A**
