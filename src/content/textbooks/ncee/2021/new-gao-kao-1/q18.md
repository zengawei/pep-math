**题目：** 已知椭圆 $C: \dfrac{x^2}{4} + y^2 = 1$，过点 $M(1, 0)$ 的直线 $l$ 与椭圆 $C$ 交于 $A$，$B$ 两点。

（1）若 $l$ 的斜率为 $1$，求 $|AB|$；

（2）设点 $B$ 关于 $x$ 轴的对称点为 $B'$，证明：直线 $AB'$ 过定点。

---

**解答：**

**（1）求 $|AB|$**

**第1步：** 写出直线方程并联立
> 📌 运用知识点：conic-section-line

直线 $l: y = x - 1$。代入椭圆方程：

$$\frac{x^2}{4} + (x - 1)^2 = 1$$

$$x^2 + 4(x^2 - 2x + 1) = 4$$

$$5x^2 - 8x = 0$$

$$x(5x - 8) = 0$$

$x_1 = 0$，$x_2 = \dfrac{8}{5}$。

**第2步：** 求 $A$，$B$ 坐标并计算 $|AB|$
> 📌 运用知识点：conic-section-line

$A = (0, -1)$，$B = \left(\dfrac{8}{5}, \dfrac{3}{5}\right)$。

$$|AB| = \sqrt{\left(\frac{8}{5}\right)^2 + \left(\frac{3}{5} + 1\right)^2} = \sqrt{\frac{64}{25} + \frac{64}{25}} = \sqrt{\frac{128}{25}} = \frac{8\sqrt{2}}{5}$$

$$\boxed{|AB| = \dfrac{8\sqrt{2}}{5}}$$

**（2）证明直线 $AB'$ 过定点**

**第3步：** 设直线 $l$ 的方程
> 📌 运用知识点：conic-section-line

设 $l: y = k(x - 1)$（先考虑斜率存在的情况），$A = (x_1, y_1)$，$B = (x_2, y_2)$。

$B' = (x_2, -y_2)$。

代入椭圆方程：

$$\frac{x^2}{4} + k^2(x - 1)^2 = 1$$

$$(1 + 4k^2)x^2 - 8k^2 x + 4k^2 - 4 = 0$$

由韦达定理：

$$x_1 + x_2 = \frac{8k^2}{1 + 4k^2}, \quad x_1 x_2 = \frac{4k^2 - 4}{1 + 4k^2}$$

**第4步：** 求直线 $AB'$ 与 $x$ 轴的交点
> 📌 运用知识点：conic-section-optimization

设直线 $AB'$ 与 $x$ 轴交于点 $(t, 0)$。由 $A$，$B'$，$(t, 0)$ 三点共线：

$$\frac{y_1}{x_1 - t} = \frac{-y_2}{x_2 - t}$$

$$y_1(x_2 - t) = -y_2(x_1 - t)$$

$$y_1 x_2 + y_2 x_1 = t(y_1 + y_2)$$

因为 $y_1 = k(x_1 - 1)$，$y_2 = k(x_2 - 1)$：

左边 $= k(x_1 - 1)x_2 + k(x_2 - 1)x_1 = k(2x_1 x_2 - x_1 - x_2)$

右边 $= t \cdot k(x_1 + x_2 - 2)$

$$t = \frac{2x_1 x_2 - (x_1 + x_2)}{x_1 + x_2 - 2}$$

**第5步：** 代入韦达定理的结果
> 📌 运用知识点：conic-section-line

$$t = \frac{2 \cdot \dfrac{4k^2 - 4}{1 + 4k^2} - \dfrac{8k^2}{1 + 4k^2}}{\dfrac{8k^2}{1 + 4k^2} - 2} = \frac{\dfrac{8k^2 - 8 - 8k^2}{1 + 4k^2}}{\dfrac{8k^2 - 2 - 8k^2}{1 + 4k^2}} = \frac{-8}{-2} = 4$$

所以直线 $AB'$ 恒过定点 $(4, 0)$。

当 $l$ 为 $x = 1$ 时，$A = \left(1, \dfrac{\sqrt{3}}{2}\right)$，$B = \left(1, -\dfrac{\sqrt{3}}{2}\right)$，$B' = \left(1, \dfrac{\sqrt{3}}{2}\right) = A$，此时 $AB'$ 不确定。但取极限情况可知结论一致。

$$\boxed{\text{直线 } AB' \text{ 恒过定点 } (4, 0)}$$

**⚠️ 易错提醒：**
1. 联立直线与椭圆方程时，注意判别式 $\Delta > 0$ 的条件（确保有两个交点）。
2. 三点共线条件的推导中，注意 $y_1, y_2$ 用 $k(x-1)$ 替换后的化简。
3. 需要单独讨论斜率不存在的情况。

**💡 解题思路总结：** 证明直线过定点的关键是将交点坐标用韦达定理表示，消去参数 $k$ 后得到定值。"设而不求"是解析几何的核心策略。
