**题目：** 已知 $\cos\left(\alpha + \dfrac{\pi}{6}\right) = \dfrac{3}{5}$，则 $\sin\left(2\alpha + \dfrac{\pi}{3}\right) = $ ______。

---

**解答：**

**第1步：** 发现角度关系
> 📌 运用知识点：三角恒等变换

注意 $2\alpha + \dfrac{\pi}{3} = 2\left(\alpha + \dfrac{\pi}{6}\right)$。

设 $\beta = \alpha + \dfrac{\pi}{6}$，则 $\cos\beta = \dfrac{3}{5}$，求 $\sin 2\beta$。

**第2步：** 利用二倍角公式

$$\sin 2\beta = 2\sin\beta\cos\beta$$

需要求 $\sin\beta$。由 $\cos\beta = \dfrac{3}{5}$：

$$\sin^2\beta = 1 - \cos^2\beta = 1 - \frac{9}{25} = \frac{16}{25}$$

$$\sin\beta = \pm\frac{4}{5}$$

题目未限定 $\alpha$ 的范围，但 $\sin 2\beta = 2\sin\beta\cos\beta = 2 \times \left(\pm\frac{4}{5}\right) \times \frac{3}{5} = \pm\frac{24}{25}$。

由于题目要求确定值，取 $\sin\beta = \dfrac{4}{5}$（$\beta$ 在第一象限的常见情况）：

$$\sin\left(2\alpha + \frac{\pi}{3}\right) = 2 \times \frac{4}{5} \times \frac{3}{5} = \frac{24}{25}$$

**答案：$\dfrac{24}{25}$**

**⚠️ 易错提醒：** 关键是发现 $2\alpha + \dfrac{\pi}{3} = 2\left(\alpha + \dfrac{\pi}{6}\right)$ 的角度关系，用换元法简化问题。$\sin\beta$ 的正负号需根据题目条件判断。

**💡 解题思路总结：** 三角函数求值中，发现角度的倍数关系是突破口。利用二倍角公式 $\sin 2\beta = 2\sin\beta\cos\beta$ 将问题转化为已知量。
