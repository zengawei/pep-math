**题目：** 在三棱柱 $ABC\text{-}A_1B_1C_1$ 中，各棱长均为 $2$，$A_1$ 在底面 $ABC$ 上的投影为 $BC$ 的中点 $M$。

（1）求证：$A_1A \perp BC$；

（2）求二面角 $A_1\text{-}BC\text{-}A$ 的余弦值。

---

**解答：**

**第1步：** 建立坐标系
> 📌 运用知识点：空间向量坐标

$M$ 为 $BC$ 中点，$A_1$ 在底面的投影为 $M$，所以 $A_1M \perp$ 底面 $ABC$。

底面 $ABC$ 是边长为 $2$ 的正三角形，$M$ 为 $BC$ 中点，$AM \perp BC$，$AM = \sqrt{3}$。

$A_1M = \sqrt{A_1A^2 - AM^2}$... 实际上 $A_1M$ 就是高。

以 $M$ 为原点，$\overrightarrow{MC}$ 为 $x$ 轴，$\overrightarrow{MA}$ 为 $y$ 轴，$\overrightarrow{MA_1}$ 为 $z$ 轴。

$M(0,0,0)$，$C(1,0,0)$，$B(-1,0,0)$，$A(0,\sqrt{3},0)$。

$A_1M \perp$ 底面，$A_1$ 在 $z$ 轴上。$A_1A = 2$，$MA = \sqrt{3}$：

$A_1M = \sqrt{A_1A^2 - MA^2}$... 不对，$A_1A$ 不是斜边。

$A_1 = (0, 0, h)$，$A_1A = |A_1 - A| = \sqrt{0 + 3 + h^2} = 2 \implies h^2 = 1 \implies h = 1$。

$A_1(0, 0, 1)$。

验证：$A_1B = \sqrt{1 + 0 + 1} = \sqrt{2}$。但题目说各棱长为 $2$，$A_1B_1 = AB = 2$，$A_1A = 2$，$BB_1 = 2$。

$B_1 = B + \overrightarrow{AA_1} = (-1, 0, 0) + (0, -\sqrt{3}, 1) = (-1, -\sqrt{3}, 1)$。

$BB_1 = |(0, -\sqrt{3}, 1)| = \sqrt{3 + 1} = 2$ ✓

**第2步：** 证明 $A_1A \perp BC$
> 📌 运用知识点：空间向量证明垂直

$\overrightarrow{A_1A} = A - A_1 = (0, \sqrt{3}, -1)$

$\overrightarrow{BC} = C - B = (2, 0, 0)$

$\overrightarrow{A_1A} \cdot \overrightarrow{BC} = 0 \times 2 + \sqrt{3} \times 0 + (-1) \times 0 = 0$

所以 $A_1A \perp BC$。

$$\boxed{A_1A \perp BC}$$

**第3步：** 求二面角 $A_1\text{-}BC\text{-}A$ 的余弦值
> 📌 运用知识点：空间向量求二面角

二面角 $A_1\text{-}BC\text{-}A$ 的棱为 $BC$。

$\overrightarrow{BC} = (2, 0, 0)$，方向为 $(1, 0, 0)$。

平面 $A_1BC$：$\overrightarrow{BC} = (2,0,0)$，$\overrightarrow{BA_1} = (1, 0, 1)$

法向量 $\vec{n_1} = \overrightarrow{BC} \times \overrightarrow{BA_1} = (0 \times 1 - 0 \times 0, 0 \times 1 - 2 \times 1, 2 \times 0 - 0 \times 1) = (0, -2, 0)$

即 $\vec{n_1} = (0, 1, 0)$。

平面 $ABC$：法向量 $\vec{n_2} = (0, 0, 1)$（底面是 $xy$ 平面）。

$$\cos\theta = \frac{|\vec{n_1} \cdot \vec{n_2}|}{|\vec{n_1}||\vec{n_2}|} = \frac{|0|}{1 \times 1} = 0$$

Hmm, that gives $\cos\theta = 0$, meaning the dihedral angle is $90°$. Let me verify.

Actually, $\vec{n_1} = (0, -2, 0)$ simplifies to $(0, 1, 0)$. $\vec{n_2} = (0, 0, 1)$.

$\vec{n_1} \cdot \vec{n_2} = 0$. So $\cos\theta = 0$, $\theta = 90°$.

Let me verify geometrically. $AM \perp BC$ (since $ABC$ is equilateral and $M$ is midpoint of $BC$). $A_1M \perp BC$ (since $A_1M \perp$ base and $BC$ is in the base). So the dihedral angle $A_1$-$BC$-$A$ is the angle $\angle A_1MA$.

$M = (0,0,0)$, $A_1 = (0,0,1)$, $A = (0,\sqrt{3},0)$.

$\overrightarrow{MA_1} = (0,0,1)$, $\overrightarrow{MA} = (0,\sqrt{3},0)$.

$\cos\angle A_1MA = \frac{\overrightarrow{MA_1} \cdot \overrightarrow{MA}}{|\overrightarrow{MA_1}||\overrightarrow{MA}|} = \frac{0}{1 \cdot \sqrt{3}} = 0$

So the dihedral angle is indeed $90°$ and $\cos\theta = 0$.

$$\boxed{\cos\theta = 0}$$

**⚠️ 易错提醒：** 求二面角时，两个法向量的夹角可能等于二面角或其补角，需要根据几何关系判断。本题中二面角恰好为 $90°$。

**💡 解题思路总结：** 建系时利用投影关系确定坐标系。二面角的余弦值等于两个半平面法向量夹角余弦的绝对值（或取负值，取决于二面角是锐角还是钝角）。
