**题目：** 已知函数 $f(x) = (x - 1)e^x - ax^2$（$a \in \mathbb{R}$）。

（1）当 $a = 0$ 时，求 $f(x)$ 的单调区间；

（2）当 $a < e$ 时，讨论 $f(x)$ 的极值点的个数。

---

**解答：**

**第1步：** 当 $a = 0$ 时求单调区间
> 📌 运用知识点：导数与单调性

$f(x) = (x-1)e^x$

$f'(x) = e^x + (x-1)e^x = xe^x$

令 $f'(x) = 0$：$x = 0$。

- 当 $x < 0$ 时 $f'(x) < 0$，$f(x)$ 单调递减；
- 当 $x > 0$ 时 $f'(x) > 0$，$f(x)$ 单调递增。

$$\boxed{f(x) \text{ 在 } (-\infty, 0) \text{ 上递减，在 } (0, +\infty) \text{ 上递增}}$$

**第2步：** 求 $f'(x)$ 并分析
> 📌 运用知识点：导数与极值

$f'(x) = e^x + (x-1)e^x - 2ax = xe^x - 2ax = x(e^x - 2a)$

令 $f'(x) = 0$：$x = 0$ 或 $e^x = 2a$。

**第3步：** 分类讨论

**当 $a \leqslant 0$ 时：** $e^x - 2a > 0$（因为 $e^x > 0 \geqslant 2a$），$f'(x) = 0$ 只有 $x = 0$ 一个根。

$x < 0$ 时 $f'(x) < 0$，$x > 0$ 时 $f'(x) > 0$。$x = 0$ 是极小值点，共 $1$ 个极值点。

**当 $0 < a < \dfrac{e}{2}$ 时：** $e^x = 2a$ 有解 $x = \ln(2a)$，且 $\ln(2a) < \ln e = 1$。

若 $\ln(2a) \neq 0$（即 $a \neq \dfrac{1}{2}$），$f'(x)$ 有两个不同的零点 $x = 0$ 和 $x = \ln(2a)$，都是极值点，共 $2$ 个。

若 $\ln(2a) = 0$（即 $a = \dfrac{1}{2}$），$f'(x) = x(e^x - 1)$。$e^x - 1$ 与 $x$ 同号，$f'(x) = x(e^x - 1) \geqslant 0$，$f(x)$ 单调递增，无极值点，共 $0$ 个。

**当 $\dfrac{1}{2} < a < e$ 时：** $\ln(2a) > 0$，两个零点 $0 < \ln(2a)$。

分析符号变化：$x < 0$ 时 $f'(x) > 0$（$x < 0$, $e^x - 2a < 0$），$0 < x < \ln(2a)$ 时 $f'(x) < 0$，$x > \ln(2a)$ 时 $f'(x) > 0$。

$x = 0$ 是极大值点，$x = \ln(2a)$ 是极小值点，共 $2$ 个。

**当 $a = \dfrac{e}{2}$ 时：** 题目要求 $a < e$，包含此情况。$\ln(2a) = \ln e = 1 > 0$，共 $2$ 个极值点。

综合：

$$\boxed{\begin{cases} a \leqslant 0 \text{ 时，} 1 \text{ 个极值点} \\ a = \dfrac{1}{2} \text{ 时，} 0 \text{ 个极值点} \\ 0 < a < \dfrac{1}{2} \text{ 或 } \dfrac{1}{2} < a < e \text{ 时，} 2 \text{ 个极值点} \end{cases}}$$

**⚠️ 易错提醒：** $f'(x) = x(e^x - 2a)$ 的因式分解是关键步骤。讨论时注意 $\ln(2a) = 0$（即 $a = \dfrac{1}{2}$）的特殊情况，此时两个零点重合，不是极值点。

**💡 解题思路总结：** 含参函数的极值点个数讨论：先因式分解 $f'(x)$，找出零点，再根据零点个数和符号变化判断极值点。特别注意零点重合的情况。
