**题目：** 已知集合 $A = \{-2, -1, 0, 1, 2\}$，$B = \{x \mid x^2 - x - 2 \leqslant 0\}$，则 $A \cap B =$

A. $\{-1, 0, 1, 2\}$

B. $\{-2, -1, 0, 1\}$

C. $\{0, 1, 2\}$

D. $\{-1, 0, 1\}$

---

**解答：**

**第1步：** 求集合 $B$
> 📌 运用知识点：一元二次不等式的解法

$x^2 - x - 2 \leqslant 0 \implies (x-2)(x+1) \leqslant 0 \implies -1 \leqslant x \leqslant 2$

$B = [-1, 2]$

**第2步：** 求 $A \cap B$
> 📌 运用知识点：集合的交集运算

$A = \{-2, -1, 0, 1, 2\}$，$B = [-1, 2]$

$A \cap B = \{-1, 0, 1, 2\}$

**答案：A**

**⚠️ 易错提醒：** $-2 \notin B$（因为 $-2 < -1$），$2 \in B$（因为 $-1 \leqslant 2 \leqslant 2$）。注意端点 $-1$ 和 $2$ 都能取到。

**💡 解题思路总结：** 先解不等式确定 $B$ 的范围，再从集合 $A$ 中逐一筛选属于 $B$ 的元素。
