**题目：** 已知函数 $f(x) = 2\sqrt{3}\sin x\cos x - 2\sin^2 x + 1$。

（1）求 $f(x)$ 的最小正周期和对称轴方程；

（2）求 $f(x)$ 在 $\left[-\dfrac{\pi}{6}, \dfrac{\pi}{3}\right]$ 上的最大值和最小值。

---

**解答：**

**第1步：** 化简 $f(x)$
> 📌 运用知识点：三角恒等变换

$$f(x) = \sqrt{3} \cdot 2\sin x\cos x - (2\sin^2 x - 1) = \sqrt{3}\sin 2x - (-\cos 2x) = \sqrt{3}\sin 2x + \cos 2x$$

$$= 2\left(\frac{\sqrt{3}}{2}\sin 2x + \frac{1}{2}\cos 2x\right) = 2\sin\left(2x + \frac{\pi}{6}\right)$$

**第2步：** 求周期和对称轴
> 📌 运用知识点：三角函数的性质

最小正周期 $T = \dfrac{2\pi}{2} = \pi$。

对称轴：$2x + \dfrac{\pi}{6} = \dfrac{\pi}{2} + k\pi \implies x = \dfrac{\pi}{6} + \dfrac{k\pi}{2}$（$k \in \mathbb{Z}$）

$$\boxed{T = \pi, \text{ 对称轴 } x = \frac{\pi}{6} + \frac{k\pi}{2} \ (k \in \mathbb{Z})}$$

**第3步：** 求最值
> 📌 运用知识点：三角函数的值域

当 $x \in \left[-\dfrac{\pi}{6}, \dfrac{\pi}{3}\right]$ 时：

$$2x + \frac{\pi}{6} \in \left[-\frac{\pi}{6}, \frac{5\pi}{6}\right]$$

在 $\left[-\dfrac{\pi}{6}, \dfrac{5\pi}{6}\right]$ 上：
- $\sin$ 在 $2x + \dfrac{\pi}{6} = \dfrac{\pi}{2}$ 时取最大值 $1$，$f(x)_{\max} = 2$
- $\sin$ 在 $2x + \dfrac{\pi}{6} = -\dfrac{\pi}{6}$ 时取最小值 $-\dfrac{1}{2}$，$f(x)_{\min} = -1$

$$\boxed{f(x)_{\max} = 2, \ f(x)_{\min} = -1}$$

**⚠️ 易错提醒：** 化简时 $2\sin^2 x - 1 = -\cos 2x$（二倍角公式的变形），不要搞错符号。求最值时先确定整体角的范围，再在该范围内找正弦的最值。

**💡 解题思路总结：** 三角函数化简的常用套路：$2\sin x\cos x = \sin 2x$，$2\sin^2 x - 1 = -\cos 2x$，最后合并为 $A\sin(\omega x + \varphi)$ 的形式。
