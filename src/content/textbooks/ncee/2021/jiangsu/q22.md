**题目：** 已知数列 $\{a_n\}$ 满足 $a_1 = 1$，$a_{n+1} = 3a_n + 1$。

（1）证明 $\left\{a_n + \dfrac{1}{2}\right\}$ 是等比数列，并求 $a_n$；

（2）设 $b_n = \dfrac{2a_n + 1}{a_n \cdot a_{n+1}}$，求 $\{b_n\}$ 的前 $n$ 项和 $T_n$；

（3）证明：$T_n < 1$。

---

**解答：**

**第1步：** 证明等比数列
> 📌 运用知识点：等比数列的判定

$a_{n+1} + \dfrac{1}{2} = 3a_n + 1 + \dfrac{1}{2} = 3a_n + \dfrac{3}{2} = 3\left(a_n + \dfrac{1}{2}\right)$

所以 $\left\{a_n + \dfrac{1}{2}\right\}$ 是公比为 $3$ 的等比数列。

首项 $a_1 + \dfrac{1}{2} = \dfrac{3}{2}$。

$$a_n + \frac{1}{2} = \frac{3}{2} \cdot 3^{n-1} = \frac{3^n}{2}$$

$$\boxed{a_n = \frac{3^n - 1}{2}}$$

**第2步：** 求 $T_n$（裂项求和）
> 📌 运用知识点：裂项求和

$2a_n + 1 = 3^n$，$a_n = \dfrac{3^n - 1}{2}$，$a_{n+1} = \dfrac{3^{n+1} - 1}{2}$。

$$b_n = \frac{3^n}{\dfrac{3^n - 1}{2} \cdot \dfrac{3^{n+1} - 1}{2}} = \frac{4 \cdot 3^n}{(3^n - 1)(3^{n+1} - 1)}$$

注意到 $3^{n+1} - 1 = 3 \cdot 3^n - 1 = 3(3^n - 1) + 2$，不太方便直接裂项。

Let me try: $\dfrac{3^n}{(3^n-1)(3^{n+1}-1)}$.

Let $u = 3^n$. Then we need $\dfrac{u}{(u-1)(3u-1)}$.

Partial fractions: $\dfrac{u}{(u-1)(3u-1)} = \dfrac{A}{u-1} + \dfrac{B}{3u-1}$

$u = A(3u-1) + B(u-1)$

$u = 1$: $1 = 2A \implies A = 1/2$

$u = 1/3$: $1/3 = B(1/3 - 1) = B(-2/3) \implies B = -1/2$

$\dfrac{u}{(u-1)(3u-1)} = \dfrac{1}{2}\left(\dfrac{1}{u-1} - \dfrac{1}{3u-1}\right) = \dfrac{1}{2}\left(\dfrac{1}{3^n-1} - \dfrac{1}{3^{n+1}-1}\right)$

So $b_n = 4 \cdot \dfrac{1}{2}\left(\dfrac{1}{3^n-1} - \dfrac{1}{3^{n+1}-1}\right) = 2\left(\dfrac{1}{3^n-1} - \dfrac{1}{3^{n+1}-1}\right)$

$T_n = 2\left(\dfrac{1}{3^1-1} - \dfrac{1}{3^{n+1}-1}\right) = 2\left(\dfrac{1}{2} - \dfrac{1}{3^{n+1}-1}\right) = 1 - \dfrac{2}{3^{n+1}-1}$

**第3步：** 证明 $T_n < 1$

$T_n = 1 - \dfrac{2}{3^{n+1}-1}$

因为 $3^{n+1} - 1 > 0$（$n \geqslant 1$），所以 $\dfrac{2}{3^{n+1}-1} > 0$，$T_n < 1$。

$$\boxed{T_n = 1 - \frac{2}{3^{n+1} - 1} < 1}$$

**⚠️ 易错提醒：** 裂项时需要用待定系数法分解 $\dfrac{3^n}{(3^n-1)(3^{n+1}-1)}$。注意 $2a_n + 1 = 3^n$ 的化简。

**💡 解题思路总结：** 递推关系 $a_{n+1} = pa_n + q$ 通过加常数 $\dfrac{q}{p-1}$ 转化为等比数列。裂项求和的关键是用待定系数法将分式分解为两项之差。
