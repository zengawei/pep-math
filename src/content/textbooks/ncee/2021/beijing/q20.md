**题目：** 已知数列 $\{a_n\}$ 满足 $a_1 = 2$，$a_{n+1} = 3a_n - 2$（$n \geqslant 1$）。

（1）求 $\{a_n\}$ 的通项公式；

（2）设 $b_n = \dfrac{1}{a_n - 1}$，求数列 $\{b_n\}$ 的前 $n$ 项和 $S_n$。

---

**解答：**

**第1步：** 构造等比数列
> 📌 运用知识点：递推数列

$a_{n+1} = 3a_n - 2$

设 $a_{n+1} - c = 3(a_n - c)$，则 $a_{n+1} = 3a_n - 2c$，比较得 $c = 1$。

所以 $a_{n+1} - 1 = 3(a_n - 1)$。

**第2步：** 求通项

令 $c_n = a_n - 1$，则 $c_{n+1} = 3c_n$，$\{c_n\}$ 是公比为 $3$ 的等比数列。

$c_1 = a_1 - 1 = 1$

$c_n = 3^{n-1}$

$$\boxed{a_n = 3^{n-1} + 1}$$

**第3步：** 求 $b_n$
> 📌 运用知识点：裂项求和

$$b_n = \frac{1}{a_n - 1} = \frac{1}{3^{n-1}}$$

**第4步：** 求 $S_n$

$$S_n = \sum_{k=1}^n \frac{1}{3^{k-1}} = 1 + \frac{1}{3} + \frac{1}{9} + \cdots + \frac{1}{3^{n-1}}$$

这是首项为 $1$、公比为 $\dfrac{1}{3}$ 的等比数列前 $n$ 项和。

$$S_n = \frac{1 - \left(\dfrac{1}{3}\right)^n}{1 - \dfrac{1}{3}} = \frac{1 - \dfrac{1}{3^n}}{\dfrac{2}{3}} = \frac{3}{2}\left(1 - \frac{1}{3^n}\right)$$

$$\boxed{S_n = \frac{3}{2}\left(1 - \frac{1}{3^n}\right)}$$

**⚠️ 易错提醒：** 递推关系 $a_{n+1} = pa_n + q$ 型通过"减常数"构造等比数列。常数 $c$ 满足 $c = pc + q$，即 $c = \dfrac{q}{1-p}$。

**💡 解题思路总结：** 线性递推数列 $a_{n+1} = pa_n + q$ 的求解方法：构造 $c_n = a_n - \dfrac{q}{1-p}$，使 $\{c_n\}$ 成为等比数列。
