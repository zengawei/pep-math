**题目：** 已知集合 $A = \{x \mid x > 1\}$，$B = \{x \mid -1 < x < 2\}$，则 $A \cap B =$

A. $\{x \mid -1 < x < 2\}$

B. $\{x \mid x > -1\}$

C. $\{x \mid 1 < x < 2\}$

D. $\{x \mid x > 1\}$

---

**解答：**

**第1步：** 分析两个集合

$A = (1, +\infty)$，$B = (-1, 2)$

**第2步：** 求交集
> 📌 运用知识点：集合的交集运算

$A \cap B$ 需要同时满足 $x > 1$ 和 $-1 < x < 2$，即 $1 < x < 2$。

$A \cap B = (1, 2)$

**答案：C**

**⚠️ 易错提醒：** 交集取"公共部分"，要同时满足两个条件。不要与并集混淆。

**💡 解题思路总结：** 数轴上标出两个集合的范围，公共部分就是交集。
