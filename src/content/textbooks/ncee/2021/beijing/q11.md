**题目：** 已知函数 $f(x) = 3^x$，则 $f(-1) + f(0) + f(1) = $ ______。

---

**解答：**

**第1步：** 逐一求值
> 📌 运用知识点：指数函数的求值

$f(-1) = 3^{-1} = \dfrac{1}{3}$

$f(0) = 3^0 = 1$

$f(1) = 3^1 = 3$

**第2步：** 求和

$f(-1) + f(0) + f(1) = \dfrac{1}{3} + 1 + 3 = \dfrac{1}{3} + 4 = \dfrac{13}{3}$

**答案：$\dfrac{13}{3}$**

**⚠️ 易错提醒：** $3^{-1} = \dfrac{1}{3}$（负指数），$3^0 = 1$（零指数），不要计算错误。

**💡 解题思路总结：** 指数函数的基本求值，注意负指数和零指数的运算规则。
