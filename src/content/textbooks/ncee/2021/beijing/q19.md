**题目：** 已知函数 $f(x) = x^2 \text{e}^{-x}$。

（1）求 $f(x)$ 的单调区间和极值；

（2）若 $f(x) \leqslant a$ 对 $x \in [0, 2]$ 恒成立，求 $a$ 的最小值。

---

**解答：**

**第1步：** 求导
> 📌 运用知识点：导数的运算

$f'(x) = 2x\text{e}^{-x} + x^2(-\text{e}^{-x}) = \text{e}^{-x}(2x - x^2) = x(2 - x)\text{e}^{-x}$

**第2步：** 分析 $f'(x)$ 的符号

因为 $\text{e}^{-x} > 0$，$f'(x)$ 的符号由 $x(2 - x)$ 决定。

- $x < 0$：$x < 0$，$2 - x > 0$，$f'(x) < 0$，递减
- $0 < x < 2$：$x > 0$，$2 - x > 0$，$f'(x) > 0$，递增
- $x > 2$：$x > 0$，$2 - x < 0$，$f'(x) < 0$，递减

**第3步：** 确定极值

$f(x)$ 在 $x = 0$ 处取极小值：$f(0) = 0$

$f(x)$ 在 $x = 2$ 处取极大值：$f(2) = 4\text{e}^{-2} = \dfrac{4}{\text{e}^2}$

$$\boxed{\text{递减区间：}(-\infty, 0) \text{ 和 } (2, +\infty)\text{；递增区间：}(0, 2)}$$

$$\boxed{\text{极小值 } f(0) = 0\text{；极大值 } f(2) = \frac{4}{\text{e}^2}}$$

**第4步：** 分析第（2）问
> 📌 运用知识点：导数与恒成立

$f(x) \leqslant a$ 对 $x \in [0, 2]$ 恒成立，即 $a \geqslant f(x)_{\max}$（$x \in [0, 2]$）。

**第5步：** 求 $f(x)$ 在 $[0, 2]$ 上的最大值

由第（1）问，$f(x)$ 在 $[0, 2]$ 上单调递增。

$f(x)_{\max} = f(2) = \dfrac{4}{\text{e}^2}$

$a$ 的最小值为 $\dfrac{4}{\text{e}^2}$。

$$\boxed{a_{\min} = \frac{4}{\text{e}^2}}$$

**⚠️ 易错提醒：** 求导时注意乘积法则和链式法则。$\text{e}^{-x}$ 的导数是 $-\text{e}^{-x}$，不要漏掉负号。

**💡 解题思路总结：** $f(x) \leqslant a$ 恒成立 $\iff a \geqslant f(x)_{\max}$。在闭区间上先确定单调性，再比较端点值和极值。
