**题目：** 已知椭圆 $C: \dfrac{x^2}{2} + y^2 = 1$，过点 $P(0, 1)$ 的直线 $l$ 与椭圆 $C$ 交于 $A$、$B$ 两点。

（1）若直线 $l$ 的斜率为 $1$，求 $|AB|$；

（2）设 $Q(0, -1)$，求 $\triangle QAB$ 面积的最大值。

---

**解答：**

**第1步：** 写出直线方程
> 📌 运用知识点：直线方程

$l$ 过 $P(0, 1)$，斜率为 $1$：$y = x + 1$。

**第2步：** 联立直线与椭圆
> 📌 运用知识点：直线与椭圆的位置关系

代入 $\dfrac{x^2}{2} + y^2 = 1$：

$\dfrac{x^2}{2} + (x+1)^2 = 1$

$\dfrac{x^2}{2} + x^2 + 2x + 1 = 1$

$\dfrac{3x^2}{2} + 2x = 0$

$x\left(\dfrac{3x}{2} + 2\right) = 0$

$x_1 = 0$，$x_2 = -\dfrac{4}{3}$

**第3步：** 求 $|AB|$

$A(0, 1)$，$B\left(-\dfrac{4}{3}, -\dfrac{1}{3}\right)$

$$|AB| = \sqrt{\left(\frac{4}{3}\right)^2 + \left(1 + \frac{1}{3}\right)^2} = \sqrt{\frac{16}{9} + \frac{16}{9}} = \frac{4\sqrt{2}}{3}$$

$$\boxed{|AB| = \frac{4\sqrt{2}}{3}}$$

**第4步：** 求面积最大值
> 📌 运用知识点：圆锥曲线的最值

设 $l: y = kx + 1$（先讨论斜率存在的情况）。

代入椭圆：$\dfrac{x^2}{2} + (kx+1)^2 = 1$

$(1 + 2k^2)x^2 + 4kx = 0$

$x[(1 + 2k^2)x + 4k] = 0$

$x_1 = 0$，$x_2 = \dfrac{-4k}{1 + 2k^2}$

**第5步：** 计算面积

$A(0, 1)$，$B\left(\dfrac{-4k}{1+2k^2}, \dfrac{1-2k^2}{1+2k^2}\right)$

$|AB| = \sqrt{1 + k^2} \cdot |x_2| = \sqrt{1+k^2} \cdot \dfrac{4|k|}{1+2k^2}$

$Q(0, -1)$ 到直线 $kx - y + 1 = 0$ 的距离 $d = \dfrac{|0 + 1 + 1|}{\sqrt{k^2 + 1}} = \dfrac{2}{\sqrt{k^2 + 1}}$

$$S = \frac{1}{2}|AB| \cdot d = \frac{1}{2} \cdot \sqrt{1+k^2} \cdot \frac{4|k|}{1+2k^2} \cdot \frac{2}{\sqrt{1+k^2}} = \frac{4|k|}{1+2k^2}$$

**第6步：** 求最大值

令 $t = |k| > 0$，$S = \dfrac{4t}{1 + 2t^2}$

$S' = \dfrac{4(1 + 2t^2) - 4t \cdot 4t}{(1 + 2t^2)^2} = \dfrac{4 - 8t^2}{(1 + 2t^2)^2}$

$S' = 0 \implies t^2 = \dfrac{1}{2} \implies t = \dfrac{\sqrt{2}}{2}$

$S_{\max} = \dfrac{4 \times \dfrac{\sqrt{2}}{2}}{1 + 2 \times \dfrac{1}{2}} = \dfrac{2\sqrt{2}}{2} = \sqrt{2}$

$$\boxed{S_{\max} = \sqrt{2}}$$

**⚠️ 易错提醒：** 联立时注意 $x_1 = 0$ 对应点 $A(0, 1)$ 即点 $P$ 本身。面积化简中 $\sqrt{1+k^2}$ 恰好消去。

**💡 解题思路总结：** 直线过定点与椭圆联立，利用韦达定理简化计算。面积最值通过求导或均值不等式解决。
