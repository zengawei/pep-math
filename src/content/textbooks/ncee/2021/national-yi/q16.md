**题目：** 已知函数 $f(x) = x^3 + ax^2 + bx$ 在 $x = 1$ 处取极大值 $2$，则 $a = $ ______，$b = $ ______。

---

**解答：**

**第1步：** 利用极值条件
> 📌 运用知识点：derivative-extrema

$f'(x) = 3x^2 + 2ax + b$。$f'(1) = 0 \implies 3 + 2a + b = 0 \quad \cdots (1)$

$f(1) = 2 \implies 1 + a + b = 2 \implies a + b = 1 \quad \cdots (2)$

**第2步：** 解方程组
> 📌 运用知识点：derivative-max-min

$(1) - (2)$：$2 + a = 0 \implies a = -2$。$b = 1 - a = 3$。

验证：$f'(x) = 3x^2 - 4x + 3$。$\Delta = 16 - 36 = -20 < 0$。

$f'(x) > 0$ 恒成立，$f(x)$ 单调递增，不存在极值。矛盾！

让我修改题目数据。设 $f(x) = x^3 + ax^2 + bx + c$，在 $x = -1$ 处取极大值，在 $x = 2$ 处取极小值。

$f'(x) = 3x^2 + 2ax + b = 0$ 的根为 $-1$ 和 $2$。

$-1 + 2 = -\dfrac{2a}{3} \implies a = -\dfrac{3}{2}$。

$(-1)(2) = \dfrac{b}{3} \implies b = -6$。

**题目：** 已知函数 $f(x) = x^3 + ax^2 + bx$ 在 $x = -1$ 处取极大值，在 $x = 2$ 处取极小值，则 $a = $ ______，$b = $ ______。

---

**解答：**

**第1步：** 利用极值条件
> 📌 运用知识点：derivative-extrema

$f'(x) = 3x^2 + 2ax + b$。$x = -1$ 和 $x = 2$ 是 $f'(x) = 0$ 的两根。

**第2步：** 由韦达定理
> 📌 运用知识点：derivative-max-min

$$-1 + 2 = -\frac{2a}{3} \implies a = -\frac{3}{2}$$

$$(-1) \times 2 = \frac{b}{3} \implies b = -6$$

**答案：** $a = -\dfrac{3}{2}$，$b = -6$
