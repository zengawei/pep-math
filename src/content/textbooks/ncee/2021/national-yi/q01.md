**题目：** 已知集合 $A = \{x \mid x < 2\}$，$B = \{x \mid x > -1\}$，则 $A \cap B = $（  ）

A. $\{x \mid -1 < x < 2\}$

B. $\{x \mid x > -1\}$

C. $\{x \mid x < 2\}$

D. $\mathbb{R}$

---

**解答：**

**第1步：** 求交集
> 📌 运用知识点：set-operations

$A \cap B = \{x \mid x < 2\} \cap \{x \mid x > -1\} = \{x \mid -1 < x < 2\}$。

**答案：A**
