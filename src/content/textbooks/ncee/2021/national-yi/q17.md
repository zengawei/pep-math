**题目：** 在 $\triangle ABC$ 中，$a$，$b$，$c$ 分别为角 $A$，$B$，$C$ 的对边，已知 $c = 2$，$C = \dfrac{\pi}{3}$，$\triangle ABC$ 的面积为 $\sqrt{3}$。

（1）求 $a$，$b$ 的值；

（2）求 $\sin A + \sin B$ 的值。

---

**解答：**

**（1）求 $a$，$b$**

**第1步：** 利用面积公式
> 📌 运用知识点：trig-function

$$S = \frac{1}{2}ab\sin C = \frac{1}{2}ab\sin\frac{\pi}{3} = \frac{\sqrt{3}}{4}ab = \sqrt{3}$$

$$ab = 4 \quad \cdots (1)$$

**第2步：** 利用余弦定理
> 📌 运用知识点：trig-identity

$$c^2 = a^2 + b^2 - 2ab\cos C$$

$$4 = a^2 + b^2 - 2 \times 4 \times \frac{1}{2} = a^2 + b^2 - 4$$

$$a^2 + b^2 = 8 \quad \cdots (2)$$

**第3步：** 联立求解
> 📌 运用知识点：trig-identity

$(a+b)^2 = a^2 + b^2 + 2ab = 8 + 8 = 16 \implies a + b = 4$。

由 $a + b = 4$，$ab = 4$：$a$，$b$ 是方程 $t^2 - 4t + 4 = 0$ 的根。

$(t-2)^2 = 0 \implies t = 2$。

$$\boxed{a = 2, \; b = 2}$$

**（2）求 $\sin A + \sin B$**

**第4步：** 利用正弦定理
> 📌 运用知识点：trig-identity

因为 $a = b = c = 2$，$\triangle ABC$ 为等边三角形，$A = B = \dfrac{\pi}{3}$。

$$\sin A + \sin B = 2\sin\frac{\pi}{3} = 2 \times \frac{\sqrt{3}}{2} = \sqrt{3}$$

$$\boxed{\sin A + \sin B = \sqrt{3}}$$

**⚠️ 易错提醒：** 注意验证 $a, b > 0$，且满足三角形不等式。

**💡 解题思路总结：** 面积公式和余弦定理联立是求三角形边长的经典方法。
