**题目：** 已知椭圆 $C: \dfrac{x^2}{4} + \dfrac{y^2}{3} = 1$，过点 $Q(1, 0)$ 的直线 $l$ 与椭圆交于 $A$，$B$ 两点。

（1）若 $|AB| = \dfrac{12}{5}$，求直线 $l$ 的方程；

（2）设 $R$ 为 $x$ 轴上一点 $(t, 0)$，若 $\overrightarrow{RA} \cdot \overrightarrow{RB}$ 为与 $l$ 斜率无关的定值，求 $t$ 的值。

---

**解答：**

**（1）求直线方程**

**第1步：** 设直线并联立
> 📌 运用知识点：conic-section-line

设 $l: x = my + 1$。代入椭圆：

$$\frac{(my+1)^2}{4} + \frac{y^2}{3} = 1 \implies 3(my+1)^2 + 4y^2 = 12$$

$$(3m^2 + 4)y^2 + 6my - 9 = 0$$

$y_1 + y_2 = \dfrac{-6m}{3m^2+4}$，$y_1 y_2 = \dfrac{-9}{3m^2+4}$。

**第2步：** 利用弦长公式
> 📌 运用知识点：conic-section-line

$$|AB| = \sqrt{1+m^2} \cdot |y_1 - y_2| = \sqrt{1+m^2} \cdot \sqrt{(y_1+y_2)^2 - 4y_1y_2}$$

$$(y_1+y_2)^2 - 4y_1y_2 = \frac{36m^2}{(3m^2+4)^2} + \frac{36}{3m^2+4} = \frac{36m^2 + 36(3m^2+4)}{(3m^2+4)^2} = \frac{144(m^2+1)}{(3m^2+4)^2}$$

$$|AB| = \sqrt{1+m^2} \cdot \frac{12\sqrt{m^2+1}}{3m^2+4} = \frac{12(m^2+1)}{3m^2+4} = \frac{12}{5}$$

$5(m^2+1) = 3m^2+4 \implies 2m^2 = -1$。无解。

说明斜率不存在时 $l: x = 1$。代入：$\dfrac{1}{4} + \dfrac{y^2}{3} = 1 \implies y^2 = \dfrac{9}{4} \implies y = \pm\dfrac{3}{2}$。

$|AB| = 3 \neq \dfrac{12}{5}$。

让我调整数据。设 $|AB| = 3$，则 $x = 1$ 即可。

或修改椭圆为 $\dfrac{x^2}{4} + y^2 = 1$，$Q(1,0)$。

$(m^2+4)y^2 + 2my - 3 = 0$... Let me just use a clean problem.

**题目：** 已知椭圆 $C: \dfrac{x^2}{4} + y^2 = 1$，过点 $M(1, 0)$ 的直线 $l$ 与椭圆交于 $A$，$B$ 两点。

（1）若 $l$ 的斜率为 $1$，求 $|AB|$；

（2）在 $x$ 轴上是否存在定点 $N(t, 0)$，使得 $\overrightarrow{NA} \cdot \overrightarrow{NB}$ 为与 $l$ 斜率无关的定值？若存在，求 $t$。

---

**解答：**

**（1）求 $|AB|$**

**第1步：** 联立方程
> 📌 运用知识点：conic-section-line

$l: y = x - 1$。代入 $\dfrac{x^2}{4} + (x-1)^2 = 1$：

$$x^2 + 4(x-1)^2 = 4 \implies 5x^2 - 8x = 0 \implies x(5x - 8) = 0$$

$x_1 = 0$，$x_2 = \dfrac{8}{5}$。$A = (0, -1)$，$B = \left(\dfrac{8}{5}, \dfrac{3}{5}\right)$。

$$|AB| = \sqrt{\left(\frac{8}{5}\right)^2 + \left(\frac{8}{5}\right)^2} = \frac{8\sqrt{2}}{5}$$

$$\boxed{|AB| = \dfrac{8\sqrt{2}}{5}}$$

**（2）求 $t$**

**第2步：** 设 $l: x = my + 1$ 并联立
> 📌 运用知识点：conic-section-line

$(m^2 + 4)y^2 + 2my - 3 = 0$。

$y_1 + y_2 = \dfrac{-2m}{m^2+4}$，$y_1 y_2 = \dfrac{-3}{m^2+4}$。

**第3步：** 计算 $\overrightarrow{NA} \cdot \overrightarrow{NB}$
> 📌 运用知识点：conic-section-optimization

$\overrightarrow{NA} \cdot \overrightarrow{NB} = (x_1 - t)(x_2 - t) + y_1 y_2$

$= (my_1 + 1 - t)(my_2 + 1 - t) + y_1 y_2$

$= (1+m^2)y_1 y_2 + m(1-t)(y_1+y_2) + (1-t)^2$

$= \dfrac{(1+m^2)(-3) + m(1-t)(-2m) + (1-t)^2(m^2+4)}{m^2+4}$

分子 $= -3 - 3m^2 - 2m^2(1-t) + (1-t)^2 m^2 + 4(1-t)^2$

$= [-3 - 2(1-t) + (1-t)^2]m^2 + [-3 + 4(1-t)^2]$

$= [(1-t)^2 - 2(1-t) - 3]m^2 + [4(1-t)^2 - 3]$

令 $m^2$ 的系数为零：$(1-t)^2 - 2(1-t) - 3 = 0$。

设 $u = 1-t$：$u^2 - 2u - 3 = 0 \implies (u-3)(u+1) = 0 \implies u = 3$ 或 $u = -1$。

$t = -2$ 或 $t = 2$。

需验证定值与 $m$ 无关：当 $t = -2$ 时，定值 $= \dfrac{4 \times 9 - 3}{m^2+4} \times (m^2+4)$... 

实际上当 $m^2$ 系数为零时，$\overrightarrow{NA} \cdot \overrightarrow{NB} = \dfrac{4(1-t)^2 - 3}{m^2 + 4} \times (m^2+4)$... 不对。

当系数为零时，分子 $= 4(1-t)^2 - 3$（常数），分母 $= m^2 + 4$（含 $m$）。所以还需要分子也为零或分母为常数。

实际上需要 $\overrightarrow{NA} \cdot \overrightarrow{NB} = \lambda$（常数），即分子 $= \lambda(m^2+4)$。

$[(1-t)^2 - 2(1-t) - 3]m^2 + [4(1-t)^2 - 3] = \lambda m^2 + 4\lambda$

比较系数：$(1-t)^2 - 2(1-t) - 3 = \lambda$ 且 $4(1-t)^2 - 3 = 4\lambda$。

$4[(1-t)^2 - 2(1-t) - 3] = 4(1-t)^2 - 3$

$4(1-t)^2 - 8(1-t) - 12 = 4(1-t)^2 - 3$

$-8(1-t) = 9 \implies 1-t = -\dfrac{9}{8} \implies t = \dfrac{17}{8}$

$\lambda = \left(-\dfrac{9}{8}\right)^2 - 2\left(-\dfrac{9}{8}\right) - 3 = \dfrac{81}{64} + \dfrac{9}{4} - 3 = \dfrac{81+144-192}{64} = \dfrac{33}{64}$

$$\boxed{t = \dfrac{17}{8}}$$

**⚠️ 易错提醒：** 设直线为 $x = my + 1$ 可避免讨论斜率不存在的情况。

**💡 解题思路总结：** 存在性问题用"设而不求"策略，利用韦达定理和待定系数法。
