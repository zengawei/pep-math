**题目：** 设集合 $A = \{x \mid x^2 - 3x + 2 \leqslant 0\}$，$B = \{x \mid x \geqslant 1\}$，则 $A \cap B = $（  ）

A. $\{x \mid 1 \leqslant x \leqslant 2\}$

B. $\{x \mid x \geqslant 1\}$

C. $\{x \mid x \leqslant 2\}$

D. $\{x \mid 1 \leqslant x < 2\}$

---

**解答：**

**第1步：** 求解集合 $A$
> 📌 运用知识点：set-operations

$x^2 - 3x + 2 \leqslant 0 \implies (x-1)(x-2) \leqslant 0 \implies 1 \leqslant x \leqslant 2$。

$A = [1, 2]$。

**第2步：** 求 $A \cap B$
> 📌 运用知识点：set-operations

$A \cap B = [1, 2] \cap [1, +\infty) = [1, 2]$。

**答案：A**
