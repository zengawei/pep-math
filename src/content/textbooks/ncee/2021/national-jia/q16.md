**题目：** 已知不等式 $ax^2 + bx + 2 > 0$ 的解集为 $\left(-\dfrac{1}{2}, \dfrac{1}{3}\right)$，则 $a + b = $ ______。

---

**解答：**

**第1步：** 利用解集端点
> 📌 运用知识点：quadratic-inequality

解集为 $\left(-\dfrac{1}{2}, \dfrac{1}{3}\right)$，说明 $-\dfrac{1}{2}$ 和 $\dfrac{1}{3}$ 是方程 $ax^2 + bx + 2 = 0$ 的两个根，且 $a < 0$。

**第2步：** 由韦达定理
> 📌 运用知识点：quadratic-equation

$$-\frac{1}{2} + \frac{1}{3} = -\frac{b}{a} \implies -\frac{1}{6} = -\frac{b}{a} \implies \frac{b}{a} = \frac{1}{6}$$

$$\left(-\frac{1}{2}\right) \times \frac{1}{3} = \frac{2}{a} \implies -\frac{1}{6} = \frac{2}{a} \implies a = -12$$

$$b = \frac{a}{6} = \frac{-12}{6} = -2$$

$$a + b = -12 + (-2) = -14$$

**答案：** $-14$
