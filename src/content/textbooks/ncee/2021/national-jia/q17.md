**题目：** 在 $\triangle ABC$ 中，$a$，$b$，$c$ 分别为角 $A$，$B$，$C$ 的对边，已知 $b\cos C + c\cos B = a\sin A$。

（1）求角 $A$；

（2）若 $a = 2$，$b + c = 4$，求 $\triangle ABC$ 的面积。

---

**解答：**

**（1）求角 $A$**

**第1步：** 利用正弦定理边化角
> 📌 运用知识点：trig-identity

由正弦定理：$\sin B\cos C + \sin C\cos B = \sin A \cdot \sin A$。

左边 $= \sin(B + C) = \sin(\pi - A) = \sin A$。

$$\sin A = \sin^2 A$$

因为 $A \in (0, \pi)$，$\sin A > 0$，所以 $\sin A = 1$。

$$\boxed{A = \dfrac{\pi}{2}}$$

**（2）求面积**

**第2步：** 利用勾股定理
> 📌 运用知识点：trig-function

$A = \dfrac{\pi}{2}$，$a = 2$。$b^2 + c^2 = a^2 = 4$。

又 $(b + c)^2 = b^2 + 2bc + c^2 = 16$，所以 $4 + 2bc = 16$，$bc = 6$。

**第3步：** 计算面积
> 📌 运用知识点：trig-function

$$S = \frac{1}{2}bc\sin A = \frac{1}{2} \times 6 \times 1 = 3$$

$$\boxed{S_{\triangle ABC} = 3}$$

**⚠️ 易错提醒：** 边化角后利用 $\sin(B+C) = \sin A$ 是关键化简步骤。

**💡 解题思路总结：** 正弦定理"边化角"结合和角公式是处理此类问题的标准方法。
