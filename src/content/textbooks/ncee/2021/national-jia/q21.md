**题目：** 已知函数 $f(x) = x\ln x - \dfrac{a}{2}x^2$（$a \in \mathbb{R}$）。

（1）当 $a = 0$ 时，求 $f(x)$ 的单调区间和极值；

（2）若 $f(x) \leqslant 0$ 对一切 $x > 0$ 成立，求 $a$ 的取值范围。

---

**解答：**

**（1）求单调区间和极值**

**第1步：** 求导
> 📌 运用知识点：derivative-operations

$a = 0$ 时 $f(x) = x\ln x$。

$$f'(x) = \ln x + 1 \quad (x > 0)$$

**第2步：** 求极值点
> 📌 运用知识点：derivative-monotonicity

$f'(x) = 0 \implies \ln x = -1 \implies x = \dfrac{1}{\mathrm{e}}$。

- 当 $0 < x < \dfrac{1}{\mathrm{e}}$ 时，$f'(x) < 0$，$f(x)$ 单调递减；
- 当 $x > \dfrac{1}{\mathrm{e}}$ 时，$f'(x) > 0$，$f(x)$ 单调递增。

极小值 $f\!\left(\dfrac{1}{\mathrm{e}}\right) = \dfrac{1}{\mathrm{e}} \times (-1) = -\dfrac{1}{\mathrm{e}}$。

$$\boxed{\text{单调递减区间 } \left(0, \frac{1}{\mathrm{e}}\right)，\text{单调递增区间 } \left(\frac{1}{\mathrm{e}}, +\infty\right)，\text{极小值 } -\frac{1}{\mathrm{e}}}$$

**（2）求 $a$ 的取值范围**

**第3步：** 转化条件
> 📌 运用知识点：derivative-applications

$f(x) \leqslant 0 \iff x\ln x \leqslant \dfrac{a}{2}x^2 \iff a \geqslant \dfrac{2\ln x}{x}$（$x > 0$）。

设 $g(x) = \dfrac{2\ln x}{x}$，需 $a \geqslant g(x)_{\max}$。

**第4步：** 求 $g(x)$ 的最大值
> 📌 运用知识点：derivative-max-min

$$g'(x) = \frac{2 \cdot \frac{1}{x} \cdot x - 2\ln x}{x^2} = \frac{2(1 - \ln x)}{x^2}$$

$g'(x) = 0 \implies x = \mathrm{e}$。$g(x)$ 在 $x = \mathrm{e}$ 处取最大值。

$$g(\mathrm{e}) = \frac{2\ln\mathrm{e}}{\mathrm{e}} = \frac{2}{\mathrm{e}}$$

$$\boxed{a \geqslant \dfrac{2}{\mathrm{e}}}$$

**⚠️ 易错提醒：** 分离参数时注意 $x > 0$ 可以除以 $x^2$ 不变号。$g(x)$ 的最大值在 $x = \mathrm{e}$ 处取到。

**💡 解题思路总结：** 恒成立问题转化为求函数最大值。分离参数后求导分析是标准方法。
