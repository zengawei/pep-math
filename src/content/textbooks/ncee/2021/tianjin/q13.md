**题目：** 已知函数 $f(x) = x\ln x$（$x > 0$），则

A. $f(x)$ 在 $\left(0, \dfrac{1}{e}\right)$ 上单调递减

B. $f(x)$ 的最小值为 $-\dfrac{1}{e}$

C. $f(x)$ 在 $x = \dfrac{1}{e}$ 处取得极小值

D. $f(x)$ 有零点 $x = 1$

在每小题给出的选项中，有多项符合题目要求．全部选对的得5分，部分选对的得2分，有选错的得0分．

---

**解答：**

**第1步：** 求导
> 📌 运用知识点：导数的运算

$$f'(x) = \ln x + x \cdot \frac{1}{x} = \ln x + 1$$

**第2步：** 分析单调性

令 $f'(x) = 0$：$\ln x = -1$，$x = e^{-1} = \dfrac{1}{e}$。

当 $0 < x < \dfrac{1}{e}$ 时，$\ln x < -1$，$f'(x) < 0$，$f(x)$ 递减。**A 正确。**

当 $x > \dfrac{1}{e}$ 时，$f'(x) > 0$，$f(x)$ 递增。

**第3步：** 求极值和最值

$x = \dfrac{1}{e}$ 处取极小值（也是最小值）：**C 正确。**

$$f\left(\frac{1}{e}\right) = \frac{1}{e} \ln\frac{1}{e} = \frac{1}{e} \times (-1) = -\frac{1}{e}$$

**B 正确。**

**第4步：** 判断零点

$f(1) = 1 \times \ln 1 = 0$。**D 正确。**

**答案：ABCD**

**⚠️ 易错提醒：** $x\ln x$ 的导数用乘积法则：$(x\ln x)' = \ln x + 1$，不是 $\dfrac{1}{x}$。

**💡 解题思路总结：** $f(x) = x\ln x$ 是高考高频函数，其导数 $f'(x) = \ln x + 1$，在 $x = \dfrac{1}{e}$ 处取最小值 $-\dfrac{1}{e}$。
