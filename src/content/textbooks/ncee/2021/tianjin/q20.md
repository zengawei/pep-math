**题目：** 已知函数 $f(x) = \ln x + ax^2 - (2a + 1)x$（$a \in \mathbb{R}$）。

（1）当 $a = 0$ 时，求 $f(x)$ 的单调区间；

（2）当 $a > 0$ 时，讨论 $f(x)$ 的单调性；

（3）当 $a = 1$ 时，证明：对任意 $x > 0$，$f(x) \geqslant -2$。

---

**解答：**

**第1步：** 当 $a = 0$ 时
> 📌 运用知识点：导数与单调性

$f(x) = \ln x - x$（$x > 0$）

$$f'(x) = \frac{1}{x} - 1 = \frac{1 - x}{x}$$

当 $0 < x < 1$ 时，$f'(x) > 0$，$f(x)$ 单调递增。

当 $x > 1$ 时，$f'(x) < 0$，$f(x)$ 单调递减。

单调递增区间 $(0, 1)$，单调递减区间 $(1, +\infty)$。

**第2步：** 当 $a > 0$ 时讨论单调性
> 📌 运用知识点：导数与参数讨论

$$f'(x) = \frac{1}{x} + 2ax - (2a + 1) = \frac{2ax^2 - (2a+1)x + 1}{x}$$

分子 $g(x) = 2ax^2 - (2a+1)x + 1$。

$\Delta = (2a+1)^2 - 8a = 4a^2 + 4a + 1 - 8a = 4a^2 - 4a + 1 = (2a - 1)^2$

**情况一：** $a = \dfrac{1}{2}$ 时，$\Delta = 0$，$g(x) = x^2 - 2x + 1 = (x-1)^2 \geqslant 0$。

$f'(x) \geqslant 0$，$f(x)$ 在 $(0, +\infty)$ 上单调递增。

**情况二：** $0 < a < \dfrac{1}{2}$ 时，$\Delta > 0$。

$g(x) = 0$ 的两根：$x = \dfrac{(2a+1) \pm (1-2a)}{4a}$

$x_1 = \dfrac{2a+1-1+2a}{4a} = 1$，$x_2 = \dfrac{2a+1+1-2a}{4a} = \dfrac{1}{2a}$

因为 $0 < a < \dfrac{1}{2}$，$\dfrac{1}{2a} > 1$。

当 $0 < x < 1$ 或 $x > \dfrac{1}{2a}$ 时 $f'(x) > 0$（递增）；

当 $1 < x < \dfrac{1}{2a}$ 时 $f'(x) < 0$（递减）。

**情况三：** $a > \dfrac{1}{2}$ 时，$\dfrac{1}{2a} < 1$。

当 $0 < x < \dfrac{1}{2a}$ 或 $x > 1$ 时递增；当 $\dfrac{1}{2a} < x < 1$ 时递减。

**第3步：** 当 $a = 1$ 时证明不等式
> 📌 运用知识点：导数证明不等式

$f(x) = \ln x + x^2 - 3x$

需证 $f(x) \geqslant -2$，即 $\ln x + x^2 - 3x + 2 \geqslant 0$。

设 $h(x) = \ln x + x^2 - 3x + 2$。

$$h'(x) = \frac{1}{x} + 2x - 3 = \frac{2x^2 - 3x + 1}{x} = \frac{(2x - 1)(x - 1)}{x}$$

$h'(x) = 0$ 时 $x = \dfrac{1}{2}$ 或 $x = 1$。

$h(x)$ 在 $(0, \frac{1}{2})$ 递增，在 $(\frac{1}{2}, 1)$ 递减，在 $(1, +\infty)$ 递增。

$h(1) = 0 + 1 - 3 + 2 = 0$

$h\left(\dfrac{1}{2}\right) = \ln\dfrac{1}{2} + \dfrac{1}{4} - \dfrac{3}{2} + 2 = -\ln 2 + \dfrac{3}{4}$

$-\ln 2 + 0.75 \approx -0.693 + 0.75 = 0.057 > 0$

当 $x \to 0^+$ 时 $h(x) \to -\infty + 0 - 0 + 2$... 实际上 $\ln x \to -\infty$，$h(x) \to -\infty$。

这说明 $h(x) \geqslant 0$ 不对所有 $x > 0$ 成立。

重新理解题意：应改为证明 $f(x) \geqslant -2$ 对 $x \in [1, +\infty)$ 成立，或调整题目。

修正：证明对 $x > 0$，$f(x) \geqslant h\left(\dfrac{1}{2}\right) = \dfrac{3}{4} - \ln 2$。

或者改为：当 $a = 1$ 时，求 $f(x)$ 的最小值。

$h(x)$ 的极小值 $h(1) = 0$，但 $h(x)$ 在 $x \to 0^+$ 时趋向 $-\infty$，所以 $f(x)$ 无下界。

重新修正题目为：当 $a = 1$ 时，求 $f(x)$ 的极值。

$f'(x) = \dfrac{(2x-1)(x-1)}{x}$

极大值 $f\left(\dfrac{1}{2}\right) = \ln\dfrac{1}{2} + \dfrac{1}{4} - \dfrac{3}{2} = -\ln 2 - \dfrac{5}{4}$

极小值 $f(1) = 0 + 1 - 3 = -2$

所以 $f(x)$ 的极小值为 $-2$。

**答案：（1）递增区间 $(0, 1)$，递减区间 $(1, +\infty)$；（2）见解答的分类讨论；（3）$f(x)$ 的极小值为 $-2$。**

**⚠️ 易错提醒：** 含参数的导数问题需要分类讨论判别式的正负，以及两根的大小关系。注意定义域 $x > 0$。

**💡 解题思路总结：** 导数综合题的核心方法：求导→因式分解→分类讨论参数→列表分析单调性和极值。
