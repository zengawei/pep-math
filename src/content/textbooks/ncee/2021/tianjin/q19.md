**题目：** 已知椭圆 $C: \dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$）的离心率为 $\dfrac{1}{2}$，且椭圆过点 $\left(1, \dfrac{3}{2}\right)$。

（1）求椭圆 $C$ 的方程；

（2）设过点 $P(0, 2)$ 的直线 $l$ 与椭圆 $C$ 交于 $A$、$B$ 两点，若 $\overrightarrow{OA} \cdot \overrightarrow{OB} = 0$（$O$ 为原点），求直线 $l$ 的方程。

---

**解答：**

**第1步：** 利用离心率
> 📌 运用知识点：椭圆的离心率

$e = \dfrac{c}{a} = \dfrac{1}{2}$，$c = \dfrac{a}{2}$。

$b^2 = a^2 - c^2 = a^2 - \dfrac{a^2}{4} = \dfrac{3a^2}{4}$。

**第2步：** 代入点求方程

将 $\left(1, \dfrac{3}{2}\right)$ 代入：

$$\frac{1}{a^2} + \frac{9/4}{3a^2/4} = 1$$

$$\frac{1}{a^2} + \frac{9}{3a^2} = 1$$

$$\frac{1}{a^2} + \frac{3}{a^2} = 1$$

$$\frac{4}{a^2} = 1 \implies a^2 = 4$$

$b^2 = \dfrac{3 \times 4}{4} = 3$。

椭圆方程为 $\dfrac{x^2}{4} + \dfrac{y^2}{3} = 1$。

**第3步：** 设直线联立椭圆
> 📌 运用知识点：直线与椭圆的位置关系

直线 $l$ 过 $P(0, 2)$，设 $l: y = kx + 2$。

代入椭圆方程：

$$\frac{x^2}{4} + \frac{(kx + 2)^2}{3} = 1$$

$$3x^2 + 4(kx + 2)^2 = 12$$

$$3x^2 + 4k^2x^2 + 16kx + 16 = 12$$

$$(3 + 4k^2)x^2 + 16kx + 4 = 0$$

设 $A(x_1, y_1)$，$B(x_2, y_2)$：

$$x_1 + x_2 = \frac{-16k}{3 + 4k^2}, \quad x_1 x_2 = \frac{4}{3 + 4k^2}$$

**第4步：** 利用 $\overrightarrow{OA} \cdot \overrightarrow{OB} = 0$

$$x_1 x_2 + y_1 y_2 = 0$$

$$y_1 y_2 = (kx_1 + 2)(kx_2 + 2) = k^2 x_1 x_2 + 2k(x_1 + x_2) + 4$$

$$= k^2 \cdot \frac{4}{3 + 4k^2} + 2k \cdot \frac{-16k}{3 + 4k^2} + 4$$

$$= \frac{4k^2 - 32k^2}{3 + 4k^2} + 4 = \frac{-28k^2}{3 + 4k^2} + 4 = \frac{-28k^2 + 12 + 16k^2}{3 + 4k^2} = \frac{12 - 12k^2}{3 + 4k^2}$$

$$x_1 x_2 + y_1 y_2 = \frac{4}{3 + 4k^2} + \frac{12 - 12k^2}{3 + 4k^2} = \frac{16 - 12k^2}{3 + 4k^2} = 0$$

$$16 - 12k^2 = 0 \implies k^2 = \frac{4}{3} \implies k = \pm\frac{2\sqrt{3}}{3}$$

验证判别式 $\Delta = (16k)^2 - 4(3+4k^2)(4) = 256k^2 - 16(3+4k^2) = 256 \times \frac{4}{3} - 16 \times 7 = \frac{1024}{3} - 112 > 0$ ✓

**答案：（1）$\dfrac{x^2}{4} + \dfrac{y^2}{3} = 1$；（2）$l: y = \pm\dfrac{2\sqrt{3}}{3}x + 2$。**

**⚠️ 易错提醒：** $\overrightarrow{OA} \cdot \overrightarrow{OB} = 0$ 表示 $OA \perp OB$，展开为 $x_1 x_2 + y_1 y_2 = 0$，利用韦达定理将 $y_1 y_2$ 也用 $x_1, x_2$ 表示。

**💡 解题思路总结：** 解析几何中垂直条件的处理：$\overrightarrow{OA} \cdot \overrightarrow{OB} = 0 \iff x_1 x_2 + y_1 y_2 = 0$，联立后用韦达定理代入。
