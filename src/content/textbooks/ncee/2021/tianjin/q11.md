**题目：** 已知 $\tan\alpha = 2$，则

A. $\sin 2\alpha = \dfrac{4}{5}$

B. $\cos 2\alpha = -\dfrac{3}{5}$

C. $\dfrac{\sin\alpha + \cos\alpha}{\sin\alpha - \cos\alpha} = 3$

D. $\sin^2\alpha + \sin\alpha\cos\alpha = \dfrac{6}{5}$

在每小题给出的选项中，有多项符合题目要求．全部选对的得5分，部分选对的得2分，有选错的得0分．

---

**解答：**

**第1步：** 利用 $\tan\alpha = 2$ 计算
> 📌 运用知识点：三角恒等变换

**A：** $\sin 2\alpha = \dfrac{2\tan\alpha}{1 + \tan^2\alpha} = \dfrac{2 \times 2}{1 + 4} = \dfrac{4}{5}$。**A 正确。**

**B：** $\cos 2\alpha = \dfrac{1 - \tan^2\alpha}{1 + \tan^2\alpha} = \dfrac{1 - 4}{1 + 4} = -\dfrac{3}{5}$。**B 正确。**

**C：** 分子分母同除以 $\cos\alpha$：

$$\frac{\sin\alpha + \cos\alpha}{\sin\alpha - \cos\alpha} = \frac{\tan\alpha + 1}{\tan\alpha - 1} = \frac{2 + 1}{2 - 1} = 3$$

**C 正确。**

**D：** $\sin^2\alpha + \sin\alpha\cos\alpha = \dfrac{\sin^2\alpha + \sin\alpha\cos\alpha}{\sin^2\alpha + \cos^2\alpha} = \dfrac{\tan^2\alpha + \tan\alpha}{1 + \tan^2\alpha} = \dfrac{4 + 2}{5} = \dfrac{6}{5}$。**D 正确。**

**答案：ABCD**

**⚠️ 易错提醒：** 已知 $\tan\alpha$ 求关于 $\sin\alpha, \cos\alpha$ 的表达式时，可以用"齐次化"方法：分子分母同除以 $\cos^n\alpha$ 转化为 $\tan\alpha$ 的表达式。

**💡 解题思路总结：** 万能公式：$\sin 2\alpha = \dfrac{2\tan\alpha}{1+\tan^2\alpha}$，$\cos 2\alpha = \dfrac{1-\tan^2\alpha}{1+\tan^2\alpha}$。齐次化是处理 $\sin, \cos$ 表达式的利器。
