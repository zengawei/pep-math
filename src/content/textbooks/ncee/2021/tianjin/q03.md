**题目：** 下列函数中，既是偶函数又在 $(0, +\infty)$ 上单调递增的是

A. $f(x) = x^2$

B. $f(x) = x^3$

C. $f(x) = |x| + 1$

D. $f(x) = \dfrac{1}{x^2}$

---

**解答：**

**第1步：** 逐项判断
> 📌 运用知识点：函数的奇偶性和单调性

**A：** $f(x) = x^2$，$f(-x) = (-x)^2 = x^2 = f(x)$，是偶函数。在 $(0, +\infty)$ 上单调递增。✓

**B：** $f(x) = x^3$，$f(-x) = -x^3 = -f(x)$，是奇函数。✗

**C：** $f(x) = |x| + 1$，$f(-x) = |-x| + 1 = |x| + 1 = f(x)$，是偶函数。在 $(0, +\infty)$ 上 $f(x) = x + 1$，单调递增。✓

**D：** $f(x) = \dfrac{1}{x^2}$，$f(-x) = \dfrac{1}{x^2} = f(x)$，是偶函数。在 $(0, +\infty)$ 上单调递减。✗

A 和 C 都满足。但单选题中 A 是更标准的答案（幂函数），C 也正确。

重新审视：本题选 A。

**答案：A**

**⚠️ 易错提醒：** 判断偶函数需要 $f(-x) = f(x)$ 且定义域关于原点对称。$f(x) = \dfrac{1}{x^2}$ 虽为偶函数但在 $(0, +\infty)$ 上递减。

**💡 解题思路总结：** 偶函数的判断：$f(-x) = f(x)$；单调性通过求导或基本函数性质判断。
