**题目：** 已知椭圆 $\dfrac{x^2}{9} + \dfrac{y^2}{4} = 1$ 的左、右焦点分别为 $F_1$、$F_2$，点 $P$ 在椭圆上，则

A. $a = 3$，$b = 2$

B. 椭圆的离心率为 $\dfrac{\sqrt{5}}{3}$

C. $|PF_1|$ 的最大值为 $3 + \sqrt{5}$

D. $\triangle PF_1F_2$ 的周长为 $6 + 2\sqrt{5}$

在每小题给出的选项中，有多项符合题目要求．全部选对的得5分，部分选对的得2分，有选错的得0分．

---

**解答：**

**第1步：** 确定参数
> 📌 运用知识点：椭圆的标准方程

$a^2 = 9$，$b^2 = 4$，$c^2 = 9 - 4 = 5$。

$a = 3$，$b = 2$，$c = \sqrt{5}$。

**第2步：** 逐项判断

**A：** $a = 3$，$b = 2$。**A 正确。**

**B：** $e = \dfrac{c}{a} = \dfrac{\sqrt{5}}{3}$。**B 正确。**

**C：** $|PF_1| = a + ex_P$（$P$ 在左焦点侧取大值），最大值为 $a + c = 3 + \sqrt{5}$（$P$ 在右端点时）。**C 正确。**

**D：** $\triangle PF_1F_2$ 的周长 $= |PF_1| + |PF_2| + |F_1F_2| = 2a + 2c = 6 + 2\sqrt{5}$。**D 正确。**

**答案：ABCD**

**⚠️ 易错提醒：** 椭圆上一点到焦点的距离范围是 $[a-c, a+c]$。焦点三角形周长 $= 2a + 2c$。

**💡 解题思路总结：** 椭圆基本量 $a^2 = b^2 + c^2$；焦半径范围 $[a-c, a+c]$；焦点三角形周长 $= 2a + 2c$。
