**题目：** 设集合 $A = \{x \mid 1 \leqslant x \leqslant 3\}$，$B = \{x \mid 2 < x < 4\}$，则 $A \cup B =$

A. $\{x \mid 2 < x \leqslant 3\}$

B. $\{x \mid 1 \leqslant x < 4\}$

C. $\{x \mid 1 \leqslant x \leqslant 4\}$

D. $\{x \mid 2 < x < 4\}$

---

**解答：**

**第1步：** 求并集
> 📌 运用知识点：集合的并集运算

$A = [1, 3]$，$B = (2, 4)$。

$A \cup B$ 包含 $A$ 和 $B$ 中所有元素。

$A$ 覆盖 $[1, 3]$，$B$ 覆盖 $(2, 4)$，两者有重叠部分 $(2, 3]$。

合并后为 $[1, 4)$。

**答案：B**

**⚠️ 易错提醒：** 并集取所有元素，注意端点的开闭：$1$ 属于 $A$ 所以包含，$4$ 不属于 $B$ 所以不包含。

**💡 解题思路总结：** 求并集时在数轴上标出两个集合的范围，取覆盖的总范围，注意端点开闭。
