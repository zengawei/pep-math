**题目：** 已知等比数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n$，若 $a_1 = 1$，$S_3 = 7$，则公比 $q = $ ______。

---

**解答：**

**第1步：** 利用求和公式
> 📌 运用知识点：等比数列的前 $n$ 项和

$$S_3 = a_1 + a_1 q + a_1 q^2 = 1 + q + q^2 = 7$$

$$q^2 + q - 6 = 0$$

$$(q + 3)(q - 2) = 0$$

$q = -3$ 或 $q = 2$。

**答案：$2$ 或 $-3$**

**⚠️ 易错提醒：** 等比数列的公比可以为负数，不要只取正值。验证：$q = 2$ 时 $S_3 = 1 + 2 + 4 = 7$ ✓；$q = -3$ 时 $S_3 = 1 - 3 + 9 = 7$ ✓。

**💡 解题思路总结：** 已知 $a_1$ 和 $S_n$ 求 $q$，将 $S_n$ 展开为关于 $q$ 的方程求解。
