**题目：** 如图，在四棱锥 $P\text{-}ABCD$ 中，底面 $ABCD$ 为矩形，$PA \perp$ 底面 $ABCD$，$PA = AB = 2$，$AD = 4$，$M$ 为 $PD$ 的中点。

（1）证明：$BM \parallel$ 平面 $PAC$（注：应为平面 $PAC$ 不对，改为证明 $PB \parallel$ 平面 $MAC$）；

重新设定：$M$ 为 $PD$ 的中点，证明 $PB \parallel$ 平面 $MAC$。

（2）求二面角 $M\text{-}AC\text{-}P$ 的余弦值。

---

**解答：**

**第1步：** 建立坐标系
> 📌 运用知识点：空间向量坐标

以 $A$ 为原点，$\overrightarrow{AB}$、$\overrightarrow{AD}$、$\overrightarrow{AP}$ 分别为 $x$、$y$、$z$ 轴。

$A(0,0,0)$，$B(2,0,0)$，$C(2,4,0)$，$D(0,4,0)$，$P(0,0,2)$。

$M$ 为 $PD$ 中点：$M = \left(0, 2, 1\right)$。

**第2步：** 证明 $PB \parallel$ 平面 $MAC$
> 📌 运用知识点：空间向量证明平行

$\overrightarrow{PB} = B - P = (2, 0, -2)$。

平面 $MAC$ 内两个向量：
$\overrightarrow{AM} = (0, 2, 1)$，$\overrightarrow{AC} = (2, 4, 0)$。

设 $\overrightarrow{PB} = \lambda \overrightarrow{AM} + \mu \overrightarrow{AC}$：

$(2, 0, -2) = \lambda(0, 2, 1) + \mu(2, 4, 0) = (2\mu, 2\lambda + 4\mu, \lambda)$

由第一分量：$2\mu = 2$，$\mu = 1$。

由第三分量：$\lambda = -2$。

验证第二分量：$2(-2) + 4(1) = -4 + 4 = 0$ ✓

所以 $\overrightarrow{PB} = -2\overrightarrow{AM} + \overrightarrow{AC}$。

又 $P$ 不在平面 $MAC$ 上，所以 $PB \parallel$ 平面 $MAC$。

**第3步：** 求二面角
> 📌 运用知识点：空间向量求二面角

二面角 $M\text{-}AC\text{-}P$ 即平面 $MAC$ 与平面 $PAC$ 的夹角。

平面 $MAC$ 的法向量 $\vec{n_1}$：

$\vec{n_1} \cdot \overrightarrow{AM} = 0$：$2y + z = 0$
$\vec{n_1} \cdot \overrightarrow{AC} = 0$：$2x + 4y = 0$，$x = -2y$

取 $y = 1$，$z = -2$，$x = -2$。$\vec{n_1} = (-2, 1, -2)$。

平面 $PAC$ 的法向量 $\vec{n_2}$：

$\overrightarrow{AP} = (0, 0, 2)$，$\overrightarrow{AC} = (2, 4, 0)$。

$\vec{n_2} \cdot \overrightarrow{AP} = 0$：$2z = 0$，$z = 0$。
$\vec{n_2} \cdot \overrightarrow{AC} = 0$：$2x + 4y = 0$，$x = -2y$。

取 $y = 1$，$x = -2$。$\vec{n_2} = (-2, 1, 0)$。

$$\cos\theta = \frac{|\vec{n_1} \cdot \vec{n_2}|}{|\vec{n_1}||\vec{n_2}|} = \frac{|4 + 1 + 0|}{\sqrt{4+1+4} \times \sqrt{4+1+0}} = \frac{5}{3\sqrt{5}} = \frac{5}{3\sqrt{5}} = \frac{\sqrt{5}}{3}$$

**答案：（1）证明见解答；（2）二面角的余弦值为 $\dfrac{\sqrt{5}}{3}$。**

**⚠️ 易错提醒：** 证明线面平行时，需验证直线方向向量可被平面内两向量线性表示，且直线不在平面内。

**💡 解题思路总结：** 空间向量法求二面角：建系→求两平面法向量→用法向量夹角公式。
