**题目：** 在 $\triangle ABC$ 中，角 $A$、$B$、$C$ 的对边分别为 $a$、$b$、$c$，已知 $2\sin B\cos A = \sin(A + C)$。

（1）求角 $A$ 的大小；

（2）若 $a = \sqrt{7}$，$b + c = 4$，求 $\triangle ABC$ 的面积。

---

**解答：**

**第1步：** 利用三角形内角和化简
> 📌 运用知识点：三角恒等变换

在 $\triangle ABC$ 中，$A + B + C = \pi$，所以 $A + C = \pi - B$。

$$\sin(A + C) = \sin(\pi - B) = \sin B$$

原式变为：

$$2\sin B\cos A = \sin B$$

因为 $\sin B \neq 0$（$B$ 是三角形内角），两边除以 $\sin B$：

$$2\cos A = 1 \implies \cos A = \frac{1}{2}$$

$$A = \frac{\pi}{3}$$

**第2步：** 利用余弦定理
> 📌 运用知识点：余弦定理

$$a^2 = b^2 + c^2 - 2bc\cos A$$

$$7 = b^2 + c^2 - 2bc \cdot \frac{1}{2} = b^2 + c^2 - bc$$

又 $b + c = 4$，$(b + c)^2 = b^2 + 2bc + c^2 = 16$。

$$b^2 + c^2 = 16 - 2bc$$

代入：

$$7 = 16 - 2bc - bc = 16 - 3bc$$

$$3bc = 9 \implies bc = 3$$

**第3步：** 求面积

$$S = \frac{1}{2}bc\sin A = \frac{1}{2} \times 3 \times \sin\frac{\pi}{3} = \frac{1}{2} \times 3 \times \frac{\sqrt{3}}{2} = \frac{3\sqrt{3}}{4}$$

**答案：（1）$A = \dfrac{\pi}{3}$；（2）$S = \dfrac{3\sqrt{3}}{4}$。**

**⚠️ 易错提醒：** $\sin(A+C) = \sin(\pi - B) = \sin B$ 是三角形中的重要转化。利用 $(b+c)^2$ 与 $b^2+c^2$ 的关系求 $bc$ 是常用技巧。

**💡 解题思路总结：** 解三角形问题：①利用 $A+B+C=\pi$ 转化角的关系；②余弦定理建立边与角的关系；③面积公式 $S = \dfrac{1}{2}bc\sin A$。
