**题目：** 在 $\left(\sqrt{x} + \dfrac{1}{\sqrt[3]{x}}\right)^6$ 的展开式中，下列说法正确的是（ ）

A. 展开式共有 $7$ 项

B. 展开式的二项式系数之和为 $64$

C. 展开式中有理项共有 $2$ 项

D. 展开式的常数项为 $1$

---

**解答：**

**第1步：** 判断展开式的项数
> 📌 运用知识点：binomial-theorem

$(a + b)^6$ 的展开式共有 $6 + 1 = 7$ 项。**A 正确。**

**第2步：** 求二项式系数之和
> 📌 运用知识点：binomial-properties

二项式系数之和为 $2^6 = 64$。**B 正确。**

**第3步：** 写出通项公式，判断有理项
> 📌 运用知识点：binomial-theorem

通项公式：

$$T_{r+1} = \binom{6}{r}(\sqrt{x})^{6-r}\left(\frac{1}{\sqrt[3]{x}}\right)^r = \binom{6}{r} x^{\frac{6-r}{2}} \cdot x^{-\frac{r}{3}} = \binom{6}{r} x^{\frac{6-r}{2} - \frac{r}{3}}$$

化简指数：

$$\frac{6-r}{2} - \frac{r}{3} = \frac{3(6-r) - 2r}{6} = \frac{18 - 5r}{6}$$

有理项要求 $\dfrac{18 - 5r}{6}$ 为整数，即 $18 - 5r$ 是 $6$ 的倍数。

逐一检验 $r = 0, 1, 2, 3, 4, 5, 6$：

- $r = 0$：$\dfrac{18}{6} = 3$ ✓
- $r = 1$：$\dfrac{13}{6}$ ✗
- $r = 2$：$\dfrac{8}{6}$ ✗
- $r = 3$：$\dfrac{3}{6}$ ✗
- $r = 4$：$\dfrac{-2}{6}$ ✗
- $r = 5$：$\dfrac{-7}{6}$ ✗
- $r = 6$：$\dfrac{-12}{6} = -2$ ✓

有理项共 $2$ 项（$r = 0$ 和 $r = 6$）。**C 正确。**

**第4步：** 判断是否存在常数项
> 📌 运用知识点：binomial-theorem

常数项要求 $\dfrac{18 - 5r}{6} = 0$，即 $18 - 5r = 0$，$r = \dfrac{18}{5}$，不是整数。

因此展开式中**没有常数项**。**D 错误。**

**答案：ABC**
