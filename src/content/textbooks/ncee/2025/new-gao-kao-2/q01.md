**题目：** 已知集合 $A = \{x \mid -1 < x < 3\}$，$B = \{x \mid 0 \leqslant x \leqslant 4\}$，则 $A \cap B = $（ ）

A. $\{x \mid 0 \leqslant x < 3\}$

B. $\{x \mid -1 < x \leqslant 4\}$

C. $\{x \mid 0 < x < 3\}$

D. $\{x \mid -1 < x \leqslant 0\}$

---

**解答：**

**第1步：** 分析集合 A 和 B 的范围
> 📌 运用知识点：set-concept

集合 $A = \{x \mid -1 < x < 3\}$ 表示开区间 $(-1, 3)$。

集合 $B = \{x \mid 0 \leqslant x \leqslant 4\}$ 表示闭区间 $[0, 4]$。

**第2步：** 求交集 $A \cap B$
> 📌 运用知识点：set-operations

$A \cap B$ 取两个集合的公共部分：

- 左端点：$\max(-1, 0) = 0$，$A$ 不含 $0$ 的左侧，$B$ 含 $0$，取较严条件，故左端为 $0$ 且包含 $0$。
- 右端点：$\min(3, 4) = 3$，$A$ 不含 $3$，$B$ 含 $3$ 的右侧，取较严条件，故右端为 $3$ 且不包含 $3$。

因此 $A \cap B = \{x \mid 0 \leqslant x < 3\} = [0, 3)$。

**答案：A**
