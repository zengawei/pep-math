**题目：** 已知椭圆 $C: \dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$）的离心率为 $\dfrac{\sqrt{3}}{2}$，且 $a + b = 3$。

(1) 求椭圆 $C$ 的方程；

(2) 设 $A$ 为椭圆 $C$ 的左顶点。$M$，$N$ 为椭圆 $C$ 上两个不同的点（均不与 $A$ 重合），且 $k_{AM} \cdot k_{AN} = -\dfrac{1}{4}$。证明：直线 $MN$ 过定点，并求出该定点的坐标。

---

**解答：**

**第1步：** 利用离心率建立 $a$，$b$ 的关系
> 📌 运用知识点：ellipse-definition

$e = \dfrac{c}{a} = \dfrac{\sqrt{3}}{2}$，所以 $c^2 = \dfrac{3}{4}a^2$。

由 $b^2 = a^2 - c^2$：

$$b^2 = a^2 - \frac{3}{4}a^2 = \frac{1}{4}a^2 \implies b = \frac{a}{2}$$

**第2步：** 联立 $a + b = 3$ 求解
> 📌 运用知识点：ellipse-definition

$$a + \frac{a}{2} = 3 \implies \frac{3a}{2} = 3 \implies a = 2,\quad b = 1$$

椭圆 $C$ 的方程：

$$\frac{x^2}{4} + y^2 = 1$$

**第3步：** 设直线 $MN$ 的方程并联立椭圆
> 📌 运用知识点：conic-section-line

$A(-2, 0)$。设直线 $MN: x = ty + m$（可表示所有不平行于 $y$ 轴的直线；若 $MN$ 平行于 $y$ 轴，可单独验证）。

代入 $\dfrac{x^2}{4} + y^2 = 1$，即 $x^2 + 4y^2 = 4$：

$$(ty + m)^2 + 4y^2 = 4$$

$$(t^2 + 4)y^2 + 2tmy + m^2 - 4 = 0$$

设 $M(x_1, y_1)$，$N(x_2, y_2)$，由韦达定理：

$$y_1 + y_2 = \frac{-2tm}{t^2 + 4}, \quad y_1 y_2 = \frac{m^2 - 4}{t^2 + 4}$$

**第4步：** 计算 $(x_1 + 2)(x_2 + 2)$
> 📌 运用知识点：conic-section-line

$$x_1 + x_2 = t(y_1 + y_2) + 2m = \frac{-2t^2 m}{t^2 + 4} + 2m = \frac{8m}{t^2 + 4}$$

$$x_1 x_2 = (ty_1 + m)(ty_2 + m) = t^2 y_1 y_2 + tm(y_1 + y_2) + m^2$$

$$= t^2 \cdot \frac{m^2 - 4}{t^2 + 4} + tm \cdot \frac{-2tm}{t^2 + 4} + m^2 = \frac{t^2 m^2 - 4t^2 - 2t^2 m^2 + m^2(t^2 + 4)}{t^2 + 4}$$

$$= \frac{4m^2 - 4t^2}{t^2 + 4}$$

$$(x_1 + 2)(x_2 + 2) = x_1 x_2 + 2(x_1 + x_2) + 4 = \frac{4m^2 - 4t^2 + 16m + 4(t^2 + 4)}{t^2 + 4}$$

$$= \frac{4m^2 + 16m + 16}{t^2 + 4} = \frac{4(m + 2)^2}{t^2 + 4}$$

**第5步：** 利用条件 $k_{AM} \cdot k_{AN} = -\dfrac{1}{4}$
> 📌 运用知识点：conic-section-line

$$k_{AM} \cdot k_{AN} = \frac{y_1}{x_1 + 2} \cdot \frac{y_2}{x_2 + 2} = \frac{y_1 y_2}{(x_1 + 2)(x_2 + 2)} = -\frac{1}{4}$$

代入：

$$\frac{\frac{m^2 - 4}{t^2 + 4}}{\frac{4(m + 2)^2}{t^2 + 4}} = \frac{m^2 - 4}{4(m + 2)^2} = -\frac{1}{4}$$

$$m^2 - 4 = -(m + 2)^2$$

$$m^2 - 4 = -m^2 - 4m - 4$$

$$2m^2 + 4m = 0 \implies 2m(m + 2) = 0$$

所以 $m = 0$ 或 $m = -2$。

**第6步：** 排除不合理解
> 📌 运用知识点：conic-section-line

若 $m = -2$，直线 $x = ty - 2$ 过点 $(-2, 0) = A$，与 $M$，$N$ 不与 $A$ 重合矛盾，舍去。

因此 $m = 0$，直线 $MN: x = ty$，即直线 $MN$ 恒过原点 $(0, 0)$。

**验证：** 当 $MN$ 过原点时，$M(x_0, y_0)$，$N(-x_0, -y_0)$（关于原点对称）。

$$k_{AM} \cdot k_{AN} = \frac{y_0}{x_0 + 2} \cdot \frac{-y_0}{-x_0 + 2} = \frac{y_0^2}{x_0^2 - 4}$$

由 $\dfrac{x_0^2}{4} + y_0^2 = 1$，$y_0^2 = \dfrac{4 - x_0^2}{4}$，代入得 $k_{AM} \cdot k_{AN} = -\dfrac{1}{4}$。✓

**结论：** 直线 $MN$ 过定点 $(0, 0)$。

**⚠️ 易错提醒：**
1. 设直线 $x = ty + m$ 而非 $y = kx + b$，是为了包含斜率不存在（竖直线）的情况。但本题最终 $m = 0$ 时直线过原点，斜率可以不存在（$x = 0$ 即 $y$ 轴），此时 $M(0, 1)$，$N(0, -1)$，需单独验证。
2. 解出 $m = 0$ 或 $m = -2$ 后，必须检验 $m = -2$ 是否使直线过 $A$ 点（导致 $M$ 或 $N$ 与 $A$ 重合），不能遗漏排除步骤。
3. 韦达定理展开 $x_1 x_2$ 时计算量大，建议先化简再代入，避免代数错误。

**💡 解题思路总结：**
- 第 (1) 问是标准的"离心率 + 条件"求椭圆方程，核心是 $c^2 = a^2 - b^2$。
- 第 (2) 问的关键策略：
  - 设 $x = ty + m$（而非 $y = kx + b$），避免讨论斜率不存在的情况。
  - 将 $k_{AM} \cdot k_{AN}$ 用韦达定理表示为关于 $m$，$t$ 的表达式。
  - 利用条件化简得到 $m$ 的值，从而确定定点。
- 这类"证明过定点"的题，核心思路是：将几何条件转化为代数方程，证明参数 $m$ 为常数（与 $t$ 无关）。
