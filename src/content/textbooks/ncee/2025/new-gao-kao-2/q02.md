**题目：** 已知复数 $z = \dfrac{2 + \mathrm{i}}{1 - \mathrm{i}}$（其中 $\mathrm{i}$ 为虚数单位），则 $|z| = $（ ）

A. $\dfrac{\sqrt{2}}{2}$

B. $1$

C. $\dfrac{\sqrt{10}}{2}$

D. $\sqrt{10}$

---

**解答：**

**第1步：** 化简复数 $z$
> 📌 运用知识点：complex-number-operations

分子分母同乘共轭复数 $1 + \mathrm{i}$：

$$z = \frac{2 + \mathrm{i}}{1 - \mathrm{i}} \cdot \frac{1 + \mathrm{i}}{1 + \mathrm{i}} = \frac{(2 + \mathrm{i})(1 + \mathrm{i})}{(1 - \mathrm{i})(1 + \mathrm{i})}$$

**第2步：** 计算分子和分母
> 📌 运用知识点：complex-number-operations

分子：$(2 + \mathrm{i})(1 + \mathrm{i}) = 2 + 2\mathrm{i} + \mathrm{i} + \mathrm{i}^2 = 2 + 3\mathrm{i} - 1 = 1 + 3\mathrm{i}$

分母：$(1 - \mathrm{i})(1 + \mathrm{i}) = 1 - \mathrm{i}^2 = 1 + 1 = 2$

所以 $z = \dfrac{1 + 3\mathrm{i}}{2} = \dfrac{1}{2} + \dfrac{3}{2}\mathrm{i}$

**第3步：** 求模
> 📌 运用知识点：complex-number-concept

$$|z| = \sqrt{\left(\frac{1}{2}\right)^2 + \left(\frac{3}{2}\right)^2} = \sqrt{\frac{1}{4} + \frac{9}{4}} = \sqrt{\frac{10}{4}} = \frac{\sqrt{10}}{2}$$

**答案：C**
