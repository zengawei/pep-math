**题目：** 如图，在四棱锥 $P\text{-}ABCD$ 中，底面 $ABCD$ 为矩形，$PA \perp$ 底面 $ABCD$，$PA = AB = 2$，$AD = 4$，$M$ 为 $PD$ 的中点。

(1) 求异面直线 $AM$ 与 $PC$ 所成角的余弦值；

(2) 求二面角 $A\text{-}PC\text{-}M$ 的正弦值。

---

**解答：**

**第1步：** 建立空间直角坐标系
> 📌 运用知识点：space-vector-coordinate

以 $A$ 为原点，$\overrightarrow{AB}$，$\overrightarrow{AD}$，$\overrightarrow{AP}$ 分别为 $x$，$y$，$z$ 轴正方向建立空间直角坐标系。

各点坐标：
$$A(0, 0, 0),\quad B(2, 0, 0),\quad C(2, 4, 0),\quad D(0, 4, 0),\quad P(0, 0, 2)$$

$M$ 为 $PD$ 的中点：
$$M = \left(\frac{0+0}{2}, \frac{0+4}{2}, \frac{2+0}{2}\right) = (0, 2, 1)$$

**第2步：** 求异面直线 $AM$ 与 $PC$ 所成角的余弦值
> 📌 运用知识点：space-vector-concept

$$\overrightarrow{AM} = (0, 2, 1), \quad \overrightarrow{PC} = C - P = (2, 4, -2)$$

$$|\overrightarrow{AM}| = \sqrt{0 + 4 + 1} = \sqrt{5}$$

$$|\overrightarrow{PC}| = \sqrt{4 + 16 + 4} = \sqrt{24} = 2\sqrt{6}$$

$$\overrightarrow{AM} \cdot \overrightarrow{PC} = 0 \times 2 + 2 \times 4 + 1 \times (-2) = 8 - 2 = 6$$

异面直线所成角 $\theta$ 的余弦值（取绝对值）：

$$\cos\theta = \frac{|\overrightarrow{AM} \cdot \overrightarrow{PC}|}{|\overrightarrow{AM}| \cdot |\overrightarrow{PC}|} = \frac{6}{\sqrt{5} \times 2\sqrt{6}} = \frac{6}{2\sqrt{30}} = \frac{3}{\sqrt{30}} = \frac{3\sqrt{30}}{30} = \frac{\sqrt{30}}{10}$$

**第3步：** 求二面角 $A\text{-}PC\text{-}M$ 的正弦值——求平面 $APC$ 的法向量
> 📌 运用知识点：space-vector-coordinate

平面 $APC$ 内的向量：$\overrightarrow{AP} = (0, 0, 2)$，$\overrightarrow{AC} = (2, 4, 0)$。

设法向量 $\vec{n_1} = (x, y, z)$：

$$\begin{cases} \vec{n_1} \cdot \overrightarrow{AP} = 2z = 0 \implies z = 0 \\ \vec{n_1} \cdot \overrightarrow{AC} = 2x + 4y = 0 \implies x = -2y \end{cases}$$

取 $y = -1$，则 $x = 2$，$\vec{n_1} = (2, -1, 0)$。

**第4步：** 求平面 $MPC$ 的法向量
> 📌 运用知识点：space-vector-coordinate

平面 $MPC$ 内的向量：$\overrightarrow{PC} = (2, 4, -2)$，$\overrightarrow{PM} = M - P = (0, 2, -1)$。

设法向量 $\vec{n_2} = (x, y, z)$：

$$\begin{cases} \vec{n_2} \cdot \overrightarrow{PC} = 2x + 4y - 2z = 0 \implies x + 2y - z = 0 \\ \vec{n_2} \cdot \overrightarrow{PM} = 2y - z = 0 \implies z = 2y \end{cases}$$

代入第一式：$x + 2y - 2y = 0 \implies x = 0$。

取 $y = 1$，则 $z = 2$，$\vec{n_2} = (0, 1, 2)$。

**第5步：** 计算二面角的正弦值
> 📌 运用知识点：space-vector-concept

$$\vec{n_1} \cdot \vec{n_2} = 2 \times 0 + (-1) \times 1 + 0 \times 2 = -1$$

$$|\vec{n_1}| = \sqrt{4 + 1 + 0} = \sqrt{5}, \quad |\vec{n_2}| = \sqrt{0 + 1 + 4} = \sqrt{5}$$

$$\cos\alpha = \frac{\vec{n_1} \cdot \vec{n_2}}{|\vec{n_1}||\vec{n_2}|} = \frac{-1}{\sqrt{5} \times \sqrt{5}} = -\frac{1}{5}$$

二面角的正弦值：

$$\sin\alpha = \sqrt{1 - \cos^2\alpha} = \sqrt{1 - \frac{1}{25}} = \sqrt{\frac{24}{25}} = \frac{2\sqrt{6}}{5}$$

**⚠️ 易错提醒：**
1. 异面直线所成角的余弦值必须取绝对值（角在 $\left(0, \dfrac{\pi}{2}\right]$ 内），不要遗漏。
2. 求法向量时，两个方程三个未知数，需要自由选取一个变量的值，注意检验计算是否正确。
3. 二面角的正弦值始终为正，$\sin\alpha = \sqrt{1 - \cos^2\alpha}$，无需判断正负。

**💡 解题思路总结：**
- 建系的关键是找到三条互相垂直的边（本题 $PA \perp$ 底面，底面为矩形，天然满足）。
- 异面直线所成角 = 方向向量夹角的绝对值（余弦取正值）。
- 二面角 = 两平面法向量的夹角（或其补角），正弦值由 $\sin^2 + \cos^2 = 1$ 求得。
