**题目：**
已知抛物线 $C: y^2 = 4x$ 的焦点为 $F$，过 $F$ 的直线 $l$ 与 $C$ 交于 $A$，$B$ 两点。

（1）若 $|AB| = 8$，求直线 $l$ 的方程；

（2）求 $|AF| + 4|BF|$ 的最小值。

---

**解答：**

$y^2 = 4x$，$2p = 4$，$p = 2$，焦点 $F(1, 0)$，准线 $x = -1$。

**第1步：** 讨论直线斜率
> 📌 运用知识点：parabola-properties

若 $l \perp x$ 轴，$l: x = 1$，代入 $y^2 = 4$，$y = \pm 2$，$|AB| = 4 \neq 8$，不合题意。

设 $l: y = k(x - 1)$（$k \neq 0$），代入 $y^2 = 4x$：
$$k^2(x-1)^2 = 4x \implies k^2 x^2 - (2k^2 + 4)x + k^2 = 0$$

设 $A(x_1, y_1)$，$B(x_2, y_2)$，由韦达定理：
$$x_1 + x_2 = \frac{2k^2 + 4}{k^2}, \quad x_1 x_2 = 1$$

**第2步：** 利用焦点弦长公式
> 📌 运用知识点：conic-section-line

$$|AB| = x_1 + x_2 + p = \frac{2k^2 + 4}{k^2} + 2 = 4 + \frac{4}{k^2}$$

令 $|AB| = 8$：$4 + \dfrac{4}{k^2} = 8 \implies k^2 = 1 \implies k = \pm 1$。

直线 $l$ 的方程为 $y = x - 1$ 或 $y = -(x - 1)$，即 $x - y - 1 = 0$ 或 $x + y - 1 = 0$。

**第3步：** 转化 |AF| + 4|BF|
> 📌 运用知识点：parabola-properties

由焦半径公式：$|AF| = x_1 + 1$，$|BF| = x_2 + 1$。

$$|AF| + 4|BF| = (x_1 + 1) + 4(x_2 + 1) = x_1 + 4x_2 + 5$$

由 $x_1 x_2 = 1$，$x_1 = \dfrac{1}{x_2}$：

$$|AF| + 4|BF| = \frac{1}{x_2} + 4x_2 + 5$$

**第4步：** 利用均值不等式求最小值
> 📌 运用知识点：conic-section-line

由均值不等式（$x_2 > 0$）：
$$\frac{1}{x_2} + 4x_2 \geq 2\sqrt{\frac{1}{x_2} \cdot 4x_2} = 4$$

等号成立：$\dfrac{1}{x_2} = 4x_2 \implies x_2 = \dfrac{1}{2}$，此时 $x_1 = 2$。

验证：$x_1 + x_2 = \dfrac{5}{2}$，$(2k^2+4)/k^2 = 5/2 \implies k^2 = 8/3 > 0$，存在。

$|AF| + 4|BF|$ 的最小值为 $4 + 5 = 9$。

---

**⚠️ 易错提醒：**
1. 使用焦点弦长公式 $|AB| = x_1 + x_2 + p$ 时，不要遗漏 $p$ 的值。
2. 使用均值不等式时，必须验证等号成立的条件是否满足（即存在对应的直线）。
3. 注意讨论直线斜率不存在的情况。

**💡 解题思路总结：**
抛物线焦点弦问题的核心技巧：①焦半径与准线距离的转化（$|PF| = x_0 + p/2$）；②韦达定理 $x_1 x_2 = p^2/4$ 的应用；③将目标化为单变量函数后利用均值不等式求最值。
