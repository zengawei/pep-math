**题目：**

在 $\triangle ABC$ 中，角 $A$，$B$，$C$ 的对边分别为 $a$，$b$，$c$，已知 $\cos 2A - 3\cos(B + C) = 1$。

（1）求角 $A$；

（2）若 $a = 2\sqrt{3}$，$b + c = 6$，求 $\triangle ABC$ 的面积。

---

**解答：**

**第1步：** 利用三角形内角和转化条件
> 📌 运用知识点：trig-identity

因为 $A + B + C = \pi$，所以 $B + C = \pi - A$，$\cos(B + C) = \cos(\pi - A) = -\cos A$。

代入已知条件：
$$\cos 2A - 3(-\cos A) = 1$$
$$\cos 2A + 3\cos A = 1$$

**第2步：** 利用二倍角公式求解
> 📌 运用知识点：trig-identity

将 $\cos 2A = 2\cos^2 A - 1$ 代入：
$$2\cos^2 A - 1 + 3\cos A = 1$$
$$2\cos^2 A + 3\cos A - 2 = 0$$
$$(2\cos A - 1)(\cos A + 2) = 0$$

因为 $|\cos A| \leq 1$，$\cos A = -2$ 不成立，所以 $\cos A = \dfrac{1}{2}$。

因为 $A \in (0, \pi)$，所以 $A = \dfrac{\pi}{3}$。

**第3步：** 利用余弦定理求 bc
> 📌 运用知识点：trig-identity

由余弦定理：$a^2 = b^2 + c^2 - 2bc\cos A$

$$12 = b^2 + c^2 - 2bc \cdot \frac{1}{2} = b^2 + c^2 - bc$$

由 $b + c = 6$，得 $b^2 + c^2 = (b+c)^2 - 2bc = 36 - 2bc$。

$$12 = 36 - 2bc - bc = 36 - 3bc$$
$$3bc = 24 \implies bc = 8$$

**第4步：** 计算面积
> 📌 运用知识点：trig-function

$$S = \frac{1}{2}bc\sin A = \frac{1}{2} \times 8 \times \frac{\sqrt{3}}{2} = 2\sqrt{3}$$

**⚠️ 易错提醒：**
1. 利用 $\cos(B+C) = -\cos A$ 转化时，注意符号不要出错。
2. 解三角方程时要检验根的范围，$\cos A = -2$ 要舍去。
3. 求面积时注意使用 $\sin A$ 而非 $\cos A$。

**💡 解题思路总结：**
解三角形问题的核心策略：利用三角形内角和为 $\pi$ 进行角的转化，将已知条件化为关于一个角的方程，再结合余弦定理和已知边长关系求解。
