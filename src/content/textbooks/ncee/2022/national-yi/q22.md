**题目：** 已知函数 $f(x) = x\mathrm{e}^{-x}$（$x \in \mathbb{R}$）。

（1）求 $f(x)$ 的单调区间和最大值；

（2）若方程 $f(x) = a$ 有两个不同的实数根，求 $a$ 的取值范围。

---

**解答：**

**（1）求单调区间和最大值**

**第1步：** 求导
> 📌 运用知识点：derivative-operations

$$f'(x) = \mathrm{e}^{-x} - x\mathrm{e}^{-x} = (1 - x)\mathrm{e}^{-x}$$

**第2步：** 判断
> 📌 运用知识点：derivative-monotonicity

$x < 1$ 时 $f' > 0$（递增），$x > 1$ 时 $f' < 0$（递减）。

最大值 $f(1) = \mathrm{e}^{-1} = \dfrac{1}{\mathrm{e}}$。

$$\boxed{\text{递增区间 } (-\infty, 1)，\text{递减区间 } (1, +\infty)，\text{最大值 } \dfrac{1}{\mathrm{e}}}$$

**（2）求 $a$ 的取值范围**

**第3步：** 分析
> 📌 运用知识点：derivative-applications

$f(x) \to 0$（$x \to -\infty$），$f(x) \to 0$（$x \to +\infty$），$f(1) = \dfrac{1}{\mathrm{e}}$。

$f(x) < 0$（$x < 0$），$f(0) = 0$，$f(x) > 0$（$x > 0$）。

$f(x) = a$ 有两个不同实根 $\iff 0 < a < \dfrac{1}{\mathrm{e}}$。

$$\boxed{0 < a < \dfrac{1}{\mathrm{e}}}$$

**⚠️ 易错提醒：** 注意 $f(x)$ 在 $x < 0$ 时为负，所以 $a$ 不能取负值。

**💡 解题思路总结：** 分析函数的极限行为和极值，画出大致图象确定水平线 $y = a$ 与图象的交点个数。
