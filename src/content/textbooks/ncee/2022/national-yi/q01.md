**题目：** 已知集合 $A = \{x \mid x^2 < 4\}$，$B = \{x \mid x > 0\}$，则 $A \cap B = $（  ）

A. $\{x \mid 0 < x < 2\}$

B. $\{x \mid -2 < x < 2\}$

C. $\{x \mid x > 0\}$

D. $\{x \mid x > -2\}$

---

**解答：**

**第1步：** 求解
> 📌 运用知识点：set-operations

$A = (-2, 2)$，$B = (0, +\infty)$。$A \cap B = (0, 2)$。

**答案：A**
