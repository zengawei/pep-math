**题目：** 已知全集 $U = \{1, 2, 3, 4, 5\}$，$A = \{1, 3, 5\}$，$B = \{2, 3\}$，则 $A \cup (\complement_U B) = $（  ）

A. $\{1, 3, 5\}$

B. $\{1, 2, 3, 5\}$

C. $\{1, 3, 4, 5\}$

D. $\{1, 2, 3, 4, 5\}$

---

**解答：**

**第1步：** 求补集
> 📌 运用知识点：set-operations

$\complement_U B = \{1, 3, 4, 5\}$。

**第2步：** 求并集
> 📌 运用知识点：set-operations

$A \cup (\complement_U B) = \{1, 3, 5\} \cup \{1, 3, 4, 5\} = \{1, 3, 4, 5\}$。

**答案：C**
