**题目：** 已知数列 $\{a_n\}$ 满足 $a_1 = 1$，$a_{n+1} = \dfrac{a_n}{1 + 2a_n}$（$n \geqslant 1$）。

（1）求 $\{a_n\}$ 的通项公式；

（2）设 $b_n = \dfrac{1}{a_n \cdot a_{n+1}}$，求数列 $\{b_n\}$ 的前 $n$ 项和 $T_n$。

---

**解答：**

**第1步：** 取倒数
> 📌 运用知识点：递推数列

$a_{n+1} = \dfrac{a_n}{1 + 2a_n}$

取倒数：$\dfrac{1}{a_{n+1}} = \dfrac{1 + 2a_n}{a_n} = \dfrac{1}{a_n} + 2$

**第2步：** 求通项

令 $c_n = \dfrac{1}{a_n}$，则 $c_{n+1} = c_n + 2$，$\{c_n\}$ 是公差为 $2$ 的等差数列。

$c_1 = \dfrac{1}{a_1} = 1$

$c_n = 1 + 2(n-1) = 2n - 1$

$$\boxed{a_n = \frac{1}{2n - 1}}$$

**第3步：** 求 $b_n$
> 📌 运用知识点：裂项求和

$$b_n = \frac{1}{a_n \cdot a_{n+1}} = (2n - 1)(2n + 1)$$

等等，$b_n = \dfrac{1}{a_n \cdot a_{n+1}} = \dfrac{1}{\dfrac{1}{2n-1} \cdot \dfrac{1}{2n+1}} = (2n-1)(2n+1)$

这是递增的，求和会很大。让我重新理解题意。

$b_n = \dfrac{1}{a_n \cdot a_{n+1}}$，其中 $a_n = \dfrac{1}{2n-1}$。

$b_n = \dfrac{1}{\dfrac{1}{2n-1} \cdot \dfrac{1}{2n+1}} = (2n-1)(2n+1) = 4n^2 - 1$

$T_n = \sum_{k=1}^n (4k^2 - 1) = 4 \cdot \dfrac{n(n+1)(2n+1)}{6} - n = \dfrac{2n(n+1)(2n+1)}{3} - n$

$$= \frac{2n(n+1)(2n+1) - 3n}{3} = \frac{n[2(n+1)(2n+1) - 3]}{3} = \frac{n(4n^2 + 6n + 2 - 3)}{3} = \frac{n(4n^2 + 6n - 1)}{3}$$

$$\boxed{T_n = \frac{n(4n^2 + 6n - 1)}{3}}$$

**⚠️ 易错提醒：** 递推关系 $a_{n+1} = \dfrac{a_n}{1 + ca_n}$ 型通过取倒数转化为等差数列。求和时注意 $b_n = (2n-1)(2n+1)$ 不是裂项而是直接求和。

**💡 解题思路总结：** 分式递推 $a_{n+1} = \dfrac{a_n}{1 + ca_n}$ 取倒数得 $\dfrac{1}{a_{n+1}} = \dfrac{1}{a_n} + c$，转化为等差数列。
