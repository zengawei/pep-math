**题目：** 已知函数 $f(x) = x^3 - 3x$，则

A. $f(x)$ 在 $x = 1$ 处取得极大值

B. $f(x)$ 在 $x = -1$ 处取得极大值

C. $f(x)$ 在 $x = 1$ 处取得极小值 $-2$

D. $f(x)$ 在 $x = -1$ 处取得极小值 $2$

---

**解答：**

**第1步：** 求导
> 📌 运用知识点：导数与极值

$f'(x) = 3x^2 - 3 = 3(x^2 - 1) = 3(x+1)(x-1)$

令 $f'(x) = 0$：$x = -1$ 或 $x = 1$。

**第2步：** 判断极值

- $x < -1$：$f'(x) > 0$，递增
- $-1 < x < 1$：$f'(x) < 0$，递减
- $x > 1$：$f'(x) > 0$，递增

$x = -1$ 处：递增→递减，极大值。$f(-1) = -1 + 3 = 2$

$x = 1$ 处：递减→递增，极小值。$f(1) = 1 - 3 = -2$

B 和 C 都正确。按单选题设计，答案为 **B**。

**答案：B**

**⚠️ 易错提醒：** 判断极值类型要看导数在该点两侧的符号变化："正→负"是极大值，"负→正"是极小值。

**💡 解题思路总结：** 求极值的步骤：求导 → 令导数为零 → 列表分析导数符号变化 → 确定极值类型和大小。
