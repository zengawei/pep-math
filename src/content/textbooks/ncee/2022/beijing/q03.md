**题目：** 已知 $a = \log_2 3$，$b = \log_3 2$，$c = \log_2 5$，则

A. $a < b < c$

B. $b < a < c$

C. $b < c < a$

D. $c < a < b$

---

**解答：**

**第1步：** 估计各值
> 📌 运用知识点：对数函数的性质

$a = \log_2 3$：因为 $2^1 = 2 < 3 < 4 = 2^2$，所以 $1 < a < 2$。更精确地 $a \approx 1.585$。

$b = \log_3 2$：因为 $3^0 = 1 < 2 < 3 = 3^1$，所以 $0 < b < 1$。更精确地 $b \approx 0.631$。

$c = \log_2 5$：因为 $2^2 = 4 < 5 < 8 = 2^3$，所以 $2 < c < 3$。更精确地 $c \approx 2.322$。

**第2步：** 比较大小

$b < 1 < a < 2 < c$

所以 $b < a < c$。

**答案：B**

**⚠️ 易错提醒：** 比较对数大小时，可以用"与 $0, 1, 2$ 等整数比较"的方法确定大致范围。

**💡 解题思路总结：** 对数大小的比较：先确定与整数的大小关系，必要时用换底公式精确比较。
