**题目：** 在 $\triangle ABC$ 中，角 $A$、$B$、$C$ 的对边分别为 $a$、$b$、$c$，已知 $a = 2$，$\cos B = \dfrac{1}{4}$，$b = 4$。

（1）求 $\sin A$ 的值；

（2）求 $c$ 的值。

---

**解答：**

**第1步：** 求 $\sin B$
> 📌 运用知识点：三角函数的基本关系

$\sin B = \sqrt{1 - \cos^2 B} = \sqrt{1 - \dfrac{1}{16}} = \sqrt{\dfrac{15}{16}} = \dfrac{\sqrt{15}}{4}$

**第2步：** 利用正弦定理求 $\sin A$
> 📌 运用知识点：正弦定理

$$\frac{a}{\sin A} = \frac{b}{\sin B}$$

$$\sin A = \frac{a \sin B}{b} = \frac{2 \times \dfrac{\sqrt{15}}{4}}{4} = \frac{\sqrt{15}}{8}$$

$$\boxed{\sin A = \frac{\sqrt{15}}{8}}$$

**第3步：** 利用余弦定理求 $c$
> 📌 运用知识点：余弦定理

$$b^2 = a^2 + c^2 - 2ac\cos B$$

$$16 = 4 + c^2 - 2 \times 2 \times c \times \frac{1}{4}$$

$$16 = 4 + c^2 - c$$

$$c^2 - c - 12 = 0$$

$$(c - 4)(c + 3) = 0$$

$c = 4$ 或 $c = -3$（舍去）

$$\boxed{c = 4}$$

**⚠️ 易错提醒：** 余弦定理代入时注意 $2ac\cos B = 2 \times 2 \times c \times \dfrac{1}{4} = c$。解方程后要舍去不合理解（$c > 0$）。

**💡 解题思路总结：** 已知两边一角（非夹角），先用正弦定理求另一角，再用余弦定理求第三边。
