**题目：** 已知函数 $f(x) = x\ln x$。

（1）求 $f(x)$ 的最小值；

（2）若 $f(x) \geqslant ax - 1$ 对 $x \in (0, +\infty)$ 恒成立，求 $a$ 的取值范围。

---

**解答：**

**第1步：** 求导
> 📌 运用知识点：导数与极值

$f(x) = x\ln x$（$x > 0$）

$f'(x) = \ln x + x \cdot \dfrac{1}{x} = \ln x + 1$

**第2步：** 求极值点

令 $f'(x) = 0$：$\ln x = -1$，$x = \text{e}^{-1} = \dfrac{1}{\text{e}}$

当 $0 < x < \dfrac{1}{\text{e}}$ 时 $f'(x) < 0$，$f(x)$ 递减。

当 $x > \dfrac{1}{\text{e}}$ 时 $f'(x) > 0$，$f(x)$ 递增。

$f(x)$ 在 $x = \dfrac{1}{\text{e}}$ 处取最小值：

$$f\left(\frac{1}{\text{e}}\right) = \frac{1}{\text{e}} \ln\frac{1}{\text{e}} = \frac{1}{\text{e}} \times (-1) = -\frac{1}{\text{e}}$$

$$\boxed{f(x)_{\min} = -\frac{1}{\text{e}}}$$

**第3步：** 分析第（2）问
> 📌 运用知识点：导数与恒成立

$x\ln x \geqslant ax - 1$ 对 $x > 0$ 恒成立。

即 $a \leqslant \ln x + \dfrac{1}{x}$ 对 $x > 0$ 恒成立。

**第4步：** 求 $g(x) = \ln x + \dfrac{1}{x}$ 的最小值

$$g'(x) = \frac{1}{x} - \frac{1}{x^2} = \frac{x - 1}{x^2}$$

$g'(x) = 0 \implies x = 1$

当 $0 < x < 1$ 时 $g'(x) < 0$，$g(x)$ 递减。

当 $x > 1$ 时 $g'(x) > 0$，$g(x)$ 递增。

$g(x)$ 在 $x = 1$ 处取最小值：$g(1) = \ln 1 + 1 = 1$

**第5步：** 确定范围

$a \leqslant g(x)_{\min} = 1$

$$\boxed{a \leqslant 1}$$

**⚠️ 易错提醒：** 分离参数后需要求 $g(x) = \ln x + \dfrac{1}{x}$ 的最小值，不要与 $f(x)$ 的最小值混淆。$g'(x)$ 的求导要仔细。

**💡 解题思路总结：** 恒成立问题分离参数：$f(x) \geqslant ax - 1 \iff a \leqslant \dfrac{f(x) + 1}{x}$，转化为求右边函数的最小值。
