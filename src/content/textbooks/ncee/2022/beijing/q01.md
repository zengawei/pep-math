**题目：** 已知全集 $U = \{1, 2, 3, 4, 5\}$，集合 $A = \{1, 3, 5\}$，$B = \{2, 3\}$，则 $A \cup (\complement_U B) =$

A. $\{1, 2, 3, 5\}$

B. $\{1, 3, 4, 5\}$

C. $\{1, 2, 3, 4, 5\}$

D. $\{3\}$

---

**解答：**

**第1步：** 求 $\complement_U B$
> 📌 运用知识点：集合的补集

$\complement_U B = U \setminus B = \{1, 2, 3, 4, 5\} \setminus \{2, 3\} = \{1, 4, 5\}$

**第2步：** 求 $A \cup (\complement_U B)$
> 📌 运用知识点：集合的并集运算

$A \cup (\complement_U B) = \{1, 3, 5\} \cup \{1, 4, 5\} = \{1, 3, 4, 5\}$

**答案：B**

**⚠️ 易错提醒：** 先求补集再求并集，注意运算顺序。补集是相对于全集 $U$ 的。

**💡 解题思路总结：** 集合运算按括号顺序进行：先补集，再并集。
