**题目：** 已知函数 $f(x) = e^x - x - 1$。

（1）求 $f(x)$ 的最小值；

（2）设 $a_n = f\left(\ln\dfrac{n+1}{n}\right)$，$S_n = \displaystyle\sum_{k=1}^{n} a_k$。证明：$S_n > \dfrac{n}{2(n+1)}$。

---

**解答：**

**第1步：** 求 $f(x)$ 的最小值
> 📌 运用知识点：导数与最值

$f'(x) = e^x - 1$

令 $f'(x) = 0$：$e^x = 1 \implies x = 0$

当 $x < 0$ 时 $f'(x) < 0$（递减），当 $x > 0$ 时 $f'(x) > 0$（递增）。

$f(x)$ 在 $x = 0$ 处取最小值：$f(0) = e^0 - 0 - 1 = 0$

$$\boxed{f(x)_{\min} = 0 \text{（在 } x = 0 \text{ 处取到）}}$$

**第2步：** 化简 $a_n$
> 📌 运用知识点：函数求值

$$a_n = f\left(\ln\frac{n+1}{n}\right) = e^{\ln\frac{n+1}{n}} - \ln\frac{n+1}{n} - 1 = \frac{n+1}{n} - \ln\frac{n+1}{n} - 1 = \frac{1}{n} - \ln\frac{n+1}{n}$$

$$= \frac{1}{n} - \ln(n+1) + \ln n$$

**第3步：** 求 $S_n$

$$S_n = \sum_{k=1}^{n} \left(\frac{1}{k} - \ln(k+1) + \ln k\right) = \sum_{k=1}^{n} \frac{1}{k} - (\ln(n+1) - \ln 1) = \sum_{k=1}^{n} \frac{1}{k} - \ln(n+1)$$

**第4步：** 证明不等式
> 📌 运用知识点：数列不等式证明

由第（1）问知 $f(x) \geqslant 0$，即 $e^x \geqslant x + 1$。

取 $x = -\ln\dfrac{n+1}{n} = \ln\dfrac{n}{n+1} < 0$：

$$e^{\ln\frac{n}{n+1}} \geqslant \ln\frac{n}{n+1} + 1 \implies \frac{n}{n+1} \geqslant \ln\frac{n}{n+1} + 1$$

$$\implies -\ln\frac{n+1}{n} \geqslant \frac{n}{n+1} - 1 = -\frac{1}{n+1}$$

$$\implies \ln\frac{n+1}{n} \leqslant \frac{1}{n+1}$$

Wait, that's not right. Let me use $e^x \geqslant x + 1$ differently.

Take $x = \ln\dfrac{n+1}{n} > 0$:

$\dfrac{n+1}{n} \geqslant \ln\dfrac{n+1}{n} + 1 \implies \dfrac{1}{n} \geqslant \ln\dfrac{n+1}{n}$

So $a_n = \dfrac{1}{n} - \ln\dfrac{n+1}{n} \geqslant 0$.

But I need a lower bound. Let me use a tighter inequality.

From $e^x \geqslant x + 1$ (with equality at $x = 0$), for $x > 0$:

$e^x > x + 1$, so $\ln(1+t) < t$ for $t > 0$.

Actually, I need $a_n > \dfrac{1}{2n(n+1)}$ or something similar.

Let me use $\ln(1+t) < t - \dfrac{t^2}{2} + \dfrac{t^3}{3}$... this gets complicated.

Let me try a different approach. We know $\ln(1+t) < t$ for $t > 0$, and $\ln(1+t) > t - \dfrac{t^2}{2}$ for $t > 0$.

$a_n = \dfrac{1}{n} - \ln\left(1 + \dfrac{1}{n}\right) > \dfrac{1}{n} - \dfrac{1}{n} + \dfrac{1}{2n^2} = \dfrac{1}{2n^2}$

Hmm, but I need $S_n > \dfrac{n}{2(n+1)}$.

$\sum \dfrac{1}{2k^2} < \dfrac{n}{2(n+1)}$? Let me check: $\dfrac{1}{2} \sum_{k=1}^n \dfrac{1}{k^2}$. We know $\sum \dfrac{1}{k^2} < 2$, so this gives $S_n < 1$, which doesn't help.

Let me try: $\ln(1+t) < t - \dfrac{t^2}{2(1+t)}$ for $t > 0$.

$a_n = \dfrac{1}{n} - \ln\left(1+\dfrac{1}{n}\right) > \dfrac{1}{n} - \dfrac{1}{n} + \dfrac{1}{2n(n+1)} = \dfrac{1}{2n(n+1)}$

$S_n > \sum_{k=1}^n \dfrac{1}{2k(k+1)} = \dfrac{1}{2}\sum_{k=1}^n \left(\dfrac{1}{k} - \dfrac{1}{k+1}\right) = \dfrac{1}{2}\left(1 - \dfrac{1}{n+1}\right) = \dfrac{n}{2(n+1)}$

This works! But I need to prove $\ln(1+t) < t - \dfrac{t^2}{2(1+t)}$.

Let $g(t) = t - \dfrac{t^2}{2(1+t)} - \ln(1+t)$.

$g(0) = 0$.

$g'(t) = 1 - \dfrac{2t(1+t) - t^2}{2(1+t)^2} - \dfrac{1}{1+t} = 1 - \dfrac{t(2+t)}{2(1+t)^2} - \dfrac{1}{1+t}$

$= 1 - \dfrac{1}{1+t} - \dfrac{t(2+t)}{2(1+t)^2} = \dfrac{t}{1+t} - \dfrac{t(2+t)}{2(1+t)^2} = \dfrac{t}{1+t}\left(1 - \dfrac{2+t}{2(1+t)}\right) = \dfrac{t}{1+t} \cdot \dfrac{2+2t-2-t}{2(1+t)} = \dfrac{t}{1+t} \cdot \dfrac{t}{2(1+t)} = \dfrac{t^2}{2(1+t)^2} > 0$

So $g(t) > 0$ for $t > 0$, which proves $\ln(1+t) < t - \dfrac{t^2}{2(1+t)}$.

This is the right approach. Let me write it up cleanly.

**解答：**

**第1步：** 求 $f(x)$ 的最小值
> 📌 运用知识点：导数与最值

$f'(x) = e^x - 1$，令 $f'(x) = 0$ 得 $x = 0$。

$x < 0$ 时递减，$x > 0$ 时递增。$f(0) = 0$。

$$\boxed{f(x)_{\min} = 0}$$

**第2步：** 化简 $a_n$ 并求 $S_n$

$$a_n = f\left(\ln\frac{n+1}{n}\right) = \frac{n+1}{n} - \ln\frac{n+1}{n} - 1 = \frac{1}{n} - \ln\frac{n+1}{n}$$

$$S_n = \sum_{k=1}^{n}\frac{1}{k} - \ln(n+1)$$

**第3步：** 证明不等式
> 📌 运用知识点：利用函数不等式证明数列不等式

由 $f(x) \geqslant 0$ 知 $e^x \geqslant x + 1$。

构造 $g(t) = t - \dfrac{t^2}{2(1+t)} - \ln(1+t)$（$t > 0$）。

$g(0) = 0$，$g'(t) = \dfrac{t^2}{2(1+t)^2} > 0$（$t > 0$），所以 $g(t) > 0$。

即 $\ln(1+t) < t - \dfrac{t^2}{2(1+t)}$（$t > 0$）。

取 $t = \dfrac{1}{n}$：

$$\ln\frac{n+1}{n} < \frac{1}{n} - \frac{1}{2n(n+1)}$$

$$a_n = \frac{1}{n} - \ln\frac{n+1}{n} > \frac{1}{2n(n+1)}$$

$$S_n > \sum_{k=1}^{n} \frac{1}{2k(k+1)} = \frac{1}{2}\sum_{k=1}^{n}\left(\frac{1}{k} - \frac{1}{k+1}\right) = \frac{1}{2}\left(1 - \frac{1}{n+1}\right) = \frac{n}{2(n+1)}$$

$$\boxed{S_n > \frac{n}{2(n+1)}}$$

**⚠️ 易错提醒：** 证明数列不等式的关键是找到合适的放缩。这里需要证明 $\ln(1+t) < t - \dfrac{t^2}{2(1+t)}$，通过构造函数求导来验证。

**💡 解题思路总结：** 利用第（1）问的结论 $e^x \geqslant x+1$ 启发，构造更精细的不等式。裂项求和后得到目标下界。
