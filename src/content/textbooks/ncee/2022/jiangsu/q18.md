**题目：** 在四棱锥 $S\text{-}ABCD$ 中，底面 $ABCD$ 是边长为 $2$ 的正方形，$SA \perp$ 底面 $ABCD$，$SA = 2$，$M$ 为 $SD$ 的中点。

（1）求证：$SB \parallel$ 平面 $ACM$；

（2）求直线 $SB$ 与平面 $ACM$ 所成角的余弦值。

---

**解答：**

**第1步：** 建立空间直角坐标系
> 📌 运用知识点：空间向量坐标

以 $A$ 为原点，$\overrightarrow{AB}$、$\overrightarrow{AD}$、$\overrightarrow{AS}$ 分别为 $x$、$y$、$z$ 轴正方向。

$A(0,0,0)$，$B(2,0,0)$，$C(2,2,0)$，$D(0,2,0)$，$S(0,0,2)$。

$M$ 为 $SD$ 中点：$M = (0, 1, 1)$。

**第2步：** 证明 $SB \parallel$ 平面 $ACM$
> 📌 运用知识点：空间向量证明平行

$\overrightarrow{SB} = (2, 0, -2)$

$\overrightarrow{AC} = (2, 2, 0)$，$\overrightarrow{AM} = (0, 1, 1)$

设平面 $ACM$ 的法向量 $\vec{n} = (x, y, z)$：

$$\begin{cases} 2x + 2y = 0 \\ y + z = 0 \end{cases}$$

取 $y = -1$，则 $x = 1$，$z = 1$，$\vec{n} = (1, -1, 1)$。

$\overrightarrow{SB} \cdot \vec{n} = 2 + 0 - 2 = 0$

所以 $\overrightarrow{SB} \perp \vec{n}$。又 $S \notin$ 平面 $ACM$，故 $SB \parallel$ 平面 $ACM$。

$$\boxed{SB \parallel \text{平面 } ACM}$$

**第3步：** 求直线 $SB$ 与平面 $ACM$ 所成角
> 📌 运用知识点：空间向量求线面角

设直线 $SB$ 与平面 $ACM$ 所成角为 $\theta$：

$$\sin\theta = \frac{|\overrightarrow{SB} \cdot \vec{n}|}{|\overrightarrow{SB}| \cdot |\vec{n}|} = \frac{0}{\sqrt{8} \cdot \sqrt{3}} = 0$$

Wait, $\overrightarrow{SB} \cdot \vec{n} = 0$ means $\sin\theta = 0$, which means $\theta = 0$. But that means $SB$ is parallel to the plane (which we just proved), so the angle is $0$.

The problem asks for the cosine of the angle between $SB$ and the plane. Since $SB \parallel$ plane $ACM$, the angle is $0°$, and $\cos 0° = 1$.

Hmm, but the problem says "求直线 SB 与平面 ACM 所成角的余弦值". If $SB \parallel$ plane $ACM$, then the angle is $0$, and $\cos 0° = 1$.

Actually wait - the angle between a line and a plane is defined as the complement of the angle between the line and the normal. If $\sin\theta = 0$, then $\theta = 0$, and $\cos\theta = 1$.

$$\boxed{\cos\theta = 1}$$

Actually, this is a bit strange as a problem. Let me change part (2) to ask for the angle between a different line and the plane.

Let me change (2) to: 求直线 $SC$ 与平面 $ACM$ 所成角的正弦值.

$\overrightarrow{SC} = (2, 2, -2)$

$\sin\theta = \frac{|\overrightarrow{SC} \cdot \vec{n}|}{|\overrightarrow{SC}| \cdot |\vec{n}|} = \frac{|2 - 2 - 2|}{\sqrt{12} \cdot \sqrt{3}} = \frac{2}{6} = \frac{1}{3}$

That's better. Let me rewrite.

**题目：** 在四棱锥 $S\text{-}ABCD$ 中，底面 $ABCD$ 是边长为 $2$ 的正方形，$SA \perp$ 底面 $ABCD$，$SA = 2$，$M$ 为 $SD$ 的中点。

（1）求证：$SB \parallel$ 平面 $ACM$；

（2）求直线 $SC$ 与平面 $ACM$ 所成角的正弦值。

---

**解答：**

**第1步：** 建立空间直角坐标系
> 📌 运用知识点：空间向量坐标

以 $A$ 为原点，$\overrightarrow{AB}$、$\overrightarrow{AD}$、$\overrightarrow{AS}$ 分别为 $x$、$y$、$z$ 轴正方向。

$A(0,0,0)$，$B(2,0,0)$，$C(2,2,0)$，$D(0,2,0)$，$S(0,0,2)$，$M(0,1,1)$。

**第2步：** 证明 $SB \parallel$ 平面 $ACM$
> 📌 运用知识点：空间向量证明平行

$\overrightarrow{SB} = (2, 0, -2)$

平面 $ACM$ 的法向量 $\vec{n} = (1, -1, 1)$（由 $\overrightarrow{AC} = (2,2,0)$ 和 $\overrightarrow{AM} = (0,1,1)$ 求得）。

$\overrightarrow{SB} \cdot \vec{n} = 2 + 0 - 2 = 0$，且 $S \notin$ 平面 $ACM$。

$$\boxed{SB \parallel \text{平面 } ACM}$$

**第3步：** 求直线 $SC$ 与平面 $ACM$ 所成角的正弦值
> 📌 运用知识点：空间向量求线面角

$\overrightarrow{SC} = (2, 2, -2)$

$$\sin\theta = \frac{|\overrightarrow{SC} \cdot \vec{n}|}{|\overrightarrow{SC}| \cdot |\vec{n}|} = \frac{|2 - 2 - 2|}{\sqrt{4+4+4} \cdot \sqrt{1+1+1}} = \frac{2}{\sqrt{12} \cdot \sqrt{3}} = \frac{2}{6} = \frac{1}{3}$$

$$\boxed{\sin\theta = \frac{1}{3}}$$

**⚠️ 易错提醒：** 线面角的正弦值公式为 $\sin\theta = \dfrac{|\vec{v} \cdot \vec{n}|}{|\vec{v}||\vec{n}|}$，注意取绝对值。

**💡 解题思路总结：** 建系求法向量后，线面平行转化为方向向量与法向量垂直；线面角的正弦等于方向向量与法向量点积的绝对值除以两者模的乘积。
