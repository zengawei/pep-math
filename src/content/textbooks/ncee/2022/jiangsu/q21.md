**题目：** 已知函数 $f(x) = x^2 - (a + 2)x + a \ln x$（$a > 0$）。

（1）当 $a = 1$ 时，求 $f(x)$ 的极值；

（2）讨论 $f(x)$ 的零点个数。

---

**解答：**

**第1步：** 当 $a = 1$ 时求极值
> 📌 运用知识点：导数与极值

$f(x) = x^2 - 3x + \ln x$，定义域 $x > 0$。

$$f'(x) = 2x - 3 + \frac{1}{x} = \frac{2x^2 - 3x + 1}{x} = \frac{(2x-1)(x-1)}{x}$$

令 $f'(x) = 0$：$x = \dfrac{1}{2}$ 或 $x = 1$。

- $0 < x < \dfrac{1}{2}$：$f'(x) > 0$（递增）
- $\dfrac{1}{2} < x < 1$：$f'(x) < 0$（递减）
- $x > 1$：$f'(x) > 0$（递增）

极大值 $f\left(\dfrac{1}{2}\right) = \dfrac{1}{4} - \dfrac{3}{2} + \ln\dfrac{1}{2} = -\dfrac{5}{4} - \ln 2$

极小值 $f(1) = 1 - 3 + 0 = -2$

$$\boxed{\text{极大值 } -\frac{5}{4} - \ln 2 \text{（在 } x = \frac{1}{2} \text{ 处），极小值 } -2 \text{（在 } x = 1 \text{ 处）}}$$

**第2步：** 分析零点个数
> 📌 运用知识点：导数与零点

$f'(x) = 2x - (a+2) + \dfrac{a}{x} = \frac{2x^2 - (a+2)x + a}{x} = \frac{(2x - a)(x - 1)}{x}$

令 $f'(x) = 0$：$x = \dfrac{a}{2}$ 或 $x = 1$。

**当 $a = 2$ 时：** $\dfrac{a}{2} = 1$，$f'(x) = \dfrac{(2x-2)(x-1)}{x} = \dfrac{2(x-1)^2}{x} \geqslant 0$，$f(x)$ 单调递增。

$f(1) = 1 - 4 + 2\ln 1 = -3 < 0$。当 $x \to +\infty$ 时 $f(x) \to +\infty$。

所以 $f(x)$ 有 $1$ 个零点。

**当 $0 < a < 2$ 时：** $\dfrac{a}{2} < 1$。$f(x)$ 在 $\left(0, \dfrac{a}{2}\right)$ 递增，在 $\left(\dfrac{a}{2}, 1\right)$ 递减，在 $(1, +\infty)$ 递增。

$f(1) = 1 - (a+2) + 0 = -a - 1 < 0$

当 $x \to 0^+$ 时 $f(x) \to -\infty$（因为 $a\ln x \to -\infty$），当 $x \to +\infty$ 时 $f(x) \to +\infty$。

极大值 $f\left(\dfrac{a}{2}\right) = \dfrac{a^2}{4} - \dfrac{a(a+2)}{2} + a\ln\dfrac{a}{2} = -\dfrac{a^2}{4} - a + a\ln\dfrac{a}{2}$

当 $0 < a < 2$ 时，$\dfrac{a}{2} < 1$，$\ln\dfrac{a}{2} < 0$，所以 $f\left(\dfrac{a}{2}\right) < 0$。

$f(x)$ 在 $(1, +\infty)$ 上从 $f(1) < 0$ 递增到 $+\infty$，有 $1$ 个零点。

**当 $a > 2$ 时：** $\dfrac{a}{2} > 1$。$f(x)$ 在 $(0, 1)$ 递增，在 $\left(1, \dfrac{a}{2}\right)$ 递减，在 $\left(\dfrac{a}{2}, +\infty\right)$ 递增。

$f(1) = -a - 1 < 0$。当 $x \to 0^+$ 时 $f(x) \to -\infty$。

$f\left(\dfrac{a}{2}\right) = -\dfrac{a^2}{4} - a + a\ln\dfrac{a}{2}$

当 $a$ 充分大时 $\ln\dfrac{a}{2}$ 可以很大，$f\left(\dfrac{a}{2}\right)$ 可以大于零。

具体地，$f\left(\dfrac{a}{2}\right) > 0 \iff \ln\dfrac{a}{2} > \dfrac{a}{4} + 1$。

设 $g(a) = \ln\dfrac{a}{2} - \dfrac{a}{4} - 1$，$g'(a) = \dfrac{1}{a} - \dfrac{1}{4}$，$g'(a) = 0 \implies a = 4$。

$g(4) = \ln 2 - 2 < 0$。$g(a)$ 的最大值为 $g(4) < 0$，所以 $f\left(\dfrac{a}{2}\right) < 0$ 对所有 $a > 0$ 成立。

因此 $f(x)$ 始终只有 $1$ 个零点（在 $(1, +\infty)$ 或 $\left(\dfrac{a}{2}, +\infty\right)$ 上）。

$$\boxed{f(x) \text{ 有 } 1 \text{ 个零点}}$$

**⚠️ 易错提醒：** 讨论零点个数时需要分析函数的单调性、极值的正负以及端点（或无穷远处）的极限。$x \to 0^+$ 时 $a\ln x \to -\infty$ 是关键。

**💡 解题思路总结：** 含参函数零点个数讨论：求导分析单调性 → 判断极值正负 → 结合极限行为确定零点个数。
