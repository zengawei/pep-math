**题目：** 在 $\triangle ABC$ 中，$a$，$b$，$c$ 分别为角 $A$，$B$，$C$ 的对边，已知 $\sin^2 A + \sin^2 B - \sin^2 C = \sin A\sin B$。

（1）求角 $C$；

（2）若 $c = 2$，$a + b = 4$，求 $\triangle ABC$ 的面积。

---

**解答：**

**（1）求角 $C$**

**第1步：** 正弦定理边化角
> 📌 运用知识点：trig-identity

$a^2 + b^2 - c^2 = ab$。

**第2步：** 余弦定理
> 📌 运用知识点：trig-identity

$\cos C = \dfrac{a^2 + b^2 - c^2}{2ab} = \dfrac{ab}{2ab} = \dfrac{1}{2}$。

$$\boxed{C = \dfrac{\pi}{3}}$$

**（2）求面积**

**第3步：** 求 $ab$
> 📌 运用知识点：trig-function

$c^2 = a^2 + b^2 - 2ab\cos C = (a+b)^2 - 2ab - ab = 16 - 3ab = 4$。

$ab = 4$。

$$S = \frac{1}{2}ab\sin C = \frac{1}{2} \times 4 \times \frac{\sqrt{3}}{2} = \sqrt{3}$$

$$\boxed{S = \sqrt{3}}$$

**⚠️ 易错提醒：** 正弦定理"角化边"后用余弦定理求角是标准方法。

**💡 解题思路总结：** $\sin^2$ 关系→边化→余弦定理→求角→面积公式。
