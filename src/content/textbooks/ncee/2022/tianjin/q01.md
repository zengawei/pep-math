**题目：** 设集合 $U = \{1, 2, 3, 4, 5, 6\}$，$A = \{1, 3, 5\}$，$B = \{3, 4, 5\}$，则 $\complement_U(A \cup B) =$

A. $\{2\}$

B. $\{2, 6\}$

C. $\{1, 2, 4, 6\}$

D. $\{1, 3, 4, 5\}$

---

**解答：**

**第1步：** 求 $A \cup B$
> 📌 运用知识点：集合的并集

$A \cup B = \{1, 3, 5\} \cup \{3, 4, 5\} = \{1, 3, 4, 5\}$

**第2步：** 求补集

$\complement_U(A \cup B) = U \setminus \{1, 3, 4, 5\} = \{2, 6\}$

**答案：B**

**⚠️ 易错提醒：** 先求并集再求补集，注意运算顺序。补集是全集去掉该集合的所有元素。

**💡 解题思路总结：** 集合运算按顺序进行，先并集后补集。也可用德摩根律：$\complement_U(A \cup B) = (\complement_U A) \cap (\complement_U B)$。
