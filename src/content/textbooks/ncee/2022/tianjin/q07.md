**题目：** 已知 $x > 0$，$y > 0$，$x + 2y = 2$，则 $\dfrac{2}{x} + \dfrac{1}{y}$ 的最小值为

A. $2$

B. $3$

C. $4$

D. $5$

---

**解答：**

**第1步：** 利用"乘1法"
> 📌 运用知识点：基本不等式

$$\frac{2}{x} + \frac{1}{y} = \frac{1}{2}\left(\frac{2}{x} + \frac{1}{y}\right)(x + 2y)$$

$$= \frac{1}{2}\left(2 + \frac{4y}{x} + \frac{x}{y} + 2\right) = \frac{1}{2}\left(4 + \frac{4y}{x} + \frac{x}{y}\right)$$

**第2步：** 应用基本不等式

$$\frac{4y}{x} + \frac{x}{y} \geqslant 2\sqrt{\frac{4y}{x} \cdot \frac{x}{y}} = 2 \times 2 = 4$$

等号成立当且仅当 $\dfrac{4y}{x} = \dfrac{x}{y}$，即 $x^2 = 4y^2$，$x = 2y$。

代入 $x + 2y = 2$：$2y + 2y = 2$，$y = \dfrac{1}{2}$，$x = 1$。

$$\frac{2}{x} + \frac{1}{y} \geqslant \frac{1}{2}(4 + 4) = 4$$

**答案：C**

**⚠️ 易错提醒：** "乘1法"中注意乘以 $\dfrac{x + 2y}{2} = 1$，展开后四项中有两项为常数，另两项用基本不等式。

**💡 解题思路总结：** 条件为线性等式时，用"乘1法"展开后用基本不等式求最值。关键是配凑使等号能成立。
