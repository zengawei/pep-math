**题目：** 已知 $a = \log_2 3$，$b = \log_3 2$，$c = \log_2 5$，则

A. $a < b < c$

B. $b < a < c$

C. $b < c < a$

D. $c < a < b$

---

**解答：**

**第1步：** 估计各值范围
> 📌 运用知识点：对数函数的性质

$a = \log_2 3$：因为 $2^1 = 2 < 3 < 4 = 2^2$，所以 $1 < a < 2$。

$b = \log_3 2$：因为 $3^0 = 1 < 2 < 3 = 3^1$，所以 $0 < b < 1$。

$c = \log_2 5$：因为 $2^2 = 4 < 5 < 8 = 2^3$，所以 $2 < c < 3$。

**第2步：** 比较大小

$b < 1 < a < 2 < c$

即 $b < a < c$。

**答案：B**

**⚠️ 易错提醒：** 比较对数值大小时，先判断与 $0$、$1$、$2$ 等整数的关系进行分组。

**💡 解题思路总结：** $\log_a b$ 的大小判断：$b > a > 1$ 时 $\log_a b > 1$；$1 < b < a$ 时 $0 < \log_a b < 1$。
