**题目：** 已知抛物线 $C: y^2 = 4x$ 的焦点为 $F$，过 $F$ 的直线 $l$ 与 $C$ 交于 $A$、$B$ 两点，则

A. $F$ 的坐标为 $(1, 0)$

B. $|AB|$ 的最小值为 $4$

C. 若 $|AF| = 3$，则 $|BF| = \dfrac{3}{2}$

D. $\overrightarrow{OA} \cdot \overrightarrow{OB} = -3$（$O$ 为原点）恒成立

在每小题给出的选项中，有多项符合题目要求．全部选对的得5分，部分选对的得2分，有选错的得0分．

---

**解答：**

**第1步：** 确定基本参数
> 📌 运用知识点：抛物线的性质

$y^2 = 4x$，$2p = 4$，$p = 2$，焦点 $F(1, 0)$。**A 正确。**

**第2步：** 判断 B

焦点弦长 $|AB| = x_1 + x_2 + p = x_1 + x_2 + 2$。

当 $l$ 垂直于 $x$ 轴时（通径），$x_1 = x_2 = 1$，$|AB| = 4$。这是最小值。**B 正确。**

**第3步：** 判断 C

由焦半径公式 $|AF| = x_1 + 1 = 3$，$x_1 = 2$。

$y_1^2 = 4 \times 2 = 8$，$y_1 = \pm 2\sqrt{2}$。

设 $l$ 过 $F(1, 0)$，斜率为 $k$：$y = k(x - 1)$。

$y_1 = 2\sqrt{2}$ 时 $2\sqrt{2} = k(2 - 1) = k$，$k = 2\sqrt{2}$。

联立：$(2\sqrt{2})^2(x-1)^2 = 4x$，$8(x-1)^2 = 4x$，$8x^2 - 20x + 8 = 0$，$2x^2 - 5x + 2 = 0$。

$x_1 x_2 = 1$，$x_2 = \dfrac{1}{2}$。

$|BF| = x_2 + 1 = \dfrac{3}{2}$。**C 正确。**

**第4步：** 判断 D

设 $l: x = my + 1$（含竖直线情况），代入 $y^2 = 4x$：

$y^2 = 4(my + 1)$，$y^2 - 4my - 4 = 0$。

$y_1 y_2 = -4$，$x_1 x_2 = \dfrac{y_1^2}{4} \cdot \dfrac{y_2^2}{4} = \dfrac{(y_1 y_2)^2}{16} = \dfrac{16}{16} = 1$。

$\overrightarrow{OA} \cdot \overrightarrow{OB} = x_1 x_2 + y_1 y_2 = 1 + (-4) = -3$。**D 正确。**

**答案：ABCD**

**⚠️ 易错提醒：** 抛物线焦点弦的重要结论：$x_1 x_2 = \dfrac{p^2}{4}$，$y_1 y_2 = -p^2$。本题 $p = 2$，所以 $x_1 x_2 = 1$，$y_1 y_2 = -4$。

**💡 解题思路总结：** 抛物线 $y^2 = 2px$ 焦点弦性质：$y_1 y_2 = -p^2$，$x_1 x_2 = \dfrac{p^2}{4}$，通径长 $= 2p$。
