**题目：** 某地区对 $100$ 名居民进行健康调查，其中 $60$ 人经常运动，$40$ 人不经常运动。在经常运动的 $60$ 人中有 $48$ 人健康，在不经常运动的 $40$ 人中有 $20$ 人健康。

（1）完成如下列联表，并判断是否有 $99\%$ 的把握认为"健康"与"运动"有关；

|          | 健康 | 不健康 | 合计 |
|:--------:|:----:|:------:|:----:|
| 经常运动 |      |        | $60$ |
| 不经常运动 |    |        | $40$ |
| 合计     |      |        | $100$ |

（2）从经常运动的 $60$ 人中用分层抽样抽取 $5$ 人（按健康与不健康分层），再从这 $5$ 人中随机选 $2$ 人，求恰有 $1$ 人不健康的概率。

附：$K^2 = \dfrac{n(ad-bc)^2}{(a+b)(c+d)(a+c)(b+d)}$。

| $P(K^2 \geqslant k_0)$ | $0.01$ |
|:----------------------:|:------:|
| $k_0$                  | $6.635$|

---

**解答：**

**（1）列联表与独立性检验**

**第1步：** 填写列联表
> 📌 运用知识点：contingency-table

|          | 健康 | 不健康 | 合计 |
|:--------:|:----:|:------:|:----:|
| 经常运动 | $48$ | $12$   | $60$ |
| 不经常运动 | $20$ | $20$ | $40$ |
| 合计     | $68$ | $32$   | $100$ |

**第2步：** 计算 $K^2$
> 📌 运用知识点：independence-test

$$K^2 = \frac{100(48 \times 20 - 12 \times 20)^2}{60 \times 40 \times 68 \times 32} = \frac{100 \times 720^2}{5222400} = \frac{51840000}{5222400} \approx 9.93$$

$K^2 \approx 9.93 > 6.635$。

$$\boxed{\text{有 } 99\% \text{ 的把握认为"健康"与"运动"有关。}}$$

**（2）求概率**

**第3步：** 分层抽样
> 📌 运用知识点：conditional-probability

经常运动中健康 $48$ 人，不健康 $12$ 人，比例 $4:1$。

抽 $5$ 人：健康 $4$ 人，不健康 $1$ 人。

**第4步：** 计算概率
> 📌 运用知识点：random-event-probability

从 $5$ 人中取 $2$ 人：$\mathrm{C}_5^2 = 10$。

恰 $1$ 人不健康：$\mathrm{C}_1^1 \times \mathrm{C}_4^1 = 4$。

$$P = \frac{4}{10} = \frac{2}{5}$$

$$\boxed{P = \dfrac{2}{5}}$$

**⚠️ 易错提醒：** 列联表填写要仔细，$K^2$ 公式中 $ad - bc$ 不要算错。

**💡 解题思路总结：** 独立性检验标准流程 + 分层抽样 + 古典概型。
