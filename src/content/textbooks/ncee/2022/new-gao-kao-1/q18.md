**题目：** 已知椭圆 $E: \dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$）的离心率为 $\dfrac{\sqrt{2}}{2}$，且过点 $\left(1, \dfrac{\sqrt{2}}{2}\right)$。

（1）求椭圆 $E$ 的方程；

（2）设过点 $P(0, 1)$ 的直线 $l$ 与椭圆 $E$ 交于 $A$，$B$ 两点，求 $\triangle OAB$ 面积的最大值（$O$ 为原点）。

---

**解答：**

**（1）求椭圆方程**

**第1步：** 利用离心率
> 📌 运用知识点：ellipse-properties

$e = \dfrac{c}{a} = \dfrac{\sqrt{2}}{2}$，$c^2 = \dfrac{a^2}{2}$，$b^2 = a^2 - c^2 = \dfrac{a^2}{2}$。

**第2步：** 代入点
> 📌 运用知识点：ellipse-definition

$$\frac{1}{a^2} + \frac{1/2}{a^2/2} = \frac{1}{a^2} + \frac{1}{a^2} = \frac{2}{a^2} = 1 \implies a^2 = 2, \; b^2 = 1$$

$$\boxed{\frac{x^2}{2} + y^2 = 1}$$

**（2）求面积最大值**

**第3步：** 设直线并联立
> 📌 运用知识点：conic-section-line

设 $l: y = kx + 1$。代入 $\dfrac{x^2}{2} + y^2 = 1$：

$$x^2 + 2(kx + 1)^2 = 2 \implies (1 + 2k^2)x^2 + 4kx = 0$$

$$x[(1 + 2k^2)x + 4k] = 0$$

$x_1 = 0$（对应 $y = 1$，即点 $P$），$x_2 = \dfrac{-4k}{1 + 2k^2}$。

但 $x_1 = 0$ 对应点 $(0, 1) = P$，这说明 $P$ 在椭圆上。

验证：$\dfrac{0}{2} + 1 = 1$。$P$ 确实在椭圆上！

所以 $A$ 或 $B$ 之一就是 $P$。设 $A = P = (0, 1)$，$B = \left(\dfrac{-4k}{1+2k^2}, \dfrac{1-2k^2}{1+2k^2}\right)$。

**第4步：** 计算面积
> 📌 运用知识点：conic-section-optimization

$$S = \frac{1}{2}|OA| \cdot d(B, OA)$$

$OA$ 的方向为 $(0,1)$，$d(B, OA) = |x_B| = \dfrac{4|k|}{1+2k^2}$。$|OA| = 1$。

$$S = \frac{1}{2} \times 1 \times \frac{4|k|}{1 + 2k^2} = \frac{2|k|}{1 + 2k^2}$$

**第5步：** 求最大值
> 📌 运用知识点：basic-inequality

$$S = \frac{2|k|}{1 + 2k^2} \leqslant \frac{2|k|}{2\sqrt{2}|k|} = \frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2}$$

等号成立：$1 = 2k^2$，$k = \pm\dfrac{\sqrt{2}}{2}$。

$$\boxed{S_{\max} = \dfrac{\sqrt{2}}{2}}$$

**⚠️ 易错提醒：** 注意 $P(0,1)$ 在椭圆上，所以直线与椭圆的一个交点就是 $P$。

**💡 解题思路总结：** 发现定点在椭圆上可简化计算；面积最值用基本不等式。
