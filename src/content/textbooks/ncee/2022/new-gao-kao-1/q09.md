**题目：** 已知 $\tan\alpha = 2$，则下列结论正确的是（  ）

A. $\sin 2\alpha = \dfrac{4}{5}$

B. $\cos 2\alpha = -\dfrac{3}{5}$

C. $\dfrac{\sin\alpha + \cos\alpha}{\sin\alpha - \cos\alpha} = 3$

D. $\sin^2\alpha + \sin\alpha\cos\alpha = \dfrac{6}{5}$

---

**解答：**

**第1步：** 验证 A
> 📌 运用知识点：trig-identity

$$\sin 2\alpha = \frac{2\tan\alpha}{1 + \tan^2\alpha} = \frac{4}{1 + 4} = \frac{4}{5}$$

A 正确。✅

**第2步：** 验证 B
> 📌 运用知识点：trig-identity

$$\cos 2\alpha = \frac{1 - \tan^2\alpha}{1 + \tan^2\alpha} = \frac{1 - 4}{1 + 4} = -\frac{3}{5}$$

B 正确。✅

**第3步：** 验证 C
> 📌 运用知识点：trig-identity

$$\frac{\sin\alpha + \cos\alpha}{\sin\alpha - \cos\alpha} = \frac{\tan\alpha + 1}{\tan\alpha - 1} = \frac{3}{1} = 3$$

C 正确。✅

**第4步：** 验证 D
> 📌 运用知识点：trig-identity

$$\sin^2\alpha + \sin\alpha\cos\alpha = \frac{\sin^2\alpha + \sin\alpha\cos\alpha}{\sin^2\alpha + \cos^2\alpha} = \frac{\tan^2\alpha + \tan\alpha}{1 + \tan^2\alpha} = \frac{4 + 2}{5} = \frac{6}{5}$$

D 正确。✅

**答案：A、B、C、D**

**⚠️ 易错提醒：** 已知 $\tan\alpha$ 求三角函数值，利用万能公式（齐次化）是常用技巧。

**💡 解题思路总结：** $\sin 2\alpha$、$\cos 2\alpha$ 的万能公式，以及分子分母同除以 $\cos^2\alpha$ 的齐次化方法。
