**题目：** 已知集合 $A = \{x \mid x^2 - 2x - 3 \leqslant 0\}$，$B = \{x \mid x < 2\}$，则 $A \cap B = $（  ）

A. $\{x \mid -1 \leqslant x < 2\}$

B. $\{x \mid -1 \leqslant x \leqslant 3\}$

C. $\{x \mid x < 2\}$

D. $\{x \mid x \leqslant 3\}$

---

**解答：**

**第1步：** 求解集合 $A$
> 📌 运用知识点：set-operations

$x^2 - 2x - 3 \leqslant 0 \implies (x-3)(x+1) \leqslant 0 \implies -1 \leqslant x \leqslant 3$。

$A = [-1, 3]$。

**第2步：** 求 $A \cap B$
> 📌 运用知识点：set-operations

$A \cap B = [-1, 3] \cap (-\infty, 2) = [-1, 2)$。

**答案：A**
