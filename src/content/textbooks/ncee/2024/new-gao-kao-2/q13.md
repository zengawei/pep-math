**题目：** 已知向量 $\vec{a} = (1, 2)$，$\vec{b} = (-2, 1)$，则 $\vec{a}$ 与 $2\vec{a} + \vec{b}$ 的夹角的余弦值为 \_\_\_\_\_\_。

---

**解答：**

**第1步：** 计算 $2\vec{a} + \vec{b}$
> 📌 运用知识点：vector-coordinate

$$2\vec{a} + \vec{b} = 2(1, 2) + (-2, 1) = (2, 4) + (-2, 1) = (0, 5)$$

**第2步：** 计算点积和模
> 📌 运用知识点：vector-dot-product

$$\vec{a} \cdot (2\vec{a} + \vec{b}) = (1)(0) + (2)(5) = 10$$

$$|\vec{a}| = \sqrt{1^2 + 2^2} = \sqrt{5}$$

$$|2\vec{a} + \vec{b}| = \sqrt{0^2 + 5^2} = 5$$

**第3步：** 计算夹角余弦
> 📌 运用知识点：vector-calculate-angle

$$\cos\theta = \frac{\vec{a} \cdot (2\vec{a} + \vec{b})}{|\vec{a}| \cdot |2\vec{a} + \vec{b}|} = \frac{10}{\sqrt{5} \times 5} = \frac{10}{5\sqrt{5}} = \frac{2}{\sqrt{5}} = \frac{2\sqrt{5}}{5}$$

**答案：$\dfrac{2\sqrt{5}}{5}$**
