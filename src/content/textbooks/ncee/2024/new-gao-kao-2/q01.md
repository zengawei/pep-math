**题目：** 已知集合 $A = \{-1, 0, 1, 2, 3\}$，$B = \{x \mid x^2 \leq 1\}$，则 $A \cap B = $（ ）

A. $\{-1, 0, 1\}$

B. $\{0, 1, 2\}$

C. $\{-1, 0, 1, 2\}$

D. $\{0, 1\}$

---

**解答：**

**第1步：** 求集合 $B$
> 📌 运用知识点：set-operations

解不等式 $x^2 \leq 1$，得 $-1 \leq x \leq 1$。

所以 $B = \{x \mid -1 \leq x \leq 1\} = [-1, 1]$。

**第2步：** 求 $A \cap B$
> 📌 运用知识点：set-operations

从集合 $A = \{-1, 0, 1, 2, 3\}$ 中，找出属于 $B = [-1, 1]$ 的元素：

- $-1 \in [-1, 1]$ ✓
- $0 \in [-1, 1]$ ✓
- $1 \in [-1, 1]$ ✓
- $2 \notin [-1, 1]$ ✗
- $3 \notin [-1, 1]$ ✗

所以 $A \cap B = \{-1, 0, 1\}$。

**答案：A**
