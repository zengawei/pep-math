**题目：** 在四棱锥 $P\text{-}ABCD$ 中，底面 $ABCD$ 为矩形，$PA \perp$ 底面 $ABCD$，$PA = AB = 2$，$AD = 4$，$M$ 为 $PD$ 的中点。

（1）求 $CM$ 与平面 $PAB$ 所成角的正弦值；

（2）求二面角 $M\text{-}AC\text{-}D$ 的余弦值。

---

**解答：**

**（1）求 $CM$ 与平面 $PAB$ 所成角的正弦值**

**第1步：** 建立空间直角坐标系
> 📌 运用知识点：space-vector-coordinate

以 $A$ 为原点，$\overrightarrow{AB}$、$\overrightarrow{AD}$、$\overrightarrow{AP}$ 分别为 $x$、$y$、$z$ 轴正方向，建立空间直角坐标系。

各点坐标为：
$$A(0,0,0),\quad B(2,0,0),\quad C(2,4,0),\quad D(0,4,0),\quad P(0,0,2)$$

$M$ 为 $PD$ 的中点：
$$M = \left(\frac{0+0}{2},\; \frac{0+4}{2},\; \frac{2+0}{2}\right) = (0,\, 2,\, 1)$$

**第2步：** 求平面 $PAB$ 的法向量
> 📌 运用知识点：space-vector-operations

平面 $PAB$ 过点 $A(0,0,0)$，包含 $\overrightarrow{AB} = (2,0,0)$ 和 $\overrightarrow{AP} = (0,0,2)$。

这两个向量分别沿 $x$ 轴和 $z$ 轴方向，因此平面 $PAB$ 即为 $y = 0$ 平面，其法向量为：
$$\vec{n}_1 = (0,\, 1,\, 0)$$

**第3步：** 计算 $CM$ 与平面 $PAB$ 所成角
> 📌 运用知识点：spatial-angle

$$\overrightarrow{CM} = M - C = (0-2,\; 2-4,\; 1-0) = (-2,\, -2,\, 1)$$

$$|\overrightarrow{CM}| = \sqrt{(-2)^2 + (-2)^2 + 1^2} = \sqrt{4+4+1} = 3$$

设 $CM$ 与平面 $PAB$ 所成角为 $\theta$，则：

$$\sin\theta = \frac{|\overrightarrow{CM} \cdot \vec{n}_1|}{|\overrightarrow{CM}| \cdot |\vec{n}_1|} = \frac{|(-2)(0) + (-2)(1) + (1)(0)|}{3 \times 1} = \frac{2}{3}$$

$$\boxed{\sin\theta = \dfrac{2}{3}}$$

**（2）求二面角 $M\text{-}AC\text{-}D$ 的余弦值**

**第4步：** 求平面 $MAC$ 的法向量
> 📌 运用知识点：space-vector-operations

$$\overrightarrow{AC} = C - A = (2,\, 4,\, 0)$$
$$\overrightarrow{AM} = M - A = (0,\, 2,\, 1)$$

设平面 $MAC$ 的法向量 $\vec{n}_2 = (a,\, b,\, c)$：

$$\vec{n}_2 \cdot \overrightarrow{AC} = 2a + 4b = 0 \quad \cdots (1)$$
$$\vec{n}_2 \cdot \overrightarrow{AM} = 2b + c = 0 \quad \cdots (2)$$

由 $(1)$：$a = -2b$。由 $(2)$：$c = -2b$。

取 $b = -1$，则 $a = 2$，$c = 2$。

$$\vec{n}_2 = (2,\, -1,\, 2)$$

**第5步：** 求二面角
> 📌 运用知识点：spatial-angle

平面 $ACD$（即底面 $ABCD$）的法向量为 $\vec{n}_3 = (0,\, 0,\, 1)$。

$$\cos\alpha = \frac{|\vec{n}_2 \cdot \vec{n}_3|}{|\vec{n}_2| \cdot |\vec{n}_3|} = \frac{|2 \times 0 + (-1) \times 0 + 2 \times 1|}{\sqrt{4+1+4} \times 1} = \frac{2}{3}$$

由图可知，$M$ 在底面上方，二面角 $M\text{-}AC\text{-}D$ 为锐角，因此：

$$\boxed{\cos\alpha = \dfrac{2}{3}}$$

**⚠️ 易错提醒：**
1. 建系时注意三条轴的方向要对应正确，$z$ 轴沿 $PA$ 方向（而非 $AP$）。
2. 线面角的正弦值等于方向向量与法向量夹角余弦的绝对值，不要混淆正弦和余弦。
3. 求二面角时注意判断是锐角还是钝角，需结合图形确定符号。

**💡 解题思路总结：**
本题采用"建系 + 向量法"。关键是正确建立空间直角坐标系，准确写出各点坐标，再利用法向量求解线面角（$\sin\theta = |\cos\langle\vec{d}, \vec{n}\rangle|$）和二面角（$\cos\alpha = |\cos\langle\vec{n}_1, \vec{n}_2\rangle|$）。
