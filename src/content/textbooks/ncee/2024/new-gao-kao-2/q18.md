**题目：** 已知椭圆 $C: \dfrac{x^2}{4} + y^2 = 1$ 的右焦点为 $F$。

（1）求椭圆 $C$ 的离心率；

（2）过 $F$ 的直线 $l$ 与椭圆 $C$ 交于 $A$、$B$ 两点，若 $|AF| = 2|BF|$，求直线 $l$ 的斜率。

---

**解答：**

**（1）求离心率**

**第1步：** 确定椭圆参数
> 📌 运用知识点：ellipse-definition

椭圆 $\dfrac{x^2}{4} + y^2 = 1$，$a^2 = 4$，$b^2 = 1$。

$$c = \sqrt{a^2 - b^2} = \sqrt{4 - 1} = \sqrt{3}$$

**第2步：** 计算离心率
> 📌 运用知识点：ellipse-definition

$$e = \frac{c}{a} = \frac{\sqrt{3}}{2}$$

$$\boxed{e = \dfrac{\sqrt{3}}{2}}$$

**（2）求直线 $l$ 的斜率**

**第3步：** 设定直线方程并联立
> 📌 运用知识点：conic-section-line

右焦点 $F(\sqrt{3},\, 0)$。

设直线 $l: x = my + \sqrt{3}$（此形式可同时包含斜率存在和不存在的情况）。

代入椭圆方程 $\dfrac{x^2}{4} + y^2 = 1$：

$$\frac{(my + \sqrt{3})^2}{4} + y^2 = 1$$

$$(my + \sqrt{3})^2 + 4y^2 = 4$$

$$m^2 y^2 + 2\sqrt{3}my + 3 + 4y^2 = 4$$

$$(m^2 + 4)y^2 + 2\sqrt{3}my - 1 = 0$$

设 $A(x_1, y_1)$，$B(x_2, y_2)$，由韦达定理：

$$y_1 + y_2 = \frac{-2\sqrt{3}m}{m^2 + 4} \quad \cdots (1)$$

$$y_1 y_2 = \frac{-1}{m^2 + 4} \quad \cdots (2)$$

**第4步：** 利用 $|AF| = 2|BF|$ 建立关系
> 📌 运用知识点：conic-section-line

由 $y_1 y_2 = \dfrac{-1}{m^2+4} < 0$ 知 $y_1$ 与 $y_2$ 异号，即 $A$、$B$ 在 $x$ 轴两侧。

由 $|AF| = 2|BF|$，且 $A$、$B$ 在焦点 $F$ 两侧，可得 $|y_1| = 2|y_2|$。

因为 $y_1$、$y_2$ 异号，设 $y_1 = -2y_2$。

**第5步：** 代入韦达定理求解
> 📌 运用知识点：conic-section-line

代入 $(1)$：

$$-2y_2 + y_2 = -y_2 = \frac{-2\sqrt{3}m}{m^2 + 4}$$

$$y_2 = \frac{2\sqrt{3}m}{m^2 + 4}$$

代入 $(2)$：

$$(-2y_2)(y_2) = -2y_2^2 = \frac{-1}{m^2 + 4}$$

$$y_2^2 = \frac{1}{2(m^2 + 4)}$$

将 $y_2$ 的表达式代入：

$$\left(\frac{2\sqrt{3}m}{m^2 + 4}\right)^2 = \frac{1}{2(m^2 + 4)}$$

$$\frac{12m^2}{(m^2 + 4)^2} = \frac{1}{2(m^2 + 4)}$$

两边乘以 $2(m^2+4)^2$：

$$24m^2 = m^2 + 4$$

$$23m^2 = 4 \implies m^2 = \frac{4}{23}$$

**第6步：** 求斜率
> 📌 运用知识点：conic-section-line

直线 $x = my + \sqrt{3}$ 的斜率 $k = \dfrac{1}{m}$，所以：

$$k^2 = \frac{1}{m^2} = \frac{23}{4}$$

$$k = \pm\frac{\sqrt{23}}{2}$$

$$\boxed{k = \pm\dfrac{\sqrt{23}}{2}}$$

**⚠️ 易错提醒：**
1. 焦半径公式 $|AF| = a - ex_1$ 仅适用于右焦点，左焦点为 $a + ex_1$，不要混淆。
2. 设直线为 $x = my + \sqrt{3}$ 时，斜率 $k = \dfrac{1}{m}$（而非 $m$），注意转换。
3. 利用 $|AF| = 2|BF|$ 时，需注意 $A$、$B$ 在焦点两侧，纵坐标异号，关系为 $y_1 = -2y_2$。

**💡 解题思路总结：**
解析几何综合题的核心策略是"设线联立 + 韦达定理 + 条件转化"。将 $|AF| = 2|BF|$ 转化为纵坐标关系 $y_1 = -2y_2$，再利用韦达定理消元求参数。设线为 $x = my + c$ 可避免讨论斜率不存在的情况。
