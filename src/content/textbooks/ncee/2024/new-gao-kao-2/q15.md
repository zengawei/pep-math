**题目：** 已知函数 $f(x) = 2\sin\omega x\cos\omega x + 2\sqrt{3}\cos^2\omega x - \sqrt{3}$（$\omega > 0$），$f(x)$ 图象相邻两条对称轴之间的距离为 $\dfrac{\pi}{2}$。

（1）求 $\omega$ 的值和 $f(x)$ 的化简结果；

（2）若 $f(\alpha) = \dfrac{6}{5}$，$\dfrac{\pi}{4} < \alpha < \dfrac{\pi}{2}$，求 $\cos 2\alpha$ 的值。

---

**解答：**

**（1）求 $\omega$ 的值**

**第1步：** 利用二倍角公式化简
> 📌 运用知识点：trig-identity

$$2\sin\omega x\cos\omega x = \sin 2\omega x$$

$$2\sqrt{3}\cos^2\omega x = \sqrt{3}(1 + \cos 2\omega x)$$

代入得：

$$f(x) = \sin 2\omega x + \sqrt{3}\cos 2\omega x + \sqrt{3} - \sqrt{3} = \sin 2\omega x + \sqrt{3}\cos 2\omega x$$

**第2步：** 辅助角公式化简
> 📌 运用知识点：trig-function

$$f(x) = 2\left(\frac{1}{2}\sin 2\omega x + \frac{\sqrt{3}}{2}\cos 2\omega x\right) = 2\sin\left(2\omega x + \frac{\pi}{3}\right)$$

**第3步：** 由对称轴间距求 $\omega$
> 📌 运用知识点：trig-function

相邻对称轴之间的距离为半个周期：

$$\frac{T}{2} = \frac{\pi}{2} \implies T = \pi$$

又 $T = \dfrac{2\pi}{2\omega} = \dfrac{\pi}{\omega}$，所以 $\dfrac{\pi}{\omega} = \pi$，解得 $\omega = 1$。

$$\boxed{f(x) = 2\sin\left(2x + \frac{\pi}{3}\right)}$$

**（2）求 $\cos 2\alpha$ 的值**

**第4步：** 利用 $f(\alpha)$ 的条件
> 📌 运用知识点：trig-function

$$f(\alpha) = 2\sin\left(2\alpha + \frac{\pi}{3}\right) = \frac{6}{5}$$

$$\sin\left(2\alpha + \frac{\pi}{3}\right) = \frac{3}{5}$$

**第5步：** 确定 $2\alpha + \dfrac{\pi}{3}$ 的范围
> 📌 运用知识点：trig-identity

因为 $\dfrac{\pi}{4} < \alpha < \dfrac{\pi}{2}$，所以：

$$\frac{\pi}{2} < 2\alpha < \pi$$

$$\frac{\pi}{2} + \frac{\pi}{3} < 2\alpha + \frac{\pi}{3} < \pi + \frac{\pi}{3}$$

$$\frac{5\pi}{6} < 2\alpha + \frac{\pi}{3} < \frac{4\pi}{3}$$

在此范围内，$\sin\left(2\alpha + \dfrac{\pi}{3}\right) = \dfrac{3}{5} > 0$，所以 $2\alpha + \dfrac{\pi}{3}$ 在第二象限：

$$\frac{5\pi}{6} < 2\alpha + \frac{\pi}{3} < \pi$$

$$\cos\left(2\alpha + \frac{\pi}{3}\right) = -\sqrt{1 - \left(\frac{3}{5}\right)^2} = -\sqrt{1 - \frac{9}{25}} = -\frac{4}{5}$$

**第6步：** 利用角的变换求 $\cos 2\alpha$
> 📌 运用知识点：trig-identity

$$2\alpha = \left(2\alpha + \frac{\pi}{3}\right) - \frac{\pi}{3}$$

$$\cos 2\alpha = \cos\left[\left(2\alpha + \frac{\pi}{3}\right) - \frac{\pi}{3}\right]$$

$$= \cos\left(2\alpha + \frac{\pi}{3}\right)\cos\frac{\pi}{3} + \sin\left(2\alpha + \frac{\pi}{3}\right)\sin\frac{\pi}{3}$$

$$= \left(-\frac{4}{5}\right) \times \frac{1}{2} + \frac{3}{5} \times \frac{\sqrt{3}}{2}$$

$$= -\frac{4}{10} + \frac{3\sqrt{3}}{10} = \frac{3\sqrt{3} - 4}{10}$$

$$\boxed{\cos 2\alpha = \dfrac{3\sqrt{3} - 4}{10}}$$

**⚠️ 易错提醒：**
1. 化简时容易忘记 $\sqrt{3} - \sqrt{3} = 0$，导致多出一项常数。
2. 确定 $2\alpha + \dfrac{\pi}{3}$ 的范围时容易出错，需要仔细计算不等式的每一步。
3. 求余弦值时，注意根据象限判断正负号。

**💡 解题思路总结：**
本题的核心技巧是"辅助角公式化简 + 角的变换"。先将函数化为 $A\sin(\omega x + \varphi)$ 的标准形式，再利用已知函数值求出相关三角函数值，最后通过角的拆分（$2\alpha = (2\alpha + \frac{\pi}{3}) - \frac{\pi}{3}$）和差角公式求解。
