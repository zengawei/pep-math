**题目：** 某工厂生产的产品质量指标 $X$ 服从正态分布 $N(100, 4)$。

（1）求 $P(96 < X < 104)$；

（2）从该工厂随机抽取 4 件产品，记 $Y$ 为指标不小于 $96$ 的产品件数，求 $Y$ 的分布列和数学期望。

参考数据：$P(\mu - \sigma < X < \mu + \sigma) \approx 0.6827$，$P(\mu - 2\sigma < X < \mu + 2\sigma) \approx 0.9545$，$P(\mu - 3\sigma < X < \mu + 3\sigma) \approx 0.9973$。

---

**解答：**

**（1）求 $P(96 < X < 104)$**

**第1步：** 确定参数
> 📌 运用知识点：normal-distribution

$X \sim N(100, 4)$，故 $\mu = 100$，$\sigma^2 = 4$，$\sigma = 2$。

**第2步：** 转化区间
> 📌 运用知识点：normal-distribution

$$96 = 100 - 4 = \mu - 2\sigma$$
$$104 = 100 + 4 = \mu + 2\sigma$$

所以：

$$P(96 < X < 104) = P(\mu - 2\sigma < X < \mu + 2\sigma) \approx 0.9545$$

$$\boxed{P(96 < X < 104) \approx 0.9545}$$

**（2）求 $Y$ 的分布列和数学期望**

**第3步：** 求单件产品合格的概率
> 📌 运用知识点：normal-distribution

$$P(X \geq 96) = P(X \geq \mu - 2\sigma)$$

由正态分布的对称性：

$$P(X \geq \mu - 2\sigma) = P(X \leq \mu + 2\sigma) = 0.5 + \frac{P(\mu - 2\sigma < X < \mu + 2\sigma)}{2}$$

$$= 0.5 + \frac{0.9545}{2} = 0.5 + 0.47725 = 0.97725$$

记 $p = P(X \geq 96) = 0.97725$。

**第4步：** 确定 $Y$ 的分布
> 📌 运用知识点：binomial-distribution

每件产品是否合格相互独立，$Y$ 为 4 次独立重复试验中合格的次数，故：

$$Y \sim B(4,\, p)，\quad p = 0.97725$$

**第5步：** 计算分布列
> 📌 运用知识点：distribution-table

$$P(Y = k) = \binom{4}{k} p^k (1-p)^{4-k},\quad k = 0, 1, 2, 3, 4$$

其中 $1 - p = 0.02275$。

| $k$ | $P(Y = k)$ | 近似值 |
|:---:|:---:|:---:|
| $0$ | $\binom{4}{0} p^0 (1-p)^4 = (0.02275)^4$ | $\approx 0.0000$ |
| $1$ | $\binom{4}{1} p^1 (1-p)^3 = 4 \times 0.97725 \times (0.02275)^3$ | $\approx 0.0001$ |
| $2$ | $\binom{4}{2} p^2 (1-p)^2 = 6 \times (0.97725)^2 \times (0.02275)^2$ | $\approx 0.0030$ |
| $3$ | $\binom{4}{3} p^3 (1-p)^1 = 4 \times (0.97725)^3 \times 0.02275$ | $\approx 0.0838$ |
| $4$ | $\binom{4}{4} p^4 = (0.97725)^4$ | $\approx 0.9131$ |

**第6步：** 求数学期望
> 📌 运用知识点：expected-value-variance

$$E(Y) = np = 4 \times 0.97725 = 3.909$$

$$\boxed{E(Y) = 3.909}$$

**⚠️ 易错提醒：**
1. 计算 $P(X \geq 96)$ 时，注意利用正态分布的对称性，不要直接查表出错。
2. 判断 $Y$ 服从二项分布时，需确认"独立重复试验"和"每次概率相同"两个条件。
3. 分布列所有概率之和应为 $1$，可用于验算。

**💡 解题思路总结：**
正态分布与二项分布的综合题，关键是"先正态后二项"：先用正态分布求单次概率，再将其作为二项分布的参数 $p$。数学期望直接用 $E(Y) = np$ 计算。
