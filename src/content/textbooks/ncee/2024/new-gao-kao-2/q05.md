**题目：** 在等比数列 $\{a_n\}$ 中，$a_1 + a_3 = 5$，$a_2 + a_4 = 10$，则 $a_5 + a_7 = $（ ）

A. $20$

B. $40$

C. $80$

D. $160$

---

**解答：**

**第1步：** 利用等比数列性质求公比
> 📌 运用知识点：geometric-sequence

设公比为 $q$，则 $a_2 = a_1 q$，$a_3 = a_1 q^2$，$a_4 = a_1 q^3$。

$$a_2 + a_4 = a_1 q + a_1 q^3 = q(a_1 + a_1 q^2) = q(a_1 + a_3)$$

代入已知条件：

$$10 = q \times 5 \implies q = 2$$

**第2步：** 求首项
> 📌 运用知识点：geometric-sequence

$$a_1 + a_3 = a_1 + a_1 q^2 = a_1(1 + 4) = 5a_1 = 5 \implies a_1 = 1$$

**第3步：** 求 $a_5 + a_7$
> 📌 运用知识点：geometric-sequence-sum

$$a_5 + a_7 = a_1 q^4 + a_1 q^6 = a_1 q^4(1 + q^2) = 1 \times 16 \times 5 = 80$$

**答案：C**
