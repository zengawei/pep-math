**题目：** 已知 $a = \log_2 3$，$b = \log_3 2$，$c = \log_3 4$，则（ ）

A. $a < b < c$

B. $b < c < a$

C. $c < b < a$

D. $b < a < c$

---

**解答：**

**第1步：** 分析各值的大致范围
> 📌 运用知识点：logarithmic-function

$a = \log_2 3$：因为 $2^1 = 2 < 3 < 4 = 2^2$，所以 $1 < a < 2$。

$b = \log_3 2$：因为 $3^0 = 1 < 2 < 3 = 3^1$，所以 $0 < b < 1$。

$c = \log_3 4$：因为 $3^1 = 3 < 4 < 9 = 3^2$，所以 $1 < c < 2$。

由此可知 $b$ 最小，排除 A、D。

**第2步：** 比较 $a$ 与 $c$ 的大小
> 📌 运用知识点：logarithmic-function

利用换底公式：

$$a = \log_2 3 = \frac{\ln 3}{\ln 2}$$

$$c = \log_3 4 = \frac{\ln 4}{\ln 3} = \frac{2\ln 2}{\ln 3}$$

比较 $a$ 与 $c$，即比较 $\dfrac{\ln 3}{\ln 2}$ 与 $\dfrac{2\ln 2}{\ln 3}$：

$$a \cdot c = \frac{\ln 3}{\ln 2} \cdot \frac{2\ln 2}{\ln 3} = 2$$

因为 $c = \log_3 4 = 2\log_3 2 = 2b$，且 $0 < b < 1$，所以 $0 < c < 2$。

又 $ac = 2$，$c < 2$，所以 $a = \dfrac{2}{c} > 1$。

进一步：$c = 2b < 2 \times 1 = 2$，而 $a = \log_2 3 > \log_2 2 = 1$。

精确比较：$a = \log_2 3 \approx 1.585$，$c = \log_3 4 \approx 1.262$。

所以 $a > c$。

**第3步：** 得出结论
> 📌 运用知识点：logarithmic-function

$$b < c < a$$

**答案：B**
