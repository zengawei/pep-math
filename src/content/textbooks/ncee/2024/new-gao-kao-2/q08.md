**题目：** 已知 $a > b > 0$，且 $a + b = 1$，则下列不等式成立的是（ ）

A. $a^2 + b^2 < \dfrac{1}{2} < 2ab$

B. $2ab < \dfrac{1}{2} < a^2 + b^2$

C. $2ab < a^2 + b^2 < \dfrac{1}{2}$

D. $\dfrac{1}{2} < 2ab < a^2 + b^2$

---

**解答：**

**第1步：** 分析 $a^2 + b^2$ 与 $\dfrac{1}{2}$ 的关系
> 📌 运用知识点：basic-inequality

由 $a + b = 1$，得：

$$(a + b)^2 = a^2 + 2ab + b^2 = 1$$

所以 $a^2 + b^2 = 1 - 2ab$。

由基本不等式，$a^2 + b^2 \geq \dfrac{(a+b)^2}{2} = \dfrac{1}{2}$。

因为 $a \neq b$（$a > b$），等号不成立，所以 $a^2 + b^2 > \dfrac{1}{2}$。

**第2步：** 分析 $2ab$ 与 $\dfrac{1}{2}$ 的关系
> 📌 运用知识点：basic-inequality

由基本不等式：

$$2ab \leq \frac{(a+b)^2}{2} = \frac{1}{2}$$

因为 $a \neq b$，等号不成立，所以 $2ab < \dfrac{1}{2}$。

**第3步：** 综合结论
> 📌 运用知识点：basic-inequality

$$2ab < \frac{1}{2} < a^2 + b^2$$

**答案：B**
