**题目：** 某校高三年级 800 名学生参加数学考试，成绩 $X$ 近似服从正态分布 $N(85, \sigma^2)$。已知 $P(X \geq 90) = 0.15$，则下列结论正确的是（ ）

A. $P(X \leq 80) = 0.15$

B. $P(80 \leq X \leq 90) = 0.7$

C. 成绩在 $80$ 分到 $90$ 分之间的学生约有 $560$ 人

D. $P(X \geq 85) = 0.5$

---

**解答：**

**第1步：** 判断选项 A
> 📌 运用知识点：normal-distribution

$X \sim N(85, \sigma^2)$，均值 $\mu = 85$。

$80$ 和 $90$ 关于均值 $85$ 对称（$85 - 5 = 80$，$85 + 5 = 90$）。

由正态分布的对称性：

$$P(X \leq 80) = P(X \geq 90) = 0.15$$

A **正确**。

**第2步：** 判断选项 B
> 📌 运用知识点：normal-distribution

$$P(80 \leq X \leq 90) = 1 - P(X < 80) - P(X > 90) = 1 - 0.15 - 0.15 = 0.7$$

B **正确**。

**第3步：** 判断选项 C
> 📌 运用知识点：sample-estimate-population

$$800 \times P(80 \leq X \leq 90) = 800 \times 0.7 = 560 \text{（人）}$$

C **正确**。

**第4步：** 判断选项 D
> 📌 运用知识点：normal-distribution

由正态分布关于均值对称的性质：

$$P(X \geq 85) = P(X \geq \mu) = 0.5$$

D **正确**。

**答案：ABCD**
