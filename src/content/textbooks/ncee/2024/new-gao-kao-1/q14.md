**题目：** 已知抛物线 $C: y^2 = 4x$ 的焦点为 $F$，过 $F$ 的直线 $l$ 与 $C$ 交于 $A$，$B$ 两点，若 $|AF| = 3|BF|$，则 $|AB| = $ ______。

---

**解答：**

**第1步：** 确定焦点和准线
> 📌 运用知识点：parabola-properties

抛物线 $y^2 = 4x$ 中 $2p = 4$，$p = 2$。

焦点 $F(1, 0)$，准线 $x = -1$。

**第2步：** 利用焦半径公式
> 📌 运用知识点：parabola-properties

设 $A(x_1, y_1)$，$B(x_2, y_2)$，由焦半径公式：

$|AF| = x_1 + 1$，$|BF| = x_2 + 1$

由 $|AF| = 3|BF|$：$x_1 + 1 = 3(x_2 + 1)$，即 $x_1 = 3x_2 + 2$。

**第3步：** 利用过焦点直线的性质
> 📌 运用知识点：parabola-properties

设直线 $l: x = my + 1$，代入 $y^2 = 4x$：

$y^2 = 4(my + 1)$，即 $y^2 - 4my - 4 = 0$

由韦达定理：$y_1 y_2 = -4$

又 $y_1^2 = 4x_1$，$y_2^2 = 4x_2$，所以 $x_1 x_2 = \dfrac{y_1^2 y_2^2}{16} = \dfrac{16}{16} = 1$

**第4步：** 联立求解
> 📌 运用知识点：parabola-properties

由 $x_1 = 3x_2 + 2$ 和 $x_1 x_2 = 1$：

$(3x_2 + 2)x_2 = 1$

$3x_2^2 + 2x_2 - 1 = 0$

$(3x_2 - 1)(x_2 + 1) = 0$

$x_2 = \dfrac{1}{3}$（$x_2 > 0$），$x_1 = 3$

$$|AB| = |AF| + |BF| = (x_1 + 1) + (x_2 + 1) = 4 + \frac{4}{3} = \frac{16}{3}$$

**答案：$\dfrac{16}{3}$**
