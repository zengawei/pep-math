**题目：** 已知数列 $\{a_n\}$ 满足 $a_1 = 1$，$a_{n+1} = 2a_n + 1$。

(1) 求数列 $\{a_n\}$ 的通项公式；

(2) 设 $b_n = \dfrac{a_n}{2^n}$，求数列 $\{b_n\}$ 的前 $n$ 项和 $T_n$。

---

**解答：**

**第1步：** 构造等比数列
> 📌 运用知识点：arithmetic-sequence

由 $a_{n+1} = 2a_n + 1$，两边加 $1$：

$$a_{n+1} + 1 = 2a_n + 2 = 2(a_n + 1)$$

设 $c_n = a_n + 1$，则 $c_{n+1} = 2c_n$，且 $c_1 = a_1 + 1 = 2$。

**第2步：** 求通项公式
> 📌 运用知识点：geometric-sequence

$\{c_n\}$ 是以 $2$ 为首项、$2$ 为公比的等比数列：

$$c_n = 2 \cdot 2^{n-1} = 2^n$$

$$a_n = c_n - 1 = 2^n - 1$$

**第3步：** 求 $b_n$ 的表达式
> 📌 运用知识点：sequence-concept

$$b_n = \frac{a_n}{2^n} = \frac{2^n - 1}{2^n} = 1 - \frac{1}{2^n}$$

**第4步：** 求前 $n$ 项和 $T_n$
> 📌 运用知识点：sequence-concept

$$T_n = \sum_{k=1}^{n} b_k = \sum_{k=1}^{n} \left(1 - \frac{1}{2^k}\right) = n - \sum_{k=1}^{n} \frac{1}{2^k}$$

其中 $\displaystyle\sum_{k=1}^{n} \frac{1}{2^k}$ 是首项为 $\dfrac{1}{2}$、公比为 $\dfrac{1}{2}$ 的等比数列前 $n$ 项和：

$$\sum_{k=1}^{n} \frac{1}{2^k} = \frac{\frac{1}{2}\left(1 - \frac{1}{2^n}\right)}{1 - \frac{1}{2}} = 1 - \frac{1}{2^n}$$

$$T_n = n - 1 + \frac{1}{2^n}$$

**⚠️ 易错提醒：** 构造辅助数列时，注意验证首项是否正确。求 $T_n$ 时容易遗漏等比数列求和公式中 $1 - \dfrac{1}{2^n}$ 的化简。

**💡 解题思路总结：** 对于 $a_{n+1} = pa_n + q$ 型递推关系，核心方法是两边加常数构造等比数列。第二问将 $a_n$ 代入后拆项，分别求和即可。
