**题目：** 已知集合 $A = \{x \mid -1 < x < 3\}$，$B = \{x \mid 0 < x < 4\}$，则 $A \cap B = $（  ）

A. $\{x \mid -1 < x < 4\}$

B. $\{x \mid 0 < x < 3\}$

C. $\{x \mid -1 < x < 0\}$

D. $\{x \mid 3 < x < 4\}$

---

**解答：**

**第1步：** 分析集合 A 和 B 的范围
> 📌 运用知识点：set-operations

集合 $A = \{x \mid -1 < x < 3\}$ 表示区间 $(-1, 3)$。

集合 $B = \{x \mid 0 < x < 4\}$ 表示区间 $(0, 4)$。

**第2步：** 求交集
> 📌 运用知识点：set-operations

$A \cap B$ 取两个区间的公共部分：

左端点取较大值：$\max(-1, 0) = 0$

右端点取较小值：$\min(3, 4) = 3$

所以 $A \cap B = \{x \mid 0 < x < 3\}$。

**答案：B**
