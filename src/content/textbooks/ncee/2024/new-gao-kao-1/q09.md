**题目：** 已知 $\sin\alpha + \cos\alpha = \dfrac{\sqrt{2}}{2}$，则（  ）

A. $\sin 2\alpha = -\dfrac{1}{2}$

B. $\sin\alpha \cos\alpha = -\dfrac{1}{4}$

C. $\sin^3\alpha + \cos^3\alpha = \dfrac{3\sqrt{2}}{4}$

D. $\tan\alpha + \dfrac{1}{\tan\alpha} = -2$

---

**解答：**

**第1步：** 求 $\sin\alpha\cos\alpha$
> 📌 运用知识点：trig-identity

将 $\sin\alpha + \cos\alpha = \dfrac{\sqrt{2}}{2}$ 两边平方：

$$\sin^2\alpha + 2\sin\alpha\cos\alpha + \cos^2\alpha = \frac{1}{2}$$

$$1 + 2\sin\alpha\cos\alpha = \frac{1}{2}$$

$$\sin\alpha\cos\alpha = -\frac{1}{4}$$

所以 **B 正确**。

**第2步：** 求 $\sin 2\alpha$
> 📌 运用知识点：trig-identity

$$\sin 2\alpha = 2\sin\alpha\cos\alpha = 2 \times \left(-\frac{1}{4}\right) = -\frac{1}{2}$$

所以 **A 正确**。

**第3步：** 求 $\sin^3\alpha + \cos^3\alpha$
> 📌 运用知识点：trig-identity

$$\sin^3\alpha + \cos^3\alpha = (\sin\alpha + \cos\alpha)(\sin^2\alpha - \sin\alpha\cos\alpha + \cos^2\alpha)$$

$$= \frac{\sqrt{2}}{2} \times \left(1 - \left(-\frac{1}{4}\right)\right) = \frac{\sqrt{2}}{2} \times \frac{5}{4} = \frac{5\sqrt{2}}{8}$$

而 $\dfrac{3\sqrt{2}}{4} = \dfrac{6\sqrt{2}}{8} \neq \dfrac{5\sqrt{2}}{8}$，所以 **C 错误**。

**第4步：** 求 $\tan\alpha + \dfrac{1}{\tan\alpha}$
> 📌 运用知识点：trig-identity

$$\tan\alpha + \frac{1}{\tan\alpha} = \frac{\sin\alpha}{\cos\alpha} + \frac{\cos\alpha}{\sin\alpha} = \frac{\sin^2\alpha + \cos^2\alpha}{\sin\alpha\cos\alpha} = \frac{1}{-\frac{1}{4}} = -4$$

而 $-4 \neq -2$，所以 **D 错误**。

**答案：AB**
