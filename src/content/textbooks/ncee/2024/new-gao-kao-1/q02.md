**题目：** 若复数 $z = \dfrac{2 + \text{i}}{1 - \text{i}}$，则 $|z| = $（  ）

A. $1$

B. $\sqrt{2}$

C. $\dfrac{\sqrt{10}}{2}$

D. $\sqrt{5}$

---

**解答：**

**第1步：** 化简复数 $z$
> 📌 运用知识点：complex-number-operations

分子分母同乘分母的共轭复数 $1 + \text{i}$：

$$z = \frac{2 + \text{i}}{1 - \text{i}} \cdot \frac{1 + \text{i}}{1 + \text{i}} = \frac{(2 + \text{i})(1 + \text{i})}{(1 - \text{i})(1 + \text{i})}$$

**第2步：** 计算分子和分母
> 📌 运用知识点：complex-number-operations

分母：$(1 - \text{i})(1 + \text{i}) = 1 - \text{i}^2 = 1 + 1 = 2$

分子：$(2 + \text{i})(1 + \text{i}) = 2 + 2\text{i} + \text{i} + \text{i}^2 = 2 + 3\text{i} - 1 = 1 + 3\text{i}$

所以 $z = \dfrac{1 + 3\text{i}}{2} = \dfrac{1}{2} + \dfrac{3}{2}\text{i}$

**第3步：** 求模
> 📌 运用知识点：complex-number-operations

$$|z| = \sqrt{\left(\frac{1}{2}\right)^2 + \left(\frac{3}{2}\right)^2} = \sqrt{\frac{1}{4} + \frac{9}{4}} = \sqrt{\frac{10}{4}} = \frac{\sqrt{10}}{2}$$

**答案：C**
