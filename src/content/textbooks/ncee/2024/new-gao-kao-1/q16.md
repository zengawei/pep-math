**题目：** 如图，在四棱锥 $P\text{-}ABCD$ 中，底面 $ABCD$ 是正方形，$PA \perp$ 底面 $ABCD$，$PA = AB = 2$。

(1) 求证：$BD \perp PC$；

(2) 求二面角 $B\text{-}PC\text{-}D$ 的余弦值。

---

**解答：**

**第1步：** 建立空间直角坐标系
> 📌 运用知识点：space-vector-coordinate

以 $A$ 为原点，$\overrightarrow{AB}$、$\overrightarrow{AD}$、$\overrightarrow{AP}$ 分别为 $x$、$y$、$z$ 轴正方向。

各点坐标：$A(0,0,0)$，$B(2,0,0)$，$C(2,2,0)$，$D(0,2,0)$，$P(0,0,2)$。

**第2步：** 证明 $BD \perp PC$
> 📌 运用知识点：space-vector-coordinate

$$\overrightarrow{BD} = D - B = (-2, 2, 0)$$

$$\overrightarrow{PC} = C - P = (2, 2, -2)$$

$$\overrightarrow{BD} \cdot \overrightarrow{PC} = (-2)(2) + (2)(2) + (0)(-2) = -4 + 4 + 0 = 0$$

所以 $BD \perp PC$。

**第3步：** 求二面角 $B\text{-}PC\text{-}D$
> 📌 运用知识点：spatial-angle

需要求平面 $BPC$ 和平面 $DPC$ 的法向量。

$\overrightarrow{PB} = (2, 0, -2)$，$\overrightarrow{PC} = (2, 2, -2)$

**第4步：** 求平面 $BPC$ 的法向量 $\vec{n_1}$
> 📌 运用知识点：space-vector-coordinate

设 $\vec{n_1} = (x, y, z)$，则：

$\vec{n_1} \cdot \overrightarrow{PB} = 2x - 2z = 0 \Rightarrow x = z$

$\vec{n_1} \cdot \overrightarrow{PC} = 2x + 2y - 2z = 0 \Rightarrow x + y - z = 0 \Rightarrow y = 0$

取 $z = 1$，则 $\vec{n_1} = (1, 0, 1)$。

**第5步：** 求平面 $DPC$ 的法向量 $\vec{n_2}$
> 📌 运用知识点：space-vector-coordinate

$\overrightarrow{PD} = (0, 2, -2)$，$\overrightarrow{PC} = (2, 2, -2)$

$\vec{n_2} \cdot \overrightarrow{PD} = 2y - 2z = 0 \Rightarrow y = z$

$\vec{n_2} \cdot \overrightarrow{PC} = 2x + 2y - 2z = 0 \Rightarrow x + y - z = 0 \Rightarrow x = 0$

取 $z = 1$，则 $\vec{n_2} = (0, 1, 1)$。

**第6步：** 计算二面角的余弦值
> 📌 运用知识点：spatial-angle

$$\cos\theta = \frac{|\vec{n_1} \cdot \vec{n_2}|}{|\vec{n_1}||\vec{n_2}|} = \frac{|0 + 0 + 1|}{\sqrt{2} \cdot \sqrt{2}} = \frac{1}{2}$$

由图可知二面角 $B\text{-}PC\text{-}D$ 为锐角，所以余弦值为 $\dfrac{1}{2}$。

**⚠️ 易错提醒：** 建系时务必确认三条轴两两垂直。求法向量时注意验证法向量与两个方向向量都垂直。二面角的余弦值需要判断正负号——观察二面角是锐角还是钝角。

**💡 解题思路总结：** 立体几何证明垂直用向量点积为零；求二面角先求两个半平面的法向量，再用夹角公式。关键是正确建系和准确计算法向量。
