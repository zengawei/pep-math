**题目：** 已知椭圆 $C: \dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$）的离心率为 $\dfrac{\sqrt{3}}{2}$，且过点 $(1, \dfrac{1}{2})$。

(1) 求椭圆 $C$ 的方程；

(2) 设直线 $l$ 过点 $M(1, 0)$ 与椭圆 $C$ 交于 $A$，$B$ 两点，问：在 $x$ 轴上是否存在定点 $N$，使得 $\overrightarrow{NA} \cdot \overrightarrow{NB}$ 为定值？若存在，求出 $N$ 的坐标和该定值；若不存在，请说明理由。

---

**解答：**

**第1步：** 利用离心率条件
> 📌 运用知识点：ellipse-definition

$e = \dfrac{c}{a} = \dfrac{\sqrt{3}}{2}$，所以 $c = \dfrac{\sqrt{3}}{2}a$，$c^2 = \dfrac{3}{4}a^2$。

$b^2 = a^2 - c^2 = a^2 - \dfrac{3}{4}a^2 = \dfrac{1}{4}a^2$

**第2步：** 代入已知点求方程
> 📌 运用知识点：ellipse-definition

椭圆过点 $(1, \dfrac{1}{2})$：

$$\frac{1}{a^2} + \frac{\frac{1}{4}}{b^2} = 1$$

代入 $b^2 = \dfrac{a^2}{4}$：

$$\frac{1}{a^2} + \frac{\frac{1}{4}}{\frac{a^2}{4}} = \frac{1}{a^2} + \frac{1}{a^2} = \frac{2}{a^2} = 1$$

$a^2 = 2$，$b^2 = \dfrac{1}{2}$

椭圆方程：$\dfrac{x^2}{2} + 2y^2 = 1$

**第3步：** 设直线和交点
> 📌 运用知识点：conic-section-line

设 $N(t, 0)$。当直线 $l$ 斜率存在时，设 $l: x = my + 1$。

代入椭圆方程：$\dfrac{(my+1)^2}{2} + 2y^2 = 1$

$(m^2 + 4)y^2 + 2my - 1 = 0$

设 $A(x_1, y_1)$，$B(x_2, y_2)$，由韦达定理：

$$y_1 + y_2 = \frac{-2m}{m^2 + 4}, \quad y_1 y_2 = \frac{-1}{m^2 + 4}$$

**第4步：** 计算 $\overrightarrow{NA} \cdot \overrightarrow{NB}$
> 📌 运用知识点：conic-section-line

$$\overrightarrow{NA} \cdot \overrightarrow{NB} = (x_1 - t)(x_2 - t) + y_1 y_2$$

$x_i = my_i + 1$，所以 $x_i - t = my_i + 1 - t$

$$(x_1 - t)(x_2 - t) = m^2 y_1 y_2 + m(1-t)(y_1 + y_2) + (1-t)^2$$

$$\overrightarrow{NA} \cdot \overrightarrow{NB} = (m^2 + 1)y_1 y_2 + m(1-t)(y_1 + y_2) + (1-t)^2$$

代入韦达定理结果：

$$= (m^2 + 1) \cdot \frac{-1}{m^2 + 4} + m(1-t) \cdot \frac{-2m}{m^2 + 4} + (1-t)^2$$

$$= \frac{-(m^2 + 1) - 2m^2(1-t)}{m^2 + 4} + (1-t)^2$$

$$= \frac{-m^2 - 1 - 2m^2 + 2m^2 t}{m^2 + 4} + (1-t)^2$$

$$= \frac{m^2(2t - 3) - 1}{m^2 + 4} + (1-t)^2$$

**第5步：** 令其为定值
> 📌 运用知识点：conic-section-line

要使上式与 $m$ 无关，令 $2t - 3 = -1$（使分子中 $m^2$ 的系数与分母成比例），即 $t = 1$。

当 $t = 1$ 时：

$$\overrightarrow{NA} \cdot \overrightarrow{NB} = \frac{-m^2 - 1}{m^2 + 4} + 0 = \frac{-(m^2 + 1)}{m^2 + 4}$$

这仍与 $m$ 有关，需重新调整。令 $\dfrac{2t-3}{1} = \dfrac{-1}{4}$（使分子为分母的常数倍），即 $2t - 3 = -\dfrac{1}{4}$ 不整。

重新整理：设 $\dfrac{m^2(2t-3) - 1}{m^2 + 4} = \lambda$（常数），则 $m^2(2t-3) - 1 = \lambda(m^2 + 4)$

比较系数：$2t - 3 = \lambda$，$-1 = 4\lambda$

$\lambda = -\dfrac{1}{4}$，$2t - 3 = -\dfrac{1}{4}$，$t = \dfrac{11}{8}$

$$\overrightarrow{NA} \cdot \overrightarrow{NB} = -\frac{1}{4} + \left(1 - \frac{11}{8}\right)^2 = -\frac{1}{4} + \frac{9}{64} = -\frac{16}{64} + \frac{9}{64} = -\frac{7}{64}$$

**第6步：** 验证斜率不存在的情况
> 📌 运用知识点：conic-section-line

当 $l: x = 1$ 时，代入椭圆：$\dfrac{1}{2} + 2y^2 = 1$，$y^2 = \dfrac{1}{4}$，$y = \pm\dfrac{1}{2}$

$A(1, \frac{1}{2})$，$B(1, -\frac{1}{2})$

$$\overrightarrow{NA} \cdot \overrightarrow{NB} = \left(1 - \frac{11}{8}\right)^2 + \frac{1}{2} \times \left(-\frac{1}{2}\right) = \frac{9}{64} - \frac{1}{4} = -\frac{7}{64}$$

验证一致。

**结论：** 存在定点 $N\left(\dfrac{11}{8}, 0\right)$，使得 $\overrightarrow{NA} \cdot \overrightarrow{NB} = -\dfrac{7}{64}$ 为定值。

**⚠️ 易错提醒：** ①求椭圆方程时注意 $b^2 = a^2 - c^2$ 的代入不要出错。②韦达定理应用前要验证判别式 $\Delta > 0$。③待定系数法求定值时，需同时验证斜率不存在的情况。

**💡 解题思路总结：** 解析几何综合题的核心策略是"设而不求"——设出直线方程和交点坐标，利用韦达定理整体处理，避免逐一求解交点。存在性问题的关键是令表达式与参数无关，通过比较系数确定待定值。
