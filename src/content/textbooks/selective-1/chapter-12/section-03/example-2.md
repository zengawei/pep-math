**例题：** 已知圆 $C: (x - 1)^2 + (y + 2)^2 = 9$，直线 $l: x - y + m = 0$。当 $m$ 为何值时，直线与圆相切？

---

**解答：**

**第1步：** 确定圆心和半径
> 📌 运用知识点：直线与圆的位置关系

圆心 $C(1, -2)$，半径 $r = 3$。

**第2步：** 利用相切条件 $d = r$
> 📌 运用知识点：直线与圆的位置关系

圆心到直线 $x - y + m = 0$ 的距离：

$d = \dfrac{|1 - (-2) + m|}{\sqrt{1^2 + (-1)^2}} = \dfrac{|3 + m|}{\sqrt{2}}$

相切条件 $d = r$：

$\dfrac{|3 + m|}{\sqrt{2}} = 3$

$|3 + m| = 3\sqrt{2}$

$3 + m = 3\sqrt{2}$ 或 $3 + m = -3\sqrt{2}$

$m = -3 + 3\sqrt{2}$ 或 $m = -3 - 3\sqrt{2}$

**💡 解题思路总结：** 直线与圆相切 $\Leftrightarrow d = r$。利用圆心到直线的距离公式列方程，解出参数。注意绝对值方程有两个解，对应两条切线。
