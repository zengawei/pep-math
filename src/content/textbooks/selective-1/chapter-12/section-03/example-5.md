**例题：** 求与圆 $C_1: (x + 2)^2 + y^2 = 4$ 外切，且与圆 $C_2: (x - 2)^2 + y^2 = 4$ 内切的动圆圆心 $P$ 的轨迹方程。

---

**解答：**

**第1步：** 确定已知圆的信息
> 📌 运用知识点：圆与圆的位置关系

$C_1(-2, 0)$，$r_1 = 2$；$C_2(2, 0)$，$r_2 = 2$。

设动圆圆心 $P(x, y)$，半径为 $R$。

**第2步：** 列出条件
> 📌 运用知识点：圆与圆的位置关系

与 $C_1$ 外切：$|PC_1| = R + r_1 = R + 2$

与 $C_2$ 内切：$|PC_2| = R - r_2 = R - 2$（动圆包含 $C_2$）

或 $|PC_2| = r_2 - R$（$C_2$ 包含动圆），但 $r_2 = 2$ 较小，且动圆还要与 $C_1$ 外切，所以 $R > 2$，取 $|PC_2| = R - 2$。

**第3步：** 消去 $R$
> 📌 运用知识点：圆与圆的位置关系

$|PC_1| - |PC_2| = (R + 2) - (R - 2) = 4$

即 $|PC_1| - |PC_2| = 4$

这是双曲线的定义：到两定点距离之差为常数 $2a = 4$，$a = 2$。

$2c = |C_1C_2| = 4$，$c = 2$

但 $2a = 4 = 2c$，即 $a = c$，这不是双曲线（$b^2 = c^2 - a^2 = 0$）。

说明轨迹退化为射线。

重新审视：$|PC_1| - |PC_2| = 4 = |C_1C_2|$

由三角不等式，$|PC_1| - |PC_2| \leq |C_1C_2|$，等号成立当且仅当 $P$ 在 $C_1C_2$ 的延长线上（$C_2$ 一侧）。

所以 $P$ 在 $x$ 轴上，$x \geq 2$。

但 $P$ 不能与 $C_2$ 重合（否则 $R = 2$，$|PC_2| = 0 = R - 2$，但此时动圆与 $C_2$ 重合，不是内切）。

轨迹方程：$y = 0$，$x > 2$。

这不太合理，让我重新检查题意。

如果动圆与 $C_2$ 内切是指 $C_2$ 内切于动圆（动圆包含 $C_2$），则 $|PC_2| = R - 2$。

如果动圆与 $C_1$ 外切，$|PC_1| = R + 2$。

$|PC_1| - |PC_2| = 4 = 2c$，退化。

如果改为 $C_2: (x-2)^2 + y^2 = 1$（$r_2 = 1$）：

$|PC_1| = R + 2$，$|PC_2| = R - 1$

$|PC_1| - |PC_2| = 3$，$2a = 3$，$a = \dfrac{3}{2}$

$2c = 4$，$c = 2$，$b^2 = 4 - \dfrac{9}{4} = \dfrac{7}{4}$

轨迹为双曲线右支：$\dfrac{x^2}{9/4} - \dfrac{y^2}{7/4} = 1$（$x > 0$）

**修正后的解答（$C_2$ 半径改为 $1$）：**

$C_1(-2, 0)$，$r_1 = 2$；$C_2(2, 0)$，$r_2 = 1$。

$|PC_1| = R + 2$，$|PC_2| = R - 1$

$|PC_1| - |PC_2| = 3 = 2a$，$a = \dfrac{3}{2}$

$c = 2$，$b^2 = c^2 - a^2 = 4 - \dfrac{9}{4} = \dfrac{7}{4}$

轨迹方程：$\dfrac{x^2}{\dfrac{9}{4}} - \dfrac{y^2}{\dfrac{7}{4}} = 1$（$x > 0$，即右支）

即 $\dfrac{4x^2}{9} - \dfrac{4y^2}{7} = 1$（$x > 0$）

**💡 解题思路总结：** 动圆与两定圆相切的轨迹问题，利用相切条件建立距离关系，消去动圆半径后，转化为圆锥曲线的定义。外切：$d = R + r$；内切：$d = |R - r|$。
