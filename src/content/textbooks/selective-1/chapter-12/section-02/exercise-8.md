**题目：** 已知圆 $C$ 经过点 $A(1, -1)$ 和 $B(-1, 1)$，且圆心在直线 $x + y - 2 = 0$ 上，求圆的方程。

---

**解答：**

**第1步：** 设圆心坐标
> 📌 运用知识点：圆的方程

圆心在 $x + y - 2 = 0$ 上，设圆心 $C(a, 2 - a)$。

**第2步：** 利用 $|CA| = |CB|$
> 📌 运用知识点：圆的方程

$|CA|^2 = (a - 1)^2 + (2 - a + 1)^2 = (a - 1)^2 + (3 - a)^2$

$= a^2 - 2a + 1 + 9 - 6a + a^2 = 2a^2 - 8a + 10$

$|CB|^2 = (a + 1)^2 + (2 - a - 1)^2 = (a + 1)^2 + (1 - a)^2$

$= a^2 + 2a + 1 + 1 - 2a + a^2 = 2a^2 + 2$

$|CA|^2 = |CB|^2$：

$2a^2 - 8a + 10 = 2a^2 + 2$

$-8a + 10 = 2$

$a = 1$

**第3步：** 求圆心和半径
> 📌 运用知识点：圆的方程

圆心 $C(1, 1)$

$r^2 = |CA|^2 = (1 - 1)^2 + (1 + 1)^2 = 0 + 4 = 4$

**第4步：** 写出方程
> 📌 运用知识点：圆的方程

$(x - 1)^2 + (y - 1)^2 = 4$

**⚠️ 易错提醒：** 也可以用 $AB$ 的垂直平分线过圆心来求解。$AB$ 中点 $(0, 0)$，$k_{AB} = \dfrac{1-(-1)}{-1-1} = -1$，垂直平分线 $y = x$。联立 $y = x$ 和 $x + y - 2 = 0$ 得 $x = 1, y = 1$，同样得到圆心 $(1, 1)$。

**💡 解题思路总结：** 已知圆过两点和圆心在某直线上，可以用 $|CA| = |CB|$ 列方程，也可以用弦的垂直平分线与已知直线联立。后者通常计算更简洁。
