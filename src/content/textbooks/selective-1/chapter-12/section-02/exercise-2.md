**题目：** 求经过三点 $A(0, 0)$，$B(2, 0)$，$C(0, 4)$ 的圆的方程。

---

**解答：**

**第1步：** 设一般方程
> 📌 运用知识点：圆的方程

设圆的方程为 $x^2 + y^2 + Dx + Ey + F = 0$。

**第2步：** 代入三点列方程组
> 📌 运用知识点：圆的方程

代入 $A(0, 0)$：$F = 0$

代入 $B(2, 0)$：$4 + 2D + F = 0 \Rightarrow 4 + 2D = 0 \Rightarrow D = -2$

代入 $C(0, 4)$：$16 + 4E + F = 0 \Rightarrow 16 + 4E = 0 \Rightarrow E = -4$

**第3步：** 写出方程
> 📌 运用知识点：圆的方程

$x^2 + y^2 - 2x - 4y = 0$

验证：$D^2 + E^2 - 4F = 4 + 16 - 0 = 20 > 0$，确实表示圆。

配方：$(x - 1)^2 + (y - 2)^2 = 5$，圆心 $(1, 2)$，半径 $\sqrt{5}$。

**💡 解题思路总结：** 已知三点求圆的方程，设一般方程后代入三点坐标列三元一次方程组，解出 $D, E, F$。
