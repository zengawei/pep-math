**例题：** 已知抛物线 $y^2 = 4x$ 的焦点为 $F$，过 $F$ 的直线交抛物线于 $A, B$ 两点，且 $|AF| = 2|BF|$，求直线的斜率。

**解答：**

**第1步：** 确定参数
> 📌 运用知识点：抛物线的几何性质

$2p = 4$，$p = 2$，焦点 $F(1, 0)$

**第2步：** 设焦半径
> 📌 运用知识点：抛物线的几何性质

设 $|BF| = t$，$|AF| = 2t$

$x_1 + 1 = 2t$，$x_2 + 1 = t$

$x_1 = 2t - 1$，$x_2 = t - 1$

**第3步：** 利用 $x_1 x_2 = \dfrac{p^2}{4}$
> 📌 运用知识点：抛物线的几何性质

过焦点的弦满足 $x_1 x_2 = \dfrac{p^2}{4} = 1$

$(2t - 1)(t - 1) = 1$

$2t^2 - 3t + 1 = 1$

$2t^2 - 3t = 0$

$t(2t - 3) = 0$

$t = \dfrac{3}{2}$

**第4步：** 求斜率
> 📌 运用知识点：抛物线的几何性质

$x_1 = 2$，$x_2 = \dfrac{1}{2}$

$x_1 + x_2 = \dfrac{5}{2}$

设直线 $y = k(x - 1)$，代入 $y^2 = 4x$：

$k^2(x-1)^2 = 4x$，$k^2 x^2 - (2k^2 + 4)x + k^2 = 0$

$x_1 + x_2 = \dfrac{2k^2 + 4}{k^2} = \dfrac{5}{2}$

$4k^2 + 8 = 5k^2$

$k^2 = 4$，$k = \pm 2$

**💡 解题思路总结：** 抛物线焦点弦比例问题：① 设焦半径建立方程；② 利用 $x_1 x_2 = \frac{p^2}{4}$ 求参数；③ 再由韦达定理求斜率。$x_1 x_2 = \frac{p^2}{4}$ 是焦点弦的重要性质。
