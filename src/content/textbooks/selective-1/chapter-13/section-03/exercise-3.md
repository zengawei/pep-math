**题目：** 已知抛物线 $y^2 = 4x$ 的焦点为 $F$，过 $F$ 的直线与抛物线交于 $A(x_1, y_1)$，$B(x_2, y_2)$ 两点，且 $|AB| = 8$，求 $x_1 + x_2$ 的值。

---

**解答：**

**第1步：** 确定参数
> 📌 运用知识点：抛物线的定义与标准方程

$2p = 4$，$p = 2$，焦点 $F(1, 0)$。

**第2步：** 利用焦点弦长公式
> 📌 运用知识点：抛物线的几何性质

过焦点的弦 $AB$ 的弦长公式：

$|AB| = x_1 + x_2 + p = x_1 + x_2 + 2$

**第3步：** 求 $x_1 + x_2$
> 📌 运用知识点：抛物线的几何性质

$8 = x_1 + x_2 + 2$

$x_1 + x_2 = 6$

**💡 解题思路总结：** 抛物线焦点弦长公式 $|AB| = x_1 + x_2 + p$ 是焦半径公式的直接推论：$|AB| = |AF| + |BF| = (x_1 + \frac{p}{2}) + (x_2 + \frac{p}{2}) = x_1 + x_2 + p$。
