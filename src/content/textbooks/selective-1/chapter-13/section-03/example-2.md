**例题：** 已知抛物线 $y^2 = 6x$ 上的点 $P(2, y_0)$，求点 $P$ 到焦点的距离和到准线的距离。

**解答：**

**第1步：** 确定参数
> 📌 运用知识点：抛物线的几何性质

$2p = 6$，$p = 3$，$\dfrac{p}{2} = \dfrac{3}{2}$

焦点 $F\left(\dfrac{3}{2}, 0\right)$，准线 $x = -\dfrac{3}{2}$

**第2步：** 求到焦点的距离
> 📌 运用知识点：抛物线的几何性质

由焦半径公式：$|PF| = x_0 + \dfrac{p}{2} = 2 + \dfrac{3}{2} = \dfrac{7}{2}$

**第3步：** 求到准线的距离
> 📌 运用知识点：抛物线的几何性质

由抛物线定义，点到焦点的距离等于到准线的距离：

$d = |PF| = \dfrac{7}{2}$

验证：$d = x_0 - \left(-\dfrac{3}{2}\right) = 2 + \dfrac{3}{2} = \dfrac{7}{2}$ ✓

**💡 解题思路总结：** 抛物线的核心性质：点到焦点的距离 = 点到准线的距离。对于 $y^2 = 2px$，焦半径 $|PF| = x_0 + \frac{p}{2}$，到准线距离 $d = x_0 + \frac{p}{2}$，两者相等。
