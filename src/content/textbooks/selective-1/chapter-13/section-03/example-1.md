**例题：** 已知抛物线 $y^2 = 2x$ 的焦点为 $F$，过 $F$ 的直线交抛物线于 $A, B$ 两点。若 $|AF| = 2|BF|$，求 $|AB|$。

**解答：**

**第1步：** 确定参数
> 📌 运用知识点：抛物线的定义与标准方程

$2p = 2$，$p = 1$，焦点 $F\left(\dfrac{1}{2}, 0\right)$。

**第2步：** 设焦半径
> 📌 运用知识点：抛物线的几何性质

设 $|BF| = t$，则 $|AF| = 2t$。

$|AB| = |AF| + |BF| = 3t$

由焦半径公式：$|AF| = x_1 + \dfrac{1}{2} = 2t$，$|BF| = x_2 + \dfrac{1}{2} = t$

所以 $x_1 = 2t - \dfrac{1}{2}$，$x_2 = t - \dfrac{1}{2}$。

**第3步：** 利用焦点弦性质 $y_1 y_2 = -p^2$
> 📌 运用知识点：抛物线的几何性质

$y_1^2 = 2x_1 = 2(2t - \frac{1}{2}) = 4t - 1$

$y_2^2 = 2x_2 = 2(t - \frac{1}{2}) = 2t - 1$

$y_1^2 y_2^2 = (4t - 1)(2t - 1) = 8t^2 - 6t + 1$

又 $y_1 y_2 = -p^2 = -1$，所以 $y_1^2 y_2^2 = 1$。

$8t^2 - 6t + 1 = 1$

$8t^2 - 6t = 0$

$2t(4t - 3) = 0$

$t = \dfrac{3}{4}$（$t = 0$ 不合题意）

**第4步：** 求 $|AB|$
> 📌 运用知识点：抛物线的几何性质

$|AB| = 3t = 3 \times \dfrac{3}{4} = \dfrac{9}{4}$
