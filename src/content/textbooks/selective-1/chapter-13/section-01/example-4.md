**例题：** 已知椭圆 $\dfrac{x^2}{4} + y^2 = 1$，直线 $l$ 过点 $P(0, 1)$ 与椭圆交于 $A, B$ 两点，且 $|AB| = \dfrac{4\sqrt{2}}{3}$，求直线 $l$ 的方程。

**解答：**

**第1步：** 设直线方程
> 📌 运用知识点：直线与圆锥曲线的位置关系

$P(0, 1)$ 在椭圆上（代入验证 $\frac{0}{4} + 1 = 1$），所以 $P$ 是一个交点。

设 $l: y = kx + 1$，代入 $\dfrac{x^2}{4} + y^2 = 1$：

$\dfrac{x^2}{4} + (kx + 1)^2 = 1$

$\left(\dfrac{1}{4} + k^2\right)x^2 + 2kx = 0$

$x\left[\left(\dfrac{1}{4} + k^2\right)x + 2k\right] = 0$

**第2步：** 求另一交点
> 📌 运用知识点：直线与圆锥曲线的位置关系

$x_1 = 0$（对应 $P$），$x_2 = \dfrac{-2k}{\frac{1}{4} + k^2} = \dfrac{-8k}{1 + 4k^2}$

$y_2 = kx_2 + 1 = \dfrac{-8k^2}{1 + 4k^2} + 1 = \dfrac{1 - 4k^2}{1 + 4k^2}$

**第3步：** 利用弦长条件
> 📌 运用知识点：直线与圆锥曲线的位置关系

$|AB|^2 = x_2^2 + (y_2 - 1)^2 = x_2^2 + k^2 x_2^2 = (1 + k^2)x_2^2$

$= (1 + k^2) \cdot \dfrac{64k^2}{(1 + 4k^2)^2} = \dfrac{64k^2(1 + k^2)}{(1 + 4k^2)^2}$

$|AB| = \dfrac{8|k|\sqrt{1 + k^2}}{1 + 4k^2} = \dfrac{4\sqrt{2}}{3}$

$\dfrac{64k^2(1 + k^2)}{(1 + 4k^2)^2} = \dfrac{32}{9}$

$9 \times 64k^2(1 + k^2) = 32(1 + 4k^2)^2$

$576k^2 + 576k^4 = 32(1 + 8k^2 + 16k^4)$

$576k^2 + 576k^4 = 32 + 256k^2 + 512k^4$

$64k^4 + 320k^2 - 32 = 0$

$2k^4 + 10k^2 - 1 = 0$

$k^2 = \dfrac{-10 + \sqrt{100 + 8}}{4} = \dfrac{-10 + \sqrt{108}}{4} = \dfrac{-10 + 6\sqrt{3}}{4} = \dfrac{-5 + 3\sqrt{3}}{2}$

$k = \pm\sqrt{\dfrac{3\sqrt{3} - 5}{2}}$

直线 $l$ 的方程为 $y = \pm\sqrt{\dfrac{3\sqrt{3} - 5}{2}} \cdot x + 1$

**💡 解题思路总结：** 已知点和弦长求直线方程：① 判断已知点是否在曲线上；② 联立求交点；③ 用弦长公式建立关于斜率的方程。注意斜率不存在的情况需单独讨论。
