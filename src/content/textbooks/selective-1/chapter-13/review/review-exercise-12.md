**题目：** 过抛物线 $y^2 = 4x$ 的焦点作一条直线与抛物线交于 $A, B$ 两点，若 $|AB| = 8$，求直线 $AB$ 的方程。

---

**解答：**

**第1步：** 确定焦点
> 📌 运用知识点：抛物线的几何性质

$2p = 4$，$p = 2$。焦点 $F(1, 0)$。

**第2步：** 设直线方程
> 📌 运用知识点：抛物线的定义

设直线 $AB: x = my + 1$（过焦点，设 $x = my + 1$ 避免斜率不存在的讨论）。

代入 $y^2 = 4x$：$y^2 = 4(my + 1)$，$y^2 - 4my - 4 = 0$。

$y_1 + y_2 = 4m$，$y_1 y_2 = -4$。

**第3步：** 利用弦长条件
> 📌 运用知识点：抛物线的几何性质

$$|AB| = x_1 + x_2 + p = (my_1 + 1) + (my_2 + 1) + 2 = m(y_1 + y_2) + 4 = 4m^2 + 4$$

$4m^2 + 4 = 8$，$m^2 = 1$，$m = \pm 1$。

直线方程：$x = y + 1$ 或 $x = -y + 1$，即 $x - y - 1 = 0$ 或 $x + y - 1 = 0$。

**⚠️ 易错提醒：** 抛物线焦点弦长 $|AB| = x_1 + x_2 + p$。设直线为 $x = my + 1$ 可以包含斜率不存在的情况。

**💡 解题思路总结：** 焦点弦问题：设直线 $x = my + \frac{p}{2}$ → 代入抛物线方程 → 韦达定理 → 弦长公式。
