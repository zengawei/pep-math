**题目：** 已知双曲线 $x^2 - \dfrac{y^2}{3} = 1$，直线 $l$ 过右焦点 $F$ 与双曲线右支交于 $A, B$ 两点，且 $|AB| = 6$，求直线 $l$ 的方程。

---

**解答：**

**第1步：** 确定基本量
> 📌 运用知识点：双曲线的几何性质

$a^2 = 1$，$b^2 = 3$，$c^2 = 4$，$a = 1$，$c = 2$

右焦点 $F(2, 0)$

**第2步：** 设直线方程
> 📌 运用知识点：直线与圆锥曲线的位置关系

设 $l: x = my + 2$（包含斜率不存在的情况）。

代入 $x^2 - \dfrac{y^2}{3} = 1$：

$(my + 2)^2 - \dfrac{y^2}{3} = 1$

$m^2y^2 + 4my + 4 - \dfrac{y^2}{3} = 1$

$\left(m^2 - \dfrac{1}{3}\right)y^2 + 4my + 3 = 0$

$(3m^2 - 1)y^2 + 12my + 9 = 0$

**第3步：** 利用韦达定理和弦长
> 📌 运用知识点：直线与圆锥曲线的位置关系

$y_1 + y_2 = \dfrac{-12m}{3m^2 - 1}$，$y_1 y_2 = \dfrac{9}{3m^2 - 1}$

需要 $3m^2 - 1 \neq 0$，且 $A, B$ 在右支上要求 $x_1, x_2 > 0$。

$|y_1 - y_2|^2 = (y_1+y_2)^2 - 4y_1y_2 = \dfrac{144m^2}{(3m^2-1)^2} - \dfrac{36}{3m^2-1} = \dfrac{144m^2 - 36(3m^2-1)}{(3m^2-1)^2} = \dfrac{36m^2 + 36}{(3m^2-1)^2} = \dfrac{36(m^2+1)}{(3m^2-1)^2}$

$|AB| = \sqrt{1+m^2} \cdot |y_1 - y_2| = \sqrt{1+m^2} \cdot \dfrac{6\sqrt{m^2+1}}{|3m^2-1|} = \dfrac{6(m^2+1)}{|3m^2-1|}$

**第4步：** 解方程
> 📌 运用知识点：直线与圆锥曲线的位置关系

$\dfrac{6(m^2+1)}{|3m^2-1|} = 6$

$m^2 + 1 = |3m^2 - 1|$

情况一：$3m^2 - 1 > 0$（$m^2 > \frac{1}{3}$）

$m^2 + 1 = 3m^2 - 1$，$2m^2 = 2$，$m^2 = 1$，$m = \pm 1$

验证：$3(1) - 1 = 2 > 0$ ✓

情况二：$3m^2 - 1 < 0$（$m^2 < \frac{1}{3}$）

$m^2 + 1 = 1 - 3m^2$，$4m^2 = 0$，$m = 0$

验证：$m = 0$ 时直线 $x = 2$，代入双曲线 $4 - \frac{y^2}{3} = 1$，$y^2 = 9$，$y = \pm 3$

$|AB| = 6$ ✓，但 $A(2, 3)$，$B(2, -3)$ 都在右支上 ✓

当 $m = \pm 1$ 时，直线 $x = \pm y + 2$，即 $y = \pm(x - 2)$

验证 $m = 1$：$2y^2 + 12y + 9 = 0$，$y = \dfrac{-12 \pm \sqrt{144-72}}{4} = \dfrac{-12 \pm 6\sqrt{2}}{4}$

$y_1 y_2 = \frac{9}{2} > 0$，$y_1 + y_2 = -6 < 0$，两根同号且为负。

$x_i = y_i + 2$，$x_1 x_2 = (y_1+2)(y_2+2) = y_1y_2 + 2(y_1+y_2) + 4 = \frac{9}{2} - 12 + 4 = -\frac{7}{2} < 0$

说明一个交点在左支，不满足"右支交于两点"，舍去。

$m = 0$ 时直线方程为 $x = 2$。

**⚠️ 易错提醒：** ① 直线与双曲线右支交于两点，需要验证 $x_1, x_2 > 0$；② 设 $x = my + 2$ 可包含斜率不存在的情况；③ 解出 $m$ 后要回代验证。

**💡 解题思路总结：** 双曲线焦点弦问题：设直线 → 联立方程 → 韦达定理 → 弦长公式 → 解方程 → 验证交点位置。
