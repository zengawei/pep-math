**例题：** 已知双曲线 $\dfrac{x^2}{9} - \dfrac{y^2}{16} = 1$，$P$ 在双曲线右支上，$F_1$ 为左焦点，求 $|PF_1|$ 的取值范围。

**解答：**

**第1步：** 确定基本量
> 📌 运用知识点：双曲线的几何性质

$a^2 = 9$，$b^2 = 16$，$c^2 = 25$

$a = 3$，$c = 5$，$e = \dfrac{5}{3}$

**第2步：** 利用焦半径公式
> 📌 运用知识点：双曲线的几何性质

设 $P(x_0, y_0)$ 在右支上，$x_0 \geqslant a = 3$

左焦半径：$|PF_1| = a + ex_0 = 3 + \dfrac{5}{3}x_0$

**第3步：** 求范围
> 📌 运用知识点：双曲线的几何性质

当 $x_0 = 3$（右顶点）时：$|PF_1|_{\min} = 3 + 5 = 8$

$x_0 \to +\infty$ 时 $|PF_1| \to +\infty$

$|PF_1|$ 的取值范围为 $[8, +\infty)$

**💡 解题思路总结：** 双曲线右支上的点到左焦点的距离：$|PF_1| = a + ex_0 \geqslant a + ea = a + c$。最小值在右顶点取到，为 $a + c$。注意与椭圆的区别：椭圆有最大值，双曲线没有。
