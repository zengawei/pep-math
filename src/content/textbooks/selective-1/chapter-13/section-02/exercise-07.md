**题目：** 已知双曲线 $\dfrac{x^2}{9} - \dfrac{y^2}{16} = 1$，求右焦点到一条渐近线的距离。

---

**解答：**

**第1步：** 确定基本量
> 📌 运用知识点：双曲线的几何性质

$a^2 = 9$，$b^2 = 16$，$c^2 = a^2 + b^2 = 25$

$a = 3$，$b = 4$，$c = 5$

右焦点 $F(5, 0)$

**第2步：** 写出渐近线方程
> 📌 运用知识点：双曲线的几何性质

渐近线：$y = \pm\dfrac{4}{3}x$，即 $4x - 3y = 0$ 或 $4x + 3y = 0$

**第3步：** 求距离
> 📌 运用知识点：双曲线的几何性质

取渐近线 $4x - 3y = 0$，右焦点 $F(5, 0)$ 到它的距离：

$d = \dfrac{|4 \times 5 - 3 \times 0|}{\sqrt{4^2 + 3^2}} = \dfrac{20}{\sqrt{25}} = \dfrac{20}{5} = 4$

（取另一条渐近线 $4x + 3y = 0$，距离 $d = \dfrac{|20|}{5} = 4$，结果相同。）

**⚠️ 易错提醒：** 右焦点到两条渐近线的距离相等（由对称性），计算时点到直线距离公式中分母是 $\sqrt{A^2 + B^2}$，不要忘记开根号。

**💡 解题思路总结：** 焦点到渐近线的距离 $d = \dfrac{bc}{c} = b$（对于标准双曲线）。本题 $b = 4$，可直接验证。这是一个有用的结论。
