**题目：** 已知函数 $f(x) = x^3 + ax^2 + bx + c$ 有两个极值点 $x_1, x_2$，且 $x_1 + x_2 = 4$，$x_1 \cdot x_2 = 3$，求 $a, b$ 的值以及 $f(x)$ 的极值之差 $|f(x_1) - f(x_2)|$。

---

**解答：**

**第1步：** 利用极值点条件求 $a, b$
> 📌 运用知识点：导数与极值

$f'(x) = 3x^2 + 2ax + b$

$x_1, x_2$ 是 $f'(x) = 0$ 的两个根，由韦达定理：

$$x_1 + x_2 = -\frac{2a}{3} = 4 \implies a = -6$$

$$x_1 \cdot x_2 = \frac{b}{3} = 3 \implies b = 9$$

**第2步：** 确定极值点
> 📌 运用知识点：导数与极值

$f'(x) = 3x^2 - 12x + 9 = 3(x - 1)(x - 3)$

极值点为 $x_1 = 1$，$x_2 = 3$。

验证：$x_1 + x_2 = 4$ ✓，$x_1 \cdot x_2 = 3$ ✓

**第3步：** 求 $f(x_1)$ 和 $f(x_2)$
> 📌 运用知识点：导数与极值

$f(x) = x^3 - 6x^2 + 9x + c$

$f(1) = 1 - 6 + 9 + c = 4 + c$

$f(3) = 27 - 54 + 27 + c = c$

**第4步：** 求极值之差
> 📌 运用知识点：导数与极值

$$|f(x_1) - f(x_2)| = |f(1) - f(3)| = |(4 + c) - c| = |4| = 4$$

$$\boxed{a = -6, \quad b = 9, \quad |f(x_1) - f(x_2)| = 4}$$

**⚠️ 易错提醒：** 韦达定理中 $3x^2 + 2ax + b = 0$ 的系数要对应准确：两根之和为 $-\frac{2a}{3}$（不是 $-\frac{a}{3}$），两根之积为 $\frac{b}{3}$（不是 $\frac{b}{1}$）。极值之差中 $c$ 被消去，说明极值之差与 $c$ 无关。

**💡 解题思路总结：** 已知极值点的和与积，利用韦达定理反求参数是经典方法。求极值之差时，$c$ 作为常数项会被消去，这是此类问题的特点。最后一定要验证判别式 $\Delta > 0$ 确保有两个不等实根。
