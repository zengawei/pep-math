**题目：** 已知函数 $f(x) = x^3 - 3x + a$ 在区间 $[-3, 0]$ 上的最大值为 $10$，求 $a$ 的值及函数在该区间上的最小值。

---

**解答：**

**第1步：** 求导并确定极值点
> 📌 运用知识点：导数与极值

对 $f(x)$ 求导：

$$f'(x) = 3x^2 - 3 = 3(x+1)(x-1)$$

令 $f'(x) = 0$，得 $x = -1$ 或 $x = 1$。

在区间 $[-3, 0]$ 内，只有 $x = -1$ 是驻点。

**第2步：** 比较端点值和极值
> 📌 运用知识点：闭区间上最值的求法

计算 $f(x)$ 在端点和驻点的值：

$$f(-3) = -27 + 9 + a = -18 + a$$

$$f(-1) = -1 + 3 + a = 2 + a$$

$$f(0) = a$$

因为 $2 + a > a > -18 + a$，所以 $f(x)$ 在 $[-3, 0]$ 上的最大值为 $f(-1) = 2 + a$。

**第3步：** 由最大值求 $a$ 并求最小值
> 📌 运用知识点：闭区间上最值

由题意 $2 + a = 10$，解得 $a = 8$。

此时最小值为 $f(-3) = -18 + 8 = -10$。

所以 $a = 8$，函数在 $[-3, 0]$ 上的最小值为 $-10$。

**⚠️ 易错提醒：** ①闭区间上的最值需要比较所有端点值和极值，不能只比较极值；②$[-3, 0]$ 内的驻点只有 $x = -1$（$x = 1$ 不在区间内），不要把区间外的驻点纳入比较。

**💡 解题思路总结：** 闭区间上求最值的步骤：①求导找驻点 → ②筛选区间内的驻点 → ③计算端点值和区间内驻点的函数值 → ④比较得出最大值和最小值。含参时先通过大小关系确定哪个是最大值（或最小值），再由已知条件求参数。
