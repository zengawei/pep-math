**题目：** 已知函数 $f(x) = x^3 + ax^2 + bx + 1$ 在 $x = 1$ 处取得极大值 $3$，求 $a$，$b$ 的值。

---

**解答：**

**第1步：** 利用极值条件建立方程组
> 📌 运用知识点：导数与极值

$f(x)$ 在 $x = 1$ 处取得极大值，则必须满足两个条件：
- $f'(1) = 0$（极值点处导数为零）
- $f(1) = 3$（极大值为 $3$）

先求导数：
$$f'(x) = 3x^2 + 2ax + b$$

由 $f'(1) = 0$：
$$3 + 2a + b = 0 \quad \cdots (1)$$

由 $f(1) = 3$：
$$1 + a + b + 1 = 3$$
$$a + b = 1 \quad \cdots (2)$$

**第2步：** 解方程组
> 📌 运用知识点：导数与极值

由 $(1)$：$2a + b = -3$

由 $(2)$：$a + b = 1$

两式相减：$(2a + b) - (a + b) = -3 - 1$，得 $a = -4$。

代入 $(2)$：$-4 + b = 1$，得 $b = 5$。

**第3步：** 验证
> 📌 运用知识点：导数与极值

当 $a = -4$，$b = 5$ 时：
$$f'(x) = 3x^2 - 8x + 5 = (3x - 5)(x - 1)$$

令 $f'(x) = 0$，得 $x = 1$ 或 $x = \dfrac{5}{3}$。

当 $x < 1$ 时 $f'(x) > 0$，当 $1 < x < \dfrac{5}{3}$ 时 $f'(x) < 0$，导数由正变负，确认 $x = 1$ 是极大值点。✓

所以 $a = -4$，$b = 5$。

**⚠️ 易错提醒：** ①求出 $a, b$ 后必须验证！$f'(x_0)=0$ 只是极值的必要条件，还需确认导数在 $x_0$ 两侧变号；②建立方程组时不要混淆 $f(1)=3$ 和 $f'(1)=0$ 两个条件；③解方程组时注意正负号运算。

**💡 解题思路总结：** 已知极值点和极值求参数，利用两个条件列方程组：①极值点处 $f'(x_0)=0$；②极值 $f(x_0)=$ 已知值。求出参数后一定要验证该点确实是极值点（导数变号）。
