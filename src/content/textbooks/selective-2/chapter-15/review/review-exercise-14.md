**题目：** 求函数 $f(x) = x^3 - 3x + 1$ 在区间 $[-2, 2]$ 上的最大值和最小值。

---

**解答：**

**第1步：** 求导数，找出区间内的驻点
> 📌 运用知识点：导数与最值

$$f'(x) = 3x^2 - 3 = 3(x+1)(x-1)$$

令 $f'(x) = 0$，得 $x = -1$ 或 $x = 1$。

两个驻点都在区间 $[-2, 2]$ 内。

**第2步：** 比较驻点和端点的函数值
> 📌 运用知识点：导数与最值

闭区间上连续函数的最值，需要比较所有驻点和端点的函数值：

$$f(-2) = (-2)^3 - 3 \times (-2) + 1 = -8 + 6 + 1 = -1$$

$$f(-1) = (-1)^3 - 3 \times (-1) + 1 = -1 + 3 + 1 = 3$$

$$f(1) = 1^3 - 3 \times 1 + 1 = 1 - 3 + 1 = -1$$

$$f(2) = 2^3 - 3 \times 2 + 1 = 8 - 6 + 1 = 3$$

**第3步：** 确定最大值和最小值
> 📌 运用知识点：导数与最值

比较四个函数值：$f(-2) = -1$，$f(-1) = 3$，$f(1) = -1$，$f(2) = 3$。

最大值为 $f(-1) = f(2) = 3$；

最小值为 $f(-2) = f(1) = -1$。

**⚠️ 易错提醒：** ①闭区间上的最值必须比较端点值和极值，不能只看驻点；②最大值和最小值可能同时在多个点取到（本题最大值为 $3$，在 $x=-1$ 和 $x=2$ 处同时取到）；③计算 $f(-2)$ 时 $(-2)^3 = -8$，不要算成 $8$。

**💡 解题思路总结：** 求闭区间上函数最值的步骤：①求 $f'(x)$，找区间内的驻点；②计算所有驻点和端点的函数值；③最大的是最大值，最小的是最小值。注意端点值不能遗漏。
