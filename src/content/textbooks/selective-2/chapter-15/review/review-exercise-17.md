**题目：** 已知函数 $f(x) = x^3 - 3x^2 + 2$。

（1）求 $f(x)$ 的极值；

（2）求 $f(x)$ 在区间 $[-1, 3]$ 上的最大值和最小值。

---

**解答：**

**第1步：** 求导数并找驻点
> 📌 运用知识点：导数与极值

$$f'(x) = 3x^2 - 6x = 3x(x - 2)$$

令 $f'(x) = 0$，得 $x = 0$ 或 $x = 2$。

**第2步：** 判断极值
> 📌 运用知识点：导数与极值

列表分析：

| 区间 | $(-\infty, 0)$ | $x=0$ | $(0, 2)$ | $x=2$ | $(2, +\infty)$ |
|------|:---:|:---:|:---:|:---:|:---:|
| $f'(x)$ | $+$ | $0$ | $-$ | $0$ | $+$ |
| $f(x)$ | ↗ | 极大值 | ↘ | 极小值 | ↗ |

极大值：$f(0) = 0 - 0 + 2 = 2$

极小值：$f(2) = 8 - 12 + 2 = -2$

所以 $f(x)$ 的极大值为 $2$（在 $x=0$ 处取得），极小值为 $-2$（在 $x=2$ 处取得）。

**第3步：** 求闭区间 $[-1, 3]$ 上的最值
> 📌 运用知识点：导数与最值

区间 $[-1, 3]$ 内的驻点为 $x = 0$ 和 $x = 2$，需要比较驻点和端点的函数值：

$$f(-1) = (-1)^3 - 3 \times (-1)^2 + 2 = -1 - 3 + 2 = -2$$

$$f(0) = 2$$

$$f(2) = -2$$

$$f(3) = 3^3 - 3 \times 3^2 + 2 = 27 - 27 + 2 = 2$$

比较得：
- 最大值为 $f(0) = f(3) = 2$；
- 最小值为 $f(-1) = f(2) = -2$。

**⚠️ 易错提醒：** ①第（2）问不能只比较极值，必须同时比较端点值 $f(-1)$ 和 $f(3)$；②$f(3) = 27 - 27 + 2 = 2$，计算时 $3^3 = 27$ 和 $3 \times 3^2 = 27$ 不要算错；③极值和最值是不同的概念——极值是局部性质，最值是全局性质。

**💡 解题思路总结：** 极值和最值的综合题是高考常见题型。第（1）问用标准方法求极值（列表判断导数变号）；第（2）问在闭区间上比较所有驻点和端点的函数值，取最大和最小。注意端点值不可遗漏。
