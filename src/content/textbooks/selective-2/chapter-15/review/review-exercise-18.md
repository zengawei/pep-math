**题目：** 已知函数 $f(x) = x^3 + ax^2 + bx + 2$ 在 $x = -1$ 处取得极值 $6$。

（1）求 $a$，$b$ 的值；

（2）求 $f(x)$ 在区间 $[-2, 2]$ 上的最大值和最小值。

---

**解答：**

**第1步：** 利用极值条件求 $a$，$b$
> 📌 运用知识点：导数与极值

$$f'(x) = 3x^2 + 2ax + b$$

由 $f'(-1) = 0$：
$$3 - 2a + b = 0 \quad \cdots (1)$$

由 $f(-1) = 6$：
$$-1 + a - b + 2 = 6$$
$$a - b = 5 \quad \cdots (2)$$

**第2步：** 解方程组
> 📌 运用知识点：导数与极值

由 $(1)$：$b = 2a - 3$

代入 $(2)$：$a - (2a - 3) = 5$

$$a - 2a + 3 = 5 \implies -a = 2 \implies a = -2$$

$$b = 2 \times (-2) - 3 = -7$$

**第3步：** 验证极值
> 📌 运用知识点：导数与极值

当 $a = -2$，$b = -7$ 时：
$$f(x) = x^3 - 2x^2 - 7x + 2$$
$$f'(x) = 3x^2 - 4x - 7 = (3x - 7)(x + 1)$$

令 $f'(x) = 0$，得 $x = -1$ 或 $x = \dfrac{7}{3}$。

当 $x < -1$ 时 $f'(x) > 0$，当 $-1 < x < \dfrac{7}{3}$ 时 $f'(x) < 0$，导数由正变负，$x = -1$ 确实是极大值点。✓

所以 $a = -2$，$b = -7$。

**第4步：** 求 $[-2, 2]$ 上的最值
> 📌 运用知识点：导数与最值

在区间 $[-2, 2]$ 内，驻点为 $x = -1$（$x = \dfrac{7}{3} \approx 2.33 > 2$，不在区间内）。

比较驻点和端点的函数值：

$$f(-2) = (-2)^3 - 2 \times (-2)^2 - 7 \times (-2) + 2 = -8 - 8 + 14 + 2 = 0$$

$$f(-1) = (-1)^3 - 2 \times (-1)^2 - 7 \times (-1) + 2 = -1 - 2 + 7 + 2 = 6$$

$$f(2) = 2^3 - 2 \times 2^2 - 7 \times 2 + 2 = 8 - 8 - 14 + 2 = -12$$

比较得：
- 最大值为 $f(-1) = 6$；
- 最小值为 $f(2) = -12$。

**⚠️ 易错提醒：** ①求出 $a, b$ 后必须验证极值条件（导数变号），不能省略验证步骤；②第（2）问中 $x = \frac{7}{3} > 2$，不在区间 $[-2, 2]$ 内，不能参与比较——这是最容易犯的错误；③计算 $f(-2)$ 和 $f(2)$ 时涉及多项代入，注意每一项的正负号。

**💡 解题思路总结：** 本题是极值与最值的综合题。第（1）问利用极值点和极值两个条件列方程组求参数，求出后必须验证；第（2）问求闭区间上的最值时，只比较区间内的驻点和端点的函数值，区间外的驻点不参与比较。审题时务必注意区间的范围。
