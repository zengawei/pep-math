**题目：** 已知函数 $f(x) = x^3 + ax^2 + bx + 2$ 在 $x = 1$ 处取得极大值 $5$，求 $a$，$b$ 的值。

---

**解答：**

**第1步：** 利用极值条件列方程
> 📌 运用知识点：极值点处导数为零

因为 $f(x)$ 在 $x = 1$ 处取得极大值，所以 $f'(1) = 0$ 且 $f(1) = 5$。

对 $f(x)$ 求导：

$$f'(x) = 3x^2 + 2ax + b$$

由 $f'(1) = 0$：

$$3 + 2a + b = 0 \quad \cdots (1)$$

由 $f(1) = 5$：

$$1 + a + b + 2 = 5 \implies a + b = 2 \quad \cdots (2)$$

**第2步：** 解方程组并验证
> 📌 运用知识点：极值的判定

联立 $(1)$ 和 $(2)$：

由 $(1)$：$2a + b = -3$

由 $(2)$：$a + b = 2$

两式相减得 $a = -5$，代入 $(2)$ 得 $b = 7$。

**验证：** 当 $a = -5$，$b = 7$ 时，$f'(x) = 3x^2 - 10x + 7 = (3x - 7)(x - 1)$。

- 当 $x < 1$ 时，$f'(x) > 0$；
- 当 $1 < x < \frac{7}{3}$ 时，$f'(x) < 0$。

导数在 $x = 1$ 两侧由正变负，$x = 1$ 确实是极大值点。✓

所以 $a = -5$，$b = 7$。

**⚠️ 易错提醒：** 求出 $a, b$ 后必须验证！$f'(x_0) = 0$ 只是极值的必要条件，还需验证导数在 $x_0$ 两侧变号。如果导数不变号（如 $f'(x) = 3(x-1)^2$），则该点不是极值点。

**💡 解题思路总结：** 已知极值点求参数的问题，核心是利用两个条件：①极值点处导数为零 $f'(x_0) = 0$；②函数值等于极值 $f(x_0) = y_0$。列方程组求解后，务必回代验证极值的充分性（导数变号）。
