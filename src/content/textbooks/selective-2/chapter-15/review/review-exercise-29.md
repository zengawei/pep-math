**题目：** 已知函数 $f(x) = x^3 - 3ax^2 + 3x + 1$ 有三个零点，求实数 $a$ 的取值范围。

---

**解答：**

**第1步：** 分析有三个零点的条件
> 📌 运用知识点：导数与单调性

$f(x)$ 有三个零点，即 $f(x) = 0$ 有三个不同的实数根。

对 $f(x)$ 求导：

$$f'(x) = 3x^2 - 6ax + 3 = 3(x^2 - 2ax + 1)$$

$f(x)$ 有三个零点的必要条件是 $f(x)$ 有两个极值点，即 $f'(x) = 0$ 有两个不同的实根。

判别式 $\Delta = 4a^2 - 4 > 0$，即 $a^2 > 1$，所以 $a > 1$ 或 $a < -1$。

**第2步：** 求极值并建立不等式
> 📌 运用知识点：极值与零点的关系

设 $f'(x) = 0$ 的两个根为 $x_1, x_2$（$x_1 < x_2$），由韦达定理：

$$x_1 + x_2 = 2a, \quad x_1 x_2 = 1$$

$f(x)$ 有三个零点等价于极大值 $f(x_1) > 0$ 且极小值 $f(x_2) < 0$。

由 $f'(x_i) = 0$ 知 $x_i^2 - 2ax_i + 1 = 0$，即 $x_i^2 = 2ax_i - 1$。

利用降次法求 $f(x_i)$：

$$f(x_i) = x_i^3 - 3ax_i^2 + 3x_i + 1$$

$x_i^3 = x_i \cdot x_i^2 = x_i(2ax_i - 1) = 2ax_i^2 - x_i = 2a(2ax_i - 1) - x_i = 4a^2x_i - 2a - x_i$

$$f(x_i) = (4a^2x_i - 2a - x_i) - 3a(2ax_i - 1) + 3x_i + 1 = 4a^2x_i - 2a - x_i - 6a^2x_i + 3a + 3x_i + 1$$

$$= (4a^2 - 6a^2)x_i + (-2a + 3a) + (-x_i + 3x_i) + 1 = -2a^2x_i + a + 2x_i + 1$$

$$= (2 - 2a^2)x_i + a + 1$$

所以：

$$f(x_1) = (2 - 2a^2)x_1 + a + 1 > 0 \quad \cdots (1)$$

$$f(x_2) = (2 - 2a^2)x_2 + a + 1 < 0 \quad \cdots (2)$$

**第3步：** 求解 $a$ 的范围
> 📌 运用知识点：含参零点问题

当 $a > 1$ 时，$2 - 2a^2 < 0$，又 $x_1 < x_2$，所以 $(2-2a^2)x_1 > (2-2a^2)x_2$，即 $f(x_1) > f(x_2)$，符合极大值大于极小值。

需要 $f(x_1) > 0$ 且 $f(x_2) < 0$，即：

$$f(x_1) \cdot f(x_2) < 0$$

$$[(2-2a^2)x_1 + a + 1][(2-2a^2)x_2 + a + 1] < 0$$

展开并利用韦达定理 $x_1 + x_2 = 2a$，$x_1 x_2 = 1$：

$$(2-2a^2)^2 x_1 x_2 + (2-2a^2)(a+1)(x_1+x_2) + (a+1)^2 < 0$$

$$(2-2a^2)^2 + (2-2a^2)(a+1)(2a) + (a+1)^2 < 0$$

$$4(1-a^2)^2 + 4a(1-a^2)(a+1) + (a+1)^2 < 0$$

提取公因子，令 $t = a+1$（注意 $a > 1$ 时 $t > 2$）：

$1 - a^2 = (1-a)(1+a) = -(a-1)t$

$$4(a-1)^2 t^2 - 4a(a-1)t^2 + t^2 < 0$$

$$t^2[4(a-1)^2 - 4a(a-1) + 1] < 0$$

因为 $t^2 > 0$，需：

$$4(a-1)^2 - 4a(a-1) + 1 < 0$$

$$4(a^2 - 2a + 1) - 4a^2 + 4a + 1 < 0$$

$$4a^2 - 8a + 4 - 4a^2 + 4a + 1 < 0$$

$$-4a + 5 < 0 \implies a > \frac{5}{4}$$

同理可验证 $a < -1$ 时不满足条件（此时 $f(x_1) < 0$ 且 $f(x_2) > 0$ 矛盾）。

所以 $a$ 的取值范围是 $a > \frac{5}{4}$，即 $\left(\frac{5}{4}, +\infty\right)$。

**⚠️ 易错提醒：** ①三个零点要求极大值 $> 0$ 且极小值 $< 0$，不能只要求有两个极值点（$\Delta > 0$）；②降次化简 $f(x_i)$ 时计算量大，容易出错，建议每步仔细验证；③$a < -1$ 的情况需要单独验证，不能想当然。

**💡 解题思路总结：** 三次函数零点个数问题的标准方法：①求导找极值点 → ②利用极值的正负判断零点个数 → ③极大值 $> 0$ 且极小值 $< 0$ 时有三个零点。降次法是处理高次多项式在驻点处函数值的关键技巧。
