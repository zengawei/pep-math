**题目：** 求函数 $f(x) = x^3 - 3x + 1$ 在 $[-3, 0]$ 上的最大值和最小值。

---

**解答：**

**第1步：** 求导并找驻点
> 📌 运用知识点：导数与最值

$f'(x) = 3x^2 - 3 = 3(x + 1)(x - 1)$

令 $f'(x) = 0$，得 $x = -1$ 或 $x = 1$。

在 $[-3, 0]$ 内的驻点只有 $x = -1$（$x = 1$ 不在区间内，舍去）。

**第2步：** 计算驻点和端点处的函数值
> 📌 运用知识点：导数与最值

$f(-3) = -27 + 9 + 1 = -17$

$f(-1) = -1 + 3 + 1 = 3$

$f(0) = 0 - 0 + 1 = 1$

**第3步：** 比较得出最值
> 📌 运用知识点：导数与最值

比较 $f(-3) = -17$，$f(-1) = 3$，$f(0) = 1$：

最大值为 $f(-1) = 3$，最小值为 $f(-3) = -17$。

**⚠️ 易错提醒：** 驻点 $x = 1$ 不在区间 $[-3, 0]$ 内，必须舍去！这是最常见的错误——不检查驻点是否在给定区间内。计算 $f(-3) = (-3)^3 - 3(-3) + 1 = -27 + 9 + 1 = -17$，注意符号。

**💡 解题思路总结：** 闭区间上求最值时，一定要先检查驻点是否在区间内，只保留区间内的驻点。然后比较区间内驻点和两个端点的函数值，取最大和最小。
