**题目：** 求函数 $f(x) = x^3 - 6x^2 + 9x + 2$ 在 $[0, 4]$ 上的最大值和最小值。

---

**解答：**

**第1步：** 求导并找驻点
> 📌 运用知识点：导数与最值

$f'(x) = 3x^2 - 12x + 9 = 3(x^2 - 4x + 3) = 3(x - 1)(x - 3)$

令 $f'(x) = 0$，得 $x = 1$ 或 $x = 3$，两个驻点都在 $(0, 4)$ 内。

**第2步：** 计算驻点和端点处的函数值
> 📌 运用知识点：导数与最值

$f(0) = 0 - 0 + 0 + 2 = 2$

$f(1) = 1 - 6 + 9 + 2 = 6$

$f(3) = 27 - 54 + 27 + 2 = 2$

$f(4) = 64 - 96 + 36 + 2 = 6$

**第3步：** 比较得出最值
> 📌 运用知识点：导数与最值

比较 $f(0) = 2$，$f(1) = 6$，$f(3) = 2$，$f(4) = 6$：

最大值为 $f(1) = f(4) = 6$，最小值为 $f(0) = f(3) = 2$。

**⚠️ 易错提醒：** 闭区间上求最值，必须同时考虑驻点和端点。不要漏掉端点 $x = 0$ 和 $x = 4$。计算 $f(4) = 64 - 96 + 36 + 2 = 6$ 时注意各项符号。

**💡 解题思路总结：** 闭区间上连续函数求最值的固定步骤：求导→找驻点→算驻点和端点的函数值→比较大小。本题中最大值和最小值各有两个取到点。
