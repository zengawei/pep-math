**题目：** 已知等差数列 $\{a_n\}$ 中，$a_3 + a_4 + a_5 = 12$，$a_6 + a_7 + a_8 = 39$，求 $a_9 + a_{10} + a_{11}$ 的值。

---

**解答：**

**第1步：** 利用等差数列的性质化简已知条件
> 📌 运用知识点：等差数列的等差中项性质

在等差数列中，若三项的下标成等差，则中间项等于首末两项的等差中项。

对于连续三项之和，有：

$$a_3 + a_4 + a_5 = 3a_4 = 12 \implies a_4 = 4$$

$$a_6 + a_7 + a_8 = 3a_7 = 39 \implies a_7 = 13$$

**第2步：** 求公差 $d$ 并计算目标值
> 📌 运用知识点：等差数列通项公式与性质

由 $a_4$ 和 $a_7$ 可求公差：

$$a_7 - a_4 = (7 - 4)d = 3d$$

$$13 - 4 = 3d \implies 3d = 9 \implies d = 3$$

同理，$a_9 + a_{10} + a_{11} = 3a_{10}$。

利用 $a_{10} = a_7 + (10 - 7)d = a_7 + 3d$：

$$a_{10} = 13 + 3 \times 3 = 13 + 9 = 22$$

因此：

$$a_9 + a_{10} + a_{11} = 3a_{10} = 3 \times 22 = 66$$

**另解（利用性质）：** 注意到三组连续三项之和也构成等差数列：

$$a_3 + a_4 + a_5 = 12$$
$$a_6 + a_7 + a_8 = 39$$
$$a_9 + a_{10} + a_{11} = ?$$

设 $T_1 = 12$，$T_2 = 39$，$T_3 = ?$。由于 $T_1, T_2, T_3$ 分别是第 $4, 7, 10$ 项的 $3$ 倍，而下标 $4, 7, 10$ 成等差，所以 $T_1, T_2, T_3$ 也成等差：

$$T_3 = 2T_2 - T_1 = 2 \times 39 - 12 = 78 - 12 = 66$$

$$\boxed{a_9 + a_{10} + a_{11} = 66}$$

**⚠️ 易错提醒：** 使用"连续三项之和等于中间项的 $3$ 倍"这一性质时，要确认三项的下标确实是连续的。另外，不要误以为 $a_9 + a_{10} + a_{11}$ 与前面的和之间没有规律，实际上每组连续三项之和本身也构成等差数列。

**💡 解题思路总结：** 本题的核心是等差数列的性质：连续三项之和等于中间项的 $3$ 倍。利用这一性质将已知条件化简为求中间项，再通过公差建立联系。另一种更巧妙的方法是发现"等距连续三项之和"也构成等差数列，直接利用等差中项求解。
