**例题：** 在等差数列 $\{a_n\}$ 中，已知 $a_3 = 7$，$a_3, a_5, a_9$ 成等比数列，求公差 $d$。

---

**解答：**

**第1步：** 用 $a_3$ 和 $d$ 表示 $a_5$ 和 $a_9$
> 📌 运用知识点：等差数列通项公式

由等差数列通项公式，将 $a_5$ 和 $a_9$ 用 $a_3$ 和 $d$ 表示：

$$a_5 = a_3 + (5 - 3)d = 7 + 2d$$

$$a_9 = a_3 + (9 - 3)d = 7 + 6d$$

**第2步：** 利用等比数列的条件列方程求解
> 📌 运用知识点：等比中项的性质

$a_3, a_5, a_9$ 成等比数列，由等比中项的性质：

$$a_5^2 = a_3 \cdot a_9$$

代入得：

$$(7 + 2d)^2 = 7 \times (7 + 6d)$$

展开左边：

$$49 + 28d + 4d^2 = 49 + 42d$$

整理：

$$4d^2 + 28d - 42d = 0$$

$$4d^2 - 14d = 0$$

$$2d(2d - 7) = 0$$

解得 $d = 0$ 或 $d = \dfrac{7}{2}$。

**验证：**
- 当 $d = 0$ 时：$a_3 = 7, a_5 = 7, a_9 = 7$，三个 $7$ 构成公比为 $1$ 的等比数列 ✓
- 当 $d = \dfrac{7}{2}$ 时：$a_3 = 7, a_5 = 7 + 7 = 14, a_9 = 7 + 21 = 28$，$14^2 = 196 = 7 \times 28$ ✓

$$\boxed{d = 0 \text{ 或 } d = \dfrac{7}{2}}$$

**💡 解题思路总结：** 本题综合考查等差数列与等比数列。关键步骤是将等差数列的各项统一用 $a_3$ 和 $d$ 表示，再利用等比中项条件 $a_5^2 = a_3 \cdot a_9$ 列方程。注意 $d = 0$ 也是合法解（常数列也构成等比数列，公比为 $1$），不要遗漏。
