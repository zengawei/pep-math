**例题：** 在等差数列 $\{a_n\}$ 中，$a_1 + a_3 + a_5 = 15$，$a_2 + a_4 + a_6 = 27$，求 $a_5 + a_7 + a_9$ 的值。

---

**解答：**

**第1步：** 利用等差数列性质化简已知条件
> 📌 运用知识点：等差数列的性质

在等差数列中，若下标成等差，则对应项之和可以用中间项表示。

对于 $a_1 + a_3 + a_5$，下标 $1, 3, 5$ 的中间值为 $3$，因此：

$$a_1 + a_3 + a_5 = 3a_3 = 15 \implies a_3 = 5$$

对于 $a_2 + a_4 + a_6$，下标 $2, 4, 6$ 的中间值为 $4$，因此：

$$a_2 + a_4 + a_6 = 3a_4 = 27 \implies a_4 = 9$$

**第2步：** 求公差 $d$
> 📌 运用知识点：等差数列通项公式

$$d = a_4 - a_3 = 9 - 5 = 4$$

**第3步：** 求 $a_5 + a_7 + a_9$
> 📌 运用知识点：等差数列的性质

同理，$a_5 + a_7 + a_9 = 3a_7$。

由通项公式：

$$a_7 = a_3 + (7 - 3)d = 5 + 4 \times 4 = 5 + 16 = 21$$

因此：

$$a_5 + a_7 + a_9 = 3a_7 = 3 \times 21 = 63$$

**💡 解题思路总结：** 本题的核心技巧是利用等差数列的对称性质：$a_{k-d} + a_k + a_{k+d} = 3a_k$。将三组项的和分别化为中间项的 $3$ 倍，可以快速求出 $a_3$、$a_4$，进而得到公差和目标值。这种方法比逐项展开计算要简洁得多。

$$\boxed{a_5 + a_7 + a_9 = 63}$$
