**题目：** 在等差数列 $\{a_n\}$ 中，$a_1 = 25$，$S_9 = S_{17}$，求前 $n$ 项和 $S_n$ 的最大值。

---

**解答：**

**第1步：** 利用 $S_9 = S_{17}$ 求公差 $d$
> 📌 运用知识点：等差数列前 $n$ 项和公式

$S_{17} - S_9 = a_{10} + a_{11} + \cdots + a_{17}$，共 $8$ 项。

由 $S_9 = S_{17}$ 知：

$$a_{10} + a_{11} + \cdots + a_{17} = 0$$

这 $8$ 项也构成等差数列，其和为：

$$\dfrac{8(a_{10} + a_{17})}{2} = 0 \implies a_{10} + a_{17} = 0$$

将 $a_{10} = a_1 + 9d = 25 + 9d$，$a_{17} = a_1 + 16d = 25 + 16d$ 代入：

$$(25 + 9d) + (25 + 16d) = 0$$

$$50 + 25d = 0 \implies d = -2$$

**第2步：** 求通项公式并确定最大值位置
> 📌 运用知识点：等差数列前 $n$ 项和的最值

通项公式为：

$$a_n = a_1 + (n-1)d = 25 + (n-1) \times (-2) = 25 - 2n + 2 = 27 - 2n$$

令 $a_n \geq 0$：

$$27 - 2n \geq 0 \implies n \leq 13.5$$

由于 $n \in \mathbb{N}^*$，当 $n \leq 13$ 时 $a_n > 0$，当 $n \geq 14$ 时 $a_n < 0$。

因此 $S_n$ 在 $n = 13$ 时取最大值。

**第3步：** 计算 $S_{13}$
> 📌 运用知识点：等差数列前 $n$ 项和公式

$$S_{13} = 13 \times a_1 + \dfrac{13 \times 12}{2} \times d = 13 \times 25 + 78 \times (-2) = 325 - 156 = 169$$

**⚠️ 易错提醒：** 由 $S_9 = S_{17}$ 求 $d$ 时，要注意 $S_{17} - S_9$ 包含的是 $a_{10}$ 到 $a_{17}$ 共 $8$ 项（不是 $7$ 项），项数计算为 $17 - 9 = 8$。另外，$n \leq 13.5$ 取整数 $n = 13$，而非 $n = 14$。

**💡 解题思路总结：** 本题的关键技巧是利用 $S_m = S_n$（$m \neq n$）的条件。由 $S_{17} - S_9 = 0$ 可以得到中间各项之和为零，进而求出公差。确定 $S_n$ 最大值时，核心思路是找到最后一个非负项的位置。

$$\boxed{S_n \text{ 的最大值为 } 169}$$
