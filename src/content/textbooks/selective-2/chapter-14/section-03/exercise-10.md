**题目：** 已知数列 $\{a_n\}$ 满足 $a_1 = 1$，$a_{n+1} = 2a_n + 1$（$n \in \mathbb{N}^*$）。

(1) 求通项公式 $a_n$；

(2) 求前 $n$ 项和 $S_n$。

---

**解答：**

**第1步：** 构造等比数列求通项公式
> 📌 运用知识点：递推关系转化为等比数列

由 $a_{n+1} = 2a_n + 1$，两边同时加 $1$：

$$a_{n+1} + 1 = 2a_n + 2 = 2(a_n + 1)$$

令 $b_n = a_n + 1$，则 $b_{n+1} = 2b_n$。

又 $b_1 = a_1 + 1 = 1 + 1 = 2$。

所以 $\{b_n\}$ 是以 $b_1 = 2$ 为首项、公比 $q = 2$ 的等比数列：

$$b_n = 2 \cdot 2^{n-1} = 2^n$$

因此：

$$a_n = b_n - 1 = 2^n - 1$$

$$= \boxed{a_n = 2^n - 1}$$

**第2步：** 利用通项公式求前 $n$ 项和
> 📌 运用知识点：分组求和法

$$S_n = \sum_{k=1}^{n} a_k = \sum_{k=1}^{n} (2^k - 1) = \sum_{k=1}^{n} 2^k - \sum_{k=1}^{n} 1$$

**第一部分：** $\displaystyle\sum_{k=1}^{n} 2^k = 2 + 2^2 + 2^3 + \cdots + 2^n$

这是首项为 $2$、公比为 $2$、共 $n$ 项的等比数列：

$$\sum_{k=1}^{n} 2^k = \dfrac{2(2^n - 1)}{2 - 1} = 2^{n+1} - 2$$

**第二部分：** $\displaystyle\sum_{k=1}^{n} 1 = n$

**第3步：** 合并结果
> 📌 运用知识点：分组求和法

$$S_n = (2^{n+1} - 2) - n = 2^{n+1} - n - 2$$

$$= \boxed{S_n = 2^{n+1} - n - 2}$$

**验证：** 当 $n=1$ 时，$S_1 = 4 - 1 - 2 = 1 = a_1$，正确。当 $n=2$ 时，$S_2 = 8 - 2 - 2 = 4$，而 $a_1 + a_2 = 1 + 3 = 4$，正确。当 $n=3$ 时，$S_3 = 16 - 3 - 2 = 11$，而 $a_3 = 2^3 - 1 = 7$，$S_3 = 4 + 7 = 11$，正确。

**⚠️ 易错提醒：** 构造辅助数列时，$a_{n+1} + c = 2(a_n + c)$ 展开后与原式比较，得 $c = 1$，不要算错待定系数。求和时注意 $\sum 2^k$ 的首项是 $2^1 = 2$（不是 $2^0 = 1$），共 $n$ 项。

**💡 解题思路总结：** 对于 $a_{n+1} = pa_n + q$ 型递推关系，通过**待定系数法**构造 $b_n = a_n + c$（其中 $c = \dfrac{q}{p-1}$），将递推转化为等比数列 $b_{n+1} = pb_n$，先求通项再求和。这是递推数列求和的标准流程。
