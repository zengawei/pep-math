**题目：** 某次考试有5道选做题，考生需从中选做3题。但规定：第1题和第2题至少选做1题，第3题和第4题至多选做1题。问共有多少种选题方案？

---

**解答：**

**第1步：** 明确约束条件，确定间接法思路
> 📌 运用知识点：组合、容斥原理

从5题中选3题，无约束时总数为：

$$C_5^3 = 10$$

设条件 $A$：第1题和第2题至少选做1题；

设条件 $B$：第3题和第4题至多选做1题。

用间接法：$N = \text{总数} - |\bar{A}| - |\bar{B}| + |\bar{A} \cap \bar{B}|$

**第2步：** 计算 $|\bar{A}|$ 和 $|\bar{B}|$
> 📌 运用知识点：组合

**$\bar{A}$：第1题和第2题都不选。**

从剩余3题（第3、4、5题）中选3题：$C_3^3 = 1$

**$\bar{B}$：第3题和第4题都选了。**

第3、4题已选，还需从剩余3题（第1、2、5题）中选1题：$C_3^1 = 3$

**第3步：** 计算 $|\bar{A} \cap \bar{B}|$
> 📌 运用知识点：容斥原理

$\bar{A} \cap \bar{B}$：第1、2题都不选，**且** 第3、4题都选。

不选第1、2题，从{3, 4, 5}中选3题，即选{3, 4, 5}。此时第3、4题确实都选了。

$$|\bar{A} \cap \bar{B}| = 1$$

**第4步：** 代入容斥公式
> 📌 运用知识点：容斥原理

$$N = 10 - 1 - 3 + 1 = 7$$

所以共有 $\boxed{7}$ 种选题方案。

**验证（枚举法）：**

列出所有 $C_5^3 = 10$ 种选法并逐一检验：

| 选题 | 条件A（1,2至少1题）| 条件B（3,4至多1题）| 是否满足 |
|------|:---:|:---:|:---:|
| {1,2,3} | ✓ | ✓ | ✓ |
| {1,2,4} | ✓ | ✓ | ✓ |
| {1,2,5} | ✓ | ✓ | ✓ |
| {1,3,4} | ✓ | ✗ | ✗ |
| {1,3,5} | ✓ | ✓ | ✓ |
| {1,4,5} | ✓ | ✓ | ✓ |
| {2,3,4} | ✓ | ✗ | ✗ |
| {2,3,5} | ✓ | ✓ | ✓ |
| {2,4,5} | ✓ | ✓ | ✓ |
| {3,4,5} | ✗ | ✗ | ✗ |

满足条件的恰好有 $7$ 种，与计算结果一致。✓

**⚠️ 易错提醒：** ①"至少"和"至多"类约束通常用间接法处理，但要注意两个约束同时存在时必须用容斥原理，不能分别减去再简单相加；②$|\bar{A} \cap \bar{B}|$ 容易遗漏——当两个约束的"反面"可能同时发生时，必须加回交集部分；③本题数据量小，可以用枚举法验证，考试中建议先算后验。

**💡 解题思路总结：** 多重"至少/至多"约束的组合问题，标准方法是**容斥原理**：总数 - 违反条件A - 违反条件B + 同时违反A和B。当总数不大时，可用枚举法验证结果的正確性。
