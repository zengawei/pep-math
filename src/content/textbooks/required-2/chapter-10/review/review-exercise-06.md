**题目：** 判断下列每对事件是互斥事件还是对立事件：

(1) 掷一枚骰子，$A$ = "出现 $1$ 点"，$B$ = "出现 $2$ 点"；

(2) 掷一枚骰子，$C$ = "出现奇数点"，$D$ = "出现偶数点"。

---

**解答：**

**第1步：** (1) 判断 $A$ 与 $B$
> 📌 运用知识点：随机事件的概率

$A \cap B = \emptyset$（不可能同时出现 $1$ 点和 $2$ 点），$A$ 与 $B$ 互斥。

但 $A \cup B \neq \Omega$（还可能出现 $3, 4, 5, 6$ 点），所以不是对立事件。

**第2步：** (2) 判断 $C$ 与 $D$
> 📌 运用知识点：随机事件的概率

$C \cap D = \emptyset$（不可能同时出现奇数和偶数），$C$ 与 $D$ 互斥。

$C \cup D = \Omega$（一定是奇数或偶数），所以 $C$ 与 $D$ 互为对立事件。

**💡 易错提醒：** 对立事件一定互斥，互斥事件不一定对立。对立要求 $A \cap B = \emptyset$ 且 $A \cup B = \Omega$。

**💡 解题思路总结：** 互斥：$A \cap B = \emptyset$；对立：$A \cap B = \emptyset$ 且 $A \cup B = \Omega$。
