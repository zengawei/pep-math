**例题：** 用一个平面去截正方体 $ABCD\text{-}A_1B_1C_1D_1$，截面过棱 $AB$、$BC$、$CC_1$ 的中点 $E$、$F$、$G$。求截面的形状和面积（设正方体棱长为 $2$）。

---

**解答：**

**第1步：** 确定截面的所有顶点
> 📌 运用知识点：截面的画法

$E$ 是 $AB$ 中点，$F$ 是 $BC$ 中点，$G$ 是 $CC_1$ 中点。

截面与面 $ABCD$ 的交线过 $E$ 和 $F$，延长 $EF$ 交 $AD$ 的延长线于 $P$，交 $CD$ 的延长线于 $Q$。

由于 $E$、$F$ 分别是 $AB$、$BC$ 中点，$EF \parallel AC$。

在面 $DCC_1D_1$ 中，$Q$ 在 $DC$ 延长线上且 $DQ = DC + CQ$。由 $EF$ 的延长线交 $DC$ 延长线于 $Q$，$CQ = 1$（利用相似三角形），$Q$ 在 $DC$ 延长线上距 $C$ 为 $1$。

截面过 $G$（$CC_1$ 中点）和 $Q$，截面与面 $DCC_1D_1$ 的交线交 $DD_1$ 于某点 $H$。

利用比例关系：$H$ 是 $DD_1$ 上距 $D$ 为 $\frac{2}{3} \times 2 = \frac{4}{3}$ 处... 

实际上，由对称性分析，截面是一个**五边形**。

让我重新用坐标法：设 $A$ 为原点，$AB$ 沿 $x$ 轴，$AD$ 沿 $y$ 轴，$AA_1$ 沿 $z$ 轴。

$E = (1, 0, 0)$，$F = (2, 1, 0)$，$G = (2, 2, 1)$。

截面方程：设 $ax + by + cz = d$，代入三点得 $a = d$，$2a + b = d$，$2a + 2b + c = d$。

解得 $b = -a$，$c = a$，$d = a$。取 $a = 1$：$x - y + z = 1$。

**第2步：** 求截面与各棱的交点
> 📌 运用知识点：截面与各面的交线

将各棱端点代入 $x - y + z = 1$：
- $A(0,0,0)$：$0 - 0 + 0 = 0 < 1$
- $B(2,0,0)$：$2 > 1$
- $D(0,2,0)$：$-2 < 1$
- $A_1(0,0,2)$：$2 > 1$
- $D_1(0,2,2)$：$2 > 1$
- $C_1(2,2,2)$：$2 > 1$

截面过 $E(1,0,0)$（在 $AB$ 上）、$F(2,1,0)$（在 $BC$ 上）、$G(2,2,1)$（在 $CC_1$ 上）。

截面还交 $A_1D_1$ 于 $H(0, 1, 2)$（验证：$0 - 1 + 2 = 1$ ✓），交 $AA_1$ 于 $I(0, 0, 1)$（验证：$0 - 0 + 1 = 1$ ✓）。

截面为五边形 $EFGHI$... 实际是五边形 $E\text{-}F\text{-}G\text{-}H\text{-}I$，但需要确认顺序。

截面过 $E(1,0,0)$、$F(2,1,0)$、$G(2,2,1)$、$H(0,1,2)$... 不对，$H$ 在 $A_1D_1$ 上：$A_1 = (0,0,2)$，$D_1 = (0,2,2)$，$H = (0,1,2)$ 确实在 $A_1D_1$ 上。

$I(0,0,1)$ 在 $AA_1$ 上。

截面为五边形 $EFGH'I$，其中 $H'$ 需要重新检查...

截面五边形为 $E(1,0,0) \to F(2,1,0) \to G(2,2,1) \to H(0,1,2) \to I(0,0,1) \to E$。

但 $G$ 到 $H$ 的连线是否在某个面上？$G(2,2,1)$ 在面 $BCC_1B_1$ 和面 $DCC_1D_1$ 的棱 $CC_1$ 上... 不，$G$ 在 $CC_1$ 上。从 $G$ 到 $H$ 的线在面 $DCC_1D_1$ 上？$G(2,2,1)$ 在 $CC_1$ 上，$H(0,1,2)$ 在 $A_1D_1$ 上，它们不在同一个面上。

需要找截面与面 $CDD_1C_1$ 的交线：$G(2,2,1)$ 在棱 $CC_1$ 上，截面与 $CD$ 的延长线交于某点...

让我简化：截面与面 $DCC_1D_1$ 交于 $G$ 和某点。$G(2,2,1)$ 在棱 $CC_1$ 上。截面与 $DD_1$ 的交点：$D(0,2,0)$ 代入得 $-2 < 1$，$D_1(0,2,2)$ 代入得 $0 < 1$。所以截面不交 $DD_1$。

截面与 $C_1D_1$ 的交点：$C_1(2,2,2)$ 代入得 $2 > 1$，$D_1(0,2,2)$ 代入得 $0 < 1$。交点在 $C_1D_1$ 上：$(t, 2, 2)$，$t - 2 + 2 = 1$，$t = 1$。交点 $J(1, 2, 2)$。

截面与 $A_1D_1$ 的交点：$A_1(0,0,2)$ 代入得 $2 > 1$，$D_1(0,2,2)$ 代入得 $0 < 1$。交点 $(0, t, 2)$，$0 - t + 2 = 1$，$t = 1$。即 $H(0, 1, 2)$。

所以截面为五边形 $E(1,0,0) \to F(2,1,0) \to G(2,2,1) \to J(1,2,2) \to H(0,1,2) \to I(0,0,1) \to E$。

这是六边形！

**第3步：** 计算截面面积
> 📌 运用知识点：截面面积的计算

利用向量叉积法，将六边形分成三角形计算。

$\vec{EF} = (1, 1, 0)$，$\vec{EI} = (-1, 0, 1)$

截面法向量 $\vec{n} = (1, -1, 1)$，$|\vec{n}| = \sqrt{3}$。

将六边形投影到 $xy$ 平面上，投影面积 $S_{\text{投影}}$ 与截面面积的关系为 $S = \frac{S_{\text{投影}}}{\cos\theta}$，其中 $\cos\theta = \frac{|\vec{n} \cdot \vec{k}|}{|\vec{n}|} = \frac{1}{\sqrt{3}}$。

投影六边形顶点：$E(1,0)$、$F(2,1)$、$G(2,2)$、$J(1,2)$、$H(0,1)$、$I(0,0)$。

用鞋带公式：$S_{\text{投影}} = \frac{1}{2}|(1 \times 1 - 2 \times 0) + (2 \times 2 - 2 \times 1) + (2 \times 2 - 1 \times 2) + (1 \times 1 - 0 \times 2) + (0 \times 0 - 0 \times 1) + (0 \times 0 - 1 \times 0)|$

$= \frac{1}{2}|1 + 2 + 2 + 1 + 0 + 0| = 3$

$S = \frac{3}{\frac{1}{\sqrt{3}}} = 3\sqrt{3}$

截面是正六边形，面积为 $3\sqrt{3}$。

**💡 方法总结：** 求截面问题的步骤：①建立空间直角坐标系；②确定截面方程；③求截面与各棱的交点；④判断截面形状并计算面积。对于正方体的截面，过三条棱中点的截面是正六边形。
