**题目：** 甲、乙两台机床各生产了 $10$ 个零件，测量尺寸（mm）如下：

甲：$98, 100, 102, 99, 101, 97, 103, 100, 98, 102$

乙：$99, 101, 100, 100, 99, 101, 100, 98, 102, 100$

(1) 分别求两组数据的平均数、中位数和方差；

(2) 求甲组数据的第 $25$ 百分位数；

(3) 若标准尺寸为 $100$ mm，综合考虑平均数和方差，哪台机床生产的零件质量更好？

---

**解答：**

**第1步：** (1) 求甲的平均数、中位数和方差
> 📌 运用知识点：用样本估计总体

$\bar{x}_{\text{甲}} = \frac{98+100+102+99+101+97+103+100+98+102}{10} = \frac{1000}{10} = 100$

甲排序：$97, 98, 98, 99, 100, 100, 101, 102, 102, 103$

中位数 $= \frac{100+100}{2} = 100$

$s^2_{\text{甲}} = \frac{4+0+4+1+1+9+9+0+4+4}{10} = \frac{36}{10} = 3.6$

**第2步：** (1) 求乙的平均数、中位数和方差
> 📌 运用知识点：用样本估计总体

$\bar{x}_{\text{乙}} = \frac{99+101+100+100+99+101+100+98+102+100}{10} = \frac{1000}{10} = 100$

乙排序：$98, 99, 99, 100, 100, 100, 100, 101, 101, 102$

中位数 $= \frac{100+100}{2} = 100$

$s^2_{\text{乙}} = \frac{1+1+0+0+1+1+0+4+4+0}{10} = \frac{12}{10} = 1.2$

**第3步：** (2) 求甲的第 $25$ 百分位数
> 📌 运用知识点：用样本估计总体

$10 \times 25\% = 2.5$，不为整数，向上取整为 $3$。

甲排序第 $3$ 个数据为 $98$。$P_{25} = 98$

**第4步：** (3) 综合判断
> 📌 运用知识点：用样本估计总体

两台机床平均数相同（$100$），都等于标准尺寸。

$s^2_{\text{乙}} = 1.2 < s^2_{\text{甲}} = 3.6$，乙的方差更小，尺寸波动更小，质量更好。

**💡 易错提醒：** 综合判断需要同时考虑平均数（是否达标）和方差（是否稳定）。

**💡 解题思路总结：** 统计综合题：平均数反映"准不准"，方差反映"稳不稳"，百分位数反映"分布位置"。
