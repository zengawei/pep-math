**题目：** 计算：$\frac{2 + i}{1 - i}$

---

**解答：**

**第1步：** 分子分母同乘共轭
> 📌 运用知识点：复数的除法

$$\frac{2 + i}{1 - i} = \frac{(2 + i)(1 + i)}{(1 - i)(1 + i)} = \frac{2 + 2i + i + i^2}{1 - i^2} = \frac{2 + 3i - 1}{1 + 1} = \frac{1 + 3i}{2} = \frac{1}{2} + \frac{3}{2}i$$

**💡 易错提醒：** 分母 $1 - i$ 的共轭是 $1 + i$。分子展开时 $i^2 = -1$。

**💡 解题思路总结：** 复数除法：分子分母同乘分母的共轭复数。
