**例题：** 在复平面内，复数 $z = (a^2 - 4) + (a + 2)i$ 对应的点在虚轴上，求实数 $a$ 的值。

---

**解答：**

**第1步：** 利用虚轴上的点的条件
> 📌 运用知识点：复数的概念——复平面

点在虚轴上 $\Leftrightarrow$ 实部为 $0$（纵坐标可以为任意值）：

$a^2 - 4 = 0$

$(a + 2)(a - 2) = 0$

$a = -2$ 或 $a = 2$

**第2步：** 验证
> 📌 运用知识点：复数的概念

$a = -2$ 时：$z = 0 + 0i = 0$，对应原点。原点在虚轴上 ✓

$a = 2$ 时：$z = 0 + 4i = 4i$，对应点 $(0, 4)$，在虚轴上 ✓

所以 $a = -2$ 或 $a = 2$。

**💡 方法总结：** 虚轴上的点实部为零，纵坐标可以是任意值（包括零）。注意原点在虚轴上，对应 $z = 0$。
