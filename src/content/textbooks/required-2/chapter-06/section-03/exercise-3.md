**题目：** 已知 $\vec{a} = (2, 1)$，$\vec{b} = (-1, 3)$，若 $\vec{c} = 2\vec{a} - \vec{b}$，求 $\vec{c}$ 的坐标及 $|\vec{c}|$。

---

**解答：**

**第1步：** 计算 $\vec{c}$ 的坐标
> 📌 运用知识点：向量的数乘运算

$\vec{c} = 2\vec{a} - \vec{b} = 2(2, 1) - (-1, 3) = (4, 2) - (-1, 3) = (4-(-1), 2-3) = (5, -1)$

**第2步：** 计算 $|\vec{c}|$
> 📌 运用知识点：平面向量的基本定理及坐标表示

$|\vec{c}| = \sqrt{5^2 + (-1)^2} = \sqrt{25 + 1} = \sqrt{26}$

**💡 解题思路总结：** 先进行向量的数乘和加减运算得到坐标，再利用公式 $|\vec{v}| = \sqrt{x^2 + y^2}$ 求模。
