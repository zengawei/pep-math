**题目：** 已知 $\overrightarrow{AB} = \vec{a}$，$\overrightarrow{AC} = \vec{b}$，$D$ 是 $BC$ 上靠近 $B$ 的三等分点。用 $\vec{a}$、$\vec{b}$ 表示 $\overrightarrow{AD}$。

---

**解答：**

**第1步：** 确定 $D$ 的位置
> 📌 运用知识点：向量的数乘——三等分点

$D$ 是 $BC$ 上靠近 $B$ 的三等分点，意味着 $BD = \frac{1}{3}BC$。

所以 $\overrightarrow{BD} = \frac{1}{3}\overrightarrow{BC}$。

**第2步：** 用 $\vec{a}$、$\vec{b}$ 表示 $\overrightarrow{AD}$
> 📌 运用知识点：向量的加法与数乘

$\overrightarrow{BC} = \overrightarrow{AC} - \overrightarrow{AB} = \vec{b} - \vec{a}$

$\overrightarrow{AD} = \overrightarrow{AB} + \overrightarrow{BD} = \vec{a} + \frac{1}{3}(\vec{b} - \vec{a}) = \vec{a} + \frac{1}{3}\vec{b} - \frac{1}{3}\vec{a} = \frac{2}{3}\vec{a} + \frac{1}{3}\vec{b}$

**💡 易错提醒：** "靠近 $B$ 的三等分点"意味着 $BD = \frac{1}{3}BC$，不是 $BD = \frac{2}{3}BC$。注意区分靠近哪个端点。

**💡 解题思路总结：** 用路径法 $\overrightarrow{AD} = \overrightarrow{AB} + \overrightarrow{BD}$，将 $\overrightarrow{BD}$ 用已知向量表示。三等分点对应系数 $\frac{1}{3}$ 或 $\frac{2}{3}$。
