**题目：** 已知 $\overrightarrow{OA} = (2, 3)$，$\overrightarrow{OB} = (4, -1)$，求 $\overrightarrow{AB}$ 的坐标和 $|\overrightarrow{AB}|$。

---

**解答：**

**第1步：** 求 $\overrightarrow{AB}$
> 📌 运用知识点：向量的减法——坐标运算

$\overrightarrow{AB} = \overrightarrow{OB} - \overrightarrow{OA} = (4 - 2, -1 - 3) = (2, -4)$

**第2步：** 求 $|\overrightarrow{AB}|$
> 📌 运用知识点：向量的模

$|\overrightarrow{AB}| = \sqrt{2^2 + (-4)^2} = \sqrt{4 + 16} = \sqrt{20} = 2\sqrt{5}$

**💡 易错提醒：** $\overrightarrow{AB} = \overrightarrow{OB} - \overrightarrow{OA}$（终点减起点），不要搞反方向。

**💡 解题思路总结：** $\overrightarrow{AB} = \overrightarrow{OB} - \overrightarrow{OA}$，模用 $|\overrightarrow{AB}| = \sqrt{x^2 + y^2}$。
