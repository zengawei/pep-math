**题目：** 计算：$3(2\vec{a} - \vec{b}) + 2(\vec{a} + 3\vec{b})$

---

**解答：**

**第1步：** 展开
> 📌 运用知识点：向量的数乘——分配律

$3(2\vec{a} - \vec{b}) + 2(\vec{a} + 3\vec{b}) = 6\vec{a} - 3\vec{b} + 2\vec{a} + 6\vec{b}$

**第2步：** 合并同类项
> 📌 运用知识点：向量的加法

$= (6 + 2)\vec{a} + (-3 + 6)\vec{b} = 8\vec{a} + 3\vec{b}$

**💡 易错提醒：** 展开时注意符号：$2(\vec{a} + 3\vec{b}) = 2\vec{a} + 6\vec{b}$，不要漏乘。

**💡 解题思路总结：** 向量的线性运算与多项式运算类似，展开后合并同类项。
