**题目：** 在三角形 $OAB$ 中，$\overrightarrow{OA} = \vec{a}$，$\overrightarrow{OB} = \vec{b}$，$M$ 是 $AB$ 上靠近 $A$ 的三等分点，$N$ 是 $OM$ 的中点。用 $\vec{a}$、$\vec{b}$ 表示 $\overrightarrow{ON}$。

---

**解答：**

**第1步：** 求 $\overrightarrow{OM}$
> 📌 运用知识点：向量的数乘——三等分点

$M$ 是 $AB$ 上靠近 $A$ 的三等分点：$AM = \frac{1}{3}AB$。

$\overrightarrow{OM} = \overrightarrow{OA} + \overrightarrow{AM} = \vec{a} + \frac{1}{3}(\vec{b} - \vec{a}) = \frac{2}{3}\vec{a} + \frac{1}{3}\vec{b}$

**第2步：** 求 $\overrightarrow{ON}$
> 📌 运用知识点：向量的数乘——中点

$N$ 是 $OM$ 的中点：

$\overrightarrow{ON} = \frac{1}{2}\overrightarrow{OM} = \frac{1}{2}\left(\frac{2}{3}\vec{a} + \frac{1}{3}\vec{b}\right) = \frac{1}{3}\vec{a} + \frac{1}{6}\vec{b}$

**💡 易错提醒：** "靠近 $A$ 的三等分点"意味着 $AM = \frac{1}{3}AB$。中点对应系数 $\frac{1}{2}$。

**💡 解题思路总结：** 路径法逐步推导：$\overrightarrow{OM} = \overrightarrow{OA} + \frac{1}{3}\overrightarrow{AB}$，$\overrightarrow{ON} = \frac{1}{2}\overrightarrow{OM}$。
