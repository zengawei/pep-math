**题目：** 在三角形 $ABC$ 中，$D$ 是 $BC$ 的中点，设 $\overrightarrow{AB} = \vec{a}$，$\overrightarrow{AC} = \vec{b}$，用 $\vec{a}, \vec{b}$ 表示 $\overrightarrow{AD}$。

---

**解答：**

**第1步：** 利用中点条件
> 📌 运用知识点：向量的加法与减法

$D$ 是 $BC$ 的中点，所以 $\overrightarrow{BD} = \frac{1}{2}\overrightarrow{BC}$。

**第2步：** 用 $\vec{a}, \vec{b}$ 表示 $\overrightarrow{BC}$
> 📌 运用知识点：向量的加法与减法

$\overrightarrow{BC} = \overrightarrow{AC} - \overrightarrow{AB} = \vec{b} - \vec{a}$

**第3步：** 求 $\overrightarrow{AD}$
> 📌 运用知识点：向量的加法与减法

$\overrightarrow{AD} = \overrightarrow{AB} + \overrightarrow{BD} = \vec{a} + \frac{1}{2}(\vec{b} - \vec{a}) = \vec{a} + \frac{1}{2}\vec{b} - \frac{1}{2}\vec{a} = \frac{1}{2}\vec{a} + \frac{1}{2}\vec{b} = \frac{1}{2}(\vec{a} + \vec{b})$

**💡 解题思路总结：** 三角形中线向量公式：$\overrightarrow{AD} = \frac{1}{2}(\overrightarrow{AB} + \overrightarrow{AC})$，其中 $D$ 是 $BC$ 的中点。
