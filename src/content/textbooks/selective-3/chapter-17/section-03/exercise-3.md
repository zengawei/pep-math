**题目：** 袋中有 $10$ 个球，其中 $6$ 个红球、$4$ 个白球。现从中取球 $3$ 次，每次取 $1$ 个。

(1) 若**有放回**地取球，设取到红球的个数为 $X$，求 $X$ 的分布列及 $E(X)$。

(2) 若**不放回**地取球，设取到红球的个数为 $Y$，求 $Y$ 的分布列及 $E(Y)$。

---

**解答：**

**第1步（第1问）：** 判断分布类型
> 📌 运用知识点：二项分布的判定

有放回取球，每次取到红球的概率均为 $p = \dfrac{6}{10} = 0.6$，各次取球相互独立，共取 $n = 3$ 次。

因此 $X \sim B(3, 0.6)$。

**第2步（第1问）：** 求 $X$ 的分布列

$$P(X = k) = \binom{3}{k}(0.6)^k(0.4)^{3-k}, \quad k = 0, 1, 2, 3$$

$$P(X = 0) = \binom{3}{0}(0.6)^0(0.4)^3 = 0.064$$

$$P(X = 1) = \binom{3}{1}(0.6)^1(0.4)^2 = 3 \times 0.6 \times 0.16 = 0.288$$

$$P(X = 2) = \binom{3}{2}(0.6)^2(0.4)^1 = 3 \times 0.36 \times 0.4 = 0.432$$

$$P(X = 3) = \binom{3}{3}(0.6)^3(0.4)^0 = 0.216$$

分布列为：

| $X$ | $0$ | $1$ | $2$ | $3$ |
|:---:|:---:|:---:|:---:|:---:|
| $P$ | $0.064$ | $0.288$ | $0.432$ | $0.216$ |

**第3步（第1问）：** 求 $E(X)$
> 📌 运用知识点：二项分布的期望公式

$$E(X) = np = 3 \times 0.6 = 1.8$$

**第4步（第2问）：** 判断分布类型
> 📌 运用知识点：超几何分布的判定

不放回取球，总体 $N = 10$，红球 $M = 6$，抽取 $n = 3$。

因此 $Y$ 服从超几何分布：

$$P(Y = k) = \frac{\dbinom{6}{k}\dbinom{4}{3-k}}{\dbinom{10}{3}}, \quad k = 0, 1, 2, 3$$

其中 $\dbinom{10}{3} = 120$。

**第5步（第2问）：** 求 $Y$ 的分布列

$$P(Y = 0) = \frac{\dbinom{6}{0}\dbinom{4}{3}}{\dbinom{10}{3}} = \frac{1 \times 4}{120} = \frac{1}{30}$$

$$P(Y = 1) = \frac{\dbinom{6}{1}\dbinom{4}{2}}{\dbinom{10}{3}} = \frac{6 \times 6}{120} = \frac{36}{120} = \frac{3}{10}$$

$$P(Y = 2) = \frac{\dbinom{6}{2}\dbinom{4}{1}}{\dbinom{10}{3}} = \frac{15 \times 4}{120} = \frac{60}{120} = \frac{1}{2}$$

$$P(Y = 3) = \frac{\dbinom{6}{3}\dbinom{4}{0}}{\dbinom{10}{3}} = \frac{20 \times 1}{120} = \frac{1}{6}$$

分布列为：

| $Y$ | $0$ | $1$ | $2$ | $3$ |
|:---:|:---:|:---:|:---:|:---:|
| $P$ | $\dfrac{1}{30}$ | $\dfrac{3}{10}$ | $\dfrac{1}{2}$ | $\dfrac{1}{6}$ |

**验证：** $\dfrac{1}{30} + \dfrac{3}{10} + \dfrac{1}{2} + \dfrac{1}{6} = \dfrac{1 + 9 + 15 + 5}{30} = \dfrac{30}{30} = 1$ ✓

**第6步（第2问）：** 求 $E(Y)$

$$E(Y) = 0 \times \frac{1}{30} + 1 \times \frac{3}{10} + 2 \times \frac{1}{2} + 3 \times \frac{1}{6} = 0 + \frac{3}{10} + 1 + \frac{1}{2} = \frac{3 + 10 + 5}{10} = \frac{18}{10} = 1.8$$

> 💡 **注意：** 本题中 $E(X) = E(Y) = 1.8$，这不是巧合。超几何分布的期望 $E(Y) = n \cdot \dfrac{M}{N} = 3 \times \dfrac{6}{10} = 1.8$，与二项分布的期望 $E(X) = np = 3 \times 0.6 = 1.8$ 相同。

**💡 解题思路总结：** 判断分布类型的关键在于**抽样方式**——有放回 → 二项分布，不放回 → 超几何分布。两者的期望公式不同但结果可以相同。
