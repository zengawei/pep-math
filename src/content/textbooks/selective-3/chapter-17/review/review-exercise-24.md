**题目：** 某游戏有 $A$、$B$ 两关，通过 $A$ 关的概率为 $0.6$，通过 $B$ 关的概率为 $0.5$，两关相互独立。通过 $A$ 关得 $2$ 分，通过 $B$ 关得 $3$ 分，未通过不得分。设总得分为 $X$。

（1）求 $X$ 的分布表；

（2）求 $E(X)$。

---

**解答：**

**第1步：** 确定 $X$ 的可能取值
> 📌 运用知识点：离散型随机变量

$X$ 的可能取值为 $0, 2, 3, 5$（分别对应两关都没过、只过A、只过B、两关都过）。

**第2步：** 计算各概率
> 📌 运用知识点：独立事件的概率

$$P(X = 0) = (1 - 0.6)(1 - 0.5) = 0.4 \times 0.5 = 0.2$$

$$P(X = 2) = 0.6 \times (1 - 0.5) = 0.6 \times 0.5 = 0.3$$

$$P(X = 3) = (1 - 0.6) \times 0.5 = 0.4 \times 0.5 = 0.2$$

$$P(X = 5) = 0.6 \times 0.5 = 0.3$$

**验证：** $0.2 + 0.3 + 0.2 + 0.3 = 1$ ✓

分布表：

| $X$ | $0$ | $2$ | $3$ | $5$ |
|:---:|:---:|:---:|:---:|:---:|
| $P$ | $0.2$ | $0.3$ | $0.2$ | $0.3$ |

**第3步：** 求 $E(X)$
> 📌 运用知识点：数学期望

$$E(X) = 0 \times 0.2 + 2 \times 0.3 + 3 \times 0.2 + 5 \times 0.3 = 0 + 0.6 + 0.6 + 1.5 = 2.7$$

**另法验证：** 设 $X_A$ 为 $A$ 关得分，$X_B$ 为 $B$ 关得分。$E(X_A) = 2 \times 0.6 = 1.2$，$E(X_B) = 3 \times 0.5 = 1.5$。$E(X) = E(X_A) + E(X_B) = 1.2 + 1.5 = 2.7$ ✓

**⚠️ 易错提醒：** 注意 $X$ 的取值不是 $0, 1, 2, 3$，而是 $0, 2, 3, 5$（由得分规则决定）。不要遗漏任何取值或重复计算。

**💡 解题思路总结：** 独立事件组合的得分问题，先枚举所有可能结果，计算每种结果的概率和对应得分，再列分布表求期望。也可以利用期望的线性性质分步计算。
