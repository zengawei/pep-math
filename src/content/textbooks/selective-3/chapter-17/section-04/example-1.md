**例题：** 某投资项目的利润 $X$（万元）的分布列为 $P(X = 2) = 0.3$，$P(X = 5) = 0.5$，$P(X = -1) = 0.2$。求 $E(X)$ 和 $D(X)$。

**解答：**

**第1步：** 验证概率之和
> 📌 运用知识点：分布列的基本性质

$$0.3 + 0.5 + 0.2 = 1 \quad \checkmark$$

**第2步：** 求 $E(X)$
> 📌 运用知识点：均值公式 $E(X) = \sum x_i p_i$

$$E(X) = 2 \times 0.3 + 5 \times 0.5 + (-1) \times 0.2$$

$$= 0.6 + 2.5 - 0.2 = 2.9$$

**第3步：** 求 $D(X)$
> 📌 运用知识点：方差公式 $D(X) = \sum (x_i - E(X))^2 p_i$

$$D(X) = (2 - 2.9)^2 \times 0.3 + (5 - 2.9)^2 \times 0.5 + (-1 - 2.9)^2 \times 0.2$$

$$= (-0.9)^2 \times 0.3 + (2.1)^2 \times 0.5 + (-3.9)^2 \times 0.2$$

$$= 0.81 \times 0.3 + 4.41 \times 0.5 + 15.21 \times 0.2$$

$$= 0.243 + 2.205 + 3.042 = 5.49$$

**💡 解题思路总结：** 已知分布列求均值和方差是基本题型。先按 $E(X) = \sum x_i p_i$ 求均值，再按 $D(X) = \sum (x_i - E(X))^2 p_i$ 求方差。计算时注意负值项的处理，$(x_i - E(X))^2$ 一定为非负数。本题也可用等价公式 $D(X) = E(X^2) - [E(X)]^2$ 验证：$E(X^2) = 4 \times 0.3 + 25 \times 0.5 + 1 \times 0.2 = 1.2 + 12.5 + 0.2 = 13.9$，$D(X) = 13.9 - 2.9^2 = 13.9 - 8.41 = 5.49$，结果一致。
