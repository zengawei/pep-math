**题目：** 从某批产品中随机抽取 $20$ 件进行质量检测，结果如下（单位：克）：

$$98, 101, 99, 100, 102, 97, 101, 99, 100, 98$$
$$103, 99, 100, 101, 98, 100, 99, 102, 100, 101$$

（1）求样本的平均数 $\overline{x}$ 和标准差 $s$；

（2）用样本估计总体，估计该批产品的平均质量和质量波动情况。

---

**解答：**

**第1步：** 计算样本平均数
> 📌 运用知识点：样本的数字特征

$$\overline{x} = \frac{1}{20}\sum_{i=1}^{20} x_i = \frac{98 + 101 + 99 + \cdots + 101}{20}$$

$$= \frac{98 + 101 + 99 + 100 + 102 + 97 + 101 + 99 + 100 + 98 + 103 + 99 + 100 + 101 + 98 + 100 + 99 + 102 + 100 + 101}{20}$$

$$= \frac{2000}{20} = 100$$

**第2步：** 计算样本标准差
> 📌 运用知识点：样本的数字特征

各数据与平均数的偏差：

$-2, 1, -1, 0, 2, -3, 1, -1, 0, -2, 3, -1, 0, 1, -2, 0, -1, 2, 0, 1$

偏差的平方和：

$$\sum (x_i - \overline{x})^2 = 4+1+1+0+4+9+1+1+0+4+9+1+0+1+4+0+1+4+0+1 = 46$$

$$s^2 = \frac{46}{20} = 2.3$$

$$s = \sqrt{2.3} \approx 1.52$$

**第3步：** 用样本估计总体
> 📌 运用知识点：样本估计总体

该批产品的平均质量估计为 $\overline{x} = 100$ 克，标准差约为 $1.52$ 克，说明产品质量比较稳定，波动较小。

**⚠️ 易错提醒：** 计算标准差时，先算偏差平方和再除以 $n$（或 $n-1$），最后开方。计算过程中注意不要遗漏任何数据。

**💡 解题思路总结：** 用样本的数字特征（均值、标准差）估计总体的相应参数。均值反映"中心位置"，标准差反映"波动大小"。
