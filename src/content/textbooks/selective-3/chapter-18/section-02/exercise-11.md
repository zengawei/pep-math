**题目：** 某市为了解市民对某项政策的支持率，采用分层抽样方法从甲、乙、丙三个区分别抽取市民进行调查。三个区的人口比例为 $3:5:2$，共抽取 $500$ 人。调查结果如下：

| 区域 | 抽取人数 | 支持人数 |
|:---:|:---:|:---:|
| 甲区 | $150$ | $120$ |
| 乙区 | $250$ | $175$ |
| 丙区 | $100$ | $60$ |

(1) 若三个区的总人口为 $200$ 万人，求各区的人口数；

(2) 分别估计各区市民对该政策的支持率；

(3) 估计全市市民对该政策的总支持率，并估算支持该政策的市民总人数。

---

**解答：**

**第1步：** 求各区人口数
> 📌 运用知识点：分层抽样

三个区人口比例为 $3:5:2$，总人口为 $200$ 万人。

设比例系数为 $k$，则 $3k + 5k + 2k = 200$，$10k = 200$，$k = 20$。

- 甲区人口：$3 \times 20 = 60$ 万人
- 乙区人口：$5 \times 20 = 100$ 万人
- 丙区人口：$2 \times 20 = 40$ 万人

验证抽样比例：甲区 $\frac{150}{600000} = \frac{1}{4000}$，乙区 $\frac{250}{1000000} = \frac{1}{4000}$，丙区 $\frac{100}{400000} = \frac{1}{4000}$。各层抽样比例一致 ✓

**第2步：** 估计各区支持率
> 📌 运用知识点：用样本频率估计总体概率

- 甲区：$\hat{p}_1 = \frac{120}{150} = 0.80 = 80\%$
- 乙区：$\hat{p}_2 = \frac{175}{250} = 0.70 = 70\%$
- 丙区：$\hat{p}_3 = \frac{60}{100} = 0.60 = 60\%$

**第3步：** 估计全市总支持率和总支持人数
> 📌 运用知识点：用样本估计总体

各区的估计支持人数：

- 甲区：$60 \times 80\% = 48$ 万人
- 乙区：$100 \times 70\% = 70$ 万人
- 丙区：$40 \times 60\% = 24$ 万人

全市支持总人数：$48 + 70 + 24 = 142$ 万人。

全市总支持率：

$$\hat{p} = \frac{142}{200} = 0.71 = 71\%$$

也可以直接计算：$\hat{p} = \frac{120 + 175 + 60}{500} = \frac{355}{500} = 0.71 = 71\%$。

估计全市市民对该政策的总支持率约为 $\boxed{71\%}$，支持该政策的市民总人数约为 $\boxed{142}$ 万人。

**⚠️ 易错提醒：** 估计全市总支持率时，由于各层抽样比例相同，可以直接用总样本中支持人数除以总样本量。但如果各层抽样比例不同，则必须分层估计后加权求和。注意区分"各区支持率"和"全市总支持率"——后者不是各区支持率的简单平均。

**💡 解题思路总结：** 分层抽样的综合应用题通常包含"求各层数量 → 分层估计 → 汇总总体"三个步骤。关键是保持各层数据的一致性，并在最终汇总时采用正确的方法（加权求和或直接用总样本频率）。
