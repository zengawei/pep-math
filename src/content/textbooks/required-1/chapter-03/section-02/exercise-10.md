**题目：** 已知函数 $f(x)$ 是定义在 $\mathbb{R}$ 上的奇函数，且当 $x > 0$ 时，$f(x) = x^2 - 4x + 3$。

(1) 求 $f(x)$ 的解析式；

(2) 求 $f(x)$ 的单调区间；

(3) 求不等式 $f(x) > 0$ 的解集。

---

**解答：**

**第1步：** 求 $f(x)$ 的解析式
> 📌 运用知识点：奇偶性与解析式

当 $x < 0$ 时，$-x > 0$，

$f(-x) = (-x)^2 - 4(-x) + 3 = x^2 + 4x + 3$

因为 $f(x)$ 为奇函数，$f(x) = -f(-x) = -x^2 - 4x - 3$。

又 $f(0) = 0$（奇函数在 $x = 0$ 处有定义则 $f(0) = 0$）。

$$f(x) = \begin{cases} x^2 - 4x + 3, & x > 0 \\ 0, & x = 0 \\ -x^2 - 4x - 3, & x < 0 \end{cases}$$

**第2步：** 求单调区间
> 📌 运用知识点：函数单调性

当 $x > 0$ 时：$f(x) = (x-2)^2 - 1$，在 $(0, 2]$ 上递减，在 $[2, +\infty)$ 上递增。

当 $x < 0$ 时：$f(x) = -(x+2)^2 + 1$，在 $(-\infty, -2]$ 上递增，在 $[-2, 0)$ 上递减。

注意 $f(x)$ 在 $x = 0$ 处不连续（$\lim_{x \to 0^-} f(x) = -3 \neq 0$，$\lim_{x \to 0^+} f(x) = 3 \neq 0$），

所以单调区间不能跨越 $x = 0$。

单调递增区间：$(-\infty, -2]$ 和 $[2, +\infty)$

单调递减区间：$[-2, 0)$ 和 $(0, 2]$

**第3步：** 解不等式 $f(x) > 0$
> 📌 运用知识点：分段函数与不等式

**当 $x > 0$ 时：** $x^2 - 4x + 3 > 0 \Rightarrow (x-1)(x-3) > 0 \Rightarrow x < 1$ 或 $x > 3$。

结合 $x > 0$：$0 < x < 1$ 或 $x > 3$。

**当 $x < 0$ 时：** $-x^2 - 4x - 3 > 0 \Rightarrow x^2 + 4x + 3 < 0 \Rightarrow (x+1)(x+3) < 0 \Rightarrow -3 < x < -1$。

**当 $x = 0$ 时：** $f(0) = 0$，不满足 $> 0$。

解集为 $(-3, -1) \cup (0, 1) \cup (3, +\infty)$。

**⚠️ 易错提醒：** ①求 $x < 0$ 时的解析式时容易忘记 $f(x) = -f(-x)$ 中的负号。②单调区间不能跨越不连续点 $x = 0$。③解不等式时要分情况讨论。

**💡 解题思路总结：** 已知奇函数在一侧的解析式，利用 $f(-x) = -f(x)$ 求另一侧。单调性和不等式问题需要分段讨论后合并结果。
