**题目：** 已知函数 $f(x) = |x^2 - 4x + 3|$。

(1) 求 $f(x)$ 的单调递减区间；

(2) 求方程 $f(x) = a$ 有四个不同实数根时 $a$ 的取值范围。

---

**解答：**

**第1步：** 分析内部函数
> 📌 运用知识点：二次函数的性质

$x^2 - 4x + 3 = (x-1)(x-3)$

零点为 $x = 1$ 和 $x = 3$，顶点为 $(2, -1)$。

$f(x) = |x^2 - 4x + 3|$ 的图象是将 $y = x^2 - 4x + 3$ 在 $x$ 轴下方的部分（即 $1 < x < 3$ 的部分）翻折到 $x$ 轴上方。

**第2步：** 确定单调递减区间
> 📌 运用知识点：函数图象与单调性

- $x \leq 1$：$f(x) = x^2 - 4x + 3$，开口向上，对称轴 $x = 2$，在 $(-\infty, 1]$ 上递减。
- $1 < x \leq 2$：$f(x) = -(x^2 - 4x + 3) = -(x-2)^2 + 1$，开口向下，对称轴 $x = 2$，在 $(1, 2]$ 上递增。
- $2 < x \leq 3$：$f(x) = -(x-2)^2 + 1$，在 $[2, 3)$ 上递减。
- $x > 3$：$f(x) = x^2 - 4x + 3$，在 $[3, +\infty)$ 上递增。

单调递减区间为 $(-\infty, 1]$ 和 $[2, 3]$。

**第3步：** 确定 $a$ 的范围
> 📌 运用知识点：函数图象与方程的根

$f(x)$ 的图象特征：
- $f(1) = 0$，$f(3) = 0$（最小值）
- $f(2) = |4 - 8 + 3| = 1$（翻折后的局部最大值）

方程 $f(x) = a$ 有四个不同实数根，即直线 $y = a$ 与 $y = f(x)$ 的图象有四个交点。

由图象可知，当 $0 < a < 1$ 时有四个交点。

所以 $a$ 的取值范围为 $(0, 1)$。

**⚠️ 易错提醒：** 含绝对值的函数需要分段讨论。画图象时注意翻折后的局部最大值点 $(2, 1)$，这是确定 $a$ 范围的关键。

**💡 解题思路总结：** 含绝对值的函数问题，先画出图象（将负值部分翻折），再利用图象分析单调性和方程根的个数。数形结合是解决此类问题的核心方法。
