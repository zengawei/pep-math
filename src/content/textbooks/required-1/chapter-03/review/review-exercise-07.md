**题目：** 已知 $f(x)$ 是一次函数，且 $3f(x+1) - 2f(x-1) = 2x + 7$，求 $f(x)$ 的解析式。

---

**解答：**

**第1步：** 设出一般形式
> 📌 运用知识点：待定系数法

设 $f(x) = ax + b$（$a \neq 0$）。

**第2步：** 代入计算
> 📌 运用知识点：函数的运算

$3f(x+1) - 2f(x-1) = 3[a(x+1) + b] - 2[a(x-1) + b]$

$= 3ax + 3a + 3b - 2ax + 2a - 2b$

$= ax + 5a + b$

**第3步：** 比较系数
> 📌 运用知识点：恒等式

$ax + 5a + b = 2x + 7$

$\begin{cases} a = 2 \\ 5a + b = 7 \end{cases}$

$5 \times 2 + b = 7$，$b = -3$

所以 $f(x) = 2x - 3$。

**第4步：** 验证
> 📌 运用知识点：检验

$3f(x+1) - 2f(x-1) = 3(2x+2-3) - 2(2x-2-3) = 3(2x-1) - 2(2x-5) = 6x-3-4x+10 = 2x+7$ ✓

**⚠️ 易错提醒：** 展开时容易漏项或算错符号。代入后务必仔细合并同类项。

**💡 解题思路总结：** 已知函数类型用待定系数法：设出一般形式→代入条件→比较系数→解方程→验证。
