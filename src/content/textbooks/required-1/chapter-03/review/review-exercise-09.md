**题目：** 判断下列各组函数是否为同一函数：

(1) $f(x) = |x|$ 与 $g(x) = \sqrt{x^2}$；

(2) $f(x) = \frac{x^2 - 1}{x - 1}$ 与 $g(x) = x + 1$。

---

**解答：**

**第1步：** 判断 (1)
> 📌 运用知识点：函数的概念

$f(x) = |x|$ 的定义域为 $\mathbb{R}$。

$g(x) = \sqrt{x^2} = |x|$ 的定义域为 $\mathbb{R}$。

定义域相同，对应关系相同（$g(x) = |x| = f(x)$），

所以 $f(x)$ 与 $g(x)$ **是**同一函数。✓

**第2步：** 判断 (2)
> 📌 运用知识点：函数的概念

$f(x) = \frac{x^2 - 1}{x - 1} = \frac{(x+1)(x-1)}{x-1} = x + 1$，但要求 $x \neq 1$。

$f(x)$ 的定义域为 $\{x \mid x \neq 1\}$。

$g(x) = x + 1$ 的定义域为 $\mathbb{R}$。

定义域不同，所以 $f(x)$ 与 $g(x)$ **不是**同一函数。✗

**⚠️ 易错提醒：** (2) 中虽然化简后 $f(x) = x + 1$，但 $x = 1$ 处 $f(x)$ 无定义。判断同一函数必须同时满足定义域和对应关系都相同。

**💡 解题思路总结：** 判断同一函数的两个条件：①定义域相同；②对应关系相同。缺一不可。化简函数时注意定义域的变化。
