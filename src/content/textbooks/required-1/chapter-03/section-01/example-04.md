**例题：** 已知 $f(x)$ 是一次函数，且 $f(f(x)) = 4x + 3$，求 $f(x)$ 的解析式。

**解答：**

**第1步：** 设出一次函数的一般形式
> 📌 运用知识点：待定系数法

设 $f(x) = ax + b$（$a \neq 0$）。

**第2步：** 计算 $f(f(x))$
> 📌 运用知识点：函数的复合

$f(f(x)) = f(ax + b) = a(ax + b) + b = a^2 x + ab + b$

**第3步：** 比较系数
> 📌 运用知识点：恒等式

$a^2 x + ab + b = 4x + 3$ 对所有 $x$ 成立，

所以 $\begin{cases} a^2 = 4 \\ ab + b = 3 \end{cases}$

**第4步：** 解方程组
> 📌 运用知识点：一元二次方程

由 $a^2 = 4$，得 $a = 2$ 或 $a = -2$。

当 $a = 2$ 时：$2b + b = 3$，$3b = 3$，$b = 1$。

当 $a = -2$ 时：$-2b + b = 3$，$-b = 3$，$b = -3$。

所以 $f(x) = 2x + 1$ 或 $f(x) = -2x - 3$。

**第5步：** 验证
> 📌 运用知识点：检验

$f(x) = 2x + 1$：$f(f(x)) = 2(2x+1)+1 = 4x+3$ ✓

$f(x) = -2x - 3$：$f(f(x)) = -2(-2x-3)-3 = 4x+6-3 = 4x+3$ ✓

**💡 解题思路总结：** 已知函数类型求解析式，用待定系数法：①设出含未知系数的一般形式；②代入已知条件建立方程（组）；③解方程求出系数；④验证。注意不要漏解。
