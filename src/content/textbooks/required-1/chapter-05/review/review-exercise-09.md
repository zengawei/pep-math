**题目：** 求下列各角的三角函数值：(1) $\sin\dfrac{5\pi}{6}$；(2) $\cos\dfrac{3\pi}{4}$；(3) $\tan\dfrac{2\pi}{3}$。

---

**解答：**

**第1步：** 求 $\sin\dfrac{5\pi}{6}$
> 📌 运用知识点：诱导公式（或特殊角）

$\dfrac{5\pi}{6} = \pi - \dfrac{\pi}{6}$

$\sin\dfrac{5\pi}{6} = \sin\left(\pi - \dfrac{\pi}{6}\right) = \sin\dfrac{\pi}{6} = \dfrac{1}{2}$

**第2步：** 求 $\cos\dfrac{3\pi}{4}$
> 📌 运用知识点：诱导公式

$\dfrac{3\pi}{4} = \pi - \dfrac{\pi}{4}$

$\cos\dfrac{3\pi}{4} = \cos\left(\pi - \dfrac{\pi}{4}\right) = -\cos\dfrac{\pi}{4} = -\dfrac{\sqrt{2}}{2}$

**第3步：** 求 $\tan\dfrac{2\pi}{3}$
> 📌 运用知识点：诱导公式

$\dfrac{2\pi}{3} = \pi - \dfrac{\pi}{3}$

$\tan\dfrac{2\pi}{3} = \tan\left(\pi - \dfrac{\pi}{3}\right) = -\tan\dfrac{\pi}{3} = -\sqrt{3}$

**⚠️ 易错提醒：** $\pi - \alpha$ 型诱导公式：正弦不变号，余弦和正切变号。注意 $\dfrac{5\pi}{6}$ 在第二象限，正弦为正，余弦为负。

**💡 解题思路总结：** 求非特殊角的三角函数值：利用诱导公式转化为特殊角。$\sin(\pi - \alpha) = \sin\alpha$，$\cos(\pi - \alpha) = -\cos\alpha$，$\tan(\pi - \alpha) = -\tan\alpha$。
