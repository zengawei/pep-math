**题目：** 已知角 $\alpha$ 的终边过点 $P(3a, -4a)$（$a \neq 0$），求 $\sin\alpha$、$\cos\alpha$、$\tan\alpha$ 的值。

---

**解答：**

**第1步：** 分类讨论 $a$ 的正负
> 📌 运用知识点：三角函数定义与分类讨论

$x = 3a$，$y = -4a$

$r = \sqrt{(3a)^2 + (-4a)^2} = \sqrt{9a^2 + 16a^2} = \sqrt{25a^2} = 5|a|$

**第2步：** 当 $a > 0$ 时
> 📌 运用知识点：三角函数定义

$r = 5a$，$x = 3a > 0$，$y = -4a < 0$（第四象限）

$\sin\alpha = \dfrac{y}{r} = \dfrac{-4a}{5a} = -\dfrac{4}{5}$

$\cos\alpha = \dfrac{x}{r} = \dfrac{3a}{5a} = \dfrac{3}{5}$

$\tan\alpha = \dfrac{y}{x} = \dfrac{-4a}{3a} = -\dfrac{4}{3}$

**第3步：** 当 $a < 0$ 时
> 📌 运用知识点：三角函数定义

$r = -5a$（因为 $|a| = -a$），$x = 3a < 0$，$y = -4a > 0$（第二象限）

$\sin\alpha = \dfrac{-4a}{-5a} = \dfrac{4}{5}$

$\cos\alpha = \dfrac{3a}{-5a} = -\dfrac{3}{5}$

$\tan\alpha = \dfrac{-4a}{3a} = -\dfrac{4}{3}$

**注意：** 无论 $a > 0$ 还是 $a < 0$，$\tan\alpha = -\dfrac{4}{3}$ 不变（因为终边在同一条直线上）。

**⚠️ 易错提醒：** $r = 5|a|$ 不是 $5a$。当 $a < 0$ 时 $r = -5a$。注意分类讨论，$a$ 的正负影响象限位置，从而影响 $\sin\alpha$ 和 $\cos\alpha$ 的符号。

**💡 解题思路总结：** 终边在含参数直线上的三角函数值：(1) $r = \sqrt{x^2 + y^2}$ 含绝对值；(2) 按参数正负分类讨论；(3) $\tan\alpha$ 不受影响（同一直线斜率相同）。
