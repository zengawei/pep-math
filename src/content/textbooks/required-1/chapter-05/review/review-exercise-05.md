**题目：** 已知角 $\alpha$ 的终边过点 $P(1, -\sqrt{3})$，求 $\sin\alpha$、$\cos\alpha$、$\tan\alpha$。

---

**解答：**

**第1步：** 求 $r$
> 📌 运用知识点：三角函数定义

$r = \sqrt{1^2 + (-\sqrt{3})^2} = \sqrt{1 + 3} = \sqrt{4} = 2$

**第2步：** 求三角函数值
> 📌 运用知识点：三角函数定义公式

$\sin\alpha = \dfrac{y}{r} = \dfrac{-\sqrt{3}}{2} = -\dfrac{\sqrt{3}}{2}$

$\cos\alpha = \dfrac{x}{r} = \dfrac{1}{2}$

$\tan\alpha = \dfrac{y}{x} = \dfrac{-\sqrt{3}}{1} = -\sqrt{3}$

**⚠️ 易错提醒：** $(-\sqrt{3})^2 = 3$，不要算成 $-\sqrt{3}^2 = -3$。点 $(1, -\sqrt{3})$ 在第四象限，$\sin < 0$，$\cos > 0$，$\tan < 0$，与结果一致。

**💡 解题思路总结：** 已知终边上一点求三角函数值：先求 $r$，再代入定义公式。
