**题目：** 已知角 $\alpha$ 的终边过点 $P(-5, 12)$，求 $\sin\alpha$、$\cos\alpha$、$\tan\alpha$。

---

**解答：**

**第1步：** 求 $r$
> 📌 运用知识点：三角函数的定义

$x = -5$，$y = 12$

$r = \sqrt{x^2 + y^2} = \sqrt{(-5)^2 + 12^2} = \sqrt{25 + 144} = \sqrt{169} = 13$

**第2步：** 求三角函数值
> 📌 运用知识点：三角函数的定义

$\sin\alpha = \dfrac{y}{r} = \dfrac{12}{13}$

$\cos\alpha = \dfrac{x}{r} = \dfrac{-5}{13} = -\dfrac{5}{13}$

$\tan\alpha = \dfrac{y}{x} = \dfrac{12}{-5} = -\dfrac{12}{5}$

**⚠️ 易错提醒：** $r$ 始终为正数（$r = \sqrt{x^2 + y^2} > 0$）。计算 $r$ 时注意 $(-5)^2 = 25$，不要漏掉负号的平方。

**💡 解题思路总结：** 已知终边上一点 $P(x, y)$ 求三角函数值：先求 $r = \sqrt{x^2 + y^2}$，再用定义 $\sin\alpha = \dfrac{y}{r}$，$\cos\alpha = \dfrac{x}{r}$，$\tan\alpha = \dfrac{y}{x}$。
