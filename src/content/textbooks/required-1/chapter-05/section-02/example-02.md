**题目：** 已知角 $\alpha$ 的终边过点 $P(-3, 4)$，求 $\sin\alpha$、$\cos\alpha$、$\tan\alpha$ 的值。

---

**解答：**

**第1步：** 求 $r$
> 📌 运用知识点：三角函数的定义

$x = -3$，$y = 4$

$r = \sqrt{x^2 + y^2} = \sqrt{(-3)^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5$

**第2步：** 求三角函数值
> 📌 运用知识点：三角函数定义公式

$\sin\alpha = \dfrac{y}{r} = \dfrac{4}{5}$

$\cos\alpha = \dfrac{x}{r} = \dfrac{-3}{5} = -\dfrac{3}{5}$

$\tan\alpha = \dfrac{y}{x} = \dfrac{4}{-3} = -\dfrac{4}{3}$

**验证：** 点 $P(-3, 4)$ 在第二象限，$\sin\alpha > 0$，$\cos\alpha < 0$，$\tan\alpha < 0$，与结果一致。

**⚠️ 易错提醒：** $r$ 永远为正。$\tan\alpha = \dfrac{y}{x}$ 中，$x \neq 0$。当终边在 $y$ 轴上时（$x = 0$），$\tan\alpha$ 不存在。

**💡 解题思路总结：** 已知终边上一点求三角函数值的三步法：(1) $r = \sqrt{x^2 + y^2}$；(2) 代入定义公式；(3) 用象限验证符号合理性。
