**题目：** 利用三角函数线，求满足 $\sin x \geq \dfrac{1}{2}$ 的角 $x$ 的集合（在 $[0, 2\pi]$ 内）。

---

**解答：**

**第1步：** 在单位圆中画出正弦线
> 📌 运用知识点：三角函数线（正弦线）

在单位圆中，$\sin x = \dfrac{1}{2}$ 对应角 $x = \dfrac{\pi}{6}$ 和 $x = \dfrac{5\pi}{6}$。

正弦线是角的终边与单位圆交点的纵坐标。

**第2步：** 确定满足条件的范围
> 📌 运用知识点：正弦函数图象与单位圆

当角 $x$ 从 $0$ 增大到 $2\pi$ 时：
- 在 $\left[0, \dfrac{\pi}{6}\right)$ 上，$\sin x < \dfrac{1}{2}$
- 在 $\left[\dfrac{\pi}{6}, \dfrac{5\pi}{6}\right]$ 上，$\sin x \geq \dfrac{1}{2}$
- 在 $\left(\dfrac{5\pi}{6}, 2\pi\right]$ 上，$\sin x < \dfrac{1}{2}$

所以满足 $\sin x \geq \dfrac{1}{2}$ 的角 $x$ 的集合为：

$\left\{x \mid \dfrac{\pi}{6} \leq x \leq \dfrac{5\pi}{6}\right\}$

**⚠️ 易错提醒：** 注意 $\sin x = \dfrac{1}{2}$ 在 $[0, 2\pi]$ 内有两个解：$\dfrac{\pi}{6}$ 和 $\pi - \dfrac{\pi}{6} = \dfrac{5\pi}{6}$。不要遗漏第二个解。不等号含等号，端点要取到。

**💡 解题思路总结：** 利用三角函数线解三角不等式：(1) 先在单位圆中找到等号成立的角；(2) 根据正弦线（纵坐标）的变化趋势确定满足不等式的区间；(3) 写出集合。
