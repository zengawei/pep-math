**题目：** 求函数 $y = 4\sin\left(3x - \dfrac{\pi}{4}\right)$ 的周期、振幅和初相。

---

**解答：**

**第1步：** 识别参数
> 📌 运用知识点：$y = A\sin(\omega x + \varphi)$ 的标准形式

对比 $y = A\sin(\omega x + \varphi)$：

$A = 4$，$\omega = 3$，$\varphi = -\dfrac{\pi}{4}$

**第2步：** 计算各量
> 📌 运用知识点：周期、振幅、初相的定义

振幅 $= |A| = 4$

周期 $T = \dfrac{2\pi}{|\omega|} = \dfrac{2\pi}{3}$

初相 $= \varphi = -\dfrac{\pi}{4}$

**⚠️ 易错提醒：** 初相是 $\varphi$ 本身，可以为负值。周期公式中 $\omega$ 取绝对值。不要把 $\omega x + \varphi$ 中的 $\varphi$ 与相位（$\omega x + \varphi$ 整体）混淆。

**💡 解题思路总结：** 直接从 $y = A\sin(\omega x + \varphi)$ 中读取参数：振幅 $= |A|$，周期 $= \dfrac{2\pi}{|\omega|}$，初相 $= \varphi$。
