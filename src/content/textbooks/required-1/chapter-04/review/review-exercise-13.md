**题目：** 已知 $a^{\frac{1}{2}} + a^{-\frac{1}{2}} = 3$（$a > 0$），求 $\frac{a^2 + a^{-2} + 2}{a + a^{-1}}$ 的值。

---

**解答：**

**第1步：** 先求 $a + a^{-1}$
> 📌 运用知识点：指数运算法则

$(a^{\frac{1}{2}} + a^{-\frac{1}{2}})^2 = 9$

$a + 2 + a^{-1} = 9$

$a + a^{-1} = 7$

**第2步：** 求 $a^2 + a^{-2}$
> 📌 运用知识点：指数运算法则

$(a + a^{-1})^2 = 49$

$a^2 + 2 + a^{-2} = 49$

$a^2 + a^{-2} = 47$

**第3步：** 代入

$\frac{47 + 2}{7} = \frac{49}{7} = 7$

**⚠️ 易错提醒：** 分子 $a^2 + a^{-2} + 2 = (a + a^{-1})^2 = 49$，也可以直接看出分子等于 $(a+a^{-1})^2$。

**💡 解题思路总结：** 反复利用整体平方技巧：$(x + x^{-1})^2 = x^2 + 2 + x^{-2}$。
