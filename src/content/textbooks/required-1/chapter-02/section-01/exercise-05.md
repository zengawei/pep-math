**题目：** 已知 $a > b > 0$，$c > d > 0$，求证：$a + c > b + d$。

---

**解答：**

**第1步：** 利用加法性质
> 📌 运用知识点：不等式的性质

因为 $a > b$，由不等式的加法性质，两边同时加 $c$ 得：
$$a + c > b + c$$

**第2步：** 再次利用加法性质
> 📌 运用知识点：不等式的性质

因为 $c > d$，由不等式的加法性质，两边同时加 $b$ 得：
$$b + c > b + d$$

**第3步：** 利用传递性得出结论
> 📌 运用知识点：不等式的性质

由 $a + c > b + c$ 和 $b + c > b + d$，根据不等式的传递性得：
$$a + c > b + d$$

**⚠️ 易错提醒：** 不能直接把两个不等式"相加"而不说明依据。应明确写出每一步使用了哪条性质。

**💡 解题思路总结：** 不等式加法性质的应用：若 $a > b$ 且 $c > d$，则 $a + c > b + d$。证明过程就是反复使用基本性质（加法性质、传递性），每一步都要有依据。
