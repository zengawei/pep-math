**例题：** 已知 $a > 0$，$b > 0$，且 $a + b = 4$，求 $ab$ 的最大值。

**解答：**

**第1步：** 应用基本不等式
> 📌 运用知识点：基本不等式

因为 $a > 0$，$b > 0$，由基本不等式：

$$\sqrt{ab} \leq \frac{a + b}{2} = \frac{4}{2} = 2$$

所以 $ab \leq 4$。

**第2步：** 验证等号成立条件
> 📌 运用知识点：基本不等式

等号成立：$a = b$。

由 $a + b = 4$ 且 $a = b$，得 $a = b = 2$。

所以 $ab$ 的最大值为 $4$，在 $a = b = 2$ 时取得。

**⚠️ 易错提醒：** 这是"和定积最大"的典型情况。$a + b = 4$ 为定值（和定），所以 $ab$ 有最大值 $\left(\frac{a+b}{2}\right)^2 = 4$。
