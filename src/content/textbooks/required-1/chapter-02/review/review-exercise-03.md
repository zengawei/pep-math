**题目：** 已知 $a > 0$，$b > 0$，且 $a + b = 10$，求 $ab$ 的最大值。

---

**解答：**

**第1步：** 应用基本不等式
> 📌 运用知识点：基本不等式

因为 $a > 0$，$b > 0$，由基本不等式：

$$\sqrt{ab} \leq \frac{a + b}{2} = \frac{10}{2} = 5$$

所以 $ab \leq 25$。

**第2步：** 验证等号成立条件
> 📌 运用知识点：基本不等式

等号成立：$a = b = 5$。

所以 $ab$ 的最大值为 $25$，在 $a = b = 5$ 时取得。

**⚠️ 易错提醒：** "和定积最大"：$a + b = 10$ 为定值，$ab$ 的最大值为 $\left(\frac{10}{2}\right)^2 = 25$。

**💡 解题思路总结：** 基本不等式的直接应用：已知和求积的最大值，用 $\sqrt{ab} \leq \frac{a+b}{2}$，即 $ab \leq \left(\frac{a+b}{2}\right)^2$。
