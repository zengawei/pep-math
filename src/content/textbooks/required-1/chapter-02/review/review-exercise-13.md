**题目：** 已知 $-1 \leq a \leq 1$，$-2 \leq b \leq 3$，求 $2a - 3b$ 的取值范围。

---

**解答：**

**第1步：** 求 $2a$ 的范围
> 📌 运用知识点：不等式的性质

由 $-1 \leq a \leq 1$，两边乘以 $2$（正数，不变号）：

$$-2 \leq 2a \leq 2$$

**第2步：** 求 $-3b$ 的范围
> 📌 运用知识点：不等式的性质

由 $-2 \leq b \leq 3$，两边乘以 $-3$（负数，变号）：

$$-9 \leq -3b \leq 6$$

**第3步：** 相加
> 📌 运用知识点：不等式的性质

$$-2 + (-9) \leq 2a + (-3b) \leq 2 + 6$$

$$-11 \leq 2a - 3b \leq 8$$

**⚠️ 易错提醒：** 乘以负数时不等号要变向。求 $-3b$ 的范围时，$-2 \leq b \leq 3$ 乘以 $-3$ 得 $-9 \leq -3b \leq 6$（注意 $-3 \times (-2) = 6 > -3 \times 3 = -9$）。

**💡 解题思路总结：** 求线性组合 $ma + nb$ 的范围：分别求 $ma$ 和 $nb$ 的范围（注意乘负数变号），再相加。
