**题目：** 已知 $a > b$，$c > d$。判断 $a + d > b + c$ 是否一定成立？若不成立，举出反例。

---

**解答：**

**第1步：** 分析
> 📌 运用知识点：不等式的性质

$a + d > b + c$ 等价于 $a - b > c - d$。

虽然 $a - b > 0$ 且 $c - d > 0$，但两者的大小关系不确定。

**第2步：** 举反例
> 📌 运用知识点：不等式的性质

取 $a = 3, b = 2, c = 10, d = 1$。

$a > b$（$3 > 2$）✓，$c > d$（$10 > 1$）✓。

$a + d = 3 + 1 = 4$，$b + c = 2 + 10 = 12$。

$4 > 12$？不成立！

所以 $a + d > b + c$ **不一定成立**。

**第3步：** 正确结论
> 📌 运用知识点：不等式的性质

由 $a > b$ 和 $c > d$，利用不等式加法性质只能得到 $a + c > b + d$（同向相加），而不能得到 $a + d > b + c$。

**⚠️ 易错提醒：** 不等式只能"同向相加"，不能"交叉相加"。$a > b, c > d \Rightarrow a + c > b + d$，但 $a + d$ 与 $b + c$ 的大小不确定。

**💡 解题思路总结：** 判断不等式命题时，如果直觉上不确定，可以举反例来否定。反例法是否定命题的最有效方法。
