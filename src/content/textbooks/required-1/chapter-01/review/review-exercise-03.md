**题目：** 用列举法表示下列集合：

(1) $A = \{x \in \mathbb{Z} \mid -3 < x \leqslant 2\}$；

(2) $B = \{x \mid x \text{ 是 } 12 \text{ 的正因数}\}$。

---

**解答：**

**第1步：** 列举集合 $A$
> 📌 运用知识点：列举法

满足 $-3 < x \leqslant 2$ 的整数为 $-2, -1, 0, 1, 2$。

$$A = \{-2, -1, 0, 1, 2\}$$

**第2步：** 列举集合 $B$
> 📌 运用知识点：列举法

$12$ 的正因数：$1, 2, 3, 4, 6, 12$。

$$B = \{1, 2, 3, 4, 6, 12\}$$

**⚠️ 易错提醒：** 注意 $-3 < x$ 表示 $x > -3$（不含 $-3$），$x \leqslant 2$ 表示含 $2$。端点开闭要仔细区分。

**💡 解题思路总结：** 列举法的关键是找出满足条件的所有元素，做到不重不漏。对于有限范围内的整数，可以逐一列举。
